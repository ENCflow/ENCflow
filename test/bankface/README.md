# test/bankface — 河岸面の掃流遮断と供給量制限(掃流砂 Exner の保存則)

[English](en/README.md)

掃流砂 Exner(`f_fluvial`)に 2026-10-17 に入れた 2 つの挙動変更
(developer.md §84.1・§84.2。蛇行発達への拡張 docs/meander_plan.md の段 0)の
検定です。

1. **河岸面の掃流遮断**(§84.2): 掃流砂は河床面を転がるもので、
   (R1) 乾いたセルは供給せず、(R2) 供給セルの水面より高い地盤には運ばない。
   変更前は両セル平均のエッジ水理量のため、水面より 2 m 高い乾いた河岸セルの
   地盤が数 mm〜数 cm 変動していた(土砂が陸に「登る」)。
2. **保存型の供給量制限**(§84.1): 複数エッジの同時流出が土層厚 sd を
   超えるセルでは、そのセルを風上とする全エッジの流砂量を同じ比率で縮小する。
   変更前はエッジ単独のクランプだけで、超過分を岩盤床でクリップして土砂体積が
   消えていた(本ケースの薄土層では 0.57 m³)。

## 構成

| 項目 | 値 |
|---|---|
| 領域・格子 | 60 m × 20 m、60 × 20 セル(Δx = 1 m)、四周壁(閉領域) |
| 地形 | 第 6〜15 行が水路(河床勾配 0.002、西が高い)、その両側は河床 +2 m の乾いた河岸。`make_init.py z` |
| 初期水深 | 水路内のみ: 上流半分(i ≤ 30)1.0 m、下流半分 0.2 m のダム破壊型。河岸は 0。`make_init.py h` |
| 土層 | `param.txt` sd₀ = 10 m(制限が発動しない)/ `param_thin.txt` sd₀ = 0.5 mm(制限が発動する) |
| 流砂 | 芦田・道上式、d50 = 1 mm、τ*c = 0.05、空隙率 0.4、変動上限 0.05 m |
| 時間 | dt = 0.05 s、60 s(毎ステップ更新)。終了時に `save*/state.dat` |

| ファイル | 内容 |
|---|---|
| `Check_bankface.py <save> <sd0>` | (1) 体積保存 \|Σ(z − z₀)\| < 1e-9、(2) 乾いた河岸セルの max\|z − z₀\| が厳密に 0、(3) 共動更新 max\|(sd − sd₀) − (z − z₀)\| < 1e-10、(4) 水路内の活性 > 1e-4 m、(5) min sd ≥ 0 |

## 実行

```bash
make
./Run.sh          # 入力生成 → param.txt / param_thin.txt → Check(数秒)
./Run_MPI.sh 4    # MPI。state.dat が逐次とバイト一致するのが規律
```

## 所見(2026-10-17。gfortran 13.3、-O2 厳密数学)

| 検定 | sd₀ = 10 m | sd₀ = 0.5 mm |
|---|---|---|
| (1) Σ(z − z₀) | −2.5e-14 | 5.4e-13(供給量制限 352,127 セル更新で発動) |
| (2) 乾いた河岸の max\|z − z₀\| | 0 | 0 |
| (3) 共動更新 | 1.8e-15 | 5.7e-14 |
| (4) 水路内の max\|z − z₀\| | 11.9 mm | 6.7 mm |
| (5) min sd | 9.99 m | 0(岩盤露出。床は割らない) |

変更前のコードでは (2) が 0.39 mm / 0.50 mm、薄土層の (1) が 0.95 m·cell
(0.57 m³ の消失)で FAIL する。
