# test/wave_river — 河口の規則 wave_vmax(波浪の沿岸漂砂と河川流の切り分け)の検定

[English](en/README.md)

沿岸漂砂(fn_wave。developer.md §84.15)は「砕波帯より深い湿潤セルはどこでも波の源」なので、
河川の流下水深が砕波水深 h_b/γ を超える河道は源になり、河道内の浅い所(砂州・早瀬)が砕波帯と
判定されて沿岸漂砂が働きます(examples/delta で発散した機構)。河口の規則 `wave_vmax` は流速
|V| がしきい値を超えるセルを源にも砕波帯にもしません(露出度 0 = 陰)。本検定はその最小再現です。

## 設定

300 m × 200 m(Δx = 2.5 m)。西の陸地(+1.5 m、非侵食)を幅 10 m・河床 −1.2 m の河道が貫き、
東の海(海浜勾配 0.02、沖は水深 2 m)に出る。河道の途中 x = 40〜60 m に早瀬(河床 −0.5 m、
水深 ≈ 0.6 m < h_b/γ = 0.86 m)。流入 10 m³/s(河道の流速 0.76〜1.0 m/s)、東辺は長波放射。
沖波 H₀ = 0.5 m、T = 5 s、進行方向 150°(examples/delta と同じ斜め入射)。掃流砂は容量給砂、
土層は河道内 1 m。morfac = 10、水理 30 分 = 地形 5 h(`make_init.py`)。

| 構成 | 設定 | 役割 |
|---|---|---|
| nowave | fn_wave なし | 河道の河床変化の基準(早瀬は河川が自力で 0.7 m 削る) |
| novmax | 波あり、規則なし | 問題の再現: 淵が源になり早瀬〜河道全体の河床が波で 1 m 動く |
| vmax | 波あり、wave_vmax = 0.5 m/s | 河道は不変(差 ≤ 0.014 m = 河口砂州の変化の水理的な帰還)、海側では波が働く |

## 検定項目(Check_wave_river.py)

1. vmax: 河口から 15 m 以上上流の河道で |Z − Z_nowave| が 0.05 m 未満、かつ novmax の差の 0.05 倍未満。
2. novmax: 同区間の差が 0.5 m 以上(規則なしでは河道に波が入ることの確認)。
3. vmax: 海側で Σ|Z − Z_nowave| dA が 10 m³ 以上(規則が海側の沿岸漂砂を止めていない)。
4. MPI: state.dat が逐次とバイト一致(Run_MPI.sh の cmp)。無効時(wave_vmax 未指定)のビット一致は
   test/wave_shore の low を規則の追加前後で比較して確認済み。

## 実行

作業場所は言語によらず `test/wave_river` 直下です(`en/` へは移動しない)。`Run.sh` と
`Run_MPI.sh` は正本の入力を使います。`en/param_*.txt` はコメントの英訳(値は同一)で、
公式の検定入力を置き換えるものではありません。直接実行する場合もケース直下から
`./encflow en/param_vmax.txt` のように指定します。出力先は正本と同じなので、同じ作業
コピーで続けて実行すると結果が上書きされます。

```bash
make
./Run.sh          # 入力生成 → nowave / novmax / vmax → Check(3 ラン。1 分程度)
./Run_MPI.sh 4
```
