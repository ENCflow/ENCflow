# test/gwsect — 断面形 σ のセルでの地表と地下・水源の水の受け渡し

[English](en/README.md)

[断面形(σ 則)](../../docs/users_guide/channel.md#断面形σ-則)(p_sect_m)のセルでは、
地表の水深 h は水位としての水深で、体積は矩形換算水深 v(h) に比例します
(D より浅いとき、水深あたりの体積の増え方は水面幅の率 σ(h) = (h/D)^m)。
浅水流の外のモジュールが地表へ水を足し引きするときは、水深でなく v で受け渡します
(h' = v⁻¹(v(h) + Δv)。developer.md §26.2)。水深をそのまま足すと体積は σ(h) 倍しか
増えず、湧き出した水・融けた雪が消えます。浸透では、引いた体積の 1/(m+1) しか
地下に入りません。その検定です。

- **param.txt(回帰の reference と比較)**: [test/gwwidth](../gwwidth/) と同じ閉じた谷
  (12 × 8 セル、dx = 10 m。列 10 は幅 2 m のサブグリッド河道、wfrac = 0.2)の河道に、
  断面形 σ(h) = (h/D)^0.5(遷移深さ D = 掘り込み深さ 0.5 m)を重ねる。1 時間の
  一様降雨 50 mm/h が浸透し(Green-Ampt)、地下水の側方流で谷へ集まって、谷底の
  σ の河道へ湧き出す。雨には濃度 1 mg/L のトレーサを持たせる。
- **param_nowidth.txt**: 河道幅を外し、σ をセル全幅の断面に掛ける。
- **param_gwc.txt**: 地表を不浸透にし、1 時間の一様降雨 20 mm/h を全セルの枡から
  管路層へ流し込む。満管で地表へ噴き出し、谷底の最下流の河道セルには陸側吐口を置く。
  雨と噴出・吐口の水の濃度は 1 mg/L。
- **param_snow.txt**: 地表を不浸透にし(地下水なし)、全セルの初期積雪 20 mm を
  気温 10 ℃・度日係数 20 mm/℃/day で融かす(2.4 時間で融け切る)。
- **param_evap.txt / param_evap_nowidth.txt**: σ のセルの蒸発散(developer.md §27.1。
  河道幅あり / なし)。地下水の側方流をなくし、2 時間の一様降雨 50 mm/h で土層を
  満たして、余った雨を谷の河道に溜める。可能蒸発散 PET は一定 48 mm/day(2 mm/h)。
  全セルに水が十分あるので、蒸発散は PET × 面積 × 時間 に等しいはず。σ のセルでは、
  今の水面幅 σ(h) の分が河道の水から、水面の外の河岸(と河道幅のセルの陸の部分)が
  地下水から蒸発する。

## 実行

```bash
make
./Run.sh
./Run_MPI.sh 4
```

## 所見

| 量 | 修正後 | 修正前(2026-11-04 の main の実行ファイル) |
|---|---|---|
| param.txt の最終の総水量 (m。領域平均) | 0.0508264(雨の総量と一致) | 0.0496(2.5 % が消えた) |
| param_nowidth.txt の最終の総水量 (m) | 0.0508264 | 0.0413(19 % が消えた) |
| param_gwc.txt の最終の総水量 (m) | 0.0203306(雨の総量と一致) | 0.0210(管路への流入で 3.5 % 増えた) |
| param_snow.txt の総水量 (m。地表 + 積雪) | 0.0200000(一定) | 0.0198(融けた水の 1 % が消えた) |
| 谷底の濃度 (mg/L) | 0.99986〜0.99993(管路は 1.00044〜1.00049) | 1.02〜1.03(河道幅なし 1.31、管路 1.0004〜1.0037) |

- 修正前の濃度が 1 を超えたのは、σ のセルで浸透の同率移動の割合を水位から出して
  いたためです。浸透する水が持ち出す物質が少なくなり、地表に残った水が濃く見えました。
  修正後は、浸透の記録も割合も体積(矩形換算水深)で取ります。
- 濃度の 1 からの小さなずれ(1e-4 程度)は、浸透・流入の同率移動の割合をステップの
  終わりの水深で評価する既存のずれです(test/gwwidth と同じ。検定の許容 ±1e-3 は
  これを許す幅)。
- 浸透の量そのもの(水位の低下 = 濡れた幅での浸透)は変えていません。管路層との
  やり取りの等化の上限は、今の水深の水面幅 σ(h) で線形化した近似です(水は保存)。
- 蒸発散(param_evap*.txt。developer.md §27.1):

  | 量 | 修正後 | 修正前(2026-11-04 の main の実行ファイル) |
  |---|---|---|
  | 助走 30 分の後の蒸発散の増分と PET × 面積 × 時間 のずれ(相対。記録時刻ごとの最大)。河道幅あり | 6e-8(出力精度) | −7.3 %(足りない) |
  | 同。河道幅なし | 4e-16 | −6.3 %(足りない) |
  | 最終の総水量 + 蒸発散 − 雨の総量(相対) | 3e-9 | 3e-9 |

  修正前は、河道に水がある間、σ のセルの水面の外の河岸と、河道幅のセルの陸の部分が
  蒸発しませんでした(下げた水位をセル全体の要求からそのまま差し引いていた)。
  雨の降り始めの数ステップは、河道のセルの地下がまだ空で要求を満たせないため、
  検定は助走 30 分の後の増分で行います。
- 地形変化の間隙水・溶岩・VZ の出口・氷河の融解水・空隙率の変更も同じ関数
  (`sect_add_vh`)で受け渡します。このテストではそれらの構成は流していません。
