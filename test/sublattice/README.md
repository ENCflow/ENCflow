# test/sublattice — 運動量保存形移流の斜め副格子(市松)モードの減衰率

ENC の斜めリンクは $`i+j`$ の偶奇が同じセル同士だけを結びます。偶数・奇数の
副格子で逆回転する斜め循環は、発散ゼロで水位を変えず(圧力項が効かない)、
運動量保存形移流(`f_advection_scheme = 2, 3`)の斜めエッジの検査体積が同じ
偶奇のセル・リンクだけで構成されていた間は移流項も作用しませんでした
(developer.md §68.36)。このケースは、そのモードを無摩擦の閉じた水槽に
初期値として置き、各スキームでの減衰率を直接測ります。

## 構成

| 項目 | 値 |
|---|---|
| 領域・格子 | 1 km × 1 km、Δx = Δy = 10 m(100 × 100)、平坦、無摩擦、四周壁、h0 = 5 m |
| 初期流速 | 1 セル渦 ψ = A sin(πx/L) sin(πy/L)、最大 V0 = 0.2 m/s(user_initial `gyre_*`) |
| `param.txt` | 渦に (−1)^(i+j) を乗じた副格子モードだけ(`gyre_alternating`)。法線エッジの初期流速は両セル平均で 0 |
| `param_smooth.txt` | 対照: 分けない渦(`gyre_smooth`)。物理的な渦なので保たれるべき |
| `param_mixed.txt` | 滑らかな渦(振幅 1)に副格子モード(振幅 0.5)を重ねる(`gyre_mixed`)。背景流の流束による線形減衰率 = 実ケースの状況 |
| `param_*_s1/s2.txt` | スキーム 1・2 の比較(`./Run.sh -s`) |
| 時間 | dt = 0.5 s(Cn = 0.35)、1 時間、出力 5 分ごと(u・v の分布) |

`Check_sublattice.py` は u・v の分布を初期パターンに射影した振幅
a_alt(副格子モード。$`\sum s\,(u u_p + v v_p)/\sum(u_p^2+v_p^2)`$、
s = (−1)^(i+j))と a_sm(滑らかな渦)の時間変化を表にし、e-folding 時間を
推定します。判定は、smooth と mixed で 1 時間後に滑らかな渦が 50 % 以上
残ること(背景流を壊さない)。副格子モードの減衰時間は計測値を表示します
(保存形の修正前は背景流下でも 1094 s、修正後は 87 s)。

## 実行

```bash
make
./Run.sh          # param.txt・param_smooth.txt・param_mixed.txt
./Run.sh -s       # スキーム 1・2 の比較も
./Run_MPI.sh 2    # np=2 と逐次の Log のビット一致
```

## 結果(2026-10-17。gfortran -Ofast)

副格子モードの振幅(初期値 1 または 0.5 に対する比)と e-folding 時間 τ。

| 構成 | スキーム 3(修正前) | スキーム 3(修正後) | スキーム 2(修正後) | スキーム 1 |
|---|---|---|---|---|
| alternating: 5 分 / 60 分後 | 0.57 / 0.33(τ 4570 s) | 0.18 / 0.08(τ 2270 s) | 0.18 / 0.08 | 0.40 / 0.10(τ 2020 s) |
| mixed: 副格子モード τ | 1094 s(60 分後も符号を変えて残る) | **87 s**(5 分で 0.03) | 87 s | 364 s |
| mixed: 背景の渦の残存(60 分) | 0.72 | 0.89 | 0.89 | 0.88 |
| smooth: 渦の残存(60 分) | 0.96 | 0.97 | 0.97 | 0.94 |

- 副格子モードだけの構成(alternating)は、移流項の減衰が流束 |q_t| に比例し、
  流束がモード自身しかないので振幅に比例して弱まり(代数的減衰)、τ は
  目安に留まる。背景流があれば(mixed)線形に減衰し、修正後は 5 分で消える。
- 修正前は副格子モードが減衰しないまま背景の渦と干渉し、背景の渦を
  28 % 失わせていた。修正後は smooth と同程度(11 %)。
- 初期流速はセル中心で与えるため、最初の 5 分で法線エッジに載らない成分が
  落ちる(alternating の KE が 0.33 または 0.06 に落ちる段)。これは初期値の
  整合で、減衰率には含めない。
