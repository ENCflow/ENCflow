# test/bedfines — Verification of the ledger of fines in the bed (f_bedfines)

> English mirror of test/bedfines/README.md. The Japanese file is the master copy.

[日本語](../README.md)

developer.md §84.10, docs/meander_plan.md §3.6c (both in Japanese). In a
computation that superposes bed load (fluv_d50) and suspended sediment
(susp_d50), this verifies the two-component ledger in which the entrainment
of suspended sediment is limited to the fines sf stocked in the bed
(0 ≤ sf ≤ sd; output Sf), and the fines move together with bed load, bank
erosion and avalanching (equal mobility).

## Configuration

| Configuration | Settings | Checks |
|---|---|---|
| off | Suspended sediment only, f_bedfines = 0 (the same closed-domain dam break as test/suspend) | Reference for the comparison with all. No Sf output |
| all | 100 % fines (fines_frac0 = 1, L_a = 0.01 m) | state.dat bit-identical to off, sf = sd |
| mix | Bed load + suspended sediment, 50 % fines (L_a = 0.05 m) | 0 ≤ sf ≤ sd; the total solids Σhs + (1−λ)Σ(z − z0) and the fines Σhs + (1−λ)Σ(sf − sf0) are below 1e-9; fines have gone into suspension (Σ(sf − sf0) < 0) |
| coarse | Bed load + suspended sediment, coarse only (fines_frac0 = 0) | hs and sf stay exactly 0 while the bed moves |
| feed | Fines fed at concentration 0.002 from a segment inflow into a straight channel of coarse material only (10 cells wide, slope 0.002) (suspended sediment only) | z − z0 ≥ 0 (the bed is not eroded), sf = z − z0 (stock = deposit), deposition occurs |
| bfeed | A bed with 50 % fines (L_a = 10 m, so the fines fraction of the outflow is ff = 0.5), only bed load moves (no entrainment), the bed is mobile up to the upstream end with capacity feed | \|z − z0\| and \|sf − sf0\| of the inlet column < 1e-9 (the feed has the same composition as the inflow cell), 0 ≤ sf ≤ sd, the stock moves along with the bed load |
| rt1 → rt2 | mix split at 4 s | state.dat and geomorph_fines.dat bit-identical to mix |

## Running

```
make
./Run.sh            # serial. Check_bedfines.py + cmp
./Run_MPI.sh 2      # MPI (np=2). Also checks bit identity with the serial save
```

The inputs zinit.txt / hinit.txt / sdinit.txt / sdfeed.txt are generated by
make_init.py (not tracked).
