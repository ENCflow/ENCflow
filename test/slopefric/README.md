# test/slopefric — 急斜面の薄層流の摩擦と流砂のせん断(斜面に沿う速さ・地盤に直角な水深)の検定

[English](en/README.md)

急勾配の重力補正(`&list_enc` の `f_gravity_correction`)の、**等流**の検証ケースです。

- `f_gravity_correction = 1`(2026-11-05 までの既定): 有効重力 $`g_e = g\cos^2\theta`$ が勾配と摩擦の両方に掛かって
  相殺し、等流は古典の水平投影のマニング式 $`h = (n^2q^2/\tan\theta)^{3/10}`$ になります
  ($`h`$ は鉛直の水深、$`q = h|\mathbf V|`$ は水平の単位幅流量。developer.md §91、
  docs/users_guide/steep_slope.md §2.3)。
- `f_gravity_correction = 2`(既定): 摩擦と流砂のせん断を、斜面に沿う速さと地盤に直角な水深 $`h\cos\theta`$ で
  評価します(developer.md §93)。等流は斜面に沿う式の $`h\cos\theta = (n^2q^2/\sin\theta)^{3/10}`$
  (Chow 1959、Van Emelen ら 2014)になります。
- `f_gravity_correction = 3`(試作): 2 に加えて、水面の勾配の項の有効重力を可変の重力 $`g'`$ にします
  (developer.md §100、docs/users_guide/steep_slope.md §2.6)。摩擦と流砂のせん断は 2 と同じで、水深が
  一様なら $`g' = g_e`$ なので、等流は 2 と同じ斜面に沿う式になるはずです。

1 と 2 の二つの関係が、斜面の向き(格子の x 軸から 0°・22.5°・45°)と 8 近傍・4 近傍のどの組でも成り立つ
ことと、流砂のせん断(掃流砂の動き出し)が 2 で斜面に沿う底面せん断 $`\tau_b = \rho g\,h\cos\theta\,\sin\theta`$
になることを、解析解と比べて確かめます。3 は 8 近傍の 3 向きと流砂の 2 向きで、2 と同じ式に合うことを
確かめます。reference 比較ではなく `Check_slopefric.py` の自己検定で
合否を決めます(test/dbonset と同じ型)。

## 構成

| 項目 | 値 |
|---|---|
| 地形 | 60 m 四方の一様な斜面(傾斜角 30°、勾配 0.5774、下り向き φ)。上りの辺(西・南)は壁、下りの辺(東、φ > 0 では北も)は自由流出(`make_init.py` が `d_<φ>/z.txt` を書く) |
| 格子 | 60 × 60 セル(Δx = 1 m)。8 近傍(`p_diagratio` の既定)と 4 近傍(`p_diagratio = 0`) |
| 流れ | 全面に 300 mm/h の一定の雨、マニングの粗度 0.1、dt = 0.1 s、20 分(到達時間の約 10 倍で定常) |
| ケース | 流れ: φ = 0°・22.5°・45° × 8・4 近傍 × `f_gravity_correction` 1・2 の 12 ケースと、8 近傍の 3 の 3 ケース(名前は `p22p5_n8_g2` = 22.5°・8 近傍・2)。流砂: φ = 0°・45° × 1・2・3 の 6 ケース(8 近傍。名前の末尾が `_sed`) |
| 流砂の構成 | 流れと同じ斜面に掃流砂(`f_fluvial = 1`、芦田・道上、τ*c = 0.05、s = 1.65、粒径 0.0515 m、可動層 1 m)。粒径は 2 の侵食の始まりが流下方向の水平距離 30 m になる値。河床変化を小さく保つため `morfac = 0.02` |

| ファイル | 内容 |
|---|---|
| `make_init.py` | 全ケースの地形 `d_<φ>/z.txt` と設定 `p_<case>.txt` を書く(引数 `list` でケース名を出す)。定数と、侵食の始まりの解析解 `sed_lc` は Check と対 |
| `Check_slopefric.py` | 各ケースの最後の出力(H・u・v・Z)から下の (1)〜(4) を判定する(引数 `table` で値の表も出す) |

判定:

1. 等流の関係: 壁と流出の辺から 5 セル以上離れ、水深が 8 mm 以上のセルで、$`h`$ と $`q = h|\mathbf V|`$ から
   求めた $`h/h_{解析}(q)`$ の平均が 1 から 0.5 % 以内、各セルが 1.5 % 以内(1 は古典の式、2・3 は斜面に
   沿う式)
2. 向き・近傍によらない: (1) が φ と近傍の全部で成り立つ
3. 検出力: 2 の水深を 1 の式で測ると $`\cos^{-13/10}30° = 1.206`$ 倍(二つの式を区別できる)
4. 流砂のせん断: 侵食の始まる流下方向の水平距離が、無次元掃流力が τ*c に達する位置 ℓ_c(1: 古典の
   $`\tau_* = h\tan\theta/(s\,d)`$ で 25.37 m、2・3: 斜面に沿う $`\tau_* = h\cos\theta\,\sin\theta/(s\,d)`$ で 30.00 m)と
   合う。ℓ_c − 1.5 m より上流は侵食なし、ℓ_c + 2〜6 m は全セルで侵食(45° の斜面では、上の角を通る流線から
   3 m 以内を除く)

水深は小数 4 桁(0.1 mm)で印字されるので、(1) は印字の丸めが 1 % 未満の 8 mm 以上で比べます。

## 実行

```bash
make            # 実行ファイルへのリンク
./Run.sh        # 21 ケースを実行して判定(4 スレッドで約 4〜5 分)
./Run_MPI.sh 2  # MPI(先に Run.sh を実行しておくと、逐次の save と state.dat をバイト比較する)
```

MPI のバイト比較は、逐次と MPI の両方を -O2(厳密な数学)でビルドしたときに意味を持ちます。既定の
-Ofast のビルドでは、逐次と MPI のビルドの差で一部のケース(流砂の 2 のケース)の最終桁が食い違う
ことがあります(developer.md §28.3・§93)。

## 所見

- 2 は 1 と同じ流量で鉛直の水深が 1.206 倍深く、水平流速が遅くなります(30°)。比が 1 からわずかに
  (+0.2〜0.4 %)ずれるのは、水深の勾配と移流による局所の釣り合いからのずれと、水深の印字の丸めです。
- 侵食の始まりは、2 では 30 m、1 では 25 m で、流砂のせん断の評価の違いがそのまま現れます。2 で
  流砂のせん断の倍率がなければ、始まりは約 52 m になる見積もりです(無次元掃流力が $`\cos^{7/3}30° = 0.715`$ 倍)。
- 3 は 2 と印字の桁でほぼ同じです(0° は同じ値、22.5°・45° で比の最終桁が 1〜2 違う。侵食の始まりは
  同じ)。一様な斜面の薄層流では水深の勾配が勾配に比べて小さく、$`g' \approx g_e`$ だからです。
- `morfac = 1` で 20 分回すと、下流の河床が水深の数十倍変わって頭部侵食や堆積が出るので、始まりの
  位置だけを見るために `morfac = 0.02` にしています。
- 45° の斜面の、上の角を通る流線(西と南の壁からの流線の合わせ目)の近くは、横への広がりで水深が
  浅く、侵食の始まりが 1 セル遅れます。この検定の地形の性質なので判定から除いています。

## できないこと・限界

- 一様な斜面の等流だけの検定です。勾配が変わる斜面(凸・凹)の遠心加速度、急な地盤の上の深い水、
  圧力の項の係数(波速)は扱いません(docs/users_guide/steep_slope.md §6。3 の深い水と波速は
  [test/steepwave](../steepwave/))。
- 混合体流動(土石流など)の抵抗則のうち、2 の倍率が掛かるのはマニングの項(マニングと合成する抵抗則
  `f_dbres` = 1・5 のマニングの項と、希薄側でマニングに退化する辺)だけです(docs/users_guide/steep_slope.md
  §2.3・§6.2、developer.md §93)。この検定は水の流れだけを見ています。
- 段差(壁・縁石・DEM の段)を下る流れは扱いません。1 辺だけの段では場の勾配(minmod)がほぼ 0 に
  なるので、2 は 1 と同じ扱いです(developer.md §93)。
