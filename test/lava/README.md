# test/lava — 溶岩流(fn_lavaflow): Huppert 相似解・Bingham 停止厚・塑性ドーム・壁際の固化・土層の埋没・温度(冷却・熱の移流・冷えて止まる流れ・熱の横断の数値拡散)

[English](en/README.md)

溶岩流モジュール(`fn_lavaflow`。Bingham 粘性重力流 + 固化。
[ユーザーガイドの溶岩流の章](../../docs/users_guide/lavaflow.md)、developer.md §51)の
検定です。reference 比較なしの解析解検定で閉じます([test/volcano](../volcano/)
と同じ流儀)。

1. **Huppert**(`param.txt`): 平坦床・中央 1 セルの定率噴出(降伏応力 0 =
   Newton 極限)。Huppert (1982) の定率供給軸対称相似解
   r_N = 0.715 (g Q³/3ν)^{1/8} √t と、面積等価半径・成長則・台帳を比べる。
2. **Bingham**(`param_ty.txt`): 等勾配斜面(tanθ = 0.2)の上流端の列噴火口
   から 300 s 供給して止める。停止厚 h∞ = τ_y/(ρ g tanθ) と固化・台帳を比べる。
3. **既定値の同値**(`param_min.txt` / `param_minx.txt`): 構成 2 と同じ設定で
   `lv_visc`・`lv_vsol` を省略 / 明示し、save と Log がバイト一致(§66)。
4. **等方性**(`param_dome.txt`): 平坦床の中央 1 セルから 900 s 噴出して止まった
   溶岩の静止形を、塑性ドームの解析解 h(r)² = (2τ_y/ρg)(R − r)(Blake 1990)と比べ、
   格子軸の方向と斜めの方向で同じ形になることを検定する(developer.md §51.4)。
5. **壁際の固化**(`param_wall.txt`): 平坦な床の端の高さ 10 m の段(壁)の前に
   溶岩をため、壁に接する列まで全量が固化することを検定する(developer.md §51.5)。
6. **土層の埋没**(`param_bury.txt`): 構成 5 の地形に土層と地下水(Green-Ampt)を
   加え、固化した溶岩の下の土層が埋まり、しみ込んでいた水が地表へ移っても水の
   総量が保たれることを検定する(developer.md §51.6)。
7. **静止した層の冷却**(`param_cool.txt`。温度モード f_lvtemp = 1): 平坦な床に厚さ 1 m の
   一様な溶岩の層(流れない)を置き、放射と対流で冷える温度を、冷却の式の後退 Euler の
   漸化式と厳密解に比べ、固化温度で固まる時刻と熱の台帳を検定する。`param_coolm.txt`
   (構成 7m)は気温を fn_meteo から読む同じ計算で、save がバイト一致すること
   (developer.md §51.7)。
8. **熱の移流**(`param_adv.txt`。温度モード・冷却なし): 噴出温度の違う 2 つの火口から
   噴出させ、熱量の保存と温度の範囲(2 つの噴出温度の間)を検定する。`param_adv0.txt`
   (構成 8')は同じ入力で f_lvtemp = 0 にした等温の計算で、溶岩の堆積がバイト一致すること
   (温度感度 0・冷却なしの温度モードの流れは等温と同じ)。
9. **冷えて止まる流れ**(`param_run.txt`・`param_run4.txt`。温度モード): 一様な斜面に同じ
   体積を噴出率 Q と 4Q で出し、冷えて止まった流れの長さが噴出率とともに増えることを
   検定する(Walker 1973 と同じ向き)。`param_runi.txt`・`param_runi4.txt` は温度を
   計算しない等温の対照で、長さが噴出率によらないこと。構成 9r は構成 9 を途中で保存して
   再開した計算が通しの計算とバイト一致すること(Run.sh が入力を作る)。
10. **熱の横断の数値拡散**(`param_x0.txt`・`param_x0m.txt`・`param_x45.txt`・`param_x45m.txt`。
    温度モード・冷却なし): 一様な斜面を流れるシート流の噴火口の片側から 1150 °C、もう片側から
    1050 °C の溶岩を噴出させ、温度の境目が流れを横切る向きに広がる幅を、流れが格子軸に沿う
    向き(0°)と 45° で、熱の移流の 1 次風上(`f_lvtemp_scheme = 1` を明示)と MUSCL
    (`f_lvtemp_scheme = 3`。既定)で比べる。0° では
    広がらないこと、45° の 1 次風上では修正方程式の横断の拡散係数 (√2/4)·u·Δx に合うこと、
    MUSCL ではその 1/4 未満になることを検定する(developer.md §94)。

## 実行

```bash
make
./Run.sh          # 構成 1 → Check → 構成 2 → Check → 構成 3 の同値検定 → 構成 4〜9・9r・10 → Check(1 スレッドで約 45 秒)
./Run_MPI.sh 4    # MPI。state.dat・lavaflow.dat(・lavaflow_temp.dat)が逐次とバイト一致(-O2 厳密数学)
python3 Fig.py    # figs/lava.png(引数 en で英語版を en/figs/ に)
```

(developer.md §51.4)。下段中: 同じ静止形を上から見た図。解析解の半径(破線)の
円になります。
下段右: 構成 5 の最終の地形(行平均)。壁の前にたまった溶岩が、壁に接する列まで
固化しています(壁際の dz 0.98 m)。流れ込みのエッジを停止判定に数えていた修正前の
判定では、壁に接する列が溶けたまま(hl 0.98 m、噴出量の 13%)残りました
(developer.md §51.5)。

| 構成 10 (3) 45° の 1 次風上 | σ = 6.85・11.04・15.73・19.37 m(s = 14・35・71・106 m)、D⊥ = 0.357·u·Δx(理論 0.354、+1.0%。許容 15%) | PASS |
| 構成 10 (4) 45° の MUSCL | σ = 3.83・5.02・6.06・6.75 m、D⊥ = 0.034·u·Δx(1 次の 0.09 倍。許容 < 0.25)、Tl = 1050〜1150 °C | PASS |

- 停止厚の +7% は停止判定 `lv_vsol` の打切りによる上振れ
  h∞ + √(v_sol h/(coef (2h + h₀) S)) を含みます(§51.3)。停止の漸近は遅く、
  検定は「検定時間内に排水が h∞ 近傍へ届く粘度」で組んであります
  (η = 1e4 では 900 s で 29% 上振れ = パラメータ選定の目安)。
- 台帳は注入の厳密加算とエッジ反対称の拡散により機械精度で閉じます。
  リスタート往復(300 s save → restore → 600 s)もバイト一致です(構成 4 でも
  3000 s save → restore → 6000 s がバイト一致)。
- 構成 4 は格子の向きによる歪みの検出器です。修正前の方式(降伏と停止を法線方向の
  勾配だけで判定)で回すと、扇形の面積等価半径の比 0.860、中心厚 +9.5%、面積等価
  半径 −5.1%、断面 RMS 12.5% で FAIL します。粘度は静止形に効かないので、検定時間
  内に止まる値(η = 1e6 Pa·s)にしてあります(3000 s と 6000 s の中心厚の差 1.6%)。
- 構成 1・2 は修正(2026-11-03)の前後で save がバイト一致です(構成 1 は τ_y = 0、
  構成 2 は幅方向に一様でエッジに沿う方向の勾配が 0)。
- 構成 5 は停止判定の検出器です。流れ込みのエッジを数えていた修正前の判定で回すと、
  固化率 0.869、壁際の hl 0.978 m で FAIL します。壁際以外の堆積の形は修正の前後で
  同じです。構成 1〜4 の save は停止判定の修正(§51.5)の前後でもバイト一致です。
- 構成 6 は土層の埋没の検出器です。修正前は固化で z だけが上がり、溶岩の下の
  80 セルに sd = 1 m と地下貯留(最大 0.059 m)が残って FAIL します。溶岩の堆積
  (z・hl)は埋める前後でバイト一致です(変わるのは土層と水だけ)。構成 1〜5 は土層を
  使わないので、埋没の修正(§51.6)の前後で save がバイト一致です。図には構成 6 を
  入れていません。
- 構成 7〜9 は温度モード(developer.md §51.7)の検定です。構成 7 の後退 Euler は 1 次精度で、
  10 s の刻み(冷却の時定数は約 80 分)で温度の低下の誤差が 0.09% です。構成 9 は、等温では
  流れの長さが体積と降伏応力で決まり噴出率によらない(停止厚 0.98 m の一様な堆積)のに対し、
  温度モードでは噴出率の低い流れが先端から冷えて早く止まり、その背後に溶岩がたまって厚く
  なる(最大の厚さ 3.5 m)ことを示します。図には構成 7〜9 も入れていません。
- 構成 1〜6 の save・分布出力・Log.txt は、温度モードの追加の前後でバイト一致です
  (等温の計算は温度の配列を確保せず、同じコードを通る)。
- 構成 10 は熱の移流の数値拡散の検出器です(developer.md §94)。4 近傍の 1 次風上は、流れが
  格子軸に沿うと横断に拡散しませんが、45° では x・y の両方のエッジから入る熱が送り手の温度の
  平均になり、修正方程式の D⊥ = (Δx/2)(|u_x| sin²θ + |u_y| cos²θ) = 0.354·u·Δx で広がります。
  MUSCL(`f_lvtemp_scheme = 3`)は主要項を消し、残りは限定器が境目の両端で 1 次に戻る分です。
  0° では温度が流れに沿って一定・横断に階段状なので再構成が働かず、1 次風上とバイト一致します。
  構成 1〜9 の save(save_info.txt の作成時刻の行を除く)・分布出力・Log.txt は、MUSCL の追加
  (当時の既定は 1)の前後でバイト一致でした。既定を 3 にした(2026-11-05)ことで変わるのは、
  温度モードで溶岩が流れる構成 8(温度の分布だけ。冷却がなく温度感度も 0 なので堆積は変わらない)と
  構成 9・9r(堆積の形と流れの長さ。噴出率 Q の流れで 55 → 50 m、比 2.64 → 2.90)です。
  等温の構成 1〜6 と構成 9 の等温の対照、流れない構成 7、1 次風上を明示した構成 10 の x0・x45 は
  変わりません。図には構成 10 を入れていません。
- 流束のステンシルは 4 近傍のままで、8 近傍化は拡散型モジュール共通の候補として
  残ります(developer.md §61.4)。
