# test/lava — 溶岩流(fn_lavaflow): Huppert 相似解・Bingham 停止厚・塑性ドーム・壁際の固化

[English](en/README.md)

溶岩流モジュール(`fn_lavaflow`。Bingham 粘性重力流 + 固化。
[ユーザーガイドの溶岩流の章](../../docs/users_guide/lavaflow.md)、developer.md §51)の
検定です。reference 比較なしの解析解検定で閉じます([test/volcano](../volcano/)
と同じ流儀)。

1. **Huppert**(`param.txt`): 平坦床・中央 1 セルの定率噴出(降伏応力 0 =
   Newton 極限)。Huppert (1982) の定率供給軸対称相似解
   r_N = 0.715 (g Q³/3ν)^{1/8} √t と、面積等価半径・成長則・台帳を比べる。
2. **Bingham**(`param_ty.txt`): 等勾配斜面(tanθ = 0.2)の上流端の列噴火口
   から 300 s 供給して止める。停止厚 h∞ = τ_y/(ρ g tanθ) と固化・台帳を比べる。
3. **既定値の同値**(`param_min.txt` / `param_minx.txt`): 構成 2 と同じ設定で
   `lv_visc`・`lv_vsol` を省略 / 明示し、save と Log がバイト一致(§66)。
4. **等方性**(`param_dome.txt`): 平坦床の中央 1 セルから 900 s 噴出して止まった
   溶岩の静止形を、塑性ドームの解析解 h(r)² = (2τ_y/ρg)(R − r)(Blake 1990)と比べ、
   格子軸の方向と斜めの方向で同じ形になることを検定する(developer.md §51.4)。
5. **壁際の固化**(`param_wall.txt`): 平坦な床の端の高さ 10 m の段(壁)の前に
   溶岩をため、壁に接する列まで全量が固化することを検定する(developer.md §51.5)。

## 構成

|---|---|---|---|---|
| 領域・格子 | 61 m × 61 m、Δx = 1 m、平坦 | 100 m × 8 m、Δx = 1 m、tanθ = 0.2(`zinit.txt`) | 61 m × 61 m、Δx = 1 m、平坦 | 40 m × 8 m、Δx = 1 m、平坦な床と i ≥ 31 の高さ 10 m の段(`zwall.txt`) |
| 噴出 | 中央 (31, 31) に 0.5 m³/s 一定 | 上流端 i = 5 の 8 セルに計 0.5 m³/s を 300 s(重複時刻で階段状に停止) | 中央 (31, 31) に 2 m³/s を 900 s(計 1798 m³) | 壁から 3 m の列 i = 28 の 8 セルに計 0.2 m³/s を 300 s |
| 流体 | ρ = 2600、η = 2e4 Pa·s、τ_y = 0、固化なし | ρ = 2600、η = 2e3 Pa·s、τ_y = 2000 Pa、固化レート 0.005 m/s、停止判定 5e-4 m/s | ρ = 2600、η = 1e6 Pa·s、τ_y = 1e4 Pa、固化なし | 構成 2 と同じ |
| 時間 | dt = 0.5 s、600 s | dt = 0.5 s、4800 s | dt = 1 s、6000 s | dt = 0.5 s、4800 s |

## 実行

```bash
make
./Run.sh          # 構成 1 → Check → 構成 2 → Check → 構成 3 の同値検定 → 構成 4・5 → Check(約 30 秒)
./Run_MPI.sh 4    # MPI。state.dat・lavaflow.dat が逐次とバイト一致(-O2 厳密数学)
python3 Fig.py    # figs/lava.png(引数 en で英語版を en/figs/ に)
```

## 所見

| 検定 | 計算値 | 判定 |
|---|---|---|
| 構成 1 (1) 台帳 Σhl·A − V_in | −5.7e-14 m³(V_in = 300 m³) | PASS |
| 構成 1 (2) 面積等価半径 | 13.17 m(r_N 12.13 m、+8.5%、許容 10%) | PASS |
| 構成 1 (3) 成長則 r(tt)/r(tt/2) | 1.423(√2 に 0.6%) | PASS |
| 構成 2 (1) 台帳 (Σhl + Σdz)·A − V_in | 1.2e-11 m³(V_in = 149.75 m³) | PASS |
| 構成 2 (2) 停止厚 <hl + dz> | 0.4203 m(h∞ 0.3925、+7.1%、許容 20%)、CV 0.001 | PASS |
| 構成 2 (3) 固化率 | 1.000、max dz 0.43 m | PASS |
| 構成 3 既定値の同値 | save・Log がバイト一致、"(default)" 2 行 | PASS |
| 構成 4 (1) 台帳 Σhl·A − V_in | −2.3e-13 m³(V_in = 1798 m³) | PASS |
| 構成 4 (2) 扇形の面積等価半径の比(斜め/格子軸) | 16.96 m / 16.74 m = 1.014(許容 1 ± 0.05) | PASS |
| 構成 4 (3) 塑性ドームの解析解 | 中心厚 3.710 m(H 3.665 m、+1.2%)、面積等価半径 16.86 m(R 17.11 m、−1.5%)、断面 RMS 0.076 m(H の 2.1%) | PASS |
| 構成 5 (1) 台帳 (Σhl + Σdz)·A − V_in | −2.3e-13 m³(V_in = 59.9 m³) | PASS |
| 構成 5 (2) 固化率 | 1.0000(残る溶岩なし) | PASS |
| 構成 5 (3) 壁に接する列 | 全行で hl = 0、min dz 0.978 m(max dz 1.076 m) | PASS |

- 停止厚の +7% は停止判定 `lv_vsol` の打切りによる上振れ
  h∞ + √(v_sol h/(coef (2h + h₀) S)) を含みます(§51.3)。停止の漸近は遅く、
  検定は「検定時間内に排水が h∞ 近傍へ届く粘度」で組んであります
  (η = 1e4 では 900 s で 29% 上振れ = パラメータ選定の目安)。
- 台帳は注入の厳密加算とエッジ反対称の拡散により機械精度で閉じます。
  リスタート往復(300 s save → restore → 600 s)もバイト一致です(構成 4 でも
  3000 s save → restore → 6000 s がバイト一致)。
- 構成 4 は格子の向きによる歪みの検出器です。修正前の方式(降伏と停止を法線方向の
  勾配だけで判定)で回すと、扇形の面積等価半径の比 0.860、中心厚 +9.5%、面積等価
  半径 −5.1%、断面 RMS 12.5% で FAIL します。粘度は静止形に効かないので、検定時間
  内に止まる値(η = 1e6 Pa·s)にしてあります(3000 s と 6000 s の中心厚の差 1.6%)。
- 構成 1・2 は修正(2026-11-03)の前後で save がバイト一致です(構成 1 は τ_y = 0、
  構成 2 は幅方向に一様でエッジに沿う方向の勾配が 0)。
- 構成 5 は停止判定の検出器です。流れ込みのエッジを数えていた修正前の判定で回すと、
  固化率 0.869、壁際の hl 0.978 m で FAIL します。壁際以外の堆積の形は修正の前後で
  同じです。構成 1〜4 の save は停止判定の修正(§51.5)の前後でもバイト一致です。
- 流束のステンシルは 4 近傍のままで、8 近傍化は拡散型モジュール共通の候補として
  残ります(developer.md §61.4)。
