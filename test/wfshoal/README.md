# test/wfshoal — 沿岸の波浪場の海浜断面の検定(fn_wavefield)

[English](en/README.md)

沿岸の波浪場([ユーザーガイドの章](../../docs/users_guide/wavefield.md)、developer.md §88)の
1 次元の海浜断面での検定です。浅水変形・飽和砕波・屈折・不規則波の砕波・底面摩擦・
非定常の伝播・台帳・再開を、理論解と、`Check_wfshoal.py` で独立に組み立てた離散の
定常解で確かめます。`param.txt` の結果は reference の Log.txt・wavefield.csv・Wh0001.txt
とも比較します(ULP=0)。

## 構成

一様勾配 1/80 の海浜(`make_z.py`。120 × 8 セル、Δx = Δy = 10 m)。西(i = 1)が沖で
水深 13.7 m、東の x = 1100 m が汀線で、その東は乾いた陸です。南北の辺は側方 Neumann
なので、解は岸に沿って厳密に一様でなければなりません(8 行がビット一致)。水位は 0 で
流れはありません(段 W1 の波浪場は流れに作用しない)。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本 | `param.txt` | 不規則波の時系列(H_m0 1.0 → 1.5 m、T 8 → 9 s、進行方向 340° → 20° で 0° をまたぐ、方向分散 20 → 15°)。準定常を 600 s ごとに更新。Baldock の砕波、f_w = 0.02、診断量も出力 |
| 浅水変形 | `param_shoal.txt` | 規則波 H = 1 m、T = 8 s、直角入射。wf_tol = 1e-8 |

| 砕波 | `param_brk.txt` | 不規則波 H_m0 = 1.5 m、T = 8 s、直角入射(単一方向)。Baldock ら(1998) |

## 検定(Check_wfshoal.py)

- **浅水変形と飽和砕波**(shoal): 規則波は飽和のほかに散逸がないので、離散の定常解は
  c_g E を保存し(2 リンク分解は直角入射で軸方向のリンクだけを使う)、H > γh のセルで
  H = γh に切られます。波高が漸化式 E_i = min(E_{i−1} c_{g,i−1}/c_{g,i}, ρg(γh_i)²/8) と、
  線形理論 H = H_0 (c_g1/c_g)^{1/2}(飽和帯は γh)に一致すること。分散関係は倍精度の
  Newton 法で独立に解きます。水深 wf_hmin 以下のセルと陸に波がないこと。
- **屈折**(refr): 水深 1 m 以深で、平均波向が Snell の法則 sin α/c = sin α_0/c_0 に、
  波高が H_0 K_s K_r(K_r = (cos α_0/cos α)^{1/2})に従うこと(方向ビン 40 で 2° 以内・1%
  以内)。方向ビン 80 で誤差が 0.65 倍未満に減ること(1 次収束)。
- **砕波**(brk・brkjb): 直角入射・岸沿い一様の離散の定常解は、セルごとの釣り合い
  c_{g,i} E_i + Δx D(E_i) = c_{g,i−1} E_{i−1} と上限 H_rms ≤ γmax h の漸化式で決まります。
  D(Baldock・Janssen & Battjes の砕波、Guza & Thornton の係数の摩擦)は本スクリプトで
  文献の形から独立に書きました。波高・砕波散逸 Wb・軌道流速 Wu がこの解と一致すること。
  あわせて、細かい刻み(Δx/100)の RK4 で求積したエネルギー式 d(E c_g)/dx = −D との差が
  沖の波高の 2% 以内(風上の 1 次の離散化の誤差の大きさ)。
- **非定常**(unst): t = 60 s で E が定常解の半分になる位置が、群速度で進んだ距離
  ∫dx/c_g = 60 s の位置と 2 セル以内で一致。900 s の後に準定常と同じ離散の定常解に
  達し、累積台帳(貯留の変化 − 正味の入力)が閉じること。
- **再開**(rt と Run.sh): 分割した計算の wavefield.dat・state.dat・Wh9998 が通し計算と
  バイト一致し、台帳の CSV の行が通し計算の同じ時刻の行と一致すること。
- **基本**(base): 更新時刻ごとの沖の波が時系列の線形補間(方向は 0° をまたぐ短い向き)
  に一致、各更新が収束、岸沿いに一様、Wu = H_rms σ/(2√2 sinh kh)。
- **台帳**: 準定常の imbalance(最後の反復での貯留の変化率)が流入に対して小さいこと
  (wf_tol = 1e-8 の構成で 1e-8〜1e-9 以下)。
- **流れへの不作用**(Run.sh): 波浪場なしの Log.txt と基本の Log.txt がバイト一致。
- **不正な設定**(Run.sh): wf_ntheta が 8 の倍数でなければ理由を示して停止。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 全検定(約 12 秒)
./Run_MPI.sh 4    # MPI(np ≤ 4)。reference と ULP=0、砕波・非定常は np = 1 とバイト一致、再開も MPI で
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1.6、Ubuntu 24.04)

浅水変形は離散解・線形理論と 5.7e-8(出力の単精度の分解能)で一致し、飽和セルは 13、
台帳の残差は流入の 1.6e-16。屈折は方向ビン 40 で波向のずれ最大 1.52°(水深 1 m 付近)・
波高 0.50%、ビン 80 で 0.63°・0.29%(比 0.42・0.57)。砕波は離散解と 5.1e-8(Baldock)・
4.5e-8(Janssen & Battjes + 摩擦)、Wb は 4.5e-8・7.5e-8、Wu は 5.7e-8・5.8e-8 で一致し、
細かい刻みのエネルギー式との差は沖の波高の 0.93%・0.97%、上限に掛かったセルは 3・2。
非定常の前線は 434.2 m(群速度の到達距離 435.0 m)、定常解は準定常と差 0、累積台帳の
残差は 2.1e-14。再開の継続は通し計算とバイト一致。基本の沖の波の補間は表示桁で厳密。
`-Og -fcheck=all` で逐次と np = 2・4 の reference 比較が一致(範囲外アクセスなし)、
release で np = 1・2・4 が逐次 reference に ULP=0。
