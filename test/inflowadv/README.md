# test/inflowadv — 区間流入の外縁セルに接するエッジの移流項と流速の上限

[English](en/README.md)

`f_inflow_edge = 2`(&list_enc。既定は 0。users_guide/advection.md §4.4)の運動量保存形の移流
(スキーム 2・3)は、区間流入の法線面を持つ外縁セル(流入セル)から区間の内側へ向かうエッジ(流入面から内側への法線エッジと、区間の幅の中の斜めエッジ)の移流項を 0 に
します。流入面に沿うエッジ(両端とも流入セル)と、区間の両端から区間の外へ出るエッジは移流項を
残します。移流項を 0 にした内側へ向かうエッジの流速は、上流側セルのエネルギー水頭から許される
速さ √(2g·max(E_上流 − η_下流, 0)) で頭打ちします(E = η + V²/2g。等流が射流になる急勾配の流入
セルでは、流入面の流量をセル幅・水深あたりにした供給流速も V に数える)。developer.md §68.40 と
その 2 回の改定です。この規則が、逆向きの失敗をどれも避けていることを確かめます(5 構成とも
`f_inflow_edge = 2` を指定。既定の 0 は流入セルに接するエッジすべての移流項を 0 にし、上限を
かけない 2026-10-24 の規則で、下の 2・3 の検定に通らない)。

## 設定

| 構成 | 内容 |
|---|---|
| `param_osc5.txt` | 壁(領域外縁)に挟まれた幅 5 列・80 行の河道だけの領域。Δx = 10 m、河床 −3.0 → −3.8 m(勾配 1/1000)、n = 0.03、北辺の区間流入 700 m³/s(`inflow_dist = 2`)、南辺の水位 0.9 m(等流水深 4.72 m)、初期水深 4.7 m、120 分。流入区間の両端の角セルが閉じて(§69.9)流入が中央 3 列に集まる |
| `param_osc3.txt` | 同じ領域の幅 3 列。流入は同じ単位幅流量の 420 m³/s(流入は中央 1 列に集まる。等流は 3.0 m/s、フルード数 0.44) |
| `param_jet3.txt` | 幅 3 列の領域に 700 m³/s(osc3 と同じ領域・水位・初期水深) |
| `param_side.txt` | 固定床の横溢。Δx = 2 m、16 列 × 20 行。西端の区間流入(列 1、行 4〜8、5 m³/s)の主水路は東辺へ自由流出。流入区間の南端の隣から、境界の列 i = 1 に沿って主水路より 0.5 m 低い側溝(南へ勾配 0.05)が南辺の自由流出まで続く。両岸は主水路の河床 + 1 m。600 秒 |
| `param_steep.txt` | 射流の区間流入。Δx = 2 m、60 列 × 8 行の壁に挟まれた勾配 1/20 の河道(n = 0.03、`p_diagratio = 0` の 4 近傍)の西端の全 8 行に 16 m³/s(単位幅 1 m²/s、等流水深 0.300 m、フルード数 1.95)、東辺は自由流出、初期水深は等流水深。600 秒。区間は西辺の全行で、角セル (1,1)・(1,8) は北・南面からも流入する(角セルは辺ごとに複製) |

side と steep は、MPI の np = 2・4 で流入区間が帯の境目をまたぐ。

## 検定項目(Check_inflowadv.py)

1. **流入行の振動がない**(osc5・osc3): j = 30 の流量(1 分ごと)の、11 分移動平均からの残差の
   標準偏差が 60〜120 分で平均流量の 0.2 % 未満、最大が 0.5 % 未満。平均流量は流入量に 1e-3 で
   一致。流入セルから内側へ向かうエッジの移流項を残すと、流入行の移流項と結合した横断のモードが
   自励して、幅 5 列で 6.3 %(最大 11.9 %)、幅 3 列で 15.5 %(最大 29.1 %)の限界周期振動が出る
   (2026-10-29 の確認)。
2. **横溢でエネルギーを作らない**(side): 最終出力で、側溝の最初のセル (1,9) のエネルギー水頭
   η + V²/2g が、流入区間の中ほどのセル (1,6) を 0.05 m より上回らない。移流項のないエッジの流速は
   水面勾配と摩擦の釣り合いに向かうので、面に沿うエッジや区間の外へ出るエッジの移流項を 0 に
   すると、側溝へ落ちる流れがエネルギー保存の許す流速を超える。
3. **流入直下でエネルギーを作らない**(osc5・osc3・jet3。緩勾配): 最終出力(120 分)で、流入側の
   行 2〜10 のセルのエネルギー水頭 z + h + V²/2g の最大が、流入行(行 1)の最大を 0.1 m より上回らない。
   内側へ向かうエッジの流速に上限がないと、流入直下に射流のジェットが立つ(幅 3 列で水深 1.0〜1.3 m・
   13 m/s)。上限の基準を流入セルの今のフルード数で切り替えると、jet3 でジェットが残る。
4. **射流の区間流入を絞らない**(steep): 最終出力で、流入側の 10 列がすべて射流(フルード数 > 1)、
   流入列(列 1)の平均水深が Manning の等流水深の ±4.5 % 以内、下流(列 31〜50)の平均水深が等流水深に
   ±2 % で一致。上限の基準を上流側セルの速さだけにすると、上限で絞られた流入セルが深くなる。

| 規則 | 1(幅 5 / 3 列) | 2(エネルギー水頭の差) | 3(osc5 / osc3 / jet3) | 4(流入列の水深 / 等流水深) |
|---|---|---|---|---|
| 内側へ向かうエッジだけ移流項 0 + 流速の上限(今の規則。f_opening_dynamic = 3) | 0.000 / 0.000 % | −0.024 m | +0.047 / −0.270 / −0.405 m | 1.030 |
| 上限なし(2026-10-29 の 1 回目の改定) | 0.000 / 0.000 % | +0.002 m | +0.227 / +5.198 m / 39 秒で停止 | 1.030 |
| 流入セルに接するすべてのエッジで移流項 0(2026-10-24〜29) | 0.000 / 0.000 % | +1.218 m | +0.092 / +5.198 m / 39 秒で停止 | 1.014 |
| 上に加えて、区間の外へ出るエッジだけ戻す(2026-10-29 に比べた案) | 0.000 / 0.000 % | +0.258 m | +0.092 / +5.198 m / 39 秒で停止 | 1.014 |
| 移流項 0 なし(2026-10-24 より前) | 6.315 / 15.502 % | +0.030 m | +1.398 / +6.664 m / 4 分で停止 | 0.967 |
| 上限の基準が上流側セルの速さだけ(比べた案) | 0.000 / 0.000 % | +0.004 m | 今の規則と同じ | 1.061 |
| 上限の基準で、流入セルが射流なら供給流速も数える(比べた案) | 0.000 / 0.000 % | +0.004 m | +0.048 / −0.269 / +2.397 m | 1.030 |

今の規則の行は 2026-10-31 からの既定 f_opening_dynamic = 3 の値、ほかの行は 2026-10-29 に当時の既定 2 で比べた記録(今の規則を 2 で回すと +0.004 m・+0.048 / −0.269 / −0.404 m)。

2026-10-24〜29 の規則では、examples/meander の param_feed(容量給砂で流入セルの河床が固定され、
横の外縁セルが掘れる)で、区間の端の外縁セルへ落ちる流れが速くなりすぎて掘れと噴流の正帰還に
なり、水理 1:10:47 に Courant 数 1 を超えた。上限がない規則では、同じ例題の fixsuspfeed などで、
流入セルのすぐ内側が掘れた落差へのエッジの流速が上がりすぎて止まった(developer.md §68.40)。
