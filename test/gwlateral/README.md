# test/gwlateral — 地下水の側方流(f_gwlateral)の解析検証

[English](en/README.md)

地下水の側方流動(`&list_gwflow` の `f_gwlateral = 1`。非線形 Boussinesq
方程式、developer.md §16.1)の検定です。平坦な基盤の上で地下貯留の起伏が
小さいとき、側方流は線形化した Boussinesq 方程式

∂η/∂t = D ∇²η、D = K_sh h̄ / s_y

(η: 地下貯留の起伏、h̄: 飽和帯厚)に従います。検定スクリプト
`Check_gwlateral.py` が 4 つの構成をこの解と比べます。reference は持たず、
合否は検定で決めます。構成 3・4 は、壁で塞がれた斜めの配分を軸エッジへ
振り替えるオプション(`f_gw_opening = 1`)の検定です。

## 構成

| 項目 | 構成 1(param.txt → result) | 構成 2(param_strip.txt → result_strip) |
|---|---|---|
| 領域・格子 | 121 × 121 セル(Δx = 1 m)、平坦、四周が無流束 | 3 × 40 セル(南北に長い帯)、ほかは同じ |
| 地下貯留の初期値 | hg = 0.2 m + 4 mm · exp(−r²/(2σ²))、σ = 4 m(中央の小山) | hg = 0.2 m + 4 mm · cos(π s/L)、L = 40 m(s は北端からの距離) |
| 地下水 | sy0 = 0.2(飽和帯厚 h̄ = 1 m)、sd0 = 2 m、`gw_ksh_mmh = 36000`(K_sh = 0.01 m/s)→ D = 0.05 m²/s | 同じ |
| 時間 | dt = 0.5 s、1800 s。分布(bil)を 300 s ごと | dt = 0.25 s、3600 s。分布を 600 s ごと |

構成 3(`param_strip_open.txt` → result_strip_open)は構成 2 に `f_gw_opening = 1` を
加えたもの、構成 4(`param_line_open.txt` → result_line_open)は同じ起伏を 1 × 40 セルの
帯(両側が領域の縁)に置いて `f_gw_opening = 1` にしたものです。

初期の地下貯留は、同じ形の初期水深(`make_init.py` が書く)を浸透能の
非常に大きい Green-Ampt(`gw_ksv_mmh = 3.6e6`、`gw_psif = 0`)で最初の
ステップに全量浸透させて作ります。分布は bil(float32)で出し、表示の
丸めなしで読みます。

- **構成 1(内部の拡散)**: 小山の 2 次モーメントは、初期の形によらず
  d⟨r²⟩/dt = 4D で伸びます。8 方向の配分を合わせた離散の演算子でも、内部
  では `gw_diagratio` によらず同じ値になります。小山は 30 分で σ ≈ 14 m まで
  広がりますが、中心から 60 m の縁には届かないので、縁の影響のない内部を
  比べられます。
- **構成 2(壁沿いの通水能)**: 起伏の減衰率は、内部の格子なら
  λ = D k²(k = π/L)です。しかし東西の縁の列には外へ向かう斜めのリンクが
  なく、その列の南北方向の通水能は内部の 1 − d/2 = 0.707 倍(d は
  `gw_diagratio` の既定 2/(2+√2))になります。3 列の帯の平均は
  (2 × 0.707 + 1)/3 = 0.805 倍で、減衰率がこの離散の予測に合うことを
  確かめます。浅水流には塞がれた斜めの配分を振り替える補正
  (f_opening_dynamic)があり、地下水の側方流にも同じ規則の振り替え
  (`f_gw_opening`、既定 0 = なし。構成 3・4)があります(developer.md §16.6)。
  構成 2 は既定の振り替えなしを確かめます。帯を南北に置くのは、MPI の帯分割(j 方向)を
  起伏の方向に入れるためです。
- **構成 3・4(振り替え)**: `f_gw_opening = 1` は、塞がれた斜めの通過幅を同じ
  界面を横切る軸エッジへ振り替えます。壁沿いの通水能が内部と同じになり、幅 1 セルの
  帯(斜めがすべて塞がれる。振り替えなしなら 0.414 倍)でも軸エッジの通過幅がセル幅
  いっぱいになるので、どちらの帯でも減衰率が λ = D k² に戻ることを確かめます。

| ファイル | 内容 |
|---|---|
| `make_init.py` | 初期水深の分布(data_gwlateral/h_gauss.txt・h_strip.txt・h_line.txt)を書く。Run.sh・Run_MPI.sh が頭で呼ぶ |
| `Run.sh` | 4 構成を逐次で回して `Check_gwlateral.py` で検定 |
| `Run_MPI.sh N` | 同じ検定を N ランクで回し、同じバイナリの np = 1 と分布出力(Hg*.bil)と Log.txt(Runge 列を除く)をバイト比較。構成 2〜4 は 40 行なので N ≤ 20 |
| `Check_gwlateral.py` | 解析検定: `gauss` は 300〜1800 s の d⟨r²⟩/dt と 4D の比(許容 0.5 %)と直線性、`strip` は減衰率と壁を含む離散の予測の比(許容 0.5 %)と指数減衰の一様さ、`strip_open`・`line_open` は減衰率と D k² の比(許容 0.5 %)。どれも S_grnd が初期の水量のまま不変で、地表水が残らないことを Log の全桁で確かめる |

## 実行

```bash
make
./Run.sh
./Run_MPI.sh 4
```

## 所見

| 量 | 計算値 | 理論値 |
|---|---|---|
| 構成 1: d⟨r²⟩/dt(300〜1800 s) | 0.200014 m²/s | 4D = 0.2 m²/s(比 1.00007) |
| 構成 2: 減衰率 | 2.4806e-4 1/s | 壁を含む離散の予測 2.4820e-4(比 0.99945)/内部の理論 D k² = 3.0843e-4(比 0.804) |
| 構成 3: 減衰率(振り替えあり) | 3.0827e-4 1/s | D k² = 3.0843e-4(比 0.99951) |
| 構成 4: 減衰率(幅 1 セル・振り替えあり) | 3.0827e-4 1/s | D k² = 3.0843e-4(比 0.99950) |

- 構成 1 の残りの差(7e-5)は、非線形(界面の飽和帯厚が起伏とともに変わる)と
  分布出力の float32 の丸めの程度です。地下貯留の総量(Log の S_grnd)は
  全時刻で全桁不変です。
- 構成 2 の減衰が内部の理論より 20 % 遅いのは、壁沿いの通水能の欠けに
  よります。帯の幅を変えた予備計算でも予測どおりで、1 列の帯で 0.414 倍、
  40 列の帯で 0.985 倍でした(developer.md §16.6)。
- 構成 3・4 の残りの差(0.05 %)は、格子上のコサインの固有値の離散化(相対
  k²Δx²/12 = 0.051 %)の程度です。構成 2 の比 0.99945 も同じ理由です。
- MPI は np = 1, 2, 4 とも、分布出力と Log が逐次とバイト一致します
  (2026-10-30)。
