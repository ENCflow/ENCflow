# test/bendsed — 90° 湾曲水路の流砂方向補正(河床勾配項+平衡二次流項)

[English](en/README.md)

掃流砂 Exner(`f_fluvial`)に 2026-10-17 に加えた流砂方向補正
(developer.md §84.3。蛇行発達への拡張 docs/meander_plan.md の段 1)の検定です。
流砂ベクトルを q⃗_b = q_b (t̂ + r n̂ − γ∇z) とし、`fluv_slope = 1` で河床
勾配項(γ = √(τ*c/(μs μk τ*))、長谷川型)、`f_secflow = 1` で平衡二次流項
(r = N* h κ、κ は水深平均流速場の流線曲率)を入れます。

## 構成

| 項目 | 値 |
|---|---|
| 領域・格子 | 91 m × 51 m、91 × 51 セル(Δx = 1 m) |
| 地形 | 幅 10 セルの水路: 西端から東へ 60 m の直線 → 半径 25 m(中心線)の円弧で 90° → 20 m の直線で出口辺へ。河床勾配 0.002(路長に沿う)、両岸は河床 +2 m の乾いた河岸。`make_init.py` が生成 |
| 構成 | left(北へ曲がる。出口 = 北辺)と right(南へ曲がる。出口 = 南辺)は配列の上下反転で厳密な鏡像。各々 on(補正あり)/ off(補正なし、対照)の 4 構成 |
| 流入・出口 | 西端の水路 10 セルに一定 Q = 6 m³/s の区間流入、出口辺は自由流出 |
| 初期水深 | 水路内 0.6 m、河岸は乾燥 |
| 流砂 | 芦田・道上式、d50 = 1 mm、τ*c = 0.05、空隙率 0.4、変動上限 0.05 m、土層 10 m |
| 係数(on) | μs = 1.0、μk = 0.45、N* = 7(文献照合待ちのため既定を置かず、ここで明示指定) |
| 時間 | dt = 0.05 s、600 s(毎ステップ更新)。終了時に `save_*/state.dat` |

| ファイル | 内容 |
|---|---|
| `Check_bendsed.py` | 円弧区間(両端 2 m を除く)で、外岸側(n < 0)と内岸側(n > 0)の平均 Δz の差を集計。(1) on: 差 < −0.05 m(外岸洗掘・内岸堆積)、(2) off: 差 > 0(対照。補正なしでは内岸側が多く削れる)、(3) left と right の鏡像差 < 1e-4 m、(4) 乾いた河岸の Δz が厳密に 0 |

## 実行

```bash
make
./Run.sh          # 入力生成 → 4 構成(各 1 分程度)→ Check
./Run_MPI.sh 4    # MPI。state.dat が逐次とバイト一致するのが規律
```

## 所見(2026-10-24。gfortran 13.3、-Ofast)

| 検定 | on | off(対照) |
|---|---|---|
| 外岸 − 内岸の平均 Δz(left = right) | −0.075 m | +0.004 m |
| 鏡像差 max\|Δz_left − flipud(Δz_right)\| | 5.3e-15 m | 7.1e-15 m |
| 乾いた河岸の max\|Δz\| | 0 | 0 |

- 補正なしでは水深平均流が内岸側で加速するため内岸側が多く削れ、補正ありで
  符号が反転して外岸側が深くなる(河床勾配項をエッジの直接差分で評価する
  改訂 §84.3 で、中央差分の初版の −0.098 m から −0.224 m に明瞭になった。
  現在のコード(2026-10-24)では −0.075 m)。
- 鏡像差は on・off とも丸め誤差の水準(5.3e-15 / 7.1e-15)で、許容 1e-4 の内
  (2026-10-17 の -O2 厳密数学ビルドでは補正ありで 2.2e-5。形態変化の正帰還が
  丸め差を増幅するため)。
- 区間流入セル(西端)は無給砂のため土層 10 m まで洗掘される(点源の局所
  洗掘。集計から外れる)。出口の自由流出面は容量輸送なので全体は低下傾向。
- 横断勾配の平衡値 ∂z/∂n ≈ r/γ の定量比較は固定岸の長時間計算として
  未実施(§84.3 の残)。
