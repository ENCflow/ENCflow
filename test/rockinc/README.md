# test/rockinc — 流水による岩盤下刻(f_rockinc)の検定

[English](en/README.md)

地形変化モジュールの流水による岩盤下刻(`&list_geomorph` の `f_rockinc = 1`、
[ユーザーガイドの地形変化の章](../../docs/users_guide/geomorph.md#流水による岩盤下刻f_rockinc))
の検証ケースです(developer.md §88、docs/mountain_stream_plan.md §4.9 の T2〜T7・T9、§11.3 の C1 = T11)。
岩盤面 z − sd を流水の剥離と運ばれる礫の研磨で下げ、剥離物は 1:1 で可動層 sd に加わり、
研磨の細粒分は系外へ出ます。可動層は
露出率 exp(−sd/H*) で下刻を抑え(被覆)、掃流砂の流出には利用可能率
1 − exp(−sd/H*) が掛かります。reference は持たず、解析解・保存則・バイト一致で判定します。

水路は幅 1 セル(両岸は乾いた +2 m の地盤)・長さ 60 m・南北向き(流れが MPI の
j 方向の帯界面を横切る)、勾配 0.01、n = 0.04、等流水深 0.3 m(V = 1.12 m/s)。
北端の区間流入 Q = 0.336 m³/s、南辺は自由流出。1 セル幅では斜めの開口がすべて
河岸で塞がれ、動的振り替え(`f_opening_dynamic = 2`、既定)で水も掃流砂も軸方向の
全幅で流れます。

## 実行

```bash
make
python3 make_init.py z > zinit.txt   # 入力の再生成(同梱。変更したときだけ)
./Run.sh            # 逐次(約 50 秒)
./Run_MPI.sh 4      # MPI(Run.sh の後に。save_*_serial とバイト比較)
```

## 検証記録(2026-10-27。2026-10-28 に流入面の水深の床の変更の後に再実行。gfortran 13.3 / Open MPI 4.1、既定の -Ofast ビルド)

- T2: 60 セル(H = 0.0961 m で一様)で解析解に max 相対誤差 1.9e-8(単精度の水理出力の
  丸め)。cover_dtg・cover_mf は cover と 2.0e-14 で一致(差は水理が倍精度で続ける
  緩やかな調整。1 回の更新の B/H* は 0.7〜1.1 なので、陽解法なら桁違いの差になる)。
- T3: 出口の被覆率 0.147、漸化式との max 相対差 4.0e-4。剥離直後の厚さでなく保存される
  厚さで比べると、1 回の更新の剥離分(B_p/H* ≈ 1e-3)だけずれる。
- T7: pluck_mf5・mf20 の累積下刻量が pluck と相対 5.6e-4・1.10e-3(差が dts に比例 =
  一次精度)。
- T3 の山形: r = 0.2・0.5・0.8 で下刻速度が理論と 4.5e-6・9.7e-7・1.3e-4、被覆率が
  5.4e-6・2.3e-5・4.6e-5 で一致。r = 1.2 は全被覆で山の頂点の 0.013 倍(被覆は厚くなり
  続ける)。r = 0.8 の被覆は流入セルで 1.41 cm、2 セル目から 1.57 cm で一様。
- T8: 勾配 0.00768〜0.00861(準解析解 0.00785〜0.00879)、max 相対差 2.2 %(時間刻みを

  縦断は滑らか(2 階差分 0.2 mm 以下)。

## 所見

- 5 セル幅の水路では、壁際の列の通水能が内部と違うため列ごとに下刻速度が違い、
  横断方向に河床の差が育って内側へ流れが集まる正帰還で準定常にならなかった。
  1 セル幅にすると u = 0 の 1 次元の連鎖になり、漸化式で閉じる(developer.md §88.4)。
- 掃流砂の通過幅を `fluv_diagratio = 0` にすると、水の動的振り替えの表が軸エッジに
  掛かって 1 セル幅の水路の容量が 2.41 倍になる(既定の fluv_diagratio では整合)。
