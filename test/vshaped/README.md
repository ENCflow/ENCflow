# test/vshaped — V 字流域の降雨流出の運動学的波の理論解との検定(格子 20 m、向き 0° と 45°)

[English](en/README.md)

幅 20 m の水路に両側 800 m の斜面が集まる V 字流域(Overton & Brakensiek 1973、
Di Giammarco ら 1996 以来の降雨流出の標準問題。ENC 格子の原論文 Tada 2026 の検証問題)に
10.8 mm/h の雨を 90 分降らせ、出口と斜面の脚の流量を運動学的波の理論解と比べて合否を
判定します。[examples/benchmark/v-shaped](../../examples/benchmark/v-shaped/README.md) の
20 m の 2 ケース(流域を格子に対して 0° と 45° に置く)を、reference を持たない環境非依存の
検定として回すものです。浅水流の設定はすべて既定値です。

## 構成

| 項目 | 値 |
|---|---|
| 地形 | 斜面 2 × 800 m(水路へ向かう勾配 0.05、水路方向 0、n = 0.015)、水路 1000 m × 20 m(勾配 0.02、n = 0.15。上流端で斜面の脚より 1 m、出口で 21 m 低い)。流域の下流に同じ断面の区間(斜面と水路。雨も降る)を 200 m 続け、その先に水路の延長 3 セルと海セル(標高 0 m・水深 1 m の吸い込み)3 セル。斜面が終わる所の手前の数セルで水路の水深が上がるので、出口の計測面をその影響の外に置くための区間。流域の長方形と下流の区間の外は領域外 |
| 格子 | Δx = 20 m。`param_r0.txt` は水路が格子の軸に沿う 0°(68 × 83)、`param_r45.txt` は 45° に傾けた置き方(107 × 107。水路は斜めの 1 列のセルで、隣どうしが角で接する) |
| 雨・時間 | 10.8 mm/h を全域に 90 分、計算 3 時間。dt = 2 s |
| 計測 | 出口: 流域の下流端の列を尾根から尾根まで横切る測線(エッジ流量方式。全幅)。斜面の脚: 左岸側の斜面の水路に接する列。1 分ごと。水深のプローブ(出口の水路のセルと、斜面の水路から 2 列目のセル)は判定に使わない |
| 入力の生成 | `make_init.py`(標準ライブラリだけ)が流域の座標の式をセル中心で評価して `data_r0/`・`data_r45/` に書く。examples の `make_inputs.py`(NumPy)と独立した実装で、出力は同一 |

理論解(`Check_vshaped.py` が標準ライブラリだけで計算): 斜面は運動学的波の閉じた式
(平衡到達 29.4 分、平衡 2.40 m³/s)、水路は側方流入つきの運動学的波を特性曲線に沿って数値積分
(広幅。出口のピーク 4.86 m³/s = i (2BL + WL)、ピークの半分に達するのは 39 分)。式の説明は
examples/benchmark/v-shaped の README にあります。

## 実行

```bash
make
./Run.sh          # 入力の生成 → 2 ケースの計算(各 7 秒)→ Check_vshaped.py(両方 PASS で PASS)
./Run_MPI.sh 2    # MPI 2 ランク。理論解との比較に加え、逐次結果(result_serial)と測線 CSV のバイト比較
```

## 判定(Check_vshaped.py)

| 指標 | 目安 |
|---|---|
| 出口の流量の NRMSE(理論解との二乗平均平方根誤差 / 理論のピーク 4.86 m³/s) | ≤ 0.04 |
| 斜面の脚の流量の NRMSE(/ 2.40 m³/s) | ≤ 0.04 |
| 格子比 = 出口のピーク / (降雨強度 × 格子上の流域の面積) | 1 ± 0.01 |
| t50 = 理論のピークの半分に初めて達する時刻 | 理論(39 分)± 3 分 |
| 収支 = (出口を通った水量 + 終了時に流域に残る水量)/ 流域に降った雨 | 1 ± 0.01 |

格子比の分母に格子上の面積を使うのは、45° ではセル中心で割り当てた流域の面積が 1.62 km² から
0.8 % 大きくなり、ピークがそれに比例するためです。

## 所見

| ケース | NRMSE 出口 | NRMSE 斜面 | ピーク (m³/s) | 格子比 | t50 (分) | 収支 | 判定 |
|---|---|---|---|---|---|---|---|
| 0°(`param_r0.txt`) | 0.019 | 0.021 | 4.860 | 1.000 | 40 | 0.998 | PASS |
| 45°(`param_r45.txt`) | 0.020 | 0.025 | 4.898 | 1.000 | 37 | 0.999 | PASS |

- 両方の向きで出口の流量が理論解に重なり、45° に傾けても結果は変わりません(水路が斜めの 1 列でも
  8 近傍の斜めのエッジがつなぐ)。差の NRMSE 0.02 は、立ち上がりの時刻の 1〜2 分のずれ(0° で遅く、
  45° で早い)と、理論側の近似(運動学的波)によるものです。
- 4 近傍(`p_diagratio = 0`)の 45° では水路の隣どうしが角でしか接しないため流出が 0 になります。
  この性質は examples/benchmark/v-shaped の比較ケースで見ます(検定の対象ではありません)。

できないこと: 理論解は運動学的波の近似で浅水方程式の厳密解ではないので、目安は「理論との差が
この水準を超えない」ことの検査です。水深(斜めの 1 列の水路で理論の 1.3 倍、水路に接する斜面の
1 列目のセルで 1.5〜1.8 倍)は判定に含めません。格子収束・基礎式の比較・4 近傍・サブグリッド河道幅は
examples 側で見ます。
