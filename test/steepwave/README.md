# test/steepwave — 水面の勾配の項の可変の重力 g′(f_gravity_correction = 3)の検定

[English](en/README.md)

急勾配の重力補正の試作の選択肢 `f_gravity_correction = 3`(`&list_enc`。developer.md §100、
docs/users_guide/steep_slope.md §2.6)の検証ケースです。3 は 2(有効重力 $`g_e = g\cos^2\theta`$ と、斜面に
沿う摩擦・流砂のせん断)に加えて、水面の勾配の項の $`g_e`$ を Yuan ら (2016) の式 42 の可変の重力
(水の場合)

```math
g' = \frac{g}{1 + |\nabla z|^2 + \nabla z\cdot\nabla h} = \frac{g}{1 + \nabla z\cdot\nabla\eta}
```

に置き換えます。水深が一様なら $`g_e`$ と同じ、水面が水平なら $`g`$ に戻り(急な地盤の上の深い水。
案 D)、一様な流れのまわりでは下り向きの水深の勾配の係数が薄層の式の $`g\cos^4\theta`$ になります
(案 E)。この三つを、静止した湖・急な湖底を渡る長波・斜面の一様な層の上の山の 3 つの構成で
確かめます。reference 比較ではなく `Check_steepwave.py` の自己検定で合否を決めます。

## 構成

| 構成 | 内容 | 比べる値 |
|---|---|---|
| lake | 40 m 四方(Δx = 1 m、8 近傍)。勾配 1(45°)の平面の地盤を格子の x 軸から 30° の向きに傾け、水位 0 の湖と乾いた湖岸の斜面を含める。マニングの粗度 0.03、60 s | 2・3 |
| wave | 800 m × 32 m(Δx = 2 m、8 近傍、南北は壁)。深さ 40 m の平らな湖底 → 勾配 0.5 の斜面(x = 400〜472 m) → 深さ 4 m の浅瀬。x = 250 m に高さ 2 cm・幅 25 m のガウス形の水位の山を置き、40 s。摩擦なし。プローブ 6 つ(x = 381〜551 m) | 0・2・3 |
| bump | 700 m × 2 m(Δx = 0.5 m、4 近傍、東は自由流出)。勾配 tan30° の摩擦のない斜面に、地盤に直角な厚さ 1 m の一様な層と、高さ 1 cm(厚さの 1 %)・幅 4 m(斜面に沿う)の山を置き、6 s | 0・2・3 |

| ファイル | 内容 |
|---|---|
| `make_init.py` | 全ケースの地形・初期水位(`d_<構成>/`)と設定 `p_<構成>_g<値>.txt` を書く(引数 `list` でケース名を出す)。構成の説明と定数は先頭にあり、Check と対 |
| `Check_steepwave.py` | 下の (1)〜(3) を判定する(引数 `table` で値の表も出す) |

判定:

1. **lake**: 静止が保たれる(流速と水位の変化の最大が 1e-12 以下)。2・3 とも水面の勾配に比例する力
   なので厳密に 0 になる。
2. **wave**: プローブ 1(深さ 40 m の平らな所)から各プローブまでの山の到達時刻の差が、3 で補正なし
   (0)と 0.3 % 以内、線形の長波の走時 $`\int dx/\sqrt{gh}`$ と 2 % 以内で合う。水面がほぼ水平な深い
   水では鉛直の静水圧が正しく、補正なしの浅水方程式がそのまま当てはまる。
3. **bump**: 層全体が $`g\sin\theta`$ で加速しても、山は上下 2 つに分かれ、その間隔は斜面に沿う座標で
   $`2\sqrt{g\cos\theta\,h_n}\,t`$ で広がる(層と一緒に動く座標では、斜面に沿う薄層の式は重力
   $`g\cos\theta`$ の浅水方程式)。3 s と 6 s の間隔の差から求めた広がる速さが、3 で薄層の式と 2 % 以内で
   合う。間隔の差を取るので層の移動は打ち消される。

2 と 0 の値は表に出すだけです(2 は wave で遅れ、bump で $`1/\cos\theta`$ 倍、0 は bump で
$`1/\cos^2\theta`$ 倍になるのが理屈)。

## 所見

- 急な湖底の上の深い水の波は、3 では補正なしと印字の桁で同じ時刻に届き、2 は斜面の上で遅れる
  (斜面の上端の先で 10 %、浅瀬に出た後で 4〜7 %)。0 と 3 の比が 1 からずれる 0.2〜1.5 % は 0 と 3 に
  共通で、山の形の変化(浅水変形と斜面からの反射)と数値の分散によると考えています。
- 斜面の一様な層の上の波の速さは、3 で薄層の式に 0.7 % 以内で合い、2 と 0 は理屈どおり
  $`1/\cos\theta`$・$`1/\cos^2\theta`$ 倍に近い値です(0 の 1.5 % のずれは、0 では層の加速も過大で流れが
  速く、数値の誤差が大きいためと考えています)。
- 試作の途中で、摩擦のない斜面のダム崩壊(乾いた斜面・濡れた斜面)を、斜面に沿う座標の解析解
  (Mangeney ら 2000、Stoker の解の移し替え)と比べることも試しましたが、層全体が時速 100 km を超えて
  加速する計算では、先端と段波のまわりの数値の誤差が 10 % 程度あり、2 と 3 の違い(理論で 15 %)を
  区別できなかったので、検定には使っていません(developer.md §100)。

## できないこと・限界

- 3 は試作で、既定(2)ではありません。急な前縁・段波では $`\nabla z\cdot\nabla h`$ の制限
  ($`[-|\nabla z|^2, |\nabla z|^2]`$)が効き、薄層の式からも Yuan らの式からも外れます。この検定は、
  制限の効かない滑らかな流れ(静止した湖、小さな波)だけを見ています。
- 境界の辺には補正を足していません。非静水圧(`fn_nh`)と組み合わせた検証はしていません。
- bump は 4 近傍の 1 次元の計算です。8 近傍では南北の壁の行で斜めの辺が欠けて、速い流れに横向きの
  乱れが出るので使っていません(静止と波は lake・wave で 8 近傍を確かめています)。
