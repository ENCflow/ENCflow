# test/vzcol — VZ 共有参照柱 1 本の検定(fn_vz)

[English](en/README.md)

鉛直不飽和浸透(VZ)流出([ユーザーガイドの章](../../docs/users_guide/vz.md)、
developer.md §87)の計算核と、区画の読み出し・台帳の検定です。柱 1 本・
区画 1 つで、解析的に決まる性質を `Check_vzcol.py` で確かめ、`param.txt` の
結果は reference の Log.txt とも比較します(ULP=0)。vz_zone.csv・vz_column.csv は
16 桁で書くため CPU が違うと最終桁が変わり(-march=native のベクトル化の差)、
reference との比較には入れていません(内容は検定で、MPI の並列数不変性は
np = 1 とのバイト比較で確かめます。同じホストで作った reference となら
`FILES="Log.txt vz_zone.csv vz_column.csv" ./Run.sh` でビット比較できます)。

## 構成

3 × 8 セル(Δx = Δy = 10 m)の全セルを区画 1 とし、柱 1 本(深さ 3 m、
層厚 2.5 cm = 120 層)を参照させて系外へ排水します(`vz_out_kind = 2`。
地表流は生じません)。土層厚は 0.3〜2.9 m の分布で、界面上の値(0.5、1.0 等)
と界面の途中の値(0.7375、1.2340 等)を混ぜています。小杉パラメータは
検定用の例示値(Ks = 100 mm/h、θs = 0.5、θr = 0.1、ψm = −0.5 m、σ = 1.5)で、
特定の土壌の推奨値ではありません。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本 | `param.txt` | 初期は定常重力排水 q0 = 1 mm/h。降雨 0〜60 分 1 mm/h(= q0)、61〜180 分 50 mm/h、以後 0。dt = 5 s、dt_vz = 60 s、12 h |
| 固定圧下端 | `param_fixed.txt` | 深さ 1 m・層厚 1 cm、下端 ψ = 0(f_vz_bottom = 2)、上端 10 mm/h を 10 日。初期は一様 ψ = −0.5 m |
| 時間収束 | `param_tight.txt` | 基本の時間誤差の許容(vz_tol_theta・vz_tol_psi・vz_tol_q)を 1/4 に |
| 面積平均 | `param_avg.txt` | 基本を f_vz_rain = 1(柱内の面積平均)で。雨は一様 |
| 土層厚 0 | `param_sd0.txt` | 基本の土層厚を `sd_zero.txt`(3 セルが 0 m)に替える |
| 静水圧の初期条件 | `param_hydro.txt` | 深さ 0.5 m・層厚 2.5 cm、下端 ψ = 0(f_vz_bottom = 2)、初期は下端を地下水面とする静水圧(vz_wt0 = 0.5 m)、雨なし 1 日 |

## 検定(Check_vzcol.py)

- **定常期**(t ≤ 3600 s、雨 = q0): 自由排水の下端では一様 ψ0(K(ψ0) = q0)が
  厳密な定常解なので、全深さの累積流束 = q0·t、貯留は不変。
- **深さ別の保存則**: 各出力深さ d で S(d, t) − S(d, t1) = [F0(t) − F0(t1)] −
  [D(d, t) − D(d, t1)] が非線形残差の予算 vz_mb_rate·t 以内(排水と貯留を同じ
  補間係数で読むため構造的に成り立つ)。
- **小杉式**: 鉛直分布(vzprof)の θ(ψ)・K(ψ) が Python の math.erfc による
  小杉式と一致。
- **区画の集約**: 区画の貯留・排水(重み W・M による集約)が、土層厚の分布から
  セルごとに補間して積み上げた値と一致。区画の収支残差が予算内。
- **雨量と台帳**: 柱の上端入力 F0 が降雨表(1 分更新・線形補間)から独立に
  組み立てた雨量と一致し、Log の S_total の変化が F0 − 系外流出/全面積と一致。
- **固定圧下端の定常解**: 定常解 dψ/dζ = 1 − q/K(ψ)、ψ(L) = 0 を RK4 で求積した
  分布と一致(層厚 1 cm の離散化誤差の範囲)し、下端流束 = 上端流束。
- **時間収束**: 許容 1/4 の再計算との累積流束の差が 0.2% 以内。
- **面積平均モード**: 雨が一様なら厳密モードと一致。
- **土層厚 0**: 土層厚 0 のセルは地表で読み出す(排水 = 雨、貯留 = 0)ので、
  区画の集約がセルごとの読み出しの和と一致し、収支残差が予算内。
- **静水圧の初期条件**: 下端固定圧 ψ = 0 の柱で地下水面を下端に置いた静水圧は
  流束 0 の静止解なので、雨なしで ψ(ζ) = ζ − 0.5 m のまま、全界面の累積流束が 0。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 全検定
./Run_MPI.sh 4    # MPI(np ≤ 4)。Log は逐次 reference と ULP=0、CSV は np = 1 と一致、面積平均も MPI で
```

## 検証記録(2026-10-26。gfortran 13.3 / Open MPI 4.1、Ubuntu 24.04)

定常期の累積流束の誤差 1e-15(相対)・貯留の変化 0、深さ別保存は予算の
2.4e-4 倍、小杉式は 4e-16(θ)・2e-15(K)、区画の集約とセル別の積み上げは
1e-16 で一致、Log の S_total の収支は 9e-12 m。固定圧の定常解は求積との差
1.1e-4 m(算術平均。調和平均では 1.7e-5 m)、下端流束 = 上端流束が 2e-14。
時間許容 1/4 との差 2.6e-4。面積平均モードは厳密モードと完全一致。
`-Og -fcheck=all` で逐次と np = 2・4 の全出力ファイルが一致、release で
np = 1・2・4 が逐次 reference に ULP=0(作成ホストで CSV を含む)。Zen3 向け
(`-march=znver3`)のビルドでは Log.txt が reference とビット一致し、CSV は
最終桁(相対 1e-15)だけ異なる。reference は解析検定の合格を根拠にした
暫定(目視確認待ち)。
