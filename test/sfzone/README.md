# test/sfzone — 貯留関数法の区画・タンク・出口の検定(fn_sfm)

[English](en/README.md)

貯留関数法の区画流出([ユーザーガイドの章](../../docs/users_guide/sfm.md)、developer.md §106)の
タンクの解・区画の入力・出口への受け渡し・雨の扱い・基底流・同期・再開・遅れ時間・蒸発散・降雨遮断による有効雨量の分離・VZ との併用の検定です。
`Check_sfzone.py` で解析解・参照解・保存則と比べ、`param.txt` の結果は reference の
Log.txt とも比較します(ULP=0。CSV を比較に入れない理由は [test/vzcol](../vzcol/README.md) と同じ)。

## 構成

7 × 8 セル(Δx = Δy = 10 m。[test/vzzone](../vzzone/README.md) と同じ格子と雨)。列 1〜5 が
区画セルで、行 1〜3 が区画 1、行 4〜5 が区画 2、行 6〜8 が区画 3。列 6 は領域外、列 7 は
行 1・3・5 だけが領域内の孤立した受水セル O_a・O_b・O_c(周囲を領域外で囲み、地表水が
動かない)。

| 区画 | タンク(S [mm] = K·q[mm/h]^P) | 初期の流出強度 | 出口 |
|---|---|---|---|
| 1 | K = 10、P = 0.6 | 0.1 mm/h | O_a へ 0.6、O_b へ 0.4 |
| 2 | K = 2(h)、P = 1(線形貯留) | 1 mm/h | O_a へ 1.0(区画 1 と同じ受水セル) |
| 3 | K = 20、P = 0.4 | 0(乾いた状態) | 系外流出 |

O_c は雨だけを受ける対照です。K・P は検定用の例示値です。降雨は 0〜60 分 1 mm/h、
61〜180 分 50 mm/h、以後 0 を全セル一様に与えます。dt = 5 s、dt_sfm = 0(毎ステップ)、12 h。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本 | `param.txt` | 上記 |

## 検定(Check_sfzone.py)

タンクは SI で q = c·S^m(m = 1/P、c = (1000/K)^m / 3.6×10⁶、S [m]、q [m/s])。各ステップの雨は
降雨の更新規則(dt_prupdate = 60 s ごと)どおりに Python で作る。

- **入力**: 区画の vin = 面積 × 地上雨量の積算。
- **線形貯留の厳密解**(区画 2): 区分一定の雨に対し、ステップごとに
  S ← S_eq + (S − S_eq)·exp(−Δt/τ)(τ = 3600·K s、S_eq = τ·r)。
- **非線形タンクの参照解**(区画 1・3): 同じ雨の dS/dt = r − c·S^m を 1 ステップ 10 分割の RK4 で解く。
- **逓減の解析解**: 雨が止んだ後の最初の記録時刻 t1 の貯留 S1 から
  S^(1−m) = S1^(1−m) + (m − 1)·c·(t − t1)(P = 1 は指数関数)。
- **出力の整合**: q 列 = (S/K)^(1/P)、区画の収支残差 = 丸め規模。
- **受水セルの水深**(プローブ): R を地上雨量の積算、V1・V2 を区画 1・2 の移送量として
  O_a = R + (0.6 V1 + V2)/A、O_b = R + 0.4 V1/A、O_c = R。地表水の総量 = 受水セルへの雨 + V1 + V2。
- **全体の収支**: Log の S_total の変化 = 雨 − 系外流出(区画 3)/全面積(タンクの貯留は S_grnd)。
- **雨の分布と面積平均**: 各区画の入力 = 区画面積 × 区画内の平均雨量、S_total の収支。
  同じ雨で厳密モードは停止。
- **再開**: 6 h で保存 → 再開した sfm_zone.csv と Log が連続計算の後半とビット一致(基底流つきも)。
- **基底流**: 累積の vbase = 区分線形の時系列の厳密な積分(Python の分数)× 区画面積、タンク側の
  列は基底流なしと文字列で一致、出口の量 = 流出 + 基底流、S_total の収支。
- **既定値**: 採用値が `(default)` 付きで表示され、同じ値を明示した `param.txt` と全出力がビット一致。
- **同期間隔**: dt_sfm = 60 s の同期時刻の貯留が参照解と sfm_tol の範囲、入力は毎ステップ同期と一致。
  同期区間の途中の保存 → 再開の貯留が連続計算と一致(許容の範囲)、収支残差は丸め規模。
- **定常**: 48 h 後に q → 10 mm/h、S = K·r^P。
- **遅れ時間**: 雨を遅れのステップ数だけ遅らせた入力(開始前は初期の流出強度 q0)に対し、区画 2 は
  線形貯留の厳密解、区画 1・3 は RK4 の参照解。vlag 列 = 直近 T_L の雨(開始直後は q0 の定常分を
  含む)× 区画面積、入力 vin は遅れなしと一致、収支残差(移動中の水を含む)は丸め規模、Log の S_total の
  収支。保存 → 再開は連続計算とビット一致。dt_sfm = 60 s の貯留は参照解と sfm_tol の範囲。
- **蒸発散**: ステップごとに「タンクを進める → 蒸発散を引く(供給制限、または
  E·min(1, S/S_lim) をステップ内で厳密に解いた量)」をなぞった参照解と、貯留・累積の蒸発散(vevap)を
  比べる。収支残差(移動中の水と蒸発散を含む)、Log の S_total = S0 + 雨 − (系外流出 + evap.csv の
  ev_total + Σ vevap)/全面積。保存 → 再開はビット一致。定常では区画 1・2 の q → r − E = 8 mm/h、
  区画 3 は r = q + E·S/S_lim(S = K·q^P)の解(引く順序による相対 1e-4 程度の差を許す)。
- **有効雨量の分離**: 初期損失の 2 段の遮断率の手順を Python でなぞった有効雨量 × 面積 = 区画の入力、
  累積の有効雨量 = 閉じた形 (1 − a1)·min(R, R_f) + (1 − a2)·max(R − R_f, 0)(R_f = smax/a1。木村の形では
  f1·min(R, R_sa) + max(R − R_sa, 0))、有効雨量に対するタンクの参照解、Log の S_total = S0 + 有効雨量 −
  系外流出(遮断は系外への損失)。分布ファイルは一様指定とビット一致、保存 → 再開はビット一致。
- **VZ との併用**: 貯留関数の区画 1・2 の sfm_zone.csv と受水セルのプローブが `param.txt` と一致、
  Log の S_total の収支(VZ の貯留と系外流出を含む)。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 全検定
./Run_MPI.sh 4    # MPI(np ≤ 4)。Log は逐次 reference と ULP=0、CSV は np = 1 と一致、面積平均・停止・再開・併用も MPI で
```

## 検証記録(2026-11-11。gfortran 13.3 / Open MPI 4.1、Ubuntu 24.04)

線形貯留の厳密解と相対 3.2e-7、非線形タンクの RK4 参照解と貯留 4e-8・流出強度 1.1e-7、逓減の
解析解と 3.6e-7 以内。遅れ時間の計算は、遅らせた雨に対する厳密解と 2.8e-7、参照解と 1.1e-7 以内、
移動中の水は 4e-16(相対)。区画の収支残差は入力の 4e-14、地表水の総量は 5e-14(相対)、S_total の収支は
6.7e-15 m。dt_sfm = 60 s の貯留は参照解と 1.5e-5、定常の q は 10 mm/h と 4.4e-9 以内。MPI np = 1・2・4 が
逐次 reference に ULP=0 で、sfm_zone.csv と同期区間の途中の保存ファイルは np = 1 とバイト一致。
`-Og -fcheck=all` で逐次と np = 2・4 の全出力が一致。reference は解析検定の合格を根拠に暫定で置いた
(人間の目視確認で確定する)。
