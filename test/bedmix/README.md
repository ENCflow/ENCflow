# test/bedmix — 混合粒径(f_bedmix)の検定

[English](en/README.md)

developer.md §84.19、docs/mixed_sediment_plan.md §6。掃流砂を粒径階に分け、河床の粒度を交換層 1 枚と
下層 1 枚で持つ計算(Hirano 型)を、極限の一致・理論値・式の再計算・収支で検定する。

水路は幅 5 セル(dx = dy = 1 m)・長さ 60 セルの直線水路で、乾いた高い河岸が挟む。西端の区間流入は
Manning の等流水深の単位幅流量 × 幅、東辺は自由流出(n = 0.03)。入力は make_init.py が型ごとに作る:

| 型 | 勾配 | 等流水深 | 河床の土層厚 | 河岸 | 下流端の 4 列 |
|---|---|---|---|---|---|
| std | 0.002 | 0.5 m | 1 m | 高さ 2 m、土層厚 0 | 土層厚 0(侵食しない床) |
| deep | 0.001 | 1.0 m | 0.5 m | 高さ 2 m、土層厚 0 | 土層厚 0 |
| free | 0.002 | 0.5 m | 1 m | 高さ 2 m、土層厚 0 | 動く床(開境界の流出を見る) |
| bank | 0.002 | 0.5 m | 1 m | 高さ 1 m、土層厚 1 m(動く河岸) | 土層厚 0 |

## 構成

| 構成 | 設定 | 検定 |
|---|---|---|
| single | std、単一粒径 3 mm、容量給砂 | equal との比較基準 |
| equal | std、3 粒径階がすべて 3 mm(割合 0.2・0.3・0.5)、交換層厚 5 m(土層より厚い = 交換層が柱全体)、容量給砂 | 河床が single と一致(最大差 < 1e-10 m)、組成が初期値のまま(< 1e-12)、開境界の正味の流出の合計が single と一致(相対 1e-8)。等移動度の極限 |
| armor | deep、1 mm と 20 mm を 0.5 ずつ、遮蔽なし、給砂なし(粗粒は限界以下で動かない) | 上流端の列の低下量が静的アーマーの理論値 L_a F_0 / (1 − f_sub) に一致(< 1e-6 m)し、そこの細粒が抜けきる(< 1e-6)、細粒の割合が単調に減る、細粒の割合の減衰率が、出力の水理量から求めた 1 セルの式 dF/dt = −(1 − f_sub) Q F / L_a の率と 3 % 以内 |
| hide1 → hide2 | free、0.5・2・8 mm(0.3・0.4・0.3)、修正 Egiazaroff(既定)。100 s で保存して 160 s まで続ける | 100〜160 s に下流端の開境界を出た粒径階ごとの量(台帳)が、下流端のセルの水深・流速・組成から芦田・道上(1972)式 (31)・(32) で求めた値と 0.5 % 以内 |
| bcfeed | std、3 粒径階、容量給砂 | 流入セルの河床と組成が変わらない(< 1e-12)、下流の河床は動く |
| bank | bank、3 粒径階、側岸侵食・安息角崩落、合計 1e-3 m³/s の給砂 + 一定の組成 0.2・0.5・0.3 | 粒径階ごとの収支(在庫の初期と最終・給砂・開境界の正味の流出)の残差 < 1e-10 m³、給砂が合計 × 組成 × 時間に一致(相対 1e-9)、交換層・下層の組成が 0〜1 で和が 1(< 1e-12)、河岸が動いている |
| qbmix | std、粒径階ごとの給砂の時系列(qbmix.txt) | 台帳の給砂が時系列(区分線形)の積分と 0.2 % 以内、収支が閉じる(< 1e-10 m³) |
| rt1 → rt2 | bank を 150 s で分割 | state.dat と geomorph_bedmix.dat が bank とビット一致 |
| nofrac | 合計の給砂だけで組成の指定がない | 初期化で止まる(給砂の組成は与件なので既定を置かない) |

検定の数値は、たとえば equal と single の河床の差 5e-15 m、armor の低下量 0.02197 m(理論値と同じ)、
減衰率 0.04934 と 0.04946 /s、hide2 の流出の比 1.0002、bank の残差 1e-13 m³ 程度。

## 実行

```
make
./Run.sh            # 逐次。Check_bedmix.py + nofrac の停止 + リスタートの cmp
./Run_MPI.sh 2      # MPI(np=2)。逐次の save とのビット一致も確認
```

入力 zinit_*.txt / hinit_*.txt / sdinit_*.txt / qbmix.txt は make_init.py が生成する(追跡外)。
reference は持たず、合否は Check_bedmix.py の解析的な検定と、逐次・MPI・リスタートのビット一致で決める。
