# test/stg — STG 格子(旧互換)の動作確認

[English](en/README.md)

STG 格子(`f_gridsystem = 1`)は、ENC 格子と比べるために残している旧互換の実装で、新しい機能には
原則として対応しない方針です(凍結。developer.md §7)。このケースは、STG が最小の構成で動き続けて
いることと、対応しない設定を初期化で明示的に止めることを確かめます。reference は持たず、
`Check_stg.py` と `Run.sh`・`Run_MPI.sh` が判定します。

## 構成(make_init.py が生成)

| 項目 | 値 |
|---|---|
| 格子 | 40 × 24、Δx = Δy = 10 m。領域マスクなし |
| 地形 | 東へ下る勾配 0.02 の斜面。外周の 1 列は標高 20 m の壁 |
| 雨・計算 | 60 mm/h を 30 分間(全期間一定)。力学波(`f_govequation = 0`)、dt = 0.5 s |
| 出力 | 水深 H をテキストと float32 の bil で(`f_output_mode = 3`) |

`p_stgmask.txt` は、同じ設定に領域マスク(`f_masktype = 1`。北東の隅の 4 × 4 セルを外す)を
与えたものです。

## 判定

- **連続式の保存**(`p_stg.txt`): STG は外周の 1 列を計算せず、そこには雨も入りません。計算する
  セル(i = 2〜39、j = 2〜23)の終わりの水量(bil の H × Δx²)が、そこに降った雨の量
  P × T × Δx² × 38 × 22 = 2,508 m³ に相対誤差 10⁻⁵ 以下で一致することを確かめます(現在の値は
  1.2 × 10⁻⁸ で、float32 の丸めの大きさ)。あわせて、外周が乾いていること、H が有限で負でないこと、
  水が東の低い側に集まること(東端の列の平均水深 0.444 m > 西端の列 0.002 m)も見ます。
- **領域マスクで止まる**(`p_stgmask.txt`): STG は計算範囲を海域の判別(`fn_sw`)の陸のセルで決め、
  領域マスクを読みません。マスクの外まで計算してしまうので、領域の外のセルがあると初期化で
  止まることを確かめます。
- **MPI は 1 ランクだけ**(`./Run_MPI.sh N`): STG は帯の境界でハロを交換しないので、2 ランク以上では
  初期化で止まることを確かめます(止めないと帯の境界で水が失われ、このケースでは np = 2・4 で
  水量が 24 %・43 % 減ります)。np = 1 では上の 2 つの判定に加えて、`Log.txt` が逐次の計算と
  バイト一致することも確かめます。

## 実行

```
./Run.sh            # 逐次(合否つき。1 秒ほど)
./Run_MPI.sh 1      # MPI の 1 ランク(2 以上では止まることを確かめる)
```

できないこと: このケースは STG の連続式の保存と止め方だけを見ます。STG の運動方程式の精度
(移流項・摩擦)は検定していません。
