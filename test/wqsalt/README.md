# test/wqsalt — 塩分まわりの水質の追加と、可能蒸発散の時系列入力

[English](en/README.md)

蒸発で濃くなる物質(塩分など)を[水質](../../docs/users_guide/wq.md)で扱うための機能と、
[蒸発散](../../docs/users_guide/forcing.md#蒸発散list_evap)の時系列入力の検定です(developer.md §139)。
どのケースも、水が動かないか、動きが結果に効かない構成にして、解析解・保存則と比べます。
reference は持ちません。

| ケース(param_<名前>.txt) | 機能 | 構成 | 判定 |
|---|---|---|---|
| mix | 水平の混合 `wq_diff` | 平らな閉じた静水(81 × 81 セル)の中心に物質を 10 秒投入。D = 0.5 m²/s | 200 s から 600 s の間に、分布の分散が x・y とも 2·D·Δt = 400 m² 増え、共分散は増えない(8 近傍の離散化で丸めの範囲で厳密)。質量は変わらない |
| mixflow | 同上 | 閉じた箱の水深に段をつけて揺らす。初期濃度は一様 100 mg/L | 濃度が一様のまま |
| mixwall | 同上 | 箱の中央に乾いた尾根。西側だけに物質を投入 | 尾根の東側の濃度が厳密に 0、西側は一様に近づく |
| mixgv | 同上 | 静水の箱の東半分の家屋の空隙率を 0.5 にする。西側に物質を投入 | 質量が変わらず、最後は空隙率によらず濃度が一様(= 投入量 ÷ 水の体積) |
| mixwd | 同上 | 静水の箱を、幅 2 m のサブグリッド河道の列(平面積率 0.2。両端のセルは 0.1)で西と東に分ける。西側に物質を投入 | 質量が変わらず、河道の列をまたいで濃度が一様になる |
| sat | 溶解度 `wq_csat`(析出) | 水深 0.5 m・濃度 100 g/L の静水を 0.1 m/h で蒸発させる。溶解度 300 g/L | 水柱の物質 = min(初期量, 溶解度 × 蒸発の前の水深)、残りが析出物。干上がると全量が析出物 |
| dis | 同上(瞬時の溶解) | 水深 0.2 m の真水の底に析出物(西 100・東 30 kg/m²) | 西は濃度 300 g/L で析出物が 40 kg/m² 残り、東は 150 g/L で析出物が尽きる |
| disk | 溶解の速さ `wq_kdis` | dis に k = 8.64 m/day(1e-4 m/s)を与える | プローブの濃度が C = Csat (1 − exp(−k t / h)) に一致(差 1e-9 以下)。東は 150 g/L で止まる |
| inf | 浸透する水による溶解、地下水と一緒に動く濃度の上限 | 乾いた地面の析出物に 36.5 mm の雨。バケツ型の浸透。その後、井戸で地下水を半分汲む(遅延化係数 R = 2) | 地下へ入る物質 = min(析出物, 溶解度 × 浸透量)。井戸が運び出す物質 = min(濃度, 溶解度)/R × 汲んだ水 |
| sea | 海から入る水の濃度 `wq_sea_conc` | 西端が海。潮位を 0 → 2 m → 1.3 m と動かして乾いた陸を浸す | 陸の水と海セルの濃度が 35 g/L。海から入った量 − 海へ出た量 = 地表の質量 |
| c0map | 初期濃度の分布 `fn_wq_c0` | 乾いた尾根の西 100 mg/L・東 300 mg/L の静水 | 開始時と終了時の濃度が与えた値のまま |
| evts | 可能蒸発散の時系列 `f_evmodel = 5` | 0 → 96 mm/day → 0 の三角形の時系列を、周期強制 12 時間で 2 回繰り返す | 累積蒸発量が 1 周期 24 mm・1 日 48 mm(ステップごとの和が積分に一致) |

| ファイル | 内容 |
|---|---|
| `Run.sh` | 12 ケースを逐次で実行し、`Check_cases.sh` で判定(約 15 秒) |
| `Run_MPI.sh N` | 12 ケースを N ランクで実行して判定し、帯の境をまたぐ輸送のある 7 ケース(mix・mixflow・mixwall・mixgv・mixwd・sea・c0map)は 1 ランクの Log.txt・wq.csv・最後の濃度の分布とバイト比較 |
| `Check_cases.sh` | 全ケースの判定(`Check_wqsalt.py` を、ケースごとの引数で呼ぶ) |
| `Check_wqsalt.py` | 判定の本体(Python 標準ライブラリのみ) |
| `make_data.py` | `data_wqsalt/` の入力(水深・地盤高・析出物・初期濃度・海域マスク・家屋の空隙率・河道マスクと河道幅の分布)を作り直す |

## 実行

```bash
make
./Run.sh
./Run_MPI.sh 2
```

## 所見

- 水平の混合の分散の増分は、理論 400 m² に対して相対 3e-9 で一致します。斜めのリンクの配分比に
  よらず、分散の増え方は各方向に 2·D·t です。
- 家屋の空隙率・サブグリッド河道幅のセルでは、リンクの面積に両側の「水の入る面積の割合」の小さい方を
  掛けます。流束をリンクの両側から同じ値で数えるので、割合が 0.1〜1 と違っていても質量は丸めの範囲で
  保存し、最後の濃度は一様になります(mixgv・mixwd。水の体積は計算が出力する分布 A0000 から求めます)。
- 析出は、蒸発散が水質の処理の後に働くので、1 ステップ前の水深で決まります(判定の式はその分を
  含みます)。出力の濃度は、溶解度を 1 ステップの蒸発の分だけ超えることがあります。
- 溶解の速さつきの溶解は、ステップの中で指数の式を厳密に解くので、時間刻みによらず解析解に一致します。
- inf の雨の総量は、雨の時系列を 1 時間の後の 1 分で 0 へ下げる分を含めて 36.5 mm です。判定は、
  井戸のないセルの地下貯留から読んだ浸透量を使います。
