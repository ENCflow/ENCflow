# test/chichibu_icmap — 窓つき領域マスク+分布ファイルの回帰ケース

[test/chichibu](../chichibu/) と同じ秩父流域 100 m 格子(560 × 300、流域マスクの
窓は列 76..501・行の一部)に、**固定遮断率モデルの遮断率分布**
`Chichibu_100m_icalpha.txt`(x 方向の勾配 α(i) = 0.8 (i−1)/(nx−1))を与え、
200 mm/h × 30 分の降雨で 1 時間計算します。

## 目的

領域マスクの窓が格子の原点 (1,1) から始まらないケースで、**全域一時に読んだ
分布ファイルを帯へ配布する経路**(`par_scatter_cell`。遮断率・初期積雪・
氷厚・管路・Green-Ampt・塩水・水質・気象・流木・瓦礫・BMI set_value が
同じ型)が窓の原点ぶんずれないことを確かめる回帰ケースです。
2026-10-16 の確保範囲の窓化(developer.md §82)で送信元ダミーの下限を
変えた際、この経路だけが取り残されて帯が (ish−1, jwh1−1) だけずれた分布を
受け取る退行が入り、既存ケースには「窓つき+分布ファイル」の組合せがなく
検出できませんでした(§82 末尾・§12)。遮断率を一様値でなく勾配にしてあるのは、
ずれると結果が変わる(S が約 20% 変わる)ようにするためです。

## 実行

```bash
make
./Run.sh            # 逐次。Log.txt を reference と比較(ULP = 1)
./Run_MPI.sh 2      # MPI
```

reference は人間が結果を確認してから `./Run.sh -u` で作成・更新します
(CLAUDE.md の絶対規律 1)。期待する挙動の目安: 1 時間時点の S ≈ 0.0568 m、
h_max ≈ 7.3 m、Q_max ≈ 28 m²/s(遮断なしの chichibu より小さい)。
