# test/river_flowline — 河道マスクを落水線に載せ直す前処理の検定

[English](en/README.md)

前処理のプログラム [utils/river_flowline](../../utils/river_flowline/README.md)(河道マスクを標高の落水線に
載せ直す)の検定です。計算は回しません(encflow は使いません)。秩父のデータに置いてある載せ直し済みの
河道マスクを、プログラムが元のマスクから作り直せることを確かめます。

```bash
./Run.sh        # utils/river_flowline をビルドして実行(数秒)
```

## 検定項目

1. **置いてあるマスクの再現(テキスト。50・100・200・500 m の 4 つの格子)。** test/chichibu の
   `data_chichibu*/` の標高・流域マスク・元の河道マスク(`…_river.txt`)から載せ直したマスクが、
   置いてある `…_river_flowline.txt` とバイト一致する。
2. **集水面積。** 落水線の集水面積(セル数)の最大が、領域のセル数に一致する(4 つの格子とも終点は
   1 セルで、全てのセルがそこへ流れる)。
3. **bil と GeoTIFF(200 m の格子。tutorials/chichibu の `data_chichibu/`)。** 表示する内訳(領域・
   低い隣のないセル・終点・元と載せ直し後のセル数・載っていたセル・外したセル・足したセル)が、
   テキストの結果と同じ。書いたファイルを元の河道マスクとして読み直して、もう一度載せ直したときの
   内訳も、テキストで同じことをした結果と同じ(書いたラスタの中身の確認)。
4. **bil の出力。** 置いてある `Chichibu_200m_river_flowline.bil` とバイト一致する。

## 結果

| 格子 | 元の河道マスク → 載せ直したマスク | 置いてあるマスクとの比較 | 集水面積の最大 = 領域のセル数 |
|---|---|---|---:|
| 50 m | 19,714 → 14,361 セル | バイト一致 | 285,843 |
| 100 m | 9,582 → 6,515 セル | バイト一致 | 71,486 |
| 200 m | 2,327 → 1,473 セル | バイト一致(テキスト・bil) | 17,885 |
| 500 m | 192 → 123 セル | バイト一致 | 2,870 |

200 m の bil・GeoTIFF の内訳は、テキストと同じです(1 回目: 2,327 → 1,473 セル。その出力をもう一度
載せ直すと 1,473 → 1,333 セル)。

## 読み方と限界

- 手続き(D8 と Priority-Flood)の正しさそのものを、別の実装と比べる検定ではありません。置いてある
  マスクが、プログラムの出力と一致し続けることを確かめる検定です(同じ入力からは、いつも同じマスクが
  できる)。
- GeoTIFF の出力は、画素の値を直接は比べていません(内訳の一致で確かめています)。
- 既定の倍精度のビルド(`PREC=double`)で確かめています。
