# test/suspend — 浮遊砂(f_suspend)の疎通・保存則と、巻き上げと沈降の釣り合い

[English](en/README.md)

浮遊砂モジュール(`&list_geomorph` の `f_suspend = 1`。河床との巻き上げ・
沈降 E-D と水柱内の移流。developer.md §19)の疎通・保存則の検定です。
閉領域の静水の上に水の山(wave_hump、+1 m)を置いて崩し、環状波の下で
巻き上がった砂が運ばれ再堆積する過程を、平衡濃度式 2 種で走らせます。
固体総量の保存・共動更新の恒等・活性を `Check_suspend.py` で検定します
([test/fluvial](../fluvial/) の掃流砂版に対応)。

構成 3・4 は、等流の水路での巻き上げと沈降の釣り合いの解析検定です
(developer.md §19.11)。清水が流入する水路で、浮遊砂は流下につれて平衡濃度
C_eq/β へ近づきます。適応を終えた区間の濃度が平衡濃度式の値に一致すること、
平衡までの不足が流下方向に減る比が離散の予測に一致することを確かめます。

## 構成 1・2(閉領域の段波)

| 項目 | 値 |
|---|---|
| 領域・格子 | 101 m × 101 m、101 × 101 セル(Δx = 1 m)、平坦、四周壁 |
| 初期条件 | 静水 h₀ = 0.5 m + コサイン型の山(+1 m、半径 15 m) |
| 土層 | sd₀ = 10 m、空隙率 λ = 0.4 |
| 時間 | dt = 0.1 s、8 s(毎ステップ更新、morfac = 1) |

| 構成 | ファイル | 平衡濃度式 `f_esform` |
|---|---|---|
| 1 | `param.txt` | 1: 超過掃流力に線形(係数 `susp_esa = 1e-4`) |
| 2 | `param_ik.txt` | 2: 板倉・岸 |

## 構成 3・4(等流の水路の平衡と適応)

| 項目 | 値 |
|---|---|
| 水路 | 南北に長い幅 1 セルの直線水路(長さ 1000 m、Δy = 1 m、勾配 0.002、n = 0.03)。両側は河床 +2 m の乾いた地盤(`make_eq.py` が書く) |
| 流れ | 北端の区間流入 Q = 0.469545 m³/s(Manning の等流水深 0.5 m、流速 0.939 m/s、τ* = 3.03)、南辺は自由流出。流入は清水 |
| 河床 | sd₀ = 10 m。morfac = 1e-8(河床の変化で流れが変わらないようにする。水柱側の交換は水理時間で進む) |
| 時間 | dt = 0.2 s、3600 s |

| 構成 | ファイル | 平衡濃度式・沈降速度・底面濃度係数 |
|---|---|---|
| 3 | `param_eq.txt` | 1: 線形(`susp_esa = 1e-4`、τ*c = 0.05)、w_f = 0.02 m/s(直接指定)、β = 1.5 |
| 4 | `param_eq_ik.txt` | 2: 板倉・岸、w_f は Rubey 式(0.02528 m/s)、β = 1 |

浮遊砂は E − D = w_f (C_eq − β C) で河床と交換し、流下につれて C_eq/β へ
近づきます。検定は次の 2 点です。

- **平衡**: 適応を終えた 250〜350 m で、C = hs/h がその場の流速と水深で求めた
  C_eq(τ*)/β に一致する。C_eq と Rubey の w_f は、users guide の式を検定
  スクリプトの中で独立に組んで求めます。
- **適応**: 平衡までの不足 hs_eq − hs は流下方向に一定の比 ρ で減ります。既定の
  MUSCL(`f_scalar_scheme = 3`)と、移流のあとに E-D を陽的に足す時間の分割を
  含めると、ρ = (1 − k)/(1 + k)、k = b/(2c(1 − b))(b = w_f β Δt/h、
  c = q Δt/(h Δy))です。10〜60 m の減衰率をこの予測と比べます。連続の解は
  セルあたり exp(−w_f β Δy/q) です。

| ファイル | 内容 |
|---|---|
| `Check_suspend.py <save>` | 構成 1・2: (1) 固体総量 \|Σhs + (1 − λ)Σ(z − z₀)\| < 1e-9、(2) 共動更新 max\|(sd − sd₀) − (z − z₀)\| < 1e-10、(3) 活性 max hs > 閾値かつ max\|z − z₀\| > 閾値 |
| `Check_suspend.py eq` / `eq_ik` | 構成 3・4: (0) 20〜350 m の等流(h/h_n・V/V_n が 1 ± 1e-5)と定常(2400 s と 3600 s の hs の差が相対 1e-5 以下)、(1) 平衡(比 1 ± 1e-5)、(2) 適応の減衰率と離散の予測の比 1 ± 1e-3、不足の減り方が一様な比であること |
| `make_eq.py` | 構成 3・4 の地形と初期水深(zinit_eq.txt・hinit_eq.txt)を書く。Run.sh・Run_MPI.sh が呼ぶ |
| `Fig.py` | 下の図 `figs/suspend.png`(Run.sh は構成 1 を `save_serial/`、構成 2 を `save/` に残す) |

## 実行

```bash
make
./Run.sh          # 構成 1 → Check → 構成 2 → Check(数秒)→ 構成 3・4(各 40 秒ほど)
./Run_MPI.sh 4    # MPI。構成 1・3・4 の state.dat が逐次とバイト一致
python3 Fig.py    # figs/suspend.png(引数 en で英語版を en/figs/ に)
```

## 所見

| 構成 | 固体総量 | 共動更新 | max hs / max\|dz\| | 判定 |
|---|---|---|---|---|
| 1 線形式 | 0.0 | 1.3e-14 | 0.49 mm / 1.13 mm | PASS |
| 2 板倉・岸 | 0.0 | 1.2e-14 | 1.12 mm / 2.52 mm | PASS |

- morfac = 1 では E-D の交換が厳密に反対称で、固体総量は機械精度で保存
  されます(MORFAC の台帳分離: 水柱側は水理時間、河床側は × morfac。§19)。
- 乾燥セル(h ≤ dd)では浮遊分を全量河床へ繰り入れ、水のない浮遊砂を
  残しません。

| 構成 | 平衡: C と C_eq/β の差 | 適応: 減衰率(セルあたり) | 離散の予測との比 | 連続の解との比 | 判定 |
|---|---|---|---|---|---|
| 3 線形 | 1.4e-6(C_eq = 5.9606e-3) | 0.0646893 | 0.999986 | 1.0125 | PASS |
| 4 板倉・岸 | 1.5e-6(C_eq = 1.4673e-2) | 0.0544050 | 0.999997 | 1.0105 | PASS |

- 平衡濃度は、検定スクリプトが独立に組んだ式の値と 6 桁で一致します(板倉・岸式の
  Ω と Rubey の沈降速度を含む)。
- 適応が連続の解より 1 % ほど速いのは、主に E-D を陽的に足す時間の分割による
  (1/(1 − b) 倍。b = w_f β Δt/h ≈ 0.01)。流入点に近い数セルは境界の面が 1 次風上
  なので比が違い、10 m から測ります。
- 20〜350 m の流れは等流から 2.4e-6 以内です。下流端の自由流出による低下背水は
  400 m より下流にとどまります。
- 土砂流入境界は [test/sedinflow](../sedinflow/)、斜面侵食(ウォッシュ
  ロード)は [test/wash](../wash/)、Kd 分配との結合は [test/kdpart](../kdpart/)。
