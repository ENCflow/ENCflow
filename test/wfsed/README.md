# test/wfsed — 沿岸の波浪場による土砂の攪拌と輸送の検定(fn_geomorph の f_wfsed。段 W4・W5)

[English](en/README.md)

沿岸の波浪場([ユーザーガイドの章](../../docs/users_guide/wavefield.md)、developer.md §90)が
掃流砂・浮遊砂に作用する段 W4(波・流れの底面せん断による攪拌と、Euler 平均流速 u^E での
輸送)と段 W5(波の歪度・非対称による岸向きの輸送速度 u_a)の検定です。モデルの出力から
独立に組み立てた Soulsby(1997)のせん断・平衡濃度・流砂量、Ruessink ら(2012)の u_a、
土砂の保存則、CERC の沿岸漂砂量と比べ、`param.txt` の結果は reference の
Log.txt・wavefield.csv・Z9998.txt・Hs9998.txt とも比較します(ULP=0)。

## 構成

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本(海浜) | `param.txt` | test/wfcurrent の基本(勾配 1/80 の海浜 120 × 8 セル、Δx = 10 m、不規則波 H_m0 = 1 m・T = 8 s・進行方向 20°、`wf_flow = 2`・ローラーあり)に掃流砂(MPM)と浮遊砂(細砂 0.2 mm)を加え、`f_wfsed = 1`(u_a の係数は既定の 0.1)。南北の辺は側方 Neumann。1 時間。再開の通し計算を兼ねる(save_all) |
| 攪拌 | `param_stir.txt` | 水深 5 m の平坦な海底に不規則波 H_m0 = 0.5 m・T = 8 s だけ(流れなし。`wf_flow = 0`)。浮遊砂だけ、u_a なし(`wfsed_facsk = wfsed_facas = 0`)。30 分 |
| 掃流砂 | `param_bed.txt` | 水深 2 m の平坦な水路(600 m × 40 m)に湧き出しの流れ 0.45 m/s と不規則波 H_m0 = 0.5 m・T = 6 s・進行方向 30°(`wf_flow = 0`)。掃流砂だけ、u_a なし。30 分 |
| 閉じた海盆 | `param_closed.txt` | 基本の流れの四辺を壁にする(沿岸流は北の壁で折り返して循環)。30 分 |
| 高波浪・低波浪 | `param_storm.txt` / `param_calm.txt` | 基本の海浜に直角入射の H_m0 = 2 m・T = 8 s(侵食)と H_m0 = 0.6 m・T = 12 s(回復)。30 分 |
| 砕波の乱れ | `param_turb.txt` | 基本に砕波の乱れによる攪拌(`f_wfsed_turb = 1`。XBeach の turb = wave_averaged の形)を加える |
| 再開 | `param_rt1.txt` → `param_rt2.txt` | 基本を 1530 s(波浪場の更新と地形の更新の間)で保存し、復元して 3600 s まで |
| 不正な設定 | `param_bad1.txt`〜`param_bad5.txt` | `fn_wavefield` なし、fn_wave の沿岸漂砂と同時、`f_wfsed = 2`、`f_wavefield = 0`、`f_wfsed = 0` で `f_wfsed_turb = 1`(どれも停止すること) |

## 検定(Check_wfsed.py)

- **攪拌**(stir): 流れがないので浮遊砂は運ばれず、各セルの濃度が平衡濃度へ近づく。モデルの
  軌道流速 Wu から τ*_w = ½ f_w u_w²/(s g d)(u_w = √2 u_rms、f_w = 1.39 (A/z0)^−0.52、
  A = u_w/ω、z0 = d50/12。Soulsby 1997)と平衡濃度 C_eq = esa (τ*_w/τ*c − 1) を組み立て、
  地形の更新ごとの E-D の緩和 c_n = (C_eq/β)(1 − (1 − β w_f Δt/h)^n) とモデルの濃度 hs/h が
  相対 1e-5 以内。固体の総量 Σ hs + (1 − λ) Σ (z − z0) が保存(save の倍精度で総量の 1e-10 以内)。
- **掃流砂**(bed): セルの掃流砂の推定 Qbx・Qby が、モデルの流速・水深・軌道流速・平均波向から
  組み立てた q_b = q*(τ*_max) √(τ*_c/τ*_max) √(sgd³)(τ*_max は Soulsby 1997 の式 69・70、
  q* は MPM。u_a = 0 の構成なので輸送の速さのせん断 τ*_s は τ*_c に等しい)と相対 1e-5 以内、向きが流れの向き、波が流れだけの流砂量を 1.5 倍以上に増やす。
- **海浜の沿岸漂砂**(beach): 沿岸漂砂が全行で北向き(沿岸流と同じ)、岸沖分布の最大が砕波帯
  (砕波の散逸が最大の 5% を超えるセル)の中、砕波帯より沖は最大の 5% 以下、行ごとの総量の差が
  1e-4 以内・地形の変化の行の差が 1e-5 m 以内(側方 Neumann の辺)、総量が CERC
  (Komar & Inman 1970。K = 0.77、波高の最大のセルを砕波点として H_rms・水深・波向をとる)の
  0.2〜5 倍(係数で合わせる量なので桁の一致)、砕波帯の岸沖の輸送が沖向き(戻り流れ)、
  堆積が侵食の沖側(戻り流れによる砂州の形成)。
- **閉じた海盆**(closed): 掃流砂・浮遊砂の移流(Stokes 輸送と u_a を差し引く面流束)・E-D を
  合わせた固体の総量が保存(総量の 1e-10 以内)。
- **岸向きの輸送速度**(asym。基本の結果): モデルの u_a(出力 Wua)が、波高・水深・周期・軌道
  流速から組み立てた u_a = (f_Sk S_k − f_As A_s) u_rms(van Thiel de Vries 2009。S_k = B cos ψ、
  A_s = B sin ψ は Ruessink ら 2012 の Ursell 数 Ur = (3/8)√2 H_rms k/(kh)³ のパラメータ化。
  係数は XBeach の公開ソースの値)と相対 2e-4 以内、波のあるセルで岸向き。
- **高波浪の侵食と低波浪の回復**(shore): 高波浪では砕波帯と浅水変形の区間の岸沖の輸送が
  すべて沖向き(戻り流れが u_a に勝つ)、低波浪では砕波帯より沖の輸送のあるセルがすべて
  岸向き(u_a が戻り流れに勝つ)。定性の検定(wavefield_plan.md の V13)。
- **砕波の乱れによる攪拌**(turb。基本と比べる): 出力の底面の乱れ Wkb が、出力のローラーの
  エネルギー E_r・水深・周期から組み立てた k_b = k_s/(exp(h/L_mix) − 1)(k_s = (D_r/ρ)^{2/3}、
  D_r = 2βgE_r/c、L_mix = √(2E_r T/(ρc)))と最大の 1e-4 以内で一致し、出力 Wu は乱れを含まない
  u_rms(線形理論の H_rms σ/(2√2 sinh kh))のまま。k_b の最大は砕波の散逸の最大より岸側、
  沿岸漂砂は基本より増え(比 1〜1.5)、行の総量の差は 1e-4 未満。
- **再開**(Run.sh): 分割した計算の state.dat・swflow_enc.dat・wavefield.dat(土砂への書き出しを
  含む)と最終分布(Z・Hs・Qby・Qsy)が通し計算とバイト一致。
- **不正な設定**(Run.sh): 5 つの構成が理由を表示して停止する。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 検定(1 スレッドで約 2 分)
./Run_MPI.sh 4    # MPI(np <= 4)。reference と ULP=0、攪拌・掃流砂・閉じた海盆・砕波の乱れは np = 1 とバイト一致、再開も MPI で
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1.6、Ubuntu 24.04)

攪拌は u_rms 0.157 m/s・τ*_w 0.0666 で、平衡濃度の緩和の式とモデルの濃度の最大の相対差 4.9e-7、
固体の総量の保存は浮遊砂の総量の 3.2e-12。掃流砂は組み立てた流砂量との最大の相対差 1.5e-7、
向きの差 5.5e-15 rad、波による増加 2.24 倍。海浜の沿岸漂砂は総量 4.47e-2 m³/s(北向き。掃流砂
1.6e-3・浮遊砂 4.31e-2)で CERC(2.76e-2 m³/s)の 1.62 倍、岸沖分布の最大は砕波帯(i = 86〜109)の
中の i = 95、砕波帯より沖は最大の 0.7%、行の総量の差 1.6e-5、地形の変化の行の差 2.2e-7 m、
砕波帯の岸沖の輸送の和は −1.28e-3 m²/s(沖向き)、最大の堆積 i = 92 は最大の侵食 i = 109 の沖側。
閉じた海盆の固体の保存は総量の 4.6e-14。u_a は 872 セルで組み立てた式との最大の相対差 8.8e-7、
最大 0.061 m/s(i = 96)。高波浪はセル 20〜110 で沖向き、低波浪は砕波帯より沖のセル 46〜89 で
岸向き。再開の継続は通し計算とバイト一致。`-Og -fcheck=all` で逐次と np = 2 が一致(範囲外
アクセスなし)、release で np = 1・2・4 が逐次 reference に ULP=0(攪拌・掃流砂・閉じた海盆は
np = 1 とバイト一致、再開も MPI で)。

砕波の乱れによる攪拌(2026-10-28 追記。developer.md §90.14)は出力 Wkb と組み立てた k_b の差が
最大の 9.2e-6、出力 Wu と線形理論の u_rms の差が最大の 1.1e-6(乱れを含まない)、k_b の最大
0.019 m²/s² は汀線のセル(i = 109、水深 0.30 m。攪拌の速さ 1.10 倍)で砕波の散逸の最大(i = 98)より
岸側、沿岸漂砂は基本の 1.019 倍、行の総量の差 1.6e-5。release で np = 1・2・4 が逐次 reference に
ULP=0 で砕波の乱れは np = 1 とバイト一致、`-Og -fcheck=all` で逐次と np = 2 が一致、1530 s で
保存した再開の継続は通し計算とバイト一致。
