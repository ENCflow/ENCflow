# test/wetbank — 雨で濡れた河岸と斜めのラスタ河道(移流項の風上供給元と側方面の人工的な減速の検定)

[English](en/README.md)

雨で濡れた河岸の薄い水膜が、隣を流れる河道の水深を変えないことを確かめる検証ケースです。物理的には、河岸に
降った雨は河道の流量を少し増やすだけで、河道の水深はその分(マニングの等流なら流量の 0.6 乗)しか変わりません。

格子に対して斜めに走る河道は、ラスタでは 1 セル横にずれる段を持つ階段になります(4 連結の 1 セル幅の階段。
tutorials/chichibu の河道マスクと同じ型)。段では、運動量保存形移流(f_advection_scheme = 3)が、河岸の水膜の
遅い流速を、深い河道セルの流束に掛けてしまう所が 2 つあります。河岸が乾いている(水深が限界水深 dd 未満)
ときは生じません(developer.md §102・§110.25)。

- **流向面の風上の供給元。** 流入面の風上値が、河道の向きに沿う線上の上流のリンク、つまり河岸の水膜のリンクから
  取られます。`&list_enc` の `f_advection_donor = 3`(既定の 4 も)は、水をほとんど運ばない薄い供給元を中立に扱います。
- **側方面。** 横から入る水の流速に、平行な隣のリンク(河岸の水膜)の値が使われます。`f_advection_lateral = 1`
  (既定の 2 も)は、入ってくる水に比べて薄い水膜のリンクを代表させません。

この検定は、その減速で河道が余分に深くなる量を、水路の向き・格子幅・河道を表すセル数を変えて測り、古い値の
組み合わせ(3・1・1・3)と、深くて遅い隣のセルの扱いの 4 つの値の組み合わせ(4・2・2・4。
[移流項のスキーム](../../docs/users_guide/advection.md) §4.4)のそれぞれで小さいことを判定します。reference 比較ではなく `Check_wetbank.py` の自己検定で合否を決めます。

## 判定

斜めの区間の中央の半分の河道セルの平均水深 h を、同じ構成の雨ありと乾いた河岸で比べ、

$$E = \frac{h_{雨}}{h_{乾}} - 1 - 0.6\left(\frac{Q}{Q_0} - 1\right)$$

を「濡れた河岸による余分な水深」とします。Q は区間中央の流量(上流端の流量に、そこまでの領域の面積 × 降雨強度を
足した値)で、0.6 (Q/Q0 − 1) が雨の流入による水深の増分です。理論値は E = 0 です。

合否(PASS/FAIL):

1. 定常: 測る区間の河道セルの平均水深が、最後の 2 つの出力で 1 mm 未満しか変わらない(乾いた河岸の 30° の階段では、
   個々のセルの水深が 1 cm 程度揺れ続けますが、平均は 0.1 mm 以内で一定です)
2. 河道に収まる: 測る区間の河岸セルの水深が 0.1 m 未満(検定の前提)
3. 乾いた河岸では、o0 と o3l0 の水深が全セルで一致(`f_advection_donor = 3` そのものは、乾いた河岸の流れを
   変えない)。新しい組では判定せず、o0n と o4l0 のセルごとの差の最大を記録します(`f_advection_donor = 4` の
   流れごとの重みは、深い供給元の重みも変えるので、この性質そのものがありません)
4. 格子に沿う水路(θ = 0°)では、どの構成でも |E| ≤ 1 %
5. 0 より悪くない: E(o3l0)・E(o3) ≤ E(o0) + 0.5 %、新しい組は E(o4l0)・E(o4) ≤ E(o0n) + 0.5 %(全ての形)
6. 乾いた河岸では、o3 の区間平均の水深が o0 に、新しい組は o4 の区間平均の水深が o4l0 に ±0.1 % で一致
   (側方面の規則が、乾いた河岸の流れを変えない。セルごとの差の最大は記録)
7. 組み合わせそのもの(o3・o4)は、濡れた河岸による余分な水深が小さい: 全ての形で |E| ≤ 5 %

o0・o3l0・o0n・o4l0 で E が 0 から離れる量(下の表)は限界として示し、合否には使いません。6 の 0.1 % と 7 の 5 % は、
今の値(0.006 % 以下、o3 が −0.4〜3.7 %・o4 が 0.2〜2.0 %)に余裕を見た回帰の上限で、理論から出した値では
ありません(理論値は 0)。

h_n は太さ ω の矩形断面のマニングの等流水深です。左の 4 列(h / h_n・E(0)・E(3・側方面 0)・E(3))は古い組の
o0・o3l0・o3、右の 4 列は新しい組の o0n・o4l0・o4 の値です。

- 格子に沿う 1 セル幅の水路では、河岸を濡らしても水深は雨の流入の分しか変わりません(どの構成も E = 0.2 %)。
  格子に沿っていても、幅が 2・4 セルの水路(Δx = 50・25 m)では、0 が 7.5・9.9 %、3 に側方面 0 が
  4.6・4.7 %、古い値の組み合わせが 1.8・1.3 % です(この 2 つの形は Run.sh には入れていません)。
- 斜めの水路では、`f_advection_donor = 0` で河道が 10〜40 % 余分に深くなります。量は向きで変わり(30° 前後で
  最大)、1 セル幅のまま格子を細かくすると増えます(22.5° で Δx = 100・50・25 m が 24・33・40 %。段の数が
  1 km あたり Δx に反比例して増え、どの段も全流量が通るため)。同じ幅 100 m を 2・4 セルで表すと 19・12 % と
  ゆっくり減ります。
- `f_advection_donor = 3` に側方面の `f_advection_lateral = 0` を組み合わせると、これが 4〜17 % に減りますが、
  0 にはなりません。残りの主な原因は側方面です: 平行な隣のリンクが河岸の水膜(dd 以上)のとき、その遅い流速が
  側方面の流入値になります(3 が側方面で扱うのは dd 未満の水膜の乾湿の切り替わりだけ)。
- **古い値の組み合わせ(3 と `f_advection_lateral = 1`)では、−0.4〜3.7 % です。** 入ってくる水に比べて薄い水膜の
  リンクを、側方面の流入値に使わないためです。合流で横から入る水が本川の運動量を薄める分は、岸の濡れに
  よらない別の項で数えます([test/tjunction](../tjunction/README.md))。
- 乾いた河岸では、古い値の組み合わせと `f_advection_donor = 0` の区間平均の水深は同じです(差は 0.001 % 未満)。
  個々のセルの水深は、45° の階段と、幅が 2・4 セルの河道で、最大 0.05・0.03・0.02 m 違います
  (`f_advection_lateral = 1` が、河道のセルどうしの側方面にも掛かるため)。ほかの 6 つの形は、出力の桁で
  全セルが一致します。
- 雨の強さにはほとんどよりません。河岸が dd を超えて濡れていれば、雨 2 mm/h(河岸の水膜は平均 2 mm・最大 4 mm)
  でも 20 mm/h(平均 6 mm・最大 11 mm)とほぼ同じ E になります(22.5°・Δx 50 m で、0 が 32.5 / 32.7 %、3 に
  側方面 0 が 8.3 / 10.2 %、古い値の組み合わせが 0.5 / 1.4 %。2 mm/h の計算は Run.sh には入れていません)。dd を 0.1 mm にしても、0 と 3(側方面 0)は
  同じ値で(水膜が dd より厚い。developer.md §102)、この検定では dd の値の影響は見ていません。

- **4 つの値の組み合わせ(o4)では、0.2〜2.0 % です。** 乾いた河岸の水深(h / h_n)は 0.94〜1.27 で、古い組の
  0.94〜1.37 より、格子の向き・幅による違いが小さくなります(22.5°・Δx 25 m の 1 セル幅が 1.37 → 1.27、30° が
  1.02 → 1.09)。乾いた河岸でも働く `f_advection_bend = 2` の分で、o0n も同じ値です。
- 新しい組の o0n と o4l0 は、乾いた河岸でも全セルでは一致しません(セルごとの差の最大は 22.5°・Δx 25 m の
  0.15 m、10° で 0.04 m)。o4 と o4l0 の区間平均の水深の差は 0.006 % 以下です(セルごとの差の最大は、45° の階段で
  0.06 m)。

## 限界

- 乾いた河岸でも、斜めの 1 セル幅の階段の水深は格子に沿う水路と同じになりません(h / h_n = 古い値の組み合わせで
  0.94〜1.37、4 つの値の組み合わせで 0.94〜1.27。22.5° では 1 セル幅のまま細かくすると深くなる)。これは移流項の構成によらない、ラスタの階段そのものの通水能の差で、
  この検定の対象外です。
- 雨は河岸と河道に一様に与え、河岸の雨水はすぐ河道へ入る形にしています。河岸が氾濫原として流れを運ぶ場合(谷底の
  浸水)の運動量の交換は扱いません。
