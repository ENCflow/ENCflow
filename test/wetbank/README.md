# test/wetbank — 雨で濡れた河岸と斜めのラスタ河道(移流項の風上供給元の人工的な減速の検定)

[English](en/README.md)

雨で濡れた河岸の薄い水膜が、隣を流れる河道の水深を変えないことを確かめる検証ケースです。物理的には、河岸に
降った雨は河道の流量を少し増やすだけで、河道の水深はその分(マニングの等流なら流量の 0.6 乗)しか変わりません。

格子に対して斜めに走る河道は、ラスタでは 1 セル横にずれる段を持つ階段になります(4 連結の 1 セル幅の階段。
tutorials/chichibu の河道マスクと同じ型)。段では、運動量保存形移流(f_advection_scheme = 3)の流入面の風上値が、
河道の向きに沿う線上の上流のリンク、つまり河岸の水膜のリンクから取られます。深い河道セルの流束に水膜の遅い
流速を掛けた人工的な減速が生じ、河岸が乾いている(水深が限界水深 dd 未満)ときは生じません(developer.md §102)。
この検定は、その減速で河道が余分に深くなる量を、水路の向き・格子幅・河道を表すセル数を変えて測ります。
あわせて、`&list_enc` の `f_advection_donor = 3`(水をほとんど運ばない薄い供給元を中立に扱う)がそれを
どれだけ除くかを測ります。reference 比較ではなく `Check_wetbank.py` の自己検定で合否を決めます。

## 構成

| 項目 | 値 |
|---|---|
| 水路 | 西端から東向きの入口区間(300 m 以上)→ 格子に対して角度 θ の直線の斜めの区間(長さ 4 km)→ 東向きの出口区間で東端の自由流出へ。河床勾配 0.0044、粗度 0.035。河道は中心線からの垂直距離が太さ ω = N·Δx·(cos θ + sin θ) の帯に入るセル(N = 1 で 4 連結の 1 セル幅の階段) |
| 河岸 | 河道の両側 250 m の帯。地盤は河床 + 6 m(越流しない高さ)で、河道へ向かって 2 % の横断勾配(雨水はすぐ河道へ入る)。その外は領域外 |
| 流れ | 上流端に一定の区間流入 Q0 = 6 m²/s × N·Δx(格子に沿う 1 セル幅で水深約 2 m)。雨のケースは全域に 20 mm/h の一定の雨。3 時間(1 時間半で定常) |
| 形(9) | Δx = 50 m・1 セル幅の θ = 0°・10°・22.5°・30°・45°、θ = 22.5° の 1 セル幅の Δx = 100・25 m(河道の幅も Δx)、θ = 22.5° の幅 100 m を Δx = 50・25 m の 2・4 セルで表したもの |
| ケース(36) | 形 × 乾いた河岸(雨なし)・雨 20 mm/h × `f_advection_donor` = 0・3。名前は `a22p5_dx50_n1_r20_o3` = 22.5°・Δx 50 m・1 セル・雨 20 mm/h・3 |

| ファイル | 内容 |
|---|---|
| `make_init.py` | 全ケースの地形 `d_<形>/`(z・領域マスク・河道マスク・中心線に沿う距離 s・info)と設定 `p_<case>.txt` を書く(引数 `list` でケース名を出す) |
| `Check_wetbank.py` | 各ケースの最後の出力の水深から下の判定をする(引数 `table` で README 用の表も出す) |

## 判定

斜めの区間の中央の半分の河道セルの平均水深 h を、同じ `f_advection_donor` の雨ありと乾いた河岸で比べ、

$$E = \frac{h_{雨}}{h_{乾}} - 1 - 0.6\left(\frac{Q}{Q_0} - 1\right)$$

を「濡れた河岸による余分な水深」とします。Q は区間中央の流量(上流端の流量に、そこまでの領域の面積 × 降雨強度を
足した値)で、0.6 (Q/Q0 − 1) が雨の流入による水深の増分です。理論値は E = 0 です。

合否(PASS/FAIL):

1. 定常: 測る区間の河道セルの平均水深が、最後の 2 つの出力で 1 mm 未満しか変わらない(乾いた河岸の 30° の階段では、
   個々のセルの水深が 1 cm 程度揺れ続けますが、平均は 0.1 mm 以内で一定です)
2. 河道に収まる: 測る区間の河岸セルの水深が 0.1 m 未満(検定の前提)
3. 乾いた河岸では `f_advection_donor` = 0 と 3 の水深が全セルで一致
4. 格子に沿う水路(θ = 0°)では、どちらの `f_advection_donor` でも |E| ≤ 1 %
5. `f_advection_donor = 3` は 0 より悪くない: E(3) ≤ E(0) + 0.5 %(全ての形)

斜めの水路で E が 0 から離れる量(下の表)は限界として示し、合否には使いません。

h_n は太さ ω の矩形断面のマニングの等流水深です。

- 格子に沿う水路では、河岸を濡らしても水深は雨の流入の分しか変わりません(0・3 とも E = 0.2 %)。
- 斜めの水路では、`f_advection_donor = 0` で河道が 10〜40 % 余分に深くなります。量は向きで変わり(30° 前後で
  最大)、1 セル幅のまま格子を細かくすると増えます(22.5° で Δx = 100・50・25 m が 23・32・40 %。段の数が
  1 km あたり Δx に反比例して増え、どの段も全流量が通るため)。同じ幅 100 m を 2・4 セルで表すと 19・12 % と
  ゆっくり減ります。
- `f_advection_donor = 3` はこれを 6〜17 % に減らし、どの形でも 0 より小さい値です。ただし 0 にはなりません。
  残りの主な原因は側方面です: 平行な隣のリンクが河岸の水膜(dd 以上)のとき、その遅い流速が側方面の流入値に
  なります(3 が側方面で扱うのは dd 未満の水膜の乾湿の切り替わりだけ)。側方面にも薄い供給元の判定を入れた作業用の
  ビルドでは、全ての形で 3.6 % 以下に
  なりました(developer.md §102。本体には入れていません)。
- 雨の強さにはほとんどよりません。河岸が dd を超えて濡れていれば、雨 2 mm/h(河岸の水膜約 3 mm)でも 20 mm/h
  (約 1 cm)とほぼ同じ E になります(22.5°・Δx 50 m で 0 が 32.1 / 32.4 %、3 が 9.1 / 10.9 %。developer.md §102)。
  dd を 0.1 mm にしても同じ値で(水膜が dd より厚い)、この検定では dd の値の影響は見ていません。

## 限界

- 乾いた河岸でも、斜めの 1 セル幅の階段の水深は格子に沿う水路と同じになりません(h / h_n = 0.94〜1.36。22.5° では
  1 セル幅のまま細かくすると深くなる)。これは `f_advection_donor` によらない、ラスタの階段そのものの通水能の差で、
  この検定の対象外です。
- 雨は河岸と河道に一様に与え、河岸の雨水はすぐ河道へ入る形にしています。河岸が氾濫原として流れを運ぶ場合(谷底の
  浸水)の運動量の交換は扱いません。
