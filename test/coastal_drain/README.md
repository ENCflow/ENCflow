# coastal_drain — 回帰テスト(海抜下ポルダーの排水。§46.5 (7)(8))

地盤 0.2 m のポルダー+潮位 0.5 m 一定の海(ゼロメートル地帯)で、
(7) 負の管底標高(fn_gwc_bot = −1.8 m)、(8b) 海域セル吐口
(fn_gwc_outfall)、(8a) 機場(&list_struct_pump の f_pump_src=1 =
管路直接取水)を同時に検査する。堤防なしのため海がポルダーへ浸入し、
全系が潮位に向かって平衡する(それ自体が検算に使える)。

## 実行方法

```
make            # ../../bin/ の実行ファイルへのリンクを張る
./Run.sh        # 逐次 + reference 比較(数十秒。2 時間の計算)
./Run_MPI.sh 2  # MPI(np=2)+ 逐次 reference と ULP=0 比較
./Run_stiff.sh  # 硬い変種(slot_sy=0.002 → サブサイクル N=2)。
                # reference 機構は使わない(下記の解析平衡で検算)
```

data_cd/ は静的データとしてコミット済み(gen_data.py は生成の記録)。

## 検証結果(2026-08-23。gfortran 13.3 / OpenMPI)

- 負の管底マップが受理される(実装前は par_stop)
- **終状態が解析平衡と厳密一致**:
  - 全域の水位 = 潮位 0.5 m(h = 0.30 m)
  - 全管路セル hgc = 0.1260 = cap + (0.5 − 管頂水頭(−0.8))·slot_sy
    = 0.1 + 1.3×0.02(吐口の等化上限が設計どおりに閉じる)
  - フラップ: ΔH=0 で放流停止(逆流なし)
- 吐口の累積放流 6.7062 m3(dispose の総括。全構成で同値)
- np=1,2,4 の全場出力・Log が逐次と完全一致
- -fcheck=all(-Og)の逐次・np=2 がクリーン完走、かつ -Ofast と
  S 列全桁一致
- 機場は hgc > 0.05 で起動し西の低地 (4,4) へ域内還元(平衡到達後は
  循環。物理的に排水を完結させるには堤防+域外/海側放流の設定にする)

## 物理的な注意

潮位より低い水頭の管内水は重力吐口では吐けない(等化上限 hgc=0.126 で
止まる)— これが §46.5 (8) の「海抜下の系は機場が必須」の数値実証。
堤防で海と切って機場の放流先を海側にすれば、内水排除の実務構成になる。
