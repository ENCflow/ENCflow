# test/wave_shore — 波浪による沿岸漂砂(fn_wave)の検定

沖波を与件に砕波帯の汀線方位から沿岸漂砂を起こす機構(developer.md §84.15、
docs/wave_plan.md 案 A)を、直線汀線の線形理論(Ashton & Murray 2006)で検定します。

## 設定

800 m × 240 m(Δx = 2.5 m)、北が乾いた浜で南へ一様勾配 0.02 で深くなる海浜(汀線
y = 20 m、水位 0。汀線が領域の内側にあるので領域の縁の扱いに依らない)。汀線に正弦波状の
擾乱 η = a sin(2πx/L)(a = 6 m、L = 200 m)を置く(`make_init.py`)。沖波は H₀ = 0.5 m、
T = 5 s(砕波水深 h_b/γ = 0.86 m = 汀線から 43 m の帯)。汀線方位の平滑化は物理長
wave_lsm = 5 m(= 2Δx)の多パス核+局所勾配項 wave_bslp = 5(§84.15 段 3 (a))。掃流砂
f_fluvial = 1 は経路の前提(静水なので掃流砂自体は動かない)。morfac = 5、水理 1 h =
地形 5 h。

| 構成 | 波の進行方向 | 役割 |
|---|---|---|
| low | 110°(岸向き法線 = 北から α = 20°) | 低角: 擾乱が拡散で減衰 |
| high | 150°(α = 60°) | 高角: 反拡散で擾乱が線形理論の成長率で育つ |
| high0 | 同上、wave_lsm = 0 | 従来のセル半径の核。凹凸が格子スケールで育つことの記録 |
| bar | 110°、直線汀線+非侵食の水没砂州(x = 350〜450 m、天端 0.2 m)、f_wave_shadow = 1 | 段 3 (b) 部分遮蔽: 砂州の陰にサリエント、風下に侵食 |
| bar0 | 同上、f_wave_shadow = 0 | 遮蔽なしの対照 |
| off | fn_wave あり・f_wave_longshore = 0 | 無効時ゼロ追加(nowave と state.dat がバイト一致) |
| nowave | fn_wave なし | off の比較基準 |

## 検定項目(Check_wave_shore.py)

1. 低角(α = 20°): 中央 2 波長(x = 200〜600 m)の h = 0.5 m 等深線の振幅 a(t) が
   exp(−D k² t) で減衰し、減衰率が線形理論 D = Q_s'(α)/h_b、
   Q_s'(α) = K₂ H₀^{12/5} T^{1/5} cos^{1/5}α (cos²α − 1.2 sin²α) の D k² に ±35 %
   (実測: 振幅 6.0 → 3.02 → 1.47 m、比 1.05)。
2. 高角(α = 60°): 同じ振幅が exp(+|D| k² t) で育ち、成長率が理論の 0.5〜1.5 倍(実測
   6.0 → 10.1 → 14.7 m、比 0.86)。かつ砕波帯沖側の等深線(h = 0.8 m)の凹凸のスペクトルで
   波長 10 m 未満のパワーが 15 % 未満(実測 6 %。格子スケールの砂州が無い)。
   2b. high0(従来のセル半径の核): 同じパワーが 20 % 以上(実測 30 %)。
3. 体積保存(閉領域。印字精度の丸めを許容)。
4. off と nowave の state.dat がバイト一致(Run.sh の cmp)。
5. 水没離岸堤(bar / bar0): 遮蔽ありで陰(汀線から 25 m まで)の堆積が遮蔽なしの 1.5 倍以上
   (実測 48 対 20 m³ = 2.4 倍)、風下 100 m の侵食が 1.3 倍以上(実測 211 対 115 m³ = 1.8 倍)。

## 実行

```bash
make
./Run.sh          # 入力生成 → low / high / high0 / bar / bar0 / off / nowave → Check(7 ラン。20 分程度)
./Run_MPI.sh 4    # MPI。state.dat が逐次とバイト一致するのが規律
```
