# test/gwwidth — サブグリッド河道幅のセルでの地下⇔地表の水の受け渡し

[English](en/README.md)

[サブグリッド河道幅](../../docs/users_guide/channel.md#サブグリッド河道幅)(fn_width)の
セルでは、地表の水深はセル内の河道部分(平面積率 wfrac)の水深です。地下の貯留
(層1 hg・管路連続体層 hgc など)はセル全体の平面の量なので、両者の間で水を
受け渡すときは体積が等しくなるように換算します(地表→地下は af/gv、地下→地表は
1/wfrac。developer.md §26.1)。この換算が抜けると、地下から湧き出した水は河道幅の
割合しか地表に出ずに消え、管路層への流入では逆に水が増えます。その検定です。

- **param.txt(回帰の reference と比較)**: 閉じた谷(12 × 8 セル、dx = 10 m)。
  勾配 5 % の両斜面が列 10 の谷底へ下り、列 10 は幅 2 m のサブグリッド河道
  (wfrac = 0.2)。1 時間の一様降雨 50 mm/h がすべて浸透し(Green-Ampt、浸透能
  200 mm/h、土層 0.5 m × 有効間隙率 0.1 = 0.05 m で飽和)、地下水の側方流
  (透水係数 1e-2 m/s)で谷へ集まって、飽和した谷底から地表へ湧き出す。雨には
  濃度 1 mg/L のトレーサを持たせる。
- **param_nowidth.txt**: 同じ構成で河道幅だけを外した対照(換算係数は 1)。
- **param_gwc.txt**: 同じ谷で地表を不浸透にし、1 時間の一様降雨 20 mm/h を全セルの
  枡(1 個/セル)から管路連続体層(貯留容量 0.01 m、管頂 = 地表、側方通水なし)へ
  流し込む。満管になると被圧水頭が立ち上がって地表へ噴き出す。谷底の最下流の河道
  セルに陸側吐口(Cd·A = 0.05 m²)を置く。雨と噴出・吐口の水の濃度は 1 mg/L。

## 構成

| 項目 | param.txt | param_nowidth.txt | param_gwc.txt |
|---|---|---|---|
| 地形 | 閉じた谷(`data_gwwidth/z.txt`、河道マスク `rw.txt`) | 同左 | 同左 |
| 河道幅 | 2 m(`width.txt`。wfrac = 0.2) | なし | 2 m |
| 雨 | 50 mm/h × 1 時間(濃度 1 mg/L) | 同左 | 20 mm/h × 1 時間(濃度 1 mg/L) |
| 地下 | Green-Ampt + 側方流(層1) | 同左 | 管路連続体層のみ(枡・吐口) |
| 時間 | dt = 0.5 s、6 時間 | 同左 | dt = 0.5 s、4 時間 |

| ファイル | 内容 |
|---|---|
| `Run.sh` | param.txt の Log.txt・wq.csv を reference と比較(ULP = 0。Log の Runge 列は除外)→ `Check_gwwidth.py` の検定 → param_nowidth.txt・param_gwc.txt を実行して検定 |
| `Check_gwwidth.py conserve\|rain\|match\|conc\|ledger` | 雨の後の総水量が一定(相対 1e-10)/ 最終の総水量が雨の総量に等しい(相対 1e-6。雨の濃度 1 mg/L なので台帳の in_rain_g が雨の体積)/ 河道幅なしと最終の総水量が等しい / 水深 1 mm を超える全セルで濃度が 1 ± 1e-3 mg/L / 水質の台帳の閉合 |

## 実行

```bash
make
./Run.sh
./Run_MPI.sh 4
```

## 所見

| 量 | 修正後 | 修正前(2026-11-03 の実行ファイル) |
|---|---|---|
| param.txt の最終の総水量 (m。領域平均) | 0.0508264(雨の総量・河道幅なしと一致) | 0.0241(53 % が消えた) |
| param.txt の谷底の濃度 (mg/L) | 0.99987〜0.99994 | 3.65〜6.21(湧き水が縮んで濃く見える) |
| param_gwc.txt の最終の総水量 (m) | 0.0203306(雨の総量と一致) | 0.0211(流入で 3.6 % 増えた) |
| param_gwc.txt の濃度 (mg/L) | 1.00041〜1.00050 | 1.00042〜1.00047 |

- 修正前の param_gwc.txt の濃度は、噴出の水量と同伴する質量が同じ単位で数えられて
  いたため 1 に近い(水の増減は管路と地表の間の換算の抜けで、検出は総水量で行う)。
- 濃度の 1 からの小さなずれ(1e-4 程度)は修正の前後で同じ大きさで、浸透・流入の
  同率移動の割合をステップの終わりの水深で評価することによる既存のずれです
  (検定の許容 ±1e-3 はこれを許す幅)。
- 断面形(σ 則)のセルの受け渡しは近似のままで、このテストの対象外です
  (developer.md §26.1、[ユーザーガイド](../../docs/users_guide/channel.md#断面形σ-則))。
