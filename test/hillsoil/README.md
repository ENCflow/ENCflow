# test/hillsoil — 斜面の土層(風化による土層生成と定常斜面)の検定

[English](en/README.md)

地形変化モジュールの基岩風化 = 土層生成(`&list_geomorph` の `f_wthr = 1`、
[ユーザーガイドの地形変化の章](../../docs/users_guide/geomorph.md)、式は
[解説 §7](../../docs/users_guide/sediment.md#7-基岩風化と隆起f_wthr--f_uplift))と、
その生成速度の倍率の分布 `fn_wthr`(developer.md §88.13)の検証ケースです。
土層厚 sd は dsd/dt = W exp(−sd/sd*)(W = W0 × 倍率)で増え、z は変わりません
(岩盤面 z − sd が下がる)。更新式は指数の厳密積分なので、解析解

  sd(T) = sd* ln(e^{sd0/sd*} + W T/sd*)

と刻みによらず丸めの水準で一致します(W1)。C2 は、隆起・風化・深さ依存クリープ
(`creep_hstar`)が釣り合う定常斜面です(docs/mountain_stream_plan.md §11.3、developer.md
§88.15)。reference は持たず、解析解・保存則・バイト一致・停止の表示で判定します。

W1 の台地は水のない平らな 8 × 12 セル(Δx = 1 m、z = 10 m)。W0 = 50 mm/kyr(既定値)、
sd* = 0.5 m、dt = 1 s を 100 ステップ、毎ステップの地形更新 × morfac 1e10(dts = 1e10 s)で
地形の時間 1e12 s(約 3.2 万年)。

C2 の領域は 11 × 24 セル(Δx = 1 m)。中央の列が南へ勾配 0.01 で下る幅 1 セルの渓流
(北端の区間流入 Q = 0.336 m³/s、等流水深 0.3 m、南辺は自由流出)で、両側に 5 セルずつの
斜面(東西の端は分水界 = 壁)。斜面だけが隆起し(U = 2e-6 m/s)風化する(W0 = 3U・6U、
sd* = 0.5 m)。渓流は隆起も風化もしない固定床(`fn_uplift`・`fn_wthr` の倍率 0。
`c2_hill.txt`)で、クリープで届いた土層を掃流砂(d50 = 1 cm)で出口へ運ぶ = 斜面の
基準面になります。クリープは D = 2.3817e-5 m²/s、H_c = 0.3 m。定常では岩盤面が動かない
(W(H) = U)ので土層厚 H_ss = sd* ln(W0/U)、z が動かない(∇·q = U)ので横断の曲率
∇²z = −U/D_eff(D_eff = D (1 − e^{−H_ss/H_c}))で、渓流から k セル目の高さは
(U/D_eff)(k L − k(k−1)/2)(L = 5。離散の 2 階差分でも厳密)。初期は渓流の底より 0.5 m
高い平らな台地(土層厚 0.3 m)。dts = 40 s(morfac 400)で地形の時間 5e6 s(斜面の最も
遅いモードの緩和時間約 6e5 s の約 8 倍)。値は検定用に時間を縮めたものです。

| 構成 | ファイル | 内容 | 判定 |
|---|---|---|---|
| W1 一様 | `param_wthr_none.txt` | fn_wthr なし(全セル W = W0。従来の式) | 全セルで解析解と相対 1e-12、z が不変 |
| W1 分布 | `param_wthr_map.txt` | 倍率 m = 0.25 ((i + 4j) mod 9)(0〜2。`wmap.txt`。並びが 9 行周期でずれるので、帯の配布の行ずれを検出できる)、初期の土層厚 0〜0.3 m(`sdinit.txt`) | 全セルで解析解と相対 1e-12、倍率 0 のセルの土層厚と全セルの z が不変 |
| リスタート往復 | `param_wthr_map_rt1.txt` → `param_wthr_map_rt2.txt` | 分布の構成を 50 s で保存し 100 s まで継続(倍率の分布は再開時に読み直す) | 通し計算と state.dat がバイト一致 |
| 入力の誤り | `param_wthr_bad.txt` / `param_wthr_nof.txt` | 1 セル(i = 4, j = 11)だけ負の倍率(`wmap_bad.txt`)/ f_wthr なしで fn_wthr を与える | 初期化で「fn_wthr must be >= 0」/「fn_wthr requires f_wthr=1」で停止 |
| C2 定常斜面 | `param_c2_w3.txt` / `param_c2_w6.txt` | W0 = 3U(H_ss = 0.549 m、U/D_eff = 0.100 1/m)/ 6U(0.896 m、0.0884 1/m) | 最後の 2 回の出力で定常性 max\|dz/dt\| < 0.01 U。中央の行(j = 7〜18)の斜面で土層厚が H_ss と相対 1 %、横断の 2 階差分(分水界は鏡像)が −U/D_eff と 5 %。土砂収支 Σ(z − z0)A = 隆起 − 開境界の流出/(1 − λ)(流出は developer.md §88.12 の台帳)の差が隆起量の 1e-8 以内。渓流の岩盤面 z − sd が不変(1e-9 m) |
| C2 のリスタート往復 | `param_c2s.txt`、`param_c2s_rt1.txt` → `param_c2s_rt2.txt` | c2_w3 を 1000 s で打ち切った通し計算と、500 s で保存して継続した計算 | state.dat がバイト一致 |

| ファイル | 内容 |
|---|---|
| `make_init.py` | W1 の倍率の分布・負の倍率の分布・初期の土層厚と、C2 の地形・初期水深・土層厚・斜面の倍率の生成(定数は `param*.txt`・`Check_hillsoil.py` と対で保守) |
| `Check_hillsoil.py wthr / c2` | 上の判定(z・sd は save の state.dat から倍精度で、C2 の定常性は bil(単精度)の Z から読む) |
| `Run.sh` / `Run_MPI.sh N` | 全構成の実行と検定。MPI は逐次の save(`save_*_serial`)とバイト比較。負の倍率のセルは最後の行の帯にあり、そのランクだけが検出しても全ランクが停止することを見る |

## 実行

```bash
make
python3 make_init.py wmap > wmap.txt   # 入力の再生成(同梱。変更したときだけ)
./Run.sh            # 逐次(約 1 分。C2 の 2 構成が各 30 秒)
./Run_MPI.sh 4      # MPI(Run.sh の後に。save_*_serial とバイト比較)
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1、既定の -Ofast ビルド)

- W1: 解析解との max 相対誤差は分布 1.6e-15・一様 6.2e-16(許容 1e-12)。倍率 0 の
  11 セルは土層厚が不変、全セルで z が不変。
- リスタート往復はバイト一致。入力の誤りの 2 構成は初期化で停止。
- C2(W0 = 3U・6U): 中央の行の斜面の土層厚と H_ss の max 相対差 1.2e-3・1.7e-4、横断の
  2 階差分と −U/D_eff の max 相対差 9.4e-3・1.1e-2(最大は渓流の隣のセル。行 12 の渓流からの
  高さは 0.4987・0.8983・1.1979・1.3976・1.4974 m、解析解 0.5・0.9・1.2・1.4・1.5 m)、定常性
  1.2e-3 U・2.0e-4 U、土砂収支の差は隆起量の 3e-10・1e-10、渓流の岩盤面の変化 6e-13 m。
  dts = 100 s(morfac 1000)では渓流の掃流砂の fluv_dzmax の制限が働き、斜面の脚部が崩れた。
  C2 のリスタート往復はバイト一致。
- np = 1, 2, 4 で逐次とバイト一致、同じ検定に PASS。-fcheck=all の np = 2 も PASS。
- fn_wthr を与えない経路は、fn_wthr の追加の前の実行ファイルと state.dat がバイト一致
  (-O2)。全セル 1 の分布も未指定とバイト一致(-O2。規格の保証ではないので検定には入れない)。
