# test/dbmix — 土石流と混合粒径の併用(f_debris + f_bedmix)の検定

[English](en/README.md)

developer.md §139・§143、docs/mixed_sediment_plan.md §12・§13。土石流の流れの土砂 h_s を粒径階ごとの柱で運び、
河床(交換層 1 枚・下層 1 枚)との出し入れの組成を追う計算を、単一粒径との一致・式の値・粒径階ごとの
収支・再開と並列のバイト一致で検定する。

既定では、土石流の侵食・堆積・流動化は粒径を選ばない。侵食と流動化は柱の上から(交換層 → 下層の順に)取り去った
組成で流れに入り、堆積はそのセルの流れの組成で河床に入る。土石流の式は代表粒径 `db_d50` の単一粒径の
ままなので、地盤高・土層厚・流れの土砂の合計は、単一粒径の計算と同じになる。検定はこの性質を使う。

`f_dbsel = 1`・`2`(高橋・中川則 `f_dbed = 3` で使う)は、土石流の式の侵食を動ける粒径階に限る。動ける粒径階は、
流動面の勾配が `db_seltan`(既定 0.03)を超えるセルでは粒径が流動深以下のもの、それ以下のセルでは限界掃流力を
超えるもの(高橋・井上・中川・里深 2000 の式 (19)〜(21)、高橋・中川・里深・川池 2001 の式 (26) と流れの型の
区分)。動ける粒径階の交換層の割合の和を K3、粒径を選ばない式の侵食速度を i、交換層の割合を F_k とすると、
粒径階 k の侵食速度は、`1` が i K3 F_k(式の印字どおり。かさの侵食速度は i K3²)、`2` が i F_k(かさの侵食速度は
i K3。同じ論文の本文「i K3 がバルクの侵食速度」に合わせた形)。動けない粒径階は河床に残り、交換層が下がる
たびに下層から加わるので、表層の割合が増えて侵食が止まる。検定は、動けない粒径階の量がどのセルでも
変わらないこと、表層の割合の増え方の式、1 ステップの侵食量の比、判定の両極限(全粒径階が動ける・何も
動けない)を使う。

地形は 20 × 60 セル(dx = dy = 1 m)の遷緩点つき斜面で、y < 40 m が勾配 0.4、下流は平坦。流れは j 方向
(南向き)で、MPI の帯の界面を横切る。入力と設定は make_init.py が作る。設定は 4 つの雛形の行を差し替えて
p_<構成>.txt に書く(差し替えた行と足した行には注釈が付く)。

| 雛形 | 土石流の起こし方 | 土層 | 境界 |
|---|---|---|---|
| param_e.txt | 雨 200 mm/h の薄層流が斜面の土層を侵食する | 一様 0.3 m | 閉領域 |
| param_r.txt | 斜面の崩壊域(12 × 12 セル)を計算の開始と同時に流動化する(`fn_dbinit`) | 崩壊域だけ 1 m、ほかは基盤 | 閉領域 |
| param_s.txt | 雨 500 mm/h の浸透で土層が飽和し、斜面安定判定(`f_slide`)が上から 0.2 m ずつ流動化する | 一様 0.5 m | 閉領域 |
| param_b.txt | 北辺の 6 セルから土砂を含む流れ(3 m³/s、体積濃度 0.3)を入れる。下流は勾配 0.1 | なし(基盤) | 南辺が自由流出 |

混合粒径の河床は 2 通り。「等粒径」は 3 粒径階がすべて 2 mm(= 単一粒径の構成の粒径)で、組成だけが違う。
「粒度の幅」は 0.5・2・8 mm で、交換層 0.2・0.5・0.3、下層 0.5・0.3・0.2、交換層厚 4 mm。`f_dbsel` の構成は、
組成と交換層厚を「粒度の幅」と同じにして、粒径だけを変える(「巨礫」= 0.5 mm・2 mm・1 m、「砂」=
0.2・0.5・1 mm)。

## 構成

| 構成 | 設定 | 検定 |
|---|---|---|
| e1 → e3 | 雛形 e。単一粒径 2 mm と、等粒径で一様な組成(0.3・0.4・0.3) | 地盤高・土層厚・h_s が一致(< 1e-12 m)、流れと河床の組成が初期値のまま(< 1e-11)。柱を 1 本ずつ運んだ和 = 1 本で運んだ結果 |
| u1 → u3 | e1 と、等粒径で交換層と下層に別の粒径階を置いた構成(交換層 1・0・0、下層 0・1・0、交換層厚 2 mm)。どちらも 1 次風上(`f_scalar_scheme = 1`) | 地盤高・土層厚・h_s が一致(< 1e-12 m)。組成が場所で変わっても、1 次風上は線形なので和が変わらない。流れの中で 2 つの粒径階が混ざり、置いていない粒径階 3 は 0 のまま |
| m3 | u3 と同じ河床で MUSCL(既定) | e1 との地盤高の差が地形の変化の 2 % 以内(制限関数が粒径階ごとに働く分の差。0 ではない)。粒径階ごとの収支は閉じる |
| w3 | 雛形 e、粒度の幅 | 粒径階ごとの収支(河床・流れ)の残差 < 1e-9 m³、河床の側と流れの側で数えた交換が一致、保存から数えた粒径階ごとの総量(河床 + 流れ)= 初期の総量、柱の和 = h_s、組成が 0〜1 で和が 1 |
| tk3 | w3 に高橋・中川則(`f_dbed = 3`、`f_dbres = 3`、`db_d50` = 1 cm) | w3 と同じ |
| tkb3 | tk3 の土層を斜面だけにする(平坦部は基盤) | 粒径階ごとの収支が閉じ、保存から数えた総量が初期の総量に一致し、平坦部の基盤に土砂が届いて計算が終わる。雨で全域が濡れているので、流れの先端は、侵食できない基盤の上を、ごく小さい土砂の柱を先に立てて進む。境界検査つきのビルド(非正規化数を残す)では、その濃度が非正規化数になったセルで、高橋・中川則の堆積の式がオーバーフローして止まった(developer.md §142 の不具合の再発防止) |
| sel3・sel3b | tk3 の粒径を「巨礫」にし、`f_dbsel` = 1(sel3)・2(sel3b)。水深 2 cm の水を置いて始める | 粒径階 3(1 m。流動深より必ず大きい)は流れに入らない(台帳も柱も 0)。その量はどのセルでも変わらない(< 1e-12 m)。侵食だけを受けたセルの表層の割合が F_3 = F_3(0) + F_sub,3 Δ / L_a(Δ は侵食深)に一致(< 1e-11)。侵食は F_3 が 1 に近づくと止まり、侵食深は (1 − F_3(0)) L_a / F_sub,3 = 14 mm を超えない(30 s で、sel3b は 400 を超えるセルで F_3 > 0.99、侵食速度が K3² に比例する sel3 は F_3 > 0.9)。堆積に粒径階 3 は入らない。粒径階ごとの収支は w3 と同じ判定 |
| selp0 → selp1・selp2 | 「巨礫」で、水深 2 cm の水を置いて 1 ステップ。`f_dbsel` = 0 と、1・2 | K3 = F_1 + F_2 = 0.7 として、斜面のかさの侵食量が selp0 の K3² 倍(selp1)・K3 倍(selp2)(< 1e-12 m)。粒径階 1・2 が流れに入る量は selp0 の K3 倍(selp1)・同じ(selp2)、粒径階 3 は 0。交換層の組成が「動ける粒径階を取り去り、下層を取り込んだ」値。平坦部(掃流の型)は限界掃流力を超える粒径階がなく、侵食しない |
| sela0 → sela1 | tk3 の粒径を「砂」(全粒径階が限界水深 1 mm 以下)にして、`f_dbsel` = 0 と、1(`db_seltan = 0` = 全域で流動深の判定) | 全粒径階が動けるので、保存(流れ・河床・組成・柱)が sela0 とすべて同じ値 |
| selb0 → selb1 | tk3 の限界掃流力を 1e-30 にして、`f_dbsel` = 0 と、2(`db_seltan = 10` = 全域で掃流力の判定) | 全粒径階が限界掃流力を超えるので、保存が selb0 と丸めの範囲で一致(< 1e-12 m)。ビット一致にはならない。動き始めの流れの先端には流速がほぼ 0(1e-15 m/s 未満)のセルがあり、そこだけは掃流力が 1e-30 も下回って判定が働く(侵食するセル × 更新の 1 % 未満) |
| selc3 | tk3 の限界掃流力を 1e30 にして、`f_dbsel = 2`、`db_seltan = 10` | どの粒径階も動けず、土石流の式は何も侵食しない(流れへ出た量・地形の変化が 0) |
| s3 | 雛形 s、粒度の幅 | w3 と同じ(斜面安定判定の流動化を含む収支) |
| r1 → r3 | 雛形 r。単一粒径と、等粒径で交換層 0.6・0.3・0.1、下層 0.1・0.3・0.6、交換層厚 5 cm。崩壊域の土層の全層(1 m)を流動化 | 流動化した柱の組成 {L_a A + (D − L_a) B}/D = 0.125・0.3・0.575 が、流れと積もった河床のどこでも保たれる(< 1e-11)。r1 との地盤高の差は緩い許容(1 cm)で比べる |
| rp3 | r3 の崩壊深を 0.5 m(土層の上半分)にして 1 ステップ | 崩壊域の柱が (1 − λ){L_a A + (D − L_a) B} = 0.045・0.09・0.165 m、残った土層の交換層と下層の組成が B |
| film3 | 雛形 r。崩壊域の土層を倍精度の下限に近い厚さ(4.6e-308 m)の膜にし、その上半分を流動化して 1 ステップ。等粒径、交換層 0.4・0.3・0.3、下層 0.3・0.3・0.4 | 交換層・下層の組成が全セルで有効なまま(0 以上、和が 1)。最適化のビルドは正規化数より小さい値を 0 にするので、膜の厚さと割合の積がすべて 0 に落ちる。割合がすべて 0 になると平均粒径が 0 になり、掃流砂の遮蔽係数が 0 除算になる(developer.md §139.7 の不具合の再発防止) |
| b3 | 雛形 b、等粒径、流入土砂の組成 `inflow_csfrac` = 0.2・0.3・0.5 | 流入の総量 = Q · cs · T = 27 m³、流入・流出・流れ・堆積の粒径階の比が与えた組成、粒径階ごとの収支が閉じる |
| bt3 | 雛形 b、粒度の幅、組成の時系列 `fn_inflow_csfrac`(0 s で 1・0・0、20 s から 0・0・1) | 粒径階ごとの流入が Q · cs · Σ f_k(t_n) Δt(各ステップの終わりの時刻の割合)に一致(< 1e-6 m³)、収支が閉じる |
| rt1 → rt2 | w3 を 24 s で分割 | state.dat・geomorph_bedmix.dat・swflow_enc.dat が w3 とバイト一致 |
| rt1 → alt2 | rt1 の保存(流れに土砂が残る)を、土石流のない混合粒径の構成に復元(`f_state_restore = 2`) | 流れの土砂の柱がその組成で河床に入る(河床の初期の在庫 = rt1 の河床 + 流れ)。保存から数えた粒径階ごとの総量が初期の総量のまま |
| rt1 → alt3 | alt2 に浮遊砂 `f_suspend = 1` | 粒径階 1 は浮遊砂として流れに残り、粒径階 2・3 が河床に入る。総量は同じ |
| bstop1 | 雛形 b、等粒径、流入土砂の組成なし | 初期化で止まる(流入土砂の組成は与件なので既定を置かない) |
| bstop2 | b3 から土石流を外した構成 | 初期化で止まる(組成は併用のときだけ意味を持つ) |
| selstop1 | w3(高橋型の侵食則)に `f_dbsel = 1` | 初期化で止まる(`f_dbsel` = 1・2 は `f_dbed = 3` が要る) |
| selstop2 | 単一粒径の高橋・中川則に `f_dbsel = 2` | 初期化で止まる(`f_dbsel` = 1・2 は混合粒径が要る) |

検定の数値は、たとえば e3 と e1 の地盤高の差 2e-15 m(地形の変化 2.9 mm)、u3 と u1 の差 4e-16 m、m3 と e1 の差
8.4e-6 m(地形の変化の 0.3 %)、w3・tk3・s3 の粒径階ごとの残差 2e-13 m³ 以下(s3 は延べ 6002 セルの流動化)、
r3 の組成の差 4e-15、r3 と r1 の地盤高の差 3e-5 m、rp3 の柱の差 7e-18 m、b3 の流入 27.000000 m³・流出
0.0865 m³、bt3 の流入 8.9910・0・18.0090 m³(式の値との差 1e-9 m³)程度。`f_dbsel` の構成は、sel3・sel3b の
動けない粒径階の量の差 6e-16 m、表層の割合の式との差 1e-13(sel3b は 760 セルで F_3 > 0.99、侵食深 14.000 mm。
sel3 は最大 0.966、13.3 mm)、selp1・selp2 の 1 ステップの侵食量の差 4e-17 m、selb1 と selb0 の地盤高の差
9e-121 m(判定が働いたのは 1855 回)程度。

r1 と r3 の許容が緩いのは、瞬時流動化の構成が、流れが止まる判定(降伏・低速凝集)をまたいで丸めの差を
広げるため。単一粒径の r1 そのものが、最適化のビルドと境界検査つきのビルドで 2 cm 違う。丸めの範囲の
一致は e1 → e3 と u1 → u3 で確かめる。

## 実行

```
make
./Run.sh            # 逐次。Check_dbmix.py + 初期化で止まる構成(bstop1・bstop2・selstop1・selstop2)+ リスタートの cmp
./Run_MPI.sh 2      # MPI(np=2)。逐次の save とのビット一致も確認
```

入力 z_slope.txt / z_out.txt / sd_rel.txt / sd_zero.txt / sd_slope.txt / sd_film.txt / dbinit.txt / dbinit_half.txt /
dbinit_film.txt / csfrac.txt と
構成の設定 p_<構成>.txt は make_init.py が生成する(追跡外)。
reference は持たず、合否は Check_dbmix.py の検定と、逐次・MPI・リスタートのバイト一致で決める。
