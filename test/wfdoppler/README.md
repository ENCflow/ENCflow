# test/wfdoppler — 流れによる沿岸の波浪場の変化の検定(fn_wavefield の f_wf_current。段 W3)

[English](en/README.md)

沿岸の波浪場([ユーザーガイドの章](../../docs/users_guide/wavefield.md)、developer.md §90)が
浅水流の流れで変わる段 W3(ドップラー効果の分散関係、流れによる屈折と移流、阻止)の
検定です。分散関係をここで独立に解いた作用量の流束の保存則と比べ、`param.txt` の結果は
reference の Log.txt・wavefield.csv・Wh9998.txt・u9998.txt とも比較します(ULP=0)。

## 構成

長さ 600 m・幅 40 m の水路(`make_z.py`。120 × 8 セル、Δx = Δy = 5 m)。河床は西端の −3 m から
東端の −1.5 m へ一様に上がり、流量 q = 1.2 m²/s の流れの流速は浅い東ほど速い。流れは端の列の
湧き出しから入り、反対の辺(長波放射)から出る。波は西の辺から入射し、南北の辺は波・流れとも
側方 Neumann(`wf_bc_side` = 2、`f_bc_n` = `f_bc_s` = 3)。河口の噴流は 300 m × 200 m
(120 × 80 セル、Δx = 2.5 m。test/wave_river と同型の河道)。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本(阻止) | `param.txt` | 逆流(東の湧き出しから西へ。0.38 → 0.69 m/s)に不規則波 H_m0 = 0.05 m、T = 1.5 s(単一方向)。x ≈ 470 m で分散関係の根がなくなる(阻止)。1 時間。再開の通し計算を兼ねる(save_all) |
| 逆流 | `param_opp.txt` | 同じ逆流に規則波 H = 0.05 m、T = 4 s(阻止されず、砕けない) |

## 検定(Check_wfdoppler.py)

検定はモデルの水位・流速の出力から、ビンの向き θ = 0 の分散関係 (ω − kU)² = g k tanh(kh) を
U → 0 で連続な枝で独立に解き(Newton 法。倍精度)、作用量の流束 (c_g + U)E/σ が保存される
定常解と比べます。

- **逆流**(opp): 作用量の流束がセル 1〜115 で相対 1e-5 以内(湧き出しの列の近くは除く)。
  入射のセルが沖のエネルギーを持つ。岸沿いに一様。
- **順流**(fol・fol72): 作用量の流束がセル 3〜117 で相対 2e-4 以内。順流では湧き出しの列が
  入射の列と重なり、流速が 1 セルで倍になる(湧き出しのセルの u は面の平均で半分)。この
  強い勾配による流れの屈折(発散)で、単一方向の波の約 3% が隣のビン(±Δθ)へ広がる
  (方向空間の 1 次風上では θ = 0 が極値なので、制限つき 2 次の補正が働かない。ビン幅に一様に
  広がった波としての表現)。広がった分は x 向きの輸送が遅く、下流で水深による屈折が θ = 0 へ
  戻すので、全エネルギーは 1 次元の理論から Δθ² に比例してずれる。fol72 はこのずれが方向
  ビンの幅の 2 乗で小さくなること(比が (72/40)² = 3.24 の 8 割以上)を確かめる。
- **非定常**(unst): 40 分後に準定常の解(param_opp)と波高が相対 1e-6 以内で一致し、作用量 × ω の
  累積の台帳が流れの立ち上がりの間も全行で流入の 1e-9 以内で閉じる(状態が作用量 = 時間変化
  する流れの中の断熱不変量なので、σ が変わっても台帳の外で増減しない)。
- **阻止**(blk): 阻止(分散関係の枝の根がない、または c_g + U ≤ 0)の始まるセルで波高が落ち、
  その先の波高が H_m0 の 6% 以下。砕波が無視できる区間(セル 1〜63)で作用量の流束の保存が
  3e-3 以内(阻止の点の近くで向きを変えて入射セルへ戻る分を含む。入射セルのエネルギーの増え
  ≤ 5e-3)。逆流で急峻になった波の砕波が大半を除き(砕波 > 阻止)、阻止の点に届いた作用量は
  台帳の「阻止」(blocked_W)に記録され、台帳(作用量 × ω)が閉じる。
- **流れの作用の有無**(nocur・zero): 流れの作用がなければ阻止の点より先に波が届く。流れが 0 なら
  `f_wf_current = 1` の解は段 W1 の経路と出力の精度で一致する。
- **河口の噴流**(river): 流れの作用なしでは波が河道を遡り(H ≥ 0.2 H_m0)、作用ありでは遡らない
  (H ≤ 0.02 H_m0。fn_wave の wave_vmax のような打ち切りなしで、分散関係の阻止として)。噴流の
  上で波が急峻になって集まり(流れの作用なしより波高が大きい)、台帳に阻止が記録される。
- **再開**(Run.sh): 分割した計算の state.dat・swflow_enc.dat・wavefield.dat と最終分布が通し
  計算とバイト一致(阻止の累積を含む)。
- **不正な設定**(Run.sh): `f_wf_current = 2` が理由を表示して停止する。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 検定(1 スレッドで約 9 分。阻止の収束が遅い基本と再開が半分ほど)
./Run_MPI.sh 4    # MPI(np <= 4)。reference と ULP=0、河口の噴流は np = 1 とバイト一致、再開も MPI で
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1.6、Ubuntu 24.04)

逆流は U = −0.375 → −0.674 m/s で σ/ω = 1.086 → 1.222、作用量の流束の保存からの最大の相対差は
2.8e-7(セル 1〜115)、セル 115 のエネルギーは流れの作用なしの浅水変形の値の 1.351 倍。順流は
U = 0.365 → 0.655 m/s で σ/ω = 0.932 → 0.859、最大の相対差 1.05e-4(セル 117)、方向ビン 72 では
3.2e-5(比 3.28。(72/40)² = 3.24)、エネルギーは流れの作用なしの値の 0.846 倍。阻止はセル 94
(x = 467.5 m)で始まり、波高もセル 94 で落ち、その先の波高は 0.0026 m 以下。砕波の手前
(セル 1〜63)の作用量の流束の保存は 2.3e-3、入射セルのエネルギーの増えは 2.3e-3。台帳は流入
30.11 W・流出 1.94 W・砕波 27.24 W・阻止 0.93 W で、残差は流入の 6e-10。非定常は 40 分後に
準定常の解と 7.3e-8 で一致し、累積の台帳は 40 行すべてで流入の 3.8e-15 以内。流れの作用なし
では阻止の点の先(x = 553 m)の波高 0.0496 m(作用ありは 0.0021 m)。流れが 0 なら W1 の経路と
波高が出力の精度で一致。河口の噴流は、流れの作用なしで河道(x = 20〜80 m)の波高 0.0617 m、
作用ありで 0.0000 m、噴流の上の波高 0.370 m(作用なし 0.200 m)、台帳の阻止 119 W。再開の
継続は通し計算とバイト一致。`-Og -fcheck=all` で逐次と np = 2 が一致(範囲外アクセスなし)、
release で np = 1・2・4 が逐次 reference に ULP=0、河口の噴流は np = 1 とバイト一致、再開の
継続も MPI で一致。
