# test/bankhalo — 堤防の越流の追い越し上限が帯の境で読む実効平面積率 af(MPI)

[English](en/README.md)

堤防の越流の追い越し上限(`cap_overshoot`。developer.md §68.29 (C'))が、MPI の帯の境で古い実効平面積率
`s%af` を読んでいた実バグ(developer.md §128)の検定です。reference を持たない検定型で、合否は `Run.sh`・
`Run_MPI.sh` の終了コードで決まります。

## 何を確かめるか

実効平面積率 af = gv × wfrac × v(h)/h(家屋の空隙率 × 河道幅の平面積率 × σ 断面の湿潤率)は、河道幅・σ 断面・
空隙率の変化のどれかが有効なときに毎ステップ更新されます。堤防の越流の追い越し上限は、深く潜った越流の流量が
水位差を 1 ステップで追い越さないよう、堤防エッジの両側のセルの af で水位の応答を換算します。帯の境では隣のセルが
ハロの行にあるので、ハロの af が持ち主の値にそろっていないと、2 ランク以上の結果が 1 ランクと一致しません。

## 構成

| 項目 | 値 |
|---|---|
| 領域・格子 | 20 × 16 セル(Δx = Δy = 10 m)の閉じた箱。np = 4 でもランクあたり 4 行 |
| 河道 | 列 i = 10 が南北に通る(河床 −1 m、サブグリッド幅 4 m = 平面積率 0.4、粗度 0.03)。両岸の地盤は 0 m |
| 堤防 | 河道セルの天端 0.5 m(堤内地の地盤 + 0.5 m) |
| 初期の水位 | 西岸 1.50 m、東岸 1.45 m、河道 1.475 m(堤防は深く潜っている) |
| 時間 | dt = 0.5 s、10 分 |

| 設定 | 内容 |
|---|---|
| `param.txt` | 河道幅だけ(af = gv × 0.4) |
| `param_sect.txt` | 河道幅 + 河道断面形 σ(h) = (h/D)^0.5(D = 天端 − 河床 = 1.5 m) |

帯の境は河道を横切るので、斜めの堤防エッジの隣のセルがハロの行に入ります。

| ファイル | 内容 |
|---|---|
| `Run.sh` | 逐次で 2 構成を回し、`Check_bankhalo.py` で検定 |
| `Run_MPI.sh [N]` | N ランク(既定 2。N ≤ 8)と 1 ランク(同じ実行ファイル)で回し、Log.txt・水位 E0001・水深 H0001 をバイト比較。`Check_bankhalo.py` も |
| `Check_bankhalo.py` | 閉じた箱の水の量 S が保たれること(最初と最後が相対 10⁻¹² で一致)と、両岸の水位差が 0.05 m から半分未満に縮まり、東岸の水位が 5 mm 以上上がること |
| `make_bankhalo.py` | 入力(地盤・河道マスク・河道幅・初期の水位)を作る |

## 結果(2026-11-24。gfortran 13.3・-Ofast)

| 実行ファイル | np = 2・4 と 1 ランクの比較 |
|---|---|
| 修正前 | 両方の構成で一致しない(水位の差は最大 1×10⁻⁴ m、流速の最大 0.044 m/s と 0.058 m/s。水の量 S は一致) |
| 修正後 | 両方の構成でバイト一致 |

-Og -fcheck=all でも検定は合格し、np = 2 は逐次とビット一致しました。両岸の水位差は 10 分で 0.05 m から
0.000 m(出力の 4 桁)に縮まります。

## このケースで確かめていないこと

- 家屋破壊の空隙率の帰還(`m_bldgdebris`)が変えた af のハロの交換(同じ型の修正だが検定はない)。
- 越流の追い越し上限そのものの精度(§68.29 の検定の対象)。
