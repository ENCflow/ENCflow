# test/fixation — 定着(f_fixation)の検定

低水で露出した砂州に定着が進み、出水時の再侵食に抵抗する過程
(developer.md §84.6、docs/meander_plan.md §3.4)の検定。

## 設定

幅 10 セルの直線水路(Δx = 1 m、勾配 0.002、両岸は +2 m の乾いた河岸)の
南側 3 行を +0.1 m の砂州にする(make_init.py)。西端の区間流入は
0〜10 分 Q = 0.1 m³/s(低水。砂州は乾く)、11 分から 1.7 m³/s(出水。砂州は
水没して掃流される)。東辺は自由流出。土層厚は両端を 0(非侵食)にして
ランプでつなぎ、検定は中央区間(列 26〜49)だけを見る。d50 = 2 mm、
T_fix = 0.1 h = 360 s、morfac = 1。

| 構成 | 設定 | 役割 |
|---|---|---|
| off | f_fixation = 0 | 基準(砂州は出水で削られる) |
| on | c_τ = 100、dz_reset = 0.1 m | 定着した砂州は出水でも削られない |
| weak | c_τ = 0.5、dz_reset = 0.002 m | 削られて定着がリセットされる |
| rt1 → rt2 | on を 600 s で分割し save_rt から復元 | リスタート往復 |

## 検定項目(Check_fixation.py)

1. 成長則: 低水期を通して乾いた砂州・河岸セルの a(600 s) = 1 − exp(−600/360)
   (rt1 の保存値 geomorph_fixation.dat で 1e-9、テキスト出力 Fx で印字精度 1e-4)。
2. 常に湿潤な河道セルの a は厳密に 0。
3. 効果: on の砂州は出水で全セル Δz ≥ 0(定着セルからの流出はゼロ)、off の
   砂州は 10 セル以上が Δz < −5 mm。
4. リセット: weak の砂州で a = 0 に戻ったセルが 1 以上、終了時の全セルで
   zref − z ≤ dz_reset(リセットの不変条件)。
5. 0 ≤ a ≤ 1。
6. 無効時の痕跡なし(result_off に Fx 出力がなく、save_off に私有ファイルがない)。

Run.sh はさらにリスタート分割継続(rt1 → rt2)の state.dat と
geomorph_fixation.dat が通し実行(on)とビット一致することを確認する。
Run_MPI.sh は同じ検定を MPI で行い、save_*_serial とのビット一致を見る
(厳密フラグ -O2 -ffp-contract=off で逐次・MPI を作って比較する。-Ofast では
最終桁が揺れる。§28.3)。

## 使い方

```
make
./Run.sh            # 逐次
./Run_MPI.sh 2      # MPI(2 ランク)
```
