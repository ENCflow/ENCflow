# test/fluxline — 流量測線の角度掃引(一様流の解析値との突合)

[English](en/README.md)

計測(`fn_record`)のフラックス測線が、いろいろな角度で正しい流量を読むかの
検定です(developer.md §24.3)。東西に長い直線水路に定常の等流を流し、同じ
流れをセル番号指定(`flxytype = 0`)と実座標指定(`flxytype = 1`)の測線で
測ります。reference は持たず、合否は `Check_fluxline.py` で決めます。

## 構成

| 項目 | 値 |
|---|---|
| 水路 | 500 × 21 セル(Δx = 1 m)、勾配 0.002、n = 0.03。南北の縁は領域の壁(`make_init.py` が書く) |
| 流れ | 西の辺の全幅から Q = 9.860442 m³/s(Manning の等流水深 0.5 m の単位幅流量 × 21 m)、東の辺は自由流出。初期水深 0.5 m |
| 時間 | dt = 0.2 s、2400 s(測線の CSV は 300 s ごと) |
| 構成 1 | `param_stair.txt`: セル番号指定の測線 25 本(`record_stair.txt`) |
| 構成 2 | `param_xy.txt`: 実座標指定の測線 23 本(`record_xy.txt`) |

測線の角度 φ は、流れに直交する向き(南北)からの傾きです。0〜85° を並べ、
種類は次の 3 つです。

- 壁から壁まで横切る測線(全幅)
- 内部の行だけを横切る測線(セル番号指定は行 6〜16、実座標指定は y = 5.3〜15.8 m)
- 流れに平行な測線

## 検定(Check_fluxline.py)

単位幅流量 q は、測線が通るセルの h·|V| の平均です(流れは東向き)。

| 測線 | 実座標指定(`xy`) | セル番号指定(`stair`) |
|---|---|---|
| 壁から壁 | 全角度で Q(差 5e-4 m³/s 以下) | 45° 未満(行方向に進む)は Q。45° 以上(列方向に進む)は Q − q_end(q_end は北端の踏面セルの h·\|V\|。比 1 ± 0.01) |
| 内部 | F·n̂·L = q × 南北の長さ(比 1 ± 2e-4) | 45° 未満は q (n − δ)(n は踏面の数。δ は 0.55〜0.62 で角度・長さによらない)、45° 以上は q × 中心間の行差(比 1 ± 0.005) |
| 平行 | 0 | 0 |

壁から壁の測線は、最後の 2 行(2100 s・2400 s)の値が変わらないこと(定常)も
確かめます。

実座標指定は、一様な流量ベクトルに対して任意の位置・傾き・長さで厳密です
(§36.2)。セル番号指定(ENC)は階段面を横切るエッジ流量の和で、壁から壁まで
行方向に進む測線は保存則から Q に一致します。端の扱いには次の 2 つの規約が
あります。

- 列方向に進む測線は、長手(列方向)にだけ両端で半セル延長されます
  (§24 (2b))。壁から壁まで引いても、両端の行の半セルずつ(合わせて壁沿いの
  1 行分)が面に入りません。
- 端が流れの中にあると、端の角を通る斜めのエッジ(各端 2 本)を数えません。
  一様な流れでは各斜めエッジが行の流量の d/2(d = 2/(2+√2))を運ぶので、
  δ ≈ d = 0.586 行分少なく読みます。

どちらも、測線の端を水のないセルに置けば効きません(扱いは検討中。
developer.md §24.3)。

| ファイル | 内容 |
|---|---|
| `make_init.py` | 地形・初期水深・測線(record_stair.txt・record_xy.txt)を書く。Run.sh・Run_MPI.sh が頭で呼ぶ |
| `Run.sh` | 2 構成を逐次で回して検定(各 30〜40 秒)。結果を result_*_serial/ に複製する |
| `Run_MPI.sh N` | 同じ検定を N ランクで回し、逐次の結果と測線の CSV・最終の水深と流速の分布をバイト比較する(21 行なので N ≤ 10) |
| `Check_fluxline.py` | 上の検定。`stair` / `xy` |

## 実行

```bash
make
./Run.sh
./Run_MPI.sh 4
```

## 所見

| 測線 | 実座標指定 | セル番号指定 |
|---|---|---|
| 壁から壁 0〜40° | Q(比 0.999996) | Q(9.8604) |
| 壁から壁 45〜85° | Q(比 0.999996〜1.000006) | Q − q_end(9.3911。比 1.0000〜1.0003) |
| 内部 0〜40° | F·n̂·L(比 0.99999〜1.00001) | q (n − δ)、δ = 0.5851〜0.5854 |
| 内部 45〜85° | F·n̂·L(比 0.99999〜1.00004) | q \|Δj\|(比 1.00002〜1.00008) |
| 平行 | 0.0000 | 0.0000 |

- 壁から壁の測線の値は 2100 s と 2400 s で変わりません(定常)。
- 内部の δ は d = 0.5858 より 0.1 % 小さく、長さ(n = 7・11・15)と角度によりません。
- MPI は np = 1, 2, 4 とも、測線の CSV と最終の分布が逐次とバイト一致します
  (どの測線もランク境界をまたぐ)。
