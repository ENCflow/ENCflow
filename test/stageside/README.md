# test/stageside — 境界として与えたセルの列から流れ出す水と、側方 Neumann の辺

[English](en/README.md)

水位規定セル(規定水位に強制するセル。`&list_bound_stage`)の列や、流量を湧き出しで与えるセル
(`&list_bound_source`)の列が、側方 Neumann の辺(`f_bc_n = 3` など)に接する配置の検定です。移流項の規則のうち、
深くて遅い隣のセルの扱いの 4 つの値の組み合わせ(`f_advection_donor = 4`・`f_advection_bend = 2`・
`f_advection_lateral = 2`・`f_dry_head_cap = 4`。[移流項のスキーム](../../docs/users_guide/advection.md) §4.4)は、
これらの「境界として与えたセル」から出る水に、静止からの加速を数えません。この扱いが、古い値の組み合わせと
同じ結果になることと、領域の枠の中の面と、側方 Neumann の境界面とで同じになっていることを確かめます
(developer.md §113.9)。

- **古い値の組み合わせ(3・1・1・3)でも、4 つの値の組み合わせでも、最後まで計算して定常になり、岸沿いに
  一様です。**
- **2 つの組み合わせの結果は一致します**(水深・流速の差が 1e-6 以下)。流れがゆるやかに変わるだけの
  水路では、4 つの値の規則は古い値と同じ値になります。
- 水位規定セルの列から流れ出す水のエネルギー水頭は、規定水位より速度水頭の分(0.021 m)だけ高くなります。
  どちらの組み合わせでも同じで、水位規定セルを静止した池の代わりに使うときの限界です。

## 設定

長さ 600 m・幅 40 m(120 × 8 セル、Δx = 5 m)の水路。河床は西端の −3 m から東端の −1.5 m へ一様に上がります
(`make_stageside.py`。[test/wfdoppler](../wfdoppler/README.md) の水路と同じ形)。マニングの粗度係数は 0.02、
dt = 0.5 s。

| 辺・セル | 条件 |
|---|---|
| 東端の 1 列(8 セル) | 水位規定セル(規定水位 +0.2 m)、または湧き出し(48 m³/s = 単位幅 1.2 m²/s。10 分で立ち上げて一定) |
| 東の辺 | 壁(東端の列の背) |
| 西の辺 | 長波放射(基準水位 0) |
| 南北の辺 | 側方 Neumann(岸沿いに一様) |

静水(水位 0)から始めて 60 分計算します。東端の列から西へ水が流れ、20 分までに定常になります。

| 構成 | 東端の列 | 移流項の規則(`f_advection_donor`・`f_advection_bend`・`f_advection_lateral`・`f_dry_head_cap`) |
|---|---|---|
| `s3` | 水位規定セル | 古い値の組み合わせ(3・1・1・3) |
| `s4` | 水位規定セル | 4 つの値の組み合わせ(4・2・2・4) |
| `q3` | 湧き出し | 古い値の組み合わせ(3・1・1・3) |
| `q4` | 湧き出し | 4 つの値の組み合わせ(4・2・2・4) |

格子は 8 行なので、MPI の np = 2 では、北の辺(行 1)と南の辺(行 8)を別のランクが持ちます。

## 検定項目(Check_stageside.py)

4 つの構成のそれぞれで判定する項目:

1. 最後まで計算する(発散して止まらない)。
2. 定常: 40 分と 60 分の流速の差の最大が 1e-5 m/s 未満。
3. 岸沿いに一様: 列 6〜120 で、行の間の流速・水深の差の最大と、岸沿いの流速の大きさの最大が、1e-6 未満
   (m/s・m)。西の辺のすぐ内側(列 1〜5)は、長波放射の辺と側方 Neumann の辺の角の影響で、岸沿いの流速が
   1e-5 m/s あるので、外します。

規則の違う 2 つの構成を比べて判定する項目(`s4` と `s3`、`q4` と `q3`):

4. 4 つの値の構成の水深・流速が、古い値の構成と一致する(差の最大が 1e-5 未満。m・m/s)。

基準は、今の値(下の表)に余裕を見た回帰の上限で、理論から出した値ではありません。出力は、バイナリ
(単精度)を読みます。

## 何が起きているか

4 つの値の組み合わせの `f_advection_bend = 2` は、流入のないセルから出る水に、静止からの加速を数えます
(エネルギー水頭を保存する形の移流項)。水位規定セルと、流量を湧き出しで与えるセルは、領域の外から流れてきた
水が入ってくる所として使うことが多いので、数えません(海セル・区間流入の面と同じ扱い)。
`f_advection_lateral = 2` も、流入元がこれらのセルのときは、流量の似かよりで下げません。

湧き出しのセルに静止からの加速を数えると、`q4` の湧き出しの列が、流出の速度水頭の分(0.015 m)だけ `q3` より
深くなります(項目 4)。

この「境界として与えたセルかどうか」の印は、側方 Neumann の辺の外の位置では、鏡像のセル(辺の法線方向に
枠内へ寄せたセル)の印を読みます。読まずに「与えたセルではない」と扱うと、与えたセルの列が側方 Neumann の
辺に接する角で、枠の中の面は「数えない」、境界面は「数える」になります。この食い違いから、角の行に岸沿いの
流れができ、`s4` は、流速が増え続けて 13 分で止まります(項目 1)。

水位規定セルや湧き出しを、静止した池の代わりに使うと、流れ出す水は、静止からの加速を数えないまま、
水面勾配と摩擦のつり合いの流速になります。このため、水位規定セルでは、流れ出した水のエネルギー水頭が、
規定水位より速度水頭の分だけ高くなります(上の値)。古い値の組み合わせでも同じです。池から流れ出す水の
加速を数えたいときは、池を、水位規定セルや湧き出しではなく、計算する水域として領域に含めます。
