# test/wfshadow — 沿岸の波浪場の 2 次元の検定(fn_wavefield)

[English](en/README.md)

沿岸の波浪場([ユーザーガイドの章](../../docs/users_guide/wavefield.md)、developer.md §88)の
2 次元の検定です。防波堤の陰、角だけで接する斜めの壁の遮断、格子の外の仮想の送り手
(入射・側方 Neumann・吸収と角の優先)を、`Check_wfshadow.py` で独立に実装した離散解と
比べます。`param.txt` の結果は reference の Log.txt・wavefield.csv・Wh0001.txt とも
比較します(ULP=0)。

## 構成

100 × 100 セル(Δx = Δy = 10 m)、水深 10 m で一様(`make_z.py`)。陸(+3 m)は

- 防波堤: 行 60・列 1..50(西の辺から延びる 1 セル厚の堤)
- 菱形: |i − 75| + |j − 30| = 8 のセル(角だけで接する 1 セル厚の斜めの壁が水域を囲む)

南の辺から北向き(90°)の波を入れます。東西の辺は側方 Neumann、北は吸収。一様水深なので
屈折はなく、砕波・摩擦も効きません(H_rms/h = 0.07)。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本 | `param.txt` | 不規則波 H_m0 = 1 m、T = 8 s、方向分散 20°。wf_tol = 1e-6 |
| 格子方向の単一方向 | `param_aligned.txt` | 同じ地形で北向きの単一方向(方向分散 0、ビン 11 = 90° の中心) |

## 検定(Check_wfshadow.py)

- **独立に実装した離散解との一致**(base): 離散の定常方程式
  c_g(q_a + q_b) E_ij = Σ q_l c_g E_送り手 を、送り手が先に決まる順(伝播の上流から)の
  掃引で直接解きます(反復なし。一様水深なので c_g は打ち消す)。2 リンク分解、格子の外の
  仮想の送り手(入射・Neumann・吸収と角の優先)、閉じた対角の規則は m_wavefield と同じ規則を
  本スクリプトで書き直したものです。沖の波のビン別エネルギーも cos^s 分布と Kuik ら(1988)の
  方向分散の定義から独立に組み立てます。全波浪セルで波高の差が 2e-4 m 未満。
- **斜めの壁の遮断**(base): 菱形の内側の 113 セルで波高が厳密に 0(対角リンクの両脇が
  ともに陸なら閉じる規則。水の ENC とは違う)。
- **格子方向に揃った波**(aligned): 2 リンク分解は軸の向きの伝播で横断の数値拡散がないので、
  防波堤と菱形の幾何学的な陰の中は H = 0、それ以外は H = H_0 = 1 m が厳密に成り立つ。
- **幾何光学解との差**(base。表示のみ): ビンごとに直進する見通しの解との差は、陰の縁での
  横断の数値拡散の大きさの目安です(判定には使いません。上の掃引解との一致で実装の正しさを
  確かめ、この差はスキームの性質として記録します)。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 検定(約 8 秒)
./Run_MPI.sh 4    # MPI。reference と ULP=0(陰・壁・側方 Neumann の辺がランク境界をまたぐ)
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1.6、Ubuntu 24.04)

掃引解との差は最大 2.8e-5 m(側方 Neumann の西の列。収束の遅い列で、wf_tol = 1e-6 の
反復 367 回)、菱形の内側 113 セルはすべて厳密に 0、格子方向に揃った波は陰の外 6426 セルで
H = 1 m(差 0)・陰の中 3492 セルで 0。防波堤の背後(行 20〜58)の幾何光学解との差は
最大 0.18 m・rms 0.037 m(陰の縁の数値拡散)。`-Og -fcheck=all` で逐次と np = 2・4 が一致、
release で np = 1・2・4 が逐次 reference に ULP=0。
