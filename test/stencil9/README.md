# test/stencil9 — 9 点のクリープ・乾式斜面侵食の曲率の等方性と壁際の振り替え

[English](en/README.md)

斜面クリープ(`&list_geomorph` の `f_creep`)と乾式斜面侵食の曲率 κ(`f_splash`)は、
斜め配分 d(`creep_diagratio`・`spl_diagratio`。既定 1/3)の 8 近傍の 9 点で解きます。
d = 1/3 で離散化誤差の主要項が等方になります。d = 0 の 4 近傍の 5 点ラプラシアン
(2026-11-05 より前の既定)は、格子幅に近い短い波長で格子の向きに偏ります(同じ波数で
45° と 0° の減衰率の差が波長 8Δ で +2.6 %、4Δ で +11 %)(developer.md §96、
[ユーザーガイドの土砂・地形変化の解説](../../docs/users_guide/sediment.md) §2・§6)。このケースは、
その等方性・重みの正規化・壁際の振り替えを、解析解・厳密な離散解・格子の向きの差で
検定する自己検証テストです(reference は持ちません)。

## 構成

| 構成 | ファイル | 内容 | 検定(Check_stencil9.py) |
|---|---|---|---|
| gauss | `param_gauss_c9.txt` | test/creep と同じよく解像したガウス丘(σ = 10Δ、101 × 101)を d = 1/3 で 50 s | 全セルが解析解に 5e-3 m 以内(重みの正規化) |
| hill | `param_hill_c5.txt`・`param_hill_c9.txt` | 解像しきれない丘(σ = 2Δ、81 × 81、`z_hill2.txt`)を d = 0(対照)と 1/3 で 4 s | 中心から同じ距離の格子軸寄りと斜めのセル(r² = 25: (5,0)・(4,3)、r² = 50: (7,1)・(5,5))の差が、d = 1/3 で 0.3 % 未満、d = 0 で 1 % 超(検出器として働く) |
| strip | `param_strip1_c9.txt`・`param_strip3_c9.txt` | 幅 1・3 セル、長さ 40 m の帯(四周は壁)の z = cos(π(j − 0.5)/40) を d = 1/3 で 100 s | 全セルの振幅が、壁で塞がれた斜めの配分を軸エッジへ振り替えたときの厳密な離散解 (1 − λΔt)^N に相対 1e-9 以内(振り替えがなければ実効の拡散係数が 1 − d・(2(1 − d/2) + 1)/3 倍になる) |
| splash | `param_hill_s5.txt`・`param_hill_s9.txt`・`param_hill_lc_s5.txt`・`param_hill_lc_s9.txt` | 同じ丘に降雨を 1 ステップ与え、雨滴項 E = P k_r (1 + c_a κ) だけで 1 回更新(リル項なし)。ℓ = 0 と 2 m(`spl_lc`)、d = 0(対照)と 1/3 | 平坦なセルとの侵食深の比から κ を読み、同じ距離のセルの差が d = 1/3 で 0.5 % 未満、d = 0 で 2 % 超(r² = 25) |

丘・帯・係数は `make_terrain.py`・`param_*.txt`・`Check_stencil9.py` で対になっています。
z は終了時の save(倍精度)から読みます。

## 実行

```bash
make              # リンクと z_*.txt(make_terrain.py)
./Run.sh          # 9 構成を実行し Check_stencil9.py で検定(数秒)
./Run_MPI.sh 4    # Run.sh の後に。MPI の state.dat を逐次の save_*_serial とバイト比較
```

## 結果(gfortran 13.3、make.inc の既定の release ビルド、2026-11-05)

| 量 | 5 点(d = 0) | 9 点(d = 1/3) |
|---|---:|---:|
| クリープ: 同じ距離の格子軸寄りと斜めのセルの差(r² = 25 / 50) | −0.49 % / −1.92 % | −0.01 % / −0.03 % |
| 曲率(ℓ = 0): 同(r² = 25 / 50) | −8.42 % / −14.71 % | −0.27 % / +0.26 % |
| 曲率(ℓ = 2 m): 同(r² = 25 / 50) | +3.27 % / −0.17 % | +0.13 % / −0.03 % |
| 帯の減衰の厳密な離散解との差(幅 1 / 3) | — | 6e-15 / 1e-14 |
| よく解像した丘の解析解との最大差(全セル) | 7.6e-4 m | 7.5e-4 m |

- 9 点は格子の向きの偏りをほぼ消します。等方になるのは誤差の向きで、大きさではありません。
  よく解像した丘の全セルの最大差は 5 点と同じで(壁の近くの裾の差が支配する)、丘の中心では
  9 点の方が大きく出ます(+1.7e-4 m 対 +6.3e-5 m。空間と時間の離散化誤差の打ち消しの程度の違い)。
- 帯の減衰は 1 次元の厳密な離散解に丸めの誤差で一致し、壁際でも拡散係数が内部と同じに
  なっていることを示します。
- `-Og -fcheck=all` の MPI np = 2 で 9 構成とも実行時エラーなく完走し、検定に合格。release の
  MPI np = 1・2・4 の state.dat は 9 構成とも逐次とバイト一致。
