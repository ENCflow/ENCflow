# test/wfcurrent — 沿岸の波浪場の流れへの作用の検定(fn_wavefield の wf_flow。段 W2)

[English](en/README.md)

沿岸の波浪場([ユーザーガイドの章](../../docs/users_guide/wavefield.md)、developer.md §90)が
浅水流に作用する段 W2(放射応力の外力・ローラー・GLM の Stokes 輸送・波・流れの底面摩擦・
側方 Neumann の流れの境界)の検定です。流れの波への作用(段 W3。`f_wf_current`)を加えた
双方向の連成も確かめます(`param_cur.txt`)。理論解・閉じた形の釣り合い・保存則と比べ、
`param.txt` の結果は reference の Log.txt・E9998.txt・v9998.txt とも
比較します(印字の最終桁 1 つ分か相対 1e-6 まで。reference を作ったマシンと CPU が違うと
-march=native のベクトル化の差で最終桁がずれるため。developer.md §90.18。同じマシンでは
`ULP=0 RTOL=0 FILES="Log.txt wavefield.csv E9998.txt v9998.txt" ./Run.sh` でビット比較できます)。

## 構成

勾配 1/80 の海浜(`make_z.py`。test/wfshoal と同じ断面、120 × 8 セル、Δx = Δy = 10 m)。
西(i = 1)が沖で入射、x = 1100 m が汀線。南北の辺は波・流れとも側方 Neumann
(`wf_bc_side` = 2、`f_bc_n` = `f_bc_s` = 3)、沖の流れの辺は長波放射。

| 構成 | ファイル | 内容 |
|---|---|---|
| 基本 | `param.txt` | 不規則波 H_m0 = 1 m、T = 8 s、進行方向 20°、方向分散 20°。`wf_flow = 2`、ローラーあり(既定)。1 時間。再開の通し計算を兼ねる(save_all) |
| ローラーなし | `param_long.txt` | 基本と同じでローラーなし |
| セットアップ | `param_setup.txt` | 規則波 H = 1 m、T = 8 s、直角入射。`wf_flow = 1`(外力だけ)。始動の副振動を減衰させるため摩擦の流速の下限 vv = 0.2 m/s |
| 一様水深 | `param_flat.txt` | 水深 5 m の平坦な海底、東は壁。不規則波 H_m0 = 1.5 m・進行方向 30°・底面摩擦 f_w = 0.05 の散逸だけで沿岸方向の外力をつくる。`wf_flow = 2`、ローラーなし。粗度 n = 0.05(立ち上がりの時定数を約 10 分に) |
| 90° 回した格子 | `param_rot.txt` | 基本を時計回りに 90° 回した格子(8 × 120。北が沖、東西が側方 Neumann) |
| 双方向の連成 | `param_cur.txt` | 基本に流れの波への作用(`f_wf_current = 1`。段 W3)を加える。沿岸流が波を変え(ドップラー・流れによる屈折と輸送)、その波が沿岸流を起こす |
| 拡散項 | `param_diff.txt` | 基本に定数の渦動粘性 ν = 0.5 m²/s の拡散項(`f_diffusion_term = 1`)を加える。側方 Neumann の辺に接するセルと境界面の拡散を鏡像セルで求める(developer.md §90.12) |
| 拡散項の回した格子 | `param_rotdiff.txt` | 拡散項の構成を時計回りに 90° 回した格子(W・E の側方 Neumann の辺の拡散。MPI ではランク界面をまたぐ) |
| 砕波による水平混合 | `param_mix.txt` | 基本に砕波による水平混合(`&list_enc` の `wf_break_visc = 1`)を加える。渦動粘性 ν_w = M h (D_r/ρ)^{1/3}(Battjes 1975。XBeach の nuhfac と同じ形)を拡散項の ν に足す |
| 再開 | `param_rt1.txt` → `param_rt2.txt` | 基本を 90 s(立ち上げの途中、波浪場の更新の間)で保存し、復元して 3600 s まで |
| 不正な設定 | `param_bad.txt` | `wf_flow = 3`(停止すること) |

## 検定(Check_wfcurrent.py)

- **セットアップ**(setup): 静止の定常で、面ごとの離散の釣り合い
  g_e (η_{i+1} − η_i)/Δx = (F_i + F_{i+1})/(2ρ h_f)(h_f は両セルの平均水深、g_e は急勾配の
  重力補正)が残差 2% + 5e-6 m/s² 以内。砕波帯より沖の set-down が
  η = −H²k/(8 sinh 2kh)(Longuet-Higgins & Stewart 1962。沖の境界のセルとの差)と砕波点での
  set-down の 2% 以内、砕波帯の勾配 dη/dx = K dz/dx が Bowen ら(1968)の
  K = 1/(1 + 8/(3γ²)) = 0.186 の −8%〜+4%(有限水深と Miche 型の砕波波高で浅水の極限より
  わずかに小さい)。岸沿いに一様。
- **一様水深の沿岸流**(flat): 屈折がなく岸沿いに一様。セルごとの沿岸方向の運動量の
  釣り合い F_y/(ρh) = g n² |V_E| v_E / h^{4/3}(v_E = v − v_S、|V_E| = √(u_E² + v_E² +
  (1.16 u_rms)²))を v_E について閉じた形で解いた v = v_S + v_E と、モデルの v が流速の最大の
  2% 以内、岸沿いの運動量の積分の釣り合い Σ F_y = Σ τ_y が 2% 以内、流れは全セルで北向き。
  岸沖方向は面ごとに g Δη/Δx = F_x/(ρh) + 戻り流れ u^E = −u^S の摩擦が 1% 以内
  (戻り流れの摩擦がセットアップ勾配の約 23%)。GLM の Lagrangian 流速 u^L ≈ 0。
- **海浜の沿岸流**(long・roller): 岸沿いの運動量の積分 Σ F_y = Σ τ_y が 2% 以内、セルごとの
  閉じた形が流速の最大の 5% 以内(砕波の始まりの急な外力の変化を ENC の斜めの面と移流が
  ならす分)、沿岸流の最大が砕波帯の中、砕波帯より沖(砕波の散逸が最大の 0.1% 未満)の
  流れが最大の 1% 以内、側方 Neumann の辺を含む全行の差が最大の 1% 以内、u^L ≈ 0。
  ローラーありでは外力の最大が岸側へ 1 セル以上・沿岸流の重心が 3 m 以上ずれ、ローラーの
  エネルギーの収支(台帳の砕波 + 上限の除去 = Σ 2βgE_r/c + 汀線への流出)が 1% 以内で閉じ、
  ローラーのエネルギーは砕波帯の中だけ。
- **90° 回した格子**(rot): 基本の結果をセル (i, j) → (9 − j, i) へ写し、東向き u → 南向き v、
  y 成分(南が正)→ x 成分の符号反転で、回した格子の水位・流速・外力・Stokes 輸送・
  ローラーが一致(水位 1e-4 m、流速は最大の 1e-3)。W・E の側方 Neumann と y 方向の符号の
  規約の検定(演算の順序が違うので丸めの規模で一致)。
- **双方向の連成**(cur): 基本と同じ海浜の沿岸流の検定(セルごとの閉じた形が最大の 5% 以内、
  運動量の積分の釣り合いが 2% 以内、岸沿いの一様性、u^L ≈ 0)と、ローラーのエネルギーの
  収支が 1% 以内(ローラーは流れでも運ばれ、位相速度は固有の σ̄/k̄。台帳の砕波は作用量 × ω
  なので、砕波の分布で重みを付けた σ/ω を掛けてエネルギーにする)。流れの作用で波高が
  1e-4〜5% 変わり(作用が効いている)、波の台帳(作用量 × ω)が閉じる。
- **拡散項**(diff): 側方 Neumann の辺を含む全行の差が水位 1e-4 m・流速の最大の 1% 以内
  (辺のセルの拡散が欠けると流入側の辺から一様性が崩れて発散した)、岸沿いの運動量の
  積分 Σ F_y = Σ τ_y が 2% 以内(拡散は運動量を岸沖へ配り直すだけ。セルごとの閉じた形は
  成り立たない)、基本より沿岸流の最大が 1〜20% 下がり、分布の広がり(|v| を重みとする
  岸沖の位置の標準偏差)が 2% 以上増える。90° 回した格子(param_rotdiff)の結果が rot と同じ
  許容で一致する(W・E の辺の拡散)。
- **砕波による水平混合**(mix): 出力の渦動粘性 Wnu が、出力のローラーのエネルギー E_r と水深から
  組み立てた ν_w = M h (D_r/ρ)^{1/3}(D_r = 2βgE_r/c、c は代表周期の位相速度)と最大の 1e-4 以内で
  一致し、最大は砕波帯の中(砕波の散逸が最大の 50% 以上のセル)。拡散項の検定(diff)と同じく、
  岸沿いの一様性(Wnu も)、運動量の積分の釣り合いが 2% 以内、沿岸流の最大が 1〜30% 下がり分布の
  広がりが 2% 以上増える。
- **再開**(Run.sh): 分割した計算の state.dat・swflow_enc.dat・wavefield.dat と最終分布が
  通し計算とバイト一致(外力の立ち上げ・準定常の外力の保持・ローラーの状態の継続)。
- **不正な設定**(Run.sh): `wf_flow = 3` が理由を表示して停止する。

## 実行

```bash
make
./Run.sh          # 逐次 + reference 比較 + 検定(1 スレッドで約 2 分)
./Run_MPI.sh 4    # MPI(np <= 4)。reference と ULP=1・RTOL=1e-6、90° 回した格子・双方向の連成・拡散項(とその回した格子)・水平混合は np = 1 とバイト一致、再開も MPI で
```

## 検証記録(2026-10-27。gfortran 13.3 / Open MPI 4.1.6、Ubuntu 24.04)

セットアップは面ごとの離散の釣り合いの残差が許容に対して 0.00(111 面)、砕波点の沖
(i = 94)の set-down がモデル −48.65 mm・Longuet-Higgins & Stewart −48.57 mm(砕波帯より
沖の最大差 0.078 mm)、砕波帯の勾配の K が 0.1766〜0.1834(12 セル。Bowen ら 0.1858)。
一様水深の沿岸流は最大 0.0555 m/s、セルごとの閉じた形との差が最大の 0.87%、運動量の
積分の比 Σ τ_y/Σ F_y = 0.986、岸沖の面ごとの釣り合いの残差 3.4e-4(戻り流れの摩擦が
セットアップ勾配の 23〜24%)、u^L の最大 6.8e-6 m/s。海浜の沿岸流はローラーなしで最大
0.224 m/s・閉じた形との差 3.2%・積分の比 1.000・行の差 7.1e-5 m/s(最大の 0.03%)、
ローラーありで最大 0.229 m/s・差 3.0%・比 0.998・行の差 5.4e-5 m/s(0.02%)、外力の最大が
1 セル・沿岸流の重心が 7.1 m 岸側へずれ、ローラーのエネルギーの収支の残差は 0.00%。
90° 回した格子は水位の差 1.0e-5 m、流速の差 6.0e-5 m/s(最大の 2.6e-4)。双方向の連成(段 W3)は
最大 0.229 m/s・閉じた形との差 2.99%・積分の比 0.998・行の差 3.5e-5 m/s、ローラーのエネルギーの
収支の残差 0.01%、流れの作用による波高の変化は最大 0.17%・沿岸流の最大の変化 −0.07%、波の
台帳(作用量 × ω)の残差は流入の 1.1e-7。再開の継続は通し計算とバイト一致。
`-Og -fcheck=all` で逐次と np = 2 が一致(範囲外アクセスなし)、release で np = 1・2・4 が
逐次 reference に ULP=0、90° 回した格子と双方向の連成は np = 1 とバイト一致。

拡散項(2026-10-28 追記。developer.md §90.12)は行の差が水位 1.4e-5 m・流速 2.0e-5 m/s、
運動量の積分の比 0.997、沿岸流の最大が 3.7% 下がり(0.2287 → 0.2202 m/s)分布の広がりが
5.6% 増え、90° 回した格子との差は水位 1.0e-5 m・流速 8.8e-5 m/s(修正前の版は同じ構成が 39 分で
発散)。release で np = 1・2・4 が逐次 reference に ULP=0 で拡散項(とその回した格子)は np = 1 と
バイト一致、`-Og -fcheck=all` で逐次と np = 2 が一致。

砕波による水平混合(2026-10-28 追記。developer.md §90.13)は出力 Wnu と組み立てた ν_w の差が
最大の 2.4e-7、最大 0.54 m²/s は砕波帯の中(i = 94。砕波の散逸が最大の 75%)、行の差は水位
1.1e-5 m・流速 2.2e-5 m/s・Wnu 1.6e-6 m²/s、運動量の積分の比 1.004、沿岸流の最大が 3.3% 下がり

再開の継続は通し計算とバイト一致。

側方 Neumann の境界面の移流項の修正(2026-10-29 追記。developer.md §90.19。境界面の検査体積を、枠外を
鏡像で読んで求める)で結果が丸めの規模で変わり(param.txt の Log.txt の S が相対 7.7e-8、E9998・v9998 が
印字の最終桁 1 つ)、reference を更新した。一様水深の行の差は 9.59e-5 → 3.29e-5 m/s、海浜の行の差は
ローラーなし 6.0e-5・ローラーあり 3.4e-5・双方向の連成 3.0e-5 m/s。検定一式は合格し、release で
np = 1・2・4 が逐次 reference に ULP=0、`-Og -fcheck=all` で逐次と np = 2(90° 回した格子は np = 2・4)が
一致。

f_opening_dynamic の既定の 2 から 3 への切り替え(2026-10-31 追記。developer.md §68.41)では、海浜の構成
(一様勾配 1/80、Δx = 10 m)の沿岸流の運動量の検定が 3 で通らない: ローラーなしで閉じた形との差 6.3%・積分の比
Σ τ_y/Σ F_y = 0.953、ローラーあり 7.7%・0.948、双方向の連成 7.7%・0.948、拡散項の比 0.947、水平混合の比 0.953
(一様水深の構成・セットアップ・90° 回した格子の一致・ローラーの収支・波の台帳は 2 と同じく合格)。一様な斜面では
3 は斜めの開口を全部開く(振り替えなし 0 と同じ結果)。Δx = 20・10・5 m(dt = 1・0.5・0.25 s。ローラーなし)で
比べると、3 の積分の比は 0.899・0.953・0.976(閉じた形との差 16.8・6.3・3.3%)と Δx に一次で 1 に近づき、2 は
0.993・1.000・0.999(4.8・3.2・1.8%)。斜面に沿う流れでは、開いた斜めの開口が Δz/h に一次の摩擦の偏りを持ち、
2 の斜面上側の開口の塞がり(s = Δz/h)がそれを打ち消していた。検定を保つため、海浜の構成(param_flat.txt 以外)は
f_opening_dynamic = 2 を明示し、reference は 2 のまま(切り替え前とバイト一致。release で np = 2 が逐次 reference に
ULP=0 で Run_MPI.sh の検定一式が合格)。開いた斜めの開口の偏りそのものの
原因と対策は今後の課題(developer.md §68.41)。
