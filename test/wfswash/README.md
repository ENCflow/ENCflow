# test/wfswash — 遡上域(swash)の輸送(f_wfswash)の検定

[English](en/README.md)

位相平均の波浪場(fn_wavefield)は汀線の手前で止まるので、汀線の面(湿ったセルと、地盤の高い乾いた
セルの間)に遡上の 1 周期で積分した正味の輸送の経験式を与える(developer.md §90.21)。岸沖は
Larson, Kubota & Erikson(2004)式 (8)、沿岸は Larson & Wamsley(2007)式 (4)、遡上高は Stockdon ら
(2006)式 (19) の振れ幅の部分 R = 1.1 S/2(setup は流れが解く)。この試験は、式と格子への当てはめ
(汀線の 4 近傍の面・沿岸の帯)を、式から独立に組み立てた値と倍精度で照合し、平衡勾配へ向かう
振る舞い・遡上の上限・保存則・再開・並列数によらない一致を確かめる。

reference は持たない(合否は Check_wfswash.py の検定、再開の往復と並列のバイト比較、不正な設定の
停止)。

## 設定

N-S の汀線(60 列、Δx = Δy = 5 m。西が沖、東が陸)に不規則波 H_m0 = 1 m・T = 8 s。掃流砂は
限界掃流力を大きくして止め(fluv_tausc = 100)、遡上域の輸送だけを見る(f_wfsed = 1 は前提)。
平衡勾配 wfswash_tanbe = 0.1、K_c・K_l・φ_m は既定(1.6e-3・K_c・30°)。rate〜cliff は波→流れの外力
なし(wf_flow = 0。静水面 η = 0 のままなので、遡上の届く高さが条件から決まる)。時間刻みは 0.25 s
(沖の水深 7.9 m で Courant 数 0.44。0.5 s(0.88)では、地形の更新が汀線で作る小さな長波が沖の
境界で育って止まった)。

| 構成 | 地形・波 | 役割 |
|---|---|---|
| rate | 一様勾配 1/40(平衡より緩い)、直角入射、更新 1 回(5 s) | 1 回の更新の量を式と照合 |
| diag | rate と同じ勾配を 45° 回した 60 × 60(陸は南東)、315° の直角入射、更新 1 回 | 汀線の向きによらないこと |
| eq | 前浜を平衡勾配 0.1、直角入射、10 分 × morfac 10 | 平衡勾配では変わらない |
| mild | rate と同じ、30 分 × morfac 10 | 岸向きの積み上げ(バームの形成) |
| steep | 前浜 0.15、30 分 × morfac 10 | 沖向き(前浜が削れて緩む) |
| obl | 前浜 0.1(岸沖の輸送 0)に 20° の斜め入射、16 行・10 分 | 沿岸の輸送の総量 |
| cliff | obl の汀線の陸側を崖(上端 2.0 m。遡上の上限 η + R ≒ 1.19 m より高い)にする | 遡上域のない汀線(崖・護岸の前)では動かない |
| flow | 一様勾配 1/40、閉じた海盆(流れの四辺は壁)、波→流れ wf_flow = 2(ローラー)、掃流砂・浮遊砂、波高の時系列 0.8 → 1.2 m、30 分 × morfac 5 | 連成での保存則・遡上の上限 |
| rt1 → rt2 | flow を 930 s で分けて再開 | 通し計算とバイト一致 |
| bad1〜4 | f_wfsed なし・wfswash_tanbe なし・tanβ_e ≥ tanφ_m・f_wfswash = 2 | 停止すること |

## 検定項目(Check_wfswash.py)

1. rate: 汀線の乾いたセルの増分と湿ったセルの減分が、初期の地形と波高(出力 Wh・H)から求めた
   −q_c Δt/Δx と一致(相対 1e-6。実測 5e-15)。q_c = −2.756e-4 m²/s(岸向き)、R = 0.3625 m、
   z = 0.0625 m。他のセルは変わらない。
2. diag: 汀線の全セルの増分が面の規則(4 近傍の面ごとの −q_c (n̂·ê) × 辺の長さ)と一致
   (相対 1e-6)。中央の 40 セルの単位長さあたりの総量が q_c Δt と一致(実測 6e-9)= 45° の汀線でも
   軸に沿う汀線と同じ(斜めの面も使うと、粗い格子で 1/√2 になる。§90.21)。
3. eq: 地形が変わらない(|Δz| < 1e-12。実測 0)。
4. mild: 保存則(Σ Δz ΔA = 1e-15 m³)、汀線の乾いたセルが積み上がり湿ったセルが同じだけ削れる
   (±0.241 m)、汀線のセル以外は変わらない、汀線の面の勾配が 0.025 → 0.049 と平衡勾配へ近づき
   越えない、堆積の上端(0.304 m)が遡上の上限 η + R(0.402 m)の下で、隣の乾いたセルより高い
   (バーム)。
5. steep: 保存則、乾いたセルが削れて湿ったセルに積もる(±0.260 m)、汀線の面の勾配が 0.15 → 0.124
   と緩み平衡勾配を越えない(乾いたセルが静水面の下になって汀線が陸側へ移り、次の乾いたセルは
   遡上の届かない高さなので止まる)。
6. obl: 北半分へ移った体積(2.2075 m³)が、汀線の波高・波向(出力 Wh・Wa。汀線での入射角 9.68°)
   から求めた遡上域の沿岸輸送の総量 Q_l × 600 s と一致(相対 1e-4。実測 8e-7)、南半分の減少と
   釣り合う、中央の行は実質的に変わらない(端の変化がゆっくり内側へ広がる分 < 1e-5 m)。
7. cliff: 崖の上端が遡上の上限より高く(2.0 m > R = 1.186 m)、同じ式なら沿岸の輸送
   Q_l = 1.2×10⁻² m³/s(600 s で 7.2 m³)が働く斜め入射でも、地形が変わらない(|Δz| < 1e-12。
   実測 0)。遡上域のない汀線セルにも沿岸のベクトルを置いていた版では 0.13 m 動いた(帯が崖の前で
   砂を運ぶ。developer.md §90.21)。
8. flow: 値が有限、土砂の保存(morfac Σ hs + (1 − λ) Σ Δz = 4e-14。浮遊砂は水柱側が水理時間、
   河床側が × morfac の台帳分離なのでこの形)、乾いたセルへの堆積が遡上の上限(H_inc ≤ 1.2 m、
   E = 1 の上限の R)を越えない。
9. 再開の往復が通し計算と state.dat・swflow_enc.dat・wavefield.dat・最終分布でバイト一致
   (入射波の波高は毎ステップ時刻の関数として受け渡すので保存しない。Run.sh)。
10. 不正な設定 bad1〜4 が、それぞれの理由で停止する(Run.sh)。
11. MPI: 同じ検定を同じ並列数で回し、全構成の state.dat・最終分布が np = 1 とバイト一致、再開の
    往復も一致(Run_MPI.sh)。

## 実行

```bash
make
./Run.sh          # 地形の生成 → 10 ラン → Check → 再開の比較 → 不正な設定(30 秒程度)
./Run_MPI.sh 4    # MPI。行が 8 の構成があるので np <= 4
```
