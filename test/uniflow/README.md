# test/uniflow — 乾いた地盤に挟まれた直線水路の等流

河道マスク(fn_rw)も河道幅モードも使わない「ラスタの掘り込み水路」で、
壁際の行の通水能を Manning の等流と比べる(developer.md §84.7)。

## 設定

長さ 1000 m、Δx = 1 m、勾配 0.002、n = 0.03。幅 W = 1・5 セルの水路の両側は
河床 +2 m の乾いた地盤。西端の区間流入 Q = q·W(q = 0.4695 m²/s は等流水深
0.5 m に対応)、東辺は自由流出。下流端の低下背水(約 250 m)を避けて
x = 400〜700 m で測る。`f_opening_dynamic` の 0(振り替えなし)と 2(全エッジ)
の 2 通り。

## 検定項目(Check_uniflow.py)

1. 定常・等流: 水面勾配が河床勾配に ±2 % で一致(4 構成)。
2. 質量収支: 行ごとの V·h の和が Q に 1e-3 で一致(4 構成)。
3. `f_opening_dynamic = 2` は Manning に一致: 全行で h/h_n と V/V_n が 1 ± 0.5 %。
4. 振り替えなしの既知の性質を記録: 幅 1 で h/h_n = 1.30(通水能が Manning の
   64 %)、幅 5 で河岸行の流速が内部行の 0.80(h/h_n = 1.04)。乾いたセルへの
   斜めリンクが流束を運ばず、その通過幅が失われるため(§68.14 の動機と同じ)。

## 使い方

```
make
./Run.sh            # 逐次(4 本で約 3 分)
./Run_MPI.sh 2      # MPI
```
