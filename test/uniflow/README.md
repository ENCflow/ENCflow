# test/uniflow — 乾いた地盤に挟まれた直線水路の等流

[English](en/README.md)

河道マスク(fn_rw)も河道幅モードも使わない「ラスタの掘り込み水路」で、
壁際の行の通水能を Manning の等流と比べる(developer.md §84.7)。

## 設定

長さ 1000 m、Δx = 1 m、勾配 0.002、n = 0.03。幅 W = 1・5 セルの水路の両側は
河床 +2 m の乾いた地盤。西端の区間流入 Q = q·W(q = 0.4695 m²/s は等流水深
0.5 m に対応)、東辺は自由流出。下流端の低下背水(約 250 m)を避けて
x = 400〜700 m で測る。`f_opening_dynamic` の 0(振り替えなし)・2(全エッジ)・
3(全エッジで、塞がりを局所の平面から測る。2026-10-29 追加、developer.md §68.41)の 3 通り。

射流の区間流入(構成 w1_sc): 同じ q を勾配 0.05 の幅 1 セルの水路(振り替え 2)に
流す(Manning の等流水深 0.190 m、Fr = 1.8)。流入面の水深の床が流れの水深を超えると、
流入セルの流速が等流より遅くなる(developer.md §89.25)。

## 検定項目(Check_uniflow.py)

1. 定常・等流: 水面勾配が河床勾配に ±2 % で一致(4 構成)。
2. 質量収支: 行ごとの V·h の和が Q に 1e-3 で一致(4 構成)。
3. `f_opening_dynamic = 2` は Manning に一致: 全行で h/h_n と V/V_n が 1 ± 0.5 %。
4. 振り替えなしの既知の性質を記録: 幅 1 で h/h_n = 1.30(通水能が Manning の
   64 %)、幅 5 で河岸行の流速が内部行の 0.80(h/h_n = 1.04)。乾いたセルへの
   斜めリンクが流束を運ばず、その通過幅が失われるため(§68.14 の動機と同じ)。
5. 射流の区間流入(w1_sc。1・2 も判定): 流入セルの水深と流速が等流区間の平均と
   ±1 %。2026-10-28 の変更(流入面の水深の床を等流水深までに)の後は水深・流速とも
   1.0000 倍(表示の 4 桁で一致)。変更前の実行ファイルでは流速が 0.71 倍・水深が 0.96 倍
   (流入面の床が限界水深)。
6. `f_opening_dynamic = 3`(構成 w1_on3・w5_on3。1・2 も判定): 項目 3 と同じく全行で h/h_n と
   V/V_n が 1 ± 0.5 %。河道の両岸が高いので塞がりはほぼ 2 と同じに数えられ、Manning に一致したまま
   (2026-10-29: 幅 1 で水深 1e-4・流速 2e-4、幅 5 で 2e-4・2e-4 の差)。

make
