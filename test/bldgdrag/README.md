# test/bldgdrag — 家屋のある水路の等流(家屋の抗力項の検定)

[English](en/README.md)

家屋の空隙率 `fn_gv` と家屋の平均寸法 `fn_bb` を与えた水路の等流で、運動方程式の
家屋の抗力項([ENC 格子と時間積分の解説](../../docs/users_guide/encgrid.md) §5)を
理論値と比べます(developer.md §107)。

## 理論値

家屋のあるセルでは、エッジの法線流速 $`u`$ の式は、圧力項と底面摩擦に空隙率 $`g_v`$ が掛かり、
家屋の抗力が加わります。

```math
\lambda_m\frac{\partial u}{\partial t}
 = -\,g_v\,g\,\frac{\partial \eta}{\partial s}
   - \left[\,g_v\,\frac{g\,n^2}{h^{4/3}} + \frac{k\,C_D}{2}\,\frac{1 - g_v}{B}\right]|\mathbf{V}|\,u
```

$`B`$ は家屋の平均寸法、$`C_D`$(`cd`)は抗力係数、$`k`$(`kk`)は補正係数です。家屋の抗力は
没水した前面積 $`B\,h`$ に比例しますが、流速の式では水柱の質量で割るので、係数は水深を
含みません。勾配 $`S`$ の一様な水路の等流では、単位幅流量 $`q = V h`$ に対して

```math
g_v\,g\,S = \left[\,g_v\,\frac{g\,n^2}{h^{4/3}} + \frac{k\,C_D}{2}\,\frac{1 - g_v}{B}\right]\frac{q^2}{h^2}
```

の解が等流水深 $`h_u`$ です(`make_init.py` の `uniform_depth`。二分法)。$`g_v = 1`$ では
マニングの等流に戻ります。

## 設定

長さ 2000 m、Δx = 5 m、勾配 0.01、n = 0.03。幅 4 セル(20 m)の水路の両側は河床 +12 m の
乾いた地盤で、水路の全体に家屋を置きます。西端の区間流入 Q = q × 20 m、東辺は自由流出。
初期水深 1 m から 90 分計算し、流入の近くと下流端の低下背水を避けた x = 300〜900 m で測ります。

| 構成 | gv | B (m) | cd | kk | q (m²/s) | 等流水深 h_u (m) | 流速 V_u (m/s) | 家屋なしのマニングの水深 (m) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| shallow | 0.7 | 10 | 1.0 | 0.5 | 0.4 | 0.299 | 1.337 | 0.280 |
| deep | 0.7 | 10 | 1.0 | 0.5 | 8.0 | 2.897 | 2.762 | 1.691 |
| dense | 0.5 | 20 | 2.0 | 0.5 | 8.0 | 4.146 | 1.930 | 1.691 |

shallow はマニングの摩擦が主(家屋の抗力はその 0.24 倍)、deep は家屋の抗力が主(5 倍)です。
dense は空隙率・家屋の寸法・抗力係数を変えて、係数の入り方を確かめます。

## 検定項目(Check_bldgdrag.py)

1. 定常: 45 分と 90 分の水深の差が 1 mm 以内。
2. 等流: 水面勾配が河床勾配に ±2 % で一致。
3. 質量収支: 行ごとの V·h の和が Q に 1e-3 で一致。
4. 理論の等流に一致: 全行で h/h_u と V/V_u が 1 ± 0.5 %。
5. 家屋の抗力が効いている: 等流水深が家屋なしのマニングの水深より深い(shallow で 1.05 倍以上、
   deep・dense で 1.5 倍以上)。

実測では、3 構成とも h/h_u・V/V_u が 1 ± 0.0001 です。抗力の係数に水深を掛けた式
(2026-11-12 までの誤り。developer.md §107)では、shallow が 0.955、deep が 2.33、dense が 2.99 に
なり、項目 4 で検出されます。

## 使い方

```
make
./Run.sh            # 逐次(3 本で約 1.5 分)
./Run_MPI.sh 2      # MPI
```

## できないこと

等流の釣り合いだけを確かめます。家屋群の抗力係数そのものの妥当性(実際の市街地の流れとの照合)は
対象外で、`cd`・`kk` は校正値です([ENC 格子と時間積分の解説](../../docs/users_guide/encgrid.md) §8)。
