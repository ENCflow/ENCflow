# test/culvert — カルバート流量則の 3 レジーム通過

盛土を横断するボックスカルバート(`&list_struct_culvert`。
[ユーザーガイドの構造物の章](../../docs/users_guide/structure.md)、
流量則は[水理則の解説](../../docs/users_guide/hydraulics.md) §2)の
検証ケースです。平坦な上流槽に 3 m の水を置き、1 m × 1 m のカルバート
1 本だけで常に乾いた下流列へ排水します。上流水深 h₁ が 3D から 0.4D
まで下がる間に、満管(流入口水没)→ 遷移(管頂付近)→ 自由水面(堰)
の 3 レジームを通過します。下流が乾いているため Q は h₁ だけの関数で、
Log の貯留 S から復元した Q(h₁) を流量則と直接比べられます
(developer.md §22 の 2026-10-12 改修の検定)。

## 構成

| 項目 | 値 |
|---|---|
| 領域・格子 | 120 m × 110 m、12 × 11 セル(Δx = 10 m)、四周壁 |
| 地形 | i = 1..10 上流槽 z = 0、i = 11 盛土 z = 10 m、i = 12 下流列 z = 0(`data_culvert/z.txt`) |
| 初期条件 | 上流槽に水深 3.0 m(`hinit.txt`)、他は乾燥 |
| 下流列 | 水位規定 η = −999 の完全排水口(`stage.txt`。常に乾燥) |
| カルバート | (10, 6) → (12, 6)、B = D = 1 m、敷高 0/0、L = 0(摩擦なし)、c_e = 0.5 |
| 時間 | dt = 0.5 s、14400 s。Log は 120 s 毎 |

全有効セル 132 × 100 m² = 13200 m² を A_total、上流槽 11000 m² を A_up
とすると、Q = −A_total dS/dt、h₁ ≈ S A_total / A_up です。

| ファイル | 内容 |
|---|---|
| `param.txt` | 上記(reference あり) |
| `make_init.py` | `data_culvert/` の 3 ファイルを再生成 |

## 実行

```bash
make
./Run.sh          # Log.txt を reference と比較(ULP = 0、Runge 列を除く)
./Run_MPI.sh 4
python3 Fig.py    # figs/law.png
```

## 図

![復元流量と流量則](figs/law.png)

赤点が S の差分から復元した計算流量、黒線が流量則
$`Q = \min(Q_w, Q_p)`$(h₁ ≥ D)です。管路式は下流水頭を出口敷高 +
(d_c + D)/2 にとるため、流入口が水没する h₁ = D で堰流量からほぼ連続に
始まり、h₁ ≈ 1.3D から上で上限として効きます。

## 所見

| h₁ (m) | 計算 Q (m³/s) | 流量則 Q (m³/s) | 差 |
|---|---|---|---|
| 2.505 | 4.435 | 4.435 | 0.0 % |
| 1.509 | 2.648 | 2.649 | 0.0 % |
| 1.006 | 1.563 | 1.565 | −0.1 % |
| 0.599 | 0.717 | 0.718 | −0.1 % |

- 復元した Q は h₁ の低下とともに全区間で単調に減少し、管頂直上
  (h₁ = 1.0〜1.1 m)に落ち込みはありません(改修前の基準では h₁ = 1.02 m
  で 1.60 → 0.51 m³/s に落ちていました)。
- 流量則との差 0.1 % 以内は、代表セル (10, 6) の水位と槽平均水位の差
  (排水による局所的な水面勾配)によるものです。
- np = 1, 2, 4 が逐次 reference とビット一致します(ULP = 0)。
