# ENCflow チュートリアル

[English](en/README.md)

実行できる例題を使って、入力の作成と計算結果の読み方を学びます。
学習の順序と関連する解説は [チュートリアルガイド](../docs/tutorial.md)、
準備は [インストールガイド](../docs/install.md) を参照してください。

| 順序 | 教材 | 内容 |
|---|---|---|
| 1 | [wave](wave/README.md) | 最初の実行、パラメータファイル、時間刻み、境界条件 |
| 2 | [chichibu](chichibu/README.md) | 実地形データ、降雨流出、計測、水収支、可視化 |
| 3 | [bmi](bmi/README.md) | Python から ENCflow を操る(BMI): 起動・時間を進める・状態の取り出し・リアルタイム描画・雨や粗度の外部供給 |

**1 の wave と 2 の chichibu は、すべての方に必ず試していただきたい**
教材です。この 2 つで、ENCflow の使い方(入力の作り方、実行、結果の
読み方)が一通り身につきます。

**3 の bmi は、ほとんどの方には不要**です。通常の使い方(パラメータ
ファイルを書いて実行し、結果ファイルを読む)では BMI を使いません。
ENCflow を他のモデルやプログラムと連携させたい方、あるいは計算の
途中で外部から状態量やパラメータを読み書きしたい方(たとえば Python から
雨を与える、粗度を変えながら繰り返す)だけが読めば十分です。

作業場所は `tutorials/wave`・`tutorials/chichibu`・`tutorials/bmi` です。
英語版を読む場合も `en/` へ移動せず、各ケース直下で実行します。
README内のリンクと、実行時の作業ディレクトリを混同しないでください。

開発用の回帰テストは [test/](../test/README.md)、現象別の例題は
[examples/](../examples/README.md) にあります。同名のケースでも用途が異なります。

本文の更新・翻訳は [多言語化規約](../docs/multilingual.md) に従います。
