# ENCflow チュートリアル

[English](en/README.md)

実行できる例題を使って、入力の作成と計算結果の読み方を学びます。
学習の順序と関連する解説は [チュートリアルガイド](../docs/tutorial.md)、
準備は [インストールガイド](../docs/install.md) を参照してください。

| 順序 | 教材 | 内容 |
|---|---|---|
| 1 | [wave](wave/README.md) | 最初の実行、パラメータファイル、時間刻み、境界条件 |
| 2 | [chichibu](chichibu/README.md) | 実地形データ、降雨流出、計測、水収支、可視化 |

作業場所は `tutorials/wave` または `tutorials/chichibu` です。
英語版を読む場合も `en/` へ移動せず、各ケース直下で実行します。
README内のリンクと、実行時の作業ディレクトリを混同しないでください。

開発用の回帰テストは [test/](../test/README.md)、現象別の例題は
[examples/](../examples/README.md) にあります。同名のケースでも用途が異なります。

本文の更新・翻訳は [多言語化規約](../docs/multilingual.md) に従います。
