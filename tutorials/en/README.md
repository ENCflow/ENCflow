# ENCflow tutorials

[日本語正本](../README.md)

> English mirror of `tutorials/README.md`. The Japanese version is authoritative.

Learn to prepare inputs and read results through runnable examples.
See the [tutorial guide](../../docs/en/tutorial.md) for the learning sequence and
related explanations, and the [installation guide](../../docs/en/install.md)
for prerequisites.

| Order | Tutorial | Contents |
|---|---|---|
| 1 | [wave](../wave/en/README.md) | First run, parameter files, time step and boundary conditions |
| 2 | [chichibu](../chichibu/en/README.md) | Real terrain data, rainfall runoff, recording, water balance and visualization |

Work in `tutorials/wave` or `tutorials/chichibu`. Even when reading English,
run commands from the case root, not from `en/`. Do not confuse the location
used to resolve documentation links with the working directory for execution.

Development regression tests are in [test/](../../test/README.en.md), and
phenomenon-specific examples are in [examples/](../../examples/README.en.md).
Cases with the same name can serve different purposes.

Follow the [multilingual policy](../../docs/en/multilingual.md) when updating
or translating these materials.
