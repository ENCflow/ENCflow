!======================================================================
!
! 境界条件設定 &list_bound_edge / &list_bound_source の例
!
!   このファイルはシステムパラメータ &list_sysparam 内で
!     fn_boundary = "list_boundary.txt"
!   のように指定して使用します(fn_boundary 未指定なら境界条件機能は
!   完全に不活性)。
!
!   族別のグループを同じこのファイルに書きます。グループ自体を
!   書かなければその族は無効です(不在は正常)。
!
!   注意: 旧形式の単一グループ &list_boundary は廃止されました。
!   検出すると停止して本形式への移行を案内します。
!
!======================================================================
! 辺境界条件: 計算領域外縁の4辺それぞれの境界条件型
!======================================================================
!   0: 不透過(壁面。既定)
!   1: 簡易流出(段落ち式による自由流出)
!
!   方角と格子添字の対応(ラスタの行順=北→南):
!     西 = i=1(左端)、東 = i=nx(右端)、
!     北 = j=1(上端)、南 = j=ny(下端)
!
!   辺境界は有効セル(x=1)が格子枠に接している辺でのみ実効です。
!   周囲を nodata(x=0)の縁が囲む地形では作用しません。
!======================================================================
&list_bound_edge
  f_bc_w = 0
  f_bc_e = 0
  f_bc_n = 0
  f_bc_s = 0
/

!======================================================================
! 内部ソース: 湧き出し・吸い込み(複数指定可)
!======================================================================
!   ソースごとに「セル集合」と「流量時系列 Q(t)」を指定します。
!   第3添字がソース番号(1 から連続)。
!     src_cell(:,k,n) = i, j     : ソース n の k 番目のセル座標
!     src_val(:,k,n) = t, q      : ソース n の時系列 (時刻(min), 流量(m3/s))
!                                  時系列は線形補間、範囲外は端の値を保持。
!                                  q < 0 で吸い込み(セルの水深は 0 で
!                                  打ち止め。不足分は汲めない)
!   流量はソースのセル集合に均等分配されます。
!   セル集合・時系列はファイル指定もできます(dir_data 起点の相対パス):
!     fn_src_cell(n) = "..."     : 各行 "i j"
!     fn_src_val(n) = "..."      : 各行 "時刻(min) 流量(m3/s)"
!======================================================================
!&list_bound_source
!  ! ソース1: 湧き出し(2セルに 100 m3/s を分配)
!  src_cell(:,1,1) = 10, 10
!  src_cell(:,2,1) = 10, 11
!  src_val(:,1,1) =   0,   0.0
!  src_val(:,2,1) =  60, 100.0
!  src_val(:,3,1) = 120,   0.0
!  ! ソース2: 吸い込み(排水口)
!  src_cell(:,1,2) = 50, 50
!  src_val(:,1,2) =   0,  -5.0
!  src_val(:,2,2) = 999,  -5.0
!/
