!======================================================================
!
! 境界条件設定 &list_bound_edge / &list_bound_source の例
!
!   このファイルはシステムパラメータ &list_sysparam 内で
!     fn_boundary = "list_boundary.txt"
!   のように指定して使用します(fn_boundary 未指定なら境界条件機能は
!   完全に不活性)。
!
!   族別のグループを同じこのファイルに書きます。グループ自体を
!   書かなければその族は無効です(不在は正常)。
!
!   注意: 旧形式の単一グループ &list_boundary は廃止されました。
!   検出すると停止して本形式への移行を案内します。
!
!======================================================================
! 辺境界条件: 計算領域外縁の4辺それぞれの境界条件型
!======================================================================
!   0: 不透過(壁面。既定)
!   1: 自由流出(洪水氾濫向け)
!      前進してきた流れは自分の速度のまま境界を通過し、滞留水は
!      段落ち(自由越流)で抜けます。流入は起きません。
!      ドライベッド上を進む氾濫流の流出に使います。
!   2: 長波放射(津波・波動伝搬向け)
!      静水面(水位=基準水位)では流出せず、境界に達した波の
!      水位偏差だけを透過させます(引き波の流入も許します)。
!      基準水位は未指定なら初期条件から自動導出されます:
!        - 初期条件が水位固定(list_initial の f_htype=2)なら e0
!        - それ以外は境界セルごとの初期水位(z+h)
!      自動導出では t=0 の放射フラックスが厳密にゼロになります。
!      bc_eta_* を明示指定するとその一様値が優先されます
!      (z と同じ基準。復元運転でも基準を固定したい場合等)。
!
!   方角と格子添字の対応(ラスタの行順=北→南):
!     西 = i=1(左端)、東 = i=nx(右端)、
!     北 = j=1(上端)、南 = j=ny(下端)
!
!   辺境界は有効セル(x=1)が格子枠に接している辺でのみ実効です。
!   周囲を nodata(x=0)の縁が囲む地形では作用しません。
!======================================================================
&list_bound_edge
  f_bc_w = 0
  f_bc_e = 0
  f_bc_n = 0
  f_bc_s = 0
  !bc_eta_w = 0.0
  !bc_eta_e = 0.0
  !bc_eta_n = 0.0
  !bc_eta_s = 0.0
/

!======================================================================
! 内部ソース: 湧き出し・吸い込み(複数指定可)
!======================================================================
!   ソースごとに「セル集合」と「流量時系列 Q(t)」を指定します。
!   第3添字がソース番号(1 から連続)。
!     src_cell(:,k,n) = i, j     : ソース n の k 番目のセル座標
!     src_val(:,k,n) = t, q      : ソース n の時系列 (時刻(min), 流量(m3/s))
!                                  q は「セル群全体の総量」(セルあたりや
!                                  単位面積あたりではない)。
!                                  時系列は線形補間、範囲外は端の値を保持。
!                                  q < 0 で吸い込み(セルの水深は 0 で
!                                  打ち止め。不足分は汲めない)
!   流量はソースのセル集合に均等分配されます(各セル同体積ずつ。
!   家屋の空隙率 gv < 1 のセルでは水深増分がその分大きくなります)。
!   セル集合・時系列はファイル指定もできます(dir_data 起点の相対パス):
!     fn_src_cell(n) = "..."     : 各行 "i j"
!     fn_src_val(n) = "..."      : 各行 "時刻(min) 流量(m3/s)"
!======================================================================
!&list_bound_source
!  ! ソース1: 湧き出し(2セルに 100 m3/s を分配)
!  src_cell(:,1,1) = 10, 10
!  src_cell(:,2,1) = 10, 11
!  src_val(:,1,1) =   0,   0.0
!  src_val(:,2,1) =  60, 100.0
!  src_val(:,3,1) = 120,   0.0
!  ! ソース2: 吸い込み(排水口)
!  src_cell(:,1,2) = 50, 50
!  src_val(:,1,2) =   0,  -5.0
!  src_val(:,2,2) = 999,  -5.0
!/

!======================================================================
! 水位規定セル群: セル集合の水位を指定値に強制する(複数指定可)
!======================================================================
!   流域抽出計算の出口(流域外への流出境界)、背水・感潮域などに
!   使います。指定セルの水深は毎ステップ h = max(η − z, 0) に強制され
!   (湧き出しより優先)、周囲との流出入は運動方程式が規定水位の作る
!   勾配から計算します(u,v,m,n・record の測線にも乗ります)。
!   η を河床より低くすればセルは常に空=完全排水口になります
!   (従来の「周囲を海で囲む+段落ち」トリックの置き換え)。
!   第3添字が群番号(1 から連続)。
!     stage_cell(:,k,n) = i, j   : 群 n の k 番目のセル座標
!     stage_eta(n) = η           : 規定水位の固定値 (m。z と同じ基準)
!     stage_val(:,k,n) = t, η    : 規定水位の時系列 (時刻(min), 水位(m))
!                                  (固定値の代わりに指定。線形補間、
!                                   範囲外は端の値を保持)
!   セル集合・時系列はファイル指定もできます(dir_data 起点):
!     fn_stage_cell(n) = "..."   : 各行 "i j"
!     fn_stage_val(n) = "..."    : 各行 "時刻(min) 水位(m)"
!   注意: 規定セルと周囲の水位差が大きいと局所的なダム崩壊流が生じ、
!   CFL 条件(dt)の見直しが必要になることがあります。
!======================================================================
!&list_bound_stage
!  ! 群1: 流域出口(河床より低い水位で完全排水)
!  stage_cell(:,1,1) = 100, 200
!  stage_cell(:,2,1) = 101, 200
!  stage_eta(1) = -999.0
!  ! 群2: 感潮域(水位時系列)
!  stage_cell(:,1,2) = 300, 150
!  stage_val(:,1,2) =   0, 0.0
!  stage_val(:,2,2) = 360, 0.5
!  stage_val(:,3,2) = 720, 0.0
!/

!======================================================================
! 区間流入: 外縁に接するセル区間への流量規定(複数指定可)
!======================================================================
!   河川などが計算領域外縁から流入する境界です。区間セル(外縁に
!   接していること)の外縁法線面に流量を規定します。湧き出しと違い
!   指向性の流入(運動量を持つ)で、u,v,m,n・record にも乗ります。
!   流量 Q は「区間全体の総流入量」(セルあたりや単位幅あたりでは
!   ない)。区間内で按分して与えられ、どの配分モードでも総流入量は
!   厳密に Q(t) になります。
!   辺の型(不透過/流出/放射)は区間の面だけ上書きされます。
!   流量は非負のみ(流出は stage / source を使ってください)。
!   第3添字が区間番号(1 から連続)。
!     inflow_cell(:,k,n) = i, j  : 区間 n の k 番目のセル座標
!     inflow_val(:,k,n) = t, Q   : 流量時系列 (時刻(min), 総流量(m3/s))
!     inflow_dist(n) = 0|1|2     : 区間内の配分モード(既定 0)
!       0: 均等按分。開口幅按分で単位幅流量 (m2/s) が区間一様
!       1: 水深按分。重み=水深 h。wet セルで流入流速 (m/s) が一様に
!          なる配分(河道横断面からの流入を想定。水深の無いセルは
!          流入ゼロ)
!       2: 通水能按分。重み=h^(5/3)。マニング則の等勾配断面と同じ
!          配分で、深いセルほど流速も大きい(1 より河道らしい配分)
!       1・2 の重み按分は、最深セルの想定流速のフルード数余裕に応じて
!       均等按分と連続ブレンドされます(Fr <= 0.5 で完全に重み按分、
!       Fr >= 1 で均等、間は線形。総流入量はブレンドによらず厳密)。
!       閾値切替がないため配分は時間的に連続で、乾いた断面・薄膜だけの
!       断面・退水時は自動的に均等側へ寄ります。低水時に澪筋だけが
!       wet の断面では完全に重み按分となり、乾いた河川敷には流入
!       しません。水深の無い(h < dd)セルへの重み側の配分はゼロ。
!       重みには前ステップの水深を使い、配分は毎ステップ更新されます。
!   セル集合・時系列はファイル指定もできます(dir_data 起点):
!     fn_inflow_cell(n) = "..."  : 各行 "i j"
!     fn_inflow_val(n) = "..."   : 各行 "時刻(min) 総流量(m3/s)"
!======================================================================
!&list_bound_inflow
!  ! 区間1: 西辺 j=100..102 から河川流入
!  inflow_cell(:,1,1) = 1, 100
!  inflow_cell(:,2,1) = 1, 101
!  inflow_cell(:,3,1) = 1, 102
!  inflow_val(:,1,1) =   0,   0.0
!  inflow_val(:,2,1) =  60, 500.0
!  inflow_val(:,3,1) = 720,  50.0
!  inflow_dist(1) = 2
!/

!======================================================================
! 排水ポンプ(内部水理構造物族。グループ不在=ポンプなし)
!   取水セル群から吐口セル群への強制転送(機械排水)。取水と吐口は
!   隣接不要・距離無制限。吐口を省略すると域外排水(下水道・他流域への
!   圧送=系から除去)。転送は質量保存的で、取水側に実在する水量までの
!   吸い上げ制限が毎ステップかかる(圧送の到達遅れは表現しない)。
!   運転ルールは次のどちらか一方:
!     pump_q0(n)     : 常時一定流量 (m3/s)
!     pump_rule(:,k,n): 基準水位—流量の折れ線 (基準値 m, 流量 m3/s)。
!                       線形補間・範囲外は端値。単純な閾値 ON/OFF は
!                       急なランプ(近接する2点)で、多段運転(台数
!                       増加)は階段状の折れ線で表す。現在水位の
!                       純関数なので履歴状態なし(リスタート無変更)。
!                       起動/停止のヒステリシスは表現しない
!   基準は f_pump_ref(n) = 0: 取水代表セル(先頭)の水位 η=z+h (m)
!                         1: 同セルの水深 h (m)
!   セル集合はファイル指定もできます(dir_data 起点、各行 "i j"):
!     fn_pump_in_cell(n) / fn_pump_out_cell(n)
!   ため池取水: 取水セルが rscap > 0(ため池)の場合は場の水面でなく
!   ため池貯留(hrs)から汲む(前池排水)。その場合の水深基準
!   (f_pump_ref=1)はため池水深 hrs を参照する。水位基準(=0)は
!   ため池代表セルでは使えない(エラー停止)
!   注意: 堤防モデル(fn_channel)の f_bank_mode=2(強制排水)は過去計算
!   との互換・極端シナリオ実験用で、実務の排水機場は本族を使うこと
!======================================================================
!&list_bound_pump
!  ! ポンプ1: 堤内の内水を本川へ、前池水深 0.5m から起動し 1.0m で定格
!  pump_in_cell(:,1,1)  = 120, 45        ! 取水セル(複数行で群指定)
!  pump_out_cell(:,1,1) = 95, 12         ! 吐口セル
!  f_pump_ref(1) = 1                     ! 基準 = 取水代表セルの水深 h
!  pump_rule(:,1,1) = 0.5, 0.0           ! (水深 m, 流量 m3/s)
!  pump_rule(:,2,1) = 1.0, 5.0           !   0.5〜1.0m でランプ、以深 5m3/s
!  ! ポンプ2: 常時一定 2m3/s を域外(下水道)へ
!  pump_in_cell(:,1,2) = 200, 80
!  pump_q0(2) = 2.0
!/
