# examples/vz_tani2023 — 谷(2023)の VZ 流出モデルの再現(竜ノ口山 TY1・TY2)

[English](en/README.md)

谷(2023)[^tani2023]が HYDRUS-1D で行った VZ 流出モデルの計算を、ENCflow の
鉛直不飽和浸透(VZ)流出([fn_vz](../../docs/users_guide/vz.md))で同じ設定のまま
計算し直し、論文の計算流出強度と比べる例題です。対象は竜ノ口山森林理水試験地
(TY。岡山市)の 3 流域(北谷 KT 17.27 ha、南谷 MN 22.61 ha、斜面 SL 500 m²)で、
1987 年 7 月の梅雨のイベント TY1 と 1976 年 9 月の台風のイベント TY2 を扱います。
論文の計算値と比べることで、ENCflow の 1 次元 Richards 式の計算核と区画の読み出し
(土層厚の深さの排水を流域で積分)を、独立な実装の結果に対して確かめます。

## 論文の数値の扱い(データは同梱しません)

論文の降雨・観測流出強度・計算流出強度は図にしかありません。この例題は数値を
リポジトリに置かず、利用者が J-STAGE から論文の PDF を入手し、
`extract_tani2023.py` が図のベクトル描画の座標から `data/` に取り出します
(降雨の棒、観測の記号 ○ KT・× MN・△ SL、計算値の曲線)。

- 対象の PDF: <https://www.jstage.jst.go.jp/article/jjshwr/36/1/36_36.1741/_pdf/-char/ja>
  (2026-10-26 に入手した版の SHA-256 をスクリプトに記録。版が違えば警告を出します)
- 読み取りの照合(表−1 と比較。スクリプトが毎回表示します):

  | 事例 | 降雨の棒 | 最大時間雨量(表−1) | 棒の合計(表−1 の総雨量) |
  |---|---|---|---|
  | TY1(図−14) | 1 時間の棒 48 本 | 14.50 mm/h(14.5) | 132.46 mm(131.5 mm) |
  | TY2(図−15) | 1 時間の棒 112 本 | 14.30 mm/h(14.3) | 376.59 mm(374.9 mm) |

  TY1 の棒の高さは 0.5 mm の格子に ±0.012 mm で乗り、読み取りの誤差は描画の
  精度の範囲です。総雨量の差(+0.7 %・+0.5 %)は、表−1 の集計期間と図の範囲の
  違いなどによると考えられます(原因は論文からは確かめられません)。
- 観測流出強度の出典は森林総合研究所関西支所の水文観測です(論文 Ⅲ.1)。

## 設定(論文の記述 → ENCflow)

| 項目 | 論文(谷 2023) | ENCflow(`param_ty1.txt`・`param_ty2.txt`) |
|---|---|---|
| 参照柱 | 長さ 10 m、刻み 2.5 cm、下端は自由排水(HYDRUS-1D の free drainage)(Ⅱ.2) | `vz_depth = 10`、`vz_dz = 0.025`、`f_vz_bottom = 1` |
| 土壌物理性 | 小杉式、TY: θr 0.230、θs 0.370、ψm −20.0 cm、σ 1.60、Ks 5.0×10⁻³ cm/s(表−2) | `vz_thetar = 0.230`、`vz_thetas = 0.370`、`vz_psim = -0.200`、`vz_sigma = 1.60`、`vz_ks_mmh = 180` |
| 初期条件 | すべての深さで ψ = −400 cm(SL の観測値による)。TY2 も TY1 と同じ(Ⅳ.2) | `vz_psi0 = -4.0` |
| 土層厚の分布 | 線形分布: 0 cm から最大値まで 2.5 cm 刻みの区分が同じ面積。最大値は SL 100、KT 175、MN 250 cm(TY1 の湿潤期に合うよう著者が決めた値)(Ⅳ.1・Ⅳ.2) | 1 区分 = 1 セル(1 m²)、1 流域 = 1 行の区画(`make_case.py`)。0 cm の区分は土層厚 0 のセル(雨がそのまま排水) |
| 柱と流域 | 流域ごとに同じ土壌柱の計算から読み出す | 3 区画(KT・MN・SL)が 1 本の柱を共有(`vz_zone_col = 1`) |
| 流出強度 | 各深さの下向きフラックスを分布で積分(図−3) | 区画の累積排水 vdrain の 10 分差分 / 区画面積(`compare_tani2023.py`)。排水は系外へ(`vz_out_kind = 2`) |
| 基底流 | 観測から分離した基底流を計算値に加えて図示(Ⅲ.1) | 加えない(論文から分離線を復元できないため)。比較は流出強度の大きい範囲で見る |
| 降雨 | 1 時間雨量(図の棒) | 図の棒を 1 時間の段階関数で(`data/precip_TY*.txt`)。時刻の割り当ては下の推定 |
| 時間 | TY1: 1987-07-14 06:00〜07-21 06:00、TY2: 1976-09-08 12:00〜09-14 00:00(図の時間軸) | `tt` = 7 日・5.5 日、`dt = dt_vz = 60` s、記録 10 分 |

全セルが VZ なので地表流は生じません(格子は流出の積分の器です)。ENCflow 側の
拡張として、土層厚 0 のセル(線形分布の 0 cm 区分)を許す変更を入れました
(developer.md §87.2)。

## 実行

```bash
cd examples/vz_tani2023
make                          # bin/ の実行ファイルへのリンクと格子入力 data/
./Run.sh <論文の PDF>         # 抽出 → TY1・TY2 の計算 → 比較(計算は約 20 s・30 s)
./Run.sh                      # 抽出済みなら計算と比較だけ
```

抽出には Python の pdfminer.six(`pip install pdfminer.six`)が要ります。
matplotlib があれば `result_ty1/fig_ty1.png`・`result_ty2/fig_ty2.png` に、
降雨と、論文の計算値・ENCflow・観測の流出強度(対数軸)を重ねた図を描きます
(論文の数値を含むので、図もリポジトリには置きません)。

## 結果(2026-10-26。gfortran 13.3、既定の数値設定)

`compare_tani2023.py` の出力です。log10 比は log10(ENCflow / 論文の計算値)、
p90 はその絶対値の 90 % 値(0.1 で約 26 %、0.03 で約 7 % の比に当たります)。
ピーク時刻は論文の計算値の主な極大ごとの ENCflow の極大との時刻差の中央値です。

| 事例 | 流域 | 0.1 mm/h 以上: 中央値 / p90 | 0.5 mm/h 以上: 中央値 / p90 | ピーク 論文 / ENCflow | ピーク時刻の差 |
|---|---|---|---|---|---|
| TY1 | KT | −0.042 / 0.113 | −0.020 / 0.065 | 4.29 / 4.13 mm/h(−3.9 %) | −0.10 h |
| TY1 | MN | −0.036 / 0.246 | −0.029 / 0.097 | 2.79 / 2.90 mm/h(+4.0 %) | −0.18 h |
| TY1 | SL | −0.010 / 0.149 | −0.008 / 0.060 | 7.42 / 7.15 mm/h(−3.7 %) | −0.11 h |
| TY2 | KT | −0.005 / 0.026 | −0.005 / 0.021 | 8.65 / 8.68 mm/h(+0.4 %) | −0.09 h |
| TY2 | MN | −0.003 / 0.089 | −0.003 / 0.029 | 6.31 / 6.46 mm/h(+2.3 %) | +0.07 h |

- **TY2** は論文の計算値にほぼ重なります(0.5 mm/h 以上で 90 % の点が 7 % 以内)。
  同じ式・同じ設定を独立に解いた結果どうしの一致で、ENCflow の計算核と読み出しが
  論文の計算を再現していると言えます。
- **TY1** も流出強度の大きい範囲では 90 % の点が 15〜25 % 以内、ピークは 4 % 以内
  です。0.1 mm/h 前後の低流量期(イベント前半の無降雨期間)では ENCflow が
  0.01〜0.03 mm/h ほど低く、これは論文の計算値に加えられた基底流の大きさに
  相当します(ENCflow には加えていません)。
- ピーク時刻の差 −0.1 h 程度は、ENCflow の流出強度を 10 分平均で求めていること
  などによる大きさです。
- 観測との比較(論文 Ⅳ.2 の議論。TY1 の前半は計算が観測を上回り、湿潤化とともに
  一致してゆく)は図で確かめられます。論文と同じく、この例題は観測に合わせる
  調整をしていません。

## 降雨の時刻の割り当て(推定)

図の降雨の棒は正時を中心とする 1 時間に描かれており、その雨が正時の前の 1 時間か
後の 1 時間かは図から決まりません。棒の位置のまま・±0.5 h・±1.0 h で計算し、
論文の計算値 0.5 mm/h 以上の p90 が最小になる割り当てを採りました
(`extract_tani2023.py` の `RAIN_SHIFT_H`)。

| 事例 | −1.0 h | −0.5 h | 棒の位置のまま | +0.5 h | +1.0 h |
|---|---|---|---|---|---|
| TY1(KT / SL / MN) | — | 0.207 / 0.306 / 0.382 | 0.171 / 0.238 / 0.276 | **0.065 / 0.060 / 0.097** | 0.096 / 0.106 / 0.183 |
| TY2(KT / MN) | 0.100 / 0.121 | **0.020 / 0.028** | 0.067 / 0.094 | 0.157 / 0.200 | — |

TY1 は正時から始まる 1 時間、TY2 は正時までの 1 時間に当たります。事例で向きが
違う理由は論文からは分かりません(図の作り方や元データの時刻の付け方の違いと
推測されますが、確かめていません)。

## この例題でまだ扱っていないこと

- 桐生(KI1・KI2)と Mettman Ridge(MREX・MR1)、桐生の小斜面の人工降雨実験
  (KIEX)。KI は排水の 1/2 を深部浸透とする後処理、MR は排水から 0.3 mm/h を
  差し引く後処理(MREX はさらに雨の 20 % を蒸発散として除く)を論文がモデルの外で
  行っており、例題の比較スクリプトで同じ扱いができます。KIEX は初期条件の静水圧
  (`vz_wt0`)と下端固定圧で設定できます。
- 土層厚の「調査分布」(KI・MR の度数分布)は論文に数値がなく、線形分布だけを
  扱えます(論文でも両者の差は小さいと報告されています)。
- 圧力水頭の観測との比較(図−14(d)〜(i))。
