# qanat — カナート(カレーズ/フォガラ)の理想化ケース

管路連続体層(`f_gwconduit=1`)+層2帯水層(`f_gwlayer2=1`)で、
地下横坑の集水・導水・出口湧出を表現する。コード変更なし
(既存機能の設定のみ)。設計の背景は param.txt のヘッダを参照。

## 実行方法

```
python3 gen_data.py          # data_qanat/ を生成
../../bin/encflow param.txt  # 約 8 秒(8 時間の計算)
python3 plot_qanat.py        # qanat_result.png を生成
```

## 検証済みの結果(2026-08-23)

- S_total = 1.44202380952386 m が全期間一定(丸め 2e-14。閉領域の質量保存)
- 出口流量 Q(8h) = 6.8 L/s(実カナートの典型 1〜100 L/s 内)。
  坑道の満管化を経て t≈2.6 h から湧出が立ち上がる
- 集水部で層2水位が坑道水頭へ向けて低下(水位低下錐)、
  導水部(3 セル)で坑道→層2 の漏水損失

## 感度実験の入口

- `gw2_ksh_mmh`: 帯水層の補給能。小(360)だと水位降下で集水が
  止まり湧出しない(このケースの最初の試行で確認)
- `gwc_leak_mmh`: 坑道と帯水層の交換能 = 集水量の上限(定数レート)
- 導水部の長さ: gen_data.py の崖位置・坑道勾配で決まる。一様斜面
  (崖なし)では導水部の漏水が集水と釣り合い、出口まで水が届かない
- `gwc_cnd`(通水能)・`gwc_slot_sy`: 坑内の導水と圧力応答。
  dt 上限に効く(初期化時に dtcheck が表示)
