# sewer_wq — 下水噴出の衛生リスク(水質×管路連続体層の連携)検証ケース

sewer_hybrid のラン D(幹線+枝管・セル別 sy・降雨 60 mm/h×1h)に
水質の管路連携(wq_gwc_conc。§30 の供給側固定濃度近似)を重ねた
検証ケース。噴出・吐口から出る水を「下水 10⁶ CFU/100mL」とみなし
(単位の読み替え: g = 10⁶ CFU → wq_gwc_conc = 1e4)、T90 = 1 日の
一次減衰で大腸菌の拡散・死滅を追う。**実務手順の正本は
users_guide/wq.md「下水噴出の衛生リスク評価」**。

## 実行方法

```
# データは ../sewer_hybrid/data_sewer を参照(先に gen_data.py を実行)
../../bin/encflow param.txt
```

## 検証結果(2026-08-23)

- wq.csv の質量収支が機械精度で閉合: 投入 in_gwc = 2.633e7(単位)、
  枡再取込 to_gwc = 7.9e4、減衰 5.2e6、地表残存 2.11e7、
  残差 1.9e-2(相対 7e-10)
- 濃度場 C: 噴出域〜東側湛水域に 7〜8×10³(名目)のプルーム =
  設定濃度 1e4 の 7〜8 割(氾濫水の大半が噴出由来という水理と整合)。
  CFU/100mL 換算は C×100 → 7〜8×10⁵ CFU/100mL
- np=2,4 の全出力ファイルが逐次と一致、-fcheck=all の逐次・np=2
  クリーン完走
