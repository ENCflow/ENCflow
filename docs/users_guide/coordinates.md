# 座標系の管理

[ユーザーガイド目次へ](../users_guide.md)

ENCflow の格子は等間隔の平面直交ラスタで、座標系の扱いは
**投影座標系のスケールまで**と割り切っています(座標変換・再投影は
GIS 側の仕事です)。座標系を教えると、出力に地理参照が付いて
GIS でそのまま開けるようになります。教えなくても計算はできます
(理想化実験ではそれで十分です)。

## セル番号の規約 — 1 スタート

計測点・構造物・境界などの位置指定に使うセル番号 (i, j) は、
**どこでも 1 スタート**です(Fortran の配列添字の文化に従っています)。
i は西端の列が 1 で東向きに 1..nx、j は北端の行が 1 で南向きに
1..ny です(ラスタの行順=北→南と同じ向き。[入出力の章](io.md))。

**QGIS など GIS ソフトのラスタは行・列番号を 0 から数える**ので、
GIS 上でセル位置を拾って ENCflow に指定するときは**行・列とも +1**
してください。1セルずれの取り違えは、河道セル・堤防セルのように
「そのセルでなければ効かない」指定で気付きにくい誤りになります。

## 実座標での位置指定

計測(プローブ・フラックス測線)の位置は、セル番号の代わりに
実座標でも指定できます。**x は東向き正・y は北向き正**(投影座標系の
慣例と同じ)で、座標の解釈は自動で切り替わります。

- **地理参照があるとき**(bil+hdr / GeoTIFF 入力で格子の座標範囲が
  判明している場合)— **投影座標系の絶対座標**として解釈します。
  QGIS 上で読んだ座標をそのまま書けます。
- **地理参照がないとき**(テキスト入力・理想化実験・経緯度の便宜使用)
  — **領域南西端を (0, 0) とするローカル座標 (m)** として解釈します。

どちらで解釈されたかと解決されたセル番号は、初期化時に
`probe 1: absolute coordinates -> cell (150,150)` のように表示される
ので、必ず確認してください(取り違えはほとんどの場合、範囲外エラーで
停止します)。セル境界のちょうど上に載る座標は、丸めによって
どちら側のセルにも解決されうるので、セルの内部を指す座標を
使ってください。

## 座標系の指定方法

方法は2つあり、併用もできます。

**1. EPSG コードの指定** — `&list_geoinfo` に書きます。

```
&list_geoinfo
  epsg = 6677               ! 例: JGD2011 平面直角座標系 IX 系
  ...
```

**2. ESRI ヘッダ(.hdr)の同伴** — bil 形式の入力ファイル
(例 `dem.bil`)と同じ場所に `dem.hdr` があれば自動で読まれ、
`nx, ny, dx, dy` と原点座標が補完されます。GDAL / QGIS / ArcGIS が
bil 出力時に作る hdr がそのまま使えます。

- hdr から補完できる値は namelist で書かなくてよくなります。
  **両方指定して矛盾していれば停止**します(どちらかを黙って優先
  することはしません)。
- 動作確認済みの座標系の例: EPSG:2451(JGD2000 平面直角 IX 系)、
  6677(JGD2011 平面直角 IX 系)、6668(JGD2011 経緯度)、
  4326(WGS84 経緯度)。

## 経緯度格子(度単位のデータ)を使うとき

国土数値情報などの経緯度格子もそのまま入力できますが、格子間隔の
度→メートル換算はモデル側で行いません:

- `dx, dy`(メートル)の**明示指定が必須**です(未指定は停止)。
- 指定値は hdr の度間隔からの概算値と照合され、大きく食い違う指定は
  停止、慣習的な近似(例: 実寸 100.2 m の格子に 100 m 指定)は受理して
  両方の値を表示します。
- 経緯度格子で CRS が未指定の場合は WGS84 を仮定します(表示つき。
  `epsg` の明示が優先)。投影座標系の場合は仮定を置かず、`epsg` 未指定
  なら出力に CRS を付けません。

## 出力への地理参照

- テキスト・bil 出力には GDAL 互換の `.hdr` が併記され、GeoTIFF 出力
  には CRS(GeoKey)が埋め込まれます。QGIS / ArcGIS でそのまま
  正しい位置に表示されることを確認済みです。
- 座標を管理していない計算で GeoTIFF 出力(`f_output_mode` のビット 4)
  を指定すると、初期化時に停止します(位置情報のない GeoTIFF を
  作らないため)。テキスト・bil 出力は座標なしでも使えます。

入出力の形式そのもの(テキスト / bil / GeoTIFF の選択)は
[入出力の章](io.md) を参照してください。
