# 初期条件(&list_initial)

[ユーザーガイド目次へ](../users_guide.md)

計算開始時(t = t0)の水深・水位・流速を与えます。`fn_initial` で
有効化します。指定しなければ全域が乾いた状態(h = 0)から始まります —
降雨流出や河川流入で水を入れる計算では、それで十分なことも多いです。

```
&list_initial
  h0 = 1.0                       ! 初期水深 1 m の静水
/
```

## 水深・水位の与え方(f_htype)

| f_htype | 与え方 | 使うパラメータ |
|---|---|---|
| 0(既定) | 水深の固定値 | h0 |
| 1 | 水深の分布ファイル | fn_hinit |
| 2 | 水位の固定値(h = max(e0 − z, 0)) | e0 |
| 3 | 水位の分布ファイル | fn_hinit |

| パラメータ | 既定値 | 意味 |
|---|---|---|
| h0 | 0 | 初期水深 (m) |
| e0 | 0 | 初期水位 (m。z と同じ標高基準) |
| fn_hinit | "" | 初期水深/水位の分布ファイル(f_htype=1, 3) |
| h0_rw | 0 | 河道マスクセルへの初期水深の増分 (m)(平水の河道を濡らしておく) |
| u0 / v0 | 0 | 初期流速 (m/s)(f_uvtype=0: 一様値のみ) |
| f_fill_depres | 0 | 1: 窪地を満水にして開始(窪地の湛水を初期状態に含める) |
| f_user_routine | "" | 初期場を加工するユーザールーチン(理想化実験用) |

- 「水位」指定(f_htype=2, 3)は地形に対して水面標高を与える方式で、
  湖・貯水池・海面の初期化に向きます。水面より高い地盤は乾いたまま
  です。辺境界の長波放射(型 2)の基準水位は、水位一定の初期条件
  なら自動的に一致します([境界条件の章](boundary.md))。
- `f_fill_depres = 1` は地形の窪地をあらかじめ水で満たします。
  流出計算で「窪地が埋まるまで流出が始まらない」助走を省きたい
  ときに使います。

## ウォームアップした場を初期条件にする

パラメータで表現できる初期状態より現実的な「流れている場」から
始めたいときは、助走計算の保存状態を初期条件として読み込めます
(`f_state_restore = 2`)。平水で河道を流しておいてから洪水シナリオを
始める、といった使い方です。[中断と再開の章](restart.md)を参照して
ください。
