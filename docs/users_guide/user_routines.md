# ユーザールーチンの作り方

地形や初期条件を、ファイルではなく **数式・コードで** 与えたいとき
(理想化実験・解析解との比較・ベンチマーク)のための仕組みです。
名前で呼び出す Fortran の手続きを `src/` の 2 つのファイルに書き足して
リビルドし、パラメータファイルの `f_user_routine` で識別名を指定します。
実データを使う通常の計算では使いません(地形・マスク・初期場はすべて
ファイルで与えられます — [地理情報](geoinfo.md)・[初期条件](initial.md))。

このページは「自分のルーチンを 1 本追加して動かす」までを順に説明します。

## 2 種類のフック

| フック | ファイル | 書き換えるもの | 呼ばれる時点 | 指定する namelist |
|---|---|---|---|---|
| 地形 | `src/user_geoinfo.f90` | 標高 `g%z`、領域マスク `g%x`、海域 `g%sw`、河道 `g%rw`(必要なら粗度 `g%rn` などの物性係数も) | 地形・マスク・係数の入力ファイルをすべて読み、河道の掘り込みを終えた直後。堤防天端・海岸堤防の構築より前 | `&list_geoinfo` の `f_user_routine` |
| 初期場 | `src/user_initial.f90` | 水深 `s%h`、流速 `s%u`, `s%v`、(必要なら)計算標高 `s%z`、ため池 `s%hrs`、地下貯留 `s%hg`、浮遊砂 `s%hs` | `f_htype` 等による既定の初期場(窪地充填・河道初期水深を含む)を作った直後。帯への切り出しより前 | `&list_initial` の `f_user_routine` |

両方を同時に使えます(例: 地形フックで斜面を作り、初期場フックで孤立波を
置く — `test/nhshelf`)。

- 地形フックは **rank0 だけ** が実行し、結果(z, x, sw, rw)が全ランクへ
  配布されます(物性係数も rank0 しか持っていません)。
- 初期場フックは **全ランクが同じ計算を冗長に** 実行します。
- **リスタート(f_state_restore > 0)では初期場フックは実行されません**
  (保存された場が正本です。地形フックの結果は保存された地形に含まれて
  いるので失われません)。

## 手順(3 ステップ + ビルド)

ここでは「東が低い一様勾配の斜面」を作る地形ルーチン `my_slope` を例に
します。初期場フックも手順は同じです(ファイルとテンプレート名が違うだけ)。

### 1. テンプレートを複製して中身を書く

`src/user_geoinfo.f90` の末尾にある `geoinfo_template` を複製し、
名前を変えて実装します。

```fortran
!----------------------------------------------------------------------
! 例: 東へ下る一様勾配の斜面(西端 z = slope * lx、東端 z = 0)
!----------------------------------------------------------------------
subroutine geoinfo_my_slope(p, g)
  type(t_sysparam), intent(in) :: p
  type(t_geoinfo), intent(inout) :: g
  integer :: i, j
  real :: x
  real, parameter :: slope = 0.001
  if (p%initialized) continue  ! 引数未使用の警告を抑制(p を使わないとき)

  do j = lbound(g%z, 2), ubound(g%z, 2)
    do i = lbound(g%z, 1), ubound(g%z, 1)
      x = (i - 0.5) * g%dx            ! セル中心の x 座標(m)
      g%z(i,j) = slope * (g%lx - x)
    end do
  end do
end subroutine
```

ループ範囲を `1, g%nx` ではなく **`lbound`/`ubound`** で書く理由は
[添字の契約](#添字の契約最重要)で説明します。

### 2. 識別名を名簿に登録する

同じファイルの冒頭にある `routine_names` に識別名を追加し、配列の要素数を
1 つ増やします(snake_case。`f_user_routine` にこの文字列を書きます)。

```fortran
  character(len=*), parameter :: routine_names(1:10) = [ character(len=32) :: &
      "wave_solid_wall",  &
      ...
      "my_slope",         &   ! 追加
      "template"          ]
```

### 3. 分岐を 1 行足す

同じファイルの `resolve` の `select case` に分岐を追加します。

```fortran
    case ("my_slope")
      fp => geoinfo_my_slope
```

名簿と分岐がずれていると、実行時に「未定義の識別名」として止まります
(登録済み名の一覧がメッセージに出ます)。

### 4. ビルドして指定する

```
cd src && make
```

```
&list_geoinfo
  f_ztype = 0                 ! 地形ファイルは読まない(z0 で埋めてからフックで上書き)
  f_user_routine = "my_slope"
/
```

地形ファイルを読んだ上でフックで加工することもできます(`f_ztype = 1` と
`fn_z` を併用)。初期場フックは `&list_initial` に同様に書きます。

## 手続きの引数と使える情報

地形フックの引数は `(p, g)`、初期場フックは `(p, g, s)` です。

| 変数 | 主な成分 | 意味 |
|---|---|---|
| `p` | `p%dt`, `p%t0` など | システムパラメータ(読むだけ) |
| `g` | `g%nx`, `g%ny` | 格子数 |
| | `g%dx`, `g%dy`, `g%lx`, `g%ly` | 格子幅(m)と領域の長さ(m) |
| | `g%z(i,j)` | 標高(m)。**窓形**(下記) |
| | `g%x(i,j)` | 領域マスク(1 = 計算対象、0 = 対象外・壁)。全域 `(0:nx+1, 0:ny+1)` |
| | `g%sw(i,j)`, `g%rw(i,j)` | 海域マスク、河道マスク(1 = 該当)。全域 `(1:nx, 1:ny)` |
| | `g%rn`, `g%gv`, `g%bb`, `g%lm`, `g%rscap` | 物性係数(地形フックのみ。窓形) |
| `s` | `s%h(i,j)` | **全水深**(m。水位ではない)。窓形 |
| | `s%u(i,j)`, `s%v(i,j)` | x・y 方向流速(m/s。セル中心) |
| | `s%z(i,j)` | 計算標高(m。初期値は `g%z` の写し) |
| | `s%hrs`, `s%hg`, `s%hs` | ため池水深、地下貯留、浮遊砂(使う機能のときだけ) |

座標の約束:

- セル (i, j) の中心は `x = (i − 0.5) * dx`、`y = (j − 0.5) * dy`。
- **i=1 が西端、i=nx が東端、j=1 が北端(ラスタの上端)、j=ny が南端**です。
  ファイルの行の並びと同じで、y は南向きに増えます。
- 水位 η を与えたいときは水深に直します: `s%h(i,j) = max(eta - s%z(i,j), 0.0)`。

## 添字の契約(最重要)

フックの中では **全域添字**(ファイルの行・列番号と同じ i, j)で配列を
読み書きします。ただし **配列の確保範囲は全域とは限りません**。

ENCflow は領域マスク(`fn_mask`)から計算対象の **窓**(有効セルを含む
行・列の範囲)を決め、標高・物性係数・初期場の配列をその窓±2 セルの
範囲だけ確保します(全域格子に小さなマスクを置く運用のメモリを窓の面積に
比例させるため — developer.md §82)。添字は全域のままなので、
`g%z(i,j)` の i, j の意味は変わりませんが、**窓の外の (i, j) は確保されて
いません**。

したがって:

- ループは **`lbound(g%z, 1)` 〜 `ubound(g%z, 1)`、`lbound(g%z, 2)` 〜
  `ubound(g%z, 2)`**(初期場フックでは `s%h`)で回します。
  窓が全域のとき(マスクなし `f_masktype = 0`、または全域が有効)は
  `1 〜 nx`, `1 〜 ny` と同じ値になるので、理想化実験では見た目も結果も
  変わりません。
- `do i = 1, g%nx` と書くと、窓が全域でないケースで配列の範囲外を書き、
  黙って壊れるか(デバッグビルドでは)停止します。
- 特定のセルに書くとき(壁を置く等)も、その (i, j) が確保範囲に入って
  いることを確かめてから書きます(`if (i >= lbound(g%z,1) .and. ...)`)。
- マスク類 `g%x`, `g%sw`, `g%rw` は **全域配列** です。これらは全域添字で
  自由に読めます。

### マスクを書き換えるとき

地形フックで `g%x` を書き換えて壁(x = 0)を置くことはできます
(`wave_solid_wall` が例)。逆に、**窓の外のセルを有効(x = 1)にすることは
できません**。その範囲の標高・係数はファイルから読んでいないためで、
本体が次のメッセージで停止します。

```
geoinfo: user routine my_walls made cells valid outside the window read from the domain mask (...); extend the domain mask (fn_mask) to cover them instead
```

有効にしたいセルは、マスクファイル側で有効にしてください。

## 守ること・落とし穴

- **地形フックの中で `par_stop` を呼ばない。** rank0 だけが実行するので
  全ランク同期の `par_stop` は成立しません。エラーで止めるときは
  `par_abort`(メッセージ付き)を使います。初期場フックは全ランク実行
  なので `par_stop` でも構いません。
- **宣言と同時の初期化(`real :: pi = 3.14`)は暗黙 SAVE** になります。
  値が不変の定数なら `parameter`、計算する値なら実行文で代入します
  (`pi = acos(-1.0)`)。
- 海域(`g%sw > 0`)の標高は、入力時に 0 に強制されています。フックで
  海域の z を書き換えるとその値が使われます(意図していないなら触らない)。
- 水深は負にしない(`max(…, 0.0)`)。初期場フックの既定の場を「上書き」
  するか「加算」するかを決めて書く(`wave_hump` は加算: `s%h = max(s%h + η − z, 0)`)。
- フックは入力ファイルの読み込みと検証の **後** に動きます。フックで
  マスクを変えても、プローブや境界の位置検証はフック後に行われるので
  整合します(窓の外を有効にする変更だけが不可)。
- 単位は m・m/s・秒。パラメータファイルの値が必要なら `p` の成分を読みます
  (独自の数値を渡したいときは、ルーチン内の `parameter` か、識別名を分けて
  複数のルーチンにします — `wave_solitary28_toe` のように)。

## 確かめ方

- 小さな格子で短時間走らせ、`Z0000`(標高)・`H0000`(初期水深)を
  図化して意図どおりか確かめます([入出力の形式](io.md))。
- デバッグビルド(`make.inc` の `-fcheck=all` 付き FFLAGS)で 1 回走らせる
  と、範囲外アクセスをその場で検出できます。
- 見本: 地形は `shelf_slope`(斜面と棚)、`gaussian_hill`(解析解
  ベンチマーク)、`wave_solid_wall`(マスクの壁)。初期場は `wave_hump`
  (既定の場に加算)、`dambreak_step`(段差)、`solitary_profile`
  (sech² 孤立波。複数の識別名が同じ本体を呼ぶ例)。それぞれ `test/` の
  ケース(`nhshelf`, `creep`, `wave`, `dambreak`, `nhsolitary`)で動いています。
