# 貯留関数法の区画流出(fn_sfm)

[ユーザーガイド目次へ](../users_guide.md)

山地や小流域の降雨流出応答を、**貯留関数法**(流域を 1 つのタンクとみなし、
貯留量と流出量の関係 S = K·q^P で流出を追跡する方法。木村 1961[^kimura1961])で
求める機能です。[鉛直不飽和浸透(VZ)流出](vz.md)と同じ組み立てで、ENCflow の
格子の上で次の 3 つの部品として扱います。

- **区画**: 区画番号ラスタで同じ番号を持つセル群です。区画ごとに 1 つの
  **タンク**(貯留関数)を持ち、区画のすべてのセルの雨がそのタンクに入ります。
  VZ の土層厚のようなセルごとの量はなく、**同じ区画のセルはすべて同じ流出**
  (単位面積あたり)になります。
- **タンク**: 単位面積あたりの貯留 S と流出強度 q の関係 S = K·q^P(S は mm、
  q は mm/h)と連続の式 dS/dt = r − q を解きます。
- **出口**: 区画の流出を地表セル(河道・谷底など)へ移すか、系外へ出すかを
  明示します。区画から出口への移動の遅れは解きません(**瞬間的な受け渡し**)。
  出口の指定と基底流の与え方は VZ と同じです。

貯留関数法は流域の応答を 2 つのパラメータ K・P に集約した**概念的なモデル**で、
流域の中のどこで流出が生じるかは表しません。K・P は流域ごとに観測で校正する量です。
谷の一連の研究は、貯留関数の貯留量と流出量の関係が斜面の土壌層の鉛直浸透を近似して
いることを論じています(VZ 流出との関係)。浅水流・河道とはつながっているので、
山地を貯留関数の区画、河道と氾濫原を地表流で解く、という組み合わせができます。
区画にしなかったセル(区画番号 0)は従来どおりです。VZ と区画が重ならなければ、
同じ計算で一部の区画を VZ、他を貯留関数にすることもできます。設計の経緯と決定は
developer.md §106 にあります。

## 有効化と設定

`&list_sysparam` で `fn_sfm` を指定します(`"-"` なら同じパラメータ
ファイル)。設定は 2 つのグループです。

```
&list_sfm                   ! 共通設定
  fn_sfm_zone = 'zone.asc'  ! 区画番号ラスタ(整数。0 = 適用外)
/
&list_sfm_zone              ! 区画(区画番号で添字)
  sfm_k(1) = 30.0           ! 貯留係数 K(S [mm] = K·q[mm/h]^P)。必須
  sfm_p(1) = 0.6            ! 貯留指数 P(省略時 0.6)
  sfm_q0_mmh(1) = 0.1       ! 初期の流出強度 (mm/h。省略時 0.1)
  sfm_out_kind(1) = 1       ! 出口 1: 地表セルへ移す / 2: 系外へ出す
  sfm_out_cell(:,1,1) = 120, 80   ! 出口セル (i, j)
/
```

例の K は形を示すための値です。K は流域ごとに桁で変わるので、必ず与えます
(下の[パラメータと既定値の根拠](#パラメータと既定値の根拠))。`f_sfm = 0` で書いたまま
一時無効化できます。区画番号は 1, 2, … の連番で、`sfm_out_kind` と `sfm_k` は区画ごとに
必ず与えます。

## とりあえず動かしてみる(最小入力)

必要なのは次の 3 つです。

1. **区画番号ラスタ** `fn_sfm_zone`(`dir_data` 下。地形と同じ格子)。
   貯留関数にするセルに 1 以上の番号、それ以外に 0。
2. **貯留係数** `sfm_k`(区画ごと)。**既定値はありません**(流域ごとの校正量です)。
3. **出口** `sfm_out_kind`(と `sfm_out_cell`)。

貯留指数 `sfm_p` を省略すると 0.6、初期の流出強度 `sfm_q0_mmh` を省略すると
0.1 mm/h を使い、採用した値を画面に `(default)` を付けて表示します。

降雨は[降雨・気象](forcing.md)のとおりに与えます。小流域の流出量だけを
見たいときは、流域の全セルを 1 区画にして `sfm_out_kind = 2`(系外流出)と
すれば、区画の流出がそのまま流出量です(`sfm_zone.csv`)。

**使い方の型**

| 型 | 構成 | 見るもの |
|---|---|---|
| 山地小流域の流出量 | 流域全体を 1 区画、`sfm_out_kind = 2` | `sfm_zone.csv` の q(流出強度 mm/h)、vdrain の時間差分 = 流出量。観測から分離した基底流を加えるときは区画に基底流を与える(下の[基底流](#基底流)) |
| 山地は貯留関数、河道は浅水流 | 支谷ごとに区画を分け、出口を支谷の出口の河道セルに置く(`sfm_out_kind = 1`) | 河道の流量(計測の測線)。河道の伝播の遅れは浅水流が解く |
| 雨に空間分布がある | `f_sfm_rain = 1`(区画内の面積平均) | 区画の入力は区画内の平均雨量(下の[雨の扱い](#雨の扱い)) |
| VZ 流出と比べる | 同じ雨で一部の区画を VZ、他を貯留関数に(区画を重ねない) | `vz_zone.csv` と `sfm_zone.csv` の流出 |

## 計算のしくみ

### タンク(貯留関数)

区画 g のタンクは、単位面積あたりの貯留 S [mm] と流出強度 q [mm/h] について

```math
\frac{dS}{dt} = r(t) - q,
\qquad
S = K\,q^{P}
```

を解きます(r は区画に降った地上雨量)。K の単位は S と q の単位に合わせた
mm^{1−P}·h^P です(P = 1 なら K は時間 [h] で、線形貯留の時定数)。貯留が増えると
流出が増え、応答の時間の目安は dS/dq = K·P·q^{P−1} です(流出が大きいほど速く
応答します)。

P = 0.6 は貯留関数法で標準的に使われてきた値です[^kimura1961]。一様な斜面の定常な
面状流を Manning 則の運動波で表すと、水深は流下距離の 3/5 乗に比例し、斜面の平均
水深(単位面積の貯留)は流出強度の 3/5 乗に比例します(S ∝ q^{0.6})。P = 0.6 は
この関係に当たります(この導出は本ガイドの説明)。

雨はすべてタンクに入り、損失はありません。木村の方法の完全形にある**遅れ時間 T_L**と、
**一次流出率 f1・飽和雨量 R_sa による有効雨量の分離**(雨の一部を流出に寄与しない
損失とする)、**2 価の貯留関数**(Prasad 型・星・山岡型)は持ちません
([適用範囲と併用の制限](#適用範囲と併用の制限))。

数値解法は後退 Euler(スカラーの Newton 法を区間の二分法で保護)で、内部の時間刻みは、
同じ状態から「刻み h で 1 歩」と「h/2 で 2 歩」を解いた貯留の差で自動調整し、受理した
歩は局所外挿(2 次精度)を採ります(この組み合わせは ENCflow 独自の選択)。流出量を
「前の貯留 + 雨 − 新しい貯留」で定義するので、タンクの水収支は丸めを除いて閉じます。
時間精度は [検証](#検証例題) の解析解・参照解との比較で確かめています。

### 雨の扱い

区画セルに降った雨は、浅水流が通常どおりいったん地表に入れたあと、同じ
ステップのうちに回収してタンクの入力にします(VZ と同じ方式。浅水流・降雨の処理は
変わりません。土壌雨量指数など地上雨量を読む機能もそのまま使えます)。
取り除くのはそのステップの雨の分だけなので、区画セルの地表水は**上流から
流れ込んだ分だけ**になり、それはタンクに入りません(地表流としてそのまま流れます)。

タンクの入力は、`f_sfm_rain` で 2 通りから選びます。

- `f_sfm_rain = 0`(既定): 区画のセルの地上雨量が**一致する**ことを毎回検査し、
  その値を使います。違えば停止します(雨の分布があるなら 1 を選ぶか、雨が一様な
  範囲で区画を分けます)。
- `f_sfm_rain = 1`: 区画の全セルの**面積平均**を使います。雨量の総量は保存されますが、
  「平均入力への置換」という近似です。流域平均雨量で流出を計算する貯留関数法の
  ふつうの使い方と同じ考え方です。

### 出口

`sfm_out_kind = 1` は区画の流出を `sfm_out_cell` のセルへ移します(雨や境界の
湧き出しと同じ換算で地表水深に加えます)。複数セルなら `sfm_out_w` の比で
分けます(和は 1。1 セルなら省略可。暗黙の等分配はしません)。複数区画が
同じセルを出口にしてもよく、加算は一度だけです。出口は区画セル・海セル・
水位規定の境界セルに置けません(VZ と併用するときは VZ のセルにも置けません)。

`sfm_out_kind = 2` は系外流出です(受水セルは不要)。大流域の末端へ直接
送ると河道の遅れまで省略することになるので、広域の計算では山地区画の
出口を支谷の出口の河道セルに置き、その先は浅水流に任せます。

### 基底流

区画ごとに基底流の時系列を与えられます(省略可)。与え方と扱いは VZ と同じです
([VZ の基底流](vz.md#基底流))。

```
&list_sfm_zone
  sfm_out_kind(1) = 2
  sfm_base(:,1,1) = 0, 0.1          ! (時刻(分), 基底流 (mm/h))
  sfm_base(:,2,1) = 1440, 0.5
  !fn_sfm_base(1) = 'base1.txt'     ! 長い系列はファイルで(1 行「時刻(分) mm/h」)
/
```

- 強度は**区画面積あたりの mm/h** です。時系列は線形補間し、範囲外は端の値を保持
  します(同じ時刻に 2 点を置くと段差)。時刻が減る系列と負の値は停止します。
  namelist は 1 区画 100 点までで、長い系列は `fn_sfm_base(z)`(`dir_data` 起点。
  namelist より優先)にします。
- 同期区間ごとに区間の積分 × 区画面積を流出に加えて出口へ渡します。基底流は外から
  与える量で、タンクの貯留と収支残差には入りません。`sfm_out_kind = 1` の基底流は
  S_total を増やし、`= 2` の基底流は系外から系外へ出るので S_total に現れません。
- 基底流の分離(どの線を引くか)は利用者の前処理です。

### 同期と時間刻み

タンクは `dt_sfm` ごとに、その区間の各ステップの雨を区分一定の入力として進め、
区間の流出を区間末にまとめて出口へ渡します(未来の雨は使いません)。既定の
`dt_sfm = 0` は毎ステップです。タンクは区画ごとに 1 つの値なので、毎ステップでも
費用は無視できます。

## 出力・確認

**台帳・ログ**

- Log の **S_grnd にタンクの貯留を算入**します(区画の Σ S·A を全セル数で割った
  柱状換算。回収済みで次の同期を待つ雨も含みます)。S_total の保存を見れば
  タンクを含む全体の水収支を確かめられます。系外流出(`sfm_out_kind = 2`)の分だけ
  S_total は減ります。タンクの貯留は地下水の `hg` とは別の量で、Hg の分布出力には
  入りません。

**時系列**(`result/`。`dt_recrd` 間隔。直近の同期時刻の値)

| ファイル | 内容 |
|---|---|
| sfm_zone.csv | 区画ごとの rain(直近ステップの雨 mm/h)、q(流出強度 mm/h)、S(貯留 mm)と、累積水量 (m³): vin(雨 × 区画面積)、vstore(現在の貯留)、vdrain(区画の流出)、vsurface(地表セルへの移送)、vexternal(系外流出)、residual(収支残差 = vstore − vstore₀ − vin + vdrain)。基底流を与えた区画があれば最後の列に vbase が加わり、vsurface・vexternal は流出 + 基底流になります |

区画の流出量 [m³/s] は q × 区画面積 / 3.6×10⁶、または vdrain の時間差分を記録間隔で
割って求めます。residual は丸め規模(入力の 10⁻¹² 程度)であることを確かめてください。

**画面**: 初期化時に区画確認表(区画ごとのセル数・面積・K・P・初期の q と S・出口と
配分率・基底流の点数と最初・最後の値)を表示します。

**再開**: タンクの貯留・内部刻み・累積の診断量(基底流を含む)・出口の繰越を
`sfm.dat` に保存・復元します。同期時刻(`dt_sfm` の倍数のステップ)で保存すると再開後の
計算は連続計算とビット一致します。区間の途中で終わる計算を保存するときは、
残りを同期してから保存します(回収済みの雨は捨てません)。再開時に fn_sfm を
外すと、`sfm.dat` が残っていれば停止します(タンクの貯留を黙って捨てないため)。
区画・K・P・出口の構成が保存時と違っても停止します。

## 適用範囲と併用の制限

初版で**併用できない機能**(指定すると初期化で停止): 地下水(`fn_gwflow`)・
積雪(`fn_snow`)・氷河(`fn_glacier`)・地形変化(`fn_geomorph`)・水質(`fn_wq`)・
淡塩 2 層(`fn_salt`)・ネスティング・STG 格子(VZ と同じ)。
**VZ 流出(`fn_vz`)とは併用できます**。ただし、区画のセルが重なる構成と、一方の出口が
他方の区画セルにある構成は初期化で停止します。

**区画セルに置けないもの**: 河道(fn_rw)・海域(fn_sw)・境界条件・湧き出し・
構造物のセル。

**できないこと・精度の限界**

- 遅れ時間 T_L・有効雨量の分離(f1・R_sa)・2 価の貯留関数を持ちません。立ち上がりの
  遅れやヒステリシス(同じ流量で増水期と減水期の貯留が違うこと)は表せません。
- 雨はすべてタンクに入り、いずれ流出します。蒸発散・深部浸透による損失はなく、
  長期の計算では流出の総量が過大になります(イベント計算向け)。
- 区画の中のどこで流出が生じるか(寄与域)を表しません。区画の流出は出口へ瞬間的に
  移り、出口が浸水しても妨げられません(背水は解きません)。
- 区画セルに上流から流れ込んだ地表水はタンクに入りません(一方向)。
- K・P は流域ごとの校正量です。もっともらしいハイドログラフが得られても、観測との
  比較なしに流出量の予測として使うことはできません。
- 計算中に止まる状態: 負の入力(雨)、内部刻みが `sfm_dt_min` を下回る(通常は
  起こりません)。P は 0 < P ≤ 1 に限ります。

## パラメータと既定値の根拠

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

**&list_sfm**

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| f_sfm | 1 | 0 で一時無効化 | **方式** |
| fn_sfm_zone | — | 区画番号ラスタ(整数。0 = 適用外) | **与件** 必須 |
| dt_sfm | 0 s | タンクを進める同期間隔(0 = 毎ステップ) | **数値設定** タンクはスカラーで費用が無視できるため毎ステップ |
| f_sfm_rain | 0 | 0: 区画内の雨量の一致を要求 / 1: 区画内の面積平均 | **方式** 一致しなければ停止して知らせる側を既定に |
| sfm_tol | 1e-4 | 内部刻みの時間誤差の相対許容(流出強度に対する比) | **検証ケース** [test/sfzone](../../test/sfzone/) で、毎ステップ同期の貯留が参照解と相対 3×10⁻⁷ 以内、`dt_sfm = 60` s で 1.5×10⁻⁵ |
| sfm_dt_min | 0.001 s | 内部刻みの下限(下回ると停止) | **数値設定** |

**&list_sfm_zone**(区画番号 z で添字。最大 50 区画)

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| sfm_k(z) | なし | 貯留係数 K(S [mm] = K·q[mm/h]^P。単位 mm^{1−P}·h^P) | **校正量** 必須。流域ごとに桁で変わる |
| sfm_p(z) | 0.6 | 貯留指数 P(0 < P ≤ 1。1 = 線形貯留) | **慣用値** 貯留関数法で標準的に使われてきた値[^kimura1961]。Manning 則の運動波の定常解の S ∝ q^{0.6} に当たる([タンク](#タンク貯留関数)) |
| sfm_q0_mmh(z) | 0.1 mm/h | 初期の流出強度。初期の貯留は S0 = K·q0^P(0 は乾いた状態) | **経験値** 降雨前の流出率の目安(VZ の `vz_q0_mmh` と同じ) |
| sfm_out_kind(z) | なし | 出口 1: 地表セル / 2: 系外 | **与件** 必須 |
| sfm_out_cell(1:2, k, z) | なし | 出口セル (i, j)(最大 99) | **与件** sfm_out_kind = 1 で必須 |
| sfm_out_w(k, z) | 1(1 セル) | 出口の配分率(和 1) | **与件** 複数セルなら必須 |
| sfm_base(1:2, k, z) | なし(基底流なし) | 基底流の時系列(時刻(分), mm/h。区画面積あたり。最大 100 点) | **与件** 観測から分離した値など(利用者の前処理) |
| fn_sfm_base(z) | なし | 基底流の時系列ファイル(1 行「時刻(分) mm/h」。sfm_base より優先) | **与件** |

**既定値を見直すときの手がかり**

- **K は観測のハイドログラフで校正します**。応答の時間の目安 K·P·q^{P−1}(h)が流域の
  ピークの遅れや逓減の速さに合うように選ぶのが出発点です。K を 2 倍にすると、同じ流出
  強度での応答の時間も 2 倍になります。
- P を変えると、流出の大きさによる応答の速さの違いが変わります(P が小さいほど、大きい
  出水で速く、小さい出水で遅く応答します)。P = 1 は流出によらず一定の時定数 K [h] の
  線形貯留です。
- 初期の流出強度 `sfm_q0_mmh` は最初の降雨への応答に効きます。降雨前の観測流量があれば
  それを区画面積で割った値を与えます。長期のスピンアップをして保存し、再開を初期値に
  する方法もあります([中断と再開](restart.md))。
- 時間誤差の許容 `sfm_tol` を 1/10 にして結果が変わらないことを確かめるのが、数値精度の
  簡単な確認方法です。

## 検証・例題

- [test/sfzone](../../test/sfzone/): 区画 3 つ(P = 0.6・1・0.4)・複数出口と共有の受水セル・
  系外流出。区画の入力 = 面積 × 雨、線形貯留(P = 1)の貯留 = 厳密解(相対 3×10⁻⁷)、
  P = 0.6・0.4 の貯留と流出強度 = 細かい刻みの RK4 の参照解(相対 10⁻⁷ 程度)、雨の後の
  逓減 = 解析解、一定の雨での定常 q → r と S = K·r^P、受水セルの水深 = 配分どおりの移送 + 雨、
  S_total の収支、雨の分布と面積平均、厳密モードの停止、基底流、既定値の表示、同期間隔
  `dt_sfm = 60` s、保存 → 再開の一致(同期区間の途中を含む)、VZ との併用と区画の重なりの
  停止を `Check_sfzone.py` で検定。
- MPI の並列数によらず結果はビット一致します(タンクは全ランクで同じ計算をし、
  出口への加算だけを所有ランクが行います)。
