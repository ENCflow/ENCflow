# 鉛直不飽和浸透(VZ)流出(fn_vz)

[ユーザーガイド目次へ](../users_guide.md)

山地斜面の降雨流出応答を、**鉛直不飽和浸透**(土壌を鉛直に浸みていく水の
圧力の伝わり方)から求める機能です。谷(2023)の VZ 流出モデル[^tani2023]を、
ENCflow の格子の上で次の 3 つの部品として扱います。

- **共有参照柱**: 十分深い 1 本の土壌柱(既定は深さ 10 m・層厚 2.5 cm)で、
  小杉式[^kosugi1996]の保水・透水特性を持つ 1 次元 Richards 式を解きます。
  解は単位面積当たりで、複数のセルが同じ柱を参照します(セルごとに鉛直の
  格子を持ちません)。
- **VZ 区画**: 区画番号ラスタで同じ番号を持つセル群です。各セルの
  **土層厚の深さで、参照柱の下向きの流束を読み出し**、区画で面積積分した
  ものを区画の排水とします(土層厚の分布が応答の違いを生みます)。
- **出口**: 区画の排水を地表セル(河道・谷底など)へ移すか、系外へ出すかを
  明示します。区画から出口への移動の遅れは解きません(**瞬間的な直接排水**)。

この直接排水は、側方の地下流の遅れと波形の変換を**省略した近似**です。
降った雨水の粒子がすぐ出口に着くという意味ではありません(流出量の応答が
速いことと水の移動が速いことは別です)。原モデルの考え方は、土壌と基岩の
境界付近の水みちによる効率的な排水が地下水位の変化を抑えるので、鉛直の
不飽和浸透が流出応答を支配する、というものです[^tani2023]。この前提が成り
立たない場所(側方の遅れや深部損失が大きい場所)では、結果をそのまま使えません。

浅水流・河道とはつながっているので、山地を VZ 区画、河道と氾濫原を地表流で
解く、という組み合わせができます。区画にしなかったセル(区画番号 0)は従来
どおりです。設計の経緯と ENCflow 側の決定は developer.md §87 と
docs/vz_plan.md にあります。

## 有効化と設定

`&list_sysparam` で `fn_vz` を指定します(`"-"` なら同じパラメータ
ファイル)。設定は 3 つのグループです。

```
&list_vz                    ! 共通設定
  fn_vz_zone = 'zone.asc'   ! 区画番号ラスタ(整数。0 = 適用外)
  dt_vz = 60.0              ! 柱を進める同期間隔 (s。0 = 毎ステップ)
/
&list_vz_column             ! 共有参照柱(柱番号で添字。省略すると試算用の既定)
  vz_ks_mmh(1) = 180.0      ! 飽和透水係数 (mm/h)
  vz_thetas(1) = 0.370      ! 飽和含水率
  vz_thetar(1) = 0.230      ! 残留含水率
  vz_psim(1) = -0.200       ! 小杉式の ψm (m。負)
  vz_sigma(1) = 1.60        ! 小杉式の σ
  vz_q0_mmh(1) = 0.1        ! 初期条件: 定常重力排水の流束 (mm/h)
/
&list_vz_zone               ! 区画(区画番号で添字)
  vz_zone_col(1) = 1        ! 参照する柱(省略時は区画番号と同じ)
  vz_out_kind(1) = 1        ! 出口 1: 地表セルへ移す / 2: 系外へ出す
  vz_out_cell(:,1,1) = 120, 80   ! 出口セル (i, j)
/
```

例の柱の値は試算用の既定と同じです(谷(2023)の竜ノ口山の土壌。下の
[パラメータと既定値の根拠](#パラメータと既定値の根拠))。実際の検討では地点の値に
置き換えます。`f_vz = 0` で書いたまま一時無効化できます。区画番号は 1, 2, … の連番で、
番号ごとの設定がなくても `vz_zone_col` は区画番号と同じ柱になります。
`vz_out_kind` は区画ごとに必ず与えます。

## とりあえず動かしてみる(最小入力)

必要なのは次の 3 つです。

1. **区画番号ラスタ** `fn_vz_zone`(`dir_data` 下。地形と同じ格子)。
   VZ にするセルに 1 以上の番号、それ以外に 0。
2. **土層厚** — `&list_geoinfo` の `f_sdtype` / `sd0` / `fn_sd`
   ([地理情報](geoinfo.md))。VZ セルの土層厚は、その深さで参照柱の流束を
   読み出す深さです。**既定値はありません**(地点の与件です)。斜面に
   垂直に測った土層厚は、前処理で鉛直の深さに換算して与えます。
3. **出口** `vz_out_kind`(と `vz_out_cell`)。

**柱の設定(`&list_vz_column`)は省略できます**。省略すると試算用の既定を
使い、採用した値を画面に `(default)` を付けて表示します。小杉パラメータ
(`vz_ks_mmh`・`vz_thetas`・`vz_thetar`・`vz_psim`・`vz_sigma`)は谷(2023)の
竜ノ口山の土壌の組、初期条件は降雨前の流出率 0.1 mm/h の定常重力排水
(`vz_q0_mmh`)です。試算用の値は地点の土壌を表すものではないので、実際の
検討では地点の値を与えてください(下の[パラメータと既定値の根拠](#パラメータと既定値の根拠))。
小杉パラメータは 5 つ全部を与えるか全部を省略します(一部だけの指定は、別の土壌の
値が混ざるのを防ぐため停止します)。区画が参照する柱の設定を省略したときも、
その柱は試算用の既定になります。

降雨は[降雨・気象](forcing.md)のとおりに与えます。小流域の流出量だけを
見たいときは、流域の全セルを 1 区画にして `vz_out_kind = 2`(系外流出)と
すれば、区画の排水がそのまま流出量です(`vz_zone.csv`)。

**使い方の型**

| 型 | 構成 | 見るもの |
|---|---|---|
| 原モデルの再現(山地小流域の流出量) | 流域全体を 1 区画、柱 1 本、`vz_out_kind = 2`、`dt_vz = 60` | `vz_zone.csv` の vdrain の時間差分 = 流出量。観測の基底流は比較図の側で扱う(モデルに足さない) |
| 山地は VZ、河道は浅水流 | 支谷ごとに区画を分け、出口を支谷の出口の河道セルに置く(`vz_out_kind = 1`) | 河道の流量(計測の測線)。河道の伝播の遅れは浅水流が解く |
| 土層厚の分布の影響 | 同じ柱を複数区画で共有(`vz_zone_col` を同じ番号に) | 区画ごとの応答の違い = 土層厚の分布の違い |
| 雨に空間分布がある | `f_vz_rain = 1`(柱内の面積平均) | 区画の入力は柱内の平均雨量(下の[雨の扱い](#雨の扱い)) |

## 計算のしくみ

### 共有参照柱(1 次元 Richards 式)

地表から鉛直下向きの深さ ζ、下向きを正とする流束 f について

```math
\frac{\partial \theta(\psi)}{\partial t} = -\frac{\partial f}{\partial \zeta},
\qquad
f = K(\psi)\left(1 - \frac{\partial \psi}{\partial \zeta}\right)
```

を解きます(ψ は圧力水頭 [m]、不飽和で負)。保水・透水特性は小杉式[^kosugi1996]です。

```math
x = \frac{\ln|\psi| - \ln|\psi_m|}{\sigma},\quad
Q(x) = \tfrac12\mathrm{erfc}\!\left(\frac{x}{\sqrt2}\right),\quad
\theta = \theta_r + (\theta_s - \theta_r)\,Q(x),\quad
K = K_s\,Q(x)^{1/2}\,Q(x+\sigma)^2
```

(ψ ≥ 0 では θ = θs、K = Ks)。Kosugi (1996) の式 (14)・(20)(ψ = 0 で飽和する
2 パラメータ形。透水係数は Mualem の式で S_e^{1/2} の形)で、ψm は有効飽和度
S_e = (θ − θr)/(θs − θr) が 0.5 になる圧力水頭(間隙径分布の中央値に対応)、
σ は ln|ψ| の分布の標準偏差です。上端は**地上雨量を流束として与え**、下端は
**自由排水**(単位動水勾配 f = K(ψ))です。

離散化は有限体積(層の平均含水率と界面の流束)と後退 Euler で、含水率の差で
書いた保存形の残差を収束判定に使い(Celia ら 1990[^celia1990] の混合形。
有限体積への展開は ENCflow 独自)、修正 Picard 反復と三重対角の解法で解きます。
内部の時間刻みは、同じ状態から「刻み δt で 1 歩」と「δt/2 で 2 歩」を解いて
含水率・圧力水頭・**全界面の積算流束**の差が許容内なら細かい側を採用する
方式(ステップ二分比較)で自動調整します。水収支が閉じることと、流束の
時間精度が十分なことは別に確かめています([検証](#検証例題))。

### 区画の読み出しと排水

セル i の土層厚 d_i が界面 ζ_j と ζ_{j+1} の間にあるとき、
α = (d_i − ζ_j)/Δζ として

- 排水(積算水量)D_i = (1−α) F_j + α F_{j+1}
- 貯留 S_i = (1−α) B_j + α B_{j+1}(B_j は深さ ζ_j までの θ の積分)

を**同じ係数**で読みます。このため各セルで ΔS_i = F_0 − D_i(F_0 は上端の雨)が
構造的に成り立ちます。区画の排水は面積積分 Σ A_i D_i で、初期化時に作った
深さの重みを使うので、時間ループではセルを走査しません。

参照柱は「その区画を代表する単位面積当たりの解」です。柱の d_i より深い
部分の水は流域の貯留として数えません。土層厚が違うセルが同じ柱を共有できる
のは、深さの違いを「同じ解をどこで読むか」で表すからです。逆に、土層の物性・
初期状態・雨の履歴が違う場所は柱を分けます。

### 雨の扱い

VZ セルに降った雨は、浅水流が通常どおりいったん地表に入れたあと、同じ
ステップのうちに VZ が回収して柱の上端流束にします(浅水流・降雨の処理は
変わりません。土壌雨量指数など地上雨量を読む機能もそのまま使えます)。
取り除くのはそのステップの雨の分だけなので、VZ セルの地表水は**上流から
流れ込んだ分だけ**になり、それは回収しません(VZ セルへの再浸透は解かず、
地表流としてそのまま流れます。上流からの流入がなければ VZ セルは乾いたままです)。

柱の上端流束は、`f_vz_rain` で 2 通りから選びます。

- `f_vz_rain = 0`(既定): 柱を参照するセルの地上雨量が**一致する**ことを
  毎回検査し、その値を使います。違えば停止します(雨の分布があるなら
  1 を選ぶか、雨が一様な範囲で区画と柱を分けます)。
- `f_vz_rain = 1`: 柱を参照する全セルの**面積平均**を使います。雨量の総量は
  保存されますが、「平均入力への置換」という近似です(平均雨量に対する応答と、
  各セルの応答の平均は一般に一致しません)。原モデルが流域平均雨量で参照柱を
  駆動するのと同じ考え方です。

### 出口

`vz_out_kind = 1` は区画の排水を `vz_out_cell` のセルへ移します(雨や境界の
湧き出しと同じ換算で地表水深に加えます)。複数セルなら `vz_out_w` の比で
分けます(和は 1。1 セルなら省略可。暗黙の等分配はしません)。複数区画が
同じセルを出口にしてもよく、加算は一度だけです。出口は VZ セル・海セル・
水位規定の境界セルに置けません。

固定比率で複数の出口に分けると、各出口の波形は振幅が違うだけの同じ形に
なります。支谷ごとの応答の違いを見たいときは、区画を分けてください
(柱は共有してかまいません)。

`vz_out_kind = 2` は系外流出です(受水セルは不要)。大流域の末端へ直接
送ると河道の遅れまで省略することになるので、広域の計算では山地区画の
出口を支谷の出口の河道セルに置き、その先は浅水流に任せます。

### 同期と時間刻み

柱は `dt_vz` ごとに、その区間の各ステップの雨を区分一定の入力として進め、
区間の排水を区間末にまとめて出口へ渡します(地下水の `dt_gwflow` と同じ
間引きです。未来の雨は使いません)。`dt_vz = 60` s 程度なら、柱を進める
費用は浅水流に比べて小さく、出口への受け渡しの粗さも山地の応答時間
(数十分〜数時間)に比べて無視できます。`dt_vz = 0` は毎ステップで、
費用は 1 柱あたり 1 ステップに後退 Euler 3 回以上になります。

## 出力・確認

**台帳・ログ**

- Log の **S_grnd に VZ 貯留を算入**します(区画の Σ A_i S_i を全セル数で
  割った柱状換算。回収済みで次の同期を待つ雨も含みます)。S_total の保存を
  見れば VZ を含む全体の水収支を確かめられます。系外流出(`vz_out_kind = 2`)
  の分だけ S_total は減ります。VZ 貯留は地下水の `hg` とは別の量で、
  Hg の分布出力には入りません。

**時系列**(`result/`。`dt_recrd` 間隔)

| ファイル | 内容 |
|---|---|
| vz_zone.csv | 区画ごとの累積水量 (m³): vin(柱の上端入力 × 区画面積)、vstore(現在の VZ 貯留)、vdrain(区画の排水)、vsurface(地表セルへの移送)、vexternal(系外流出)、vcorr(丸め規模の負の排水を 0 にした補正)、residual(収支残差 = vstore − vstore₀ − vin + vdrain − vcorr) |
| vz_column.csv | 柱ごとの直近の上端流束 (m/s)、累積の上端入力 F0・下端流束 (m)、`vz_out_depth` の各深さの累積排水 D と貯留 S (m)、内部刻みの診断(受理数・棄却数・反復数・直近の刻み) |
| vzprof_<柱>_<番号>.csv | `f_vz_outprof = 1` のとき、分布出力の時刻(`dt_file`)ごとの柱の鉛直分布(層中心の ψ・θ・K と、層の下面の累積流束) |

区画の流出量 [m³/s] は vdrain の時間差分を記録間隔で割って求めます。
residual は非線形反復の残差の集積で、`vz_mb_rate` × 経過時間 × 面積より
十分小さいことを確かめてください。

**画面**: 初期化時に区画確認表(区画ごとのセル数・面積・土層厚の最小/平均/
最大・出口と配分率)を表示します。

**再開**: 柱の状態(ψ)・内部刻み・累積の診断量・出口の繰越を `vzflow.dat` に
保存・復元します。同期時刻(`dt_vz` の倍数のステップ)で保存すると再開後の
計算は連続計算とビット一致します。区間の途中で終わる計算を保存するときは、
残りを同期してから保存します(回収済みの雨は捨てません)。再開時に fn_vz を
外すと、`vzflow.dat` が残っていれば停止します(VZ 貯留を黙って捨てないため)。
柱・区画・土層厚・出口の構成が保存時と違っても停止します。

## 適用範囲と併用の制限

初版で**併用できない機能**(指定すると初期化で停止): 地下水(`fn_gwflow`)・
積雪(`fn_snow`)・氷河(`fn_glacier`)・地形変化(`fn_geomorph`。土層厚が
変わるため)・水質(`fn_wq`)・淡塩 2 層(`fn_salt`)・ネスティング・STG 格子。
VZ と地下水の同居(区画ごとの所有の切り分け)は今後の拡張です。

**VZ セルに置けないもの**: 河道(fn_rw)・海域(fn_sw)・境界条件・湧き出し・
構造物のセル。土層厚は 0 以上で、柱の深さ `vz_depth` 以下であること。土層厚 0 の
セルは雨がそのまま排水される区分として扱います(地表で読み出すので排水 = 雨、
貯留 = 0。岩盤が露出した場所や、谷(2023)の土層厚の線形分布の 0 cm 区分)。

**計算中に停止する状態**(適用外として理由を表示します)

- **湛水が必要になった**: 雨が強く、地表面に正の圧力をかけないと土壌が
  受け入れられない状態です(湛水時の境界の切り替えは今後の拡張)。
- **読み出す深さに有意な上向き流束**: 直接排水は上向きの排水を扱いません。
- **時間刻みが `vz_dt_min` を下回る**: 物性や初期条件・雨の与え方を見直します。

ほかに知っておくこと: 地表に溜まった水は VZ に戻りません(一方向)。
蒸発散・根の吸水は VZ 貯留に作用しません(イベント計算向け)。出口が浸水しても
排水は妨げられません(背水は解きません)。

## パラメータと既定値の根拠

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

**&list_vz**

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| f_vz | 1 | 0 で一時無効化 | **方式** |
| fn_vz_zone | — | 区画番号ラスタ(整数。0 = 適用外) | **与件** 必須 |
| dt_vz | 60 s | 柱を進める同期間隔(0 = 毎ステップ) | **数値設定** 山地の応答時間に比べ十分短く、費用が小さい値([test/vzcol](../../test/vzcol/) で確認) |
| f_vz_rain | 0 | 0: 柱内の雨量の一致を要求 / 1: 柱内の面積平均 | **方式** 一致しなければ停止して知らせる側を既定に |
| f_vz_kface | 1 | 界面透水係数 1: 算術平均 / 2: 調和平均 | **方式** 原論文が使った HYDRUS-1D と同じ算術平均を既定に(比較用に調和平均) |
| vz_dt_init | 1 s | 内部刻みの初期値 | **数値設定** |
| vz_dt_min | 0.001 s | 内部刻みの下限(下回ると停止) | **数値設定** |
| vz_dt_max | 3600 s | 内部刻みの上限 | **数値設定** |
| vz_tol_theta | 1e-3 | 時間誤差の θ の尺度(θs − θr に対する比) | **数値設定** [test/vzcol](../../test/vzcol/) で 1/4 にした再計算との差 0.03% |
| vz_tol_psi | 1e-3 | 時間誤差の ψ の尺度(絶対 m と相対の共通値) | **数値設定** 同上 |
| vz_tol_q | 1e-2 | 時間誤差の界面積算流束の相対尺度 | **数値設定** 1e-3 との差は深さ別の積算流束で 0.05%、計算量は 1/7(developer.md §87) |
| vz_mb_rate | 1e-11 m/s | 柱の非線形反復の水収支誤差の予算 | **数値設定** 1 年で 0.3 mm 以下 |
| vz_maxit | 25 | Picard 反復の上限 | **数値設定** |
| vz_out_depth | なし | vz_column.csv に出す深さ (m。最大 20) | **与件** |
| f_vz_outprof | 0 | 1: 柱の鉛直分布を出力 | **方式** |

**&list_vz_column**(柱番号 c で添字。最大 50 柱)

**既定値を見直すときの手がかり**

- **小杉パラメータの既定は試算用です**。原論文[^tani2023]の値は試験地ごとの
  現場の土壌の値(表−2。竜ノ口山・桐生・Mettman Ridge で大きく異なる)で、
  普遍的な値ではありません。既定には、論文の主な事例(TY1・TY2)の土壌で、3 組の
  中で透水性が最も穏当な竜ノ口山(TY)の組を置きました(下の表)。まず動かして
  挙動を見るための値です。実際の検討では、土壌の保水・透水試験から小杉式を当てはめた
  値を与えてください(Kosugi 1996[^kosugi1996])。文献の当てはめ値には保水曲線の
  変曲点の圧力水頭(Kosugi 1996 の記号で ψ₀。初期条件の ψ0 とは別)を示すものが
  あり(同論文の表 1 など)、その場合は vz_psim = ψ₀ exp(σ²)(同 式 (12))に換算し、
  m 単位で与えます。原論文の竜ノ口山の値と設定は
  [examples/vz_tani2023](../../examples/vz_tani2023/) にあります。森林土壌は表層の Ks が大きく、降雨強度より
  十分大きいことが多い一方、σ と ψm は応答の速さ・逓減の形に強く効きます。
- 初期条件 `vz_q0_mmh` は「降雨前の流出率」に相当します(自由排水の下端では
  一様な ψ0 が厳密な定常解)。既定の 0.1 mm/h は試算用の目安です。初期条件は
  最初の降雨への応答に強く効きます。TY の組では q0 = 0.1 mm/h が一様な
  ψ ≈ −0.31 m、0.01 mm/h が ψ ≈ −0.62 m に当たり、ψ = −1 m は q0 ≈ 0.0015 mm/h、
  原論文の竜ノ口山の初期値 ψ = −4 m は q0 ≈ 2×10⁻⁶ mm/h です(採用した ψ は画面に
  表示します)。長期のスピンアップをして保存し、再開を初期値にする方法も
  あります([中断と再開](restart.md))。
- `vz_depth` は、読み出す最大の土層厚より十分深く取ります。柱を深くしても
  読み出す深さの流束が変わらないことを確かめると安心です。
- 時間誤差の許容(`vz_tol_*`)を 1/4 にして結果が変わらないことを確かめるのが、
  数値精度の簡単な確認方法です。

**van Genuchten のパラメータからの換算**: 手元に van Genuchten 式の α・n しか
ないときは、二つの式の保水曲線の変曲点と中央値(S_e = 0.5 の ψ)をともに一致させる
対応(Kosugi 1996[^kosugi1996] の式 (24)〜(26)。50 土壌の当てはめで両式の変曲点が
ほぼ一致したことに基づく)で、小杉式の σ と ψm に換算できます(θs・θr・Ks は
そのまま)。

```math
m = 1 - \frac{1}{n},\quad
\sigma^2 = (1 - m)\,\ln\frac{2^{1/m} - 1}{m},\quad
\psi_m = -\frac{(2^{1/m} - 1)^{1-m}}{\alpha}
```

ψm の単位は 1/α の単位です(α が 1/cm なら cm なので、m に直して与えます)。
二つの式の曲線は似ますが同じではありません(同論文の図 3〜8)。

  上の谷(2023)の 3 組が適しています。

## 検証・例題

- [test/vzcol](../../test/vzcol/): 柱 1 本・区画 1 つ。定常重力排水(全深さで
  F = q0·t)、深さ別の保存則 ΔS = F0 − D、小杉式の値、区画の重みによる集約と
  セル別の読み出しの一致、雨量と S_total の収支、固定圧下端の定常解と求積の
  一致、時間許容 1/4 との差、面積平均モードの一致、試算用の既定(柱の設定を省略した
  計算が同じ値の明示とビット一致し、採用値を表示する。一部だけの指定は停止)を
  `Check_vzcol.py` で検定。
- [test/vzzone](../../test/vzzone/): 柱 2 本・区画 3 つ(柱の共有)・複数出口と
  共有の受水セル・系外流出。受水セルの水深 = 配分どおりの移送 + 雨、地表水の
  総量、S_total の収支、柱を共有しても複製しても応答がビット一致すること、
  雨の分布と面積平均、厳密モードの停止、保存 → 再開の一致を `Check_vzzone.py` で検定。
- [examples/vz_tani2023](../../examples/vz_tani2023/): 谷(2023)の全 7 事例の計算
  (HYDRUS-1D)を同じ設定で再計算し、論文の計算流出強度と比べる例題(小斜面の人工
  降雨・ゼロ次谷・竜ノ口山・桐生。土層厚の線形分布、柱の共有、深部浸透などの
  論文の後処理を含む)。KIEX・MREX・MR1・TY2 は流出強度の大きい範囲の 90 % の点が
  論文の計算値と 5〜22 % 以内、ピーク差は 2.3 % 以内。圧力水頭も比べ、TY2・KI1・
  KI2 は湿潤前線の到達時刻が 0.1〜3 m の全深さで ±0.8 h 以内(KI2 の 2・3 m は
  +1.5 h)。論文の数値は利用者が入手した PDF の図から取り出す(同梱しない)。
- MPI の並列数によらず結果はビット一致します(柱は全ランクで同じ計算をし、
  出口への加算だけを所有ランクが行います)。
