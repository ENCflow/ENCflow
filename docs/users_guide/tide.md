# 潮位・海面(&list_tide)

[ユーザーガイド目次へ](../users_guide.md)

海域セルに潮位(海面水位)の時系列を与え、高潮・上げ潮による沿岸
浸水や、干潮に向けた排水を計算します。`fn_tide` で有効化します。

**前提**: 海域は地理情報の海域マスク `fn_sw` で指定されている必要が
あります([地理情報の章](geoinfo.md))。潮位は海域セルへ水位として
強制されます。海セルの水深・セル流速は通常の陸セルのようには更新せず、
海を水位規定の境界として扱います。ただし、**海と陸の間の流量は通常の
ENCエッジ計算で求めます**。この流量によって陸側の水深が変わり、
陸側の流れとともに浸水・排水が計算されます。

```
&list_tide
  titype = 2                     ! 一様時系列
  hsea0 = 1.0                    ! 海セルの見かけ水柱厚 (m)
  tival(1:2,1) = 0,    0.0       ! (時刻(min), 潮位(m))
  tival(1:2,2) = 180,  0.8
  tival(1:2,3) = 360,  0.0
  tival(1:2,4) = 540, -0.8
/
```

結果の見方(分布・台帳・計測列・再開)は、このページの[出力・確認](#出力確認)にまとめています。

## 潮位の与え方(titype)

| titype | 与え方 | 使うパラメータ |
|---|---|---|
| 1 | 一様な固定値 | ti0 |
| 2 | 一様な時系列(線形補間) | tival |
| 3 | 分布1枚 × 倍率時系列 | fn_timap、tival(倍率) |
| 4 | 分布ファイルのリスト(隣接2枚を線形補間) | fn_timaplist、dt_timaplist |

| パラメータ | 既定値 | 意味 |
|---|---|---|
| titype | 1 | 潮位タイプ(上表)。未指定なら 1(一様固定潮位 ti0)を採用し "(default)" 付きで表示 |
| ti0 | 0 | titype=1: 一様固定潮位 (m。z と同じ標高基準)。既定 0 = 平均潮位 |
| tival | — | titype=2, 3: 時系列 `(時刻(min), 潮位(m) または倍率)` |
| fn_timap | "" | titype=3: 潮位分布ファイル (m) |
| fn_timaplist / dt_timaplist(_c) | "" / 60 | titype=4: 分布ファイルリストと時間間隔 (min)。フレーム i の時刻は (i−1)×間隔、範囲外は端値保持 |
| dt_tiupdate | 1 | 潮位の更新間隔 (min) |
| hsea0 | 1.0 | 海セルの見かけ水柱厚 (m)(下記) |

## hsea0 — 海セルの見かけ水柱厚

海域マスクが有効な領域内セルでは、潮位の更新時に `z = η − hsea0`、
`h = hsea0` として、水面 `z + h` を指定潮位 η に合わせます。
`hsea0` はこの境界表現に使う一定の水柱厚であり、実際の海の水深や
海底地形を与える値ではありません。潮位が変わると計算上の z が変わり、
水柱の厚さ h は一定に保たれます。η と陸側の地盤高は同じ標高基準で
与えてください。

海が供給側になる浸水(高潮・上げ潮)では、海セルのこの水柱が乾燥
判定・セル境界の水深・摩擦を賄います。**限界水深 dd の数十倍以上**を
推奨します(小さすぎると海から陸への浸水流量が過小になります。
dd 以下はエラー)。標準的には 1 m 程度から始め、浸水流量の hsea0
感度が気になる場合は値を変えて確認してください。

![潮位時系列と海セルの断面](../figs/tide_section.png)

(a) は上の tival 入力例を示す潮位時系列で、線形補間し、範囲外では
端値を保持します。(b) は時刻 A の高潮位を与えたときの浸水の模式図です。
海セルでは η = +0.8 m、h = hsea0 とし、海陸境界の流量によって陸側へ
水が入ります。陸側の水面は浅水計算で決まるため、全域が海と同じ水位に
なると仮定しません。水域の先端は陸の地盤との交点で閉じています。
(c) は時刻 B の低潮位(η = −0.8 m)での排水と滞留を示します。
海へ通じる流路があり、水位差等の条件を満たす水は排水されますが、
地形の高まりで隔てられた低地には水が残る場合があります。

(b)(c) の地形・陸側の水面・流向矢印は仕組みを説明する模式表現で、
(a) の時系列を入力して得た数値計算結果ではありません。

## とりあえず動かしてみる(最小入力)

最小入力は fn_sw の海域マスクと **fn_tide に空の &list_tide**(= 潮位 0 m の
固定・hsea0 1 m。海を「水位 0 の排水先」にする最簡の使い方。
根拠は下の[パラメータと既定値の根拠](#パラメータと既定値の根拠))です。

```
&list_tide
/
```

fn_tide を与えない海域マスクも有効で、そのとき海セルは z = 0(標高は地形
ファイルの値によらず 0 に強制)、h = [初期条件](initial.md)で与えた値の
まま固定されます(海セルは更新されないため)。f_htype=0 なら海面 = h0、
f_htype=2 なら海面 = e0 で、その水面が規定水位として働きます。空の
&list_tide との違いは、潮位 0 m と hsea0 の水柱を明示的に与える点です。

## 使い方の型

- **高潮・上げ潮の浸水**: titype=2 の時系列で潮位を上げる。
  海岸堤防([地理情報の章](geoinfo.md))と併用すると越流・破堤前の
  防護が表現されます。
- **干潮への排水**: 潮位を下げ、海への流路と水位差等の条件に応じた
  排水を計算します。地形の高まりや堤防で隔てられた低地は、潮位を
  下げるだけでは排水できない場合があります。
- **警戒潮位での定常運転**: titype=1 の固定値。
- **津波(境界からの入射)**: 潮位機能ではなく、辺境界の長波放射
  (型 2)と水位規定セル・初期水位の組み合わせが基本です
  ([境界条件の章](boundary.md))。領域内で波を伝播させる「解く海」は
  海域マスク fn_sw を使わず、sw=0 の通常セルに海底地形と初期水位を
  与えます。防潮堤の海側判定には fn_seaside を使います
  ([地理情報の章](geoinfo.md))。

## パターン別の推奨値

潮位の値は与件ですが、型ごとの目安を示します。

| 型 | titype | 潮位の与え方の目安 | 組で使う機能 |
|---|---|---|---|
| 天文潮(感潮域の往復) | 2 | 半日周 12.42 h の正弦。振幅は日本の太平洋岸 0.5〜1 m、瀬戸内・有明海 1.5〜3 m | 区間流入(河川)、淡塩 2 層 |
| 高潮 | 2 | 天文潮に台風の偏差 1〜3 m を 3〜6 時間の山で重畳 | 海岸堤防 fn_seawall、家屋群 fn_gv |
| 干潮への排水 | 2 または 1 | 低潮位(−1 m 程度)へ下げる・固定 | 排水ポンプ・樋門 |
| 警戒潮位の定常 | 1 | ti0 = 計画高潮位 | 海岸堤防 |
| 津波 | — | 潮位機能ではなく境界入射([境界条件](boundary.md)) | fn_seaside |

hsea0 は限界水深 dd の数十倍以上(標準 1 m)から始めてください。

## 出力・確認

分布出力の 3 通りの有効化(自動 / 指定 / 共用)と柱状量の面積基底の読み方は[入出力の形式](io.md#状態量の分布出力の考え方)に、確認したい量から出力を逆引きする早見表は同じ節の末尾にあります。

**分布**(`result/` のラスタ)

| ファイル | 出し方 | 内容 |
|---|---|---|
| H0001… / E0001… | f_out_h(既定 on)/ f_out_e | 海セルは水深 H = hsea0、水位 E = 与えた潮位。陸側の浸水・排水はこれらで読む |
| X0000 | 常時 | 領域マスク(2 = 海域)。海域マスクが意図どおりかの確認に |

**台帳・ログ**

- Log.txt の S 列と h_max 列は海セルを含みません(2026-10-22 以前は
  S に海セルの一定の水柱が上乗せされていました)。海から陸へ入った水は
  S の増加、海へ排水した水は S の減少として現れます。

**計測**(プローブ・測線の列)

- 海岸線を横切る[測線](record.md)で浸水・排水の流量 Q(m³/s。符号は
  測線の向き)が得られます(端点は陸セルに置き、海セルを含めない。
  含めると Hmax・B に hsea0 が混じります)。陸側のプローブの `h`・`z + h`
  で潮位への追従を確認します。

**再開**

- 潮位の更新位相は絶対ステップ番号基準なので、再開後も中断なしランと
  同じタイミングで更新されます(再開往復はビット一致)。

**読み方と検算のコツ**

- 海セルの z は潮位に合わせて毎回変わるため、`Z0001…` の海域は地形では
  ありません(陸の地形は変わりません)。
- 浸水流量の hsea0 感度は、同じ潮位で hsea0 を変えた測線 Q の差で
  確認します(上の[パラメータと既定値の根拠](#パラメータと既定値の根拠))。

## 制約・注意

- ENC 格子系専用です(旧 STG では使えません)。
- 海域マスクのセルは流れを解かず、**地形変化(土砂)の全プロセスも
  海セルには働きません**。津波・高潮による海底の泥・砂の巻き上げと
  堆積を扱う場合は、水域を通常セル+初期水位で表します
  ([土砂・地形変化](geomorph.md)の浮遊砂の項)。
- 同様に、降雨・蒸発散・浸透・地下水(側方流は海セルと交換しない)・
  積雪・水質・流木・瓦礫のどの計算にも海セルは入りません。海は無限
  容量のリザーバで、海へ出た水と物質は系外へ消え、海から入る水は
  海セルの水量を減らしません(Log の S 列・最大値統計が海セルを除く理由)。
  例外は[淡塩 2 層](salt.md)(海セルを塩水の規定水頭に使う)と
  [管路層](gwflow.md)の海域吐口(系外放流)です。
- 河口の段落ち強制 f_rivermouth_drop([浅水流計算](swflow.md))とは
  併用できません(高潮位の背水を無視する常時射流と矛盾するため、
  エラーで停止)。領域内に海セル(領域マスク内かつ sw > 0)が 1 つも
  ない場合もエラーで停止します。
- 潮位の更新位相は絶対ステップ番号基準なので、[再開](restart.md)後も
  中断なしランと同じタイミングで更新されます(潮位有効の再開往復も
  ビット一致します)。
## パラメータと既定値の根拠

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| titype | 1(未指定時) | 潮位の与え方 | **方式** 空の &list_tide で「水位 0 の排水先」になる最簡の既定。現象に応じて 2〜4 |
| ti0 | 0 m | 一様固定潮位 | **与件** 0 = 標高基準の平均潮位(T.P. 基準の地形なら T.P. 0) |
| tival / fn_timap / fn_timaplist | — | 時系列・分布 | **与件** 潮位表・検潮所の実測・高潮推算 |
| dt_tiupdate | 1 min | 潮位の更新間隔 | **数値設定** 潮位の変化(数時間周期)に対して十分細かい。計算刻みより短くしても意味はない |
| dt_timaplist | 60 min | 分布リストのフレーム間隔 | **与件** 推算モデルの出力間隔に合わせる |
| hsea0 | 1 m | 海セルの見かけ水柱厚 | **経験値** 限界水深 dd(既定 1 mm)の数十倍以上で、海から陸への流量が hsea0 に鈍感になる。実際の海の水深ではない |

**既定値を見直すときの手がかり**

- 天文潮は気象庁の潮位表(主要港の予報値)か近傍検潮所の実測から、
  高潮は台風シナリオの推算結果(自治体の高潮浸水想定の資料)から
  時系列を作ります。潮位と地形の標高基準(T.P.・D.L.・港湾基準面)を
  必ず揃えてください。
- hsea0 の感度は、同じ潮位で hsea0 を 0.5 m・1 m・2 m と変えた
  浸水流量(測線)の差で確認できます。
