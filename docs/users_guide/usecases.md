# 用途集(現象から引く)

[ユーザーガイド目次へ](../users_guide.md)

「計算したい現象」から、使う機能の組み合わせと設定の要点を引くための
一覧です。各機能の詳細は該当章を、パラメータの正確な意味は
[全パラメータ索引](params_index.md)を参照してください。
末尾に**現時点では未対応(計画中)**の現象も明示します。

備考欄には、その用途で利用者が知っておくべき近似の性質・データの
与え方・精度上の注意だけを書いています(空欄は特記なし)。

## 洪水・氾濫

| 現象 | 使う機能 | 設定の要点 | 備考 |
|---|---|---|---|
| 河川洪水の氾濫(外水) | [地理情報](geoinfo.md)+[境界条件](boundary.md)(+[河道](channel.md)・[構造物](structure.md)) | 地形+流入時系列(bc_qin / inflow) | 実地形は窪地除去(utils/rmdepress_river)を前処理で。平坦河道区間の流量振動対策はチュートリアル参照 |
| 降雨をそのまま載せる氾濫解析(rain-on-grid) | [降雨・気象](forcing.md) | fn_precip(一様/分布)を地形に直接載せる | 損失は流出係数でなく浸透([地下水](gwflow.md) の Green-Ampt)で物理的に表すのが流儀 |
| ダム・ため池の決壊氾濫 | [河道](channel.md)の堤防+破堤(+初期条件) | 貯水域を河道セル(rw)+堤体を堤防(bank)で表し、決壊は破堤(&list_channel_breach)の天端時系列で与える | 決壊口の拡大過程は入力(時系列)で与える(侵食による自発拡大は予測しない) |
| 霞堤・越流堤・二線堤・輪中の治水効果 | [河道](channel.md)の堤防 | fn_bank / bank0+開口 f_bank_opening | 越流幅・天端高・開口位置はデータで与える |
| 遊水地・調節池の効果検証 | 地形+[河道](channel.md)+[構造物](structure.md) | 越流堤(bank)+流入・排水ゲート(culvert/gate) | |
| 越波・越流による市街地浸水 | [境界条件](boundary.md)のソース | 越波流量時系列を &list_bound_source で護岸背後セルに投入 | 波浪・越波流量そのものは計算しない(外部推算値を与える) |

## 沿岸・河口

| 現象 | 使う機能 | 設定の要点 | 備考 |
|---|---|---|---|
| 高潮・津波の遡上 | [潮位・海面](tide.md) | 海域マスク+潮位/水位時系列 | 沖側の発生・伝播は外部から水位で受ける |
| 高潮による貯木場からの材木流入(伊勢湾台風型) | [流木](driftwood.md)+[潮位・海面](tide.md) | 貯木場・市街地は通常セル+初期水位(海域マスクは沖側のみ)。材木ストックを貯木場セルに与え、水理的流失を「高潮による係留切れ」として使う(dw_hrec を平常水深より高く)。実例: [examples/timberyard](../../examples/timberyard/)(driftwood.md の例題節に解説) | 材木の到達・堆積マップ(Wd9999)まで。個別材木の衝突力は対象外だが、指針の衝撃力式(流速×代表径)への入力は出力から得られる(後処理評価) |
| 河川津波(津波の河川遡上) | [潮位・海面](tide.md)+[河道](channel.md) | 河口の海域セルに津波波形 | 河道内は 1 セル 1 水位(断面内の水位差は表現しない) |
| 津波による湾内の泥・砂の巻き上げと遡上域への堆積(津波堆積物) | [土砂・地形変化](geomorph.md)の f_suspend(砂は+f_fluvial) | 湾は海域マスクでなく通常セル+初期水位 f_htype=2 で表し、津波は辺境界の長波放射で入射。巻き上げ可能層は土層厚 sd(詳細は geomorph.md 浮遊砂の項) | 海域マスクのセルには地形変化が働かないため、水域の表し方が要点。砂は板倉・岸式(f_esform=2)で校正不要、泥は susp_wf・susp_esa・susp_tausc の校正(Partheniades 型の読み替え)。単一粒径のため堆積厚・範囲まで(内陸細粒化は表現しない) |
| 複合氾濫(高潮×河川洪水×豪雨) | 潮位+境界+降雨の重ね合わせ | 各機能を同時に有効化するだけ | プロセス間の順序・結合は自動(単一時間発展) |
| 帯水層への海水浸入・後退 | [淡塩2層](salt.md)+[地下水](gwflow.md) | fn_salt(f_salt_gw=1)+f_gwlateral=1+海域マスク | 鋭利界面近似: 汽水(混合)は作られない。平衡は Ghyben-Herzberg |
| 揚水誘引の海水浸入・井戸の塩水化 | [淡塩2層](salt.md)+[地下水](gwflow.md)の揚水シンク | 上記+f_gwpump=1(沿岸の井戸) | 揚水は淡水優先(浅井戸スクリーン近似)。淡水厚で足りない分が塩水の混入として現れ、くさびの誘引・アップコーニングは側方流動と塩水層の力学が自動で表す |
| 淡水レンズ(島嶼・砂州) | [淡塩2層](salt.md)+降雨・浸透 | 涵養(降雨+Green-Ampt)+海域マスク | レンズ厚は涵養と K_sh の比で決まる(スピンアップ推奨) |
| 河口の塩水くさび | [淡塩2層](salt.md)(f_salt_surf=1) | 河川流入(淡水)+潮位(塩水) | くさびの準定常位置と応答が対象(内部波の慣性はなし)。移流分担率 salt_alpha が実質的な校正点 |
| 沿岸帯水層の潮汐応答 | [淡塩2層](salt.md)+[潮位・海面](tide.md) | 潮位時系列がそのまま地下の海側境界水頭になる | 海と地下の接続は淡塩2層モジュール経由でのみ行われる |
| 高潮・津波の遡上海水の行き先(塩水の面的分布) | [淡塩2層](salt.md)+[潮位・海面](tide.md) | 遡上した海水は自動的に塩水として追跡される(Hss 出力) | 現状は地表の到達範囲まで。浸透して土壌・帯水層を汚染する経路(塩害の完結)は計画中(下記) |
| 干拓地・低平地の機場排水 | [河道](channel.md)の堤防+[構造物](structure.md)+[潮位・海面](tide.md) | 堤防で囲み、ポンプで外水(海・河道)へ排水 | |

## 土砂・斜面・火山

| 現象 | 使う機能 | 設定の要点 | 備考 |
|---|---|---|---|
| 降雨で誘発される斜面崩壊→土石流→氾濫 | [土砂・地形変化](geomorph.md)+[地下水](gwflow.md) | f_slide+浸透(Green-Ampt)+側方流 | 崩壊の安定判定は地下水位(間隙水圧)に連動する — 浸透を有効にしてこそ「降雨誘発」になる |
| 山体崩壊→河道閉塞(天然ダム)→決壊洪水 | [土砂・地形変化](geomorph.md) | f_release / f_slide+土石流+堆積(走路の連行は f_dbed=4) | 堆積地形が自動的に流れを堰き止める(地形と流れの双方向結合) |
| 砂防施設(遊砂地・砂防堰堤)の効果検討 | [土砂・地形変化](geomorph.md)(+[構造物](structure.md)・[河道](channel.md)) | 施設あり/なしの2ケース比較。遊砂地は地形の掘り込み、不透過堰堤は不侵食地形(z に足して sd=0)、透過型は堤体+カルバート(水のみ通す=捕捉の上限側評価)。geomorph.md「砂防施設の表し方」 | 堆砂→満砂→天端越流の時間発展は自動。単一粒径のため粒径選択捕捉は表現できない(流木の面的な捕捉量は[流木](driftwood.md)の併用で評価可能)。結果はランク数によらずビット再現するため、2ケースの差=施設の効果が数値誤差と切り分けられる |
| 地すべり・山体崩壊による津波(貯水池・天然ダム湖・湾の段波) | [土砂・地形変化](geomorph.md)+水域(初期水位 f_htype=2 や[潮位・海面](tide.md)) | fn_dbinit / f_slide で崩壊土塊を与える(追加設定は不要 — 突入・造波・伝播・遡上は自動) | 流入する混合体の体積・運動量と、堆積による底面隆起(水深保存で水面が持ち上がる)が波を発生させる。非分散の長波近似のため、分散性が効く深い水域の近地波形・最大波高には限界(貯水池・狭い湾など長波近似が成り立つスケールが適所)。突入後の土砂は水柱と一体で、水面下を走る密度流としては分離されない |
| 流木を伴う洪水・氾濫、土石流と流木の混合流れ | [流木](driftwood.md)(+[土砂・地形変化](geomorph.md)) | 立木ストック(dw_stock0 / fn_dwstock)+発生(水理的流失 dw_wrec・侵食連行 dw_droot)+停止(dw_wstop)。土石流混合は f_debris と同時有効化するだけ | 流木量のラスタ場としての概算(Wd9999 = 期間最大到達量が流木ハザードマップ)。個別流木の追跡・橋梁やスリットの幾何的閉塞・衝突力は対象外(閉塞効果は開口を絞った2ケース比較で近似) |
| 貯水池の堆砂・排砂 | [土砂・地形変化](geomorph.md)+[構造物](structure.md) | 浮遊砂(f_suspend)+ダム操作 | 排砂ゲートの操作は時系列で与える |
| 河床変動・河口砂州のフラッシュ | [土砂・地形変化](geomorph.md)(+[潮位・海面](tide.md)) | 掃流砂(f_fluvial)+浮遊砂(f_suspend)+出水ハイドログラフ。汀線近傍は海域マスクでなく通常セル+初期水位 f_htype=2 で表し、砂州の賦存量は土層厚 sd で与える(geomorph.md「海域マスクと土砂の行き先」) | 越流→切り下げ→流量集中の正のフィードバックは地形と流れの双方向結合で自動。切り下げは自動だが明瞭な側岸崩落は表現しない(弱い f_creep が粗い代用)。天端が一様な場合は切れ込み想定位置に低所を与える。急速なフラッシュでは fluv_dzmax がレート制限になり得る。波浪がないためフラッシュ後の砂州回復(沿岸漂砂)は対象外 |
| 火山泥流(ラハール)・融雪型泥流 | [土砂・地形変化](geomorph.md)+[雪]([降雨・気象](forcing.md)) | 土石流の抵抗則+融雪水 | 希薄系(火砕サージ・降灰輸送)は対象外 |
| 溶岩流の到達範囲・溶岩原形成→その後の降雨流出 | [溶岩流](lavaflow.md) | 噴火口セル群+噴出率時系列+η・τ_y(+固化 lv_wsol/lv_vsol) | 固化溶岩は地盤 z になり、同じランで降雨・洪水・土砂が新地形の上を流れる。等温(冷却・温度依存粘度は将来拡張)。溶岩と水の熱的相互作用は対象外 |
| バッドランド・火砕丘の谷形成(表面流のない高透水斜面) | [土砂・地形変化](geomorph.md) | f_splash(乾式斜面侵食)+浸透(Green-Ampt)。谷間隔の選択には弱い f_creep 併用。実例: [examples/badland](../../examples/badland/) | 降雨が全量浸透して地表流が生じない斜面でも、雨滴+サブグリッドリルの凹地形フィードバックで崖縁から谷が成長する。固結度(f_slide 併用)が谷形成の有無を分ける |

## 現時点では未対応(計画中)

以下は利用者からの需要を認識しており、既存の枠組みに乗る拡張として
計画しているものです(順序・時期は未定)。

| 現象 | 現状 | 予定の形 |
|---|---|---|
| 吹送流・風による水位セットアップ(内湾・湖・広い氾濫原) | 風応力項なし | 運動方程式への風応力項+風速入力(気象強制場の拡張) |
| 塩害の完結(浸透した海水による土壌・帯水層の汚染) | 遡上海水の到達範囲までは可(上記) | 浸透・蒸発散の淡塩配分 |
| 田んぼダム(水田の落水口絞りによる流出抑制) | 貯留+オリフィスの組み合わせで近似可能だが定型がない | 検討中 |
| 煙型(粉雪)雪崩・積雪(SWE)計算からの雪崩の自動連成 | 流れ型のランアウト+走路連行は可(上記雪氷)。煙型は浅水近似の外 | 煙型は対象外のまま。SWE→連行可能層(sd)の自動変換は検討中(現状は前処理で変換) |
| 管網モデル(1次元管路網)とのオンライン結合、大口径幹線の明示的追跡 | 対象外(連続体近似の適用範囲外) | 外部結合・幹線ハイブリッドとして検討中 |
