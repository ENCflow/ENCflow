# 用途集(現象から引く)

[ユーザーガイド目次へ](../users_guide.md)

「計算したい現象」から、使う機能の組み合わせと設定の要点を引くための
一覧です。各機能の詳細は該当章を、パラメータの正確な意味は
[全パラメータ索引](params_index.md)を参照してください。
末尾に**現時点では未対応(計画中)**の現象も明示します。

備考欄には、その用途で利用者が知っておくべき近似の性質・データの
与え方・精度上の注意だけを書いています(空欄は特記なし)。

## 洪水・氾濫

| 現象 | 使う機能 | 設定の要点 | 備考 |
|---|---|---|---|
| 河川洪水の氾濫(外水) | [地理情報](geoinfo.md)+[境界条件](boundary.md)(+[河道](channel.md)・[構造物](structure.md)) | 地形+流入時系列(bc_qin / inflow) | 実地形は窪地除去(utils/rmdepress_river)を前処理で。平坦河道区間の流量振動対策はチュートリアル参照 |
| 降雨をそのまま載せる氾濫解析(rain-on-grid) | [降雨・気象](forcing.md) | fn_precip(一様/分布)を地形に直接載せる | 損失は流出係数でなく浸透([地下水](gwflow.md) の Green-Ampt)で物理的に表すのが流儀 |
| ダム・ため池の決壊氾濫 | [河道](channel.md)の堤防+破堤(+初期条件) | 貯水域を河道セル(rw)+堤体を堤防(bank)で表し、決壊は破堤(&list_channel_breach)の天端時系列で与える | 決壊口の拡大過程は入力(時系列)で与える(侵食による自発拡大は予測しない) |
| 河川堤防の破堤氾濫 | [河道](channel.md)の破堤(仮想壁面)、または[規定底面運動](bedmotion.md)(解像堤防) | 堤防が仮想壁面なら &list_channel_breach の天端時系列。高解像度 DEM に堤防が標高として入っている(解像堤防)なら、破堤口のセルの地盤高を時刻歴で下げる(make_breach.py で表と窓付き変位ファイルを生成)。実例: [examples/levee_breach](../../examples/levee_breach/) | 決壊口の幅・深さの進行は入力で与える(侵食による自発拡大は予測しない)。解像堤防の破堤は規定の形状変化で、土層厚は変えない |
| 霞堤・越流堤・二線堤・輪中の治水効果 | [河道](channel.md)の堤防 | fn_bank / bank0+開口 f_bank_opening | 越流幅・天端高・開口位置はデータで与える |
| 遊水地・調節池の効果検証 | 地形+[河道](channel.md)+[構造物](structure.md) | 越流堤(bank)+流入・排水ゲート(culvert/gate) | |
| 越波・越流による市街地浸水 | [境界条件](boundary.md)のソース | 越波流量時系列を &list_bound_source で護岸背後セルに投入 | 波浪・越波流量そのものは計算しない(外部推算値を与える) |

## 沿岸・河口

| 現象 | 使う機能 | 設定の要点 | 備考 |
|---|---|---|---|
| 高潮・津波の遡上 | [潮位・海面](tide.md) | 海域マスク+潮位/水位時系列 | 沖側の発生・伝播は外部から水位で受ける(発生から計算するなら次の行) |
| 地震(断層)による津波の発生〜伝播〜遡上と、沿岸の隆起・沈降 | [規定底面運動](bedmotion.md)+水域(初期水位 f_htype=2。海域マスクを使わない「解く海」)+[境界条件](boundary.md)(辺の長波放射) | 断層パラメータ(位置・走向・傾斜・すべり角・長さ・幅・すべり量・破壊時刻・立ち上がり)を utils/fault2disp で地盤変位のスナップショット表に変換し、fn_bedmotion に与える。経緯度・投影座標・地理参照つき格子のどれでも。実例: [examples/tsunami_fault](../../examples/tsunami_fault/)(理想化断層)、[examples/tsunami_coast](../../examples/tsunami_coast/)(沿岸の沈降・隆起と沖の津波の時間差) | 陸・海のセルが同じ変位場で動くので、沈降した低地の浸水、隆起域から広がる波、湾内での重なりまで同じランに入る。瞬時変位(初期水位方式)との違いは近地の時間差(数十秒〜数分の破壊伝播)。長波近似(静水圧)で十分なのは震源幅 ≫ 水深のとき。狭い変位(分岐断層・海底地滑り)の近地は非静水圧の f_nh_bottom |
| 高潮による貯木場からの材木流入(伊勢湾台風型) | [流木](driftwood.md)+[潮位・海面](tide.md) | 貯木場・市街地は通常セル+初期水位(海域マスクは沖側のみ)。材木ストックを貯木場セルに与え、水理的流失を「高潮による係留切れ」として使う(dw_hrec を平常水深より高く)。実例: [examples/timberyard](../../examples/timberyard/)(README に図付きの解説と感度ケース) | 材木の到達・堆積マップ(Wd9999)まで。個別材木の衝突力は対象外だが、指針の衝撃力式(流速×代表径)への入力は出力から得られる(後処理評価) |
| 津波・高潮による木造家屋の破壊と瓦礫の流動・堆積(流木による破壊力の増加を含む) | [家屋破壊・瓦礫](bldgdebris.md)(+[流木](driftwood.md)+[潮位・海面](tide.md)) | 家屋ストック fn_bdstock(木造率込み)と破壊可能割合 fn_bdfrac を与え、浸水深(被害関数対応)か荷重(流木・瓦礫込み)で破壊判定。空隙率への帰還 f_bdgv で破壊が流れへ返る。実例: [examples/tsunami_town](../../examples/tsunami_town/) | 破壊率マップ(Bs)・瓦礫の到達/堆積マップ(Bd9999)・荷重込み流体力(Fd9999)まで。個別家屋・個別瓦礫・衝突力は対象外(衝撃荷重は後処理) |
| 河川津波(津波の河川遡上) | [潮位・海面](tide.md)+[河道](channel.md) | 河口の海域セルに津波波形 | 河道内は 1 セル 1 水位(断面内の水位差は表現しない)。遡上中のソリトン分裂・undular bore を見るなら次の行 |
| 分散性のある津波・波(河川遡上津波のソリトン分裂、undular bore、孤立波、短い震源・地滑りの近地) | [浅水流計算](swflow.md)の非静水圧補正 f_nonhydrostatic(+f_nh_slope 底面勾配項、f_nh_bottom 動く底面の加速度項、f_nh_breaking 砕波スイッチ、nh_break_visc 砕波の渦粘性) | 1 層非静水圧の射影(研究オプション。既定は静水圧)。格子は水深の 1/4〜1/8、Courant ≲ 0.1 が目安。活性集合 f_nh_adaptive=1 で必要な場所だけ解く。検証: [test/nhwave_nh](../../test/nhwave_nh/)(定在波)、[nhsolitary](../../test/nhsolitary/)(孤立波)、[nhshelf](../../test/nhshelf/)・[nhbore](../../test/nhbore/)(ソリトン分裂)、[nhbreak](../../test/nhbreak/)(砕波遡上)、[nhbottom](../../test/nhbottom/)(動く底面) | 分散関係は 1 層理論(kH ≲ 2 で有効)。砕波性の遡上は砕波スイッチ+渦粘性+摩擦で実験則の +8%。反復ソルバのため静水圧の 2〜10 倍の計算時間 |
| 津波による湾内の泥・砂の巻き上げと遡上域への堆積(津波堆積物) | [土砂・地形変化](geomorph.md)の f_suspend(砂は+f_fluvial) | 湾は海域マスクでなく通常セル+初期水位 f_htype=2 で表し、津波は辺境界の長波放射で入射。巻き上げ可能層は土層厚 sd(詳細は geomorph.md 浮遊砂の項) | 海域マスクのセルには地形変化が働かないため、水域の表し方が要点。砂は板倉・岸式(f_esform=2)で校正不要、泥は susp_wf・susp_esa・susp_tausc の校正(Partheniades 型の読み替え)。単一粒径のため堆積厚・範囲まで(内陸細粒化は表現しない) |
| 複合氾濫(高潮×河川洪水×豪雨) | 潮位+境界+降雨の重ね合わせ | 各機能を同時に有効化するだけ | プロセス間の順序・結合は自動(単一時間発展) |
| 帯水層への海水浸入・後退 | [淡塩2層](salt.md)+[地下水](gwflow.md) | fn_salt(f_salt_gw=1)+f_gwlateral=1+海域マスク | 鋭利界面近似: 汽水(混合)は作られない。平衡は Ghyben-Herzberg |
| 揚水誘引の海水浸入・井戸の塩水化 | [淡塩2層](salt.md)+[地下水](gwflow.md)の揚水シンク | 上記+f_gwpump=1(沿岸の井戸) | 揚水は淡水優先(浅井戸スクリーン近似)。淡水厚で足りない分が塩水の混入として現れ、くさびの誘引・アップコーニングは側方流動と塩水層の力学が自動で表す |
| 淡水レンズ(島嶼・砂州) | [淡塩2層](salt.md)+降雨・浸透 | 涵養(降雨+Green-Ampt)+海域マスク | レンズ厚は涵養と K_sh の比で決まる(スピンアップ推奨) |
| 河口の塩水くさび | [淡塩2層](salt.md)(f_salt_surf=1) | 河川流入(淡水)+潮位(塩水) | くさびの準定常位置と応答が対象(内部波の慣性はなし)。移流分担率 salt_alpha が実質的な校正点 |
| 沿岸帯水層の潮汐応答 | [淡塩2層](salt.md)+[潮位・海面](tide.md) | 潮位時系列がそのまま地下の海側境界水頭になる | 海と地下の接続は淡塩2層モジュール経由でのみ行われる |
| 高潮・津波の遡上海水の行き先(塩水の面的分布) | [淡塩2層](salt.md)+[潮位・海面](tide.md) | 遡上した海水は自動的に塩水として追跡される(Hss 出力) | 現状は地表の到達範囲まで。浸透して土壌・帯水層を汚染する経路(塩害の完結)は計画中(下記) |
| 干拓地・低平地の機場排水 | [河道](channel.md)の堤防+[構造物](structure.md)+[潮位・海面](tide.md) | 堤防で囲み、ポンプで外水へ排水(吐口は河道セルに置く。海へ出すときは吐口省略の域外排水。海域マスクのセルには構造物を置けない) | 管路から直接取水する機場と海域吐口の例: [test/coastal_drain](../../test/coastal_drain/) |
| 海岸の波高・波向の分布(浅水変形・屈折・砕波・防波堤や島の陰) | [沿岸の波浪場](wavefield.md)(fn_wavefield) | 沖は海域マスクでなく通常セル+初期水位 f_htype=2 の「解く海」。沖の辺を入射(wf_bc_side = 1)、海岸に交わる左右の辺を側方 Neumann(2)。沖の波は wf_hm0・wf_trep・wf_dir(・wf_spread)か時系列 wf_val。準定常(既定)は dt_wave ごとに更新。検証: [test/wfshoal](../../test/wfshoal/)(浅水変形・屈折・砕波)、[test/wfshadow](../../test/wfshadow/)(防波堤の陰) | 位相平均・代表周期 1 個・方向ビン(XBeach 定常モード・SnapWave と同じ階層)。回折・反射・風による発達はない(陰の縁のぼけは数値拡散)。地形への作用は下の行(f_wfsed。波を解かない簡易な沿岸漂砂は fn_wave) |
| 波によるセットアップ・沿岸流・戻り流れ | [沿岸の波浪場](wavefield.md#流れへの作用wf_flow段-w2)(`wf_flow = 2`)+流れの辺境界の側方 Neumann([境界条件](boundary.md)の `f_bc_*` = 3) | 上の行の構成に `wf_flow = 2`(外力 + GLM の Stokes 輸送 + 波・流れの摩擦)。海岸に交わる左右の辺は波・流れとも側方 Neumann。出力の流速 u・v は Lagrangian 平均(底面の流れは u − Wsx)。検証: [test/wfcurrent](../../test/wfcurrent/)(セットアップ・沿岸流・ローラー) | 放射応力(波+ローラー)・GLM・波・流れの摩擦は XBeach の定常モードと同じ系統。波による水平混合はない。方向分散 0 の波は屈折が遅れ、砕波帯より沖に偽の沿岸方向の外力が出る(方向分散を与える) |
| 河口・潮流・離岸流の上の波(遡上の阻止・急峻化・流れによる屈折) | [沿岸の波浪場](wavefield.md#流れによる波の変化f_wf_current段-w3)(`f_wf_current = 1`) | 上の行の構成に `f_wf_current = 1`。波による流れと双方向にするなら `wf_flow = 2` も。阻止された作用量は台帳 `wavefield.csv` の blocked。検証: [test/wfdoppler](../../test/wfdoppler/)(逆流・順流・阻止・河口の噴流) | 代表周期 1 個なので阻止はすべてのエネルギーに同時に起こる。阻止の点での反射はない。メモリは波浪場の分で約 3 倍。阻止の近くは準定常の反復の収束が遅い(`wf_itmax` を上げる) |
| 沿岸漂砂・浜の侵食と回復(波浪場による過程の漂砂) | [沿岸の波浪場](wavefield.md#土砂への作用f_wfsed段-w4w5)(fn_geomorph の `f_wfsed = 1`) | 上の行の構成(`wf_flow = 2`)に、fn_geomorph の掃流砂・浮遊砂と `f_wfsed = 1`。海岸に交わる左右の辺は側方 Neumann(土砂も勾配 0)。沿岸漂砂量は Qby・Qsy の岸沖方向の積分(`f_wf_outdiag = 1`)。検証: [test/wfsed](../../test/wfsed/)(攪拌・沿岸漂砂と CERC・侵食と回復・土砂の保存) | 攪拌は軌道流速だけ(砕波の乱れなし)、浮遊砂の水平拡散なし、遡上域の輸送なし。侵食と回復の釣り合いは係数 `wfsed_facsk`・`wfsed_facas` に敏感(校正の量)。fn_wave の沿岸漂砂とは排他 |
| 弧状・カスプ状デルタ、汀線の均し、砂嘴(波浪による沿岸漂砂) | [土砂・地形変化](geomorph.md)の fn_wave(+掃流砂 f_fluvial) | 沖波の有義波高・周期・進行方向(固定値か時系列)を fn_wave で与える。f_fluvial=1 が必須。海は海域マスクでなく通常セル+初期水位で表す | 沖波 CERC 式の沿岸漂砂を砕波帯の掃流砂として河床に適用。回折なし(露出度の簡易扱い)、岸沖輸送・セットアップ・離岸流は対象外。砕波帯より深い水域はどこでも波の源になるので、対象外の水域は海域マスクにするか波の向きで陰にする |

## 土砂・斜面・火山

| 現象 | 使う機能 | 設定の要点 | 備考 |
