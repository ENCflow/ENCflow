# 沿岸の波浪場(fn_wavefield)

[ユーザーガイド目次へ](../users_guide.md)

沿岸の短周期の波(風波・うねり)の波高と波向を、浅水流と同じ格子・同じ時間発展の中で
求める機能です。沖の波(波高・周期・進行方向・方向分散)を領域の外縁の辺から入れ、
浅水変形(水深による波高の変化)・屈折(浅い側へ曲がる)・砕波・底面摩擦・
防波堤や島の背後の陰を計算します。

波は**位相平均**(1 波ずつの水面の上下は解かず、波のエネルギーの分布を解く)で、
**代表周期 1 個**、進行方向を **N_θ 個の方向ビン**に分けて扱う概算です。周波数の広がり・
風による発達・波どうしの非線形相互作用・回折・反射は扱いません。

波浪場は、設定に応じて流れと土砂にも作用します。どれも既定は 0(作用なし)です。

| 作用 | 有効にするパラメータ | 表すもの |
|---|---|---|
| [流れへの作用](#流れへの作用wf_flow) | `wf_flow`(&list_wavefield) | 波によるセットアップ(汀線付近の平均水位の上昇)・沿岸流・戻り流れ |
| [流れによる波の変化](#流れによる波の変化f_wf_current) | `f_wf_current`(&list_wavefield) | 河口・潮流・離岸流の上の波(ドップラー効果・流れによる屈折・遡上の阻止) |
| [土砂への作用](#土砂への作用f_wfsed) | `f_wfsed`(&list_geomorph) | 波による土砂の攪拌と輸送(沿岸漂砂・浜の侵食と回復) |
| [遡上域の輸送](#遡上域の輸送f_wfswash) | `f_wfswash`(&list_geomorph) | 汀線より上への砂の積み上げと前浜の侵食(経験式) |

`wf_flow = 0` かつ `f_wfsed = 0` なら、`fn_wavefield` を書いても書かなくても浅水流と地形の
結果は同じです。

[土砂・地形変化の章](geomorph.md)の「波浪による沿岸漂砂」(`fn_wave`。波を解かずに、沖の波から
汀線帯の沿岸漂砂を CERC 型の式で与える簡易モード)とは別の機能です。

基礎式・数値解法・既定値の根拠と、参考にした他モデル(XBeach・SnapWave など)と ENCflow 独自の
部分の区別、参考文献は[沿岸の波浪場の解説](wavefield_models.md)にあります。

## とりあえず動かしてみる(最小入力)

`&list_sysparam` で `fn_wavefield` を指定し(`"-"` なら同じパラメータファイル)、`&list_wavefield` に
入射の辺と沖の波を書きます。

```
&list_sysparam
  fn_wavefield = '-'
/
&list_wavefield
  wf_bc_side = 1, 0, 2, 2   ! 辺 W, E, N, S の型(0 吸収 / 1 入射 / 2 側方 Neumann)
  wf_hm0 = 1.5              ! 沖の波高 (m。不規則波は有義波高 H_m0)
  wf_trep = 8.0             ! 代表周期 (s)
  wf_dir = 0.0              ! 進行方向 (deg。x 軸 = 東から反時計回り、北 = 90)
  wf_spread = 20.0          ! 方向分散 σθ (deg)
/
```

必要なのは**入射の辺**と**沖の波**(`wf_hm0`・`wf_trep`・`wf_dir`)だけです。

**向きは「進む向き」です**(来る向きではありません)。x 軸(東)から反時計回りに
測り、北へ進む波が 90°、西へ進む波が 180° です。[土砂・地形変化の章](geomorph.md)の
`wave_dir` と同じ規約で、SWAN・XBeach の「来る向き」(nautical)とは 180° 違います。

**周期は代表周期 1 個です。** `wf_trep`(と `wf_val` の周期の列)は分散関係の
σ = 2π/T にそのまま使います。不規則波ではエネルギー周期 T_m−1,0 を与えるのを既定の
解釈とします。ピーク周期 T_p しか分からないときは、単峰のスペクトルで T_m−1,0 ≈ T_p/1.1 が
目安です(EurOtop 2018)。

**手順**

1. **沖は「解く海」にします。** 海底地形を z に与え、初期水位で水を張ります
   (`f_htype = 2` など。[初期条件](initial.md))。**海域マスクの海セル(sw)の帯は波が
   通りません**(潮位を与える境界のセルで、浅水流でも計算しないセルです。[潮位・海面](tide.md))。
   入射の辺に接するセルが開始時に 1 つも波浪セルでなければ、警告を表示します。
2. **沖の辺を入射(1)にします。** 直線的な海岸なら、海岸に交わる左右の辺を
   **側方 Neumann(2)**にします。Neumann は「境界の外にも同じ海が岸沿いに続く」という
   扱いで、左右の辺の近くに偽の陰ができません。吸収(0)にすると、外から斜めに
   入るはずの波がなくなり、辺の近くに陰ができます(閉じた湾の奥の辺など、外に海が
   ない辺に使います)。陸側の辺は何でも構いません。
3. **方向ビン数・砕波の係数は既定のまま**で始め、結果(Wh・Wa)を見てから必要なら
   変えます。
4. **結果を確かめます。** 分布 Wh(波高)・Wa(平均波向)を見て、台帳 `result/wavefield.csv` の
   imbalance(収支の残差)が小さいことを確かめます([出力・確認](#出力確認))。

## パターン別の推奨値

| 型 | 構成 | 見るもの |
|---|---|---|
| 海浜の波高分布・砕波帯の位置 | `wf_mode = 2`(準定常。既定)、沖の波は固定値 | Wh(波高)・Wb(砕波散逸。`f_wf_outdiag = 1`) |
| 防波堤・島の背後の陰 | 同上。方向分散は既定 20° | Wh・Wa(平均波向) |
| 波候の時間変化(地形変化と組む準備) | `wf_val` の時系列、`dt_wave` で更新間隔、`wf_clock = 1` で地形時間 | `wavefield.csv`(更新ごとの台帳) |
| 波の前線の到達(津波・洪水と同時に進める) | `wf_mode = 1`(非定常)、`f_wf_init = 0` | Wh の時間変化 |
| 波によるセットアップ・沿岸流 | `wf_flow = 2`、海岸に交わる左右の辺を波・流れとも側方 Neumann(`wf_bc_side` = 2、`f_bc_*` = 3) | E(水位)・u・v(流速)・Wfx・Wfy(外力) |
| 河口・潮流・離岸流の上の波(遡上の阻止・急峻化) | `f_wf_current = 1`(波と流れの双方向なら `wf_flow = 2` も) | Wh・Wa、台帳の blocked |
| 沿岸漂砂・浜の侵食と回復(地形の変化) | `wf_flow = 2` と fn_geomorph の掃流砂・浮遊砂に `f_wfsed = 1` | Z(地盤高)・Qby・Qsy(沿岸漂砂。`f_wf_outdiag = 1`) |
| 陸化・汀線の高まり(デルタ・浜のバーム) | 上の行に遡上域の輸送 `f_wfswash = 1` と前浜の平衡勾配 `wfswash_tanbe` | Z |

**設定の要点**

- **沿岸流を見る**: 方向分散を与えます(既定 20°。方向分散 0 の単一方向の波は屈折が遅れ、
  砕波帯より沖に偽の沿岸方向の外力が出ます)。沿岸流の岸沖分布は、砕波による水平混合
  `wf_break_visc`(&list_enc)でならせます(強さは校正の量。[砕波による水平混合](#砕波による水平混合list_enc-の-wf_break_visc))。
- **流れによる波の変化と波による流れを組む**(`f_wf_current = 1` と `wf_flow = 2`): 小さな背景粘性を
  足します(`f_diffusion_term = 2`、`p_diffusion_nu = 0.05` m²/s 程度。
  [沖の格子規模の縞と背景粘性](#沖の格子規模の縞と背景粘性wf_flow-と組むとき))。
- **地形変化と組む**: 準定常(既定)で、更新間隔 `dt_wave` を波候の変わる速さに合わせます。沖の波の
  時系列を地形時間で与えるなら `wf_clock = 1` です(MORFAC。[土砂・地形変化](geomorph.md))。
- **浜の侵食と回復を合わせる**: 岸向きの速度の係数 `wfsed_facsk`・`wfsed_facas` で校正します
  ([浜の侵食と回復の校正](#浜の侵食と回復の校正))。
- **陸化・汀線の高まりを見る**: 遡上域の輸送 `f_wfswash = 1` に、前浜の平衡勾配 `wfswash_tanbe` を
  現地の観測から与え、時間刻み `dt` に余裕を持たせます([遡上域の輸送](#遡上域の輸送f_wfswash))。
- **急な海浜**: 砕波を `wf_break = 2`(Janssen & Battjes 2007)にすると、急な海浜での散逸の過大を
  補正します。
- **岩礁など摩擦の大きい海底**: 底面摩擦 `wf_fw` を与えます(既定 0 = なし。流れの摩擦係数より
  1 桁以上大きいことがあります)。

## 波浪場の設定の要点

### 辺の型

外縁の各辺は次のいずれかです(`wf_bc_side`。辺 W・E・N・S の順)。

| 型 | 辺の外から入る波 | 使いどころ |
|---|---|---|
| 1 入射 | 沖の波 | 沖の辺 |
| 2 側方 Neumann | 辺の内側のセルと同じ波(外にも同じ海が続く) | 海岸に交わる左右の辺 |
| 0 吸収 | なし | 外に海がない辺・陸側の辺 |

外へ出ていく波は、どの型の辺からも自由に出ます(反射しません)。角では 入射 > 側方 Neumann >
吸収 の優先で型を決めるので、入射の辺と側方 Neumann の辺の角でも、直線海岸の岸沿いに一様な
解は崩れません。

### 波が通るセル・通らないセル

波を計算するセル(**波浪セル**)は、領域内(x > 0)で、海域マスクの海セル(sw)でも吸収セルでもなく、
水深が `wf_hmin` を超えるセルです。陸・乾いたセル・海セル・吸収セルへ向かう波は吸収されます
(反射なし。台帳の absorbed)。

- **家屋の空隙率 gv < 1 のセル**と**サブグリッド河道の幅・断面形のセル**も吸収セルとして扱い、
  その数を開始時に表示します。
- 角だけで接する 1 セル厚の斜めの堤を、波はすり抜けません(対角の両脇の 2 セルがどちらも波の通らない
  セルなら、その対角は波を通しません。1 セル幅の斜めの水路に水を通す浅水流とは意図的に違う規則です)。

### 準定常と非定常

- **準定常(`wf_mode = 2`。既定)**: `dt_wave` ごとに定常解を求めます(前回の解から反復。収束の判定は
  `wf_tol`、反復の上限は `wf_itmax`)。地形変化の計算のように、波の伝播時間より長い時間で条件が
  変わる用途向けです。収束しない旨の表示が出たら `wf_itmax` を上げてください。
- **非定常(`wf_mode = 1`)**: 物理時間の時間刻みで毎ステップ進めます。波の前線は群速度で進み、
  十分な時間の後は準定常と同じ定常解に達します。津波・洪水と同時に進めるときに使い、静穏から
  始めるなら `f_wf_init = 0` にします。毎ステップ解くので、浅水流の本体より重くなることがあります。

どちらも MPI の分割数・スレッド数によらず、結果はビット単位で一致します。

### 方向ビンの数と精度

屈折の誤差はビン幅に比例して小さくなります。勾配 1/80 の平行等深線の海浜に 30° で入る波では、
水深 1 m までの平均波向の Snell の法則からのずれが N_θ = 40(既定)で 1.5°、N_θ = 80 で 0.6°、
波高のずれは 0.5%・0.3% でした(test/wfshoal の refr)。

格子の軸・対角に揃った向きに進む波の陰は鋭く出ますが、その間の向きでは陰の縁が数値拡散で
ぼけます。これは実際の回折(陰に回り込む波)とは別物です。

### 砕波と底面摩擦の選び方

- **不規則波**(`wf_wavetype = 1`。既定)の砕波は確率モデルで、`wf_break = 1`(Baldock ら 1998。既定)か
  `2`(Janssen & Battjes 2007。急な海浜で散逸の過大を補正)を選びます。係数 `wf_gamma`・`wf_alpha`・
  `wf_gammax` は既定のまま始めてください。
- **規則波**(`wf_wavetype = 2`)は波高が水深の γ 倍を超えた分を除く飽和砕波だけで、理論解と比べる
  検定用です。
- **底面摩擦** `wf_fw` は既定 0(なし)です。

式は[解説](wavefield_models.md#5-砕波底面摩擦上限)にあります。

## 流れへの作用(wf_flow)

`wf_flow` を 1 か 2 にすると、波浪場が浅水流に作用し、**波によるセットアップ
(汀線付近の平均水位の上昇)・沖のセットダウン・沿岸流**が生じます。既定の 0 では
流れに作用しません(`fn_wavefield` を書いても浅水流の結果は同じ)。

```
&list_wavefield
  ...
  wf_flow = 2              ! 0 作用なし(既定)/ 1 外力 / 2 外力 + GLM + 波・流れの摩擦
/
&list_bound_edge
  f_bc_n = 3               ! 海岸に交わる左右の辺は側方 Neumann(沿岸流が通り抜ける)
  f_bc_s = 3
/
```

**どれを使うか。** 沿岸流・離岸流・河口の流れとの相互作用を見るなら **2** を
使ってください。2 は、波が運ぶ質量(Stokes 輸送)とその戻り流れ(底層の離岸方向の
流れ)、波の軌道流速で強まる底面摩擦を含みます。1 は放射応力の勾配だけを外力として
加える簡略形(セットアップの古典理論と同じ扱い)で、摩擦は流れの流速だけで決まります。
1 では静止に近い流れの摩擦が弱く、始動時の振動が長く残ります(下の「外力の立ち上げ」)。

波の外力(放射応力の勾配)が平均水位を上げ下げし、斜めに入る波の砕波が沿岸方向の外力になって
沿岸流を駆動します。`wf_flow = 2` では、浅水流の流速を Lagrangian 平均流速(水の質量輸送)と読み、
底面の流れ(オイラー流速 = 流速 − Stokes 輸送)が戻り流れを表します(出力の流速の読み方は
[出力・確認](#出力確認))。式は[解説](wavefield_models.md#6-流れへの作用wf_flow)にあります。

### ローラー(f_wf_roller・wf_beta)

砕けた波のエネルギーは、いったん波頭の表面の渦(ローラー)に移ってから散逸します。ローラーは
砕波の運動量をいったん蓄えて岸側で放すので、**外力・セットアップ・沿岸流の最大が砕波点より岸側へ
ずれます**。既定で有効です(`f_wf_roller = 1`、散逸係数 `wf_beta = 0.1`)。

### 外力の立ち上げ(wf_tramp)

準定常の波浪場は開始時に全域で満値になるので、急に加わる外力が汀線付近の振動
(副振動)を起こします。`wf_tramp`(既定 100 s)の間、外力と Stokes 輸送を 0 から線形に
増やします。立ち上げは時間軸の起点 t0 から数えるので、再開(`f_state_restore = 1`)では続きの
値になります。保存した状態を初期条件として使う(`f_state_restore = 2`)ときは新しい時間軸で
立ち上げ直すので、すでに釣り合った状態から続けるなら `wf_tramp = 0` にしてください。

### 砕波による水平混合(list_enc の wf_break_visc)

砕波の乱れは運動量を横方向にも混ぜ、沿岸流の岸沖分布をならします。浅水流の `&list_enc` の
`wf_break_visc`(既定 0 = なし)を正にすると、波浪場が更新ごとに求める渦動粘性
ν_w = M h (D/ρ)^{1/3}(Battjes 1975 型。M = `wf_break_visc`、D は砕波の散逸。ローラーがあれば
ローラーの散逸)を[拡散項](diffusion.md)の ν に足します(`f_diffusion_term = 0` でも拡散項が
計算されます)。M = 1 が XBeach の既定で、混合の強さは校正の量です。ν_w は砕波帯の中で最大になり(test/wfcurrent の海浜で
0.54 m²/s)、沿岸流の最大を下げて分布を岸沖へ広げます(同じ海浜で最大が 3.3% 下がる)。分布は
出力 `Wnu`(`f_wf_outdiag = 1`)で確かめられます。

### 側方の境界(f_bc = 3)

海岸に交わる左右の辺は、**波を側方 Neumann(`wf_bc_side` = 2)、流れを側方 Neumann
(`f_bc_*` = 3。[境界条件](boundary.md))**にします。流れの側方 Neumann は「境界の外にも
同じ海岸が続く」扱いで、沿岸流が辺を通り抜けます(壁にすると沿岸流がせき止められて
辺に偽の循環ができます)。岸沿いに一様な海岸では、境界の行も内部の行と同じ解になります
(test/wfcurrent で全行の差が流速の最大の約 0.03%)。土砂も同じ扱いで、浮遊砂(と水質・塩水などの
スカラー)と掃流砂は辺で勾配 0 になります(地形が変わっても岸沿いに一様な海岸は一様のまま。
test/wfsed)。

辺の近くで流れが岸沿いに一様でなくても(河口・デルタ・構造物の近く、流れによる波の変化
`f_wf_current = 1`、地形の変化)、辺から入る流れを移流が加速することはありません。ただし辺の外も
同じ海岸・同じ地形が続く扱いなので、辺は流れ・地形・波がなるべく岸沿いに一様な区間に置き、
見たい区域を辺から十分離してください。examples/delta の param_wfsed.txt は、比べる相手の wave と
同じく、流れの南北の辺を壁にしています(沿岸流は流入側の壁から立ち上がり、反対側の壁で沖へ
折り返します)。

## 流れによる波の変化(f_wf_current)

`f_wf_current = 1` にすると、浅水流の流れ(河川流・潮流・離岸流・沿岸流・津波の流れ)が
波を変えます。逆流(波と向き合う流れ)では波長が縮んで波高が増し、強い逆流では波が流れを
遡れなくなります(**阻止**)。順流では波長が伸びて波高が下がります。流れの速さが場所で
変わると波の向きも曲がります(流れによる屈折)。河口の噴流が沖からの波の遡上を止める
現象や、離岸流・潮流の上での波の急峻化を表します。

```
&list_wavefield
  ...
  f_wf_current = 1         ! 0 なし(既定)/ 1 流れの波への作用
/
```

波による流れ(`wf_flow`)と組むと、波と流れの双方向の連成になります(沿岸流が波を変え、
その波が沿岸流を起こす)。使う流速は浅水流の流速そのものです(`wf_flow = 2` では Lagrangian
平均流速)。阻止された波のエネルギーは台帳 `wavefield.csv` の blocked に記録して除きます。
式は[解説](wavefield_models.md#7-流れによる波の変化f_wf_current)にあります。

### 沖の格子規模の縞と背景粘性(wf_flow と組むとき)

流れによる波の変化と波による流れ(`wf_flow = 2`)を組むと、沖の静かな水域に波長 3〜4 セルの
斜めの縞(流速・波高・外力)が時間とともに育つことがあります。地形の変化がなくても育ちます
(流れの縞が波を屈折させ、波高の縞が外力の縞を生み、それが流れの縞を強める正帰還です。
仕組みは[解説](wavefield_models.md#73-沖の格子規模の縞の仕組み))。

小さな背景粘性で止まります。[拡散項](diffusion.md)のゼロ方程式モデルに背景粘性を足してください
(`&list_enc` の `f_diffusion_term = 2`、`p_diffusion_nu = 0.05` m²/s 程度)。examples/delta の
wfsed(水深 2 m・周期 6 s・Δx = 5 m)では、沖の流速の縞(3×3 平均からの偏差の rms)が 3 時間で
2 倍以上に育つのが、ν0 = 0.05 で一定に止まり、汀線の近くの流速と河口の噴流の最大はほぼ変わり
ません(−1 %)。

### 計算量と収束

流れがあると、更新ごとにセルとビンごとの分散関係と輸送の分解を求め直し、ビンごとの量を
持ちます。波浪場のメモリは約 3.6 倍になります(倍精度の 1 セルあたり、方向ビン 1 個につき 16 バイトに
42 バイトが加わり、N_θ = 40 で約 0.64 kB から約 2.3 kB)。非定常
(`wf_mode = 1`)では毎ステップ求め直すので重くなります。阻止の近くでは準定常の反復の収束が
遅くなります(test/wfdoppler の河口の噴流で約 2000 回、阻止される水路で約 7000 回)。収束しない
旨の表示が出たら `wf_itmax` を上げてください。

## 土砂への作用(f_wfsed)

[土砂・地形変化](geomorph.md)の掃流砂(`f_fluvial`)・浮遊砂(`f_suspend`)に、`&list_geomorph`
の `f_wfsed = 1` を加えると、波浪場が土砂を動かします。波の軌道運動が海底の砂を攪拌して
(巻き上げと掃流の量を増やし)、波による流れ(沿岸流・戻り流れ)と波の歪度・非対称による
岸向きの速度が砂を運びます。沿岸漂砂(汀線に沿う砂の移動)と、浜の侵食(高波浪の戻り流れで
砂が沖へ)・回復(低波浪の非対称で砂が岸へ)を、地形変化と同じ時間発展で求めます。

```
&list_geomorph
  f_fluvial = 1             ! 掃流砂(攪拌の粒径は fluv_d50)
  f_suspend = 1             ! 浮遊砂(攪拌の粒径は susp_d50)
  f_wfsed = 1               ! 波浪場による攪拌と輸送
  !wfsed_facsk = 0.1        ! 歪度の係数 f_Sk(既定 0.1。0 で岸向きの速度の歪度の項なし)
  !wfsed_facas = 0.1        ! 非対称の係数 f_As(既定 0.1)
  !f_wfsed_turb = 1         ! 砕波の乱れによる攪拌(既定 0 = なし)
/
```

`fn_wavefield` が必要です。波による流れ(`wf_flow = 2`)と組むのが基本の使い方です(沿岸流と
戻り流れが砂を運ぶ。`wf_flow = 0` では流れが波で起きないので、攪拌と岸向きの速度だけが
効きます)。[fn_wave の沿岸漂砂](geomorph.md)(CERC 型)とは同時に使えません(同じ輸送を
二重に数えないため、開始時に停止します)。土石流(`f_debris`)とも併用できません。

- **攪拌**: 波の底面の軌道流速が、掃流砂の流砂量式と浮遊砂の平衡濃度式の無次元掃流力を、波と
  流れを合わせた底面せん断(波の周期の中の最大)まで上げます(閾値の判定も)。波がなければ
  `f_wfsed = 0` と同じ式です。
- **砕波の乱れによる攪拌**(`f_wfsed_turb = 1`。既定 0 = なし): 砕波の乱れが底面まで届く汀線の
  近くで攪拌を強めます(test/wfsed の海浜で、攪拌の速さが汀線のセルで 1.10 倍、砕波の散逸の最大の
  セルで 1.01 倍、沿岸漂砂は 1.9% 増)。底面の乱れは出力 `Wkb`(`f_wf_outdiag = 1`)で確かめられます。
- **輸送**: 砂は、波による流れから Stokes 輸送を除いた Euler 平均流速(砕波帯では沖向きの戻り流れ)と、
  波の歪度・非対称による岸向きの速度 u_a で運ばれます。

式は[解説](wavefield_models.md#8-土砂への作用f_wfsed)にあります。

### 浜の侵食と回復の校正

浜の侵食と回復は、沖向きの戻り流れと岸向きの速度の釣り合いで決まります。高波浪では戻り流れが
勝って砂が沖へ運ばれ(砂州ができる)、低波浪・長周期のうねりでは砕波帯より沖で岸向きの速度が
勝って砂が岸へ戻ります(test/wfsed の storm・calm)。どちらが勝つかは歪度・非対称の係数
`wfsed_facsk`・`wfsed_facas`(既定 0.1)に敏感なので、地形の変化を合わせたい場合はこの 2 つで
校正します。

### 沿岸漂砂の出力と CERC との比較

`f_wf_outdiag = 1` で、掃流砂の推定 Qbx・Qby と浮遊砂の輸送量 Qsx・Qsy(固体体積の単位幅
輸送量 m²/s。向きは流速 u・v と同じ)、岸向きの速度 Wua(m/s)を出力します。海岸に沿う
成分を岸沖方向に積分すると沿岸漂砂量になります。test/wfsed の直線海岸(H_m0 = 1 m、
T = 8 s、20°)では CERC(Komar & Inman 1970)の 1.6 倍程度で、桁が合います
(CERC の係数も過程の漂砂の係数も校正の量です)。

直線海岸の左右の辺は、波・流れと同じく側方 Neumann(`f_bc_*` = 3)にします(土砂も勾配 0。
[側方の境界](#側方の境界f_bc--3))。

### 遡上域の輸送(f_wfswash)

位相平均の波浪場は汀線の手前で止まり(波浪セルは水深 `wf_hmin` 以上)、遡上の流れを持たないので、
上の輸送には、浅瀬の砂を汀線より上(遡上の届く高さ)へ積み上げる過程がありません。
`&list_geomorph` の `f_wfswash = 1` を加えると、汀線の面(湿ったセルと、地盤の高い乾いたセルの間)に、
遡上の 1 周期で積分した正味の輸送の経験式を与えます。

```
&list_geomorph
  f_fluvial = 1
  f_wfsed = 1
  f_wfswash = 1             ! 遡上域の輸送
  wfswash_tanbe = 0.1       ! 前浜の平衡勾配 tanβ_e(必須)
  !wfswash_kc = 1.6e-3      ! 岸沖の輸送係数 K_c(既定 1.6e-3)
  !wfswash_kl = 1.6e-3      ! 沿岸の輸送係数 K_l(既定 = K_c。0 で沿岸の輸送なし)
  !wfswash_phim = 30.0      ! 動く粒子の摩擦角 φ_m (度)(既定 30)
/
```

`f_wfsed = 1` と掃流砂 `f_fluvial = 1` が必要です(流束は掃流砂と同じ面の流束の仕組みに乗せます)。
汀線の水位の上昇(setup)は流れが解く前提なので、波による流れ `wf_flow = 2`(か 1)と組みます
(`wf_flow = 0` では遡上の上限が setup の分だけ低くなり、開始時に警告します)。岩盤下刻
(`f_rockinc`)とは併用できません。

**何が起こるか。**

- **岸沖**: 前浜が平衡勾配 `wfswash_tanbe` より緩ければ砂を遡上の届く高さまで積み上げ(バーム)、
  急なら前浜を削ります。平衡勾配では動きません(Larson ら 2004 の式)。
- **沿岸**: 斜めに入る波の遡上が、砂を汀線に沿って運びます(Larson & Wamsley 2007 の式)。平均波向が
  汀線の法線から 80° 以上なら沿岸の輸送はありません。
- **遡上の高さ**: 汀線のセルの水位(流れが解いた setup を含む)から、入射波の波高・周期と前浜の勾配で
  決まる遡上の振れ幅(Stockdon ら 2006 の式)だけ上までです。堆積はこの高さを越えません。
- **波の届き方**: デルタの陰や河道の内部のように波が届きにくい汀線では、近くの波高に応じて遡上を
  小さくします。近くに波浪セルがない汀線と、遡上の届かない崖・護岸の前の汀線では動きません。

式・係数・格子への当てはめは[解説](wavefield_models.md#9-遡上域の輸送f_wfswash)にあります。

**使い方の注意。**

- 前浜の勾配は 2 セルにわたる中央差分なので、格子が粗いほど平均化されます。遡上域(幅は遡上の高さ /
  前浜の勾配)が 1 セルより狭い粗い格子では、汀線の隣の乾いたセル 1 つに砂が積み上がり(バーム)、
  その先の乾いたセルは変わりません。
- 平衡勾配 tanβ_e は利用者が与える量です(粒径と波で決まり、粒径が大きいほど急。現地の前浜の
  勾配の観測から与えるのが基本です)。係数 K_c の既定は細砂(0.18 mm)の現地観測で較正した値です。
- 地形の更新が汀線の水位を変えるので、汀線から小さな長波が出ます。沖の深い所の Courant 数が 1 に
  近いと、それが沖の境界で育って計算が止まることがあります(test/wfswash では 0.88 で発生、0.44
  で安定)。時間刻み `dt` に余裕を持たせてください。
- 運んだ量は終了時に表示します(乾いた前浜へ運んだ固体体積・前浜から運び出した体積・沿岸の流束が
  面を通した体積の絶対値の和。ランクごと)。
- 使用例: [examples/delta](../../examples/delta/README.md) の wfsed(README の「沿岸の波浪場」)。遡上域の
  輸送で陸化が約 1.4 倍になり、陸地が遡上の届く高さまで積み上がります(陸地の縁は 1 セル規模で
  入り組みます)。

## 出力・確認

**分布**(出力時刻ごと。[入出力の形式](io.md))

| 記号 | 内容 | 単位 |
|---|---|---|
| Wh | 波高(不規則波は H_m0、規則波は H) | m |
| Wa | 平均波向(進む向き。x 軸から反時計回り。無波セルは −9999) | deg |
| Wu | 底面軌道流速 u_rms = H_rms σ/(2√2 sinh kh)(XBeach の定義)。`f_wf_outdiag = 1` | m/s |
| Wb | 砕波散逸 D_w(不規則波)。`f_wf_outdiag = 1` | W/m² |
| Wfx・Wfy | 波の外力 F = −∇·S(セル中心。ローラーを含む)。`wf_flow` ≥ 1 かつ `f_wf_outdiag = 1` | N/m² |
| Wsx・Wsy | Stokes 輸送の速さ u^S。`wf_flow = 2` かつ `f_wf_outdiag = 1` | m/s |
| Wr | ローラーのエネルギー E_r。`f_wf_roller = 1` かつ `f_wf_outdiag = 1` | J/m² |
| Qbx・Qby | 掃流砂の輸送量の推定(固体体積の単位幅。fn_geomorph の `f_wfsed = 1`・`f_fluvial = 1`)。`f_wf_outdiag = 1` | m²/s |
| Qsx・Qsy | 浮遊砂の輸送量 hs·u_s(同、`f_suspend = 1`)。`f_wf_outdiag = 1` | m²/s |
| Wua | 波の歪度・非対称による岸向きの輸送速度 u_a(平均波向の向きが正。`f_wfsed = 1`)。`f_wf_outdiag = 1` | m/s |
| Wnu | 砕波による水平混合の渦動粘性 ν_w(&list_enc の `wf_break_visc` > 0)。`f_wf_outdiag = 1` | m²/s |
| Wkb | 底面の乱れのエネルギー k_b(fn_geomorph の `f_wfsed_turb = 1`)。`f_wf_outdiag = 1`。このとき Wu は乱れを含まない u_rms | m²/s² |

**y の成分(Wfy・Wsy・Qby・Qsy)は流速 v と同じ向き(行の増える向き = 南が正)です。** 波向の
規約(北が正)とは逆なので注意してください。`wf_flow = 2` の流速 u・v は Lagrangian
平均流速 u^L で、底面の流れ(オイラー流速)は u − Wsx、v − Wsy です。

**台帳** `result/wavefield.csv`。準定常は更新ごとに収束時の率(W)を、非定常は
計測間隔(`dt_recrd`)ごとに累積量(J)を書きます。

| 列 | 内容 |
|---|---|
| iter・residual(準定常)/ nsub(非定常) | 反復回数と最後の残差 / サブステップ数 |
| H_bc・T_bc・dir_bc | その時刻の沖の波 |
| in・out | 境界からの流入・境界への流出(側方 Neumann の辺の出入りを含む) |
| absorbed | 陸・乾燥・吸収セルへ向かって失われた分 |
| breaking・friction | 砕波・底面摩擦の散逸 |
| limit | 上限(不規則波の H_rms ≤ γmax h、規則波の飽和)で除いた分 |
| dry | 水深が `wf_hmin` 以下になったセルから除いた分(量 J) |
| trunc | 数値的な切り捨て(負値の 0 化で足した分。通常は 0 か丸め誤差の規模) |
| imbalance・storage | 収支の残差・波浪場の貯留(Σ E A) |
| blocked(`f_wf_current = 1`) | 阻止で除いた分 |

`f_wf_current = 1` では台帳の量は作用量 × ω(流れがなければエネルギーと同じ)です。
準定常の imbalance は最後の反復での貯留の変化率で、`wf_tol` を小さくすると 0 に
近づきます。非定常の imbalance は(貯留の変化)−(正味の入力)で、丸め誤差の規模です。
大きな値が出たら不具合なので報告してください。

## 適用範囲と併用の制限

- **位相平均・代表周期 1 個**です。回折・反射・周波数の広がり・風による発達・非線形の
  波の相互作用は扱いません。陰の縁のぼけは数値拡散で、回折ではありません。
- **土砂への作用(`f_wfsed`)**: 攪拌は既定では底面の軌道流速だけです(砕波の乱れによる巻き上げは
  `f_wfsed_turb = 1` で加えられます)。浮遊砂の水平拡散はありません。位相平均の波は汀線の手前で止まるので、
  遡上域(swash)の輸送は経験式(`f_wfswash = 1`。上の「遡上域の輸送」)で加えます。既定(0)では
  浅瀬の砂を汀線より上へ積み上げる過程がなく、砂は浅瀬にとどまって陸になりにくくなります。
  砂丘の崩れは安息角崩落 `f_repose` です。代表粒径は掃流砂・浮遊砂それぞれ 1 つです。浜の侵食と回復を分ける戻り流れと岸向きの速度の釣り合いは
  係数 f_Sk・f_As に敏感です(校正の量)。岸向きの速度の元になる波の歪度・非対称のパラメータ化(Ruessink ら
  2012)は、海底勾配が 1/30 より緩い海浜の現地観測に基づくもので、それより急な海底では使わないよう勧められて
  います。方向の狭いうねりでは歪度を過小に見積もる可能性があります。
- **阻止された波は作用量を除くだけ**で、阻止の点での反射(短い波への変換)は表しません。
  代表周期 1 個なので、阻止はすべてのエネルギーに同時に起こります(実際の波はスペクトルの
  短い成分から阻止されます)。阻止の手前の急峻化による砕波は表します。
- 流れが時間変化しても、沖の波の角周波数 ω は一定とします(流れの時間変化による ω の変化は
  入れません)。
- **流れの急な変化**(湧き出しの近く・噴流の縁)では、単一方向の波が流れによる屈折で隣の
  ビンへ数 % 広がります(方向空間の 1 次風上の数値拡散。ビン幅の 2 乗で小さくなります)。
- **砕波による横方向の混合(渦粘性)は既定では入りません。** 既定では沿岸流の分布は、ENC の
  斜めの面の移流による数値的な横混合でならされます(砕波の始まりの外縁に最大の数 % の流れが
  出ます)。波による混合は `wf_break_visc`(&list_enc。Battjes 1975 型。上の「砕波による
  水平混合」)で加えられます。混合の強さ M は校正の量です。
- **方向分散 0 の単一方向の波(規則波を含む)は、屈折が Snell の法則より遅れます**
  (N_θ = 40、入射 20° で砕波点の向きが約 1.5° 大きい)。沿岸方向の放射応力 S_xy は
  向きに敏感なので、砕波帯より沖に偽の沿岸方向の外力が出ます(砕波帯の外力の約 5%。
  方向分散 20° では約 1%)。沿岸流を見るときは方向分散を与えるか、ビン数を増やして
  ください。
- **側方 Neumann の辺**は「外にも同じ海岸が続く」扱いです。地形が辺の近くで岸沿いに
  変わる場合や、構造物が辺に接する場合は、見たい区域を辺から十分離してください
  ([側方の境界](#側方の境界f_bc--3))。
- **海域マスクの海セル(sw)は波浪の計算域外**です。沖は海底地形を持つ通常のセルで表し、
  入射の境界は外縁の辺に置きます。
- **STG 格子・ネストとは併用できません**(開始時に停止します)。
- 家屋の空隙率 gv < 1 のセル、サブグリッド河道の幅・断面形のセルは波を吸収します。
- 計算量: 方向ビン数 N_θ 個の面を持ち、1 回の更新は N_θ 回のスカラー輸送とセルごとの
  三重対角です。準定常の 1 回の解は数百回の反復です(100 × 100 セル・40 ビンで
  367 回・約 2 秒、4 スレッド)。非定常で毎ステップ解くと浅水流本体より重くなることが
  あります。
