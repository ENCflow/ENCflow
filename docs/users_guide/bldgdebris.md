# 家屋破壊・瓦礫(fn_bldgdebris)

[ユーザーガイド目次へ](../users_guide.md)

津波・高潮・洪水の氾濫流による**木造家屋群の破壊**と、生じた**瓦礫**の
流動・堆積を、セルごとの柱状材積(m³/m²)の**ラスタ場**として概算します。
個々の家屋の構造応答や個々の瓦礫の軌跡を追う方式ではなく、「どこの
家屋がどの程度壊れ、瓦礫がどこまで届き、どこに残るか」の面的な
ポテンシャル評価が目的です。流木モジュール([流木](driftwood.md))と
同じ型の別モジュールで、同時に有効化すると**流木を含む流れによる
家屋破壊**が表現できます。

瓦礫は3つの台帳を移動します:

```
家屋ストック wbs ──破壊──> 流動瓦礫 hbd ──接地・低速──> 堆積瓦礫 wbd
 (不動・入力)            (水と同速で移流)            (再流動も可)
                 └──沈下分(bd_fsink)──────────────────┘
```

- **破壊**: 判定量が閾値を超えたセルの家屋ストックが、指定レートで
  瓦礫化します。判定量は**浸水深**(`f_bdcrit=1`。実務の浸水深ベースの
  被害関数と対応)か、**荷重**(`f_bdcrit=2`。流木・瓦礫を含む流れの
  運動量流束 (h + (1+s)·hs + sg木·hd + sg瓦礫·hbd)·V²。F9999 と同じ基底)を
  選びます。荷重判定では**流動流木 hd と流動瓦礫 hbd が破壊力に加わる**
  ため、流木 → 家屋破壊 → 瓦礫 → 更なる破壊の連鎖が一つの時間発展で
  つながります。
- **停止**: 水深が喫水(瓦礫の見かけ比重と代表寸法から円柱の浮力平衡で
  決まる浮遊限界水深。流木と同じ導出)を下回るか低速になったセルで
  堆積します。乾燥したセルでは全量が堆積に移ります。
- **輸送**: 流動瓦礫は水(土石流有効時は混合体)と同じ速度で移流します。
- **空隙率への帰還**(`f_bdgv=1`。既定): 破壊率に応じて建物の空隙率 gv が
  上がり、同じ水が広い面積に広がって水位が下がる = 破壊が流れへ返ります
  (体積は厳密に保存)。`f_bdgv=0` にすると片方向結合(破壊率と瓦礫の
  分布を出すだけで流れは変わらない)になり、同一ケースで帰還の効果を
  比較できます。

## 有効化と設定

`&list_sysparam` で `fn_bldgdebris` を指定します。

**「とりあえず瓦礫を動かしてみる」最小入力は、建物の空隙率 `fn_gv`
のある地形で `&list_bldgdebris` を空のまま置くだけです**(全項目が既定)。
家屋ストックは建物のあるセル(gv < 1)に一様 0.3 m³/m² が置かれ、瓦礫の
諸元・破壊判定(浸水深 1 m から 3 m の線形ランプ)・レートはすべて既定値で
動きます。採用された既定値は実行開始時に
`bldgdebris: bd_hcrit = 1.0000 m (default)` のように **(default)** 印付きで
表示されるので、値を見ずに済ませることはできません。事例に合わせて必ず
見直してください(型ごとの目安は本章末尾の「パターン別の推奨値」)。

```
&list_bldgdebris
/
```

実務では家屋ストックの分布と判定の閾値を与えます:

```
&list_bldgdebris
  fn_bdstock = 'bdstock.txt' ! 家屋ストック (m3/m2。瓦礫化可能材積。木造率込み)
  bd_dlog = 0.3             ! 瓦礫の代表寸法 (m)
  bd_sg = 0.5               ! 瓦礫の見かけ比重(0〜1。喫水は浮力平衡から自動導出)
  f_bdcrit = 1              ! 判定量(1:浸水深、2:荷重)
  bd_hcrit = 1.0            ! 浸水深閾値 (m。破壊の開始)
  bd_hcrit2 = 3.0           ! 第2閾値 (m。破壊可能率 1)
  bd_wdes = 5.0e-4          ! 破壊レート (m/s)
  bd_wstop = 0.01           ! 接地堆積レート (m/s)
/
```

## パラメータ

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_bd | 1 | 0 でファイルを残したまま一時無効化 |
| bd_stock0 | (0.3 を建物セルに) | 一様な家屋ストック (m³/m²。全セル)。fn_bdstock と排他。**両方未指定なら建物のあるセル(gv < 1)にだけ 0.3 m³/m²** を置く(fn_gv がなく建物セルが無ければ停止) |
| fn_bdstock | — | 家屋ストック(瓦礫化可能材積)の分布ファイル (m³/m²。地形と同じ行列形式)。木造率はここに織り込む(木造率 30 % のセルは 100 % のセルの 30 %) |
| fn_bdfrac | — | 建物占有のうち破壊可能な割合 fw(0〜1)の分布ファイル。省略時 1。RC 造・耐津波構造が残るセルで空隙率帰還の上限 gv0 + (1−gv0)·fw を決める |
| bd_dlog | 0.3 | 瓦礫の代表寸法 (m) |
| bd_sg | 0.5 | 瓦礫の見かけ比重(0〜1)。喫水は流木と同じ円柱の浮力平衡の厳密解(0.5 × 0.3 m で 0.15 m) |
| f_bdcrit | 1 | 破壊判定量。1 = 浸水深 h+hs、2 = 荷重 (h+(1+s)hs+sg木·hd+sg瓦礫·hbd)·V² |
| bd_hcrit | 1.0 | 浸水深閾値 (m。f_bdcrit=1) |
| bd_hcrit2 | 3.0 | 浸水深の第2閾値 (m。閾値1で 0、閾値2で 1 になる線形の破壊可能率をレートに掛ける = 被害関数の幅の近似)。**両方未指定なら 1.0〜3.0 のランプ、bd_hcrit だけを指定するとランプなし(単一閾値)** |
| bd_fcrit | 2.0 | 荷重閾値 (m³/s²。f_bdcrit=2) |
| bd_fcrit2 | 6.0 | 荷重の第2閾値 (m³/s²。同上。bd_fcrit だけを指定するとランプなし) |
| bd_wdes | 5.0e-4 | 破壊レート (m/s = m³/m²/s)。破壊の所要時間 = ストック ÷ レート(既定は 0.3 m³/m² が 10 分で全壊) |
| bd_fsink | 0 | 沈下率(0〜1)。破壊量のうちこの比率をその場で堆積に移す(瓦・基礎など沈む瓦礫の抽象化。0 = 全量浮遊 = 到達範囲の上限側) |
| bd_wstop | 0.01 | 接地堆積レート (m/s) |
| bd_vstop | 0.05 | 低速堆積の流速閾値 (m/s。0 = 水深(喫水)判定のみ。既定は湛水して流れが止まったら堆積) |
| bd_wfloat | 0 | 再流動レート (m/s。0 = 堆積した瓦礫は動かない(安全側)) |
| bd_rfloat | 1.5 | 再流動の浮遊余裕率(水深 > rfloat×喫水 で再流動。1 より大) |
| bd_vfloat | — | 再流動の流速閾値 (m/s。bd_wfloat > 0 のとき必須。bd_vstop 以上) |
| f_bdgv | 1 | 1 = 破壊率に応じて空隙率を上げる(帰還あり)、0 = 片方向結合 |

**閾値の当たり**(いずれも校正パラメータ。文献照合の記録は
developer.md §63.7):

- **浸水深閾値(f_bdcrit=1)**: 首藤(1993)の津波強度と家屋被害の対応では
  木造家屋は浸水深 2 m 超で全壊、1 m 程度で部分破壊。東北地方太平洋沖
  地震津波の被害関数(Suppasri ほか 2013。構造種別・階数別)でも木造の
  流失確率は 2 m 前後で急増し、4 m 超で大半が流失します。被害関数が確率
  曲線であるのに対し本モジュールは閾値+レート(または 2 閾値の線形
  ランプ)なので、「曲線の中央値を bd_hcrit〜bd_hcrit2 の中点、曲線の幅を
  ランプ幅」と読み替えてください(例題は 1.0〜3.0 m)。RC 造は同じ浸水深
  でも流失しにくいため、fn_bdstock(木造率)と fn_bdfrac で表します。
- **荷重閾値(f_bdcrit=2)**: 単位は F9999 と同じ m³/s²(清水規格化。
  ×ρw で N/m)。Koshimura ほか(2009)の流体力ベースの被害関数
  (F = ½ρ C_D u²h)から換算するか、水のみの F9999 の分布と被害実績を
  突き合わせて決めます。FEMA P-646 は瓦礫を含む流れの流体力に係数
  k_s(推奨 1.25)を乗じますが、本モジュールは同じ効果を浮遊物の柱状量から
  計算します(流木・瓦礫の項)。これは「浮遊物を含む流れの平均的な
  破壊力」であり、1 本の材の衝撃荷重や堰き止め力(国総研資料 905 §4.3、
  FEMA P-646 の個別荷重)の置き換えではありません。
- **家屋ストック**: 延床面積 × 構造材積原単位 × 木造率をセルで集計して
  与えます(建物台帳からの集計は前処理)。棟数・金額への換算は後処理です。

既定値の根拠は developer.md §63.9。

## パターン別の推奨値

既定値は「動く」ための中庸です。現象の型が決まっているときは次を
出発点にしてください(校正で変わる量です。出典は developer.md §63.7)。

| 型 | 判定 | 閾値 | ストック・諸元 | レート・堆積 | 備考 |
|---|---|---|---|---|---|
| 津波の市街地遡上(木造密集地) | f_bdcrit=1 | bd_hcrit 1.0 / bd_hcrit2 3.0 m(首藤 1993: 2 m 超で全壊。Suppasri ほか 2013 の木造流失曲線の幅) | 0.2〜0.4 m³/m² × 木造率。bd_dlog 0.3、bd_sg 0.5 | bd_wdes 5e-4(押し波 10 分で全壊)、bd_fsink 0.2〜0.4、bd_vstop 0.05 | 空隙率帰還あり。例題 tsunami_town |
| 津波(流木・瓦礫の連鎖を見る) | f_bdcrit=2 | bd_fcrit 2 / bd_fcrit2 6 m³/s²(浸水深 2 m・流速 1〜1.7 m/s 相当。Koshimura ほか 2009 の流体力曲線で換算) | 同上。流木は fn_driftwood と同時有効化 | 同上 | 水のみの F9999 の分布を見て閾値を置き直す |
| 高潮・河川氾濫(低平地の住宅地。流速小) | f_bdcrit=1 | bd_hcrit 2.0 / bd_hcrit2 4.0 m(浸水は深くても流速が小さく、津波より壊れにくい側) | 0.2〜0.3 × 木造率 | bd_wdes 1e-4(数十分〜時間の冠水で徐々に)、bd_vstop 0.02 | 床上浸水の損傷(非破壊)は対象外 = 全壊・流失だけを数える |
| 土石流・氾濫流の集落直撃(山地渓流) | f_bdcrit=2 | bd_fcrit 1 / bd_fcrit2 4 m³/s²(混合流動深 h+hs と混合密度 1+sC が荷重に入る) | 0.2〜0.3 × 木造率。bd_sg 0.5 | bd_wdes 1e-3(数分で全壊)、bd_fsink 0.5(土砂に埋まる分) | f_debris と同時有効化。瓦礫は混合体と同速 |
| 到達範囲の上限側評価(ハザードマップ) | 事例の判定 | 事例の閾値 | 同上 | bd_fsink 0、bd_vstop 0、bd_wfloat 0 | Bd9999 を使う。残留量は bd_vstop・bd_wfloat に敏感(例題 README) |
| 耐津波化・都市化のシナリオ比較 | 事例の判定 | 事例の閾値 | fn_bdstock(木造率込み)と fn_bdfrac を差し替え | 同上 | 2 ケース比較。コード側の追加なし |

## 出力

| スイッチ | ファイル | 内容 |
|---|---|---|
| f_out_hbd | Bf0001… | 流動瓦礫の柱状材積 (m³/m²) の分布(dt_file 間隔) |
| f_out_wbd | Bd0001… | 堆積瓦礫 (m³/m²) の分布 |
| f_out_wbd | Bd9999 | **期間最大の到達量** max(流動+堆積)。瓦礫ハザードマップの本体 |
| f_out_bds | Bs0001… | 家屋の破壊率 1 − 残ストック/初期ストック(0〜1)。最終フレームが被害率マップ |
| f_out_fdmax | Fd9999 | 流木・瓦礫込みの最大流体力 (h+(1+s)hs+sg木·hd+sg瓦礫·hbd)·V²(既存の F9999 は水と土砂のみで定義不変) |

`result/bldgdebris.csv` に材積台帳(破壊(浮遊・沈下)・堆積・再流動・
ダム捕捉の累積と現在貯留)が dt_recrd 間隔で記録されます。閉領域なら
「ストック+流動+堆積」の総和が初期ストック総量と機械精度で一致します。
材積への換算は柱状量 × gv × セル面積です(空隙率が変わるセルでも体積は
保存されます)。

## 併用関係・制約

- ENC 格子のみ。地形時間の加速(morfac ≠ 1)とは併用できません。
- [流木](driftwood.md)との併用は自由で、荷重判定(f_bdcrit=2)のとき
  流動流木が破壊力に算入されます。流木モジュール側は瓦礫を知りません
  (一方向)。[土砂・地形変化](geomorph.md)・地下水とも併用可。
- **空隙率への帰還**(f_bdgv=1)では、破壊したセルの水深が体積保存の
  もとで縮み(h × gv が不変)、地下貯留は変わりません。家屋の平均サイズ
  bb は変えません(全壊で空隙率 1 = 建物なしの扱いに自動で移ります)。
- **ダムの捕捉帯**に入った流動瓦礫はダムに捕捉されます。**カルバート・
  ポンプ**は水だけを送るため、瓦礫は施設の上流に滞留します。
- 中断・再開(save/restore)では瓦礫の全台帳と変更後の空隙率が
  `bldgdebris.dat` に保存され、分割実行しても厳密に連続します。

## 例題: 津波の市街地遡上と家屋破壊・瓦礫

沿岸市街地への津波遡上で木造家屋が破壊され、瓦礫が内陸へ運ばれて堆積する
理想化実験を [examples/tsunami_town](../../examples/tsunami_town/) に
収録しています(流木なし/あり、浸水深判定/荷重判定、空隙率帰還あり/なし
の比較。解説は README)。

## モデル化していないもの

個別家屋の構造応答、個別瓦礫の軌跡・向き・回転・相互作用、瓦礫・流木の
個別衝突力、瓦礫による閉塞の幾何判定、火災、堆積瓦礫の地形 z への算入と
空隙の再閉塞は対象外です(ラスタ表現の方針による明示的な適用限界)。
RC 造・鉄骨造は「破壊されない占有」として fn_bdfrac で表し、構造種別
ごとに閾値を変える多クラス化は将来課題です。実装仕様は developer.md §63。
