# 田んぼダム(水田の落水口の流出抑制。fn_paddy)

[ユーザーガイド目次へ](../users_guide.md)

**田んぼダム**は、水田の落水口(排水枡)に流出量を絞る板(穴・切欠き)を付け、豪雨の水を畦畔の中に
一時的に貯めて、下流の排水路・河川のピークを下げる取組です[^maff2026]。この機能は、水田の貯留と
落水口の流量則を格子の上に置き、取組率(水田のうち田んぼダムにした割合)・装置の型・事前の湛水の
状態を変えて、流出と浸水がどう変わるかを見積もるためのものです。

水田の表し方は格子の大きさに合わせて 2 つあり、入力で選びます。

- **A: サブグリッドのタンク**(水田面積率 `fn_pd_frac`・`pd_frac` を与える): セルの中の水田をタンクとして表します
  (下の[計算のしくみ](#計算のしくみ))。100〜200 m の流域モデルから 20〜50 m の排水区の格子まで、同じ式で使えます。
  地表の水とのやり取りは 2 通りから選べます。既定の**片方向**は水田の上の雨だけをタンクに入れ、**双方向**
  (`f_pd_exchange = 1`)は河川や排水路から来た外水・内水も、落水口と畦畔を通って水田に入ります(下の
  [地表の水との関係](#地表の水との関係片方向と双方向))。
- **B: 区画の解像**(区画番号の分布 `fn_pd_plot` を与える): 5〜10 m の格子で個々の区画をセルの集まりとして解き、
  畦畔を仮想壁面、落水口をその切欠きとして表します(下の[区画の解像(B)](#区画の解像b))。区画の湛水・畦畔の越流・
  排水路からの逆流・外水の流入を、浅水流の計算そのものとして表します。

同じ計算で A と B を混ぜることはできません。以下の A の説明(水田のタンク・地表の水との関係)は B には当てはまりません。

- **水田のタンク**: セルの水田面積率 a の上に降った雨を受けるタンクです。取組率で
  「通常の落水口の水田」(種類 1)と「田んぼダムの水田」(種類 2)に分け、種類ごとに 1 つの
  湛水深(田面からの水深)を持ちます。畦畔・農道・台地に降って水田へ流れ込む雨は、集水面積率
  `fn_pd_catch` で与えると、そのセルと周りのセルのタンクに入ります(下の[集水面積率](#集水面積率fn_pd_catch))。
- **落水口**: 代表区画面積 A_plot ごとに 1 か所あり、湛水深と下流(セルの地表)の水深から
  装置則で流量を決めます。流量はセルの地表へ移り、浅水流で流れます。
- **畦畔**: 湛水深が畦畔高を超えた分は、すぐに地表へあふれます。双方向では、地表の水位が畦畔を越えると
  水田がすぐに満ちます。

設計の経緯と決定は developer.md §127、検討と文献の一覧は docs/paddy_plan.md にあります。

## 有効化と設定

`&list_sysparam` で `fn_paddy` を指定します(`"-"` なら同じパラメータファイル)。設定は 1 つの
グループです。

```
&list_paddy
  fn_pd_frac = 'paddy_frac.txt'   ! 水田面積率の分布(セル面積に対する割合 0〜1)
  pd_adopt = 0.5                  ! 取組率(水田のうち田んぼダムの割合。省略時 0)
  !pd_aplot = 3000.0              ! 代表区画面積 (m2。省略時 3000)
  !pd_hlev = 0.30                 ! 畦畔高 (m。省略時 0.30)
  !pd_dev_type(2) = 1             ! 田んぼダムの装置の型(省略時 1 = 機能分離型)
  !pd_open_d(2) = 0.05            ! 流出量調整板の穴の径 (m。省略時 0.05)
  !f_pd_exchange = 1              ! 外水・内水も水田に入る双方向(省略時 0 = 雨だけの片方向)
  !fn_pd_catch = 'paddy_catch.txt' ! 集水面積率の分布(雨が水田へ流れ込む面積の割合。省略時 0)
/
```

`f_paddy = 0` で書いたまま一時無効化できます。面積率は分布 `fn_pd_frac` か一様値 `pd_frac` の
どちらか、取組率は分布 `fn_pd_adopt` か一様値 `pd_adopt` のどちらかで与えます。

区画を解像する B では、面積率の代わりに区画番号を与えます(A だけの入力 `fn_pd_frac`・`pd_frac`・`fn_pd_adopt`・
`pd_adopt`・`pd_aplot`・`f_pd_exchange` と併せると停止します)。

```
&list_paddy
  fn_pd_plot = 'plot.txt'         ! 区画番号の分布(0 = 水田でない。整数)
  fn_pd_outlet = 'outlet.txt'     ! 落水口の向き(落水口のある出口セルに 1〜8、ほかは 0)
  fn_pd_class = 'class.txt'       ! 落水口の種類(区画のセルに 1 = 通常、2 = 田んぼダム。省略時 全て 1)
  !pd_hlev = 0.30                 ! 畦畔高 (m。省略時 0.30。全区画で同じ)
  !pd_dev_type(2) = 1             ! 田んぼダムの装置の型(A と同じ)
/
```

## とりあえず動かしてみる(最小入力)

必要なのは**水田面積率**(`fn_pd_frac` か `pd_frac`)だけです。土地利用データ(例: 国土数値情報の
土地利用細分メッシュの「田」)から、格子のセルごとの面積の割合を前処理で作ってください(本体は
土地利用を読みません。土地利用からマスクを作る前処理と同じ考え方です。[地理情報](geoinfo.md)の海域マスク・河道マスクの節、
developer.md §40)。ほかを省略すると、区画 30 a・畦畔
0.30 m・減水深 5 mm/d・取組なし(全て通常の落水口 = 水位調整板 0.03 m × 幅 0.30 m)を使い、
採用した値を画面に `(default)` を付けて表示します。田んぼダムの効果は `pd_adopt` を与えて比べます。

**使い方の型**

| 型 | 構成 | 見るもの |
|---|---|---|
| 流域の河川のピーク(100〜200 m) | 水田面積率の分布 + 取組率 0 と 1(と途中)の計算を比べる | 河道の測線の流量のピーク・時刻、`paddy.csv` の貯留と満水の割合 |
| 排水区の幹線の水位(20〜50 m) | 幹線排水路を河道マスク・サブグリッド幅で、水田を面積率で | 幹線の測線の流量・プローブの水位、`Hpd` の湛水深 |
| 装置の比べ | `pd_dev_type(2)` と穴の大きさを変える | `paddy.csv` の流出(落水と越流)の速さ `qsurf` と貯留 |
| 事前の状態の比べ | `pd_h0`(0 = 中干しで空、0.03 = 通常の湛水、0.30 = 前の雨で満水) | 同上 |
| 外水・内水の氾濫(粗い格子) | `f_pd_exchange = 1`。河川の越水・破堤や排水路の背水を河道・境界で与える | 浸水深 `H`、`paddy.csv` の流入 inflow・levee_in、`Hpn`・`Hpd` |
| 区画の湛水・越流・背水(5〜10 m の B) | `fn_pd_plot`・`fn_pd_outlet`・`fn_pd_class`。農道・排水路・集落を地形で、排水機場・樋門を境界・構造物で | 水深 `H`(区画の湛水深を含む)、排水路の測線・プローブ、`paddy.csv` の落水口・畦畔の流出入 |

B の入力は、筆ポリゴン(農地の区画の多角形)などから前処理で作ります。区画番号は区画の多角形を格子に焼き付けた
もの、落水口は区画ごとに出口セルと向き(排水路の側)を選んだもの、種類は取組の区画に 2 を入れたものです。区画の幅に
3 セル以上が要るので、30 a の標準区画(30 m × 100 m)では格子は 10 m 以下が目安です。田面の高さは区画ごとに平らに
してください(5 m の DEM のままでは区画の貯留に ±14〜15 % の誤差が出る例があります[^tebakari2023])。

## 計算のしくみ

### 水田のタンク

セル (i, j) の水田面積率 a を、取組率 r で 2 つの種類に分けます。

```math
a_1 = a\,(1 - r)\ (\text{通常の落水口}),\qquad a_2 = a\,r\ (\text{田んぼダムの落水口})
```

種類 c の水田はセル内で同じ湛水深 $`H_c`$(田面からの水深)を持ち、落水口は代表区画面積
$`A_{\mathrm{plot}}`$ ごとに 1 か所あるとします。セルの落水口の数は $`N_c = a_c\,\Delta x\,\Delta y/A_{\mathrm{plot}}`$、
セルの流出は $`N_c\,Q_c`$ で、水田面積あたりの流出強度は

```math
q_c = \frac{Q_c(H_c, h_D)}{A_{\mathrm{plot}}}
```

です。$`q_c`$ は格子の大きさによらないので、100 m の格子でも 20 m の格子でも同じ水田は同じ応答をします
(粗い格子の分布型流出モデルで水田をセルの面積率のタンクにした前例[^nihei2024]と同じ形)。
毎ステップ(浅水流の直後)に次の順で進めます。

1. **雨**: 水田の上に降った雨 $`a\,R\,\Delta t`$ を地表の水から引き、各タンクに $`R\,\Delta t`$ を足します
   (R は地上の雨。[降雨遮断](forcing.md)があれば遮断の後)。集水面積率 c があれば、引く雨は
   $`(a + c)\,R\,\Delta t`$ で、集水面積の雨は周りの 3 × 3 のセルの水田へ配ります(下の[集水面積率](#集水面積率fn_pd_catch))。
2. **落水**: $`\Delta H = q_c\,\Delta t`$ を地表へ移します。$`h_D`$ はセルの地表水深(落水口の下流の水位を
   田面から測った値)です。
3. **越流**: $`H_c`$ が畦畔高を超えた分を、すぐに地表へ移します(農林水産省の水田流出簡易計算
   プログラムと同じ扱い[^maff2026])。
4. **減水深**: `pd_perc_mmd` の割合で系外へ出します(地下水には入りません)。

地表へ移った水はセルの地表水として浅水流で流れ、河道・排水路へ集まります。

#### 集水面積率(fn_pd_catch)

区画より高い畦畔・農道・台地に降った雨の一部は、畦畔を越えて隣の水田へ流れ込みます。粗い格子の A では、
これらはセルの水田でない部分なので、何もしなければその雨は地表の水になって排水路へ向かいます(排水路へ出る水を
多く、田んぼダムの効果を小さく見積もる)。集水面積率 c(`fn_pd_catch`。セルの面積のうち、雨が水田へ流れ込む
部分の割合)を与えると、その雨もタンクに入ります。

- 地表から引く雨は、雨の降るセルの $`(a + c)\,R\,\Delta t`$ です。集水面積の雨 $`c\,R\,\Delta t`$ は、そのセルを
  中心とする 3 × 3 のセル(領域の外は除く)の水田へ、水田の面積の比で配ります(種類を問いません。独自の簡略化)。
  配る先のどのタンクも同じ水深 $`w = c\,R\,\Delta t/A`$($`A`$ = その 3 × 3 のセルの水田面積率の和)を受け、
  水田のセルのタンクの雨は、そのセルの雨 $`R\,\Delta t`$ に、周りの雨の降るセルから受けた $`w`$ の和を足した値です。
  配った水の総量は集水面積の雨に等しく、降ったステップのうちにタンクへ入ります(流下の時間は持ちません)。
- 周りのセルへ配るのは、1 つの区画が粗いセルの境をまたぐと、区画の一部と農道・台地だけを含むセルができるからです。
  同じセルのタンクだけに入れると、そこへ集水面積の雨が集まってあふれやすくなります(例題
  [paddy_dam](../../examples/paddy_dam/README.md) の D では、区画を解像した計算との差の最大の要因でした。
  developer.md §127.14)。周りへ配ることは、区画の中で水が広がることの近似です。
- タンクの面積・落水口の数・畦畔・減水深・双方向の断面(水田でない面積の割合 1 − a/gv)は a のままです。
  面積率に集水面積を足す近似と違い、湛水深と落水口の数は変わりません。
- c は雨の降るセルで数えます(本体は地形をたどりません)。高解像の地形と区画図から、区画でも排水路でもないセルの
  雨を低い隣のセルへ等しく分けてたどり、区画に着く割合を、雨の降る粗いセルで集計します(例題
  [paddy_dam](../../examples/paddy_dam/README.md) の `make_district.py` の `catchment()`)。等しく分けるのは、区画・
  排水路より高い農道・台地から段を落ちる流れの量が、落ちる先の深さによらないからです(最急の下り 1 つや勾配の比で
  たどると、水田と排水路にはさまれた農道の雨の多くを排水路へ送ります)。面積率 a を田面(畦畔を除く)で与えるなら、
  畦畔の面積(面積率の頭打ちで外した分も)を c に入れます。
- 水田へ回した雨は途中で浸透・蒸発しません。浸透する集水面積(畑・台地)では、面積に流出率を掛けた値を c に
  します。
- 受ける水田を「1 セル以内の近傍」とみなします。区画よりずっと粗い格子では実際より遠くの水田まで配り、区画より
  細かい格子では区画の一部にしか配りません(どちらも水田に入る水の総量は変わりません)。区画の形は表しません。
- 水質と併用すると、集水面積の雨の物質も水と同じ行き先(配った先のタンクのプール)へ入ります。雨滴侵食に掛ける
  「1 − 面積率」には c を含めません(集水面積にも雨滴は当たります)。
- 0 ≤ c、a + c ≤ 空隙率 gv、c > 0 は水田のあるセル(a > 0)だけです(違えば起動時に停止)。水田のないセルにある
  集水面積は、周りのセルの水田へ流れ込むものも表せません。区画の解像(B)と、地形変化の雨滴侵食(`f_wash` の
  雨滴の項・`f_splash`)とは併用できません(起動時に停止。剥がれた土が地表に残り、運ぶ水がタンクへ行く不整合を
  避けるため)。

### 落水口の装置則

落水口 1 か所の流量 Q (m³/s) を、湛水深 H と下流の水深 $`h_D`$(同じ基準)から求めます。要素は次の 3 つです。

**堰(水位調整板・流出量調整板の天端。天端の高さ z、幅 B、係数 C)**。$`h_1 = H - z`$、$`h_2 = \max(h_D - z, 0)`$。

```math
Q = \frac{2}{3}C\sqrt{2g}\,B\,h_1^{3/2}\quad(h_2/h_1 < 2/3),
\qquad
Q = \sqrt{3}\,C\,B\,h_2\sqrt{2g\,(h_1 - h_2)}\quad(h_2/h_1 \ge 2/3)
```

切替点で連続です。C = 0.525 のとき、ENCflow の堤防の越流に使う本間公式(0.35・0.91。
[水理則の解説](hydraulics.md) §1)に一致します。本間公式の形を流量係数 C で一般化したのは独自の
組み立てです。

**三角の切欠き(V 字。頂点の高さ z、角度 θ)**: $`Q = \tfrac{8}{15}C\tan(\theta/2)\sqrt{2g}\,h_1^{5/2}`$[^maff2026]。
潜りは堰の潜りと自由の比 $`S(\rho) = \tfrac{3\sqrt{3}}{2}\rho\sqrt{1 - \rho}`$($`\rho = h_2/h_1 \ge 2/3`$)を掛けます
(独自の類推)。

**穴(円の径 d、または長方形の幅 b・高さ e。下端の高さ $`z_o`$)**。自由流出は穴の弦の幅の積分です。

```math
Q_f = C\int_{z_o}^{\min(H,\ z_o + \text{高さ})} b(y)\sqrt{2g\,(H - y)}\,dy
```

穴の一部だけが水に浸かる低い水頭でも成り立つ形[^yoshikawa2010][^miyazu2012]で、H が穴の高さより十分大きいと
$`C\,a\sqrt{2g\,(H - \text{穴の中心})}`$[^maff2026] に近づきます。下流の水深が穴の下端を超えたら、潜りの式
$`Q_s = C\,A_w\sqrt{2g\,(H - h_D)}`$($`A_w`$ は H より下の穴の面積)[^miyazu2012] との小さい方を
とります(カルバートの 3 つの流れを小さい方でつなぐのと同じ考え方。[水理則の解説](hydraulics.md) §2。独自の
組み立て)。

装置の型 `pd_dev_type` で要素を組み立てます[^maff2026]。

| 型 | 装置 | 流量 |
|---|---|---|
| 0 | 水位調整板だけ(通常の落水口。板を外した状態は天端 0) | 堰(水位調整板の天端 `pd_board_h`、幅 `pd_board_w`) |
| 1 | 機能分離型(水位調整板とは別に、排水枡の中に穴のある流出量調整板) | min(水位調整板の堰, 穴 + 流出量調整板の天端 `pd_plate_h` の越流) |
| 2 | 機能一体型(水位調整板の下部に穴・切欠き) | 穴 + 水位調整板の天端の越流 |

型 1 は、雨が小さいうちは水位調整板の堰が流量を決め(絞らない)、流量が穴の流せる量を超えると穴が絞ります。
型 2 は降り始めから穴が絞ります。三角の切欠き(三角セキ)・長方形の切欠き(門型セキ)の一体型は、型 2 の
穴の形 `pd_open_type` = 3・2 で表します。

### 地表の水との関係(片方向と双方向)

**片方向(既定。`f_pd_exchange = 0`)**: 落水口の下流の水深には、セルの地表水深を使います。地表の水が増えると
落水口が潜って流出が減り、地表の水位が湛水深に届くと流出は止まります。**逆向きの流れ(浸水が落水口や畦畔から
水田に入る流れ)は表しません**。地表の水はセル全面に広げているので、この形のまま両向きにすると、両者が同じ水位に
なったとき貯留を二重に数えてしまうためです(面積率 0.8・畦畔 0.3 m の水田が浸水すると、浸水深を約 0.24 m 小さく
見積もる)。浸水が水田に入る対象には双方向を使ってください。

**双方向(`f_pd_exchange = 1`)**: 水田のセルの地表の水を、河道の断面形 σ と同じ仕組みで**階段形の断面**として
扱います(developer.md §127.6、設計は docs/paddy_plan.md §13)。

- 畦畔の高さより下: 水田でない面積(道路・排水路・畦畔。セルの空隙のうち 1 − a/gv の割合)だけが、水を貯めて
  流します。
- 畦畔の高さより上: セル全面が、水を貯めて流します。
- 畦畔より下の水田の水はタンクが持ちます。水田が満ちて水位が畦畔より上なら、セルの水は「空隙の面積 × 水深」に
  なり、二重に数えません。

地表とタンクのやり取り(1 ステップ):

1. **雨**: 片方向と同じく、水田の上の雨をタンクに入れます。
2. **落水口(両向き)**: 水位の高い側を上流として装置則を使います。排水路(地表)の水位が湛水より高いと、
   落水口から水田へ逆流します(装置の向きによらず同じ式を使うのは独自の簡略化)。地表の水位が畦畔高以上のときは
   落水口のやり取りをしません(水田は次の 3 で満ちます)。
3. **畦畔**: 湛水深が畦畔高を超えた分は地表へあふれます。地表の水位が畦畔を越えると、畦畔より上の地表の水で、
   満ちていない水田をすぐに満たします(足りなければ空きの比で分けます)。
4. **減水深**: 片方向と同じです。

表れる挙動: 外水が来ると、まず道路・排水路(地表)を満たし、水位が畦畔を越えたところで水田が満ちます(遊水)。
全ての水田が満ちた後は、セル全面の浸水として広がります。水位が畦畔より下がると、水田は畦畔高まで水を残し、
落水口からゆっくり抜けます(田んぼダムなら穴で絞られます)。雨だけのときも片方向とは結果が変わります。地表の水が
水田でない面積に集まって深くなり、落水口が潜りやすくなるためです。

### 区画の解像(B)

`fn_pd_plot` を与えると、区画の湛水は浅水流の水深 h そのものになり、畦畔と落水口が浅水流のエッジ(セルの間の
流れ)を上書きします(developer.md §127.8、設計は docs/paddy_plan.md §14)。

- **畦畔(仮想壁面)**: 区画番号が違う 2 つのセルの間の全てのエッジ(斜めを含む)に壁を立てます。天端より下は
  水を通さず、天端を越えると両向きに本間公式で越流します([水理則の解説](hydraulics.md) §1。河川堤防の仮想壁面と
  同じ式)。天端はエッジの両端のセルの「田面 + 畦畔高(区画のセル)・地盤(区画でないセル)」の大きい方で、段々の
  区画の間では高い方の田面 + 畦畔高になります。天端が両側の地盤以下のエッジ(畦畔より高い道路の縁など)は壁に
  しません(地盤の段差のまま流れます)。斜めのエッジが別の区画のくびれ(2 × 2 の市松の角)を横切るときも壁にします。
- **落水口(壁の切欠き)**: 出口セルと、向きの先のセルの間のエッジだけ、壁の代わりに[装置則](#落水口の装置則)で
  流します。水位の高い側を上流とし、湛水深 H と下流の水深 $`h_D`$ はどちらも出口セルの田面から測ります。排水路の
  水位が湛水より高ければ、落水口から区画へ逆流します(装置の向きによらず同じ式を使うのは独自の簡略化)。水位が
  天端を越えれば、このエッジでも畦畔の越流を足します。落水口の先は別の区画でもかまいません(田越し)。
- **事前の湛水深**: 計算を新しく始めるとき、区画のセルの水深を `pd_h0`(既定は種類ごとの流れ始める高さ)まで
  満たします。初期条件でもっと深い水を与えたセルはそのままです。
- **減水深**: 毎ステップ、区画のセルの水深から `pd_perc_mmd` の割合で系外へ出します。

落水口の向きの番号はラスタの並び(ファイルの 1 行目が上)で数えます。

```
1 2 3
4 * 5      (* = 出口セル)
6 7 8
```

区画の外(農道・排水路・集落)は通常の浅水流です。幹線排水路を河道マスクとサブグリッド幅で表すこともできますが、
落水口は堤防のある河道のセルを向けません(堤防の壁と重なるため)。

### 水質との併用(fn_wq)

[水質](wq.md)(`fn_wq`)を有効にすると、水田の水も物質を運びます(developer.md §127.10、設計は docs/paddy_plan.md
§16.1)。物質は水質の章の 1 つの物質で、減衰・沈降の係数もそのまま使います。水田に固有の物質のモデル(施肥、代かきの
濁水、農薬の溶出など)は持たず、物質の種類を決めない汎用の形です。

- **A のタンク**: 種類ごとのタンクに物質のプールを持ち、タンクの中は完全混合(濃度 = プールの質量 / タンクの水の
  量)とします。水を動かすのと同じ割合で物質を動かします(取水・ポンプと同じ扱い)。
  - 水田の上に降った雨の物質(降雨中の濃度 `wq_rain_conc`)はタンクのプールに入り、地表には水田でない部分の雨の
    物質だけが入ります。
  - 落水と畦畔の越流はタンクの濃度で地表へ、減水深はタンクの濃度で系外へ出ます。
  - 双方向では、落水口から逆流する水と、畦畔を越えて水田を満たす水が、地表の濃度でタンクへ入ります。
  - プールにも一次減衰(`wq_thalf`・`wq_k20`)が働き、単相の沈降(`wq_vs`)はタンクの湛水深で割って掛けます。
- **B の区画**: 区画の水は地表の水なので、雨・移流・減衰・沈降は水質の章のとおりです。減水深だけ、区画のセルの
  水と一緒に地表の濃度で系外へ出します。
- **事前の湛水の濃度**: `pd_wq_c0`(mg/L。既定 0)。A ではタンクの初めの水の濃度、B では区画のセルに足した水
  (`pd_h0` まで満たした分)の濃度です。初期条件の地表の水の濃度は水質の `wq_c0` です。

### 時間刻み

タンクは陽解法で、刻み $`\Delta t`$ は浅水流と同じです。落水口の流量の変化は、湛水深が数 cm 変わる時間(数分〜
数時間)で、浅水流の刻み(数秒)より十分長いので、刻みの制限にはなりません。1 ステップに移す水は、流れ始める
高さまでの貯留と、下流との水位差の半分を埋める量で上限します(陽解法の追い越しの防止)。双方向でも、貯留と通水が
同じ割合で変わるので重力波の速さは変わらず、時間刻みの制限は増えません。B は浅水流の刻みそのもので、5 m の格子では
水深 0.3〜1 m の重力波で 0.5〜1 s 程度が目安です。畦畔の越流と落水口の流量は、河川堤防の越流と同じく、1 ステップで
両側の水位差の半分までしか動かしません(追い越しの防止)。

| 出力 | 内容 |

| Log の S(S_surf) | 地表の水に水田のタンクの貯留を足した値(領域平均 m) |
| `paddy.csv` の c1・c2(水質と併用するときだけ) | 種類ごとの水田の水の平均濃度 (mg/L。物質の総量 / 水の総量)。A はタンク、B は区画のセルの水 |
| `paddy.csv` の sed(双方向と浮遊砂 `f_suspend` を併用するときだけ。c1・c2 の後) | 地表からタンクへ入った水の浮遊砂を田面に積んだ累積 (m³。固相の体積) |

`paddy.csv` の累積は、計算の開始から(再開したときは再開から)の値です。水田のタンクの湛水深は状態の保存
(`f_state_save`)で私有ファイル `paddy.dat` に保存され、再開で引き継がれます([中断と再開](restart.md))。水質と
併用するときはタンクのプールも保存します(保存したときと水質の有無が違う再開は停止します)。

**水質の収支の見方**: `wq.csv` の全体系の質量に `mass_paddy_g` を足し、系外への除去に `out_paddy_perc_g` を足すと、
[水質](wq.md)の章の「読み方と検算のコツ」の収支が閉じます。タンクのプールの減衰は `decay_g`、沈降は `settle_g` に
入ります。地表とタンクの間の移動は内部の移動なので列にしません。

**B の出力**: 区画の湛水深は水深 `H` そのものです(`Hpn`・`Hpd` は出しません。Log の S もタンクを足さない地表の水)。
`paddy.csv` は同じ列を次の意味で書きます: area1・area2(種類ごとの区画の面積)、rain(区画のセルに降った雨)、
outflow・inflow(落水口からの流出・流入)、spill・levee_in(畦畔を越えた流出・流入)、perc(減水深)、store1・store2
(種類ごとの区画の水の量)、h1・h2(種類ごとの平均水深)、full1・full2(水深が畦畔高以上のセルの面積の割合)、
qsurf(直近のステップの正味の流出の速さ)、residual(貯留の変化 −(雨 + 流入 − 流出 − 減水深))。区画どうしの
落水口・畦畔の流れ(田越し)は、出る区画の流出と入る区画の流入の両方に数えます。`paddy.dat` はヘッダ(表現の印)
だけで、A と B を取り違えた再開や、B を無効にした再開を止めます。

**田んぼダムの効果の見方**: 取組率だけを変えた 2 つの計算で、河道・排水路の測線の流量のピーク・時刻、浸水の
深さ・広さを比べます。`full2`(田んぼダムの水田が満水の割合)が 1 に近い時間帯は、田んぼダムの貯留が使い切ら
れて効果がなくなった時間帯です。`h2` と畦畔高の差は残りの空き容量です。

## 適用範囲と併用の制限

**表せないこと(設計上の非対象)**

- 畦畔の決壊・漏水・崩れ、調整板の詰まり・取り外し(装置の型と取組率を変えたシナリオとして与えるだけ)。
- 片方向での、浸水が水田に入る流れ(双方向を使います。上の[地表の水との関係](#地表の水との関係片方向と双方向))。
- 稲の生育・冠水被害の判定(湛水深と継続時間を出すまで)、用水の取水・配水、中干しなどの水管理の時間変化
  (計算の途中で装置は変わりません)。
- 区画ごとのばらつき: 同じセルの同じ種類の水田はすべて同じ湛水深です。田面の高さや畦畔の高さのばらつきは
  表しません。
- タンクからの蒸発散(`fn_evap` を指定しても水田のタンクからは引きません。洪水の時間では小さい量です)。
- 減水深の水は系外へ出し、地下水(`fn_gwflow`)には入りません。

**精度の限界(結果を読むときに)**

- 落水口から出た水は、自分のセルの地表へ出て浅水流で流れます。粗い格子では排水路を解像しないので、水田から
  河道までの時間は地表の粗度に左右されます。斜面向けの大きい粗度のままだと、水田からの流出が遅れすぎます。
- 流域の河川のピークの低減は、水田面積率・取組率に比例して小さくなります。水田面積率が 20 % 未満の大河川では
  効果がほとんど出ないことが報告されています[^saha2023]。長い雨で田んぼダムの水田が満水になると効果が消え、
  3 日で 450 mm を超える雨では、製品の試験でもほとんど効かないことが報告されています[^minakawa2022]。
- 越流の主な原因は排水路の水位の上昇による逆流・排水不良であることが現地で報告されています。新潟の亀田郷
  (水田 41 %)の計算では、越流した水田の 9 割超が排水路の高い水位によるもので、日雨量 200 mm では越流の 89 % が
  排水路からの逆流でした[^sato2021]。片方向は下流の水位で流出を絞りますが、逆流は表さないので、背水の強い低平地
  では越流を少なく見積もります。双方向は落水口からの逆流を表します。
- 流域での効果は、日雨量 268 mm(約 120 年に 1 回)の雨で最も大きく、それより強い雨では畦畔を越える水田が増えて
  小さくなる例が報告されています[^miyazu2020]。
- **外水・内水が水田に及ぶセル(片方向)**(河川の越水・破堤、排水路のあふれ): 地表の水はタンクに入らず、タンクの水も
  浸水と合わさりません。畦畔を越える浸水があるセルでは、浸水の水位を最大で「面積率 × タンクの湛水深」だけ低く
  見積もり(面積率 0.8・湛水深 0.2 m で 0.16 m)、`Hpn`・`Hpd` は雨だけで貯めた湛水深のまま(浸水した実際の湛水深
  より小さい)です。畦畔より低い浸水は、地表の水がセル全面に広がるので、水田の外(道路・排水路・集落)の実際の
  深さより小さく出ます(水田のない粗い格子の計算と同じ限界)。浸水が水田に及ぶ評価には双方向
  (`f_pd_exchange = 1`)を使います。
- **双方向の限界**: 畦畔を越える流入は瞬時に扱い、越流の長さを持ちません。試算では、100 m のセル(水田 8 割)が
  越流水深 5〜10 cm で 4〜12 分で満ちる程度で、洪水の時間の尺度より短いですが、浅い越流が長く続く場面では水田を
  早く満たしすぎます。畦畔より下では、水は水田でない面積だけを流れます(区画の間の排水路・道路の並びは表しません)。
  浸水が水田に運ぶ浮遊砂は、地形変化と併用すると田面に積みます(下の「地形変化との併用」)。物質は水質と併用すると
  運びます(上の[水質との併用](#水質との併用fn_wq))。
- **粗い格子の水田面積率(A)**: 集水面積率 `fn_pd_catch` を与えなければ、タンクはセルの水田の部分に降った雨だけを
  受けます。区画より高い農道・台地に降って畦畔を越えて水田に流れ込む雨は地表の水になり、そうした雨の多い地区では、
  排水路へ出る水を多く、田んぼダムの効果を小さく見積もります(例題 [paddy_dam](../../examples/paddy_dam/README.md)
  の結果 2)。集水面積率の値は前処理のたどり方(例題は低い隣へ等しく分ける簡略なもの。浅水流は解かない)に左右
  され、集水面積の雨は流下の時間を持たずに、周りの 3 × 3 のセルの水田へ面積の比で入ります(区画の形は表しません)。
  集落の浸水の有無のように判定がしきい値に近い場面では、面積率・集水面積率の数 % の違いで結果が変わります。
- 装置の流量係数は製品・設置で 0.40〜0.88 と変わります[^yoshikawa2009][^minakawa2022]。既定の 0.6 は手引きの
  計算プログラムの値で、校正の出発点です。

**B(区画の解像)の限界**

- 畦畔の天端は「田面 + 畦畔高」で、畦畔高は全区画で同じです(`pd_hlev`)。天端は初期の地形から決め、計算の途中で
  変わりません。実際の畦畔の高さのばらつき・低い所からの越流は、田面の高さの精度と同じく地形の精度によります。
- 落水口は出口セルの 1 つのエッジで、装置則の流量だけを流します(エッジの幅は装置の幅と関係しません)。畦畔の越流は
  エッジの幅全体で起こるので、天端を越えた後の越流の長さは格子の並び(斜めのエッジを含む)で決まります。
- 区画の外の排水路・道路は格子の幅で解きます。セルより狭い小排水路は、格子の幅の水路として流れます。
- 区画の水の蒸発散は減水深に含めて扱うので、蒸発散(`fn_evap`)・地下水(`fn_gwflow`)とは併用できません。非静水圧
  (`f_nonhydrostatic = 1`)・土石流(`fn_geomorph` の `f_debris`)とも併用できません(起動時に停止)。
- 区画のセルは、格子の外周の行と列、海のセルや海側(`fn_seaside`)のセルの隣、ため池(`fn_rscap`)のセルにも置けません
  (起動時に停止)。区画番号は 0〜16 777 215 の整数です。

**併用の制限**: 格子システムは ENC(`f_gridsystem = 0`)だけです。ネスティング(複数の格子)、
淡塩 2 層(`fn_salt`)とは併用できません(起動時に停止)。水田のセル(面積率 > 0)は、海域・河道(`fn_rw`)・
水位規定・区間流入・湧き出し・構造物のセル、[VZ](vz.md)・[貯留関数法](sfm.md)の区画セルに置けません。面積率は
家屋の空隙率 `fn_gv` を超えられません(水田と家屋は同じセルの別の部分です)。双方向は、家屋破壊の空隙率の帰還
(`fn_bldgdebris`)・土石流(`f_debris`)・非静水圧(`f_nonhydrostatic = 1`)と併用できず、水田のセルを
ため池のセル(`fn_rscap`)に置けず、水田でない面積の割合 1 − a/gv が 0.01 以上(落水口から出る水の行き場)である
必要があります(起動時に停止)。片方向で保存した状態から双方向で再開すること(その逆も)はできません。
集水面積率(`fn_pd_catch`)は、区画の解像(B)と、地形変化の雨滴侵食(`f_wash` の雨滴の項・`f_splash`)とは
併用できません(起動時に停止)。区画の解像(B)は、混合粒径(`f_bedmix`)・芦田・道上の有効掃流力(`f_taupart = 2`)
と併用できず、双方向で浮遊砂(`f_suspend`)を使う計算は、混合粒径と併用できません(起動時に停止。これらの掃流砂・
浮遊砂の手続きは、区画の畦畔と田面への堆積を扱っていません)。

**地形変化との併用**(`fn_geomorph`): 水田の上の雨はタンク(田面の湛水)に落ちるので、雨滴による侵食
(`f_wash` の雨滴の項・`f_splash`)は水田の部分を除いて計算します(侵食の速さに「1 − 面積率」を掛けます。湛水は
雨滴の飛沫による侵食をほぼ止めます[^bako2016])。タンクが空(湛水深 0)でも水田の部分を除きます(独自の簡略化)。
双方向で浮遊砂(`f_suspend`)と併用すると、地表から水田のタンクへ入る水(落水口からの逆流・畦畔を越える満水)の
浮遊砂を、そのセルの田面(河床)に積みます(浮遊砂の沈降と同じ換算。独自の簡略化)。積んだ量は `paddy.csv` の
sed 列(固相の体積の累積 m³)です。浸水が運んだ土砂が水田に残ることは現地で報告されています[^manh2014]。
区画の解像(B)と併用すると、掃流砂は畦畔と落水口のエッジを越えません(河川堤防の仮想壁面と同じ扱い。畦畔を
越える流れが運ぶのは浮遊砂)。
限界: タンクは土砂を運ばず、落水口から出る水は濁りを持ちません(代かき後の落水などの濁水は表しません)。タンクに
入った浮遊砂はすべてその場で積もり(沈降にかかる時間を持たない)、セルの河床がセル全体で上がります(水田の部分と
それ以外を分けません)。流れによる侵食(`f_wash` の面状侵食の項・浮遊砂の巻き上げ・掃流砂)はセル全面で計算し、
水田の部分の土も地表の流れで削れます。B でも、斜面のクリープ・安息角の崩れ・崩壊は畦畔を見ません(区画の境を越えて
土が動きます)。溶食(`f_dissol`)の水量は変えません(雨の量で決める設定では水田の部分の雨も数え、浸透の量で決める
設定では水田の減水深を数えません)。

**水質との併用の限界**(`fn_wq`。上の[水質との併用](#水質との併用fn_wq))

- A のタンクの中は完全混合で、田面の土・稲との物質のやり取り(吸着・溶出・巻き上げ)は表しません。代かき・施肥の
  後の高い濃度は、事前の湛水の濃度 `pd_wq_c0` として与えるだけです。
- A のタンクで沈んだ物質(`wq_vs`)はプールから除き、表面蓄積プール(`f_wq_settle = 1`)には入りません。二相分配
  (`wq_kd`)はタンクの中では扱わず、沈降もしません(粒子態も溶存態と同じく落水とともに出ます)。
- A の片方向では浸水が水田に入らないので、浸水の物質もタンクに入りません(双方向を使います)。
- 水田の上の雨の物質がタンクに入るのは、そのステップの水を動かした後です。そのステップの落水の濃度は、雨の水を
  含めた分だけ低く出ます(1 ステップの時間の分割の誤差)。
- 双方向の水田のセルに初期の水深と水質の初期濃度 `wq_c0` を与えると、水質の初めの質量は `wq_c0` × 水深(矩形の
  換算)で置かれます。畦畔より下の水は水田でない面積にしかないので、初めの地表の濃度は `wq_c0` を 1 − a/gv で
  割った値になります(水質の初期濃度の既知の簡略化)。
- タンクからは蒸発散を引かないので(上の「表せないこと」)、蒸発による濃縮は表しません。
- タンクの濃度の分布は出力しません(`paddy.csv` の種類ごとの平均 c1・c2 だけ。地表の濃度の分布 `C` は地表の水)。

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

|---|---:|---|---|
| f_paddy | 1 | 0 で一時無効化 | **方式** |
| fn_pd_frac | — | 水田面積率の分布(セル面積に対する割合 0〜1) | **与件** `pd_frac` とどちらか一方が必須 |
| pd_frac | — | 水田面積率の一様値 | **与件** |
| fn_pd_adopt | — | 取組率の分布(水田面積のうち田んぼダムの割合 0〜1) | **与件** |
| pd_adopt | 0 | 取組率の一様値 | **与件** 0 = 取組なし |
| fn_pd_catch | — | 集水面積率の分布(セルの面積のうち、雨が水田へ流れ込む部分の割合。その雨は周りの 3 × 3 のセルの水田へ配る。A だけ) | **与件** 省略 = 0(前処理で地形からたどる。上の[集水面積率](#集水面積率fn_pd_catch)) |

| f_pd_exchange | 0 | 地表と水田の水のやり取り(0: 片方向 = 雨だけ、1: 双方向 = 外水・内水も落水口と畦畔から水田に入る。A だけ) | **方式** 双方向は独自の組み立て(docs/paddy_plan.md §13、developer.md §127.6) |

| pd_board_h(c) | 0.03 m | 水位調整板の天端の高さ(田面から) | **文献値** 計算プログラムの既定[^maff2026][^minakawa2022] |

| pd_co(c) | 0.6 | 穴の流量係数 C | **文献値** 計算プログラムの既定[^maff2026]。実験・現地では 0.62〜0.88[^yoshikawa2009][^yoshikawa2010][^miyazu2012] |

**既定値を見直すときの手がかり**

- **装置**: 取組の地区で使っている装置の型と寸法を与えます。手引きは機能分離型 φ50・一体型の 60° の切欠きを
  例に挙げ、ほかの地区の例として φ30〜60 mm の穴(区画面積に合わせる)、門型の切欠き 12 cm × 5 cm を載せています[^maff2026]。
- **区画面積**: 大区画化した地区(1 ha など)では `pd_aplot` を大きくします。同じ穴で区画が大きいと、水田
  面積あたりの流出強度は小さくなります。
- **事前の湛水深**: 洪水の時期の水管理(中干しで空、通常の湛水、前の雨で満水)で結果が大きく変わります。
  複数の状態で計算して幅を示すのが安全です。
