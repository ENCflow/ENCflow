# 田んぼダム(水田の落水口の流出抑制。fn_paddy)

[ユーザーガイド目次へ](../users_guide.md)

**田んぼダム**は、水田の落水口(排水枡)に流出量を絞る板(穴・切欠き)を付け、豪雨の水を畦畔の中に
一時的に貯めて、下流の排水路・河川のピークを下げる取組です[^maff2026]。この機能は、水田の貯留と
落水口の流量則を格子の上に置き、取組率(水田のうち田んぼダムにした割合)・装置の型・事前の湛水の
状態を変えて、流出と浸水がどう変わるかを見積もるためのものです。

現在の版は、セルの中の水田を**サブグリッドのタンク**として表します(下の[計算のしくみ](#計算のしくみ))。
100〜200 m の流域モデルから 20〜50 m の排水区の格子まで、同じ式で使えます。個々の区画を 5〜10 m の
格子で解像し、畦畔を仮想壁面、落水口をその切欠きとして表す方式は計画中です(設計は
docs/paddy_plan.md §7)。

- **水田のタンク**: セルの水田面積率 a の上に降った雨を受けるタンクです。取組率で
  「通常の落水口の水田」(種類 1)と「田んぼダムの水田」(種類 2)に分け、種類ごとに 1 つの
  湛水深(田面からの水深)を持ちます。
- **落水口**: 代表区画面積 A_plot ごとに 1 か所あり、湛水深と下流(セルの地表)の水深から
  装置則で流量を決めます。流量はセルの地表へ移り、浅水流で流れます。
- **畦畔**: 湛水深が畦畔高を超えた分は、すぐに地表へあふれます。

設計の経緯と決定は developer.md §119、検討と文献の一覧は docs/paddy_plan.md にあります。

## 有効化と設定

`&list_sysparam` で `fn_paddy` を指定します(`"-"` なら同じパラメータファイル)。設定は 1 つの
グループです。

```
&list_paddy
  fn_pd_frac = 'paddy_frac.txt'   ! 水田面積率の分布(セル面積に対する割合 0〜1)
  pd_adopt = 0.5                  ! 取組率(水田のうち田んぼダムの割合。省略時 0)
  !pd_aplot = 3000.0              ! 代表区画面積 (m2。省略時 3000)
  !pd_hlev = 0.30                 ! 畦畔高 (m。省略時 0.30)
  !pd_dev_type(2) = 1             ! 田んぼダムの装置の型(省略時 1 = 機能分離型)
  !pd_open_d(2) = 0.05            ! 流出量調整板の穴の径 (m。省略時 0.05)
/
```

`f_paddy = 0` で書いたまま一時無効化できます。面積率は分布 `fn_pd_frac` か一様値 `pd_frac` の
どちらか、取組率は分布 `fn_pd_adopt` か一様値 `pd_adopt` のどちらかで与えます。

## とりあえず動かしてみる(最小入力)

必要なのは**水田面積率**(`fn_pd_frac` か `pd_frac`)だけです。土地利用データ(例: 国土数値情報の
土地利用細分メッシュの「田」)から、格子のセルごとの面積の割合を前処理で作ってください(本体は
土地利用を読みません。土地利用からマスクを作る前処理と同じ考え方です。[地理情報](geoinfo.md)の海域マスク・河道マスクの節、
developer.md §40)。ほかを省略すると、区画 30 a・畦畔
0.30 m・減水深 5 mm/d・取組なし(全て通常の落水口 = 水位調整板 0.03 m × 幅 0.30 m)を使い、
採用した値を画面に `(default)` を付けて表示します。田んぼダムの効果は `pd_adopt` を与えて比べます。

**使い方の型**

| 型 | 構成 | 見るもの |
|---|---|---|
| 流域の河川のピーク(100〜200 m) | 水田面積率の分布 + 取組率 0 と 1(と途中)の計算を比べる | 河道の測線の流量のピーク・時刻、`paddy.csv` の貯留と満水の割合 |
| 排水区の幹線の水位(20〜50 m) | 幹線排水路を河道マスク・サブグリッド幅で、水田を面積率で | 幹線の測線の流量・プローブの水位、`Hpd` の湛水深 |
| 装置の比べ | `pd_dev_type(2)` と穴の大きさを変える | `paddy.csv` の流出(落水と越流)の速さ `qsurf` と貯留 |
| 事前の状態の比べ | `pd_h0`(0 = 中干しで空、0.03 = 通常の湛水、0.30 = 前の雨で満水) | 同上 |

## 計算のしくみ

### 水田のタンク

セル (i, j) の水田面積率 a を、取組率 r で 2 つの種類に分けます。

```math
a_1 = a\,(1 - r)\ (\text{通常の落水口}),\qquad a_2 = a\,r\ (\text{田んぼダムの落水口})
```

種類 c の水田はセル内で同じ湛水深 $`H_c`$(田面からの水深)を持ち、落水口は代表区画面積
$`A_{\mathrm{plot}}`$ ごとに 1 か所あるとします。セルの落水口の数は $`N_c = a_c\,\Delta x\,\Delta y/A_{\mathrm{plot}}`$、
セルの流出は $`N_c\,Q_c`$ で、水田面積あたりの流出強度は

```math
q_c = \frac{Q_c(H_c, h_D)}{A_{\mathrm{plot}}}
```

です。$`q_c`$ は格子の大きさによらないので、100 m の格子でも 20 m の格子でも同じ水田は同じ応答をします
(粗い格子の分布型流出モデルで水田をセルの面積率のタンクにした前例[^nihei2024]と同じ形)。
毎ステップ(浅水流の直後)に次の順で進めます。

1. **雨**: 水田の上に降った雨 $`a\,R\,\Delta t`$ を地表の水から引き、各タンクに $`R\,\Delta t`$ を足します
   (R は地上の雨。[降雨遮断](forcing.md)があれば遮断の後)。
2. **落水**: $`\Delta H = q_c\,\Delta t`$ を地表へ移します。$`h_D`$ はセルの地表水深(落水口の下流の水位を
   田面から測った値)です。
3. **越流**: $`H_c`$ が畦畔高を超えた分を、すぐに地表へ移します(農林水産省の水田流出簡易計算
   プログラムと同じ扱い[^maff2026])。
4. **減水深**: `pd_perc_mmd` の割合で系外へ出します(地下水には入りません)。

地表へ移った水はセルの地表水として浅水流で流れ、河道・排水路へ集まります。

### 落水口の装置則

落水口 1 か所の流量 Q (m³/s) を、湛水深 H と下流の水深 $`h_D`$(同じ基準)から求めます。要素は次の 3 つです。

**堰(水位調整板・流出量調整板の天端。天端の高さ z、幅 B、係数 C)**。$`h_1 = H - z`$、$`h_2 = \max(h_D - z, 0)`$。

```math
Q = \frac{2}{3}C\sqrt{2g}\,B\,h_1^{3/2}\quad(h_2/h_1 < 2/3),
\qquad
Q = \sqrt{3}\,C\,B\,h_2\sqrt{2g\,(h_1 - h_2)}\quad(h_2/h_1 \ge 2/3)
```

切替点で連続です。C = 0.525 のとき、ENCflow の堤防の越流に使う本間公式(0.35・0.91。
[水理則の解説](hydraulics.md) §1)に一致します。本間公式の形を流量係数 C で一般化したのは独自の
組み立てです。

**三角の切欠き(V 字。頂点の高さ z、角度 θ)**: $`Q = \tfrac{8}{15}C\tan(\theta/2)\sqrt{2g}\,h_1^{5/2}`$[^maff2026]。
潜りは堰の潜りと自由の比 $`S(\rho) = \tfrac{3\sqrt{3}}{2}\rho\sqrt{1 - \rho}`$($`\rho = h_2/h_1 \ge 2/3`$)を掛けます
(独自の類推)。

**穴(円の径 d、または長方形の幅 b・高さ e。下端の高さ $`z_o`$)**。自由流出は穴の弦の幅の積分です。

```math
Q_f = C\int_{z_o}^{\min(H,\ z_o + \text{高さ})} b(y)\sqrt{2g\,(H - y)}\,dy
```

穴の一部だけが水に浸かる低い水頭でも成り立つ形[^yoshikawa2010][^miyazu2012]で、H が穴の高さより十分大きいと
$`C\,a\sqrt{2g\,(H - \text{穴の中心})}`$[^maff2026] に近づきます。下流の水深が穴の下端を超えたら、潜りの式
$`Q_s = C\,A_w\sqrt{2g\,(H - h_D)}`$($`A_w`$ は H より下の穴の面積)[^miyazu2012] との小さい方を
とります(カルバートの 3 つの流れを小さい方でつなぐのと同じ考え方。[水理則の解説](hydraulics.md) §2。独自の
組み立て)。

装置の型 `pd_dev_type` で要素を組み立てます[^maff2026]。

| 型 | 装置 | 流量 |
|---|---|---|
| 0 | 水位調整板だけ(通常の落水口。板を外した状態は天端 0) | 堰(水位調整板の天端 `pd_board_h`、幅 `pd_board_w`) |
| 1 | 機能分離型(水位調整板とは別に、排水枡の中に穴のある流出量調整板) | min(水位調整板の堰, 穴 + 流出量調整板の天端 `pd_plate_h` の越流) |
| 2 | 機能一体型(水位調整板の下部に穴・切欠き) | 穴 + 水位調整板の天端の越流 |

型 1 は、雨が小さいうちは水位調整板の堰が流量を決め(絞らない)、流量が穴の流せる量を超えると穴が絞ります。
型 2 は降り始めから穴が絞ります。三角の切欠き(三角セキ)・長方形の切欠き(門型セキ)の一体型は、型 2 の
穴の形 `pd_open_type` = 3・2 で表します。

### 地表の水との関係(片方向)

落水口の下流の水深には、セルの地表水深を使います。地表の水が増えると落水口が潜って流出が減り、地表の水位が
湛水深に届くと流出は止まります。**逆向きの流れ(浸水が落水口や畦畔から水田に入る流れ)は表しません**。
地表の水はセル全面、タンクは水田の面積の上にあるので、双方向にして両者が同じ水位になると貯留を二重に数えて
しまうためです(面積率 0.8・畦畔 0.3 m の水田が浸水すると、浸水深を約 0.24 m 小さく見積もる)。低平地で浸水が
水田に入ることが重要な対象は、下の[適用範囲と併用の制限](#適用範囲と併用の制限)を読んでください。

### 時間刻み

タンクは陽解法で、刻み $`\Delta t`$ は浅水流と同じです。落水口の流量の変化は、湛水深が数 cm 変わる時間(数分〜
数時間)で、浅水流の刻み(数秒)より十分長いので、刻みの制限にはなりません。1 ステップに移す水は、流れ始める
高さまでの貯留と、下流との水位差の半分を埋める量で上限します(陽解法の追い越しの防止)。

## 出力・確認

| 出力 | 内容 |
|---|---|
| `Hpn0001…`・`Hpd0001…` | 通常の落水口の水田・田んぼダムの水田の湛水深 (m。田面から)。その種類の水田がある計算だけ自動で出力。水田のないセルは 0 |
| `paddy.csv`(`dt_record` ごと) | time(s)、area1・area2(種類ごとの水田面積 m²)、rain(水田の上に降った雨の累積 m³)、outflow(落水の累積)、spill(畦畔の越流の累積)、perc(減水深の累積)、store1・store2(種類ごとの貯留 m³)、residual(貯留の変化 −(雨 − 落水 − 越流 − 減水深))、qsurf(直近のステップに地表へ移した速さ m³/s)、h1・h2(種類ごとの平均湛水深 mm)、full1・full2(畦畔高まで満ちた水田面積の割合) |
| Log の S(S_surf) | 地表の水に水田のタンクの貯留を足した値(領域平均 m) |

`paddy.csv` の累積は、計算の開始から(再開したときは再開から)の値です。水田のタンクの湛水深は状態の保存
(`f_state_save`)で私有ファイル `paddy.dat` に保存され、再開で引き継がれます([中断と再開](restart.md))。

**田んぼダムの効果の見方**: 取組率だけを変えた 2 つの計算で、河道・排水路の測線の流量のピーク・時刻、浸水の
深さ・広さを比べます。`full2`(田んぼダムの水田が満水の割合)が 1 に近い時間帯は、田んぼダムの貯留が使い切ら
れて効果がなくなった時間帯です。`h2` と畦畔高の差は残りの空き容量です。

## 適用範囲と併用の制限

**表せないこと(設計上の非対象)**

- 畦畔の決壊・漏水・崩れ、調整板の詰まり・取り外し(装置の型と取組率を変えたシナリオとして与えるだけ)。
- 浸水が水田に入る流れ(上の[地表の水との関係](#地表の水との関係片方向))。
- 稲の生育・冠水被害の判定(湛水深と継続時間を出すまで)、用水の取水・配水、中干しなどの水管理の時間変化
  (計算の途中で装置は変わりません)。
- 区画ごとのばらつき: 同じセルの同じ種類の水田はすべて同じ湛水深です。田面の高さや畦畔の高さのばらつきは
  表しません。
- タンクからの蒸発散(`fn_evap` を指定しても水田のタンクからは引きません。洪水の時間では小さい量です)。
- 減水深の水は系外へ出し、地下水(`fn_gwflow`)には入りません。

**精度の限界(結果を読むときに)**

- 落水口から出た水は、自分のセルの地表へ出て浅水流で流れます。粗い格子では排水路を解像しないので、水田から
  河道までの時間は地表の粗度に左右されます。斜面向けの大きい粗度のままだと、水田からの流出が遅れすぎます。
- 流域の河川のピークの低減は、水田面積率・取組率に比例して小さくなります。水田面積率が 20 % 未満の大河川では
  効果がほとんど出ないことが報告されています[^saha2023]。長い雨で田んぼダムの水田が満水になると効果が消え、
  3 日で 450 mm を超える雨では、製品の試験でもほとんど効かないことが報告されています[^minakawa2022]。
- 越流の主な原因は排水路の水位の上昇による逆流・排水不良であることが現地で報告されています。新潟の亀田郷
  (水田 41 %)の計算では、越流した水田の 9 割超が排水路の高い水位によるもので、日雨量 200 mm では越流の 89 % が
  排水路からの逆流でした[^sato2021]。この版は下流の水位で流出を絞りますが、逆流は表さないので、背水の強い低平地
  では越流を少なく見積もります。
- 流域での効果は、日雨量 268 mm(約 120 年に 1 回)の雨で最も大きく、それより強い雨では畦畔を越える水田が増えて
  小さくなる例が報告されています[^miyazu2020]。
- **外水・内水が水田に及ぶセル**(河川の越水・破堤、排水路のあふれ): 地表の水はタンクに入らず、タンクの水も
  浸水と合わさりません。畦畔を越える浸水があるセルでは、浸水の水位を最大で「面積率 × タンクの湛水深」だけ低く
  見積もり(面積率 0.8・湛水深 0.2 m で 0.16 m)、`Hpn`・`Hpd` は雨だけで貯めた湛水深のまま(浸水した実際の湛水深
  より小さい)です。畦畔より低い浸水は、地表の水がセル全面に広がるので、水田の外(道路・排水路・集落)の実際の
  深さより小さく出ます(水田のない粗い格子の計算と同じ限界)。浸水が水田に及ぶ低平地の評価には、区画を解像する
  方式(計画中)が要ります。
- 装置の流量係数は製品・設置で 0.40〜0.88 と変わります[^yoshikawa2009][^minakawa2022]。既定の 0.6 は手引きの
  計算プログラムの値で、校正の出発点です。

**併用の制限**: 格子システムは ENC(`f_gridsystem = 0`)だけです。ネスティング(複数の格子)、水質(`fn_wq`)、
淡塩 2 層(`fn_salt`)とは併用できません(起動時に停止)。水田のセル(面積率 > 0)は、海域・河道(`fn_rw`)・
水位規定・区間流入・湧き出し・構造物のセル、[VZ](vz.md)・[貯留関数法](sfm.md)の区画セルに置けません。面積率は
家屋の空隙率 `fn_gv` を超えられません(水田と家屋は同じセルの別の部分です)。地形変化(`fn_geomorph`)とは併用
できますが、タンクは土砂を運ばず(落水口から出る水は濁りを持たない)、雨滴による侵食(`f_wash` の雨滴の項・
`f_splash`)は水田の部分にも計算されます(湛水した水田では本来ほとんど起きません)。

| pd_open_d(c) | 0.05 m | 円の穴の径 | **文献値** 手引きの例・新潟の φ50[^maff2026][^yoshikawa2009] |
| pd_open_b(c)・pd_open_e(c) | — | 長方形の穴の幅・高さ | **与件** 型 2 の長方形で必須 |
| pd_open_ang(c) | 60° | 三角の切欠きの角度 | **文献値** 手引きの一体型の例[^maff2026] |
| pd_open_z(c) | 0 m | 穴の下端(三角は頂点)の高さ(田面から) | **与件** |
| pd_plate_h(c) | なし | 流出量調整板の天端の高さ(型 1 の越流。なし = 越流しない) | **与件** |
| pd_plate_w(c) | 水位調整板の幅 | 流出量調整板の越流の幅 | **与件** |
| pd_cw(c) | 0.6 | 堰の流量係数 C | **文献値** 計算プログラムの既定[^maff2026] |
| pd_co(c) | 0.6 | 穴の流量係数 C | **文献値** 計算プログラムの既定[^maff2026]。実験・現地では 0.62〜0.88[^yoshikawa2009][^yoshikawa2010][^miyazu2012] |

**既定値を見直すときの手がかり**

- **装置**: 取組の地区で使っている装置の型と寸法を与えます。手引きは機能分離型 φ50・一体型の 60° の切欠きを
  例に挙げ、ほかの地区の例として φ30〜60 mm の穴(区画面積に合わせる)、門型の切欠き 12 cm × 5 cm を載せています[^maff2026]。
- **区画面積**: 大区画化した地区(1 ha など)では `pd_aplot` を大きくします。同じ穴で区画が大きいと、水田
  面積あたりの流出強度は小さくなります。
- **事前の湛水深**: 洪水の時期の水管理(中干しで空、通常の湛水、前の雨で満水)で結果が大きく変わります。
  複数の状態で計算して幅を示すのが安全です。
