# 浅水流計算(&list_enc と数値定数)

[ユーザーガイド目次へ](../users_guide.md)

コアの地表水計算(ENC 格子上の浅水方程式)の調整パラメータです。
**既定値のままで妥当に動くように設定されています** — この章の設定は
精度・コストの調整や数値実験のためのもので、通常の計算で触る必要が
あるのは適応的ルンゲクッタの閾値くらいです。

## 方式の選択(&list_sysparam)

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_gridsystem | 0 | 0: ENC 格子(既定)、1: STG(スタガード格子。旧互換の比較用。新機能・再開は非対応) |
| f_govequation | 0 | 0: 力学波(移流+圧力。既定)、1: 拡散波(圧力のみ)、2: 運動波 |
| f_check_cfl | 1 | クーラン数の監視。0: 監視のみ(停止しない)、1: Cn > 1 で状態を表示して停止(既定)、2: 波速を無視した移流クーラン数で判定・停止(Cn 列・Cn 出力の定義も移流 Cn に変わる) |

拡散波・運動波は感度実験・他モデルとの比較用です。乾湿を含む氾濫・
遡上は力学波のまま使ってください。

## 数値定数(&list_sysparam)

| パラメータ | 既定値 | 意味 |
|---|---|---|
| dd | 0.001 | 限界水深 (m)。この水深以上のセルで水の移動を計算 |
| dv | 0.001 | 仮想水深 (m)。これ以下の水深の計算上の下限 |
| vv | 0.01 | 摩擦項計算の流速下限 (m/s) |
| gg | 9.8 | 重力加速度 (m/s²) |
| cm / cd / kk | 2.0 / 1.0 / 0.5 | 家屋群の付加質量係数・抗力係数・抗力補正係数(地理情報の gv/bb とセットで使用。[地理情報の章](geoinfo.md)) |

## ENC 計算の調整(&list_enc)

`fn_enc` で有効化します(未指定でもコアは既定値で動きます)。

```
&list_enc
  p_adprunge_thresh = 1.1        ! 適応的ルンゲクッタの閾値 (1.1 ~)
/
```

**時間積分(適応的ルンゲクッタ)**

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_adaptive_runge | 1 | 適応的ルンゲクッタ(流速変動の大きいセルだけ4段 RK で再計算) |
| p_adprunge_thresh | 1.5 | 再計算を発動する流速変動率の閾値(小さいほど高精度・高コスト。1.1〜) |

閾値の意味と効果は[チュートリアル Step 2](../../tutorials/wave/README.md#step-2-enc-パラメータの設定)
が実演しています。画面の Runge 列が適用率です。

**フラックス・安定化**

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_gravity_correction | 1 | 重力の補正(急勾配地形での斜面方向重力の誤差を補正) |
| f_exflux_reduction | 1 | 過大な流出フラックスの抑制。乾いた地表を進む前縁の負水深を防ぐ(乾床のある計算では on のまま推奨) |
| f_hcap_upwind | 1 | セル境界(質量流束)の水深。0: 両側セルの平均、1: 平均を上流側水深で頭打ち(既定)、2: 上流側水深そのもの(Stelling & Duinmeijer の連続式と同じ。段波先端で前線の 1 セルに水が積み上がるスパイクを防ぐ。乾いた地表への前縁の流出が増えるため、氾濫計算では ex_flux と前縁の進み方を確認して使う) |
| f_friction_fastmath | 0 | 摩擦項計算の高速化。0: 厳密(既定)、1〜5: テーブル近似(数字が大きいほど粗く速い) |
| p_diagratio | 2/(2+√2) | 8方向フラックスの対角成分の配分比(通常変更不要) |

**移流項・拡散項**

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_advection_scheme | 1 | 移流項のスキーム。1: セル中心勾配(既定。3×3 の重み付き勾配を両側セル平均でエッジへ投影)、2: 運動量保存形・1次風上、3: 運動量保存形+MUSCL(van Leer)。2・3 は Stelling & Duinmeijer (2003) のスタガード格子向け定式化を ENC の 8 方向エッジに拡張したもので、段波・跳水の速度が正しく出る(湿潤床ダム破壊で段波位置誤差 1%、既定の 1 は 15% 遅れ)。p_adv_upwind_index・f_advection_tvd はスキーム 1 だけに作用する |
| f_advection_donor | 0 | 運動量保存形移流(f_advection_scheme 2・3)の風上供給元の制限。0: 湿潤セルすべて(既定)、1: 河道セル(fn_rw の河道マスク、rw > 0)同士のエッジでは流下方向の供給元を河道セルに限る(非河道セルが供給元になる流下方向の面は ū = u_e。側方面は対象外で、斜面からの横流入による減速は残る)。屈曲・合流・不規則な 2 セル幅で、検査体積の線上の風上エッジが浸水した谷底・斜面セルに落ちると、その遅い水が運動量の供給元になって流下方向に減速が積み重なる人工損失を防ぎます(developer.md §68.18)。実地形の試験(chichibu)では効果が現れなかったため、通常は指定不要です。河道マスクが必須で、スキーム 1 では効果なし |
| f_dry_head_cap | 0 | 乾燥セルへ向かうエッジ水深のエネルギー頭による頭打ち。0: なし(既定)、1: 有効。受け手セルが乾燥(h < dd)のとき、そのエッジが運べる水深を送り手のエネルギー頭 η + u_n²/2g が受け手の地盤を超える分 max(η + u_n²/2g − z_受け手, 0) で頭打ちし、超えられないエッジは流速も 0 にします(Bernoulli。堰越流の越流水深と同じ考え方)。既定では圧力項だけが「水面より高い乾いた地盤へ水が登る」ことを止めているため、段波先端や 1〜2 セル幅の掘込水路で移流項が勝つと水が堤内地へ漏れて発散することがあります(developer.md §68.15)。地盤が水面より低い通常の乾湿前縁では頭打ちが効かず既定と同一で、wave の reference にも一致します |
| f_opening_dynamic | 0 | 塞がれた開口の動的振り替え。0: なし(既定)、1: 河道セル間のエッジのみ(fn_rw の河道マスクが必須)、2: 全エッジ。ENC の 8 方向配分では、斜め先のセルの地盤が水面より高いと(谷底の 1 セル幅河道、壁沿い)その方向の通過幅が使えず、軸エッジの流速がセル流速の約 2.4 倍になって摩擦が過大(等流水深 +30%)になり、移流項(特にスキーム 3)の加減速も増幅されます。有効にすると、塞がり率 s = clamp((z_隣 − z)/h, 0, 1)(水面が隣接地盤より低ければ 1)に応じて、塞がれた通過幅シェアを開いた軸・斜めエッジへ毎ステップ振り替えます(堤防の開口補正 f_bank_opening と同じ規則の動的版。平坦な開水面では係数 1 で既定と同一)。1 セル河道の等流水深が Manning に一致し、スキーム 1 と 3 の洪水波の差が消えます。2(全域)は斜面の薄い表面流にも作用して流出が速くなるため、粗度の校正と合わせて評価してください。費用はステップあたり 1 パス(数%)、メモリは 4 実数/セル。リスタート直後の u,v,m,n は復元した水深から再導出するため保存時と最終桁で異なりえます |
| f_advection_runge | 0 | 適応的ルンゲクッタの再計算段で移流項も更新する。0: 更新しない(既定。移流項は陽的オイラー値のまま固定)、1: 各段の更新後流速に比例させて移流項を更新 |
| f_advection_tvd | 0 | 移流項に TVD スキームを使用(スキーム 1 のみ。**実験的。現在は有効化を推奨しません**) |
| p_adv_upwind_index | 0.5 | 移流項の風上化指数(0〜1。スキーム 1 のみ)。0: 中心差分、1: 1次精度の風上差分 |
| f_diffusion_term | 0 | 拡散項。0: なし(既定)、1: 定数粘性、2: ゼロ方程式モデル(ν = ν0 + α·u*·h) |
| p_diffusion_nu | — | 動粘性係数 ν0 (m²/s)。**モデル 1 では正値の明示が必須**(未指定はエラー停止)。モデル 2 では省略可のバックグラウンド粘性 |
| p_diffusion_alpha | 0.41/6 | ゼロ方程式の係数 α(既定は Elder 型) |

「とりあえず拡散項を入れてみたい」ときは**モデル 2 を推奨**します —
係数を1つも指定せずに、流れに応じて物理的にスケールした粘性
ν = α·u\*·h(α の既定は Elder 型)が働きます。モデル 1 の定数粘性は
格子幅・流れの規模に依存するため普遍的な推奨値がなく、値の明示が
必須です(指定し忘れは初期化時に停止するので、黙って無効になる
ことはありません)。

**その他**

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_rivermouth_drop | 0 | 河口から海への段落ち(旧方式。潮位機能 fn_tide とは併用不可 — 現在は[潮位](tide.md)+[境界条件](boundary.md)の利用を推奨) |

## とりあえず動かしてみる(最小入力)

この章の設定は**すべて既定値で動きます** — fn_enc を書かなくて構いません。
既定は「乾床前縁の安定(f_exflux_reduction)・急勾配の重力補正
(f_gravity_correction)・適応的ルンゲクッタ(閾値 1.5)」が有効の、
津波・氾濫・出水のどれにも無難な組です。

## パターン別の推奨値

| 型 | 推奨する設定 | 理由 |
|---|---|---|
| 津波・高潮の遡上 | 既定(p_adprunge_thresh 1.2〜1.5)。f_check_cfl=1 で Cn 監視 | 乾床を進む前縁と反射波の両方を既定の安定化が扱う |
| 急勾配山地の出水・土石流 | f_gravity_correction=1(既定)、dt は Cn_max 0.5 以下を目安 | 斜面方向の重力項の誤差補正。土砂は[地形変化](geomorph.md) |
| 河川の低水・緩流の流速分布 | f_diffusion_term=2(係数指定不要) | 流れに応じた渦粘性で横断方向の流速分布が滑らかになる |
| 都市氾濫(家屋群あり) | 既定 + fn_gv/fn_bb([地理情報](geoinfo.md))。cm/cd/kk は既定 | 貯留減少と抗力は地理情報側で表す |
| 広域・長期(コスト優先) | p_adprunge_thresh 2〜3、f_friction_fastmath 3〜5、必要なら f_govequation=1(拡散波) | 再計算率と摩擦項のコストを落とす。拡散波は慣性を無視するので氾濫の前縁・津波には使わない |
| 精度検証・数値実験 | p_adprunge_thresh 1.1、p_adv_upwind_index 0.5、f_friction_fastmath 0 | 高精度側。コストは数割増 |
| 段波・跳水・津波の遡上(不連続を含む流れ) | f_advection_scheme 3 | 運動量保存形移流。段波速度が正しく、段波背後の振動が出ない。既定の 1 は段波が遅れ背後に振動が出る |

## 検証との関係

これらのスイッチの多くは計算結果を変えます。回帰テスト
(test/ の reference)は既定値で作られているので、変更した設定での
結果比較は自前の基準で行ってください。
