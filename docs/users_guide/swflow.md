# 浅水流計算(&list_enc と数値定数)

[ユーザーガイド目次へ](../users_guide.md)

コアの地表水計算(ENC 格子上の浅水方程式)の調整パラメータです。
**既定値のままで妥当に動くように設定されています** — この章の設定は
精度・コストの調整や数値実験のためのもので、通常の計算で触る必要が
あるのは適応的ルンゲクッタの閾値くらいです。格子の幾何・連続式・
セル流速の再構成・運動方程式の各項・適応的ルンゲクッタ・クーラン数・
数値定数の式と既定値の根拠は[ENC 格子と時間積分の解説](encgrid.md)に、
移流項・拡散項・非静水圧補正はそれぞれの解説ページにあります。

![ENC 格子と適応的ルンゲクッタ](../figs/swflow_enc.png)

**(a) ENC 格子。** 水深 h と地盤高 z はセル中心に置き、周囲8セル
(軸4方向・対角4方向)へのエッジで法線流速 uv と単位幅流量 mn を扱います。
塗りつぶしの四角は軸方向、白抜きの四角は対角方向のエッジ量の位置です。
セル中心の流速 u, v はエッジ流速を幾何重みで合成して再構成します。
p_diagratio は対角方向の通過幅の配分を調整する係数で、既定値は 8 本の
通過幅が等しくなる値です([解説](encgrid.md) §2・§4)。格子の定式化と
検証は原論文[^tada26]にあります。

**(b) STG 格子。** 旧互換・比較用の4近傍スタガード格子です。水深と地盤高は
セル中心(内部配列名 D・H)、x 方向の単位幅流量 M は東西面(四角)、
y 方向の単位幅流量 N は南北面(菱形)に置きます。出力用のセル流速 u, v は、
対向する2面の流量の平均をセル水深で割って求めます(限界水深未満では0)。
再開、サブグリッド河道・堤防、内部水理構造物は STG では非対応です。

(a)(b)は正方セルの模式図で、中央セルに関わる接続と量の位置を強調しています。
**(c) 適応的ルンゲクッタの判定帯。** 陽解法で得たエッジの単位幅流量を
前ステップ値と比較し、閾値の範囲外ならそのエッジを4段RKで再計算します。
判定式・段の構成・Runge 列の集計は[解説](encgrid.md) §6 にあります。

## とりあえず動かしてみる(最小入力)

この章の設定は**すべて既定値で動きます** — fn_enc を書かなくて構いません。
既定は「乾床前縁の安定(f_exflux_reduction)・急勾配の重力補正
(f_gravity_correction)・適応的ルンゲクッタ(閾値 1.5)」が有効の、
津波・氾濫・出水のどれにも無難な組です。

## 方式の選択(&list_sysparam)

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_gridsystem | 0 | 0: ENC 格子(既定)、1: STG(スタガード格子。旧互換の比較用。新機能・再開は非対応) |
| f_govequation | 0 | 0: 力学波(移流+圧力。既定)、1: 拡散波(圧力のみ)、2: 運動波 |
| f_check_cfl | 1 | クーラン数 Cn = (\|V\| + √(gh)) dt / min(dx, dy) の監視。0: 監視のみ(停止しない)、1: Cn > 1 で状態を表示して停止(既定)、2: 波速を無視した移流クーラン数で判定・停止(Cn 列・Cn 出力の定義も移流 Cn に変わる)([解説](encgrid.md) §7) |

拡散波・運動波は感度実験・他モデルとの比較用です。乾湿を含む氾濫・
遡上は力学波のまま使ってください。

## 数値定数(&list_sysparam)

| パラメータ | 既定値 | 意味(根拠は[解説](encgrid.md) §8) |
|---|---|---|
| dd | 0.001 | 限界水深 (m)。両側がこれ未満のエッジは流量を計算しない |
| dv | 0.001 | 摩擦項に使う水深の下限 (m) |
| vv | 0.01 | 摩擦項に使う流速の下限 (m/s) |
| gg | 9.8 | 重力加速度 (m/s²) |
| cm / cd / kk | 2.0 / 1.0 / 0.5 | 家屋群の付加質量係数・抗力係数・遮蔽係数(地理情報の gv/bb とセットで使用。[地理情報の章](geoinfo.md)) |

## ENC 計算の調整(&list_enc)

`fn_enc` で有効化します(未指定でもコアは既定値で動きます)。

```
&list_enc
  p_adprunge_thresh = 1.1        ! 適応的ルンゲクッタの閾値 (1.1 ~)
/
```

**時間積分(適応的ルンゲクッタ)**(詳しくは[解説の §6](encgrid.md#6-時間積分と適応的ルンゲクッタ))

陽解法で得たエッジの単位幅流量が前ステップ値の 1/thr 倍〜thr 倍の帯を
外れた(反転を含む)エッジだけを 4 段ルンゲクッタで再計算します。少数の
極端なセルのために全域の dt を縮めないための機構で、画面の **Runge 列**
(再計算したエッジの割合)が数割に達するなら dt を小さくする方が本筋です。
閾値の効果は[チュートリアル Step 2](../../tutorials/wave/README.md#step-2-enc-パラメータの設定)
が実演しています。

| パラメータ | 既定値 | 意味(詳細は[解説](encgrid.md)の §) |
|---|---|---|
| f_adaptive_runge | 1 | 適応的ルンゲクッタ。流量が判定帯を外れたエッジだけ 4 段 RK で再計算(移流項は時刻 n に固定)(§6) |
| p_adprunge_thresh | 1.5 | 再計算の閾値 thr(1.1 以上。小さいほど再計算が増える。精度は dt で上げる方が確実)(§6) |

**フラックス・安定化**

| パラメータ | 既定値 | 意味(詳細は[解説](encgrid.md)の §) |
|---|---|---|
| f_gravity_correction | 1 | 急勾配の有効重力 g cos²θ(Ni et al. 2019)。緩勾配では無効果(§5) |
| f_exflux_reduction | 1 | 過大な流出の抑制。乾いた地表を進む前縁の負水深を防ぐ(乾床のある計算では on のまま)(§5) |
| f_hcap_upwind | 1 | エッジ水深。0: 両側平均、1: 平均を上流側水深で頭打ち(既定)、2: 上流側水深そのもの(段波先端のスパイク防止。砕波・段波を含む非静水圧ケースでは必須。乾いた地表への流出が増えるので氾濫では ex_flux を確認)(§3、[移流項](advection.md) §5) |
| f_friction_fastmath | 0 | 摩擦項 h^(−4/3) の表近似。0: 厳密(既定)、1〜5: 粗く速い(相対誤差 2e-4〜6%)(§8) |
| p_diagratio | 2/(2+√2) | 斜めエッジへの通過幅の配分比。既定は 8 本の通過幅が等しくなる値(通常変更不要)(§2) |

**移流項・拡散項**

移流項(慣性項)は既定の運動量保存形+MUSCL(スキーム 3)で段波・跳水・
実地形の洪水波を正しく扱い、通常は変更不要です。拡散項(渦動粘性による
運動量の水平拡散)は既定で無効で、数値の安定化のためには要りません。
方程式・スキーム・ステンシルの解説は[移流項のスキーム](advection.md)、
渦動粘性モデル・離散化・安定条件の解説は[拡散項の解説](diffusion.md)に
あります。

拡散項をまず使ってみるなら、指定は 1 行です(ゼロ方程式モデル。係数は
流れと粗度から自動で決まる)。

```
&list_enc
  f_diffusion_term = 2    ! 拡散項(ゼロ方程式モデル。移流項は既定のまま)
/
```

**使い方の要点**(詳しくは[移流項の §5](advection.md#5-性質の比較と使い分け)・[拡散項の §6](diffusion.md#6-使いどころと注意))

- **移流項は既定のまま**(スキーム 3 + `f_opening_dynamic = 2` +
  `f_dry_head_cap = 1`)。旧版で校正したケースの再現だけ
  `f_advection_scheme = 1`、`f_opening_dynamic = 0`、`f_dry_head_cap = 0`
  (2026-10-03 以前の既定。スキーム 3 へ移るなら粗度を再校正)。
  2026-10-18 までの既定 `f_opening_dynamic = 1`(河道マスクのエッジだけ)は
  河道マスクのない掘込河道・壁沿いで無効だったため、全エッジの 2 を既定に
  した(1 セル幅の水路の通水能が Manning に一致する。test/uniflow)。
- **実地形で観測より遅い・小さいとき**(河道マスクあり)は
  `f_advection_donor = 1` を試す。
- **拡散項の出番**は河道の横断流速分布・湾内の循環流。`f_diffusion_term = 2`
  なら係数不要で、粗度 n が ν の大きさを決めます(典型値 0.01〜0.1 m²/s)。
  定数粘性(モデル 1)は `p_diffusion_nu` の明示が必須で、陽解法の上界
  Δx²/(2.83 dt) 以下にします(超えると警告)。
- **質量**は移流項・拡散項の設定によらず厳密に保存されます。スキーム 2・3
  のコストはスキーム 1 の +12〜27%、拡散項は無効時にゼロ追加です。
- **検証ケース**: 段波 [test/dambreak](../../test/dambreak/README.md)、
  屈曲・階段・横流入 [test/bendloss](../../test/bendloss/README.md)、斜面流
  [test/hillslope](../../test/hillslope/README.md)、実地形
  [test/chichibu](../../test/chichibu/README.md)。拡散項の解析解ベンチマーク
  [test/diffusion](../../test/diffusion/README.md)(ガウス形ジェットの拡散。
  誤差 0.14% 以下)。

| パラメータ | 既定値 | 意味(詳細は解説ページの §) |
|---|---|---|
| f_advection_scheme | 3 | 移流項のスキーム。3: 運動量保存形+MUSCL(既定)、2: 運動量保存形・1 次風上、1: セル中心勾配(旧既定。非保存形で段波が遅れ、実地形で格子収束しない)([移流項](advection.md) §3〜5) |
| f_advection_donor | 0 | 1: 河道セル同士のエッジで流下方向の風上供給元を河道セルに限る(屈曲・合流の人工損失対策。河道マスク fn_rw が必須。妥当性は実測で判断)(§4.4) |
| f_scalar_scheme | 3 | スカラー輸送(浮遊砂・水質・塩水層・流木・瓦礫)の移流スキーム。3: リンクごとの MUSCL(既定)、1: 1 次風上(旧既定。数値拡散が縦断で 3〜5 倍、横断で 14 倍。比較・退避用)([移流項](advection.md) §7) |
| f_dry_head_cap | 1 | 乾燥セルへ向かうエッジ水深をエネルギー頭で頭打ち(水は水面より高い乾いた地盤へ登らない。段波先端・掘込水路の漏れと発散を防ぐ。通常の乾湿前縁では効かず 0 と同一)(§5) |
| f_opening_dynamic | 2 | 塞がれた斜め開口の動的振り替え。2: 全エッジ(既定。2026-10-18 に 1 から変更)、1: 河道セル間のエッジのみ(河道マスクがなければ無効)、0: なし。1 セル幅河道・壁沿いでエッジ流速が過大になる ENC の性質の補正(§5) |
| p_adv_upwind_index | 0.5 | スキーム 1 だけの風上化指数(0: 中心差分、1: 1 次風上)(§3) |
| f_diffusion_term | 0 | 拡散項。0: なし(既定)、2: ゼロ方程式モデル ν = ν0 + α·u*·h(推奨)、1: 定数粘性([拡散項](diffusion.md) §2) |
| p_diffusion_nu | — | ν0 (m²/s)。モデル 1 では正値の明示が必須(未指定はエラー停止)。モデル 2 では省略可のバックグラウンド粘性(§2) |
| p_diffusion_alpha | 0.41/6 | ゼロ方程式の係数 α(既定は Elder 型。横断混合を強めるなら 0.15〜0.6 で校正)(§2) |

**非静水圧補正(研究用)**

1 層非静水圧補正は、周波数分散(短い波ほど遅い)が本質の現象 — 河川を
遡上する津波のソリトン分裂・undular bore、地滑り津波の近地造波、貯水池の
孤立波 — のための研究オプションです。降雨流出・洪水氾濫・高潮・一般的な
長波津波には不要で、既定は静水圧です(無効時は計算・メモリ・通信の追加が
なく、従来とビット一致)。方程式・射影アルゴリズム・活性集合・砕波・底面項
と、参考にした他モデル・文献の解説は別ページ
[非静水圧補正の解説](nonhydrostatic.md)にあります。

まず使ってみるなら、指定は 1 行です(ソルバ CG・全域解・平坦床の 1 層
モデル)。

```
&list_enc
  f_nonhydrostatic = 1    ! 1 層非静水圧補正(他は既定)
/
```

**使い方の要点**(詳しくは[解説の §8](nonhydrostatic.md#8-適用範囲と使い方の要点))

- **格子は水深の半分以下**(Δx ≲ H/2。検証は H/4〜H/8)。それより粗いと
  格子の数値分散に埋もれて補正の意味がありません。コストはソルバより
  この解像度要件で決まります。
- **必要に応じて段階的に足す**: コストを抑えるなら `f_nh_adaptive = 1`
  (分散が効く場所だけで解く)。砕波・段波を含むなら `f_nh_breaking = 1`
  + `f_hcap_upwind = 2`(必須)、遡上高の定量評価には `nh_break_visc = 1.44`
  と摩擦 n ≈ 0.01 を併せ、Courant ≲ 0.1・Δx ≲ H/8 で収束を確認する。
  急な地形変化(棚・海底地滑り)で `f_nh_slope = 1`、地滑り津波の近地で
  `f_nh_bottom = 1`。
- **自動で静水圧に退化する場所**: 水深 nh_hmin 未満、海域マスク、堤防壁、
  サブグリッド河道幅・断面形、家屋占有セル、砕波セル、強制境界の近傍
  (nh_bc_margin)。
- **制約**: 土石流(f_debris)とは併用不可。再開は cold start(非静水圧の
  私有状態は保存しない)。ネストの子格子は帯で親の φ を受け取る
  ([ネスティング](nest.md) nest_nh)。
- **コスト**: 全域で解くと静水圧の 2〜3 倍(CG で 1 ステップ 10〜90 反復)。
  活性集合で解く範囲を限ると長波・定常流・氾濫の領域には乗りません。
- **検証ケース**: 定在波の分散関係 [test/nhwave_nh](../../test/nhwave_nh/README.md)、
  孤立波 [test/nhsolitary](../../test/nhsolitary/README.md)、undular bore
  [test/nhbore](../../test/nhbore/README.md)、棚のソリトン分裂
  [test/nhshelf](../../test/nhshelf/README.md)、砕波遡上
  [test/nhbreak](../../test/nhbreak/README.md)、動く底面
  [test/nhbottom](../../test/nhbottom/README.md)(結果の要約は解説の §8)。

## パターン別の推奨値

| 型 | 推奨する設定 | 理由 |
|---|---|---|
| 津波・高潮の遡上 | 既定(p_adprunge_thresh 1.2〜1.5)。f_check_cfl=1 で Cn 監視 | 乾床を進む前縁と反射波の両方を既定の安定化が扱う |
| 急勾配山地の出水・土石流 | f_gravity_correction=1(既定)、dt は Cn_max 0.5 以下を目安 | 斜面方向の重力項の誤差補正。土砂は[地形変化](geomorph.md) |
| 河川の低水・緩流の流速分布 | f_diffusion_term=2(係数指定不要) | 流れに応じた渦粘性で横断方向の流速分布が滑らかになる |
| 都市氾濫(家屋群あり) | 既定 + fn_gv/fn_bb([地理情報](geoinfo.md))。cm/cd/kk は既定 | 貯留減少と抗力は地理情報側で表す |
| 広域・長期(コスト優先) | p_adprunge_thresh 2〜3、f_friction_fastmath 3〜5、必要なら f_govequation=1(拡散波) | 再計算率と摩擦項のコストを落とす。拡散波は慣性を無視するので氾濫の前縁・津波には使わない |
| 精度検証・数値実験 | p_adprunge_thresh 1.1、f_friction_fastmath 0、dt は Cn_max 0.5 以下 | 高精度側。コストは数割増。閾値を下げるより dt を縮める方が確実(dt 0.01 と 0.05 の差は閾値では埋まらない。tutorials/wave Step 2) |
| 段波・跳水・津波の遡上(不連続を含む流れ) | 既定(f_advection_scheme 3) | 運動量保存形移流。段波速度が正しく、段波背後の振動が出ない。旧既定の 1 は段波が遅れ背後に振動が出る |
| 河道マスクのある区間だけ振り替えたいとき | f_opening_dynamic 1 | 2026-10-18 までの既定。既定の 2 は全エッジで壁沿い・掘込水路の通水能を補正する |
| 旧バージョンで校正したケースの再現 | f_advection_scheme 1、f_opening_dynamic 0、f_dry_head_cap 0 | 2026-10-03 以前の既定。3 への移行では粗度の再校正が要る(運動量保存形は跳水の損失と谷底との運動量交換を解くぶん遅く小さい) |

## 出力・確認

分布出力の 3 通りの有効化(自動 / 指定 / 共用)と柱状量の面積基底の読み方は[入出力の形式](io.md#状態量の分布出力の考え方)に、確認したい量から出力を逆引きする早見表は同じ節の末尾にあります。

**分布**(`result/` のラスタ。`dt_file` 間隔)

| ファイル | 出し方 | 内容 |
|---|---|---|
| H / E | f_out_h(既定 on)/ f_out_e | 水深 (m。空隙面積基底)/ 水位 (m) |
| u / v / V | f_out_u / v / vv | セル流速の成分と絶対値 (m/s) |
| m / n / Q / Qd | f_out_m / n / qq / qd | 単位幅流量の成分・絶対値 (m²/s)・流向 (rad) |
| Fr / Cn | f_out_fr / f_out_cn | フルード数 / クーラン数の分布 |
| H9999 / Ht9999 / V9999 / Q9999 / Qt9999 / Qd9999 | f_out_hmax(既定 on)ほか | 期間最大の水深・流速・流量とその時刻(分)・流向 |

**台帳・ログ**(収支と数値の健全性)

- Log.txt の列: `time, progress, S(m), Runge, ex_flux, Cn_max, h_max, V_max`
  (地下水・積雪・氷河のいずれかが有効なら S は S_surf / S_grnd / S_total の
  3 列。`f_disp_*` で列の表示を選択)。S は領域平均の貯留高(m。gv 換算と
  ため池・ダム貯留込み、海セルを除く)、`Runge` は適応的ルンゲクッタで
  再計算したエッジの割合、`ex_flux` は過大な流出フラックスを抑制した回数、
  `Cn_max` は領域最大のクーラン数です。

**計測**(プローブ・測線の列)

- プローブ: `z, h, u, v, |V|, q`(+ hg, hs, sd、水質の C・cq)。
  測線: `Q, Hmax, Vmax, B`(+ 水質の L・Lcum)。終了時に `summary.csv` に
  全地点・全測線の Qmax・Hmax をまとめます([計測の章](record.md))。

**再開**

- 水深・流量は本体の状態保存、ENC のエッジ量(流速・流量・通過幅の
  動的振り替え)は私有ファイル `swflow_enc.dat` で自動的に扱われます。
  非静水圧補正は再開時に cold start です。

**読み方と検算のコツ**

- 時間刻みの健全性: `Cn_max` が 1 を超えない(超えると既定では停止)、
  `Runge` が数十 % を超えて張り付かない、`ex_flux` が増え続けない。
  いずれかに当てはまれば dt を小さくします([クーラン数と時間刻み](courant.md))。
- 水収支: 閉領域で境界条件がなければ S は一定です(桁は `f_disp_debug = 1`
  で全有効桁)。変化があれば境界・海域・構造物・蒸発散の経路を疑います。
- 最大値統計は毎ステップ更新されるため、`dt_file` 間隔のフレームから
  拾った最大とは異なります。浸水深のハザードマップには H9999 を使って
  ください。
