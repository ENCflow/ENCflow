# 流木モデルの解説(流木の補足)

[流木の章へ](driftwood.md) | [ユーザーガイド目次へ](../users_guide.md)

[流木の章](driftwood.md)の 3 台帳モデルの移送則、代表材の喫水、面積基準と
材積収支、実務値の出典、既定値の根拠と、構造物での捕捉と集積(4 つ目の台帳。§6)を
まとめます。実装は `src/m_driftwood.f90`(集積の抵抗の項は `src/m_swflow_enc.f90`)で、
設計の経緯と文献照合は developer.md §50 にあります。

## 1. 台帳と移送則

立木ストック $`w_{st}`$・流動流木 $`h_d`$・堆積流木 $`w_d`$ の 3 台帳を
使い、$`h_d`$ だけが水(土石流時は水・土砂の混合体)とともに保存的に
輸送されます。判定に使う混合流動深は $`H = h + \max(h_s, 0)`$、$`V`$ は
セル流速で、水だけの乾燥判定 $`h \le d_d`$ とは区別します。

| 経路 | 条件 | 移送 |
|---|---|---|
| ① 水理的流失 $`w_{st} \to h_d`$ | $`H >`$ dw_hrec かつ $`V >`$ dw_vrec | レート dw_wrec |
| ② 侵食連行 $`w_{st} \to h_d`$ | $`z_{ref} - z >`$ dw_droot(基準からの正味の地盤低下) | 残量を全量 |
| ③ 停止・堆積 $`h_d \to w_d`$ | $`h \le d_d`$ なら全量。それ以外は $`H < h_f`$ または $`V <`$ dw_vstop | レート dw_wstop |
| ④ 再流動 $`w_d \to h_d`$ | dw_wfloat > 0 のとき、$`H >`$ dw_rfloat $`\times h_f`$ かつ $`V >`$ dw_vfloat | レート dw_wfloat |

各レート $`w`$(m³/m²/s)による 1 ステップの移送量は、移送元台帳の残量
$`S`$ を上限とします。

```math
\Delta = \min\left(w\,\Delta t,\ S\right)
```

実装では移流・地形更新後に ② → ① →(⑤ 構造物での捕捉。§6)→ ③ → ④ → ダム捕捉 →
期間最大値の更新の順に処理します。乾燥判定を通ったセルでも、再流動を有効にして
$`H`$・$`V`$ の条件を満たせばその後の ④ で再判定されます。侵食連行の
判定量は侵食増分の累積ではなく基準標高 $`z_{ref}`$(初期化時。再開時は
保存値)からの正味の低下で、侵食の原因は区別しません。

## 2. 代表材の喫水

代表材の喫水 $`h_f`$ は、直径 $`D`$ = dw_dlog、材比重 $`s_g`$ = dw_sglog の
横向き円柱の浮力平衡(水没断面積比 = 比重)の解です[^braudrick00]。
水没弓形の中心角を $`\theta`$ とすると

```math
\frac{\theta - \sin\theta}{2\pi} = s_g,\qquad
h_f = \frac{D}{2}\left(1 - \cos\frac{\theta}{2}\right)
```

で、$`s_g = 0.5`$ のとき $`\theta = \pi`$、$`h_f = D/2`$(半没)です。
一般には $`h_f \ne s_g D`$($`s_g = 0.3`$ で $`h_f \approx 0.34 D`$)。

## 3. 面積基準と材積収支

$`w_{st}`$ はセルの幾何面積当たり、$`h_d`$・$`w_d`$ は水と同じ実効面積当たりの
柱状材積です。$`A = \Delta x\,\Delta y`$、$`f = g_v\,w_{frac}`$(河道幅を
指定しない場合は $`w_{frac} = 1`$)とすると、領域内の材積は

```math
Q = \sum_{i,j} A\left[w_{st,ij} + f_{ij}\,(h_{d,ij} + w_{d,ij})\right]
```

です。流木化で $`w_{st}`$ が $`\Delta w`$ 減ると $`h_d`$ は $`\Delta w / f`$
増えます。dw_wrec は幾何面積当たり、dw_wstop・dw_wfloat は実効面積当たりの
材積レート(m³/m²/s)です。閉領域・ダム捕捉なしなら現在貯留の和 $`Q`$ が
初期材積を保存します(数値誤差を除く)。集積流木 $`w_j`$(§6)は $`h_d`$・$`w_d`$ と
同じ実効面積当たりの柱状量で、捕捉セルを与えたときは $`f_{ij}\,w_{j,ij}`$ が和に加わります。

## 4. 実務値の出典

砂防計画の指針[^nilim904]に基づく目安です。

- **dw_dlog**: 流木の平均直径は上流立木の平均胸高直径とほぼ等しい、が
  指針の推定法です。胸高直径の調査値をそのまま使えます。
- **立木ストック**: 単木材積 $`V_1`$ と本数密度 $`N`$(本/m²)から

  $`w_{st} = N\,V_1`$、$`V_1 = \tfrac{\pi}{4} D_{bh}^2 H_t f_s`$
  ($`D_{bh}`$ 胸高直径、$`H_t`$ 樹高、$`f_s`$ 胸高係数 0.3〜0.7)で材積
  (m³/m²)へ換算します(前処理)。渓流での発生流木量の実績包絡値は
  針葉樹で概ね 1,000 m³/km²(= 0.001 m³/m²)、広葉樹で概ね 100 m³/km²
  (= 0.0001 m³/m²)です。
- **検証指標**: 施設がない渓流では発生流木の 8〜9 割が谷出口へ流出した、
  との実態報告が指針に引かれています(流木流出率 0.8〜0.9)。
- **侵食連行(dw_droot)**は、指針の発生量算出(崩壊・土石流の発生・流下
  範囲にある立木が流木化する)と同じ考え方です。
- **水理的流失**の閾値・レートは校正パラメータです(指針は水深・流速閾値に
  よる流失式を持たないため実務標準値はありません)。
- **再流動**: 水路実験では流向平行・根株付きの流木は喫水の約 1.2 倍の
  水深で動き、流向に斜交した流木は喫水未満でも回転しながら動きます
  [^braudrick00]。既定 dw_rfloat = 1.5 は安定側の値です。
- **衝突力**(後処理): 実務の標準[^nilim905]は流木の衝撃力を「礫の衝撃力
  算定式を準用し、速度は流れの流速・径は流木の最大直径」として算出します。
  最大流速 V9999 と代表材の諸元をその式(あるいは FEMA P-646 の流木衝突式)に
  与えれば指針整合の衝突力マップを作れます。

**既定値を見直すときの手がかり**

- 立木ストックは、森林簿・森林資源データの林分材積(m³/ha)を
  1 ha = 10⁴ m² で割って与えるのが最も直接的です。流出する割合は
  流木対策の技術指針[^nilim904]の発生原単位で見積もれます。
- 代表直径・比重は樹種(針葉樹・広葉樹)と林齢で決まり、同指針の
  推定法に表があります。

## 6. 構造物での捕捉と集積

捕捉率の分布 `fn_dwtrap` を与えると、流動流木 $`h_d`$ から集積流木 $`w_j`$ への経路 ⑤ と、
集積の抵抗が有効になります。$`w_j`$ は動かない台帳で、増える向きだけです。開口がセルより狭い
カルバートは、カルバートごとの `culv_jam = 1` で、流入口の集積を流量則の損失として扱います
(この節の「カルバートの流入口の損失」)。

**捕捉の規則(独自)。** 捕捉率 $`E`$ は「捕捉セルを 1 回通過する流木のうち捕捉される割合」です。
計算はセルの中だけで行います。よく混ざったセルでは、滞留時間 $`\Delta x / |V|`$ の間に一定の
率 $`k`$ で捕捉が進むと、通過する流木のうち捕捉される割合は $`k\tau/(1 + k\tau)`$ です。これが
$`E`$ になるよう $`k\tau = E/(1-E)`$ と置くと、1 ステップの捕捉量は

```math
\Delta = h_d\,\frac{r}{1+r},\qquad r = \frac{E}{1-E}\,\frac{|V|\,\Delta t}{\Delta x}
```

です($`\Delta x`$ はセルの短い方の辺)。$`E \ge 1`$ はその時点の $`h_d`$ の全量で、移流の後に
適用するので「入った流木をすべて止める」になります。集積量が `dw_jamgrow` を超えたセルは
$`E = 1`$ として扱います。捕捉は発生(① ②)の後、接地の堆積(③)の前に適用します。
格子の軸に沿う一様な定常の流れでは、移流と捕捉を順に適用する離散化でも、捕捉される割合が
$`E`$ に一致します。流れが変化する場合や斜めの流れでは近似で、検証ケースでは $`E = 0.3`$ に
対して 0.304 でした。

**集積の抵抗。** 集積を多孔質の障害物として扱います。流木の集積による運動量の損失を、
丸太の径・充填の度合い・集積の長さに比例する抗力で表す考え方[^follett20]に基づき、その構造の
係数 $`C_A = L\,C_D\,a/(1-\varphi)^3`$($`L`$ は集積の長さ、$`a`$ は単位体積あたりの前面積、
$`\varphi`$ は実材積の割合。円柱では $`a = 4\varphi/(\pi d)`$)と同じ形の抗力を、運動方程式の
半陰の項に入れます(離散化は独自)。集積の中の間隙流速は $`u/(1-\varphi)`$ なので、見かけの
流速 $`u`$ に対する減速度は $`\dfrac{C_D\,a}{2(1-\varphi)^3}|u|u`$ です。セルの集積が充填率
$`\varphi`$ で水柱の全深を占め、セルの長さのうち $`(w_j/h)/\varphi`$ の割合を塞ぐとすると、
辺の抗力項は

```math
F_{\text{jam}} = -\,\kappa_0 \min\!\left(\frac{w_e}{h_f},\ \varphi\right)|\mathbf{V}|_e,
\qquad \kappa_0 = \frac{2\,C_D}{\pi\,d\,(1-\varphi)^3}\ \ [\mathrm{m^{-1}}]
```

になります。$`w_e`$ は辺の両側のセルの $`w_j`$ の平均、$`h_f`$ は摩擦項と同じ辺の水深、
$`|\mathbf{V}|_e`$ は辺の速さです。$`\min`$ は、水柱に入りきらない分が抵抗を増やさないことを
表します。半陰の項なので、時間刻みの制約は増えません。河道幅(`fn_width`)のセルでは流速が
河道の中の流速で、集積量も河道の平面積あたりなので、同じ式がそのまま使えます。

定常の 1 次元の流れでは、漸変流の式に項が 1 つ増えた形になり、これが検証の解析解です。

```math
\frac{dh}{dx} = \frac{S_0 - \dfrac{n^2 q^2}{h^{10/3}} - \kappa_0 \min\!\left(\dfrac{w}{h},\ \varphi\right)\dfrac{q^2}{g\,h^2}}{1 - \dfrac{q^2}{g\,h^3}}
```

**カルバートの流入口の損失(独自)。** [カルバート](structure.md)の開口はセルより狭く、流入口へ
集まるセルの流れは開口の中の流れよりずっと遅いので、上の辺の抗力では開口の閉塞を表せません
(損失は流速の 2 乗に比例します。10 m 格子と 1 m × 1 m の開口の試算では、流入口のセルに 100 m³ の
集積を置いても流量は 0.1 % しか減りませんでした)。そこで、`culv_jam = 1` を付けたカルバートでは、
集積を開口の流速に対する損失係数にします。

- **捕捉。** カルバートは流木を通さないので、そのステップにカルバートが取水している側のセル群
  (流量が正なら取水セル群、負なら吐口セル群)の流動流木 $`h_d`$ を、全量 $`w_j`$ へ移します。
  流量が 0 のステップは移しません。
- **損失係数。** 開口の断面 $`B \times D`$ を、厚さ $`L`$・充填率 $`\varphi`$ の集積が覆うと
  考えます。集積の実材積は $`V_j = \varphi L B D`$ なので、上と同じ構造の係数は

  ```math
  C_A = \frac{L\,C_D\,a}{(1-\varphi)^3} = \frac{4\,C_D}{\pi d\,(1-\varphi)^3}\,\frac{V_j}{BD}
      = 2\,\kappa_0\,\frac{V_j}{BD}
  ```

  になります。$`V_j`$ は、水位の高い側のセル群の $`w_j`$ の実材積の和(m³)です。
- **満管。** エネルギー式の損失の和に足します。
  $`Q_p = BD\sqrt{2g\,\Delta\eta' / (1 + c_e + f_L + C_A)}`$。
- **自由水面(堰)。** 限界流の断面の手前で損失 $`C_A u_c^2/2g`$ が出るとします。上流の水頭を
  $`H`$、限界水深を $`y_c`$ とすると $`H = y_c + (1 + C_A)\,u_c^2/2g`$、$`u_c^2 = g\,y_c`$ から
  $`y_c = H/(1.5 + C_A/2)`$ です。流量は $`y_c^{3/2}`$ に比例するので、損失のないときの

  ```math
  \left(\frac{1.5}{1.5 + C_A/2}\right)^{3/2} = \left(1 + \frac{C_A}{3}\right)^{-3/2}
  ```

  倍になります。この倍率を、本間公式の堰の流量(自由越流と潜り越流)に掛けます。管路の式の
  下流側の水頭に使う限界水深 $`d_c`$ は、倍率を掛けた後の流量から求めます。

既定の係数($`d`$ = 0.3 m、$`\varphi`$ = 0.3、$`C_D`$ = 1 で $`\kappa_0`$ = 6.19 m⁻¹)と
$`c_e`$ = 0.5・管路長 0 では、1 m × 1 m の開口に実材積 0.06 m³ で $`C_A`$ = 0.74(堰 0.72 倍、
満管 0.82 倍)、0.5 m³ で $`C_A`$ = 6.2(堰 0.19 倍、満管 0.44 倍)です。

この定式の限界は次のとおりです。

- 損失は $`V_j/(BD)`$ だけの関数です。流木の長さと開口の寸法の比、集積の形、水位と集積の位置の
  関係は見ません。
- 堰の倍率は、損失を限界流の断面の流速 $`u_c`$ で見積もる仮定によります。集積は開口の手前の
  水深の深い所にあるので、そこでの流速で見積もるより損失が大きく出ます。$`C_A`$ が大きいと、
  堰の倍率($`C_A^{-3/2}`$ に比例)は満管の倍率($`C_A^{-1/2}`$ に比例)より速く小さくなります。
  照合できる実測はまだありません。
- 取水セル群に入った流木は、カルバートへ向かう流れの割合によらず全量が集積します。流れの一部
  だけがカルバートへ向かうセル(河道の本流のセルを取水セル群にした樋管)では、閉塞を過大に
  見積もります。
- 集積は減らず、流量は 0 にはなりません。流れが逆転すると、水位の高い側のセル群の集積だけを
  読みます。

**係数と限界。**

- $`C_D`$・$`\varphi`$ は校正値です。$`\varphi`$ は $`(1-\varphi)^3`$ で効くので感度が大きく、
  枝葉や細かい有機物の割合が堰上げを大きく変えることが水路実験で報告されています[^schalko18]。
  既定の 1.0・0.3 は仮の置き値です。上の 2 つの文献は、この作業では原文を入手できず、式の形と
  記述は二次の資料によります。文献の一括の式(集積の前後の水深を結ぶ式)と、ここでの分布した
  抗力の積分とは、同じ係数でも堰上げが一致するとは限らないので、文献の校正値をそのまま
  持ち込むことはできません。実測の堰上げとの照合はまだありません。
- 抵抗は集積の実材積で決まります。水路の幅あたりの実材積が同じなら、置き方と格子幅を変えても
  堰上げの差は 1 % 未満でした(開発時の試計算)。
- 底面せん断(流砂)には集積の抵抗を入れません。集積の抵抗は形状抵抗で、粒子にかかるせん断では
  ないためです。
- できないこと(掛かるかどうかの判定、集積の形と崩壊、桁による圧力流れ、セルより小さい開口の
  閉塞など)は[流木の章](driftwood.md#構造物での捕捉と集積fn_dwtrap)にまとめています。

## 7. 検証ケース

- [test/driftwood](../../test/driftwood/): 侵食連行・水理的流失の両経路について材積保存・輸送・堆積を検定し、分割継続と通し計算の保存状態も比較。構造物での捕捉と集積は、直線水路で、材積保存(集積を含む)、集積の抵抗による堰上げが上の漸変流の式の解に一致すること(上昇量の比 1.003。充填率の上限が効く条件で 0.982)、捕捉率(0.3 に対して 0.304)、`f_dwjam = 0` の流れが流木なしの計算とバイト一致すること、分割継続を検定。カルバートの流入口の損失は、上流槽を 1 本のカルバートで排水する構成で、貯留の減り方から求めた流量が、損失を入れた流量則に一致すること($`C_A`$ = 6.2 の堰で 0.02 % 以内、$`C_A`$ = 0.74 の満管と堰で 0.12 % 以内)、`culv_jam = 0` と `f_dwjam = 0` の流れが流木なしの計算とバイト一致すること、分割継続を検定。
- [examples/timberyard](../../examples/timberyard/): 高潮による貯木場からの材木流入(材木の流出を遅らせる・貯木場を離す・防潮壁を高くする対策の比較、補足に堆積パラメータの比較、衝突力の後処理)。
- [examples/tsunami_town](../../examples/tsunami_town/): 津波の海岸林・貯木場と家屋破壊との連鎖(補足)。
