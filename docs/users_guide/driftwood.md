# 流木(fn_driftwood)

[ユーザーガイド目次へ](../users_guide.md)

洪水・氾濫・土石流に同伴する**流木**の発生・輸送・堆積を、セルごとの
柱状材積(m³/m²)の**ラスタ場**として概算します。1本1本の流木を追跡
する方式(個別要素モデル)ではなく、「どこの立木がどれだけ流木化し、
どこへどれだけ到達・堆積するか」の面的なポテンシャル評価が目的です。

流木は3つの台帳を移動します:

```
立木ストック wst ──流木化──> 流動流木 hd ──接地・乾燥──> 堆積流木 wd
 (不動・入力)   (a)(b)      (水と同速で移流)    (再流動も可)
```

- **(a) 水理的流失**: 浸水深と流速が閾値を超えたセルの立木が、指定
  レートで流失します(通常洪水の流木発生)。
- **(b) 侵食連行**: 河岸・渓床の累積侵食深が根系深を超えたセルの
  立木が、根系ごと全量流失します。侵食は
  [土砂・地形変化](geomorph.md)の掃流砂・土石流・斜面崩壊のどれでも
  自動的に連動します(設定は不要)。
- **停止**: 水深が喫水(材比重と代表直径から円柱の浮力平衡で決まる
  浮遊限界水深。Braudrick & Grant, 2000)を下回るか低速になった
  セルで堆積します。乾燥したセルでは全量が堆積に移ります。
- **輸送**: 流動流木は水(土石流有効時は水+土砂の混合体)と同じ
  速度で移流します。**土石流と流木の混合流れは、土砂・地形変化の
  f_debris と本機能を同時に有効化するだけで表現されます。**

## 有効化と設定

`&list_sysparam` で `fn_driftwood` を指定します。最小の設定は
立木ストックと流木の代表諸元、発生と停止のパラメータです:

```
&list_driftwood
  dw_stock0 = 0.01          ! 立木ストック (m3/m2。一様値)
  dw_dlog = 0.3             ! 流木の代表直径 (m)
  dw_sglog = 0.5            ! 材比重(0〜1。喫水は浮力平衡から自動導出)
  dw_wrec = 1.0e-5          ! 水理的流失レート (m/s)
  dw_hrec = 0.5             ! 流失の浸水深閾値 (m)
  dw_vrec = 1.0             ! 流失の流速閾値 (m/s)
  dw_droot = 0.5            ! 根系深 (m。侵食連行の閾値)
  dw_wstop = 0.01           ! 接地堆積レート (m/s)
/
```

## パラメータ

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_dw | 1 | 0 でファイルを残したまま一時無効化 |
| dw_stock0 | — | 一様な立木ストック (m³/m²)。fn_dwstock と排他でどちらか**必須** |
| fn_dwstock | — | 立木ストックの分布ファイル (m³/m²。地形と同じ行列形式) |
| dw_dlog | — | 流木の代表直径 (m)。**必須** |
| dw_sglog | — | 材比重 ρ木/ρ水(0〜1)。**必須**。喫水(浮遊限界水深)は円柱の浮力平衡の厳密解として自動導出(Braudrick & Grant, 2000。sg=0.5 でちょうど半没 = 0.5×dw_dlog) |
| dw_wrec | なし | 水理的流失レート (m/s = m³/m²/s)。指定で水理的流失が有効 |
| dw_hrec | — | 水理的流失の浸水深閾値 (m。土石流時は h+土砂の混合深で判定。dw_wrec 指定時必須) |
| dw_vrec | — | 水理的流失の流速閾値 (m/s。同上) |
| dw_droot | なし | 根系深 (m)。指定で侵食連行が有効(累積侵食深 > dw_droot で全量流失) |
| dw_wstop | — | 接地堆積レート (m/s)。**必須** |
| dw_vstop | 0 | 低速堆積の流速閾値 (m/s。0 = 水深(喫水)判定のみ) |
| dw_wfloat | 0 | 再流動レート (m/s。0 = 堆積した流木は動かない(安全側)) |
| dw_rfloat | 1.5 | 再流動の浮遊余裕率(水深 > rfloat×喫水 で再流動。1 より大) |
| dw_vfloat | — | 再流動の流速閾値 (m/s。dw_wfloat > 0 のとき必須。dw_vstop 以上) |

発生(dw_wrec / dw_droot)は少なくとも一方の指定が必要です。

**実務値の目安**(国総研資料 904「砂防基本計画策定指針(土石流・
流木対策編)解説」2016 より):

- **dw_dlog**: 流木の平均直径は上流立木の**平均胸高直径**とほぼ
  等しい、が指針の推定法です。胸高直径の調査値をそのまま使えます。
- **立木ストック**: 単木材積 = (π/4)×樹高×胸高直径²×胸高係数
  (0.3〜0.7)× 本数密度で材積 (m³/m²) へ換算します(換算は前処理
  で)。渓流での発生流木量の実績包絡値は針葉樹で概ね 1,000 m³/km²
  (= 0.001 m³/m²)、広葉樹で概ね 100 m³/km²(= 0.0001 m³/m²)です
  (流域一様ストックの目安・結果の量水準の確認に)。
- **検証指標**: 施設がない渓流では発生流木の 8〜9 割が谷出口へ
  流出した、との実態報告が指針に引かれています(流木流出率
  0.8〜0.9)。渓流スケールの計算結果の妥当性確認に使えます。
- **侵食連行(dw_droot)**は、指針の発生量算出(崩壊・土石流の
  発生・流下範囲にある立木が流木化する)と同じ考え方です。

水理的流失(dw_wrec/hrec/vrec)の閾値・レートは校正パラメータです
(指針は水深・流速閾値による流失式を持たないため実務標準値は
存在しません — 感度解析を推奨)。再流動の目安として、水路実験では
流向平行・根株付きの流木は喫水の約 1.2 倍の水深で動き、流向に
斜交した流木は喫水未満でも回転しながら動きます(Braudrick &
Grant, 2000 — 既定 dw_rfloat=1.5 は安定側の値です)。

## 出力

| スイッチ | ファイル | 内容 |
|---|---|---|
| f_out_hd | Hd0001… | 流動流木の柱状材積 (m³/m²) の分布(dt_file 間隔) |
| f_out_wd | Wd0001… | 堆積流木 (m³/m²) の分布 |
| f_out_wd | Wd9999 | **期間最大の到達量** max(流動+堆積)。流木ハザードマップの本体 |

`result/driftwood.csv` に材積台帳(流木化・堆積・再流動・ダム捕捉の
累積と現在貯留)が dt_recrd 間隔で記録されます。閉領域なら
「ストック+流動+堆積」の総和が初期ストック総量と機械精度で一致
します(系外流出・ダム捕捉があればその分が引かれます)。

## 併用関係・制約

- ENC 格子のみ。地形時間の加速(morfac ≠ 1)とは併用できません
  (流木はイベント量のため)。
- [土砂・地形変化](geomorph.md)との併用は自由です(f_debris との
  同時有効化で土石流+流木の混合流れ)。geomorph なしでも水理的
  流失だけで動作します(侵食連行は地形が動かないため発火しません)。
- **ダムの捕捉帯**に入った流動流木はダムに捕捉されます(放流には
  流木は含まれません)。**カルバート・ポンプ**は水だけを送るため、
  流木は施設の上流に滞留します(= 捕捉の上限側評価。
  [砂防施設の表し方](geomorph.md)と同じ流儀で「施設あり/なし」の
  2ケース比較に使えます)。
- 中断・再開(save/restore)では流木の全台帳が `driftwood.dat` に
  保存され、分割実行しても厳密に連続します。

## 例題: 高潮による貯木場からの材木流入(伊勢湾台風型)

海岸の貯木場に浮かぶ材木が高潮で流出し、防潮壁を越えた氾濫流に
乗って市街地へ流入・堆積する現象の理想化実験を
[examples/timberyard](../../examples/timberyard/) に収録しています
(`python3 make_terrain.py && ./encflow param.txt` で実行。約1分)。
組み方の要点:

1. **貯木場・港湾の水面は海域マスクにしない**。海域セルには材木を
   置けず流木の移流も働かないため、浸水・材木輸送を解く範囲はすべて
   通常セル+初期水位(`f_htype=2`)で表し、海域マスク+潮位強制
   (`fn_tide`)は沖側の境界列だけにします(津波土砂と同じ流儀 —
   [土砂・地形変化](geomorph.md)「海域マスクと土砂の行き先」)。
2. **材木ストックは貯木場のセルにだけ** `fn_dwstock` で与えます
   (例題は 0.5 m³/m² × 200 m × 600 m = 6 万 m³)。
3. **発生は水理的流失を「高潮による係留切れ・浮上」として使います**:
   `dw_hrec` を貯木場の平常水深より高く(例題は平常 2.0 m に対し
   3.0 m)設定すると、高潮で水位が上がったときに初めて流失が始まり、
   発生タイミングが高潮と同期します。`dw_vrec = 0`(浮けば流失)、
   `dw_wrec` は高潮の継続時間内に全量が流失するレートにします。
   侵食連行(dw_droot)や地形変化モジュールは不要です。
4. **防潮壁・開口部**は地形で表します(例題は天端 +1.5 m の壁と
   低所 +0.5 m の開口)。流入が開口部に集中し、材木の堆積が
   その背後の市街地に集中する様子が Wd 出力に現れます。
5. 市街地の**建物は空隙率 `fn_gv`** で表します(例題は 0.6)。

読み方の注意: **Wd9999 は期間最大の到達量(流動+堆積)の包絡値**
です(通過しただけのセルにも値が残る = ハザードマップ用)。最終的な
堆積分布・質量勘定には最終フレーム(Wd9998)を使い、材積への換算は
柱状量 × gv × セル面積です(例題では 6 万 m³ のうち約 7 割が市街地に
堆積し、総和は初期ストックと機械精度で一致します)。

**材木の家屋への衝突力**はモデル内部では計算しません(個別衝突は
適用限界)が、衝突力式の入力はすべて出力から得られます: 実務の標準
(国総研資料 905 §4.3)は流木の衝撃力を「礫の衝撃力算定式を準用し、
速度は流れの流速・径は流木の最大直径」として算出する後処理方式なので、
ENCflow の最大流速 V9999(または流速フレーム)と代表材の諸元を
その式(あるいは FEMA P-646 の流木衝突式)に与えれば、指針整合の
衝突力マップを作れます。材木がどの家屋群に届くかは Wd9999・Hd で
判定し、水そのものの流体力は F9999(= u²h)で評価します。

## モデル化していないもの

個別の流木の軌跡・向き・回転、橋脚やスリット堰堤の部材間隔と流木長の
幾何的な引っ掛かり(閉塞)、流木の衝突力は対象外です(ラスタ表現の
方針による明示的な適用限界)。閉塞の**効果**を検討する場合は、開口を
狭めた地形・カルバートをシナリオとして与えた2ケース比較で近似して
ください。実装仕様は developer.md §50。典拠: 喫水・移動限界は
Braudrick, C. A. and Grant, G. E. (2000), When do logs move in
rivers?, Water Resources Research 36(2), 571-583。実務値・発生機構は
国総研資料 第904号「砂防基本計画策定指針(土石流・流木対策編)解説」
・第905号「土石流・流木対策設計技術指針 解説」(2016)。
