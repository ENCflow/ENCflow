# 土壌雨量指数(fn_swi)

[ユーザーガイド目次へ](../users_guide.md)

土砂災害警戒の実務で使われる**土壌雨量指数**(SWI)をセル別に
計算します。気象庁が運用する石原・小葉竹(1979)の直列3段タンク
モデルを、**全国一律の標準定数のまま**(変更不可)実装したものです。
降った雨がタンクを満たし、時間とともに流出・浸透で抜けていく様子を
指数化した「先行降雨込みの土中水分量の目安」で、値そのもの(mm)が
警戒判定の基準(CL 線)と比較される量です。

## 有効化と設定

`&list_sysparam` で `fn_swi` を指定します。設定はほぼありません
(タンク定数は公式定義を守るため固定です):

```
&list_swi
  f_swi = 1                 ! 0 で一時無効化
  swi0 = 0.0, 0.0, 0.0      ! 各タンクの初期貯留 (mm)(先行降雨の効果)
/
```

## 計算の約束(専用計算)

指数を公式定義(入力 = 地上雨量そのもの)どおりに保つため、
**土壌雨量指数の計算は専用ランで行います**:

- 併用できるのは**定率遮断**(&list_intercept の f_icmodel=1)だけ
  です。地下水・蒸発散・積雪・氷河・地形変化・水質など他の
  プロセスモジュールを有効にすると停止します(雨量を書き換える・
  指数と物理量の混同を招くため)。
- `dt` は **600 s 以下**(気象庁の計算間隔 10 分)。超えると停止します。
- 格子は任意です(指数はセル面積に依存しません)が、`dx,dy` が
  1 km でない場合は「公式の 1km プロダクトと同条件ではない」旨の
  警告が出ます。1 km 解析雨量を 1 km 格子に与えれば公式と同じ
  土俵になります。

物理モデル(地下水の飽和度など)との比較をしたい場合は、同じ降雨で
別ランを回してください。

## 出力

有効化すると自動で出力されます(スイッチはありません):

| ファイル | 内容 |
|---|---|
| Swi0001… | 土壌雨量指数 SWI (mm) の分布(dt_file 間隔) |
| Swi9999 | **期間最大の SWI**(警戒判定に使う統計。危険度マップ) |
| Swit9999 | 最大の発生時刻 (min) |

中断・再開(save/restore)ではタンクの状態が `swi.dat` に保存され、
長雨の途中で分割しても指数は厳密に連続します。

## 注意

- 降雨時系列(prtype=1)のテーブルは**線形補間**です。矩形波の
  降雨を与えるときは終端を二重に打ってください(例:
  `(0,30),(180,30),(181,0)`)。
- モデル・定数の典拠: 石原・小葉竹(1979)、岡田ほか(2001,
  測候時報 68)、気象庁「土壌雨量指数」解説。実装仕様は
  developer.md §49。
