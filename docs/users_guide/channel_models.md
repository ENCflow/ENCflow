# 河道の解説(河道の補足)

[河道の章へ](channel.md) | [ユーザーガイド目次へ](../users_guide.md)

[河道の章](channel.md)の各仕組み — 堤防(仮想壁面)、サブグリッド河道幅、
断面形 σ、破堤 — の定式と設計の理由、既定値の根拠をまとめます。
堰越流の式は[構造物と境界の水理則の解説](hydraulics.md) §1 にあります。
実装は `src/m_swflow_enc_channel.f90` と `src/m_swflow_enc.f90`(断面形・
通過幅)で、設計の経緯は developer.md §17・§18・§26 にあります。

## 1. 堤防(仮想壁面)

河道セルと堤内地セルの間の全エッジ(対角を含む)に、セルを太らせない
仮想の壁を立てます。海域マスク(fn_sw)の海セルとの間のエッジには壁を
立てません(河口は自動開口。[河道](channel.md))。天端は河道側セルの値から次の基準で決めます。

| f_bank_datum | 天端 $`z_c`$ |
|---|---|
| 0 | 河床(掘り込み後)+ 高さ |
| 1(既定) | 堤内地セル標高 + 高さ。隣接する堤内地の平均(f_bank_aggr = 0)、最小(1)、最大(2)で集約 |
| 2 | 絶対標高 |

エッジごとの実効天端は、堤内地側の地盤高 $`z_l`$ と河道側の河床高 $`z_b`$ を
下回りません。

```math
z_{c}^{\mathrm{eff}} = \max\!\left(z_c,\ z_l,\ z_b\right)
```

天端がそれより低いエッジでは地盤そのものが段差として通常の浅水計算に
入り、堤防としては働きません(V 字谷の自然河岸や、天端を絶対標高で
与えたときに効きます。`bank0 = 0` は堤防なしと同じではなく、既定の
f_bank_datum = 1・f_bank_aggr = 0 では平均より低い堤内地セルへのエッジに
壁が立ちます。堤防なしは bank0 を書かないことで指定します)。

天端を超えた分は本間公式の堰越流([水理則](hydraulics.md) §1)で堤内地へ
あふれます。堤防が深く水没した状態(堤内地の湛水が天端を大きく超える、
閉じた窪地の池など)では、潜り越流の流量に「1 ステップで両側の水位差の
半分までしか縮めない」上限を掛けます。慣性のない堰公式が深い水で
1 ステップおきに流向を反転させる振動を防ぐためで、天端近くの通常の越流では
効きません。

**開口補正(f_bank_opening = 1)。** 堤防壁で塞がれた開口の通過幅を、同じ
横断面の開いた河道—河道エッジへ振り替えます。軸方向の 1 セル河道では
塞がれた斜め開口を法線エッジへ、斜め方向(8 連結)の 1 セル河道では塞がれた
軸開口を斜めエッジへ振り替え、どちらも通過幅がセルの自然幅(軸: セル幅、
斜め: セル面積 / 対角路長 = 0.707 セル幅)になります。幅 1 セルの河道の
過小通水を向きによらず補正するもので、0 は旧挙動との比較用です
([test/bendloss](../../test/bendloss/) の直線・対角河道で Manning 等流解と
比較)。

**水理モード(f_bank_mode)。** 0 は越流のみ(双方向とも天端まで不透過)、
1 は樋門(逆止弁。天端以下では堤内 → 河道のみ通す簡便法。河道水位が天端を
超えれば 0 と同じ堰越流)、2 は強制排水(互換・実験用)
です。実務の排水機場・樋門は[構造物](structure.md)のポンプ・カルバートを
使います。

## 2. サブグリッド河道幅

幅 $`W`$ を与えたセルでは、平面積率

```math
f_w = \min\!\left(\frac{W}{\Delta},\ 1\right)
```

を貯留(セルの水量 = $`f_w\,\Delta^2 h`$)と通水のキャップに使い、水深・水位・
流量はセル内の河道部分だけを表します。セル内の堤内地は存在しないものと
して扱い、河道と堤内地の水のやり取りは隣接する堤内地セルとの間で直接
行います。1 セルに斜面と河道の 2 つの水位を持つ方式(RRI など)とは
異なる設計で、セル内の堤内地の貯留・浸水を表現できない代わりに、川幅が
セルサイズを跨いでもモデルの切替が存在せず、細流から大河まで単一の定式で
解けることを優先しています(developer.md §18)。氾濫域はセル単位で
解像されるので、河道セル自身の中の氾濫まで解きたい区間はセルサイズを
川幅より細かくして解像河道に移行します。

- **自然河岸と開口の動的補正。** 堤防がなければ河道と斜面の間の水の
  やり取りは通常の浅水計算のままで、塞がれた斜め開口の通水能は
  f_opening_dynamic(既定で有効。[ENC 格子の解説](encgrid.md))が動的に
  補正します。河道内流速の正規化(通水率)も同じ塞がり率で毎ステップ
  求めるので、乾いて高い斜面に接するセルでは壁付きと同じ流速になります。
  幅セルが絡むエッジの振り替えは、既定の 2(全エッジ)でも河道セル同士の
  エッジに限ります(幅セルと斜面の間は幅モデルが担うため。二重補正は発散の
  元。developer.md §68.38)。
  壁なしで f_opening_dynamic = 0 にすると幅がセルより狭い河道の流速が
  過小になるので、併用しないでください。旧版の「高さ 0 堤防の自動有効化」は、
  斜面が天端より高い自然河岸で堰越流が落差流になり発散するため廃止しました。
- **辺境界。** 河道が計算領域の外縁に接する場合、自由流出・長波放射の
  境界面は河道幅相当に縮めて流します(幅の狭い河道の貯留を境界面が
  抜き切ることはありません)。区間流入は規定流量どおりです。
- **幅の値の不感性。** 幅は常に $`\min(W/\Delta, 1)`$ の形でだけ使われる
  ため、セルサイズを超えた値はどれでも厳密に同じ結果になります。厳密には
  河道の上流端・下流端のセルだけ平面積率の飽和にセルサイズの 2 倍が必要
  なので、解像扱いにしたい区間には 2 × セルサイズ以上(例: 9999)を
  一括で与えます。断面形 σ と併用しても同じです(σ は矩形換算水深を
  通して流束と水位に効き、幅は貯留の平面積率と通水キャップにだけ使う。
  通水のキャップ q = min(W/面長, 1) は河道—河道エッジ、開いた辺境界の面、
  および海域マスク(fn_sw)の海セルとの面(幅河道の河口 = 同じ幅の河道が海へ
  続く)に掛かり、河道—堤内地のエッジには掛からない(developer.md §18)。
  2026-10-04 改定。それ以前は有効幅を「幅 × σ(h)」としていたため幅の
  実値が低水時に効きました)。
- **移流項。** `f_channel_advection = 0` で河道セルを含むエッジの移流項を
  落とせます(強い幅不均質下での安定化オプション。既定 1)。堤防
  (bank0 / fn_bank)が有効なときだけ働き、壁なしの幅モードでは効きません
  (壁なしで働かせる試験では発散したため据え置き。developer.md §18)。
- **精度の限界。** 河道はラスタ(河道マスク+幅)で表現され、河道セル
  同士の接続は「隣接していればつながる」暗黙の規則で決まります。1 次元
  河道網モデルと異なり、合流・分派の対応や、近接・並行する河道の分離を
  厳密には指定できないため、意図しない接続や分断が生じ得ます。河道網の
  位相が結果を支配する用途ではこれが精度の限界で、疑わしい箇所はセル
  サイズを細かくして解像します。1 セルの中で蛇行する川に使うと、河道長の
  過小評価により流量・流速が過大になります。

## 3. 断面形(σ 則)

通水率を $`\sigma(h) = (h/D)^m`$ とする単パラメータの断面形です。矩形換算
水深 $`v_h`$(断面積 ÷ 幅)は

```math
v_h = \int_0^h \sigma\,dh' =
\begin{cases}
\dfrac{D}{m+1}\left(\dfrac{h}{D}\right)^{m+1} & (h < D)\\[8pt]
h - \dfrac{m}{m+1}\,D & (h \ge D)
\end{cases}
```

で、流束は流速 × 断面積(幅 × $`v_h`$)、水位は $`v_h`$ から $`h`$ への逆変換で
求めます。$`m = 0`$ は矩形、0.5 は放物線的、1 は三角形的な断面に相当し、
$`h \ge D`$ では矩形力学に退化します。

**遷移深さ D。** 直接は指定しません。堤防が有効なセルでは「天端 − 河床」
(f_bank_datum = 1 なら bank0 + 堤内地標高 − 河床。河道セルと堤内地の地盤が
同じ高さなら bank0 + depth_rw)、堤防のないセルでは掘り込み深さ depth_rw が
そのまま D です。河床が動く計算([地形変化](geomorph.md)の掃流砂など)では、
天端(堤防の天端、または初期河床 + depth_rw)を固定して河床との差で
毎ステップ追従します。河床低下で断面が深く(満杯容量が増え)、堆積で
浅くなり、天端まで埋まると矩形に戻ります。D が変わるとき貯留体積は保たれ、
水深だけが読み替わります。

**幅が不正確な場合。** σ 有効時、幅は貯留の平面積率と通水キャップにだけ
効きます。実幅より過大な幅(セルサイズや一律の便宜値)を与えても、低水時の
流れは「広い河床の中を細い澪筋が多数に分かれて流れる」複列断面と等価な
解釈が成り立ち、高水時($`h \ge D`$)は矩形力学に退化して実幅指定との差は
ほぼ消えます。幅データの精度は、低水部の水位・流速の再現を重視する区間
から段階的に上げれば十分です。

形状指数 m は領域一様の 1 値です。上流の渓流と下流の大河で断面形が異なる
のは自然なので、必要が生じれば分布ファイルによるセル別指定への拡張を
検討します(将来拡張の候補)。

## 4. 破堤

サイト(隣接する河道セルと堤内地セルの対)の境界エッジ 1 本の天端を、
残存割合 $`r(t)`$(br_series の線形補間)で

```math
z_c^{\mathrm{eff}}(t) = z_l + r(t)\,\bigl(z_c - z_l\bigr)
```

と下げます($`z_l`$: 堤内地盤高)。複数セル区間の決壊は複数サイトで
指定し、決壊幅はエッジ単位です。壁エッジの通水は本間公式です。

**斜めエッジの連動(f_br_diag)。** f_br_diag = 0 ではサイトにしたエッジ
以外(斜めリンクを含む)は壁のまま残ります。法線エッジの通過幅シェアは
$`1 - p_{\mathrm{diag}} = 0.414`$ で、計測上の実効幅もサイト 1 本あたり
0.38 dx です。f_br_diag = 1 では、斜めエッジ (c, l) の実効天端を、河道セル
が c で堤内地セルが l の 4 近傍にあるサイト、または堤内地セルが l で河道
セルが c の 4 近傍にあるサイトの実効天端の最小値まで下げます(法線サイトの
両側の斜め。破堤口の両端の外側へ向かう斜めも含む)。これで破堤セル 1 つ
あたりの通過幅が法線 0.414 + 斜め 2 × 0.293 = 1 セル幅になります。
examples/levee_breach(セル幅 10 m、越流水深 1.7〜1.9 m)の計測:

| 破堤幅(セル) | 解像堤防 Q (m³/s) | f_br_diag = 0 Q / 解像比 | f_br_diag = 1 Q / 解像比 |
|---:|---:|---:|---:|
| 1 | 40 | 15 / 0.39 | 60 / 1.51 |
| 2 | 74 | 29 / 0.40 | 81 / 1.10 |
| 3 | 104 | 43 / 0.41 | 100 / 0.95 |
| 5 | 154 | 68 / 0.44 | 131 / 0.85 |

広頂堰の目安 $`Q = 1.7\,B\,H^{3/2}`$(B = セル数 × dx、H = 河川水位 −
堤底)は解像堤防の値に合い(幅 1 セルで 39 対 40、5 セルで 169 対 154)、
f_br_diag = 1 は幅 2〜3 セルでそれに最も近づきます。幅 1 セルで 1.5 倍に
なるのは両端の斜め 2 本(0.59 セル幅)が加わるためで、広いほど堤内地側の
水位上昇で堰公式が下回ります。実効天端が両側地盤以下まで下がった
エッジの壁を解除して通常の浅水計算に戻す案は、3 m の段差を 1 本の
エッジで解くと限界流の制御がなく噴流になり解像堤防の 1.3〜3 倍と過大に
なるため採りませんでした。DEM の標高で
表した解像堤防の破堤は仮想壁面の外なので、[規定底面運動](bedmotion.md) §5
(破堤口のセルの地盤高を時刻歴で下げる)で扱います。

## 5. パラメータと既定値の根拠

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| f_bank_datum | 1 | 堤防高の基準 | **方式** 堤内地標高基準は GIS で堤防高分布を作るときに自然で、天端が地盤を下回る矛盾が起きにくい |
| f_bank_aggr | 0 | datum = 1 の天端の集約 | **方式** 隣接堤内地の平均は DEM のノイズを抑える。越流開始に忠実なら 1、安全側なら 2 |
| f_bank_mode | 0 | 水理モード | **方式** 既定は越流のみ。1 の逆止弁は簡便法で、実務は[構造物](structure.md) |
| f_bank_opening | 1 | 開口補正 | **検証ケース** [test/bendloss](../../test/bendloss/) で幅 1 セルの直線・対角河道が Manning 等流解に乗る(§1) |
| p_sect_m | 0 | 断面の形状指数 | **互換** 既定は矩形(従来互換)。推奨 0.3〜1 は経験値(章の表) |
| f_channel_advection | 1 | 河道セルを含むエッジの移流項(堤防有効時のみ働く) | **方式** 既定は通常。0 は強い幅不均質下の安定化用 |
| rn0_rw | — | 河道粗度 | **慣用値** Manning の n(コンクリート 0.015〜0.02、砂床 0.025〜0.035、礫床 0.035〜0.05、植生のある高水敷 0.05〜0.1。Chow の表[^chow59]と河川砂防技術基準も同程度) |

**既定値を見直すときの手がかり**

- 河道粗度は、河川管理者の不等流計算に使われた n(河川整備計画・
  浸水想定の資料)があればそれを優先し、なければ河床材料と植生から
  Chow の表[^chow59]で引きます。
- 断面形状指数 p_sect_m は、横断測量の水深—水面幅の関係を
  $`B \propto h^{m}`$ で当てはめて決められます(矩形なら 0、三角形なら 1)。
