# 規定底面運動(&list_bedmotion)

[ユーザーガイド目次へ](../users_guide.md)

地盤変位の**時刻歴**を与えて地盤高 z を強制的に動かします。断層
パラメータから求めた海底変位で津波を発生させる(発生 → 伝播 → 遡上 →
氾濫を 1 ランで追う)用途が主です。水柱 h は変えずに z を動かすので、
水面 e = z + h が地盤と一緒に持ち上がります(地形変化モジュールと同じ
契約)。設計の全文は [docs/bedmotion_plan.md](../bedmotion_plan.md)、
実装記録は developer.md §70。

## 有効化

メインパラメータで `fn_bedmotion = "-"`(同じファイルから読む)または
設定ファイル名を指定し、`&list_bedmotion` を書きます。未指定なら
メモリ・CPU の追加はありません。

```
&list_bedmotion
  fn_bmlist = 'bm/bmlist.txt'   ! スナップショット表(dir_data 相対)
/
```

| 項目 | 既定 | 意味 |
|---|---|---|
| f_bedmotion | 1 | 0 でファイルを残したまま一時無効化 |
| fn_bmlist | (必須) | スナップショット表のファイル名(dir_data 相対) |
| f_bminterp | 1 | スナップショット間の時間補間。1: 線形、0: 階段(直前のスナップショットを保持) |
| bm_tscale | 1.0 | 表の時刻の単位(秒)。60 で分、3600 で時 |

## スナップショット表と変位ファイル

表は 1 行に「時刻 ファイル名」(空行と `#`・`!` で始まる行は無視)。
時刻は t0 からの相対値(昇順)、ファイル名は dir_data 相対です。

```
# time(s)  file
  0.0      bm/disp_0000.txt
 10.0      bm/disp_0010.txt
 60.0      bm/disp_0060.txt
```

各ファイルは**累積変位** d [m](計算開始時の地形からの変位。増分では
ない)で、地盤高 z と同じ形式・同じ行順(テキスト行列 / bil / GeoTIFF。
f_input_mode に従う)です。表の最初の時刻より前は先頭の値、最後より後は
末尾の値が保たれます。1 行だけの表(t = 0 に最終変位)は「開始時に瞬時に
変位」= 初期水面変位の与え方と同じになります。

広域の計算では、行の末尾に 4 つの整数 `i1 j1 ni nj` を付けると、その
ファイルは全域格子の列 i1〜i1+ni−1・行 j1〜j1+nj−1 の**窓だけ**を持つ
ni × nj の行列として読まれ、窓の外は変位 0 とみなされます(utils/fault2disp
の `f_window = 1` がこの形で書き出します)。本体は変位の適用を全窓の
和集合に限定するので、ファイルの大きさも 1 ステップの処理量も窓の
大きさで決まります。

```
# time(s)  file               i1  j1  ni  nj
  0.0      bm/disp_0000.txt   90  40  80  70
 30.0      bm/disp_0010.txt   90  40  80  70
```

## 動作の契約

- 各ステップの頭で、そのステップ末尾の時刻の変位を補間し、前回適用した
  変位との**差分**を陸セル(x > 0、海域マスク外)の z に加えます。h は
  変えず e = z + h を回復します。運動量は触りません。土層厚 sd は変えません
  (岩盤面 z − sd が変位します)。
- 増分で与えるので、土砂・地形変化(f_bedslide を含む)・溶岩流が同じ
  ランで z を動かしていても衝突しません(地震で誘発される海底地滑りを
  同じランに置けます)。
- 海域マスク(sw > 0)のセルは動きません。津波計算は海域マスクを使わず、
  初期水位(f_htype=2)で水域を表す「解く海」の型で行ってください
  (examples/landslide_tsunami と同じ)。
- 時間補間が線形のとき底面速度はスナップショット間で一定です。非静水圧の
  加速度項(f_nh_bottom)を使うときは、スナップショット境界で速度の跳びが
  加速度のパルスとして入ります。滑らかな時刻歴が必要なら前処理で
  スナップショットを細かく出してください(test/nhbottom は毎ステップ)。
- リスタート: 私有の状態は保存しません。再開時は再開時刻の変位を表から
  求めて「適用済み」とし、中断なしの計算と同じ増分列になります。
- ライブラリ API の set_value('z') は fn_bedmotion 有効時に拒否されます
  (z の生産者は一人)。
- 出力: 地盤高 Z(f_out_z)に変位後の地形が出ます。終了時に適用した変位の
  最大・最小を表示します。

## 非静水圧との関係

静水圧計算では底面の持ち上げがそのまま水面に写ります(長波長の海溝型
地震ではこれで十分)。震源の幅が水深と同程度の短い変位(分岐断層、深海の
狭い滑り、海底地滑り)では、水柱の慣性による短波の減衰(Kajiura
フィルタ)を [非静水圧補正](swflow.md) の f_nh_bottom=1 が与えます
(1 層近似 1/(1 + βk²)²。developer.md §69.10)。

## 検証

test/nhbottom 構成 3: 水深 10 m の水路で |x − x_c| < 20 m を 1 s で 0.2 m
持ち上げる Hammack 型の隆起を、毎ステップのスナップショット表で与え、
ライブラリ API で同じ運動を与えたドライバの結果と一致します(Log の
全有効桁の体積列の最終桁を除いて同一)。再開(0.5 s で save → restore)
も中断なしの計算と一致(静水圧。非静水圧の f_nh_bottom では加速度項の
1 ステップ分だけ異なります)、海底地滑り(f_bedslide)との同居では
Σ(z − z0) = Σ d(底層の内部移転は総和 0)が出力精度の範囲で成り立ちます。

## 前処理(断層パラメータ → 変位): utils/fault2disp

断層パラメータ(上端中心の位置・上端深さ・走向・傾斜・すべり角・長さ・
幅・すべり量・破壊開始時刻・立ち上がり時間)から Okada (1985) の式で
変位場とスナップショット表を作るユーティリティです
([utils/fault2disp/README.md](../../utils/fault2disp/README.md))。
複数セグメントの重ね合わせ、セグメントごとの時間差と立ち上がり関数
(線形 / 半正弦)、水平変位の寄与 u_h·∇z(Tanioka & Satake 1996。地盤高
ファイルを与えたとき)、広域向けの窓付き出力(f_window)に対応します。
断層位置は格子と同じ投影座標か、経緯度(f_lonlat=1。横メルカトル投影 =
UTM・平面直角座標系。走向は子午線収差で格子北基準に補正)で与えます。
地理参照された地盤高(bil+hdr / GeoTIFF)を fn_z に与えると、格子の原点・
セル寸法・セル数をファイルから取るので、断層位置はその投影座標系の
絶対座標で書けます(平面直角座標系の X・Y の並びは f_jpr=1)。

```
cd utils/fault2disp && make && make check   # Okada (1985) Table 2 の検算
./fault2disp fault2disp.txt                  # bm/disp_NNNN.txt と bm/bmlist.txt
```

使用例は examples/tsunami_fault(理想化した逆断層: 走向 N-S、傾斜 15°、
60 km × 30 km、すべり 5 m、30 s 立ち上がり。静水圧 / 瞬時変位 / 非静水圧 +
加速度項の比較)。
