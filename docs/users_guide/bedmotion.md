# 規定底面運動(&list_bedmotion)

[ユーザーガイド目次へ](../users_guide.md)

地盤変位の**時刻歴**を与えて地盤高 z を強制的に動かします。断層
パラメータから求めた海底変位で津波を発生させ、発生 → 伝播 → 遡上 →
氾濫を 1 ランで追う用途が主です。陸のセルも同じ変位場で動くので、
沿岸の地震性隆起・沈降(沈降した低地の浸水、隆起域から広がる波)も
同じ計算に入ります。水柱 h は変えずに z を動かすので、水面 e = z + h が
地盤と一緒に持ち上がります(地形変化モジュールと同じ契約)。設計の
全文は [docs/bedmotion_plan.md](../bedmotion_plan.md)、実装記録は
developer.md §70、断層パラメータからの前処理は
[utils/fault2disp/README.md](../../utils/fault2disp/README.md)。

## 1. 最小の設定例

逆断層 1 枚の津波を、理想化した海域(地理参照なし)で発生させる
手順です。3 つのファイルを用意します。

**(1) 断層パラメータ → 変位の時刻歴**(utils/fault2disp)

```
&list_fault2disp
  nx = 200                  ! 格子(ENCflow の list_geoinfo と同じ)
  ny = 150
  dx = 1000.0
  dy = 1000.0
  dir_out = 'bm'            ! bm/disp_0000.txt … と bm/bmlist.txt を書く
  nout = 10
  nseg = 1
  x_top(1) = 120000.0       ! 上端中心(格子の左下隅から東 120 km・北 75 km)
  y_top(1) = 75000.0
  d_top(1) = 5000.0         ! 上端深さ 5 km
  strike(1) = 0.0           ! 走向 N。断層は走向の右手(東)へ下がる
  dip(1) = 15.0
  rake(1) = 90.0            ! 逆断層
  flength(1) = 60000.0
  fwidth(1) = 30000.0
  slip(1) = 5.0
  t_r(1) = 0.0              ! 破壊開始 (s)
  t_rise(1) = 30.0          ! 立ち上がり 30 s
/
```

```
cd utils/fault2disp && make          # 初回のみ(src が未ビルドなら先に src で make)
cd <ケースの dir_data> && <path>/fault2disp fault2disp.txt
```

**(2) 本体のパラメータ**(抜粋。津波計算に固有の設定だけ示します)

```
&list_sysparam
  fn_bedmotion = '-'        ! 同じファイルの &list_bedmotion を読む
  f_out_z = 1               ! 変位後の地盤高も出力
  ...
/
&list_initial
  f_htype = 2               ! 初期水位固定(静水面 e0 = 0。z < 0 が海)
  e0 = 0.0
/
&list_bound_edge
  f_bc_w = 0                ! 陸側は壁
  f_bc_e = 2                ! 海側の辺は長波放射(反射を返さない)
  f_bc_n = 2
  f_bc_s = 2
/
&list_bedmotion
  fn_bmlist = 'bm/bmlist.txt'   ! (1) が書いた表(dir_data 相対)
/
```

**(3) 実行**

通常どおり `./encflow param.txt`(MPI 版も同じ)。開始時にスナップ
ショットの枚数と時刻範囲、終了時に適用した変位の最大・最小と読んだ
枚数・適用したステップ数が表示されます。完全な例は [examples/tsunami_fault](../../examples/tsunami_fault/README.md)
(この最小例そのもの)と [examples/tsunami_coast](../../examples/tsunami_coast/README.md)
(沿岸の沈降・隆起と沖の津波の時間差)。

## 2. 入力の約束(スナップショット表と変位ファイル)

**表**は 1 行に「時刻 ファイル名」(空行と `#`・`!` で始まる行は無視)。
時刻は計算開始 t0 からの相対値で昇順、ファイル名は dir_data 相対です。

```
# time(s)  file
  0.0      bm/disp_0000.txt
 10.0      bm/disp_0010.txt
 60.0      bm/disp_0060.txt
```

**変位ファイル**は各時刻の**累積変位** d [m](計算開始時の地形からの
変位。前の時刻からの増分ではない)で、地盤高 z と同じ形式・同じ行順
(テキスト行列 / bil / GeoTIFF。f_input_mode に従う。行 1 が北端)です。
正が隆起、負が沈降。

- 表の最初の時刻より前は先頭の値、最後の時刻より後は末尾の値が保たれ
  ます。t = 0 に変位ゼロの行を置くのが普通です(fault2disp はそう書く)。
- スナップショットの間は線形補間(f_bminterp=1。既定)または階段
  (f_bminterp=0。直前の値を保持)。
- 時刻の単位は秒。分や時で書いた表は bm_tscale(60、3600)で換算します。
- 本体はスナップショットを 2 枚(前後)だけ保持し、時刻が進むたびに
  次の 1 枚を読みます。表が長くてもメモリは増えません。

## 3. 変位の与え方(3 つのパターン)

### パターン A: 断層パラメータから(utils/fault2disp)

地震の津波はこのパターンです。断層の位置・走向・傾斜・すべり角・長さ・
幅・すべり量・破壊開始時刻・立ち上がり時間から Okada (1985) の式で
変位場を作り、表まで書き出します。複数セグメント(破壊の時間差つき)、
水平変位の寄与 u_h·∇z(Tanioka & Satake 1996。地盤高を与えたとき)に
対応します。座標の与え方は 3 通りあり、どれも fault2disp 側で吸収する
ので本体の設定は変わりません(詳細は fault2disp README §3)。

| 座標の持ち方 | fault2disp の指定 |
|---|---|
| 理想化実験(地理参照なし) | x_top, y_top を格子の左下隅からの距離 (m) で(§1 の例) |
| 投影座標系で地理参照がある解析 | bil+hdr / GeoTIFF の地盤高を fn_z に与える → 格子と原点をファイルから取り、x_top, y_top はその座標系の絶対座標。平面直角座標系の並び(X 北距, Y 東距)は f_jpr=1 |
| 経緯度 | f_lonlat=1 で lon_top, lat_top と格子の投影(proj_lon0 等。UTM・平面直角座標系)を与える。走向は子午線収差で補正 |

### パターン B: 自分で作った変位場(測地観測・断層反転解・別モデル)

断層モデルを経由せず、地盤変位のラスタを直接持っているときは、§2 の
約束に合わせて自分で表を書きます。z と同じ格子・同じ形式に前処理で
揃え(ENCflow は内挿しません)、各時刻の累積変位にします。1 時刻しか
ない変位場(最終変位だけ)でも §3-C の形で使えます。

### パターン C: 瞬時変位(従来の初期水位方式と同じ)

破壊過程を省いて最終変位を t = 0 に瞬時に与えるには、表を 1 行にします。

```
# instantaneous: final displacement at t = 0
0.0  bm/disp_0010.txt
```

これは初期水面変位を与える従来法と同じ結果になります(陸の変位も
含めて地盤が動く点だけが違う)。時刻歴ありとの差は震源近傍の到達時刻
と波高(examples/tsunami_fault では最高水位 2〜3%、tsunami_coast の
湾口・棚では +24〜40%)。

### 広域の計算: 窓付きの変位ファイル

全域格子が大きく変位域が一部なら、行の末尾に 4 つの整数 `i1 j1 ni nj`
を付けます。そのファイルは全域の列 i1〜i1+ni−1・行 j1〜j1+nj−1 の
**窓だけ**を持つ ni × nj の行列として読まれ、窓の外は変位 0 です。
本体は変位の適用を全窓の和集合に限定するので、ファイルの大きさも
1 ステップの処理量も窓で決まります(fault2disp の f_window=1 が
この形で書き出します。切り捨てる変位の閾値は d_min)。

```
# time(s)  file               i1  j1  ni  nj
  0.0      bm/disp_0000.txt   90  40  80  70
 30.0      bm/disp_0010.txt   90  40  80  70
```

## 4. 水域と境界の与え方

- 津波計算は**海域マスクを使わず**、初期水位 f_htype=2(静水面 e0。
  z < e0 のセルが海)で水域を表す「解く海」の型で行います
  (examples/landslide_tsunami と同じ)。海域マスク(sw > 0)のセルは
  水位を規定される側なので、変位を与えても動きません。
- 外洋に接する辺は長波放射(f_bc_* = 2)にして、出て行く波が反射して
  戻らないようにします。陸に接する辺は壁(0)。
- 陸のセル(x > 0)はすべて動きます。沈降した低地は水面 e0 より低く
  なれば海から浸水し、隆起した海底は干出します。乾湿の扱いは浅水流
  計算の通常どおりです。

## 5. 時間の扱いと静水圧・非静水圧

- 各ステップの頭で、そのステップ末尾の時刻の変位を補間し、前回適用した
  変位との**差分**を z に加えます。線形補間のとき底面速度はスナップ
  ショット間で一定で、境界で速度が跳びます。
- 静水圧計算では底面の持ち上げがそのまま水面に写ります。震源の幅が
  水深に比べて十分広い海溝型地震はこれで十分です。
- 震源の幅が水深と同程度の短い変位(分岐断層、深海の狭い滑り、海底
  地滑り)では、水柱の慣性で短波が減衰します(Kajiura フィルタ)。
  [非静水圧補正](swflow.md)の f_nonhydrostatic=1 と f_nh_bottom=1 が
  これを 1 層近似 1/(1 + βk²)² で与えます(developer.md §69.10)。
  このとき速度の跳びが加速度のパルスとして入るので、スナップショットを
  細かく(fault2disp の nout を増やす。test/nhbottom は毎ステップ)
  出してください。examples/tsunami_fault では非静水圧で沿岸の最高水位が
  −24%(分散)、加速度項の寄与はさらに −2% です。

## 6. パラメータ一覧

メインパラメータで `fn_bedmotion = "-"`(同じファイルから読む)または
設定ファイル名を指定し、`&list_bedmotion` を書きます。未指定なら
メモリ・CPU の追加はありません。

| 項目 | 既定 | 意味 |
|---|---|---|
| f_bedmotion | 1 | 0 でファイルを残したまま一時無効化 |
| fn_bmlist | (必須) | スナップショット表のファイル名(dir_data 相対) |
| f_bminterp | 1 | スナップショット間の時間補間。1: 線形、0: 階段(直前のスナップショットを保持) |
| bm_tscale | 1.0 | 表の時刻の単位(秒)。60 で分、3600 で時 |

変位ファイルの形式は地盤高と同じ f_input_mode(&list_geoinfo)に従います。

## 7. 動作の契約と併用関係

- 陸セル(x > 0、海域マスク外)の z に増分を加え、h は変えず e = z + h を
  回復します。運動量は触りません。土層厚 sd は変えません(岩盤面
  z − sd が変位します)。
- 増分で与えるので、土砂・地形変化(f_bedslide を含む)・溶岩流が同じ
  ランで z を動かしていても衝突しません。地震で誘発される海底地滑り
  (f_bedslide)を同じランに置けます。
- リスタート: 私有の状態は保存しません。再開時は再開時刻の変位を表から
  求めて「適用済み」とし、中断なしの計算と同じ増分列になります。
- ライブラリ API の set_value('z') は fn_bedmotion 有効時に拒否されます
  (z の生産者は一人)。
- MPI: 各ランクが変位ファイル全体を読み、自分の帯を切り出します
  (ファイルの読み込みは冗長、適用は帯ごと)。結果はランク数によらず
  同一です。
- 出力: 地盤高 Z(f_out_z)に変位後の地形が出ます。終了時に適用した
  変位の最大・最小を表示します。

## 8. 検証と例題

test/nhbottom 構成 3: 水深 10 m の水路で |x − x_c| < 20 m を 1 s で 0.2 m
持ち上げる Hammack 型の隆起を、毎ステップのスナップショット表で与え、
ライブラリ API で同じ運動を与えたドライバの結果と一致します(Log の
全有効桁の体積列の最終桁を除いて同一)。再開(0.5 s で save → restore)
も中断なしの計算と一致(静水圧。非静水圧の f_nh_bottom では加速度項の
1 ステップ分だけ異なります)、海底地滑り(f_bedslide)との同居では
Σ(z − z0) = Σ d(底層の内部移転は総和 0)が出力精度の範囲で成り立ちます。

- [examples/tsunami_fault](../../examples/tsunami_fault/README.md):
  理想化した逆断層(走向 N-S、傾斜 15°、60 km × 30 km、すべり 5 m、
  30 s 立ち上がり)。静水圧 / 瞬時変位 / 非静水圧 + 加速度項の比較と、
  fault2disp の座標パターン(bil・GeoTIFF の地理参照、平面直角座標系、
  経緯度)の設定例。
- [examples/tsunami_coast](../../examples/tsunami_coast/README.md):
  海岸直下の深部断層(沿岸 0.6 m 沈降)、沖の浅部断層(30 s 遅れて主津波)、
  湾口の分岐断層(岬が 0.8 m 隆起)の 3 セグメント。沿岸の地盤変動が
  起こす擾乱が沖の津波より 10 分早く海岸に現れ、沈降した湾奥の平野の
  浸水が早まる。
