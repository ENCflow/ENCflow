# 家屋破壊・瓦礫モデルの解説(家屋破壊・瓦礫の補足)

[家屋破壊・瓦礫の章へ](bldgdebris.md) | [ユーザーガイド目次へ](../users_guide.md)

[家屋破壊・瓦礫の章](bldgdebris.md)の破壊判定と破壊レート、空隙率への
帰還、面積基準と材積収支、閾値の文献との対応、既定値の根拠をまとめます。
喫水と移送則の基本形は[流木モデルの解説](driftwood_models.md)と共通です。
実装は `src/m_bldgdebris.f90` で、設計の経緯と文献照合は developer.md §63
にあります。

## 1. 破壊判定量と破壊レート

判定量 $`X`$ は、`f_bdcrit = 1` で混合流動深 $`H = h + \max(h_s, 0)`$、
`f_bdcrit = 2` で清水規格化した単位幅流体力

```math
X = \bigl[h + (1 + s)\max(h_s, 0) + s_{g,\mathrm{log}}\,h_d + s_{g,\mathrm{bd}}\,h_{bd}\bigr]\,V^2
\quad [\mathrm{m^3/s^2}]
```

です($`s`$: 土砂の水中比重、$`s_{g,\mathrm{log}}`$: 流木の比重。流木項は流木
モジュール有効時だけ加える)。荷重は出力 Fd9999 と同じ定義で、F9999 は水・
土砂だけを含む従来の定義です。

第 1 閾値 $`c_1`$、第 2 閾値 $`c_2`$ に対する倍率は

```math
a(X) = \min\left(1,\ \max\left(0,\ \frac{X - c_1}{c_2 - c_1}\right)\right)
```

で、$`c_1`$ 以下で 0、$`c_1`$〜$`c_2`$ で線形に増え、$`c_2`$ 以上で 1 です。
第 1 閾値だけを明示指定した場合はランプを使わず $`X > c_1`$ で 1 です。
このランプは、文献の被害関数(浸水深に対する流失確率の累積分布曲線
[^suppasri13][^koshimura09])を折れ線で近似したもので、曲線の中央値を
$`(c_1 + c_2)/2`$、幅を $`c_2 - c_1`$ と読み替えます。1 ステップの破壊量は

```math
w = \min\left(w_{bs},\ \mathtt{bd\_wdes}\;a(X)\,\Delta t\right)
```

です。「破壊可能率」は破壊レートの倍率であり、累積破壊率の上限では
ありません(倍率 0.5 が続けば半分のレートで残ストックの破壊が進む)。
破壊量 $`w`$ のうち bd_fsink の割合はその場で $`w_{bd}`$ へ、残りは $`h_{bd}`$
へ移します。沈下分も再流動を有効にすれば $`w_{bd}`$ の再流動条件で動き得ます
(沈下用の独立した不動台帳はありません)。停止・堆積と再流動の条件と
レートの上限は[流木モデル](driftwood_models.md) §1 と同形です。

## 2. 空隙率への帰還

破壊率は $`d = 1 - w_{bs}/w_{bs0}`$(初期ストック $`w_{bs0}`$ が 0 なら 0)で、
`f_bdgv = 1` のとき空隙率を

```math
g_v = g_{v0} + (1 - g_{v0})\,f_w\,d
```

へ更新します。$`f_w`$ は `fn_bdfrac` で与える破壊可能な建物占有の割合
(省略時 1)で、空隙率の上限を決める値です。ランプ倍率 $`a`$ とは別で、
初期ストックや破壊レートに直接掛ける値ではありません(破壊可能な材積・
木造率は `fn_bdstock` または `bd_stock0` に織り込む)。空隙率の更新では
$`h`$・$`h_s`$・$`h_{bd}`$・$`w_{bd}`$ 等の空隙面積基準の柱状量を
$`g_{v,\mathrm{old}}/g_{v,\mathrm{new}}`$ 倍して体積を保存し、水深・水位が
下がった状態で次の流れの計算へ返ります。局所処理の順序は 荷重評価 →
① 破壊・帰還 → ② 停止 → ③ 再流動 → ダム捕捉 → 最大値更新で、$`H`$ は局所
処理の冒頭で評価し、乾燥判定はその時点の水深 $`h`$ を参照します。

## 3. 面積基準と材積収支

$`w_{bs}`$ は幾何セル面積当たり、$`h_{bd}`$・$`w_{bd}`$ は実効面積当たりの
柱状材積です。$`A = \Delta x\,\Delta y`$、$`f = g_v\,w_{frac}`$(河道幅を
指定しない場合は $`w_{frac} = 1`$)とすると、領域内の材積は

```math
Q = \sum_{i,j} A\left[w_{bs,ij} + f_{ij}\,(h_{bd,ij} + w_{bd,ij})\right]
```

です。破壊量 $`w`$ を $`h_{bd}`$・$`w_{bd}`$ へ加えるときは $`f`$ で割って
基準を変換します。閉領域・ダム捕捉なしなら現在貯留の和 $`Q`$ が初期材積を
保存します(数値誤差を除く)。

## 4. 閾値と文献の対応

- **浸水深閾値(f_bdcrit = 1)**: 首藤[^shuto93]の津波強度と家屋被害の対応では
  木造家屋は浸水深 2 m 超で全壊、1 m 程度で部分破壊。東北地方太平洋沖
  地震津波の被害関数(構造種別・階数別)[^suppasri13]でも木造の流失確率は
  2 m 前後で急増し、4 m 超で大半が流失します。被害関数が確率曲線である
  のに対し本モジュールは閾値+レート(または 2 閾値の線形ランプ)なので、
  「曲線の中央値を bd_hcrit〜bd_hcrit2 の中点、曲線の幅をランプ幅」と
  読み替えます(例題は 1.0〜3.0 m)。RC 造は同じ浸水深でも流失しにくい
  ため、fn_bdstock(木造率)と fn_bdfrac で表します。
- **荷重閾値(f_bdcrit = 2)**: 単位は F9999 と同じ m³/s²(清水規格化。
  × ρ_w で N/m)。流体力ベースの被害関数[^koshimura09]
  $`F = \tfrac{1}{2}\rho C_D u^2 h`$ から $`X = hV^2 = F/(\tfrac{1}{2}\rho C_D)`$
  で換算するか、水のみの F9999 の分布と被害実績を突き合わせて決めます。
  FEMA P-646[^fema12] は瓦礫を含む流れの流体力に係数 $`k_s`$(推奨 1.25)を
  乗じますが、本モジュールは同じ効果を浮遊物の柱状量から計算します
  (流木・瓦礫の項)。これは「浮遊物を含む流れの平均的な破壊力」であり、
  1 本の材の衝撃荷重や堰き止め力(国総研資料 905[^nilim905] §4.3、
  FEMA P-646 の個別荷重)の置き換えではありません。

## 5. パラメータと既定値の根拠

根拠欄の分類語の意味は[既定値の根拠の読み方](../users_guide.md#既定値の根拠の読み方)を参照してください。

| パラメータ | 既定 | 意味 | 根拠 |
|---|---:|---|---|
| 家屋ストック | 0.3 m³/m²(建物のあるセル gv < 1) | 両方未指定時の既定 | **経験値** 建物占有 0.4 × 階数 1.5 × 木造の構造材積原単位(延床当たり 0.5 m³/m² 程度)。gv が全域 1 なら停止して入力を促す |
| bd_dlog / bd_sg | 0.3 m / 0.5 | 瓦礫の代表寸法・見かけ比重 | **経験値** 木造の構造材の寸法級と比重。喫水 0.15 m |
| bd_hcrit / bd_hcrit2 | 1.0 / 3.0 m | 浸水深閾値のランプ | **文献値** 木造 2 m 超で全壊[^shuto93]を中央値に、木造流失曲線の幅[^suppasri13]を近似。両方未指定なら両方に既定(ランプあり)、閾値 1 だけ指定ならランプなし(明示の尊重) |
| bd_fcrit / bd_fcrit2 | 2.0 / 6.0 m³/s² | 荷重閾値のランプ | **校正量** 浸水深 2 m・流速 1〜1.7 m/s の $`hV^2`$ に相当(流体力曲線[^koshimura09]から換算できる)。水のみの F9999 の分布で置き直す前提 |
| bd_wdes | 5e-4 m/s | 破壊レート | **経験値** 既定ストック 0.3 m³/m² が 10 分(津波の押し波 1 回の継続時間)で全壊 |
| bd_wstop | 0.01 m/s | 接地堆積レート | **経験値** 流木と同じ |
| bd_vstop | 0.05 m/s | 低速堆積の流速閾値 | **経験値** 湛水して流れが止まった瓦礫はその場に残る(例題の値)。流木の既定 0 と異なるのは、市街地の瓦礫は停滞で残る方が実態に近いため |
| bd_fsink / bd_wfloat | 0 / 0 | 沈下率・再流動 | **経験値** 全量浮遊・再流動なし = 到達範囲の上限側(安全側) |
| f_bdgv | 1 | 空隙率への帰還 | **方式** 破壊した家屋の貯留増と抗力減を流れに返す(§3) |

**既定値を見直すときの手がかり**

- 家屋ストックは、建物の延床面積の統計(都市計画基礎調査・固定資産
  データ)× 木造の構造材積原単位で地域ごとに置き換えられます。
- 閾値は被害関数の文献(浸水深 vs 全壊率[^shuto93][^suppasri13]、流体力
  vs 被害率[^koshimura09])から、対象地域の家屋構造に合わせて読み替えて
  ください。流体力閾値は、水のみで一度計算した F9999 の分布を見て
  「全壊が始まる値」として置き直すのが実用的です。

&list_bldgdebris + gv.txt と既定値を全て明示した構成の保存状態がバイト一致。
