# 計測(&list_record)

[ユーザーガイド目次へ](../users_guide.md)

観測点との比較や流量ハイドログラフの取得のために、**プローブ**
(点の時系列)と**フラックス測線**(線を横切る流量の時系列)を
設定します。`fn_record` で有効化し、出力間隔は `&list_sysparam` の
`dt_recrd`(と時間窓 st_recrd/et_recrd。[時刻の章](time.md))で
制御します。

```
&list_record
  ! プローブ(セル番号指定)
  pbxy(:,1) = 150, 150           ! 1本目: (ix, iy)
  pbxy(:,2) = 200, 120           ! 2本目
  ! フラックス測線(セル番号指定): 右岸から左岸へ
  flxy(:,1) = 100, 50, 100, 60   ! 1本目: (右岸ix, iy, 左岸ix, iy)
/
```

## プローブ(点の時系列)

| パラメータ | 既定値 | 意味 |
|---|---|---|
| pbxytype | 0 | 座標の指定法。0: セル番号 (ix, iy)、1: 実座標 (x, y)(m。領域左下原点) |
| pbxy | — | プローブ位置 `(x, y, 番号)`。複数指定可 |

出力は `result/probes/probe0001.csv` などに1点1ファイルで書かれます。
列は時刻(hour/min)・地盤高 z・水深 h・流速 u, v, |V|・流量 q・
地下貯留 hg・浮遊砂 hs・土層厚 sd(水質有効時は濃度 C・地表負荷 cq も)
です。使っていない機能の列は 0 のままです。

## フラックス測線(通過流量の時系列)

| パラメータ | 既定値 | 意味 |
|---|---|---|
| flxytype | 0 | 0: セル番号指定(固定)。実座標指定(1)は廃止され、指定すると停止します |
| flxyfile | 0 | 0: flxy で直接指定、1: 測線情報ファイル fn_flxy から読み込み |
| flxy | — | 測線の始点・終点 `(右岸x, 右岸y, 左岸x, 左岸y, 番号)` |
| fn_flxy | — | 測線情報ファイル(1行1測線、カンマまたは空白区切りで「右岸x 右岸y 左岸x 左岸y」) |

- 流量の符号は**始点から終点に向かって右側へ抜ける流れが正**です。
  河川では右岸を始点・左岸を終点にすると下流向きが正になります。
- 斜めの測線は DDA 階段面(セル境界に沿う階段状の面)に変換して
  計測されるので、任意の角度で引けます。
- 出力は `result/fluxes/flux0001.csv` などに1測線1ファイルです。
- カルバートなど構造物の転送流量は測線には乗りません
  ([構造物の章](structure.md))。

## 集計サマリ

計測を有効にすると、`result/summary.csv` に全プローブ・全測線の
集計(最大値等)がまとめて出力されます。

## 分布データからの事後計測(utils/rerecord)

「計算が終わってから計測点を追加したい」場合のために、出力済みの
分布ファイルから時系列を再構成するユーティリティ
`utils/rerecord` があります(流向 `f_out_qd` の出力が必要です。
[入出力の章](io.md))。長時間の計算をやり直さずに済みます。
