# 降雨・気象(&list_precip / intercept / meteo / evap / snow)

[ユーザーガイド目次へ](../users_guide.md)

水文計算の駆動力となる5つの機能をまとめて説明します。必要な機能を
`fn_*` で有効化し、気温・暦などの依存条件を満たして組み合わせます。

**降水 (`fn_precip`) は水収支への質量入力**、**気象強制場 (`fn_meteo`)
は気温と標高補正の供給元**です。雨だけを与え、標高補正や気温を使う
過程を有効化しなければ、`fn_meteo` は不要です。

![降水の経路、気象による補正、蒸発散の適用順](../figs/forcing_chain.png)

(a) 降水は樹冠遮断を経て雨と雪に分かれ、雨は降雨として、雪は積雪水量
(SWE)に蓄えてから融雪水として地表へ届きます。(b) 気象強制場は降水の
標高補正、雨雪判定・融雪、気温からの可能蒸発散(PET)の推算に使います。
(c) 蒸発散は地表流・浸透などの計算後、樹冠保水→地表水→ため池・
ダム／湖沼捕捉帯の貯留→地下水の順に、残った要求を満たす分だけ差し引きます。
青実線は水の経路、灰破線は情報・補正、橙実線は蒸発散要求の適用順です。
橙の矢印は貯留間の水の移送を意味しません。図は陸域の使用セルに対する模式図で、
全過程を含む水収支図ではありません。`runoff_rate=1` を前提とし、
各 `fn_*` が参照するファイルには対応する `&list_*` を記述します。

遮断を使わなければ降水はそのまま次へ渡り、積雪を使わなければ全量を
雨として扱います。蒸発散は有効な場合だけ適用します。
各モデルの式と既定値の根拠は[降雨・気象のモデルの解説](forcing_models.md)に
あります。

結果の見方(分布・台帳・計測列・再開)は、このページの[出力・確認](#出力確認)にまとめています。各機能の節末にも、その機能に関係する出力だけを短く記しています。

## とりあえず動かしてみる(最小入力)

雨だけなら `fn_precip` と `&list_precip` の時系列(下の例)で足ります。
各 fn_\* には同じファイル名を指定できるので、気象系の入力は1枚に
まとめられます(推奨書式)。

```
&list_sysparam
  ...
  fn_precip = "forcing.txt"
  fn_meteo  = "forcing.txt"
  fn_snow   = "forcing.txt"
/
```

```
! ---- forcing.txt ----
&list_precip
  prtype = 1
  prval(:,1) = 0, 10        ! (時刻(min), 雨量強度(mm/h))
  prval(:,2) = 1440, 10
/
&list_meteo
  temp0 = 2.0               ! 一様気温 (℃)
/
&list_snow
  snow_ddf = 3.0            ! 度日係数 (mm/℃/day)
/
```

## 降水(&list_precip)

雨の与え方は `prtype` で選びます。

| prtype | 与え方 | 使うパラメータ |
|---|---|---|
| 0(既定) | 降水なし(一時無効化) | — |
| 1 | 一様な時系列 | prval |
| 2 | 固定の分布 × 時系列倍率 | fn_prmap、prval(倍率) |
| 3 | 時系列の分布ファイル群(レーダー雨量等) | fn_maplist、dt_maplist |

| パラメータ | 既定値 | 意味 |
|---|---|---|
| prval | — | 時系列 `(時刻(min), 値)` の組。値は prtype=1 で雨量強度 (mm/h)、prtype=2 で倍率。最後の時刻以降は最後の値で継続 |
| dt_prupdate | 1 | 降雨の更新間隔 (min)(prtype=1, 2) |
| fn_prmap | "" | 降水分布ファイル(prtype=2) |
| fn_maplist | "" | 分布ファイル名のリスト(1行1ファイル。prtype=3)。**リスト中のパスも dir_data 起点**(リストファイルからの相対ではない) |
| dt_maplist(_c) | 60 | 分布ファイルの時間間隔 (min)(prtype=3) |
| dt_mapunit(_c) | 0 | 分布ファイルの値が「何分間の積算雨量 (mm)」かの指定。0(既定)なら prtype=2 は1日(= mm/day)、prtype=3 はファイル間隔(dt_maplist 間の積算 mm。間隔1時間なら mm/h と同値) |
| runoff_rate | 1.0 | 流出率。現行実装では prtype によって適用先が異なるため、下記参照。地下水計算との併用では 1.0 を使う |

**`runoff_rate` の現行実装**: `prtype=1,2` では出力用雨量 `prh` に掛かり、
水収支へ渡す降水強度 `pre` には掛かりません。`prtype=3` では分布値を
`dt_mapunit` で降水強度へ換算するときに `pre` に掛かります。
したがって、どのモードでも同じように実際の降水を減らす係数としては
扱えません。図のような外力の連携では既定の `1.0` とし、降水量自体を
変えたい場合は入力値を調整してください。

```
&list_precip                ! 例: 10分から24時間、15 mm/h の一様雨
  prtype = 1
  prval(:,1) =    0,  0
  prval(:,2) =   10, 15
  prval(:,3) = 1440, 15
  prval(:,4) = 1450,  0
/
```

書式の実例は [examples/List_samples/list_precip.txt](../../examples/List_samples/list_precip.txt)
に4タイプ分あります。降雨強度の分布は `f_out_pre = 1` で `Pr0001` と
して出力できます。

**降雨の型の目安**(雨量は与件ですが、設定の出発点として。
地域・再現期間で 2 倍程度動きます)

| 型 | 強度 (mm/h) | 継続 | 総雨量 (mm) | 与え方 |
|---|---|---|---|---|
| 梅雨前線の長雨 | 10〜30 | 6〜24 h | 100〜300 | prtype=1 の台形 |
| 台風 | 20〜50(ピーク 50〜80) | 12〜24 h | 200〜600 | prtype=1 の山形、または prtype=3 の解析雨量 |
| 線状降水帯 | 50〜100 | 3〜6 h | 200〜400 | prtype=1 の矩形 |
| 都市の設計降雨(5〜10 年確率、60 分) | 50〜80 | 1 h | 50〜80 | prtype=1 の矩形(内水・下水道) |
| 浸水想定(想定最大規模) | 100 以上(ピーク) | 数時間 | 300〜1000 | prtype=1 のハイエトグラフ |
| 融雪出水 | 0(無雨)〜10 | 日単位 | — | fn_meteo の気温 5〜10 ℃ + fn_snow |

**この節に関係する出力**: 降雨強度の分布 `Pr0001…`(`f_out_pre=1`。与えた降水 × 流出率)。領域に入った総量は Σ(Pr × dt / 1000 × A) で、Log の S の増分と照合します([出力・確認](#出力確認))。

## 降雨遮断(&list_intercept)

樹冠などによる遮断を、雨雪判定より前の降水に適用します。積雪と併用
する場合も、雨と雪を区別する前に同じ遮断モデルが作用します。

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_icmodel | 0 | 0: なし(一時無効化)、1: 固定遮断率、2: 初期損失(貯留型) |

モデル固有の設定は同じファイル内の専用グループに書きます。

**固定遮断率(f_icmodel = 1、&list_intercept_fixed)** — 降雨の一定
割合 α を損失として取り除き、残りを後続の雨雪判定へ渡します(樹冠貯留は
持ちません)。`ic_alpha`(一様値。既定 0.15)または `fn_icalpha`(分布。
指定時は ic_alpha 不使用)。

**初期損失(f_icmodel = 2、&list_intercept_initloss)** — 降り始めの
雨を最大貯留量まで蓄え、満たされた後は素通しにします。`ic_smax_mm`
(一様値 mm。既定 1.5)または `fn_icsmax`(分布)。`fn_evap` の蒸発散で
樹冠保水が減ると再び遮断できるようになります(蒸発散を使わなければ空き
容量は回復しません)。

一様値は未指定なら既定を採用し "(default)" 付きで表示します(最小入力は
f_icmodel と空の固有グループ)。式と既定値の根拠は[解説](forcing_models.md) §1。
植生別の目安(校正で変わる量です):

| 型 | ic_alpha(遮断率) | ic_smax_mm(樹冠貯留 mm) |
|---|---|---|
| 針葉樹林(密) | 0.25〜0.4 | 1.5〜3 |
| 広葉樹林・混交林(既定) | 0.1〜0.2 | 0.8〜1.5 |
| 落葉期の広葉樹林 | 0.05〜0.1 | 0.3〜0.8 |
| 草地・農地 | 0.05〜0.1 | 0.3〜0.5 |
| 市街地(窪地貯留としての初期損失) | — | 1〜2.5(不透水面の窪地貯留。SWMM の慣用値) |

**この節に関係する出力**: 遮断量の分布・台帳はありません。`Pr0001…` は遮断前の値なので、遮断損失は降水総量 − S_total の増分 − 蒸発として差し引きで求めます。初期損失モデルの樹冠貯留は `intercept_initloss.dat` に保存されます([出力・確認](#出力確認))。

## 気象強制場(&list_meteo)

気温を一元管理し、蒸発散・融雪・水質などへ提供します。入力は
**3通りのいずれか1つ**です。

| パラメータ | 既定値 | 意味 |
|---|---|---|
| temp0 | — | 一様な定数 (℃) |
| tempval | — | 一様な時系列 `(経過日数, ℃)`。時刻は t=0 からの経過**日** |
| fn_tempmap | "" | 気温分布ファイルのリスト(1行1ファイル、dt_tempmap_c 間隔で順次適用・終端保持) |
| dt_tempmap_c | "1 day" | 分布ファイルの時間間隔 |
| f_temp_lapse | 0 | 1: 標高による気温減率を有効化(一様入力のみ) |
| temp_lapse | 0.65 | 減率 (℃/100 m) |
| temp_zref | 領域最低標高 | 気温減率の基準標高 (m) |

一様入力で `f_temp_lapse=1` のとき、基準標高からの標高差に減率を掛けて
気温を下げます(減率 0.65 ℃/100 m、標高差 1000 m なら 6.5 ℃。式は
[解説](forcing_models.md) §2)。分布気温 `fn_tempmap` に減率を重ねる設定は
初期化時にエラーになります。気温減率と積雪を併用すると、標高による雨雪
判定・融雪の違いが現れます。

このほか、長期計算([氷河](glacier.md)・長期地形変化)向けの
オプションが2つあります。

| パラメータ | 既定値 | 意味 |
|---|---|---|
| tempofs | — | 長周期の気温オフセット系列 `(経過日数, ΔT ℃)`。気温入力(一様・分布とも)へ加算される。周期強制 t_cycle で折り返されない実時間軸で補間されるため、**代表年の反復に寒冷化・温暖化トレンドや氷期サイクルを重畳**できる |
| f_prec_lapse | 0 | 1: 降水の標高勾配を有効化(地形性降水・氷河涵養の簡便表現。分布降水入力があればそちらを推奨。倍率の式は[解説](forcing_models.md) §2) |
| prec_lapse | 0.0 | 降水の増率 (%/100 m) |
| prec_zref | 領域最低標高 | 降水勾配の基準標高 (m) |

降水の標高補正は、基準標高からの標高差に増率を掛けた倍率を降水の更新時
(遮断より前)に掛けます(10 %/100 m、標高差 500 m なら 1.5 倍。負になる
場合は 0)。降水補正と積雪の気温評価は、氷河が有効なら氷面 `z + hi` を
標高に使います。蒸発散の気温評価は地盤高 `z` を使います。

**この節に関係する出力**: 気温の分布出力はありません。気温は融雪(`Sw0001…` の減少)と PET(`evap.csv` の `pet_ref_mmday`)を通じて結果に現れます([出力・確認](#出力確認))。

## 蒸発散(&list_evap)

可能蒸発散(PET)の与え方を `f_evmodel` で選びます。

| f_evmodel | 方法 | 必要なもの |
|---|---|---|
| 0(既定) | なし(一時無効化) | — |
| 1 | 一定速度 evap0 (mm/day) | — |
| 2 | 月別気候値 evap_monthly (mm/day ×12) | 暦(date0_c) |
| 3 | Hamon 式(気温と可照時間から推算) | 暦・気温(fn_meteo)・緯度 lat |
| 4 | Thornthwaite 式 | 3 に加えて月平均気温の平年値 temp_normal(×12) |

| パラメータ | 既定値 | 意味 |
|---|---|---|
| evap0 | 3.0 | モード1: PET (mm/day)。未指定なら既定を採用し "(default)" 付きで表示 |
| evap_monthly | — | モード2: 月別 PET (mm/day)。12ヶ月分 |
| evap_kc | 1.0 | 換算係数(パン係数・校正用。全モード共通) |
| lat | — | 代表緯度 (deg)。モード3, 4 で必須 |
| temp_normal | — | 月平均気温の平年値 (℃)。モード4 で必須 |

モード 3・4 は気温と可照時間だけから推算する簡便法で、放射・風・湿度は
使いません(式は[解説](forcing_models.md) §3)。`evap_kc` で校正します。

PET は `evap_kc` を掛けて日ごとに評価し、各計算ステップで `PET × dt` に
相当する水深を **樹冠保水(貯留型遮断のみ)→ 地表水 `h` → 貯留 `hrs`
(ため池・ダム／湖沼捕捉帯)→ 地下水 `hg`** の順に、存在する水量を上限に
差し引きます。樹冠・地表水・貯留・地下水別の累積蒸発体積と合計を結果
ディレクトリの `evap.csv` に出力します(実行開始からの積算。リスタートで
リセット)。必要条件が揃っていない設定(暦なしのモード2など)は初期化時に
停止します。

モード1 の既定 3 mm/day は温帯湿潤気候の暖候期の基準蒸発散の下寄りです
(根拠は[解説](forcing_models.md) §3)。季節を通す計算ではモード2〜4 を
使ってください(月別値・緯度・平年気温は与件なので既定はありません)。

**この節に関係する出力**: `result/evap.csv` の基準 PET と、樹冠・地表水・貯留・地下水別の累積蒸発体積(m³。再開でリセット)。どの貯留から抜けたかを列で追えます([出力・確認](#出力確認))。

## 積雪・融雪(&list_snow)

度日法による積雪・融雪です。**気温(fn_meteo)が必須**です。

| パラメータ | 既定値 | 意味 |
|---|---|---|
| f_snow | 1 | 0 でファイルを残したまま一時無効化 |
| snow_t_snow | 0.0 | すべて雪になる気温閾値 (℃) |
| snow_t_rain | 2.0 | すべて雨になる気温閾値 (℃)。間は雨雪が線形に混合 |
| snow_t_melt | 0.0 | 融雪の気温閾値 (℃) |
| snow_ddf | 4.0 | 度日係数 (mm/℃/day)。未指定なら既定を採用し "(default)" 付きで表示(根拠は[解説](forcing_models.md) §4) |
| snow_swe0 / fn_snow_swe0 | — / "" | 初期積雪水量 (mm)(一様値 / 分布。排他。どちらも省略で無雪から開始) |

遮断後の降水を雨と雪へ分け(`snow_t_snow` 以下は全雪、`snow_t_rain` 以上は
全雨、その間は線形混合)、雪を積雪水量(SWE)として蓄えます。融雪量は
気温が融雪閾値を超えた分に度日係数を掛けた量で、SWE が上限です(式と
数値例は[解説](forcing_models.md) §4)。融雪水は地表水 `h` に直接加え、降雨
強度 `pre` には含めません。再凍結、雪内の雨水保持、昇華は扱いません。
初期SWEを与えれば、新たな降水がなくても気温に応じた融雪を計算できます。

「とりあえず動かしてみる」最小入力は **fn_snow に空の &list_snow**
(+ fn_meteo の気温)です。既定 `snow_ddf` = 4 mm/℃/day は日本の山地流域の
融雪出水の慣用値 3〜5 の中庸です(根拠は[解説](forcing_models.md) §4)。
度日係数の目安(校正で変わる量です):

| 型 | snow_ddf (mm/℃/day) | 備考 |
|---|---|---|
| 森林(針葉樹林の林内) | 2〜3 | 日射が遮られ小さい |
| 開放地・疎林(既定) | 3.5〜5 | 日本の山地流域の融雪出水の実績域 |
| 融雪期後半・高標高の開放地 | 5〜7 | 雪面の汚れ・日射の増加で大きくなる(季節変化は未実装なので期間平均で与える) |
| 氷河上の雪 | 3〜5 | 氷面は gl_ddfi([氷河](glacier.md)) |

**この節に関係する出力**: 積雪水量 `Sw0001…`(mm。自動)、Log の S_total に算入、再開は `snow.dat`。融雪量は Sw の減少 × A で、融雪出水は S_surf・測線 Q の増加に現れます([出力・確認](#出力確認))。

## 出力・確認

分布出力の 3 通りの有効化(自動 / 指定 / 共用)と柱状量の面積基底の読み方は[入出力の形式](io.md#状態量の分布出力の考え方)に、確認したい量から出力を逆引きする早見表は同じ節の末尾にあります。

**分布**(`result/` のラスタ。`dt_file` 間隔)

| ファイル | 出し方 | 内容 |
|---|---|---|
| Pr0001… | f_out_pre = 1 | 降雨強度 (mm/h) = 与えた降水 × 流出率 runoff_rate。遮断・雨雪判定の前の値 |
| Sw0001… | 自動(fn_snow) | 積雪水量 SWE (mm 水柱。幾何面積基底) |

気温・遮断・蒸発散の分布は出力されません。

**台帳・ログ**(収支の検算)

- 積雪有効時は Log.txt の S 列が S_surf / S_grnd / S_total の 3 列になり、
  S_total に積雪水量が算入されます(地下水無効なら S_grnd は 0)。
- 蒸発散有効時は `result/evap.csv` に `time_s`、基準 PET
  `pet_ref_mmday` (mm/day) と、樹冠 `ev_canopy_m3`・地表水 `ev_surface_m3`・
  貯留(ため池・ダム捕捉帯)`ev_pond_m3`・地下水 `ev_gw_m3`・合計
  `ev_total_m3` の累積蒸発体積 (m³) を `dt_recrd` 間隔で記録します
  (実行開始からの積算。再開でリセット)。
- 遮断量・融雪量の台帳はありません(下の「読み方」の差し引きで求めます)。

**計測**(プローブ・測線の列)

- 強制場専用の列はありません。降雨への応答はプローブの `h`・測線の Q で
  見ます。

**再開**

- 積雪は `snow.dat`、貯留型遮断(初期損失モデル)の樹冠貯留は
  `intercept_initloss.dat` で自動的に扱われます。定率遮断・気温・蒸発散に
  保存する状態はありません。

**読み方と検算のコツ**

- 降水量の検算: 領域に入った水 = Σ(Pr × dt / 1000 × A)。閉領域なら
  S_total の増分 × 有効セル数 × A + evap.csv の `ev_total_m3` と
  (遮断の損失分を除いて)一致します。遮断損失はその差です。
- 雨雪判定は Sw と Pr を並べて確認します(気温閾値 snow_t_snow /
  snow_t_rain の間は按分)。融雪は Sw の減少と S_surf の増加の対応で読み、
  融雪水は地表水として流出します。

## 併用の条件まとめ

| 機能 | 必要な他機能 |
|---|---|
| 降水 | なし(単独で使える) |
| 遮断 | 降水があるときに作用(有効化に他機能の必須条件はない) |
| 気象強制場 | なし(消費側の機能と組で使う) |
| 蒸発散(モード1) | なし |
| 蒸発散(モード2〜4) | 暦 date0_c。3・4は気象強制場と緯度、4は temp_normal も必須 |
| 積雪・融雪 | 気象強制場。降水は新たな積雪の供給に使うが、有効化の必須条件ではない |
| 氷河([専用の章](glacier.md)) | 気象強制場+有効な積雪・融雪。降水は涵養の供給に使うが、有効化の必須条件ではない |

設定書式の実例は [examples/List_samples/](../../examples/List_samples/)
の list_precip / list_intercept / list_meteo / list_evap / list_snow を
参照してください。

## 検証・例題

- [test/chichibu](../../test/chichibu/): 実地形流域への一様降雨と、斜面から河道への集水・洪水波の回帰ケース。
- [test/icevap](../../test/icevap/): 固定遮断率・初期損失・一定蒸発散について、最小入力と既定値を明示した入力の同値を検定。
- [test/frost](../../test/frost/): 一定気温による凍結指数の増加と浸透抑制を解析値と比較。
