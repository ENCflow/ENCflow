## 0. 結論(要約)

- **入れるもの**: 掃流砂を粒径階 N 個(数個。上限 8 案)に分け、河床の粒度を交換層 1 枚と下層 1 枚で
  持つ(Hirano 1971 型)。粒径階ごとの流砂量は芦田・道上(1972)の式 (32)、遮蔽係数は修正 Egiazaroff
  (同 式 (31))。流砂の向きの補正(河床勾配・二次流)は粒径階ごとに当てる。
- **入れないもの**: 鉛直の層序(下層を複数持つこと)、粒径階ごとの浮遊砂、摩耗、粒径に応じた粗度、
  土石流の力学の多粒径化(細粒の間隙流体化、流れの中の粒径選別、代表粒径を組成から決めること)。浮遊砂は
  1 粒径のまま(段 2a で最も細かい粒径階に対応づけた。developer.md §122)。土石流の流れが粒径階の組成を
  受動的に運ぶことだけは、段 2c-1 で入れた(§12。方針 6 の例外の 2026-11-27 の追記)。土石流の式の侵食を、
  文献の判定(流動深と、掃流の領域の限界掃流力)で動ける粒径階に限る選択子は、段 2c-4 で入れた(§13。同
  2026-11-28 の追記。既定は選ばない)。
- **無効時のコスト**: 有効化しなければ、新しい配列は確保せず、新しい手続きを呼ばず、ハロ交換も
  増やさない。既存の掃流砂のループには分岐を入れず、手続きの先頭で混合粒径の写しへ分ける
  (波浪場の掃流砂 calc_fluvial_wfsed と同じ形)。増えるのは手続きの先頭の整数の判定だけ(§4)。
- **段取り**: 段 1 = 掃流砂・交換層・下層・境界・給砂・側岸侵食と安息角・定着と検定、段 2 = 浮遊砂と
  ほかの過程の組成・岩盤下刻の被覆、段 3 = 国総研の移動床実験の例題と、砂分の効果を持つ式の検討(§8)。
- **検証**: 無効時ビット一致、全粒径階を同じ粒径にした極限、粒径階ごとの質量保存、アーマー化、
  遮蔽係数、給砂、リスタート・MPI(§6)。
- **段 1 の決めごと**(2026-11-22 決定。§10): 名称 f_bedmix・bmix_*、交換層厚の既定 = 初期の組成の D90 の
  2 倍、給砂の組成は指定が必須、粒径階は 2〜8、遮蔽係数は両セルの d_m の平均・利用可能率は風上、側岸侵食と
  安息角崩落は供給側の交換層の組成で運ぶ。

## 1. 動機

### 1.1 単一粒径で外れる場面

- **砂と礫の河床**: 国総研の常願寺川 1/100 移動床実験(小橋ら 2026。セグメント 1 の二極化)の
  ケース 2-1 では、中小出水の給砂の 94〜97 % が 0.57 mm の砂、3〜6 % が 3 mm、6.6 mm は 0 である。
  平均年最大流量程度(水深 1〜2 cm、勾配 1/50〜1/90)で概算すると、無次元掃流力は 0.57 mm で限界の
  数倍、3 mm で限界付近、6.6 mm でほぼ限界以下になり、ほぼ動かない礫の上を砂が流れる。代表粒径を
  3 mm にすると動かなすぎ、0.57 mm にすると動きすぎて、どちらも外れる見込み。
- **給砂の減少への応答**: 給砂が減ると表層が粗粒化(アーマー化)して河床低下が早く止まる。単一粒径では
  この分を表せず、勾配が緩むまで掘り続けて低下を過大に見積もる。
- **二極化**: 同論文は、大粒径で静的に安定した側岸が拡幅を抑え、低水路幅の縮小につながると述べる。
  単一粒径の非粘着性の河岸には拡幅を抑える機構がない。

いずれも精緻化ではなく、概算(方針 4)の一次の効果と判断した(developer.md §84.19)。

### 1.2 応用の広がり

1. 土砂供給が変わったときの河道の応答: ダム下流のアーマー化、置き土・土砂還元、セグメント 1 の
   二極化。国総研は混合粒径の実験データを 3 件公開している(§7)。
2. 流砂系の連鎖(開発目的 1): 斜面・土石流から河道・貯水池・河口へ、どの土砂がどこに届くかは
   粒径で分かれる。粒径階がないと、連鎖の中で「どの土砂が」を言えない。
3. 山地渓流: mountain_stream_plan.md §6.2 で方針の議論が先とした粒径(砂は素通りし、礫が被覆と
   道具になる)。
4. 湾曲部の横断方向の分級(外岸に粗粒、内岸砂州に細粒。Parker & Andrews 1985): 流砂の向きの
   補正を粒径階ごとに当てると現れると期待できる(§3.3)。
5. 天然ダムの決壊(例題 examples/debris_dam)の侵食の段階: 粒度の広い堤体の表層の粗粒化。土石流そのものの
   多粒径化(高橋・中川 1991 の多粒径の式)は範囲外。(2026-11-27 追記: 土石流と混合粒径の併用 = 段 2c-1 を
   入れた。決壊のハイドログラフは併用してもほぼ変わらず、混合粒径が効くのは決壊のあとの流水による分級である
   ことを、試しの計算で確かめた。§12.3)

### 1.3 既存の仕組みとの関係

- **細粒分の帳簿 f_bedfines**(developer.md §84.10): 2 成分(掃流砂 1 粒径・浮遊砂 1 粒径)の在庫で、
  交換層厚 L_a による利用可能率 min(1, sf/L_a)、組成を保った受け渡し(等移動度)、流出の組成の
  ハロ交換、私有 save を持つ。混合粒径はこの型の一般化として作る。混合粒径では最も細かい粒径階が
  浮遊砂の役を担う(段 2)ので、f_bedfines とは併用しない(役を引き継ぐ)。
- **専用モデル**: Nays2DH・Delft3D・BASEMENT・TELEMAC などは交換層型の混合粒径を標準で持つ。
  ENCflow が持つ意味は、粒径を流域・洪水・土石流と同じ格子・同じ時間発展の連鎖の中で扱えることに
  ある(comparison.md の位置づけ)。精度を専用モデルと競うものではない。

## 3. 定式化

### 3.1 記号と状態

- 粒径階 k = 1..N(粒径 d_k。細かい順)。
- F_k: 交換層の体積割合(ΣF_k = 1)。f_k: 下層の体積割合(Σf_k = 1)。
- L_a: 交換層厚(領域で一様)。実効の交換層厚 L_e = min(L_a, sd)、下層厚 L_s = sd − L_e
  (sd は既存の土層厚 = 可動層厚。z と共動するのは既存と同じ)。
- 柱の粒径階 k の量(かさの厚さ): L_e F_k + L_s f_k。全粒径階の和が sd。
- d_m = Σ F_k d_k(交換層の算術平均粒径。芦田・道上の d_m)。
- 不変条件: 0 ≤ F_k、0 ≤ f_k、ΣF_k = Σf_k = 1。

### 3.2 粒径階ごとの掃流力・限界掃流力・流砂量

- 無次元掃流力: τ*_k = f_τ n² V² / (s d_k h^(1/3))。既存のマニング閉じと同じで、補正(有効掃流力の
  比 fluv_taufac・抵抗分割 f_taupart・斜面に沿うせん断 f_gravity_correction = 2)も同じく掛ける。
  芦田・道上の有効掃流力(f_taupart = 2。2026-11-24。developer.md §121)は、d = d_m で式 (11) の
  (u*e/u*)³ をエッジごとに求め、全粒径階の流束に掛ける(原典の式 (32) の u*e。閾値は全 τ*)。
- 遮蔽係数(修正 Egiazaroff。芦田・道上 1972 式 (31)): ξ_k = τ*c,k / τ*cm で
  - d_k/d_m ≤ 0.4 のとき ξ_k = 0.85 d_m/d_k
  - d_k/d_m > 0.4 のとき ξ_k = {log10 19 / log10(19 d_k/d_m)}²
  
  τ*cm は fluv_tausc(既定 0.05。芦田・道上が混合砂礫の平均粒径の値として使う値。§19 の原典照合)。
  遮蔽なし(比較用)は ξ_k = 1。
- 流砂量(同 式 (32)): q_k = F_k Φ(τ*_k, τ*c,k) √(s g d_k³)。Φ は既存の f_qbform の式で、芦田・道上は
  17 τ*^(3/2) (1 − τ*c/τ*)(1 − √(τ*c/τ*))、MPM は 8 (τ* − τ*c)^(3/2)(τ*c を τ*c,k に置き換える)。
- 定着 f_fixation: 供給側の定着度 a で τ*c,k (1 + c_τ a)(既存と同じ形)。
- **評価の場所**(2026-11-22 決定。§10 の 5): τ*_k はエッジの水理量(既存と同じ両セル平均)、ξ_k は
  両セルの d_m の平均(片側の土層厚が 0 = 岩盤・固定床なら、もう片側の d_m)、利用可能率 F_k と定着度 a は
  供給側(風上)のセルで評価する。向きの補正 γ_k は ξ_k に依存するので、ξ_k を風上で取ると「向き → 風上 →
  ξ_k → 向き」と循環する。この形は循環がなく、既存の作り(エッジの水理量は両セル平均、供給量の制限と
  細粒分の組成は風上)と同じ。ループ 1 は粒径階ごとに、τ*_k と τ*c,k の判定 → γ_k → 向きの射影 → 供給側の
  決定 → F_k と定着度、の順。弱点は組成が急に変わる所で遮蔽が 1 セル分なまることで、検定 T4・T5 や例題で
  問題が出たら、風上の d_m で評価し直す案を検討する。

### 3.3 流砂の向き

既存の q⃗_b/q_b = t̂ + r n̂ − γ ∇z(developer.md §84.3)を粒径階ごとに当てる:
γ_k = (μs μk)^(−1/2) √(τ*c,k / τ*_k)。二次流の項 r は全粒径階で共通。修正 Egiazaroff では、粗い
粒径階ほど τ*c,k/τ*_k が大きく横断斜面を下りやすいので、湾曲部で外岸に粗粒、内岸に細粒が集まる
横断方向の分級が出ると期待できる。検定ではなく例題で確かめる。

### 3.4 河床・交換層・下層の更新(Hirano 1971)

- 全量(既存と同じ): (1 − λ) ∂z/∂t = −∇·Σ_k q_k + 源泉。
- 交換層: (1 − λ) [∂(L_e F_k)/∂t + f_I,k ∂(z − L_e)/∂t] = −∇·q_k。
- 界面の組成 f_I,k: 界面(z − L_e)が下がるとき下層の組成 f_k、上がるとき交換層の組成 F_k。
  堆積時に流砂の組成を重みで混ぜる式(Hoey & Ferguson 1994)は段 3 の候補。
- 下層: 界面が上がるときは交換層の組成で厚くなり、一様に混ぜて f_k を更新する。下がるときは組成を
  変えずに薄くなる。
- 薄い土層: sd ≤ L_a では L_e = sd で下層を持たない。sd = 0(岩盤・固定床)のセルに堆積が始まる
  ときは、入ってくる土砂の組成で交換層を作る。
- 組成の丸め: 負の割合は 0 にして和を 1 に正規化し、正規化で動いた量を台帳に数える(粒径階ごとの
  保存則の検定で、ほぼ 0 であることを確かめる)。

### 3.5 離散化 — 既存の枠組みの粒径階版

- **ループ 1**(エッジの流束): 粒径階 k の流束 Q_k を作る。既存のガード(河岸面の遮断 R1・R2、定着、
  通過幅 frw・動的振り替え fwd、可動層クランプ)は粒径階ごとに同じく掛け、変動上限 dzmax は合計に
  掛ける。作業配列は粒径階ごとのエッジ流束(セルあたり 4N)。
- **ループ 1.5**(供給量制限)を 2 段にする: (a) 合計の流出が sd を超えないよう縮小する(既存の fdon と
  同じ)。(b) 粒径階 k の流出が、交換層にある k の量 L_e F_k(とこの更新で下層から交換層に入る分)を
  超えないよう縮小率 fdon_k を掛ける。fdon と同じくハロ交換して、エッジの両側が同じ値を読む
  (反対称性 = 粒径階ごとの保存)。
- **ループ 2**(発散と更新): 合計で z・sd を共動更新し(既存の式)、粒径階ごとの発散と界面の規則で
  L_e F_k・L_s f_k を更新する。
- **交換層の時間刻み**: 陽解法では、1 回の更新で交換層の粒径階 k が入れ替わる割合が 1 を超えては
  いけない。(b) の制限が構造的に守り、発動回数を台帳に数える(多いときは dt_geomorph を縮めるか
  L_a を厚くする目安として表示)。
- **実装(2026-11-23。developer.md §119.2)**: ループ 1.5 は (b) だけにし、上限は L_e F_k(この更新で
  下層から入る分は数えない保守側)にした。Σ_k L_e F_k = L_e ≤ s_d なので (a) は (b) に含まれる。
  ループ 1 の可動層クランプは粒径階版(エッジ単独の流出 ≤ 供給側の L_e F_k)にした。全粒径階を同じ
  粒径にした極限(T2)で単一粒径の計算に一致させるのに要った。側岸侵食・安息角崩落の等移動度の流束は、
  ループ 2 の前(ループ 1.4)に供給側の更新前の組成で粒径階の流束に直す。
- メモリ(有効時のみ): セルあたり 4N(エッジ流束)+ 2N(組成)+ N(fdon_k)程度。既定の倍精度で、
  N = 8 なら 100 万セルあたり約 450 MB、N = 3 なら約 170 MB。

### 3.6 境界と給砂

- 開境界の流出: 境界セルの組成で、粒径階ごとの容量輸送(既存と同じ判定)。区間流入が作った面から
  流出させない規則(§19.12)も同じ。
- 側方 Neumann: 粒径階ごとに内側の流束を写す。
- 容量給砂(fluv_bcfeed = 1): 流入セルの粒径階ごとの正味流出 × 倍率(倍率 1 で流入セルの z と組成が
  固定。f_bedfines の容量給砂と同じ考え方)。正味流出は粒径階ごとの供給量制限の後の量で数える(制限の前の量で
  数えると、制限が削った分が流入セルに溜まった。developer.md §123.7)。
- 区間流入の給砂(2026-11-22 決定。§10 の 3): 給砂は境界の与件なので組成の既定を置かず(developer.md
  §62)、次のどちらかを必須にする。どちらもなければ初期化で止める。
  - (a) 粒径階ごとの時系列 `fn_inflow_qbmix(n)`: 1 行に時刻 (min) と Qb_1〜Qb_N(m³/s 固体体積)の
    N + 1 個。組成が時間で変わる給砂(国総研のケース 2)に使う。行を文字列で読み、値の数が N + 1 で
    なければ止める。Fortran のリスト入力は、値が足りない行では黙って次の行を読み、余った値は捨てるので、
    既存の fn_inflow_qb の列数を自動で判定する形は採らない。
  - (b) 既存の合計(inflow_qb・fn_inflow_qb)と、一定の組成 `inflow_qbfrac(1:N, n)`(和が 1)。

## 4. 無効時のコストをゼロにする作り

- `f_bedmix = 0`(既定)なら、新しい配列は確保せず、新しい手続きを呼ばず、ハロ交換も増えない。増える
  のは手続きの先頭の整数の判定(セルのループの外)と、型の小さな成分だけ。state.dat も変わらない。
- **既存のループに分岐を入れない**: calc_fluvial の先頭で混合粒径の写し(calc_fluvial_bmix)へ分ける
  (波浪場の掃流砂 calc_fluvial_wfsed と同じ形)。apply_edge_flux・apply_bedfeed・feed_pass・
  neumann_bed_pass も混合粒径用の写しを持ち、呼び出し側(calc_fluvial・calc_repose など)で分ける。
  理由は、実行されない分岐でも -Ofast の FMA 縮約・インライン化が変わり、最終桁が動いた実例が
  あるため(developer.md §90.4)。
- **確かめ方**: 全検定の reference が変わらないこと(無効時ビット一致)と、掃流砂の検定
  (test/fluvial・sedfeed・bendsed)と examples/meander の計算時間を変更の前後で比べる。
- **保守の約束**: 掃流砂のループ 1 を変えるときは 3 か所(calc_fluvial・calc_fluvial_wfsed・
  calc_fluvial_bmix)を同じく変える。それぞれのヘッダに書き、無効時の reference と、全粒径階を同じ
  粒径にした検定(T2)で取りこぼしを見つける。これは有効時・無効時の計算コストではなく、開発の
  コストとして残る。

## 5. 数値上の注意

- **悪設定**: Hirano 型の交換層モデルは、細かい下層へ掘り込む条件などで方程式が双曲型でなくなり
  (特性速度が複素数)、格子を細かくすると振動が速く育つことが知られている(Ribberink 1987、
  Stecca ら 2014、Chavarrías ら 2018)。砂と礫の 2 峰性の河床(国総研の例)では起こりうる。段 1 は
  兆候の診断(格子を細かくした比較、交換層の組成の 2 セル周期の振動の監視)と文書化までとし、
  対策(L_a を厚くする、正則化)は起きたときに議論する。
- **交換層厚への感度**: 文献の目安は表層の D90 の 1〜2 倍(Parker の電子書籍 第 17 章。Parker 2008 は係数を 1 程度の校正値とする。§11)で、既定はその上端の
  2 倍(§3.8)。例題で感度を示す。
- **計算量**(有効時のみ): 掃流砂の計算とハロ交換が粒径階の数にほぼ比例して増える。dt_geomorph
  間隔の間欠実行は既存と同じ。
- **単精度**(PREC=single): 組成の和の丸めは正規化と台帳で扱う。handoff 0c の確認項目に入れる。

## 6. 検定(段 1)

- **T1** 無効時ビット一致: 全検定の reference が変わらない。
- **T2** 全粒径階を同じ粒径にした混合(交換層と下層の組成を同じにする): 合計の河床変化が単一粒径の
  計算と丸め誤差の範囲で一致し、組成が変わらない(遮蔽係数は 1、等移動度の極限)。
- **T3** 粒径階ごとの質量保存: 閉領域と給砂のある水路で、粒径階 k の在庫の変化 = 給砂 − 流出が
  機械精度で成り立つ。
- **T4** アーマー化: 給砂なしの一様水路で、(a) 交換層の平均粒径が単調に増え流砂量が単調に落ちる、
  (b) 終状態で F_k > 0 の全粒径階が限界以下(静的アーマー)、(c) 水深が河床変化より十分大きく水理が
  ほぼ変わらない条件で、上流端のセル(流入がなく流出だけで決まる)の組成の時間変化を、同じ式の
  常微分方程式を Check_*.py で独立に解いた値と比べる。
- **T5** 遮蔽係数と流砂量: 一様流で、下流端の開境界を出た粒径階ごとの体積(台帳)が、式 (31)・(32) の
  値 × 時間に合う(組成がほぼ変わらない短時間)。
- **T6** 給砂: 容量給砂で入口の z と組成が固定される。fn_inflow_qbmix と inflow_qbfrac の粒径階ごとの
  供給が台帳に合い、組成の指定がなければ初期化で止まる。
- **T7** リスタート往復ビット一致、np = 1, 2, 4 が逐次に ULP = 0、-fcheck=all の np = 2(静的データを
  使う構成で)。
- 例題で見るもの: 湾曲部の横断方向の分級、格子の向きによる差、L_a への感度。

3. **給砂の組成**: 既定を置かず、指定を必須にする。給砂は境界の与件で(§62 は与件に既定を置かない)、流入
   セルの組成を既定にすると給砂が河床の状態に引きずられ、固定床(土層厚 0)の流入部では組成が決まらない
   (国総研の流入部の助走区間がそれにあたる。§3.6)。
4. **粒径階の上限**: 8。方針の本文が「数個」で、実務の多くは 3〜6 階で足りる。費用は有効時だけで N に
   比例し、掃流砂の範囲より細かい粒径階は、粒径階ごとの浮遊砂を持たない条件 (3) の下では費用が増える
   だけ。上限は定数 1 個で、必要になれば議論のうえで上げる(§3.8)。
5. **遮蔽係数と利用可能率の評価の場所**: 遮蔽係数は両セルの d_m の平均、利用可能率と定着度は風上(§3.2)。
6. **側岸侵食と安息角崩落で運ぶ組成**: 供給側の交換層の組成。ラスタの河岸の後退は河岸セルの地盤を上から
   下げる表現なので Hirano の帳簿と整合する。交換層の組成は、下げた厚さ / 交換層厚 の指数関数で下層の組成に
   近づくので、交換層厚の数倍を下げれば運ぶ組成はほぼ下層の組成になる。柱の平均で運ぶ案は、
   交換層にだけある粒径階で下層の組成が負になるので取り下げた(§3.7)。非粘着性の河岸で拡幅を抑えるのは
   脚部の交換層の粗粒化で、国総研の二極化の機構がこの経路で出るかは例題で確かめる。

## 12. 段 2c-1: 土石流との併用(2026-11-27 決定・実装)

利用者の依頼(f_debris と f_bedmix を併用したい。用途は天然ダムの決壊 = 例題 debris_dam の一連の過程と、
扇状地の形成とその後の侵食)で、これまで併用を止めてきた理由・費用・利点と案を示し(developer.md §139.1)、
利用者が「全てイエスで進めて」と決めた。実装と検証の記録は developer.md §139。

### 12.1 範囲(方針 6 の例外の追記)

土石流の流動体は、粒径階の組成を受動的に運ぶ場(粒径階ごとの土砂柱)に限って持てる。河床との交換は粒径を
選ばず、土石流の式(平衡濃度・抵抗・交換速度)は代表粒径 `db_d50` の単一粒径のままとする。細粒の間隙流体化と
流れの中の粒径選別は含まない(policy.md 方針 6 の 2026-11-27 の追記)。

### 12.2 決めごと

1. **流れの状態**: 流れの土砂 h_s を粒径階ごとの柱 h_s,k(和が h_s)で持つ。浅水流は柱を 1 本ずつ既存の
   スカラー輸送の核(advect_scalar)で運び、h_s をその和に置き換える。核は柱状量について 1 次の同次式
   (1 次風上は線形、MUSCL の面値も定数倍に対して定数倍)なので、組成が空間に一様なら和は h_s を 1 本で
   運んだ結果に丸めの範囲で一致する。組成が場所で変わる所では、制限関数が粒径階ごとに働く分だけ違う
   (粒径階ごとの保存は厳密)。
2. **侵食で流れに入る組成**: 柱の上から(交換層、下層の順に)取り去った厚さの平均。交換層厚で頭打ちに
   しない(崩落と同じ。§3.7)。典拠は高橋ら (1990) §1 と (1991) 式 (6)。
3. **堆積で河床に入る組成**: そのセルの流れの組成 h_s,k / h_s。乾いたセルへの全量の繰り入れと低速凝集も同じ。
   交換層に入り、Hirano の界面の規則で下層へ移る(§3.4)。
4. **流動化**(斜面安定判定 `f_slide`・瞬時流動化 `fn_dbinit`): 流動化する厚さ(上から `slide_dmax` か全層、
   崩壊深)の柱の組成。
5. **境界から入る土砂の組成**: 必須の与件。一定の組成 `inflow_csfrac(1:N, n)` か、組成の時系列
   `fn_inflow_csfrac(n)`(1 行に時刻 (min) と f_1〜f_N。各行の和が 1)。流入土砂(`inflow_cs`・`inflow_qs`)の
   ある区間にどちらもなければ初期化で止める(給砂の組成と同じ扱い。§3.6)。
6. **代表粒径**: `db_d50` は与件の固定値のまま(単一粒径の式)。
7. **保存と再開**: geomorph_bedmix.dat の末尾に、粒径階の数の印と柱 N 面を足す(併用しない計算の保存は
   以前と同じバイト列)。土石流のない混合粒径の構成に復元したら、柱をその場の河床にその組成で堆積させる
   (浮遊砂 `f_suspend` があれば粒径階 1 は流れに残す)。これで交互計算(土石流 ⇄ 出水)の停止が解ける。
   柱のない保存を併用の構成で復元したときは、復元した h_s を粒径階 1 とする。
8. **当面止める組み合わせ**: ネスティング(柱を格子の間で受け渡さない)、岩盤下刻 `f_rockinc`(土石流による
   岩盤侵食の生成物の組成)、動く底層 `f_bedslide`。
9. **台帳**: 粒径階ごとに、河床から流れへ出た量を河床の側と流れの側の両方で数え、流れの在庫と系外との
   出入り(開いた辺・海セル・水位規定セル)を足して収支の残差を表示する。

### 12.3 用途に対して得られるもの(試しの計算と原典からの整理)

- **天然ダムの決壊のハイドログラフは、併用してもほぼ変わらない**。例題 debris_dam の `dam_ref`(10 m 格子)で、
  同じ平均粒径 3 cm の粒度の幅(0.5・2・8 cm)を持つ堤体にすると、ピークは 396 → 393 m³/s(全粒径階を 3 cm に
  した等粒径の極限は 397 m³/s)。決壊の間は掃流力が全粒径階の限界を大きく超え、掃流砂は全粒径階をほぼ組成の
  比で運ぶ(芦田・道上式は限界を大きく超えると粒径によらない)。土石流の交換は粒径を選ばない。
- **決壊に効く粒径の入力は `db_d50`**(土石流の抵抗と交換速度の d_L)で、掃流砂の粒径より強く効く
  (`db_d50` だけ 10 cm で 0.60 倍、`fluv_d50` だけ 10 cm で 0.87 倍、両方で 0.49 倍)。
- **粒径の幅を決壊の速さに効かせる文献の経路は、細粒の間隙流体化**(高橋ら 1990)。`fluv_sgrav` を変えただけの
  粗い代用(間隙流体の密度 1.1・1.2 に相当)で、ピークは 1.33・1.52 倍になった。これは土石流の力学の
  2 成分化で、段 2c-1 の外にある(§12.4)。
- **混合粒径が効くのは、土石流のあとの流水による侵食**(決壊のあとに残った堤体と下流の堆積、扇状地の水みち)。
  高橋ら (1991) は、扇状地の侵食を平均粒径 1 個で計算して縦侵食が過大になり、アーマーコートを課題に挙げた。

### 12.4 この段の外に残したもの

- **代表粒径を流れの組成から決める**(高橋ら 1991 の d_L = 流動深全体にわたる平均粒径)。材料が 1 種類の計算では流れの平均粒径が
  変わらないので結果は変わらない見込み。材料の違う場所が混ざるとき、境界の組成が時間で変わるときに効く。
- **細粒の間隙流体化**(同 1990 の式 (11)〜(18))。運動方程式・平衡濃度・抵抗に入る 2 成分化で、方針の議論が
  別に要る(利用者は 2026-11-27 に、段 2c-1 のあとに検討を始めると決めた。handoff 00ae)。
- **流れの中の粒径選別**(先端への大礫の集中)。流動深を層に分ける計算で、水深積分の単層の混合体では表せない。

## 13. 段 2c-4: 土石流の式の侵食を動ける粒径階に限る(2026-11-28 決定・実装)

利用者の依頼(段 2c-1 の限界「土石流の式による侵食は、表層が粗くなっても抑えられない」を解く)で、原典を調べ、
試作と 2 つの例題の試しの計算で案を比べて示し(developer.md §143.1〜143.3)、利用者が「全て推奨で」と決めた。
実装と検証の記録は developer.md §143。

### 13.1 範囲(方針 6 の例外の追記)

土石流の式による侵食は、文献の式による動ける粒径階の判定(流動深と、掃流の領域の限界掃流力)に限って粒径を
選べる。既定は選ばない。堆積と流動化は粒径を選ばない(policy.md 方針 6 の 2026-11-28 の追記)。構成則の
代表粒径 1 個と、細粒の間隙流体化・流れの中の粒径選別を含まないことは変えない。

### 13.2 決めごと

1. **入力**: `f_dbsel`(0 = 選ばない。既定、1・2 = 動ける粒径階だけを侵食)と `db_seltan`(流れの型を分ける
   流動面の勾配。既定 0.03)。高橋・中川則 `f_dbed = 3` と混合粒径 `f_bedmix = 1` が要る(なければ初期化で止める)。
2. **動ける粒径階の判定**(§11 の 2001 年の論文の型の区分どおり。利用者に示した案 A):
   - 流向の流動面の勾配(高橋・中川則が平衡濃度に使うのと同じ勾配)が `db_seltan` を超えるセルは、土石流・
     掃流状集合流動の型として、粒径が流動深 h + h_s 以下の粒径階。
   - `db_seltan` 以下のセルは、掃流の型として、限界掃流力を超える粒径階。判定には、混合粒径の掃流砂と同じ
     無次元掃流力(マニング閉じ、有効掃流力の比、斜面に沿うせん断)と遮蔽係数つきの限界 τ*c ξ_k を、その
     セルの値で使う(**独自の当てはめ**。原典の掃流力は水深 × 水面勾配、限界は勾配に依存する式)。
   - 流動深の判定だけを全域で使う案(案 B)は採らない。勾配が緩んだあとの侵食(決壊のあとの決壊口)に
     効かない。型の区分を使わず、流動深の判定と掃流砂の判定の両方を全域で課す案(案 C)も採らない。文献にない
     組み合わせで、掃流砂のマニング型の掃流力が急勾配の土石流の底面のせん断を小さく見積もり、扇状地の形成の
     段の侵食まで止めた(§143.3)。
3. **侵食速度**: 動ける粒径階の交換層の割合の和を K3、粒径を選ばない式の侵食速度(かさ)を i、交換層の割合を
   F_k とする(細粒を別の相にしないので、全粒径階が原典の粗粒子に当たり、f_bLk = F_k)。
   - `f_dbsel = 1`: 粒径階 k の侵食速度 i K3 F_k(原典の式の印字どおり)。河床の低下(かさ)は i K3²。
   - `f_dbsel = 2`: 粒径階 k の侵食速度 i F_k。河床の低下は i K3(原典の本文「i K3 がバルクの侵食速度」)。
   - 動けない粒径階は 0。河床の低下は、どちらも出ていった粒径階の和(粒径階ごとの保存が厳密)。
   - 利用者に 2026-11-28 に示して合意したのは 2 の形(「侵食速度 × 動ける粒径階の交換層の割合の和」。試しの
     計算もこの形)。実装の途中で、原典の式の印字が 1 の形であることを 2000 年の論文で確かめた(英語の論文の
     式 (26) の和の因子は誤植ではなかった)ので、掃流状集合流動の抵抗の指数 `db_immexp` と同じ扱いで、印字
     どおりを 1、本文に合わせた形を 2 とした。薦める形は、例題の結果を見た利用者が 2026-11-28 に 2 と決めた
     (developer.md §143.10)。1 は、式に忠実な形として選べるまま残す。
4. **交換層の更新**: 動けない粒径階があるセルは、交換層から動ける粒径階だけを、その割合の比で取り去る。
   下がった分は Hirano の式(§3.4)で下層の組成が入る。動けない粒径階の表層の割合は F_k(0) + f_k Δ / L_a で
   増える(Δ は侵食深)。全粒径階が動けるセルは、段 2c-1 と同じ取り去り方(柱の上から。交換層厚で頭打ちに
   しない)で、`f_dbsel = 0` の結果と丸めまで同じ。
5. **1 回の更新の上限**: 動けない粒径階があるセルで取り去るのは、交換層にある動ける粒径階の量 L_e K3 まで
   (**独自**。掃流砂の粒径階ごとの供給量制限 §3.5 と同じ考え方。終了時に回数を表示する)。
6. **変えないもの**: 堆積、流動化(斜面安定判定・瞬時流動化)、乾いたセルへの繰り入れと低速凝集、土石流の式の
   粒径 `db_d50`(原典は動ける粗粒子の平均粒径 d_mL)。保存の形式も変えない(新しい状態はない)。
7. **無効時**: 既存の手続き(debris_exchange_bmix)とパス 1・2 のループは変えず、`f_dbsel > 0` のときだけ別の
   手続き(debris_exchange_bmix_sel)を呼ぶ。増えるのは calc_debris の整数の判定 1 回。

### 13.3 用途に対して得られるものと限界

例題の結果は、examples/debris_dam・debris_fan_flume の README と developer.md §144 にある。要点は、
(1) 巨礫を含む堤体の決壊のあとでは、土石流の式を有効にしたままでも、流動面の勾配が `db_seltan` まで緩んだ所で
決壊口の低下がほぼ止まること、(2) 流動深が粒径より浅い薄い流れ(水路実験の扇状地の水みち)では侵食を止めすぎること、
(3) 最も粗い粒径階が流動深と同じ程度の計算(巨礫を含む堤体の決壊)は、決壊が遅れ、その時刻とピークが判定の
形(1・2)に敏感なこと。

### 13.4 この段の外に残したもの

- 式に使う粒径を、動ける粗粒子の平均粒径にすること(§12.4 の「代表粒径を流れの組成から決める」と同じ項)。
- 掃流の型の判定を、原典の式(水深 × 勾配の掃流力と、勾配に依存する限界)にすること。
- 細粒の間隙流体化と、流れの中の粒径選別(§12.4)。
