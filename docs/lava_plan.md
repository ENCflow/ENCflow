固化しなかったため。developer.md §51.5)。また、固化したセルの土層を溶岩の
下に埋める(sd → 0)ようにした(§5。土層が溶岩の上に残っていたため。
developer.md §51.6)。
残る将来枠は段階2(温度1変数。§8)。

## 1. 位置づけと方針適合(なぜ独立モジュールか)

火山系の「密度流」(岩屑なだれ・dense 火砕流・ラハール)は debris の
等価流体モード(developer.md §28.8、debris_plan.md §5)で実装済みだが、
**溶岩流は物理が別物**であり、既存部品の読み替え(雪崩方式)では閉じない:

1. 支配抵抗が粒状摩擦・乱流でなく**粘性**(η = 10²〜10⁷ Pa·s)。
2. **冷却 → 粘度・降伏応力の桁変化 → 固化**という時間軸の物理が本質
   (等価流体モードは τ_y・μ 定数を明言した割り切り)。
3. 間隙水を含まない一相の融体。debris の疑似間隙水近似(§5.2 案a)を
   溶岩に使うと水収支を汚し、**降雨と同居させる目的**(§4)と矛盾する
   (雨水が溶岩の「キャリア水」と混ざる)。
4. 水と溶岩は速度が桁で違い、同じ運動量場(swflow の u,v)を共有できない。

そこで **m_glacier と同型の独立モジュール m_lavaflow** とする。力学は
深さ平均 Bingham 粘性重力流(潤滑近似)で、溶岩厚 hl の
**非線形拡散方程式 1 本**に帰着する(§3):

- **§0-5「水平は SWE+1方程式拡散が上限」の範囲内**。鉛直の速度分布
  (降伏面より下のせん断層+上のプラグ流)は解析的に深さ平均されて
  フラックス式に抽象化される = SIA と同じ構図。
- 離散化は calc_creep・m_gwflow_lateral・m_glacier と同じ
  **保存形2ループ+エッジ反対称フラックス+ドナー律速+ハロ交換**の型に
  そのまま乗る。溶岩体積は機械精度で保存される。
- 慣性を落とす近似の適用限界: 高速のチャネル化した玄武岩溶岩流
  (数 m/s)では慣性・チャネル形成が効くため精度は落ちる。ハザード
  概算(到達範囲・堆積厚)としては粘性重力流近似が実務水準
  (溶岩流モデルの多数派は CA/拡散系)であり、「複数プロセスの
  同時概算」(§0-4)には十分と判断する。
- 有効化は fn_lavaflow(§0-7)。無効時メモリ・CPU 追加ゼロ(§0-8)。
  η・τ_y・ρ は直接入力(§0-12: 物理量は直接与える)。

## 2. スコープの線引き(有効化しないものの明言)

- **対象内(段階1)**: 噴火口セル群からの湧き出し(噴出率ハイドロ
  グラフ)、等温 Bingham 粘性流動、降伏による停止、停止溶岩の固化
  → s%z への転換(溶岩原・溶岩堤の地形化)、固化後の降雨・洪水・
  土石流の連鎖(同一ラン。追加実装なしで自動)。溶岩ドームは、降伏応力で
  支えられた静止形(塑性ドーム。Blake 1990)の概算までを対象とする
  (2026-11-03 に users_guide の型別表で「適用外」から改めた。等温 Bingham の
  静止形は解析解と一致することを test/lava 構成 4 で確かめている)。
- **対象内(段階2。設計案 2026-11-03、合意待ち)**: 深さ平均温度 1 変数(移流+放射・対流
  冷却+噴出温度)、η(T)・τ_y(T)、温度による固化判定(§8)。
- **対象外(有効化しない)**:
  - 溶岩と水の熱的相互作用(水蒸気爆発・急冷破砕・laze)。溶岩が水域に
    入る挙動は「水を無視して z の上を広がる」概算になる(§5)。
  - 雪氷の融解によるラハール生成(glacier/snow が受け皿として存在する
    ため将来枠に記録。当面は融雪水を境界・降雨入力で与える —
    火砕流の融雪型泥流と同じ扱い。handoff 1j-(iv))。
  - 溶岩トンネル・チューブ流(gwconduit_plan.md §3 が同型適用の候補と
    して記録済み。本モジュールとは別系)。
  - パホイホイ/アア遷移・表面形態、インフレーション、3次元的な
    溶岩堤の力学(堤は「固化 → z → 後続流を誘導」の範囲で自然に出る
    ものだけ)。
  - 噴煙・降灰(debris_plan.md §5.1 で対象外宣言済み。堆積灰は前処理で
    z/sd へ)。
  - 溶岩ドームの崖錐(表面が割れて崩れた岩塊の斜面。実際のドームの急な
    側面)、内側から膨らむ成長(内成的成長)、ドームの崩落とそれによる
    火砕流(崩落は debris の f_release で別に与える)。

## 3. 定式(段階1: 等温 Bingham 粘性重力流)

溶岩厚 hl(m)、溶岩面 s = z + hl、面勾配 S = |∇s|。基底せん断応力
τ_b = ρ g hl S が降伏応力 τ_y 以下なら不動。超えるとき、降伏面より
下のせん断層+上のプラグ流を深さ平均した単位幅フラックス(Bingham
潤滑流の標準解):

```
h0 = τ_y / (ρ g S)                     降伏に必要な最小厚(S→0 で発散=平坦では不動)
q  = 0                                  (hl ≤ h0)
q  = (ρ g S / 6η) (hl−h0)² (2 hl+h0)   (hl > h0。τ_y=0 で q = ρgS hl³/3η の Newton 極限)
∂hl/∂t = −∇・q + Q_vent/A − w_sol
```

- 拡散形 q = −D ∇s、D = (ρg/6η)(hl−h0)²(2hl+h0)。SIA(D ∝ H⁵|∇s|²)と
  同族の非線形拡散で、m_glacier の離散化・サブサイクル機構(§6)を
  そのまま踏襲する。
- エッジ係数は 4 近傍・両セル平均の hl と、エッジの勾配の大きさ
  |∇s| = √(法線勾配² + 接線勾配²) から作り、エッジの向きは線形項
  Δs/dist(法線勾配)の射影にだけ使う(Mahaffy 1976 の考えの 4 近傍版。
  接線勾配はエッジ両側の溶岩のあるセルの、エッジに沿う方向の溶岩面の
  差分の平均)。起案時は glacier G2 と同じ法線勾配だけの評価だったが、
  斜め 45° で勾配が 1/√2 に見えて降伏応力が実質 √2 倍になり、平坦床の
  ドームが格子軸の方向に伸びたひし形になったため変更した(2026-11-03。
  developer.md §51.4。test/lava 構成 4 が検出器)。ドナー律速(1エッジの
  持ち出し ≤ ドナー溶岩体積の 1/4)で hl ≥ 0 を構造的に保証。
- 停止は降伏が内包する: 斜面 tanθ での最終厚 h∞ = τ_y/(ρg tanθ)
  (検証の解析解。§9)。
- パラメータ(&list_lavaflow 直接入力): lv_rho(kg/m³。玄武岩質
  ~2600)、lv_visc(Pa·s)、lv_tauy(Pa。0 = Newton 流体も許す)。
  **レオロジーはラン全体で 1 組**(噴火口毎の粘度指定はしない —
  合流時に混合則=粘度の移流場が必要になり複雑化に見合わない。
  粘度差の実体は温度・組成であり、段階2の温度従属+噴火口毎の
  噴出温度で表現するのが §0-12 に整合する。2026-08-23 討議の合意)。

## 4. 噴火口ソース(湧き出し)

- **モジュール私有のソース**とする(&list_lavaflow 内。水の
  &list_bound_source は流用しない — あれは s%h に注ぐ機構。私有ソースの
  前例は m_gwflow_pump の井戸シンク)。
- 書式は src_cell/src_val と同型のセル列挙+時系列(第3添字が噴火口番号):

```
&list_lavaflow
  lv_rho  = 2600.0
  lv_visc = 1.0e4
  lv_tauy = 2000.0
  lv_wsol = 0.005                ! 固化レート(m/s。§5)
  lv_vsol = 5.0e-4               ! 停止判定の速度閾値(m/s。§5)
  lv_cell(1:2,1,1) = 55, 40      ! 噴火口1のセル(i, j)
  lv_cell(1:2,2,1) = 55, 41
  lv_val(1:2,1,1) =    0,  0.0   ! (時刻(min), 総噴出率(m3/s))
  lv_val(1:2,2,1) =   60, 10.0
/
```

- 総噴出率をセル集合へ均等分配(内部ソースと同じ規約)。指向性
  (運動量)は持たない — 拡散型に運動量入力は存在しないため自然。
- 割れ目噴火はセル列挙で表現。複数噴火口・時間差噴火は第3添字で。
- f_release 型(初期堆積の一斉解放)は溶岩には不要(ドーム崩落は
  debris の管轄)。
- list_lavaflow は namelist を読むだけ。範囲検査・単位換算(min→s)・
  セルの担当帯判定は m_lavaflow_init(§12 の層契約)。

## 5. 固化と地形結合(唯一の必須インタラクション)

- **固化(段階1の数値的閉包)**: エッジ深さ平均速度 u = D・S/he(S は
  §3 のエッジの勾配の大きさ)の最大が閾値 lv_vsol 未満の「停止セル」の
  hl を、レート lv_wsol
  (m/s)で s%z へ転換する。**速度閾値+レートは f_dbstop=1
  (db_vstop/db_wstop)と同じ閉じ方**。起案時は「全エッジのフラックスが
  0 の不動セル」判定だったが、Bingham の停止は漸近的
  (q ∝ (h−h∞)² → 0 だが有限時間で厳密 0 に達しない)で発火しない
  ことが実装中に判明し、速度閾値方式へ変更した(2026-08-23)。
  流動中のセル・供給を受けるセルは閾値を超えるため固化しない =
  活動的なチャネルは開いたまま、というマクロ挙動が出る。閾値の
  目安は 1e-4〜1e-3 m/s(小さいほど停止厚が h∞ に近づくが判定まで
  時間がかかる。停止厚の上振れ ≈ √(v_sol·h/(coef·(2h+h0)·S)))。
  数えるのは溶岩が動けるエッジだけで、溶岩面の高い側(送り手)に溶岩が
  ない流れ込みのエッジは数えない(流量はドナー律速で 0。2026-11-03 に追加 —
  数えていたため、溶岩より高い乾いたセル〔谷壁・先に固まった溶岩の縁〕に
  接するセルが、流れ込むはずのない上り勾配のエッジを流速とみなして固化
  しなかった。developer.md §51.5。test/lava 構成 5 が検出器)。
  物理的な固化則(クラスト成長 ∝ √t、温度判定)は段階2(§8)。
- **z の更新契約**(geomorph/glacier と同じ): Δz 適用と同一ループで
  s%e = s%z + s%h を回復し、ステップ末に s%z のハロ交換まで行う。
- **sd は増やさない**: 固化溶岩は侵食されない岩盤 → z のみ増加
  (z−sd の基岩が厚くなる)。f_dbstop の z・sd 共動(停止デブリ=
  可動堆積物)とは意図的に異なる。後続の fluvial 基岩侵食則が固化面に
  作用するのは「溶岩の河川侵食」の抽象として受容。
- **固化したセルの土層は埋める**(2026-11-03。developer.md §51.6): 溶岩が
  固化したセルにあった土層 sd は溶岩の下に埋まる → sd = 0(土層の内数 hb・
  sf・ht と定着度 fx も 0)。地下水計算が有効なら、容量を失った地下貯留を
  地表水へ移す(水は保存)。起案時は土層をそのまま残し、溶岩の上に土層が
  残る(土層ごと持ち上がる)扱いになっていた。土層が 1 層なので、埋まった
  土は後で掘り出されても岩盤として扱われる。
- **再流動なし**: 固化は不可逆(z は恒久)。後続の溶岩は固化面の上を
  流れる(溶岩堤・溶岩原の積層が z の履歴として残る)。
- 台帳: Σhl + Σ(z−z0)_溶岩分 = ∫Q dt が機械精度で成立すること
  (総和は par_sum_rows。固化累計は私有台帳に記録し dispose で報告)。

## 6. 時間刻み(適応サブサイクリング)

D = (ρg/6η)(hl−h0)²(2hl+h0) は hl³/η のオーダーで変動する。目安:

| 溶岩 | η (Pa·s) | hl=3m, dx=10m の D | 陽解法 dt 上限 dx²/4D |
|---|---|---|---|
| 流動性の高い玄武岩質 | 10² | ~2400 m²/s | ~0.01 s |
| 玄武岩質 | 10³〜10⁴ | ~24〜240 m²/s | ~0.1〜1 s |
| 安山岩質〜 | ≥10⁵ | ≤2.4 m²/s | ≥10 s |

- glacier §2.3 と同じ**動的サブサイクル**: 毎 dt、その時点の D_max
  (allreduce_max = 全ランク同一 → collective 安全)から分割数を決め、
  サブサイクル毎に hl のハロ交換。上限 lv_nsubmax で暴走ガード。
- 水文 dt(洪水計算で 0.1〜1 s)に対し、η ≥ 10³ ならサブサイクルは
  数回以内で済む見込み。η = 10² の大規模玄武岩ではコストが立つ —
  それは慣性が効き始める領域でもあり、拡散近似の適用限界と同じ場所に
  コスト限界が来る(限界の一致は設計として健全)。実測して users_guide に
  適用目安を書く。

## 7. 実装契約の要点(m_glacier の様式を踏襲)

- **状態**: s%hl(m 溶岩柱。有効時のみ確保)。場出力 Hl(+累積固化厚の
  私有場を出力候補に。名称は実装時)。リスタートは私有ファイル
  lavaflow.dat(契約5: dispose 内で save。save_version 同時更新)。
  S 台帳への算入は行わない(水当量でないため。私有台帳で報告)。
- **実行順序**: geomorph_calc・driftwood_calc の後、calcstat の前
  (z 更新プロセスの末尾に追加。§2.2 の順序表の更新まで同じ作業に
  含める。水と直接の読み書き共有がないため順序依存は z のみ)。
- **並列**: owner-compute(js..je)+エッジ反対称+ハロ交換。
  噴火口セルの担当判定は帯所属で(全ランクが namelist を読み、自帯の
  セルだけ注入 — collective 判定は全ランク同一)。np=1,2,4 ULP=0。
- **STG 非対応**(z の時間発展。geomorph/glacier と同じ init ガード)。
  morfac 非対応 = 1 に限定(イベント計算。debris と同じ init 検査)。
- **水理との関係(抽象化)**: 地表水 s%h は流動中の溶岩に不可視で
  **z の上を流れる**(glacier §5「氷は水理に不可視」と同じ割り切り)。
  固化した分だけ z が上がるので、固化後の水理は自動的に新地形に従う。
  流動中の溶岩上の降雨は溶岩を素通りして z 上の h に入る(既知の妥協。
  溶岩活動域は通常狭く、洪水計算への影響は小さい)。
- **粗度は変更しない(段階1)**: 固化面の rn は既存分布のまま(§0-6
  徐々に精緻化)。浸透係数(K_sv)も変えないが、固化したセルは土層が
  埋まる(§5)ので、土層を地下水の層とするモデル(Green-Ampt・側方流)
  では容量が 0 になり、溶岩の上には雨がしみ込まない(2026-11-03 から。
  実際の新しい溶岩は割れ目が多く透水性が高いことが多いので浸透を過小に
  見積もる。溶岩の透水性の表し方は将来枠)。

## 8. 段階2: 温度 1 変数(設計案。2026-11-03 起案、利用者との合意待ち)

段階1 の等温モデルの最大の限界は、溶岩が冷えて止まることを表せない点にある。流れの長さが
噴出率と冷却で決まる関係(Walker 1973)が出ず、降伏応力を「冷えて止まる効果を含めた実効値」
として校正する必要がある(examples/shield_volcano で実測の 10 倍)。停止判定も速度閾値の数値的な
閉じ方で、止まった厚さの上振れや、厚い舌の先端が流れ続ける問題がある(examples/stratovolcano で
溶岩の 3〜6% をドライバが固化扱い)。段階2 は、深さ平均温度 1 変数を足して、これを冷却で閉じる。

### 8.1 範囲(方針 §0 との整合)

- 対象内: 深さ平均温度 Tl の移流(溶岩フラックスに乗せる)、表面からの放射・対流の冷却、
  噴火口ごとの噴出温度、温度による粘度・降伏応力の変化、温度による固化。
- 対象外(段階2 では扱わず、限界として明記): 表面の殻と内部を分けた鉛直構造(FLOWGO 型の
  3 層。Harris & Rowland 2001)、結晶化の潜熱(有効比熱に含めて与えるのは可)、地面への熱伝導、
  粘性発熱、溶岩と水の熱的相互作用、溶岩トンネル。
- 方針との整合: 平面 2 次元・深さ平均で、鉛直は抽象化する。流れの式は増やさず、溶岩の流れが
  運ぶスカラー 1 つを足す(水質の濃度と同じ型)。有効化は f_lvtemp = 1 で、無効時は状態を
  確保せず計算もしない(既存の結果とビット一致)。物理量は直接与える。
- 先行例: 深さ平均の厚さ・速度・温度の式で溶岩流を解き、粘度を温度の指数関数にした
  Costa & Macedonio (2005)。表面からの放射だけで冷やし、温度で粘度を変える Bingham の
  セルオートマトン MAGFLOW(Vicari et al. 2007、Del Negro et al. 2007)。本設計はこの 2 つに近い。

### 8.2 状態変数

- s%tl: 深さ平均温度 (°C)。f_lvtemp = 1 のときだけ確保(帯+ハロ)。溶岩のないセル(hl = 0)
  では意味を持たない(出力では 0)。
- 移流で保存する量は熱量 hl·Tl(柱状 m × °C。ρ c_p を掛けると単位面積あたりの熱量)。
  放射の計算だけ絶対温度 (K) に直す。

### 8.3 支配方程式(深さ平均)

  ∂(hl Tl)/∂t + ∇·(q T*) = Σ_噴火口 (Q/A) T_v − (F_rad + F_conv) / (ρ c_p)

- q は段階1 と同じ溶岩のエッジ流量(拡散形・ドナー律速)。T* はエッジの上流側(送り手)の
  温度(風上)。
- T_v: 噴火口の噴出温度(噴火口ごと)。注入した溶岩は注入先の溶岩と熱量で混ざる。
- 放射: F_rad = ε σ (Tl_K⁴ − Ta_K⁴)。対流: F_conv = h_c (Tl − Ta)。Ta は気温(fn_meteo があれば
  セルの気温、なければ定数)。
- 地面への伝導・潜熱・粘性発熱は入れない(§8.1)。

### 8.4 冷却の表し方(案の比較)

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A(推奨) | 深さ平均温度 Tl から、有効放射率 ε で放射する。表面の殻の断熱は ε を下げることで抽象化 | パラメータ 1 つ。MAGFLOW と同じ型 | 動いている溶岩(殻が割れて熱い)と止まった厚い溶岩(殻が厚く断熱)を 1 つの ε で表すので、どちらかがずれる。厚い溶岩だまりは実際より早く冷える |
| B | FLOWGO 型: 殻の被覆率 f と殻の温度 T_c から表面温度を作り、殻と割れ目を別に放射させる | 殻の効果が物理的。FLOWGO の既定(被覆率 0.6、殻 827 °C)が出発点 | パラメータが 2〜3 個増える。被覆率は本来流速で変わる(FLOWGO は 1 次元の流路用) |

最小版は案 A とし、校正の対象は「流れの長さ」とする。厚い溶岩だまりの固化の時刻は当てにならない
ことを限界として書く。案 B は結果を見てからの拡張にする。

### 8.5 レオロジーの温度依存

  η(T) = η_r exp(−β_η (T − T_r))、 τ_y(T) = τ_r exp(−β_τ (T − T_r))

- η_r・τ_r は既存の lv_visc・lv_tauy を「基準温度 T_r での値」として読み替える(等温モードでは
  従来どおり)。β_η・β_τ は温度感度 (1/K)。指数則は Costa & Macedonio (2005) の粘度と同じ形で、
  log η が温度の 1 次式になる経験式(MAGFLOW などが使う型)とも同じ。
- エッジの温度は両セルの熱量の加重平均 T_e = (hl_c Tl_c + hl_n Tl_n)/(hl_c + hl_n) とし、
  エッジの係数 ρg/(6 η(T_e)) と降伏最小厚 τ_y(T_e)/(ρ g S) を求める。β = 0 なら係数は等温と
  同じ式・同じ値になる(検定 §8.10 の構成 8 で、流れが等温モードとビット一致することを確かめる)。

### 8.6 停止と固化

- 流れの停止は、冷えて降伏応力が上がることで起きる(冷却で止まる流れ)。
- 固化は温度で判定する: Tl ≤ T_sol(固化温度)のセルの溶岩を、そのセルで全量 z へ移す
  (深さ平均温度が固化温度を下回ったら柱全体が固まったとみなす)。土層の埋没(§5)は同じ。
- 温度モードでは速度閾値の閉じ方(lv_vsol・lv_wsol)は使わない。止まっても熱いうちは固まらず、
  冷えてから固まる。

### 8.7 数値解法と並列

1 回の更新(dt_lavaflow)の中の順序(契約):

1. 噴火口の注入: hl に dh を足し、熱量に dh·T_v を足して Tl を混合温度にする(owner-compute)。
2. hl・Tl のハロ交換。
3. 流動のサブサイクル(段階1 と同じ骨組み):
   - パス A: エッジの温度 T_e から係数を作り、D_max → dt_sub(粘度が最も低い熱い溶岩が
     刻みを決める)。
   - パス B: 溶岩のエッジ流量 q(段階1 と同じドナー律速)と、熱のエッジ流量 q·T*(風上の温度)。
   - パス C: hl と熱量を発散で更新し、Tl = 熱量 / hl。風上とドナー律速の組み合わせで、新しい
     Tl は前の時刻の近傍の温度の凸結合になる(温度の新しい最大・最小は生まれない)。
   - hl・Tl のハロ交換。
4. 冷却: セルごとに dTl/dt = −(F_rad + F_conv)/(ρ c_p hl) を、更新の刻み dtw ごとに後退
   Euler で積分する(ニュートン法数回。右辺が Tl について単調なので収束し、Tl は Ta を下回らない)。
   薄い溶岩ほど速く冷える(時定数 ∝ hl)が、陰解法なので刻みの制約はない。失った熱量を台帳へ。
5. 固化: Tl ≤ T_sol のセルの hl を z へ(§8.6)。e の回復と z(・sd ほか)のハロ交換。

- 決定性: すべてセル・エッジごとの決まった順の計算と、既存の決定的な総和だけを使い、
  逐次と MPI np=1,2,4 でビット一致させる(段階1 と同じ規律)。
- 気温: m_lavaflow_calc に気象の構造体を渡して meteo_temp_cell で読む(glacier と同じ)。
  公開インターフェースの変更なので、トップレベル make で utils の追随を確かめる(§10 規約)。

### 8.9 出力・台帳・保存

- 分布出力 Tl(°C。溶岩のあるセルだけ、ほかは 0)。f_lvtemp = 1 で自動。
- 熱の台帳(dispose で表示): 噴出した熱量、放射と対流で失った熱量、固化した溶岩の熱量、残る溶岩の
  熱量。噴出 = 放射 + 対流 + 固化 + 残存 が丸めの範囲で閉じることを検定する(0 °C 基準の顕熱)。
- リスタート: lavaflow.dat に Tl を加える(save_version を更新。§7 の規約)。

### 8.11 時間の扱いと計算量

- 冷却は実時間で進むので、段階1 の例題のように粘度を大きくして時間を縮めることはできない。
  実際の粘度(玄武岩で 10²〜10⁴ Pa s)で計算する必要がある。
- サブサイクル数は、噴火口近くの最も熱い(粘度の低い)溶岩の粘度にほぼ反比例する。粗い見積もり:
  examples/shield_volcano(粘度 10⁶ Pa s、20 回の噴火で約 6 分)を粘度 10⁴ Pa s で計算すると
  約 100 倍(10 時間程度)、10³ Pa s なら約 1000 倍。1 回の噴火の到達範囲を求める用途なら
  数十分〜数時間、多数の噴火を重ねる地形の実験には向かない(等温モードを使う)。

- developer.md §51 に実装記録、users_guide/lavaflow.md(日英)に温度モードの節(できないこと・

- 例題は検証の後で別に決める(1 回の噴火の到達範囲を噴出率で比べる例など)。既存の例題

### 8.13 決めること(利用者との合意事項)

1. 冷却の表し方: 案 A(有効放射率。推奨)か案 B(殻の被覆率と温度)か。
2. 固化: 温度だけで判定する(推奨)か、速度閾値の閉じ方も残すか。
3. 潜熱・地面への伝導・粘性発熱: 最小版では入れない(推奨。潜熱は有効比熱で代用可と明記)か。
4. 既定値: 溶岩の種類で変わる値は明示指定、放射率・対流係数・比熱は原典を確かめて既定を置く
   (推奨)か。
5. 実装の順: 最小版(案 A + 温度による固化 + 指数則)→ 検証 → 文書 → 例題は後日(推奨)。

## 9. 検証(test/lava。2026-08-23 実施済み — 記録の正本は §51.3)

- **構成1(Newton 極限・Huppert 相似解)**: 平坦床・中央1セル定率供給。
  先端半径 r_N(t) = 0.715 (g Q³/3ν)^{1/8} t^{1/2}(Huppert 1982)に対し
  面積等価半径の誤差 8.5%(tol 10%)、成長則 r(tt)/r(tt/2) は √2 に
  誤差 0.6%、台帳 Σhl は機械精度(3e-13 m³)。
- **構成2(Bingham 停止・固化)**: 等勾配斜面 tanθ=0.2・列噴火口の
  300 s 供給。停止厚 h∞ = τ_y/(ρg tanθ) に誤差 7.1%(tol 20%。
  lv_vsol 打切りの上振れを含む)・CV 0.001、固化率 1.000、台帳
  Σhl+Σdz 機械精度(1e-11 m³)。停止の漸近が遅いため、検定は
  「検定時間内に排水が h∞ 近傍へ届く粘度」で組む(η=2e3・tt=4800 s)。
- **構成4(等方性。2026-11-03 追加 — 記録の正本は §51.4)**: 平坦床・中央1セルの
  定率噴出(τ_y = 10⁴ Pa・固化なし)が止まった形を、塑性ドームの静止形
  h(r)² = (2τ_y/ρg)(R − r) と比べる。格子軸の方向と斜めの方向の扇形の面積等価
  半径の比 1.014、中心厚 +1.2%、面積等価半径 −1.5%(法線勾配だけの旧方式では
  比 0.860・中心厚 +9.5% のひし形)。
- **構成5(壁の前の溶岩だまり。2026-11-03 追加 — 記録の正本は §51.5)**: 平坦な床と
  高さ 10 m の段。壁の前にたまった溶岩が、壁に接する列まで全量固化すること
  (固化率 1.0000。流れ込みのエッジを数えていた旧判定では 0.869 で、壁際の列が
  溶けたまま残った)。
- **構成6(土層の埋没。2026-11-03 追加 — 記録の正本は §51.6)**: 構成5 の地形に
  土層と Green-Ampt の地下水を加え、固化した溶岩の下の土層が埋まり(sd = 0、
  hg = 0)、しみ込んでいた水が地表へ移っても水の総量が保存されること。
- **共通規律**(CLAUDE.md): 無効時に全22回帰ケースがビット一致
  (逐次+MPI np=2)、-fcheck=all np=2 を最適化検証より先に実行、
  -O2 厳密数学で逐次 = np=1,2,4 バイト一致、リスタート往復バイト一致。
  reference 比較は使わない(解析解検定で閉じる = volcano と同じ流儀)。
