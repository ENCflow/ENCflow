## 1. 位置づけと方針適合(なぜ独立モジュールか)

火山系の「密度流」(岩屑なだれ・dense 火砕流・ラハール)は debris の
等価流体モード(developer.md §28.8、debris_plan.md §5)で実装済みだが、
**溶岩流は物理が別物**であり、既存部品の読み替え(雪崩方式)では閉じない:

1. 支配抵抗が粒状摩擦・乱流でなく**粘性**(η = 10²〜10⁷ Pa·s)。
2. **冷却 → 粘度・降伏応力の桁変化 → 固化**という時間軸の物理が本質
   (等価流体モードは τ_y・μ 定数を明言した割り切り)。
3. 間隙水を含まない一相の融体。debris の疑似間隙水近似(§5.2 案a)を
   溶岩に使うと水収支を汚し、**降雨と同居させる目的**(§4)と矛盾する
   (雨水が溶岩の「キャリア水」と混ざる)。
4. 水と溶岩は速度が桁で違い、同じ運動量場(swflow の u,v)を共有できない。

そこで **m_glacier と同型の独立モジュール m_lavaflow** とする。力学は
深さ平均 Bingham 粘性重力流(潤滑近似)で、溶岩厚 hl の
**非線形拡散方程式 1 本**に帰着する(§3):

- **§0-5「水平は SWE+1方程式拡散が上限」の範囲内**。鉛直の速度分布
  (降伏面より下のせん断層+上のプラグ流)は解析的に深さ平均されて
  フラックス式に抽象化される = SIA と同じ構図。
- 離散化は calc_creep・m_gwflow_lateral・m_glacier と同じ
  **保存形2ループ+エッジ反対称フラックス+ドナー律速+ハロ交換**の型に
  そのまま乗る。溶岩体積は機械精度で保存される。
- 慣性を落とす近似の適用限界: 高速のチャネル化した玄武岩溶岩流
  (数 m/s)では慣性・チャネル形成が効くため精度は落ちる。ハザード
  概算(到達範囲・堆積厚)としては粘性重力流近似が実務水準
  (溶岩流モデルの多数派は CA/拡散系)であり、「複数プロセスの
  同時概算」(§0-4)には十分と判断する。
- 有効化は fn_lavaflow(§0-7)。無効時メモリ・CPU 追加ゼロ(§0-8)。
  η・τ_y・ρ は直接入力(§0-12: 物理量は直接与える)。

## 2. スコープの線引き(有効化しないものの明言)

- **対象内(段階1)**: 噴火口セル群からの湧き出し(噴出率ハイドロ
  グラフ)、等温 Bingham 粘性流動、降伏による停止、停止溶岩の固化
  → s%z への転換(溶岩原・溶岩堤の地形化)、固化後の降雨・洪水・
  土石流の連鎖(同一ラン。追加実装なしで自動)。
- **対象内(段階2。将来枠)**: 深さ平均温度 1 変数(移流+放射・対流
  冷却+噴出温度)、η(T)・τ_y(T)、温度による固化判定(§8)。
- **対象外(有効化しない)**:
  - 溶岩と水の熱的相互作用(水蒸気爆発・急冷破砕・laze)。溶岩が水域に
    入る挙動は「水を無視して z の上を広がる」概算になる(§5)。
  - 雪氷の融解によるラハール生成(glacier/snow が受け皿として存在する
    ため将来枠に記録。当面は融雪水を境界・降雨入力で与える —
    火砕流の融雪型泥流と同じ扱い。handoff 1j-(iv))。
  - 溶岩トンネル・チューブ流(gwconduit_plan.md §3 が同型適用の候補と
    して記録済み。本モジュールとは別系)。
  - パホイホイ/アア遷移・表面形態、インフレーション、3次元的な
    溶岩堤の力学(堤は「固化 → z → 後続流を誘導」の範囲で自然に出る
    ものだけ)。
  - 噴煙・降灰(debris_plan.md §5.1 で対象外宣言済み。堆積灰は前処理で
    z/sd へ)。

## 3. 定式(段階1: 等温 Bingham 粘性重力流)

溶岩厚 hl(m)、溶岩面 s = z + hl、面勾配 S = |∇s|。基底せん断応力
τ_b = ρ g hl S が降伏応力 τ_y 以下なら不動。超えるとき、降伏面より
下のせん断層+上のプラグ流を深さ平均した単位幅フラックス(Bingham
潤滑流の標準解):

```
h0 = τ_y / (ρ g S)                     降伏に必要な最小厚(S→0 で発散=平坦では不動)
q  = 0                                  (hl ≤ h0)
q  = (ρ g S / 6η) (hl−h0)² (2 hl+h0)   (hl > h0。τ_y=0 で q = ρgS hl³/3η の Newton 極限)
∂hl/∂t = −∇・q + Q_vent/A − w_sol
```

- 拡散形 q = −D ∇s、D = (ρg/6η)(hl−h0)²(2hl+h0)。SIA(D ∝ H⁵|∇s|²)と
  同族の非線形拡散で、m_glacier の離散化・サブサイクル機構(§6)を
  そのまま踏襲する。
- エッジ係数は 4 近傍・両セル平均の hl と法線勾配(Mahaffy 型 =
  glacier G2 と同じ)。ドナー律速(1エッジの持ち出し ≤ ドナー溶岩体積の
  1/4)で hl ≥ 0 を構造的に保証。
- 停止は降伏が内包する: 斜面 tanθ での最終厚 h∞ = τ_y/(ρg tanθ)
  (検証の解析解。§9)。
- パラメータ(&list_lavaflow 直接入力): lv_rho(kg/m³。玄武岩質
  ~2600)、lv_visc(Pa·s)、lv_tauy(Pa。0 = Newton 流体も許す)。
  **レオロジーはラン全体で 1 組**(噴火口毎の粘度指定はしない —
  合流時に混合則=粘度の移流場が必要になり複雑化に見合わない。
  粘度差の実体は温度・組成であり、段階2の温度従属+噴火口毎の
  噴出温度で表現するのが §0-12 に整合する。2026-08-23 討議の合意)。

## 4. 噴火口ソース(湧き出し)

- **モジュール私有のソース**とする(&list_lavaflow 内。水の
  &list_bound_source は流用しない — あれは s%h に注ぐ機構。私有ソースの
  前例は m_gwflow_pump の井戸シンク)。
- 書式は src_cell/src_val と同型のセル列挙+時系列(第3添字が噴火口番号):

```
&list_lavaflow
  lv_rho  = 2600.0
  lv_visc = 1.0e4
  lv_tauy = 2000.0
  lv_wsol = 0.005                ! 固化レート(m/s。§5)
  lv_vsol = 5.0e-4               ! 停止判定の速度閾値(m/s。§5)
  lv_cell(1:2,1,1) = 55, 40      ! 噴火口1のセル(i, j)
  lv_cell(1:2,2,1) = 55, 41
  lv_val(1:2,1,1) =    0,  0.0   ! (時刻(min), 総噴出率(m3/s))
  lv_val(1:2,2,1) =   60, 10.0
/
```

- 総噴出率をセル集合へ均等分配(内部ソースと同じ規約)。指向性
  (運動量)は持たない — 拡散型に運動量入力は存在しないため自然。
- 割れ目噴火はセル列挙で表現。複数噴火口・時間差噴火は第3添字で。
- f_release 型(初期堆積の一斉解放)は溶岩には不要(ドーム崩落は
  debris の管轄)。
- list_lavaflow は namelist を読むだけ。範囲検査・単位換算(min→s)・
  セルの担当帯判定は m_lavaflow_init(§12 の層契約)。

## 5. 固化と地形結合(唯一の必須インタラクション)

- **固化(段階1の数値的閉包)**: エッジ深さ平均速度 u = D・S/he の
  最大が閾値 lv_vsol 未満の「停止セル」の hl を、レート lv_wsol
  (m/s)で s%z へ転換する。**速度閾値+レートは f_dbstop=1
  (db_vstop/db_wstop)と同じ閉じ方**。起案時は「全エッジのフラックスが
  0 の不動セル」判定だったが、Bingham の停止は漸近的
  (q ∝ (h−h∞)² → 0 だが有限時間で厳密 0 に達しない)で発火しない
  ことが実装中に判明し、速度閾値方式へ変更した(2026-08-23)。
  流動中のセル・供給を受けるセルは閾値を超えるため固化しない =
  活動的なチャネルは開いたまま、というマクロ挙動が出る。閾値の
  目安は 1e-4〜1e-3 m/s(小さいほど停止厚が h∞ に近づくが判定まで
  時間がかかる。停止厚の上振れ ≈ √(v_sol·h/(coef·(2h+h0)·S)))。
  物理的な固化則(クラスト成長 ∝ √t、温度判定)は段階2(§8)。
- **z の更新契約**(geomorph/glacier と同じ): Δz 適用と同一ループで
  s%e = s%z + s%h を回復し、ステップ末に s%z のハロ交換まで行う。
- **sd は増やさない**: 固化溶岩は侵食されない岩盤 → z のみ増加
  (z−sd の基岩が厚くなる)。f_dbstop の z・sd 共動(停止デブリ=
  可動堆積物)とは意図的に異なる。後続の fluvial 基岩侵食則が固化面に
  作用するのは「溶岩の河川侵食」の抽象として受容。
- **再流動なし**: 固化は不可逆(z は恒久)。後続の溶岩は固化面の上を
  流れる(溶岩堤・溶岩原の積層が z の履歴として残る)。
- 台帳: Σhl + Σ(z−z0)_溶岩分 = ∫Q dt が機械精度で成立すること
  (総和は par_sum_rows。固化累計は私有台帳に記録し dispose で報告)。

## 6. 時間刻み(適応サブサイクリング)

D = (ρg/6η)(hl−h0)²(2hl+h0) は hl³/η のオーダーで変動する。目安:

| 溶岩 | η (Pa·s) | hl=3m, dx=10m の D | 陽解法 dt 上限 dx²/4D |
|---|---|---|---|
| 流動性の高い玄武岩質 | 10² | ~2400 m²/s | ~0.01 s |
| 玄武岩質 | 10³〜10⁴ | ~24〜240 m²/s | ~0.1〜1 s |
| 安山岩質〜 | ≥10⁵ | ≤2.4 m²/s | ≥10 s |

- glacier §2.3 と同じ**動的サブサイクル**: 毎 dt、その時点の D_max
  (allreduce_max = 全ランク同一 → collective 安全)から分割数を決め、
  サブサイクル毎に hl のハロ交換。上限 lv_nsubmax で暴走ガード。
- 水文 dt(洪水計算で 0.1〜1 s)に対し、η ≥ 10³ ならサブサイクルは
  数回以内で済む見込み。η = 10² の大規模玄武岩ではコストが立つ —
  それは慣性が効き始める領域でもあり、拡散近似の適用限界と同じ場所に
  コスト限界が来る(限界の一致は設計として健全)。実測して users_guide に
  適用目安を書く。

## 7. 実装契約の要点(m_glacier の様式を踏襲)

- **状態**: s%hl(m 溶岩柱。有効時のみ確保)。場出力 Hl(+累積固化厚の
  私有場を出力候補に。名称は実装時)。リスタートは私有ファイル
  lavaflow.dat(契約5: dispose 内で save。save_version 同時更新)。
  S 台帳への算入は行わない(水当量でないため。私有台帳で報告)。
- **実行順序**: geomorph_calc・driftwood_calc の後、calcstat の前
  (z 更新プロセスの末尾に追加。§2.2 の順序表の更新まで同じ作業に
  含める。水と直接の読み書き共有がないため順序依存は z のみ)。
- **並列**: owner-compute(js..je)+エッジ反対称+ハロ交換。
  噴火口セルの担当判定は帯所属で(全ランクが namelist を読み、自帯の
  セルだけ注入 — collective 判定は全ランク同一)。np=1,2,4 ULP=0。
- **STG 非対応**(z の時間発展。geomorph/glacier と同じ init ガード)。
  morfac 非対応 = 1 に限定(イベント計算。debris と同じ init 検査)。
- **水理との関係(抽象化)**: 地表水 s%h は流動中の溶岩に不可視で
  **z の上を流れる**(glacier §5「氷は水理に不可視」と同じ割り切り)。
  固化した分だけ z が上がるので、固化後の水理は自動的に新地形に従う。
  流動中の溶岩上の降雨は溶岩を素通りして z 上の h に入る(既知の妥協。
  溶岩活動域は通常狭く、洪水計算への影響は小さい)。
- **粗度・浸透は変更しない(段階1)**: 固化面の rn・浸透係数は既存分布の
  まま(§0-6 徐々に精緻化)。必要が生じたら「固化セルの鉛直浸透カット」
  (fn_gw_ksv のマップ化と同じ帯配列に書く)を小拡張として追加。

## 8. 段階2(温度 1 変数。将来枠)

- 深さ平均温度 Tl を溶岩フラックスで移流(拡散フラックス q に乗せる
  スカラー輸送)+冷却源項(放射 σε(Tl⁴−Ta⁴) と対流の単純則。表面
  クラストの断熱は有効放射率 ε_eff への縮約で抽象化)。
- η(Tl)・τ_y(Tl) は指数則(パラメータ直接入力: 基準温度・基準値・
  感度係数)。固化は Tl < 固相線温度で物理的に閉じ、lv_wsol の
  数値的閉包を置き換える。
- **噴出温度は噴火口毎に指定**(lv_temp0(n))。粘度の噴火口別指定の
  代替がこれ(§3)。
- 気温 Ta は fn_meteo があれば連動、なければ定数。

## 9. 検証(test/lava。2026-08-23 実施済み — 記録の正本は §51.3)

- **構成1(Newton 極限・Huppert 相似解)**: 平坦床・中央1セル定率供給。
  先端半径 r_N(t) = 0.715 (g Q³/3ν)^{1/8} t^{1/2}(Huppert 1982)に対し
  面積等価半径の誤差 8.5%(tol 10%)、成長則 r(tt)/r(tt/2) は √2 に
  誤差 0.6%、台帳 Σhl は機械精度(3e-13 m³)。
- **構成2(Bingham 停止・固化)**: 等勾配斜面 tanθ=0.2・列噴火口の
  300 s 供給。停止厚 h∞ = τ_y/(ρg tanθ) に誤差 7.1%(tol 20%。
  lv_vsol 打切りの上振れを含む)・CV 0.001、固化率 1.000、台帳
  Σhl+Σdz 機械精度(1e-11 m³)。停止の漸近が遅いため、検定は
  「検定時間内に排水が h∞ 近傍へ届く粘度」で組む(η=2e3・tt=4800 s)。
- **共通規律**(CLAUDE.md): 無効時に全22回帰ケースがビット一致
  (逐次+MPI np=2)、-fcheck=all np=2 を最適化検証より先に実行、
  -O2 厳密数学で逐次 = np=1,2,4 バイト一致、リスタート往復バイト一致。
  reference 比較は使わない(解析解検定で閉じる = volcano と同じ流儀)。
