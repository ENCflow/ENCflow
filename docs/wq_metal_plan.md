## 1. 要件の整理

発端の要望を分解すると、要件は次の5つになる。

- **R1 平常時の河川濃度分布** — 「水質分布の図化」の主対象は多くの
  場合、出水時ではなく平水〜低水時の定常的な分布。基底流出が河川水の
  主体となるため、**地下水経由の負荷が河川に戻る経路**が要る。
- **R2 出水時の負荷流出** — 面源(農地・鉱山残土等)からの洗い出しと
  粒子態輸送。L-Q 非線形・ファーストフラッシュ。
- **R3 金属ごとの図化** — As・Cd・Pb 等を個別に。金属ごとに
  溶存/粒子親和性(Kd)が大きく異なる。
- **R4 250 m 格子での河道表現** — 川幅はセル未満。結果は「250 m
  河道区間の断面平均濃度」と解釈する。
- **R5 貯水池・ため池** — スリランカ乾燥帯はタンク(ため池)
  カスケードが卓越する。流域がタンクを含む場合、貯留水体の濃度の
  扱いが結果を左右する。

計算規模は 1300 km² / (250 m)² ≒ 20,800 セル(chichibu 実績
560×300 = 168,000 セルの 1/8)。**計算量は一切の制約にならない**。
設計判断の軸は物理表現の範囲だけである。

## 2. 現状の到達点(W2)の確認(2026-08-26 コード確認)

§30 の実装で、地表水系は既に一通り揃っている。

- 輸送: s%cq を advect_scalar(浮遊砂と同カーネル)で移流。
  **一次風上・純移流**(スカラーの明示拡散項はない)。
- 発生源: 点源(g/s)・面源(kg/ha/day)・分布面源 fn_wq_map・
  降雨中濃度・境界流入濃度の重ね合わせ。表面蓄積プール bp +
  洗い出し(buildup-washoff)で R2 は機構的に対応済み。
- 鉛直: 一次減衰・沈降(wq_vs)・浸透同伴(fxg 契約で cg へ)。
- 出力: C 場・B 場・プローブ/測線負荷・wq.csv 質量収支台帳。
- R4: サブグリッド河道幅(fn_width)+σ 断面で対応済み。濃度換算
  cqc = cq/vh は幅セル・σ セルでも正しい(§30)。

W1 からの既知の妥協(§30 に明記)が、そのまま今回の不足と一致する:

1. **cg は台帳(横移動なし)**。gwflow_lateral の飽和湧出は
   **水のみ戻る(質量は片道)** → R1 が成立しない。
2. **Kd 分配なし**(f_wq_infil の 0/1 で粒子態/溶存態の二極近似)
   → R3 の金属差は近似でしか表せない。
3. **ダム放流濃度 0・ため池(rscap)吸収分は地表残留** → R5 の
   タンク流域で系統誤差。

## 3. 外部レビューの論点と判定

| # | 指摘 | 判定 | 対応 |
|---|---|---|---|
| 1 | 地下水中の cg 側方移流+湧出還元が最大の不足 | **採用** | W3(handoff 1l と同一線)。設計は §4 |
| 2 | 実装は記録フラックスを使う advect_gw_scalar の新設 | **修正採用** | 方式比較の結果、lateral_core 内の同伴輸送を推奨(§4.1) |
| 3 | 地表・地下の物理分散項 diffuse_scalar の追加 | **保留** | 理由は下記 |
| 4 | advect_scalar の TVD/MUSCL 高精度化 | **保留** | 理由は下記 |
| 5 | 浮遊砂と結合した Kd 溶存/粒子二相 | **段階採用** | K1(平衡分配の相選択)を先行、K2(E-D 結合)は保留(§5) |
| 6 | 単一物質を species 次元へ拡張(複数金属同時) | **不採用** | 理由は下記 |

**#3・#4 を保留とする理由**: 図化の主対象(R1)は準定常の濃度分布で
あり、定常状態の河川濃度は流量比の混合(合流希釈)で決まる。一次
風上でも質量保存は厳密なので、**準定常分布の合流希釈は数値拡散の
影響を受けない**。数値拡散が効くのは非定常フロント(事故時のパルス
負荷、ファーストフラッシュの先端形状)と氾濫原の横方向広がりで
あって、今回の成果物には二次的である。さらに #4 はカーネルが
hs・hss・hd と共有のため、変更すると geomorph・saltwater・driftwood
の全 reference が動く大規模検証になる。§0「過度に複雑化せず徐々に
精緻化」に従い、**パルス投入の対照テスト(解析解または細格子参照との
比較)で必要性を定量してから**判断する。#3 は #4 より先に入れても
一次風上の数値拡散(〜u·dx/2)に埋もれるため、順序としても後になる。

**#6 を不採用とする理由**: 本モジュールは単一物質の線形輸送であり、
物質間の相互作用を持たない。したがって**金属ごとの別ランは species
次元の同時計算と厳密に等価**で、21k セル規模では実行コストの差も
無視できる。species 次元は状態・save 形式(wq.dat)・出力・台帳の
全面変更を強いる割に便益がない。物質間反応(硫化物生成・競合吸着等)
を扱う段になれば再検討だが、それは §0 の「概算」の範囲を超えるため
方針議論が先である。

## 4. W3: 地下横輸送+湧出還元の設計

### 4.1 方式比較

**方式A — フラックス記録契約+独立輸送カーネル**(外部レビュー案):
gwflow_lateral がエッジ流量を記録場(fxg 同型)に残し、m_wq が
advect_gw_scalar で cg を風上輸送する。

- 長所: モジュール分離が保たれる(lateral は wq を知らない)。
  fxg / fxci / fxco の契約前例と同型。
- 短所: (a) エッジ流量は「無履歴スクラッチ」(lateral ヘッダの
  設計原則)であり、記録場は 4成分×帯の永続配列の新設になる。
  (b) **時刻整合の罠**: m_wq が読む時点で hg は更新済みのため、
  風上濃度 cg/hg の分母に時刻 n の hg が必要になり、hg^n の退避も
  記録する羽目になる(2ループ分離で消した旧 wk の復活)。
  (c) 飽和湧出はループ2内で直列処理されるため、湧出量のセル場記録も
  別途要る。

**方式B — lateral_core ループ2への同伴輸送の畳み込み**(推奨):
ループ2は計算済みエッジ流量 q を読んで発散を取る場所であり、同じ
q・同じ時刻 n の cg/hgw から風上質量フラックスをその場で計算できる。
飽和超過の引き渡し(hg > cap → s%h)と同所で、超過水量 fx に
同率移動を適用して質量を s%cq へ還元する — **湧出の連鎖と同一
ステップで質量も閉じる**。

- これは地表側の役割分担(§30「輸送はカーネル所有者 swflow_enc が
  実行し、wq は発生源・鉛直・診断」)を地下へそのまま対称に適用する
  もの。エッジ無履歴の原則も崩さない。
- cg は m_wq 私有から **s%cg(t_state)へ昇格**する(s%cq と同格。
  save は引き続き wq.dat = 契約C、3成分形式は不変)。lateral_core は
  「s%cg が allocated なら同伴」で判定し(conduit の fxci 記録と同じ
  流儀)、wq の意味論を知らない。
- 層2(f_gwlayer2)への一般化: lateral_core は t_latlayer で層非依存の
  ため、cg2(handoff 1l)は同じ引数化で自然に載る。第2弾とする。

**推奨: 方式B**。handoff 1l の「フラックス記録契約」の文言は本書で
上書きし、合意後に handoff を消し込む。

### 4.2 仕様細目

- 風上濃度 Cg = cg/hg(時刻 n。hg ≤ eps ガードは水と同条件 =
  水が動かないエッジは質量も動かない)。エッジ質量フラックス
  = q_k · Cg_upwind。負値防止は水側の exflux_reduction に相乗り
  (縮小後の q を読むため構造的に安全側)。
- **遅延化係数 wq_rg**(R ≥ 1。既定 1 = 遅延なし): 地下移流の実効
  速度を 1/R に落とす平衡吸着の遅延表現。実装は輸送分担率
  (advect_scalar の share = 1/R と同型。§47)。R は**物理量として
  直接与える**(R = 1 + ρb·Kd/θ の導出は前処理 — §0)。重金属の
  地下輸送は強い遅延を受けるのが通例で、この 1 係数が「地下水経由の
  金属」の一次近似の要になる。
- 湧出還元: Δcg = cg · fx/(hg + fx)(浸透同伴と同じ柱状量同率移動 —
  面積基底によらず質量保存が厳密)。行き先は s%cq。
- 減衰(fdec)の cg への毎ステップ乗算は現行のまま不変。
- 台帳: wq.csv に湧出還元列(seep_g)を追加(**列構成変更** —
  wq.csv 依存の後処理は要追随。reference 比較対象ではない)。
- MPI: ループ2 は担当帯のみ、帯界面エッジは冗長計算配布(既存機構の
  まま)。cg のハロは calc 冒頭の hg 交換に相乗りして 1 本追加。
  台帳集計は par_sum_rows(決定的)。
- bucket 経路(浸透 fxg → 同伴)は不変。rscap・ダムの扱いも本段では
  不変(§6)。

### 4.3 検証計画(絶対規律2・3)

- 無効時(fn_wq 未指定): 全回帰ビット一致。wq 有効・gwflow 無効:
  既存 wq ケースとビット一致(lateral の同伴分岐が不活性)。
- 保存: 閉領域で cq + cg の総質量不変(発生源・減衰なし)。
  一様 Cg 場が一様のまま(カーネルの基本性質)。
- 定常検証: 1次元斜面の定常浸透→側方→湧出で、湧出濃度 = 入力濃度に
  漸近(トレーサ滞留時間の解析解対照。wq_rg の効きは到達時間 ×R で
  分離確認 — handoff 1l の「逓減解析+トレーサ滞留時間でパラメータが
  分離同定できる」の実検証を兼ねる)。
- wq.csv 閉合: to_gw・seep・貯留の収支残差 ≈ 0。
- 帯確保配列に触れるため **-fcheck=all np≥2 を最適化ビルドより先に**
  (規律3)。np=1, 2, 4 が逐次と ULP=0。リスタート往復ビット一致。

## 5. Kd 二相(粒子吸着系)の設計 — 段階案

### K1 — 平衡分配の相選択(f_suspend 連携の最小形)

現行の f_wq_infil による「全量溶存/全量粒子」の二極を、浮遊砂濃度に
応じた連続的な分配に置き換える。

- 有効化: wq_kd(m³/kg。**直接与える** — 金属・流域ごとの文献値)。
  指定時は f_suspend 必須(未指定はエラー。浮遊砂なしで Kd は
  定義できない)。
- 毎ステップ・セルごとに溶存率 fd = 1/(1 + Kd·Css)、
  Css = hs/vh(kg/m³)。粒子率 fp = 1 − fd。
- 適用先(いずれも既存機構の係数化で、状態の追加はない):
  - 浸透同伴(f_wq_infil=1): 同伴質量を fd 倍(粒子態は地表残留)。
  - 沈降: wq_vs に代えて fp·cq に浮遊砂の沈降速度 gm%wf を適用。
    行き先は f_wq_settle の既存機構(=1 の bp プール行きを推奨 —
    せん断洗い出しが再懸濁を担い、河床金属の蓄積↔再懸濁が閉じる)。
  - 水平移流は cq 一本のまま(溶存態も粒子態も水柱と同速で動くため
    分ける必要がない — 差が出るのは鉛直・河床交換だけ)。
- save 形式・出力形式は不変(fd は導出量)。無効時(wq_kd 未指定)は
  経路・ビットとも不変。
- 限界: 河床の金属は bp(セル固定)であり、掃流砂としての移動や
  河床変動(E-D)との厳密な結合はしない。

### K2 — E-D 結合(保留)

geomorph_suspend の浸食 E・沈降 D フラックスの記録契約を介して、
金属沈着 = D×(fp·cq/hs)、再懸濁 = E×(河床交換層の金属/砂比)と
する案。交換層厚(または河床の金属/砂濃度比)という新しい状態と
仮定が必要になるため、**K1 の実流域適用で不足が示されてから**設計
する。Cs-137 等の粒子吸着系(handoff 1l「別ライン」)もこの段。

## 6. 貯水池・タンクの放流濃度(第2弾候補)

対象流域がタンクカスケードを含む場合(R5)、現行の「ダム放流濃度 0・
rscap 吸収分は地表残留」は主要な系統誤差になる。

- ダム・湖沼: 捕捉台帳の質量 M と貯水量 V(hrs 総和)から放流濃度
  = M/V の完全混合池モデル(handoff 1l 既載)。捕捉同伴(既存)+
  放流同伴で池の収支が閉じる。沈降を池内で効かせる場合は M にも
  fdec・沈降を適用(タンクは重金属のシンクなので、これが本命の
  効き方になる)。
- ため池(rscap): 吸収分の質量を rscap プール(bp と同型の枠)に
  持ち、あふれ時に同伴放出する案。吸収量の記録契約が必要
  (handoff 1l 既載)。
- 優先度は**流域選定に依存**する: 湿潤帯の流域(タンク僅少)なら
  後回し、乾燥帯なら Phase 1 と同格に前倒し。

## 7. スリランカケースの構成(Phase 0 — 現行 W2 で直ちに可能)

コード変更なしで始められる構成。**水理が結果を支配する**ので、
まず水質なしで流量再現を確立してから水質を載せる(users_guide/wq.md
の下水評価と同じ順序)。

- 座標系: DEM(SRTM/Copernicus 30 m 等)を投影座標系(SLD99 または
  UTM 44N)へ再投影し 250 m へ集約・窪地処理(GIS 側の仕事。§0)。
- 河道: fn_rw(集水面積閾値から生成)、fn_width(実測・衛星判読
  または流域面積回帰式)、depth_rw、rn0_rw。
- 水文: 降雨(観測・衛星)、蒸発散(&list_evap)、gwflow バケツ+
  側方(基底流出。低水逓減の検証は handoff 1j の残項目と重なる —
  本ケースがその実検証を兼ねられる)。
- 負荷: 点源(鉱山・工業・都市排水)+ fn_wq_map(土地利用別原単位。
  文献値から作成し wq_map_factor で校正)。
- 金属ごとに別ラン。W2 の二極近似で挟む:
  溶存性の強い金属(As 等)= f_wq_infil=1・減衰 0・沈降 0(保存性
  上限)/ 粒子親和の強い金属(Pb 等)= f_wq_infil=0 + wq_vs +
  f_wq_settle=1(再懸濁つき下限)。K1 実装後に Kd で連続化。
- 校正・妥当性: 既往の河川水質観測(スリランカは重金属実測の公表
  研究が複数ある)と wq.csv の収支検算。
- 作成手順は .claude/skills/make-case に従う。
