## 1. 結論(要約)

- 捕捉した材積は、**セルの台帳(柱状量のラスタ場)**として m_driftwood に持つのがよい(§4)。
  構造物の種類・両端・並列・保存・出力・材積収支が 1 つの仕組みで閉じる。構造物ごとの量は、
  セルの台帳を集計した診断として出せる。
- 流れへの作用は、開口がセルで解像されているか(流れが格子の辺を通るか)で 2 通りに分ける。
  台帳は共通にする(§5)。
  - **格子の中を流れる構造物**(橋脚・橋の径間、格子型の透過型堰堤、河道を横断する流木捕捉工):
    集積したセルの**抵抗**(運動方程式の半陰の抗力項)。これを**第 1 段**にする。
  - **セルより小さい開口を流量則で通す構造物**(カルバート、カルバートで近似したスリット堰堤):
    流入口の**損失を流量則に足す**。これを**第 2 段**にする。
- 試作で確かめたこと(§6)。
  1. 抵抗の方式は、定常の堰上げが解析解と 1〜6 % で一致し、流速の異常が出ない。
  2. 通過幅を縮める方式は、堰上げが理論(縮流部の限界流)の半分ほどにとどまり、下流に最大
     13 m/s の噴流が出る。採らない。
  3. カルバートの流入口のセルに実材積 100 m³ を置いても、セルの抵抗では流量が 0.1〜0.3 % しか
     変わらない。開口がセルより小さいと、セルの流速が開口の流速より桁違いに遅いためである。
     流量則に損失を足す形では、0.5 m³ で流量が 0.23〜0.28 倍になる。
  4. 連鎖(上流の立木の流失 → 橋で捕捉 → 堰上げ → 氾濫原へあふれて橋を迂回 → 河畔林の流失)が、
     第 1 段だけで計算できる。
  5. 機能を使わない設定の結果は、変更前の実行ファイルとビット一致した(10 構成)。
- 添付の案との違いは 2 点。台帳を構造物でなくセルに置くこと、格子の中を流れる構造物には
  流量則でなく抵抗を使うこと。添付の案の「構造物の通水能を下げる」は、第 2 段のカルバートにあたる。
- 捕捉率と抵抗の係数は**校正の要る経験的な値**である。丸太の向き・長さの分布・橋脚への架橋を
  解いたかのようには説明しない(添付の案と同じ立場)。

## 2. 現状(コードの確認)

- 流木は運動方程式に入らない。m_swflow_enc が流動流木 hd に触れるのは、ステップ頭のハロ交換、
  輸送(advect_scalar)、水位規定セルの置き直し、ステップ末尾の確定だけである
  (src/m_swflow_enc.f90 の `s%dw_active` の分岐)。摩擦・抗力の項(calc_kth_flux の `tfe`)は
  hd・wd を読まない。
- カルバート・ポンプ・分水の転送は、水と水質だけを運ぶ(src/m_swflow_enc_bc.f90 の boundary_h。
  §30.10)。流木は取水側のセルに残る。
- したがって、流木を通さないカルバートの流入口のセルには、流動流木 hd が流れ着いて濃くなり続ける。
  水は抜け、流木は残るので、濃度 hd/h に上限はない。この流木は流量則(代表セルの水位だけの関数。
  §22)にもセルの流れにも作用しない。利用者の指摘のとおりである。
- 流木モジュールの将来課題には「抵抗則への算入、動的閉塞則」が挙がっている(§50.1)。
  家屋破壊・瓦礫には、破壊が空隙率 s%gv へ返る経路(§63.4)がある。gv は増える向きだけである。

## 3. 現象と、モデルに要る 3 つの部品

橋や透過型堰堤での流木の集積は、次の順に進む。

1. 流れてきた流木の一部が、橋脚・桁・部材に掛かって止まる(**捕捉**)。掛かるかどうかは、
   流木の長さと開口の幅の比、水位と桁下の高さ、流速などで決まる。いったん掛かると、後から来る
   流木は掛かりやすくなる。
2. 止まった流木が溜まる(**集積**)。
3. 集積した流木の間を水が通るときに損失が出て、上流の水位が上がる(**流れへの作用**)。水位が
   堤防・河岸・取付道路を越えると、流れが構造物を迂回する。

ラスタの材積場(§50)で表すには、部品が 3 つ要る。

| 部品 | 決めること | 節 |
|---|---|---|
| 台帳 | 集積した材積をどこに持つか | §4 |
| 流れへの作用 | 台帳の量を流れにどう効かせるか | §5 |
| 捕捉 | 流動流木のうちどれだけを台帳へ移すか | §7.2 |

個々の丸太が掛かるかどうかの幾何の判定(部材の間隔と流木の長さ)は、引き続き対象外である
(§0 方針 2。§50)。捕捉の割合は与件として与える。

## 4. 台帳の置き場所: 構造物の属性か、セルの属性か

| 観点 | 構造物の属性(添付の案) | セルの属性(柱状量のラスタ場) |
|---|---|---|
| 対象 | fn_structure の構造物(2 つのセル群と流量則)に限る。橋・格子型堰堤のように流れが格子の辺を通る構造物には、別の入れ物が要る | 捕捉セルを塗れば、どの構造物にも使える。カルバートの流入口のセルにも置ける |
| 双方向の構造物 | 取水側・吐口側の 2 つの量が要る | セルごとに持つので、両端が自然に分かれる |
| 状態の保存 | 構造物族は今のところ履歴状態を持たない(§22。ダムの貯留は s%hrs)。構造物の状態と save の形式が新しく要る | driftwood.dat に成分を 1 つ足す(m_restart の既存の経路) |
| 並列 | 構造物のセルが複数のランクにまたがると、捕捉量の総和を毎ステップ全ランクで共有する | セル場とハロ交換で足りる。collective は増えない |
| 層の関係 | m_boundary が流木の量を知る経路が要る(共有状態 s に構造物別の配列) | m_driftwood が台帳を持ち、流れは s のセル場を読む(§3 の「s を介してだけ結合」のまま) |
| 出力・収支 | 材積がラスタの外へ出る。分布図に出ない | 分布(Wj)に出る。Σwst + Σhd + Σwd + Σwj が閉じる |
| 構造物ごとの量 | そのまま読める | 構造物のセル群で集計して出す(診断) |
| 再流動・崩壊(将来) | 台帳からセルへ戻す処理が要る | セルの中の移し替えで済む |

セルの属性にする。方針 2(ラスタ純化。構造物はセル群の指定)とも合う。流量則が材積を要るとき
(第 2 段)は、構造物の上流側のセル群の台帳を読む。

既存の堆積流木 wd と同じ台帳にはしない。wd は浅い水で接地した流木で、深く速い流れで再流動する
規則を持つ(dw_wfloat)。構造物に掛かった流木は深く速い流れの中に留まるので、規則が逆になる。
出力でも区別したい。新しい台帳の名前は、仮に **集積流木 `s%wj`**(出力 Wj)とする。

## 5. 流れへの作用の候補と比較

### 5.1 候補

| 案 | 内容 | 判定 |
|---|---|---|
| A 構造物の流量則 | カルバートの流量則に、集積の損失(または開口の縮小)を入れる | セルより小さい開口には必要(§6.3)。**第 2 段** |
| B セルの抵抗 | 集積したセルの辺に、家屋の抗力項と同じ形の半陰の抗力を足す | 解析解と一致し安定(§6.1)。**第 1 段** |
| C 通過幅の縮小 | 集積したセルの辺の通過幅に (1 − 閉塞率) を掛ける(動的な振り替えの表 fwd と同じ読み手) | 堰上げが過小で噴流が出る(§6.2)。採らない |
| D 空隙率 gv | 集積した分だけ gv を下げる(m_state_set_gv) | 採らない(下記) |
| E 動的粗度 s%rnv | 集積を等価な Manning の n に直して rnv に入れる | 採らない(下記) |
| F 透過壁の辺 | 河道を横断する辺の流束を、開口つきの堰・オリフィスの式で置き換える(堤防の仮想壁面の一般化) | 見送り(下記) |

- **D を採らない理由**: gv は平面の空隙率で、連続式の貯留も変える。通過幅は縮めない(encgrid.md §2)。
  流れに効くのは家屋の抗力項だけで、その寸法 bb は静的な入力である。集積の水柱に占める割合は
  水深で変わるが、gv は水深によらない。m_state_set_gv は増える向きだけを許している(§63.1)。
  植生の動的粗度のときも、同じ理由(gv は貯留も変える)で抗力項の流用を退けている(§84.8)。
- **E を採らない理由**: 式の上では B と同じにできる(n² = n₀² + κ h^{4/3}/g)。しかし s%rnv は
  geomorph の定着が確保・更新する場で、持ち主が 2 つになる。水深に依存する換算を毎ステップ
  セルで作る必要もある。B は 1 文で足りる。
- **F を見送る理由**: スリット堰堤・堰・水門を「格子の辺を通る流束」として表せる利点がある
  (土砂・流木が水と一緒に通り、測線にも乗る)。しかし堤防の壁(河道と堤内地の間の辺に限る)の
  一般化になり、開口補正・追い越し禁止上限・適応ルンゲクッタとの関係を含めて m_swflow_enc_channel
  の広い範囲に触れる。方針 6(徐々に精緻化)により、需要が確かになってから別に検討する。

### 5.2 案 B の定式(セルの抵抗)

集積した流木を、多孔質の障害物として扱う。Follett ら(2020)は、流木の集積を「運動量の損失が
丸太の数・径・充填の度合い・集積の長さに比例する多孔質の障害物」として表し、Schalko ら(2018)の
堰上げの実験を説明している。その構造の係数は C_A = L C_D a / (1 − φ)³ である(L は集積の長さ、
a は単位体積あたりの前面積、φ は実材積の割合)。円柱では a = 4φ / (π d) になる。

ENCflow では、同じ抗力を運動方程式の半陰の項に入れる(離散化は独自)。集積の中の間隙流速は
u/(1 − φ) なので、見かけの流速 u に対する減速度は (C_D a / 2(1 − φ)³) |u| u になる。セルの集積が
充填率 φ で水柱の全深を占め、セルの長さのうち (w_j/h)/φ の割合を塞ぐとすると、辺の抗力項は

    F_jam = − κ₀ · min(w_e / h_f, φ) · |V|_e
    κ₀ = 2 C_D / (π d (1 − φ)³)   [1/m]

になる。w_e は辺の両側のセルの集積量 w_j の平均、h_f は摩擦項と同じ辺の水深、|V|_e は辺の
速さである。d は代表直径(既存の dw_dlog)、φ は集積体の充填率、C_D は抗力係数である。
min は、水柱に入りきらない分(水面より上に積み上がる分、上流へ伸びる分)が抵抗を増やさない
ことを表す。

- 損失は集積の総量で決まる。幅あたりの実材積 V_s/B = Σ w_j Δs が同じなら、1 セルに置いても
  2 セルに分けても、格子幅を変えても、堰上げはほぼ同じになる(§6.6)。
- 柱状量の基底は hd・wd と同じ(空隙面積・河道幅の中)にする。河道幅(fn_width)のセルでは、
  流速が河道の中の流速で、集積量も河道の平面積あたりなので、同じ式がそのまま使える。
- 半陰の項なので、時間刻みの制約は増えない。
- 定常の 1 次元の流れでは、漸変流の式に項が 1 つ増えた形になる。これが検定の解析解になる(§6.1)。

      dh/dx = [ S₀ − n² q² / h^{10/3} − κ₀ min(w/h, φ) q² / (g h²) ] / (1 − q² / (g h³))

- 底面せん断(流砂)には入れない。集積の抵抗は形状抵抗で、粒子にかかるせん断ではない。
  m_geomorph は粗度と流速から底面せん断を作るので、何もしなくてもそうなる(植生の動的粗度と
  同じ考え。§84.8)。流速が落ちる分だけ、集積の上流で土砂が堆積する。

### 5.3 案 A の定式(カルバートの流入口の損失。第 2 段)

カルバートの流入口の前の集積を、開口の流速に対する損失係数にする。台帳はセルのものを読む。

    C_A = 2 κ₀ · V_j / (B · D)

V_j は上流側のセル群の集積の実材積(m³)、B・D は断面の幅と高さである。V_j/(B D) は、流入口を
覆う集積の「厚さ × 実材積の割合」にあたる。流量則の 2 つのレジームには、次の形で入る(導出は独自)。

- **満管**: 損失の和に足す。Q_p = B D √(2g Δη′ / (1 + c_e + 2g n² L / R^{4/3} + C_A))。
- **自由水面(堰)**: 限界流の手前で損失 C_A u_c² / 2g が出るとすると、限界水深が
  H / (1.5 + C_A/2) になる。流量は (1 + C_A/3)^{−3/2} 倍になる。

C_A = 0 では乗算・加算そのものを飛ばし、現行とビット同一にする(ゲートなしのカルバートと同じ扱い)。

## 6. 試作の結果

共通の設定: gfortran 13.3、make.inc は既定のまま(-Ofast・倍精度・逐次・OpenMP 4 スレッド)。
集積の係数は d = 0.3 m、φ = 0.3、C_D = 1(κ₀ = 6.19 1/m)。

### 6.1 案 B と解析解(E1)

幅 20 m(Δx = 5 m の 4 セル)、勾配 0.002、n = 0.03 の直線水路。両岸は乾いた高い地盤。
等流水深 2.0 m(q = 4.73 m²/s、Fr = 0.53)。水路の中央の 1 列に、静的な集積 w_j を置いた。

| 実材積 (m³) | V_s/B (m²) | w_j (m) | 解析解の堰上げ (m) | 試作の堰上げ (m) | 比 |
|---:|---:|---:|---:|---:|---:|
| 10 | 0.5 | 0.1 | 0.656 | 0.648 | 0.987 |
| 20 | 1.0 | 0.2 | 0.998 | 0.999 | 1.001 |
| 40 | 2.0 | 0.4 | 1.445 | 1.467 | 1.015 |
| 100 | 5.0 | 1.0 | 2.216 | 2.296 | 1.036 |
| 200 | 10.0 | 2.0 | 2.918 | 3.095 | 1.061 |

- 堰上げは、集積の 1 セル上流の水深から等流水深を引いた値。解析解は §5.2 の漸変流の式を、
  集積のセルの両側の辺(長さ 2Δx、集積量は半分ずつ)について下流から積分したもの。
- 領域の最大流速は、5 ケースとも等流の 2.45 m/s のままだった。横断方向の水深の差は 4 mm 以下。
- 堰上げは材積のおよそ 0.5 乗で増える(材積 20 倍で 4.8 倍)。水深が深くなるほど流速が落ち、
  同じ集積でも損失が小さくなるためである。

### 6.2 案 C(通過幅の縮小)との比較

同じ水路で、集積のセルの辺の通過幅を (1 − β) 倍にした(動的な振り替えの表 fwd に掛けた)。
理論値は、損失のない縮流部で限界流になるときの上流の水深である。

| 閉塞率 β | 理論の上流水深 (m) | 試作の上流水深 (m) | 堰上げの比 | 下流 1 セルの水深・流速 | 最大流速 (m/s) |
|---:|---:|---:|---:|---|---:|
| 0.3 | 2.29 | 2.01 | 0.04 | 1.37 m・3.4 m/s | 3.4 |
| 0.5 | 3.01 | 2.54 | 0.53 | 0.66 m・5.4 m/s | 6.6 |
| 0.7 | 4.35 | 3.26 | 0.53 | 0.42 m・7.0 m/s | 10.3 |
| 0.8 | 5.74 | 3.91 | 0.51 | 0.32 m・8.3 m/s | 13.3 |

- 堰上げは理論の半分ほどで、下流に薄く速い噴流が出る。β = 0.5〜0.8 の縮流部の限界流速は
  4.5〜6.1 m/s で、最大流速はその 1.5〜2.2 倍ある。
- 1 本の辺で急な縮小を解くと限界流の制御が働かない、という既知の性質と同じである(破堤口の
  壁を解除する案を退けた理由。channel_models.md §4)。流木の間を通る流れは損失で減速するので、
  噴流は現象とも合わない。地形変化と併用すると、下流に偽の洗掘が出る。
- 通過幅の読み手は連続式・ルンゲクッタの仮水深・スカラー輸送・掃流砂・セル流速の再構成に
  またがる。幅を縮めたセルの流速の正規化(河道幅の cwx にあたるもの)も要る。実装の範囲も
  案 B より広い。

### 6.3 カルバート(E3)

test/culvert の構成(10 m 格子の上流槽を 1 m × 1 m のカルバートで排水。満管から堰へ移る)。
流入口のセルに集積を置き、上流水深 h₁ ごとの流量を比べた。

### 6.4 連成の試計算(E2)

幅 20 m(4 セル)・満杯水深 3.5 m の河道と、両側の氾濫原(1200 m × 200 m、Δx = 5 m、勾配 0.002、
n = 0.03)。流量 137.3 m³/s(等流水深 2.5 m)。立木は、上流の河道の中(x = 100〜400 m)に 183 m³、
橋の上流の氾濫原の河畔(河道から 20 m 以内、x = 600〜790 m)に 156 m³。橋は x = 800 m の河道の
4 セルで、捕捉率 0.3、集積が 0.05 m³/m² を超えたセルは捕捉率 1。水理的流失は dw_hrec = 0.3 m、
dw_vrec = 0.5 m/s、dw_wrec = 3e-5 m/s。2 時間。

| 橋の集積(終了時) | 171 m³ | 124 m³ |

| 橋の断面の流量(河道 / 氾濫原) | 137 / 0 m³/s | 66 / 65 m³/s |

  流木の一部が氾濫原へ回って堆積したためである。

- 時間刻み 0.2 s のまま安定に走った(クーラン数の最大 0.38、過大流出の抑制 0 回)。集積 100 m³ の

### 6.8 ついでに分かったこと(既存のコードの性質。この検討の対象外)

- **堤体のスリットを地形で解像したときの堰上げ**: §6.1 の水路を横断する堤体(地形)に、1 セル幅
  (5 m)のスリットを開けた。上流の水深は 3.68 m で、損失のない限界流の理論値 4.93 m より低い
  (堰上げは理論の 0.57 倍)。スリットのセルの流速は 7.9 m/s で、限界流速 5.7 m/s を超える。
  2 セル幅(10 m)では 2.44 m 対 3.01 m(0.44 倍)だった。§6.2 と同じ性質で、1〜2 セルの急な縮小の
  上流の水位は低く出る。スリット堰堤を地形だけで表すときの注意になる(§7.7)。
- **薄く濡れた氾濫原に接する河道の水位**: §6.4 の配置で満杯水深を 3.0 m にすると、流木の作用を
  切った計算でも、橋の上流の河道の水深が 2.44 m から 2.74 m に上がった(流量は同じ)。区間流入の
  近くで速度水頭の分だけ岸を越えた水が、氾濫原を薄く(5〜7 cm)濡らした後である。濡れた後の
  断面の平均流速は、同じ水深の Manning の 0.86 倍だった(中央の 2 行 2.29 m/s、岸沿いの 2 行
  2.76 m/s)。氾濫原を流れる量は全体の 2 % に満たない。氾濫原が乾いたままの計算(満杯水深 3.5 m)
  では、平均は Manning に 1 % 以内で一致する。原因は調べていない。満杯に近い河道の氾濫の開始に
  効くので、例題を作る前に別に確かめる。
- **家屋の抗力項の次元**: 集積の抗力項の形を合わせるために読んだところ、ENC の家屋の抗力項
  (src/m_swflow_enc.f90 の `tfe = tfe - p%kk * p%cd * hhe / bbe * (1 - gve) * vve / 2`)は、半陰の
  係数(1/s)としては長さの次元が 1 つ余る。STG(src/m_swflow_stg.f90 の
  `FC=FC+KK*CD/DC/BBC*SQRT(MMC**2.0+NNC**2.0)*(1.0-GVC)`)は k C_D (1 − g_v) |V| / B で、次元が合う。
  ENC の値は STG の h/2 倍(h は m 単位の水深)にあたり、水深 2 m で一致する。h は 2026-01-14 の
  コミット af151189 で入った(初版は h なし)。調査と影響の記録は handoff.md の 00t。集積の抗力項は
  §5.2 のとおり 1/s の次元で書く。

## 7. 推奨する設計

### 7.1 状態と台帳

- **`s%wj`**(t_state): 集積流木の柱状材積 (m³/m²)。基底は hd・wd と同じ空隙面積・河道幅の中。
  捕捉セルを指定したときだけ m_driftwood が確保する。持ち主は m_driftwood(更新・保存)。
  m_state_set_gv の「空隙面積基底の柱状量」の並びに足す。
- 流木の台帳は 4 つになる: 立木 wst → 流動 hd → 堆積 wd、または集積 wj。
  Σwst + Σhd + Σwd + Σwj(+ ダム捕捉 + 系外流出)が初期材積に閉じる。
- 流れが読む係数(κ₀・φ・有効フラグ)は、m_driftwood_init が t_state のスカラーへ書く
  (s%dw_sg と同じ様式)。

### 7.2 捕捉

- **捕捉セル**を捕捉率 E(0〜1)のラスタで与える(仮に `fn_dwtrap`。0 = 捕捉しない)。
  橋のセルの列、堰堤の透過部のセルの列を塗る。斜めの抜けを防ぐため、列は 4 近傍でつなぐ
  (ダムの捕捉帯と同じ注意)。
- E は「捕捉セルを 1 回通過する流木のうち捕捉される割合」である。計算はセルの中だけで行う
  (m_driftwood の「セル局所」の様式のまま)。よく混ざったセルの滞留時間 Δx/|V| に対して

      捕捉量 = hd · r / (1 + r)、 r = E/(1 − E) · |V| Δt / Δx

  とする。E = 1 はその時点の hd の全量である。移流の後に呼ばれるので、E = 1 は厳密に
  「入った流木をすべて止める」になる。この規則は独自である。
- 捕捉は、発生(侵食連行・水理的流失)の後、接地の堆積の前に置く。捕捉セルに残った hd は、
  従来どおり接地の堆積の対象になる。集積の上流の淀みで止まった流木(dw_vstop)は堆積 wd に入り、
  抵抗には数えない。
- **E を何から決めるか**: 流木の長さと開口の幅の比が支配する。モジュールは長さを持たない
  (§50.4 の長さ非依存の抽象化)ので、E は利用者が与える(方針 12。換算は前処理・目安の表)。
  ユーザーガイドに目安を置く。材料の候補は §11。
- **集積が進むと掛かりやすくなる効果**(任意): 集積量がしきい値を超えたセルは E = 1 にする
  (仮に `dw_jamgrow`。未指定なら E は一定)。§6.4 の試計算で使った。第 1 段に入れるかは §9 の 4。
- 捕捉率を水位(桁下の高さ)で切り替える、流木の長さの分布を持つ、は将来の候補にとどめる。

### 7.3 流れへの作用(第 1 段: セルの抵抗)

- §5.2 の抗力項を、calc_kth_flux の家屋の抗力項と同じ並びに 1 文で足す。
  無効時(捕捉セルの指定なし、または作用を切ったとき)は論理 1 つの分岐だけで、配列は確保しない。
- ステップ頭の hd のハロ交換と同じ場所で、s%wj もハロ交換する(辺が両側のセルの w_j を読む)。
- 作用を切る選択子(仮に `f_dwjam`。既定 1 = 作用あり、0 = 台帳だけ)を持つ。
  家屋破壊の f_bdgv(§63.4)と同じ役割で、「流木なし」「運ぶが流れに影響させない」「閉塞が
  成長する」の 3 通りを同じケースで比べられる。

### 7.4 流れへの作用(第 2 段: カルバートの流入口の損失)

- カルバートごとの選択子(仮に `culv_jam(n)`)で有効にする。有効なカルバートの上流側・下流側の
  セル群は、捕捉率 1 の捕捉セルとして扱う(カルバートは流木を通さないので、届いた流木は
  すべて流入口に溜まる)。
- structure_makebdc が、水位の高い側のセル群の s%wj から実材積 V_j を集計し、§5.3 の C_A を
  流量則に渡す。セル群が複数のランクにまたがる場合は、決定的総和(par_sum_rows)を使う。
- 流量則の共通インターフェース(i_struct_law)に引数が 1 つ増える。

### 7.5 パラメータ(仮の名前)

| パラメータ | 既定 | 意味 |
|---|---|---|
| fn_dwtrap | —(指定で有効) | 捕捉率 E の分布(0〜1。地形と同じ行列形式) |
| f_dwjam | 1 | 集積の流れへの作用。0: 台帳だけ、1: 抵抗 |
| dw_jamcd | 1.0 | 集積体の抗力係数 C_D(校正値) |
| dw_jamphi | 0.3 | 集積体の充填率 φ(実材積 / 見かけの体積。校正値) |
| dw_jamgrow | なし | 集積量 (m³/m²) がこれを超えたセルは E = 1(任意) |
| culv_jam(n) | 0 | 第 2 段。カルバート n の流入口の集積を流量則に入れる |

- 代表直径は既存の dw_dlog を使う。
- 既定を採用した値は、実行開始時に "(default)" 付きで表示する(§50.6 の様式)。
- φ は (1 − φ)³ で効くので、感度が大きい(φ = 0.2・0.3・0.4・0.5 で κ₀ = 4.1・6.2・9.8・17 1/m)。
  枝葉・細かい有機物は損失を大きく増やすことが知られている(Schalko ら 2018)。C_D と φ は
  合わせて 1 つの校正値として扱うよう、ガイドに書く。

### 7.6 出力・保存・並列

- 分布: Wj0001…(仮に `f_out_wj`)。期間最大の Wd9999 は hd + wd のままにする(集積は別の図)。
- driftwood.csv: 捕捉の累積 `trap_m3` と現在の集積 `vol_jam_m3` の列を足す。
- 保存: driftwood.dat に s%wj を足す。使わない設定の既存の save をそのまま読めるよう、
  有無の印をつけて追記する(swflow_enc.dat の fwd と同じ方式。§7)。
- 並列: 新しい帯配列は s%wj と捕捉率の 2 つ。collective は第 1 段では増えない
  (ハロ交換が 1 つ増える)。確保に触れるので、-fcheck=all の np ≥ 2 を先に回す(規律 3)。
- 実行順序は変えない。m_driftwood_calc(捕捉)はステップの末尾、抵抗は次のステップの
  運動方程式で効く。

### 7.7 構造物ごとの表し方

| 構造物 | 地形・構造 | 捕捉 | 流れへの作用 | 段 |
|---|---|---|---|---|
| 橋(河道がセルで解像されている、または河道幅 fn_width) | 橋のセルの列を捕捉セルにする。橋台・取付道路・堤防は地形と堤防 | E は利用者が与える | セルの抵抗 | 1 |
| 格子型(鋼製)の透過型堰堤、流木捕捉工 | 透過部のセルの列を捕捉セルにする。袖部は地形 | E ≈ 1 | セルの抵抗 | 1 |
| スリット堰堤(スリットがセルより狭い) | 堤体は地形、スリットはカルバート(現行の近似) | 流入口のセルで全量 | 流量則の損失 | 2 |
| カルバート・樋管 | 現行どおり | 流入口のセルで全量 | 流量則の損失 | 2 |
| スリット堰堤(スリットをセルで解像) | 堤体は地形、スリットは 1〜2 セルの切れ目 | E は利用者が与える | セルの抵抗 | 1 |

- 構造物そのものの抵抗(橋脚、堰堤の部材)は、既存の粗度 fn_rn・地形・河道幅で与える。
  新しい入力は足さない。
- スリットをセルで解像する表し方は、流木の作用は入るが、スリット自身の堰上げが低く出る(§6.8)。
  スリット堰堤の水位が要る計算には、カルバートの近似(第 2 段)を勧める。
- 透過型堰堤では、流木で塞がると土砂も溜まる。これは追加の仕組みなしに出る。集積の抵抗で
  上流の流速が落ち、掃流砂・土石流の堆積が進む。ただし単一粒径なので、巨礫による閉塞は
  表せない(geomorph_applications.md §6 のまま)。

### 7.8 できないこと(利用者向け文書に書く限界)

- 丸太が掛かるかどうかの判定。捕捉率は与件である。
- 集積の形(上流へ伸びる、水面に浮く、桁の下へ潜る)。台帳は構造物のセルの材積だけである。
  水柱に入りきらない分は抵抗を増やさない。
- 集積の崩壊・再放出、橋の流失。集積は動かない(増える向きだけ)。
- 桁による圧力流れと桁の上の越流。橋は桁を持たない。
- 流木が水の体積を押しのける効果。
- セルより小さい開口の閉塞(第 1 段だけでは作用しない。第 2 段で扱う)。
- 抵抗の係数(C_D・φ)と捕捉率は校正値である。実測の堰上げとの照合はまだない。

## 9. 決めること(推奨は太字)

1. 台帳の置き場所: **セルの台帳 s%wj** / 構造物の属性(添付の案)。
2. 格子の中を流れる構造物への作用: **セルの抵抗(案 B)** / 通過幅の縮小(案 C)/ 空隙率(D)/
   動的粗度(E)。
3. カルバートなどセルより小さい開口: **第 2 段で流量則に損失を足す(案 A。台帳はセルのものを読む)** /
