## 0. 結論(要約)

- **可能。採る形は「汀線帯の沿岸漂砂」(案 A)+「波による攪拌」(案 B)。** 沖の波
  (有義波高 H₀・周期 T・向き φ₀。固定値か時系列)を与件として与え、砕波帯のセルで
  局所の汀線方位を水深勾配から取り、CERC/Ashton–Murray 型の沿岸漂砂を岸に沿う
  エッジ流束として既存の掃流砂の機構(apply_edge_flux)に乗せる。攪拌は掃流砂・
  浮遊砂の τ* を波・流れ合成に差し替える。
- **採らない**: 放射応力で沿岸流を SWE に起こす案(案 C。波の屈折・砕波を含む伝播
  計算 = もう 1 本の方程式系が要る)、位相解像の波(案 D)。波浪卓越帯の水理は
  SFINCS・XBeach・Delft3D+SWAN の領分で、ENCflow の位置づけ(comparison.md)を
  変える判断になる。
- **方針 §0 との整合**: 汀線はベクトルでなく水深勾配の向き(ラスタ純化)、追加は
  流束発散 1 本(SWE+1 方程式拡散の内側)、鉛直は線形理論の底面軌道流速で抽象化、
  有効化は fn_wave、無効時ゼロコスト、外部ライブラリなし、入力は波高・周期・向きの
  単純な時系列。
- **検証目標**: 直線汀線の擾乱が低角の波で拡散し高角の波で成長する(Ashton & Murray
  2006 の線形理論)、デルタで R = Q_r/Q_w を変えると鳥趾状 → カスプ状に移る
  (Nienhuis ら 2015)。

## 1. 弧状・カスプ状デルタを作る機構と ENCflow に無いもの

波浪卓越型デルタ(Galloway)の形は、砕波帯の沿岸漂砂が河口の突出を両側へ均すこと
で決まる。沿岸漂砂量は汀線に対する波の入射角 α の関数 Q_s(α) ∝ cos^{6/5}α·sin α で、
|α| < 45° では汀線の凸部が均される(拡散)、|α| > 45° では成長する(反拡散 =
砂嘴・カスプの非対称化)(Ashton & Murray 2006)。Nienhuis ら(2015)は河川の土砂
供給 Q_r と波が運べる最大沿岸漂砂量 Q_w の比 R = Q_r/Q_w で形を整理し、R ≪ 1 で
滑らかなカスプ状、R ≫ 1 で鳥趾状になることを示した。ENCflow には Q_w にあたる
過程がないので R = ∞ の形しか出ない。必要なのは (a) 波の入射角に依存する岸に沿う
土砂流束と、(b) 浅い前縁で波が土砂を動かしやすくする効果の 2 つで、(a) が形を
決め、(b) は嵐時の再配分と泥の再浮上を担う。

## 3. 定式(案 A: 汀線帯の沿岸漂砂 `f_wave_longshore`)

### 3.1 与件
沖(砕波前)の有義波高 H₀ (m)、周期 T (s)、進行方向 φ₀(deg。波が進む向き。x 軸
から反時計回り)。固定値か時系列(潮位 fn_tide と同じ流儀: `wave_val(1:4,:)` =
時刻 (min)、H₀、T、φ₀。線形補間、範囲外は端値)。更新は dt_geomorph の地形更新
ごと(波は地形時間の強制。morfac の扱いは §3.6)。

### 3.2 砕波帯
砕波波高 H_b = 0.39 g^{1/5} (T H₀²)^{2/5}(Komar & Gaughan 1972)、砕波水深
h_b = H_b/γ(γ = 0.78 既定)。砕波帯セル = 湿潤(h > dd)で h ≤ h_b、海域マスク外。
(砕波帯の内側の浅い干潟も含む。乾いたセルは含めない = 土砂は水面より上へ登らない。
§84.2 R2 と同じ)。

### 3.3 汀線方位
汀線はベクトルで持たない。平滑化した水深 h_s(ガウス核、半径 r_s セル。既定 3 =
砕波帯の幅程度)の勾配で岸沖の向きを取る: n̂ = ∇h_s/|∇h_s|(沖向き)、岸平行
t̂ = n̂ を +90° 回したもの。波の相対角 α = φ₀ − 方位(n̂)。|∇h_s| が小さい(平坦な
海底・沖合)セルは汀線方位が定義できないので除外(閾値 S_min)。平滑化は自帯で
計算してハロ交換(r_s がハロ幅 2 を超える場合は r_s を 2 に制限するか、ハロ幅を
広げる。初期実装は r_s ≤ 2)。

### 3.4 沿岸漂砂量
沖波で書いた CERC 式(Ashton & Murray 2006 式 (2)。岸平行等深線の屈折・浅水を
内包):
  Q_s = K₂ H₀^{12/5} T^{1/5} cos^{6/5}(α) sin(α)   [m³/s、空隙込みの体積]
K₂ ≈ 0.34 m^{3/5} s^{−6/5}(K = 0.39、γ = 0.78 の CERC 式を沖波に換算した値。
文献値なので既定に置く。§19.8)。符号は t̂ の向きに沿って sin α の符号で決まる。
Q_s は砕波帯の断面を通る総量なので、単位岸沖幅あたりの流束 q = Q_s/W_b に直す。
W_b = max(h_b/S_s, Δx)(S_s = |∇h_s| = 局所の海底勾配)。各砕波帯セルの流束
ベクトル q⃗ = q t̂(m²/s、固体体積に直すため ×(1 − λ))。

### 3.5 エッジ流束への射影と適用
両セルの q⃗ の平均を ê_k に射影し通過幅を掛けてエッジ流量 gq = (q⃗·ê_k) wl(k)
(掃流砂の dirp と同じ形。§84.3)。受け手が乾いている・受け手の地盤が供給側の
水面以上なら 0(§84.2 R1・R2)、堤防エッジは遮断、河道幅の係数(frw・fwd)は
掃流砂と同じく乗じる。`gm%wrk%q` に**加算**し(掃流砂・側岸侵食と同じ更新で)、
`apply_edge_flux` が供給量制限(可動層 sd。非侵食の崖は給砂しない)・dzmax・
保存則を担う。収束で堆積、発散で侵食。岸沖方向の形は既存の河床勾配補正と安息角が
保つ(汀線が後退すると乾いた側は崩落で追随する = 波による崖の後退は段 2 の
攪拌+側岸侵食則で)。定着(f_fixation)の供給側 τ*c は沿岸漂砂には効かせない
(砕波帯は常時湿潤で a = 0)。

### 3.6 時間と morfac
Q_s は地形時間の量(波は水理の時間刻みと無関係)。geomorph の dts = dt·idt·morfac
をそのまま使う。嵐の時系列は地形時間で与える(morfac > 1 では水理時間の 1/morfac
で進む点に注意。潮位・降雨の時計は加速しないので、波だけ地形時間なのは一貫しない。
**要議論**: 波を水理時間で与えて morfac 倍するか(嵐の継続時間が水理時間)、地形
時間で与えるか(年単位の波候の統計)。初期実装は後者を推奨: 波は「波候」で、
デルタの時間尺度に合う)。

### 3.7 段 3: 遮蔽(段 1 で簡易版を実装済み: 露出度の Jacobi 伝播。§84.15)
デルタ自身の陰(波が当たらない側)を無視すると沿岸漂砂を過大評価する。簡易化は
「露出度」のスカラーを波の進行方向の風上に向かって 8 方向で掃く(陸地に当たれば
0。1 方程式の風上伝播で、ラスタ純化の範囲)。回折は扱わない。段 1・2 の結果を見て
から要否を決める。

## 4. 定式(案 B: 波による攪拌 `f_wave_stir`)

各湿潤セルで H = min(H₀ K_s, γ h)(K_s は浅水係数。線形理論)、波数 k は分散関係
ω² = g k tanh(kh)(近似式。反復 2〜3 回)、底面軌道流速 u_w = π H/(T sinh(kh))、
波の底面せん断応力 τ_w = ½ ρ f_w u_w²(f_w は Swart 型の摩擦係数。粒径から)。
流れとの合成は Soulsby(1997)の τ_m = τ_c [1 + 1.2 (τ_w/(τ_c + τ_w))^{3.2}]
(平均。輸送量式に)と τ_max = ((τ_m + τ_w cos φ)² + (τ_w sin φ)²)^{1/2}(閾値
判定に)。掃流砂(calc_fluvial)と浮遊砂(calc_suspend)の τ* を無次元化して
差し替える。流砂の向きは変えない(流れの向きのまま。波だけでは往復で正味 0 =
向きは A が担う)。無効時は乗算なし(ビット一致)。

## 6. 実装の骨子

- `list_wave`(fn_wave): wave_h0・wave_t・wave_dir(固定値)または wave_val(1:4,:)
  (時系列)、f_wave_longshore、f_wave_stir、wave_k2(0.34)、wave_gamma(0.78)、
  wave_smooth(r_s。既定 2)、wave_smin(汀線方位の勾配下限)、wave_shadow(段 3)。
- `m_geomorph_wave`(submodule): init(与件の検証・配列確保)、update_wave(時系列の
  補間 → H_b・h_b)、calc_wave_longshore(§3.3〜3.5。calc_fluvial と bank の後、
  repose の前に `gm%wrk%q` へ加算)、stir_factor(§4。calc_fluvial/calc_suspend が
  τ* に掛ける係数を返す)、dispose(台帳: 沿岸漂砂の総量・侵食/堆積の体積)。
- MPI: 平滑化は自帯+ハロ交換(h・z・sd のハロを呼び出し前に最新化)、流束は既存の 2 ループ構造。collective なし。np = 2, 4 で逐次とバイト一致(§84.15。初回の不一致は全域端の範囲外読みが原因)。
- save/restore: 状態なし(与件と地形から毎回作る)。
- 計算順(architecture.md §2.2): geomorph_calc の内部で fluvial → bank → **wave** →
  repose → suspend の順(wave の流束は fluvial と同じ apply_edge_flux に乗せるので
  1 回の適用にまとめる)。

## 7. 検証計画

1. **保存・無効時**: f_wave_* = 0 で既存 reference とビット一致。有効時に土砂体積保存
   (閉領域)、乾いたセルへの流入なし、np = 1, 2, 4 のバイト一致、-fcheck np = 2。
2. **直線汀線の線形理論**(test/wave_shore): 一様勾配の海底に正弦波状の汀線擾乱
   (波長 L、振幅 a ≪ L)。低角の波(α = 20°)で振幅が exp(−D k² t) で減衰し、
   D = (K₂ H₀^{12/5} T^{1/5} / D_c)·(d/dα)[cos^{6/5}α sin α](D_c = 閉鎖水深 ≈ h_b)
   に ±20 %。高角の波(α = 60°)で振幅が成長する(符号の検定)。
3. **突出の均し**: 三角形の突出が弧状に均され、頂点の後退量が沿岸漂砂の発散と
   整合(体積収支)。
4. **デルタ**(examples/delta に param_wave を追加): R = Q_r/Q_w を 0.1〜10 で振り、
   汀線の凹凸比と分流路数が R とともに増える。R < 1 でカスプ状(Nienhuis ら 2015 の
   形の分類と比較)。斜め波で非対称(砂嘴)。
   **2026-10-22 保留**: 試行 4 ラン(§84.15 限界)で、(i) 正面入射は河道を遡る、
   (ii) 入射角 45° は砂嘴が伸び続ける、(iii) 容量給砂は入口の供給が 11 倍に暴走、
   (iv) 固定給砂では河道の深み(h > h_b)が波の源になって河道内の砂州に沿岸漂砂が
   働き発散。河口の規則 wave_vmax(流速規則)を同日に追加し test/wave_river で検定済み
   (§84.15)。例題は固定給砂+非侵食河道+wave_vmax で再開し完了(examples/delta の
   baseqb・wave。陸化 2.4 倍、分流路 1 本、風下への砂嘴。格子幅の指状砂州は段 3 の課題)。
   R を振る感度は未実施(handoff.md 00e)。
5. **攪拌**(test/wave_stir。**現状注記 2026-10-22**: 未作成。段 2 の着手時に新設): 静水の斜面に波だけを当てて正味の輸送がゼロ(往復)、
   流れを加えると輸送が増える。嵐の時系列でプロデルタの泥が再浮上する。

## 8. 限界(採用後も残るもの)

波の遮蔽・回折(段 3 で簡易化)、岸沖輸送(前浜・バリア・砂丘)、波のセットアップと
離岸流、砕波帯内の岸沖分布、潮汐流との相互作用、多方向スペクトル(φ₀ は 1 方向)。
これらは案 C 以上の水理(波の伝播と放射応力)を要し、ENCflow の枠外。
