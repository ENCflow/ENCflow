# 乾式斜面侵食 f_splash — 設計・定式化・検証の詳細(splash_plan)

内部開発文書(正本は developer.md §48。本書はその詳細版で、定式化の
根拠・離散化・試行錯誤の全記録・文献を残す)。実装 2026-08-20。

## 1. 背景と問題設定

### 1.1 動機となる観察

高透水性の火砕物からなる台地状火砕丘の縁辺部(例: 新島南部)では、
次の組が観察される:

- 台地内部: 完全に平坦で谷・リル・凹地形が存在しない
- 台地縁辺〜崖: 樹枝状の深い谷が密集し、稜線は鋭い
- 透水係数が極めて高く、**地表流が生じない**(降雨は全量浸透)
- **地下水面が存在しない**(湧水サッピングは排除される)
- 岩相は均質(差別侵食は排除される)

既知の谷形成メカニズム(表面流の移流的侵食・地下水サッピング・
差別侵食)がすべて排除される条件で深い谷が形成されており、
既存の地形発達モデル(LEM)では説明できない。

### 1.2 パラダイムとの関係

地形学では Smith & Bretherton (1972) 以来、「谷(チャンネル)の開始は
**移流的プロセス(表面流)が拡散的プロセスを支配するとき**の不安定化に
よる」が基本パラダイムである。Howard (1994) の剥離制限型モデルは
移流項(ストリームパワー則)と拡散項(マスウェイスティング)の
重ね合わせで排水密度・谷間隔を説明し、Perron et al. (2008, 2009) は
谷間隔 λ が移流係数と拡散係数の比

$$\lambda \propto \sqrt{\frac{K_s}{K_t K_z}}$$

で決まることを示した。一方、「**移流(表面流)がゼロでも谷が形成され
うるか**」に正面から答えた研究は見当たらない(Smith & Bretherton 自身、
移流優位の線形安定解析では最も不安定な波数が無限大になる=有限の
谷間隔を説明できない、という問題を原論文に内包していた)。

f_splash は、この問いに対する仮説

> グリッドスケールの移流なしに、**サブグリッドスケールの移流効果の
> パラメータ化**(凹地形でのリル・粒子転動の集中)によって谷形成が可能

を数値実験できるようにする ENCflow の地形変化成分である。物理的
実体としては、(a) 凹地形での微地形的集水によるリル密度の増大、
(b) 雨滴衝突で乾いた砂面を転がる粒子集合体(sandball)が凹部へ集中する
機構(Trottet et al., 2025)が対応する。

### 1.3 Howard (1994, 1997) モデルとの対比

Howard の枠組み(各セルで斜面・河川プロセスを重ね合わせ):

$$\left.\frac{\partial z}{\partial t}\right|_m = -\nabla\cdot\mathbf{q}_m,\qquad
q_m = \left[K_s\,\mathscr{G}(S) + K_f\left(\frac{1}{1-K_x|S|^\alpha}-1\right)\right]$$

$$\left.\frac{\partial z}{\partial t}\right|_c = -K_t K_z A^{g} S^{h} \quad (g\approx0.3,\ h\approx0.7)$$

に対し、f_splash は次の点で意図的に異なる:

| 項目 | Howard 型 | f_splash |
|---|---|---|
| 基本構造 | 連続の式(領域内で土砂保存) | 浸食と堆積の分離(系外排出を許容) |
| 移流項 | 集水面積 A 依存(表面流) | A を使わない(表面流なし)。S^h × 凹地形乗数 |
| 拡散項 | モデルに内蔵 | **持たない**(必要なら既存 f_creep を重ね合わせ) |
| 適用対象 | 湿潤・閉じた系 | 乾燥・開いた系(急崖→海) |

拡散項を f_splash 自身が持たない根拠: (1) 対象斜面(裸地火砕物・
バッドランド)ではクリープを担う土壌・植生がなく K_s ≈ 0、
(2) 侵食土砂は遠方(海)に排出され隣接セルに堆積しないため、連続の
式による局所再分配が物理的に不適切、(3) ENCflow では拡散が必要な場合
f_creep の重ね合わせで表現でき、係数を独立に制御できる(§6.2 の
とおり、これが谷間隔の選択に本質的な役割を果たす)。

## 2. 定式化

### 2.1 浸食則(連続形)

地表到達降雨強度を P [m/s]、勾配の大きさを S = |∇z|、凹地形で正の
曲率を κ = max(∇²z, 0) [1/m] として、固体体積の浸食レート
E [m/s] を

$$E \;=\; P\,\Bigl[\,k_r\,\Phi_A(\kappa) \;+\; k_t\,\Phi_B(\kappa)\,S^{\,h}\Bigr],
\qquad \Phi_A = 1 + c_a\,\kappa,\quad \Phi_B = 1 + c_b\,\kappa$$

とする(namelist: k_r = spl_kr, c_a = spl_ca, k_t = spl_kt,
c_b = spl_cb, h = spl_h)。

- **第1項(雨滴・スプラッシュ)**: 表面流と独立のメカニズムで、
  S → 0 の平坦な台地上でも働く**加算項**。曲率増幅 Φ_A は
  雨滴・転動粒子の凹部への集中を表す(将来の風向依存は Φ_A 側に
  入る。§8)。
- **第2項(サブグリッドリル)**: DEM に表現されない微地形の集水に
  よるリル・転動の集中を、移流的侵食の効率変調(**乗算**)として
  パラメータ化する。S → 0 で消えるため「台地上に谷が生じない」が
  構造的に保証される(加算では不可能 — 議論記録第7部の乗算根拠)。
  κ 依存の Φ_B が「凹部ほど侵食が速い → さらに凹む」の正の
  フィードバック(谷形成の核心)を与える。
- 両項とも P に比例させる(侵食は降雨イベント駆動。無降雨時は
  E = 0)。k_r, k_t は無次元、c_a, c_b は長さ [m](κ [1/m] との積が
  無次元)、h は無次元。

### 2.2 適用範囲と土砂の行き先

- **乾燥セル(h ≤ dd)のみ**。湿潤セルは既存の f_wash(雨滴+面状
  侵食 → 浮遊砂輸送)の管轄で、**相補**により二重計上しない。
- 河道セル(rw > 0)・海セル・領域外は対象外。ただし海セルの z は
  勾配・曲率の近傍としては読む(海食崖の縁がまさに侵食対象)。
- 剥離土砂は浮遊砂 hs に注入**しない**(表面流がないため移流できない)。
  **系外排出**とし(開いた系)、排出体積を台帳に積んで終了時に報告
  する。堆積を陽に解く場合の受け皿は容量式

  $$D(x,t) = \max\Bigl(0,\ \sum_{\mathrm{upstream}} Q_s - Q_c(S, A)\Bigr)\Big/\delta^2$$

  (D8 経路の輸送・堆積)だが、対象領域(急崖→海)では D ≈ 0 の
  ため Phase 3 に先送りした(§8)。
- 剥離は z と土層厚 sd の**共動更新**(帯水層底 z − sd 不変)で、
  sd = 0 に達したセルは岩盤露出として停止する(基岩風化 f_wthr と
  組で収支が閉じる)。地下水有効時は容量 sd·sy0 の縮小超過分を
  地表水へ引き渡す(f_wash と同一規約)。

### 2.3 離散化

格子幅 dx, dy、5点ラプラシアンと中央差分:

$$
\kappa_{ij} = \max\!\left(\frac{z_{i+1,j}+z_{i-1,j}-2z_{ij}}{\Delta x^2}
 + \frac{z_{i,j+1}+z_{i,j-1}-2z_{ij}}{\Delta y^2},\ 0\right)
$$

$$
S_{ij} = \sqrt{\left(\frac{z_{i+1,j}-z_{i-1,j}}{2\Delta x}\right)^2
 + \left(\frac{z_{i,j+1}-z_{i,j-1}}{2\Delta y}\right)^2}
$$

無効な近傍(配列範囲外・領域外 x=0)は自セル値で鏡像(寄与ゼロ)。
1回の地形更新(実効時間 Δt_geo = dt × idt_geomorph × morfac)の
河床低下量は、空隙率 λ(fluv_porosity)による体積換算込みで

$$\Delta z_b = \min\!\Bigl(\ E\,\Delta t_{geo}\,\frac{1}{1-\lambda},\ \ sd,\ \ \Delta z_{max}\Bigr)$$

(Δz_max = spl_dzmax > 0 のときのみ。フィードバック暴走の安全弁で、
発動回数を終了時に報告する)。排出固体体積の台帳は
Σ Δz_b (1−λ) dx dy。

### 2.4 スケール依存性について

Φ_B はサブグリッド効果のパラメータ化なので、係数 c_b は原理的に
格子幅 δ に依存する(気候モデルの対流パラメータ化と同じ論理構造)。
本実装では δ 依存の関数形を固定せず、係数の較正に委ねる
(δ を跨ぐ較正則の確立は Phase 2 の課題。§8)。

## 3. 実装(m_geomorph の加算成分)

設計判断(developer.md §48): 独立モジュールではなく **m_geomorph の
加算フラグ**(creep / wash / debris と同型)。z・sd の所有、
e = z + h 回復(水深保存契約)、リスタート、MORFAC 台帳、可動層
クランプを単一実装のまま継承するため。内部状態を持たないので
save/restore への追加はない。無効時は配列確保・計算ともゼロ。

### 3.1 MPI: 2パス構造と適用順

勾配・曲率が近傍の z を読むため、m_geomorph_calc 内の適用順を

1. `eval_splash` — **時刻 n の z** から侵食量を評価し spl%fx に格納
   (calc_debris より前 = debris の「先頭で時刻 n の z を読む」契約と
   両立)
2. `calc_debris` — 従来どおり
3. `apply_splash` — 局所適用(近傍を読まない)
4. **z のハロ交換**(f_splash と後続の近傍参照プロセス(f_creep /
   f_fluvial)が併用される場合のみ。§6.3 の実バグ対策)
5. fluvial → suspend → wash → creep → 風化 → 隆起(従来どおり)

とする。排出台帳の集計は行別部分和 → 逐次総和(スレッド数に
よらず決定的)。

## 4. 解析検証(test/splash)

遷緩点付き斜面(ユーザールーチン slope_break: tanθ = 0.4、遷緩点
x = 30 m)+一様降雨 30 mm/h + Green-Ampt(ksv = 72 mm/h > P)で
**全時間 h = 0(地表流なし)**を保証し、凹地形増幅を切る
(c_a = c_b = 0)と浸食深が解析的になる:

$$\Delta z = P\,(k_r + k_t S)\,\frac{T_{geo}}{1-\lambda}$$

パラメータ(k_r = 0.003, k_t = 0.0175, h = 1, λ = 0, T_geo =
tt × morfac = 3600 × 5 = 18000 s, P = 30/3.6×10⁶ m/s)に対する
理論値と結果:

| 領域 | S(離散) | 理論 Δz | 結果 |
|---|---|---|---|
| 斜面内部(i=2..29) | 0.4 | 1.5000×10⁻³ m | 一致(出力桁) |
| 平坦部(i=32..49) | 0 | 4.5×10⁻⁴ m | 一致 |
| 境界列 i=1(鏡像で S 半減) | 0.2 | 9.75×10⁻⁴ m | 一致 |
| 遷緩点 i=30 / i=31(中央差分) | 0.3 / 0.1 | 1.2375×10⁻³ / 7.125×10⁻⁴ m | 一致 |
| **総排出体積**(全列クラスの解析和 × 12 行) | — | **0.6417 m³** | **0.64170 m³(表示全桁一致)** |

貯留台帳: S_grnd(3600 s) = P×3600 = 0.0300 m(全量浸透)も一致。
MPI は np = 1, 2, 4 が逐次 reference に ULP=0、gfortran -fcheck=all
(np=2)で splash・chichibu ともクリーン完走。

## 5. 模式実験: 表面流なしの谷形成(§48.1 の記録の詳細)

台地(z = 15 m)+擾乱付き急崖(tanθ = 1.5 ≈ 56°、縁位置に
±0.5 m の 2 モード正弦擾乱)、一様降雨 10 mm/h、全量浸透。
k_t = 0.05, c_b = 8, h = 1.5, T_geo = 1.8×10⁶ s。

結果(f_creep = 5×10⁻⁷ m²/s 併用時): 全時間 h = 0 のまま、

- 台地内部: 均一 ~2 mm(k_r 項のみ。**谷ゼロ** — 標準偏差 8×10⁻⁵ m)
- 崖縁: y 方向起伏が 0.5 → 1.5〜1.6 m(×3)に成長、最大下刻 5 m、
  谷 9 本、稜線鋭化

「台地上に谷なし・端部に深い谷」の観察がグリッドスケールの移流なしに
再現された。

## 6. 試行錯誤の記録(そのまま残す)

### 6.1 発散(パラメータ過大)

最初の試行(morfac = 5000, spl_dzmax = 0.5): dzmax クリップが全面
発火(33771 セル)しつつ深さ ~90 m の穴が開き、水がそこへ集中して
流速 250 m/s 超で発散停止。**安全弁(クリップ+発動報告)と発散検知は
設計どおり働いた**が、フィードバック時定数に対して地形加速が
桁違いに過大だった。教訓: spl_dzmax は「1回の更新で地形の局所起伏を
作り変えない」大きさ(格子スケール地形の 1/10 程度)にする。

### 6.2 格子スケールの市松模様(無限波数問題の顕在化)

morfac = 500, dzmax = 0.05 に落とすと谷は形成されたが、侵食帯に
1セル周期の市松状凹凸が卓越した。これは **Smith & Bretherton (1972)
が内包していた「移流優位では最も不安定な波数が無限大」問題**が
そのまま数値に現れたもので、κ の正フィードバックは反拡散だから
最短波長(= 2Δx)が最速成長する。バグではなく理論どおりの性質。

対策 = **弱い f_creep(線形拡散)の重ね合わせ**。波長選択は増幅
(c_b)と拡散(creep_d)の比で決まり、Perron et al. (2008, 2009) の
λ ∝ √(K_s/K) と同じ構図になる。実験系列:

| creep_d (m²/s) | 崖縁起伏(0.5 m 初期) | 評価 |
|---|---|---|
| 0(なし) | ×5〜6 に成長するが市松卓越 | 波長選択なし |
| 5×10⁻⁷ | ×3。谷 9 本・市松弱残存 | **採用**(実証実験) |
| 1.5×10⁻⁶ | ×1(ほぼ成長せず) | 拡散優位の入口 |
| 3×10⁻⁶ | ×0.4〜0.8(擾乱が減衰) | 完全に拡散優位 |

増幅と拡散の比の**窓**の中でだけ「有限波長の谷が成長」する —
これ自体が理論(谷間隔の選択則)と整合する挙動である。κ 評価の
平滑化(市松の別対策)は Phase 2 課題(§8)。

### 6.3 帯界面のランク数依存(test/splashslide が検出した実バグ)

splash と creep を併用した対照テスト(§7)の初版で、MPI の
state.dat が逐次とバイト不一致になった。原因: apply_splash が帯内の
z を更新した後、creep が近傍 z を読む際に**ハロ行だけ時刻 n のまま**
残り、帯界面のエッジフラックスを両側ランクが異なる入力(自帯=更新後、
ハロ=旧値)から計算していた。修正: apply_splash の後、後続に
近傍参照プロセス(f_creep / f_fluvial)がある場合に z(fluvial 併用時は
sd も)のハロ交換を追加。修正後 np = 1, 2, 4 でバイト一致。
(同構造の潜在問題は debris → creep/fluvial の併用にもあり得るが、
この交換は debris の更新も配布するため同時に塞がれる。)

### 6.4 崩壊深の連鎖反応(対照テストの調整)

未固結構成(f_slide, c′ = 0)の初版(sd0 = 20 m)では、1回の崩壊が
土層全厚を流動化 → 隣接セルに 20 m の段差 → tanθ ≫ tanφ_s → 連鎖
崩壊が**平坦な台地内部まで**伝播し、全域が岩盤まで掘り抜かれた。
c′ = 0 の無限長斜面判定では、1セル段差の勾配 sd/Δx が tanφ_s を
超える限り伝播が止まらない(離散モデルの構造)。さらに土石流の
E-D(f_dbed = 1)が定常運転で河床を自己加速的に連行し、掘削を深めた。

対策: (1) **sd ≤ Δx·tanφ_s** を満たす土層厚にする(段差が安息角以下
→ 伝播が自然停止)。採用値: Δx = 2 m, φ_s = 35°(tanφ_s = 0.70)、
sd0 = 1.3 m(段差勾配 0.65)。(2) 土石流は **f_dbed = 0(交換なし=
等価流体)+ f_dbstop = 1(低速凝集)**とし、「崩れて・流れて・積もる」
だけの安息角緩和モードに限定(連行の自己加速を遮断)。

## 7. 白ママ対照テスト(test/splashslide)

同一地形・同一降雨・同一 splash 係数で、崖の固結度だけを変えた
2 構成の対照実験。「**谷形成の真の臨界条件は崖面の固結度**(凹部が
維持されるか)」という仮説の数値版(sandball 機構が最も活発なはずの
未固結砂面=白ママ断崖に谷がない、という野外の内部対照に対応)。

- 構成1(param_c.txt、固結): f_splash + 弱 creep のみ。崖(56°)は
  安息角を超えて自立 → 凹部が維持され、起伏が成長する。
- 構成2(param_l.txt、未固結): + f_debris + f_slide(**c′ = 0**,
  φ_s = 35°)。崖は安息角まで緩和し、splash が刻む凹部も
  Fs < 1 → 流動化 → 埋め戻しでリセットされる。

検定(Check_contrast.py。崖面帯の y 方向起伏 = 谷の指標):

| 判定 | 固結(c) | 未固結(l) |
|---|---|---|
| 起伏成長比(final/init) | **×1.34 ≥ 1.25** | **×0.75 ≤ 0.9** |
| 台地内部(x ≤ 12 m)の不変 | max\|Δz\| = 0 | max\|Δz\| = 0 |
| 侵食下限の有界(z ≥ −1.5 m) | −1.22 | −1.30 |

MPI は np = 2, 4 とも state.dat が逐次とバイト一致。
補足: 下限判定を sd0 ちょうどにしない理由は、creep が仕様上 sd に
触れない(z − sd = 岩盤面が厳密不変でない)ため(m_geomorph
ヘッダに記載の既知の妥協)。

## 8. 既知の限界と積み残し

- **Phase 2**: 雨滴項の風向・風速依存 Φ_A(κ, θ_wind)(雨滴の斜め
  軌道による風上谷壁への運動量集中)。κ 評価の平滑化(市松の
  数値的抑制の別解)。実 DEM(1 m 級)での係数較正と、格子幅 δ を
  跨ぐ Φ_B の較正則。
- **Phase 3**: 容量式の堆積(§2.2 の D 式、D8 経路)。崖下が海で
  ない内陸バッドランドへの適用に必要。
- Φ_B の関数形(1 + c_b κ の線形)は最も単純な仮定であり、飽和形
  (上限付き)等の検討余地がある。
- 谷間隔の定量(λ と c_b/creep_d 比の関係の系統実験)は未実施。
