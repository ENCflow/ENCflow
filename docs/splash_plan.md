# 乾式斜面侵食 f_splash — 設計・定式化・検証の詳細(splash_plan)

内部開発文書(正本は developer.md §48。本書はその詳細版で、定式化の
根拠・離散化・試行錯誤の全記録・文献を残す)。実装 2026-08-20、
曲率の相関長 spl_lc と侵食基準面 spl_zbase の追加 2026-10-19(§2.5・§6.6)。

## 1. 背景と問題設定

### 1.1 動機となる観察

高透水性の火砕物からなる台地状火砕丘の縁辺部(例: 新島南部)では、
次の組が観察される:

- 台地内部: 完全に平坦で谷・リル・凹地形が存在しない
- 台地縁辺〜崖: 樹枝状の深い谷が密集し、稜線は鋭い
- 透水係数が極めて高く、**地表流が生じない**(降雨は全量浸透)
- **地下水面が存在しない**(湧水サッピングは排除される)
- 岩相は均質(差別侵食は排除される)

既知の谷形成メカニズム(表面流の移流的侵食・地下水サッピング・
差別侵食)がすべて排除される条件で深い谷が形成されており、
既存の地形発達モデル(LEM)では説明できない。

### 1.2 パラダイムとの関係

地形学では Smith & Bretherton (1972) 以来、「谷(チャンネル)の開始は
**移流的プロセス(表面流)が拡散的プロセスを支配するとき**の不安定化に
よる」が基本パラダイムである。Howard (1994) の剥離制限型モデルは
移流項(ストリームパワー則)と拡散項(マスウェイスティング)の
重ね合わせで排水密度・谷間隔を説明し、Perron et al. (2008, 2009) は
谷間隔 λ が移流係数と拡散係数の比

$$\lambda \propto \sqrt{\frac{K_s}{K_t K_z}}$$

で決まることを示した。一方、「**移流(表面流)がゼロでも谷が形成され
うるか**」に正面から答えた研究は見当たらない(Smith & Bretherton 自身、
移流優位の線形安定解析では最も不安定な波数が無限大になる=有限の
谷間隔を説明できない、という問題を原論文に内包していた)。

f_splash は、この問いに対する仮説

> グリッドスケールの移流なしに、**サブグリッドスケールの移流効果の
> パラメータ化**(凹地形でのリル・粒子転動の集中)によって谷形成が可能

を数値実験できるようにする ENCflow の地形変化成分である。物理的
実体としては、(a) 凹地形での微地形的集水によるリル密度の増大、
(b) 雨滴衝突で乾いた砂面を転がる粒子集合体(sandball)が凹部へ集中する
機構(Trottet et al., 2025)が対応する。

### 1.3 Howard (1994, 1997) モデルとの対比

Howard の枠組み(各セルで斜面・河川プロセスを重ね合わせ):

$$\left.\frac{\partial z}{\partial t}\right|_m = -\nabla\cdot\mathbf{q}_m,\qquad
q_m = \left[K_s\,\mathscr{G}(S) + K_f\left(\frac{1}{1-K_x|S|^\alpha}-1\right)\right]$$

$$\left.\frac{\partial z}{\partial t}\right|_c = -K_t K_z A^{g} S^{h} \quad (g\approx0.3,\ h\approx0.7)$$

に対し、f_splash は次の点で意図的に異なる:

| 項目 | Howard 型 | f_splash |
|---|---|---|
| 基本構造 | 連続の式(領域内で土砂保存) | 浸食と堆積の分離(系外排出を許容) |
| 移流項 | 集水面積 A 依存(表面流) | A を使わない(表面流なし)。S^h × 凹地形乗数 |
| 拡散項 | モデルに内蔵 | **持たない**(必要なら既存 f_creep を重ね合わせ) |
| 適用対象 | 湿潤・閉じた系 | 乾燥・開いた系(急崖→海) |

拡散項を f_splash 自身が持たない根拠: (1) 対象斜面(裸地火砕物・
バッドランド)ではクリープを担う土壌・植生がなく K_s ≈ 0、
(2) 侵食土砂は遠方(海)に排出され隣接セルに堆積しないため、連続の
式による局所再分配が物理的に不適切、(3) ENCflow では拡散が必要な場合
f_creep の重ね合わせで表現でき、係数を独立に制御できる(§6.2 の
とおり、これが谷間隔の選択に本質的な役割を果たす)。

## 2. 定式化

### 2.1 浸食則(連続形)

地表到達降雨強度を P [m/s]、勾配の大きさを S = |∇z|、凹地形で正の
曲率を κ = max(∇²z, 0) [1/m] として、固体体積の浸食レート
E [m/s] を

$$E \;=\; P\,\Bigl[\,k_r\,\Phi_A(\kappa) \;+\; k_t\,\Phi_B(\kappa)\,S^{\,h}\Bigr],
\qquad \Phi_A = 1 + c_a\,\kappa,\quad \Phi_B = 1 + c_b\,\kappa$$

とする(namelist: k_r = spl_kr, c_a = spl_ca, k_t = spl_kt,
c_b = spl_cb, h = spl_h)。

- **第1項(雨滴・スプラッシュ)**: 表面流と独立のメカニズムで、
  S → 0 の平坦な台地上でも働く**加算項**。曲率増幅 Φ_A は
  雨滴・転動粒子の凹部への集中を表す(将来の風向依存は Φ_A 側に
  入る。§8)。
- **第2項(サブグリッドリル)**: DEM に表現されない微地形の集水に
  よるリル・転動の集中を、移流的侵食の効率変調(**乗算**)として
  パラメータ化する。S → 0 で消えるため「台地上に谷が生じない」が
  構造的に保証される(加算では不可能 — 議論記録第7部の乗算根拠)。
  κ 依存の Φ_B が「凹部ほど侵食が速い → さらに凹む」の正の
  フィードバック(谷形成の核心)を与える。
- 両項とも P に比例させる(侵食は降雨イベント駆動。無降雨時は
  E = 0)。k_r, k_t は無次元、c_a, c_b は長さ [m](κ [1/m] との積が
  無次元)、h は無次元。

### 2.2 適用範囲と土砂の行き先

- **乾燥セル(h ≤ dd)のみ**。湿潤セルは既存の f_wash(雨滴+面状
  侵食 → 浮遊砂輸送)の管轄で、**相補**により二重計上しない。
- 河道セル(rw > 0)・海セル・領域外は対象外。ただし海セルの z は
  勾配・曲率の近傍としては読む(海食崖の縁がまさに侵食対象)。
- 剥離土砂は浮遊砂 hs に注入**しない**(表面流がないため移流できない)。
  **系外排出**とし(開いた系)、排出体積を台帳に積んで終了時に報告
  する。堆積を陽に解く場合の受け皿は容量式

  $$D(x,t) = \max\Bigl(0,\ \sum_{\mathrm{upstream}} Q_s - Q_c(S, A)\Bigr)\Big/\delta^2$$

  (D8 経路の輸送・堆積)だが、対象領域(急崖→海)では D ≈ 0 の
  ため Phase 3 に先送りした(§8)。
- 剥離は z と土層厚 sd の**共動更新**(帯水層底 z − sd 不変)で、
  sd = 0 に達したセルは岩盤露出として停止する(基岩風化 f_wthr と
  組で収支が閉じる)。地下水有効時は容量 sd·sy0 の縮小超過分を
  地表水へ引き渡す(f_wash と同一規約)。

### 2.3 離散化

格子幅 dx, dy、5点ラプラシアンと中央差分:

$$\kappa_{ij} = \max\!\left(\frac{z_{i+1,j}+z_{i-1,j}-2z_{ij}}{\Delta x^2}
 + \frac{z_{i,j+1}+z_{i,j-1}-2z_{ij}}{\Delta y^2},\ 0\right)$$

$$S_{ij} = \sqrt{\left(\frac{z_{i+1,j}-z_{i-1,j}}{2\Delta x}\right)^2
 + \left(\frac{z_{i,j+1}-z_{i,j-1}}{2\Delta y}\right)^2}$$

無効な近傍(配列範囲外・領域外 x=0)は自セル値で鏡像(寄与ゼロ)。
1回の地形更新(実効時間 Δt_geo = dt × idt_geomorph × morfac)の
河床低下量は、空隙率 λ(fluv_porosity)による体積換算込みで

$$\Delta z_b = \min\!\Bigl(\ E\,\Delta t_{geo}\,\frac{1}{1-\lambda},\ \ sd,\ \ \Delta z_{max}\Bigr)$$

(Δz_max = spl_dzmax > 0 のときのみ。フィードバック暴走の安全弁で、
発動回数を終了時に報告する)。排出固体体積の台帳は
Σ Δz_b (1−λ) dx dy。

### 2.4 スケール依存性について

Φ_B はサブグリッド効果のパラメータ化なので、係数 c_b は原理的に
格子幅 δ に依存する(気候モデルの対流パラメータ化と同じ論理構造)。
本実装では δ 依存の関数形を固定せず、係数の較正に委ねる
(δ を跨ぐ較正則の確立は Phase 2 の課題。§8)。

### 2.5 曲率の相関長 ℓ(spl_lc)と侵食基準面(spl_zbase。2026-10-19)

§2.4 の「c_b は格子幅に依存する」問題と §6.2・§6.5 の「間隔が格子に張り付く」
問題は同根で、κ を格子の 5 点ラプラシアンで取る限り V 字谷底の κ が 2S/Δx、
最速成長波長が 2Δx になることに由来する。κ を**相関長 ℓ で平滑化した z**
から取ると(ガウス核、標準偏差 ℓ)、擾乱の線形成長率は

$$\sigma(k) = D_a\,k^2\,e^{-\ell^2k^2/2},\qquad
D_a = P\,k_t\,c_b\,S^{h}$$

で、有限の波数 $k^* = \sqrt{2}/\ell$ で極大を持つ。谷間隔
$\lambda^* = 2\pi\ell/\sqrt{2} \approx 4.4\,\ell$ は $\ell$(サブグリッドリルの
集水スケール = パラメータ化の物理的な長さ)だけで決まる物理量になり、
V 字谷底の $\tilde\kappa$ も $\sim 2S/\ell$ に有界になる。$c_b$ は成長の速さ
($\sigma_{max} = 2 D_a/(e\,\ell^2)$)を決め、間隔には効かない、という役割分担。

**クリープは併用しない**(利用者の指示 2026-10-19: 力学的モデルでない)。
§6.2 の「弱い f_creep の重ね合わせ」は格子の κ の市松を抑える対症療法で、
相関長を入れた今は不要。参考として、拡散項 $D$ を足した場合の成長率は
$\sigma = k^2[D_a e^{-\ell^2k^2/2} - D]$ で、$u = \ell^2k^{*2}$ は
$R e^{-u/2}(1 - u/2) = 1$($R = D_a/D$)の根($R \to \infty$ で 4.4 ℓ、$R = 4$ で
約 6 ℓ)— 初版の creep 併用実験(§6.6 の表)で 5〜6 ℓ が出た理由。
拡散項なしでは短波長の擾乱は減衰せず中立にとどまる(成長しないだけ)。

離散化: 5 点核(自セル $1 - 2w_x - 2w_y$、x 近傍 $w_x$、y 近傍 $w_y$)を
$N = 4(\ell/\Delta_{min})^2$ 回反復($w = \ell^2/(2N\Delta^2)$、$\Delta_x = \Delta_y$ で
$1/8$)。各パスの分散は方向ごとに $2w\Delta^2$ で、$N$ パス後に $\ell^2$。核の
伝達関数 $1 - 2w_x(1-\cos k_x\Delta) - 2w_y(1-\cos k_y\Delta)$ が市松モードで非負
($w_x + w_y \le 1/4$)であることが必須(§6.6)。勾配 $S$ は生の $z$ から取る
(侵食率の位置依存そのもの)。

侵食基準面 spl_zbase: 崖下が海の系では海面以下を削らない($z \le z_{base}$ の
セルは対象外、$\Delta z_b \le z - z_{base}$)。sd による岩盤露出とは独立の量
(§6.6 の理由)。

### 2.6 検討: 雨滴項の輸送化(飛散長 L_h)と勾配評価の修正(2026-10-19)

クリープを外した理由は「保存則は満たすが浸食速度に物理的根拠がない」こと
(利用者 2026-10-19)。クリープが担っていた 2 つの数値的役割 — (i) 1 セル幅の
尾根をならす、(ii) 格子スケールの凹凸を減衰させる — を、物理的根拠のある
形で置き換える案を検討した。

**(a) 雨滴項の輸送化。** 現行の第 1 項 $P k_r$ は「雨滴が剥離した体積」を
系外排出している。実際には剥離した粒子(または Trottet らの sandball)は
斜面の下方へ有限距離だけ移動して再堆積する。剥離率 $P k_r$ に斜面下方への
正味の移動距離 $L_h S$(飛散長 $L_h$ × 勾配。Furbish らの実験で下方への
偏りは勾配に比例し、飛散距離の分布は指数型)を掛けると、単位幅あたりの
輸送流束は

$$\mathbf{q}_s = -\,P\,k_r\,L_h\,\nabla z,\qquad
\left.\frac{\partial z}{\partial t}\right|_s = -\nabla\cdot\mathbf{q}_s
 = P\,k_r\,L_h\,\nabla^2 z$$

で、形は線形拡散だが係数 $D_s = P k_r L_h$ の 3 因子はいずれも測れる量
(降雨強度・雨滴剥離率・飛散長)で、無降雨時は 0 になる。これがクリープ
との違いで、定数の物理的意味が明確。台地($S = 0$)では正味の移動がなく
標高は変わらない(現行の一様な台地低下はなくなる)。

**桁の見積もり。** 雨滴剥離率 $k_r$ は裸地で 1 m の降雨あたり
10⁻³〜10⁻² m(土壌侵食実験の典型値。本例題の 2×10⁻⁴ は保守的)、飛散長は
粒子の飛散で $L_h$ = 0.02〜0.1 m(室内)、野外較正では 1 桁大きく 0.1〜0.3 m
(Ghahramani らの Furbish モデル較正)、sandball の転動では 30° 斜面で
1 m 級(Trottet ら 2025)。$P$ = 10 mm/h で $D_s$ = 10⁻¹⁰〜3×10⁻⁸ m²/s、
T_geo = 9×10⁶ s での拡散長 $\sqrt{D_s T}$ は 0.03〜0.5 m。すなわち
**1 m 格子の谷(間隔 10 m、深さ 30 m)の尺度では効かない**。1 セル幅の尾根
(曲率 $2H/\Delta x^2$)に対してだけ $D_s \cdot 2H/\Delta x^2$ = 10⁻⁷ m/s 級の
低下を与えうるが、それは格子依存の効き方で物理ではない。役割 (i)(ii) の
置き換えにはならず、入れるなら「物理的に存在する小さな項」として入れる
(例題の試算: $D_s$ = 2.8×10⁻⁸ の上限値で主ケースを走らせた比較を §6.7)。

**sandball と系外排出の関係。** 急斜面では sandball は斜面の末端(海)まで
転がる = $L_h \to \infty$。現行の「剥離して系外排出」はこの極限で、
緩斜面の有限 $L_h$ と連続につなぐには $L_h(S)$(停止勾配に近づくと発散)の
形が要る。これは Phase 3 の堆積(§8)と同じ課題で、本検討では保留。

**(b) 勾配評価の修正(spl_sgrad = 1。実装済み、2026-10-19 に既定化)。** 稜線の頂の
セルは中央差分の勾配が左右で打ち消して $S \approx 0$ になり、1 セル幅の
尾根は雨滴項でしか削れない(主ケースの最終地形で稜線の 56 % が 1 セル幅、
10 % は台地の高さのまま)。本当の尾根は両面の斜面が削られて頂が下がる。
$S$ を最急降下(8 近傍への下り勾配 $(z_c - z_n)/d$ の最大)で取ると、頂の
セルは面の勾配で削れ、尾根の鋭さは「面の勾配で決まる有限の値」になる。
副次効果として、市松(1 セルおきの凹凸)は高いセルだけが $S > 0$ になって
削られ、低いセル($S = 0$)は削れないので**減衰する** — 格子ノイズの減衰も
物理(高い方の面が削れる)から出る。test/splash の解析形は
$\Delta z = P(k_r + k_t S)T$ のまま、遷緩点の列が「中央差分の平均」でなく
面の値になり(§6.7)、境界列の鏡像半減もなくなる(解析としては単純化)。
結果は §6.7。

## 3. 実装(m_geomorph の加算成分)

設計判断(developer.md §48): 独立モジュールではなく **m_geomorph の
加算フラグ**(creep / wash / debris と同型)。z・sd の所有、
e = z + h 回復(水深保存契約)、リスタート、MORFAC 台帳、可動層
クランプを単一実装のまま継承するため。内部状態を持たないので
save/restore への追加はない。無効時は配列確保・計算ともゼロ。

### 3.1 MPI: 2パス構造と適用順

勾配・曲率が近傍の z を読むため、m_geomorph_calc 内の適用順を

1. `eval_splash` — **時刻 n の z** から侵食量を評価し spl%fx に格納
   (calc_debris より前 = debris の「先頭で時刻 n の z を読む」契約と
   両立)
2. `calc_debris` — 従来どおり
3. `apply_splash` — 局所適用(近傍を読まない)
4. **z のハロ交換**(f_splash と後続の近傍参照プロセス(f_creep /
   f_fluvial)が併用される場合のみ。§6.3 の実バグ対策)
5. fluvial → suspend → wash → creep → 風化 → 隆起(従来どおり)

とする。排出台帳の集計は行別部分和 → 逐次総和(スレッド数に
よらず決定的)。

## 4. 解析検証(test/splash)

遷緩点付き斜面(ユーザールーチン slope_break: tanθ = 0.4、遷緩点
x = 30 m)+一様降雨 30 mm/h + Green-Ampt(ksv = 72 mm/h > P)で
**全時間 h = 0(地表流なし)**を保証し、凹地形増幅を切る
(c_a = c_b = 0)と浸食深が解析的になる:

$$\Delta z = P\,(k_r + k_t S)\,\frac{T_{geo}}{1-\lambda}$$

パラメータ(k_r = 0.003, k_t = 0.0175, h = 1, λ = 0, T_geo =
tt × morfac = 3600 × 5 = 18000 s, P = 30/3.6×10⁶ m/s)に対する
理論値と結果:

| 領域 | S(離散) | 理論 Δz | 結果 |
|---|---|---|---|
| 斜面内部(i=2..29) | 0.4 | 1.5000×10⁻³ m | 一致(出力桁) |
| 平坦部(i=32..49) | 0 | 4.5×10⁻⁴ m | 一致 |
| 境界列 i=1(鏡像で S 半減) | 0.2 | 9.75×10⁻⁴ m | 一致 |
| 遷緩点 i=30 / i=31(中央差分) | 0.3 / 0.1 | 1.2375×10⁻³ / 7.125×10⁻⁴ m | 一致 |
| **総排出体積**(全列クラスの解析和 × 12 行) | — | **0.6417 m³** | **0.64170 m³(表示全桁一致)** |

貯留台帳: S_grnd(3600 s) = P×3600 = 0.0300 m(全量浸透)も一致。

## 5. 模式実験: 表面流なしの谷形成(§48.1 の記録の詳細)

台地(z = 15 m)+擾乱付き急崖(tanθ = 1.5 ≈ 56°、縁位置に
±0.5 m の 2 モード正弦擾乱)、一様降雨 10 mm/h、全量浸透。
k_t = 0.05, c_b = 8, h = 1.5, T_geo = 1.8×10⁶ s。

結果(f_creep = 5×10⁻⁷ m²/s 併用時): 全時間 h = 0 のまま、

- 台地内部: 均一 ~2 mm(k_r 項のみ。**谷ゼロ** — 標準偏差 8×10⁻⁵ m)
- 崖縁: y 方向起伏が 0.5 → 1.5〜1.6 m(×3)に成長、最大下刻 5 m、
  谷 9 本、稜線鋭化

「台地上に谷なし・端部に深い谷」の観察がグリッドスケールの移流なしに
再現された。

**白色雑音版(2026-08-20 改訂。examples/badland に収録)**: 正弦擾乱は
谷間隔を初期条件で規定してしまう(利用者指摘)ため、縁位置の擾乱を
シード固定の白色雑音(±0.5 m)に置き換えた。結果: 谷は雑音からでも
自己形成され(起伏 0.45 → 1.67 m = ×3.7、台地無傷)、**間隔・位置は

## 6. 試行錯誤の記録(そのまま残す)

### 6.1 発散(パラメータ過大)

最初の試行(morfac = 5000, spl_dzmax = 0.5): dzmax クリップが全面
発火(33771 セル)しつつ深さ ~90 m の穴が開き、水がそこへ集中して
流速 250 m/s 超で発散停止。**安全弁(クリップ+発動報告)と発散検知は
設計どおり働いた**が、フィードバック時定数に対して地形加速が
桁違いに過大だった。教訓: spl_dzmax は「1回の更新で地形の局所起伏を
作り変えない」大きさ(格子スケール地形の 1/10 程度)にする。

### 6.2 格子スケールの市松模様(無限波数問題の顕在化)

morfac = 500, dzmax = 0.05 に落とすと谷は形成されたが、侵食帯に
1セル周期の市松状凹凸が卓越した。これは **Smith & Bretherton (1972)
が内包していた「移流優位では最も不安定な波数が無限大」問題**が
そのまま数値に現れたもので、κ の正フィードバックは反拡散だから
最短波長(= 2Δx)が最速成長する。バグではなく理論どおりの性質。

当時の対策 = **弱い f_creep(線形拡散)の重ね合わせ**(波長選択は増幅
(c_b)と拡散(creep_d)の比で決まると解釈した。**2026-10-19 に改定**:
拡散項は成長の符号を変えるだけで間隔を選ばず、クリープは力学的モデルでも
ないため併用しない。間隔は相関長 ℓ が決める。§2.5・§6.6)。当時の実験系列:

| creep_d (m²/s) | 崖縁起伏(0.5 m 初期) | 評価 |
|---|---|---|
| 0(なし) | ×5〜6 に成長するが市松卓越 | 波長選択なし |
| 5×10⁻⁷ | ×3。谷 9 本・市松弱残存 | **採用**(実証実験) |
| 1.5×10⁻⁶ | ×1(ほぼ成長せず) | 拡散優位の入口 |
| 3×10⁻⁶ | ×0.4〜0.8(擾乱が減衰) | 完全に拡散優位 |

増幅と拡散の比の**窓**の中でだけ「有限波長の谷が成長」する —
これ自体が理論(谷間隔の選択則)と整合する挙動である。κ 評価の
平滑化(市松の別対策)は Phase 2 課題(§8)。

### 6.3 帯界面のランク数依存(test/splashslide が検出した実バグ)

splash と creep を併用した対照テスト(§7)の初版で、MPI の
state.dat が逐次とバイト不一致になった。原因: apply_splash が帯内の
z を更新した後、creep が近傍 z を読む際に**ハロ行だけ時刻 n のまま**
残り、帯界面のエッジフラックスを両側ランクが異なる入力(自帯=更新後、
ハロ=旧値)から計算していた。修正: apply_splash の後、後続に
近傍参照プロセス(f_creep / f_fluvial)がある場合に z(fluvial 併用時は
sd も)のハロ交換を追加。修正後 np = 1, 2, 4 でバイト一致。
(同構造の潜在問題は debris → creep/fluvial の併用にもあり得るが、
この交換は debris の更新も配布するため同時に塞がれる。)

### 6.4 崩壊深の連鎖反応(対照テストの調整)

未固結構成(f_slide, c′ = 0)の初版(sd0 = 20 m)では、1回の崩壊が
土層全厚を流動化 → 隣接セルに 20 m の段差 → tanθ ≫ tanφ_s → 連鎖
崩壊が**平坦な台地内部まで**伝播し、全域が岩盤まで掘り抜かれた。
c′ = 0 の無限長斜面判定では、1セル段差の勾配 sd/Δx が tanφ_s を
超える限り伝播が止まらない(離散モデルの構造)。さらに土石流の
E-D(f_dbed = 1)が定常運転で河床を自己加速的に連行し、掘削を深めた。

対策: (1) **sd ≤ Δx·tanφ_s** を満たす土層厚にする(段差が安息角以下
→ 伝播が自然停止)。採用値: Δx = 2 m, φ_s = 35°(tanφ_s = 0.70)、
sd0 = 1.3 m(段差勾配 0.65)。(2) 土石流は **f_dbed = 0(交換なし=
等価流体)+ f_dbstop = 1(低速凝集)**とし、「崩れて・流れて・積もる」
だけの安息角緩和モードに限定(連行の自己加速を遮断)。

### 6.5 初期擾乱の性質と波長選択の弱さ(2026-08-20)

当初の模式実験は崖縁に 2 モードの正弦擾乱を与えており、形成された
谷 9 本の間隔は実質的に初期条件が規定していた(自然な谷の発生の
模擬になっていない — 利用者指摘)。白色雑音(シード固定)に置き換えた
実験では:

- 谷は雑音からでも自己形成される(間隔・位置を初期条件が与えない
  ことの確認)。起伏成長 ×3.7・台地無傷は正弦版と同等。
- 一方、prominence 0.5 m 以上の谷は 21 本・間隔 2.9±1.1 m(2〜3Δx)と
  **分解能近傍**に寄り、最終地形のスペクトルは広帯域のまま
  (卓越成分のパワー比 ~0.1)で鋭い波長選択は起きない。
- 増幅(spl_cb)と拡散(creep_d)を同率で強めても(cb 8→24、
  D 5e-7→4e-6)、間隔はほぼ 3Δx のままで成長だけが弱まった。
  線形の凹地形増幅 Φ_B = 1 + c_b κ では、拡散が抑えきれない帯域の
  最短波長が常に最速成長するため、**格子で解ける最小スケールに
  張り付く**と解釈できる(無限波数問題の帰結。§6.2)。

含意: 現行の線形 Φ_B は「谷が生じるか否か」と「凹地形フィード
バックの強さ」を表すが、**谷間隔の物理的な選択則はまだ持たない**。
間隔まで再現対象にする場合は、Φ_B の飽和形(κ の上限)や κ 評価の
平滑化(有限の相関長の導入 = サブグリッドリルの物理的な集水
スケール)が必要で、Phase 2 の主題とする(§8)。

### 6.6 再検討: 間隔は creep では選べない・格子依存・基準面(2026-10-19)

移流項の改定が一段落したのを機に、新島南海岸型の地形(鋭い稜線・深い谷)
の形成と発達を目標に再検討した。

セルで地下水容量 sd·sy0 < hg となり、超過分が地表へ渡されて(wash と同じ
規約)水が湧き、無流水の前提が崩れて発散した(Δx = 0.5 m)。基準面は地下水と

$w = 1/8$(伝達関数 ≥ 0)に改めて解消。

Δz の重心波長 11.5 / 11.9 / 11.8 m(中央差分では 10.3 / 12.9 / 13.1)、

立つ(Δz のパワー比 0.06〜0.10)がその後減衰し(0.01)、起伏も 4.2 → 1.0 m
に落ちる。最急降下では高いセルだけが S > 0 で削られるため、格子ノイズは
物理(高い面が削れる)から減衰する。ただし κ の格子評価そのものの問題
(最短波長が最速)は残るので、spl_lc は依然必要。

**雨滴輸送の試算**(§2.6 (a) の上限 D_s = 2.8×10⁻⁸ m²/s を線形拡散で模擬、

**test/splash への影響**: 最急降下では斜面内部 1.5 mm・平坦部 0.5 mm は
不変、境界列(鏡像で半減していた 1.0 mm)が 1.5 mm、遷緩点の 2 列が中央差分の
平均(1.2 / 0.7 mm)から面の値(1.0 / 0.5 mm)になる(出力は 0.1 mm 単位)。
解析形 Δz = P(k_r + k_t S)T は保たれ、むしろ単純になる。既定を 1 にする
場合は reference の更新(承認要)。MPI は np = 2, 4 が逐次と Log・state.dat
ビット一致(test/splashlc 構成 l + spl_sgrad = 1)。

**結論(利用者承認 2026-10-19)**: (1) 勾配は最急降下を**既定**にした(物理に
合い、稜線の不死と極端な率を解消。test/splash の reference は貯留台帳のみで
不変、解析値の列クラスは README を更新)。乾式斜面侵食のテスト・例題は
すべてクリープなし(test/splashslide も creep_d 3e-5 を外し、固結崖の成長
×1.25 で閾値を 1.15 に再調整)。(2) 雨滴項の輸送化は定数の物理的意味は明確
だが、谷の尺度では効かないので今は実装せず、sandball の $L_h(S)$ と堆積
(Phase 3)を扱うときに併せて入れる。(3) 深い段階の格子収束には S の飽和が
要る(次の課題)。

### 6.8 浸透能を下げて豪雨時だけ表面流が出る場合(examples/badland_storm。2026-10-21)

主ケースの崖に 1 時間周期の降雨(50 分 10 mm/h + 10 分 60 mm/h)を与え、
浸透能 12 mm/h(豪雨の超過分が表面流)と 100 mm/h(全量浸透)を比べた。
湿潤セルは f_wash + f_suspend。結果の要点(詳細は examples/badland_storm/README.md):
- 湿潤侵食の係数を発散しない桁に落とした構成では、表面流は谷を刻まず、
  **「水が乗っている間は乾式侵食が止まる」**効果だけが現れる。乾式侵食は
  P に比例するので、最も効く豪雨の雨が表面流に回り、豪雨後も谷頭が最も
  長く湿るため、谷頭の後退が 43 m → 8 m に落ち、崖面に浅い切れ込みが並ぶ
  エスカープメントにとどまる(谷間隔は同じ)。湿潤侵食を切った変種で同じ
  結果になることから切り分けた。平坦な台地では水が次の豪雨まで抜けず、
  2 % の傾きを付けても結論は同じ。
- 湿潤侵食を発散しない上限付近(susp_esa 1e-4、wash_kf 2e-9、morfac 50)
  まで上げると地形が一変する: 谷間隔が半分(6.5 m)の密なガリー網が台地に
  52 m 食い込み、56° の崖は勾配 0.5〜1 の緩い斜面に均される(起伏 2 m)。
  乾式の κ フィードバック(谷頭を深く刻んで尾根を残す)と表面流の面状侵食
  (流れが集まる所から斜面全体を均しながら下げる)は別の地形を作る。新島の
  鋭い稜線の深い谷は前者の型で、「浸透能が豪雨を上回る」ことがその条件
  という仮説と整合する。
- 実装上の注意: prtype = 1 の降雨時系列は線形補間される(階段には両端を
  与える)。急崖の薄い流れは τ*/τ*c が 10³ 級で、f_wash・f_suspend の既定
  係数は morfac 500 だと 1 豪雨で数 m 削れて発散する。乾式と湿式の切替は
  水深 dd = 1 mm の閾値 1 本で決まり、その感度は未確認。
- **ガリー間隔は格子収束しない**(2026-10-22、Δx = 2 / 1 / 0.5 m、10 周期):
  間隔 7.8 → 5.6 → 3.7 m(≈ Δx^0.5)、間隔/Δx = 3.9 → 5.6 → 7.3 セル。初回の
  豪雨だけで 1 セル幅・深さ 3.5〜5.3 m(Δx に依らない)の溝が刻まれ、溝壁の
  勾配が Δx に反比例する。面状侵食・巻き上げとも τ*/τ*c に比例し、セル幅への
  流れの集中の正帰還に長さスケールがないため。谷頭の位置と最大下刻は格子に
  依らず、谷は細かい格子ほど密で浅く、平均低下は大きい。Δx = 0.5 m は
  dt/Δx を Δx = 1 m と同じにすると初回豪雨で発散(溝に集まる流れが Cn > 1)、
  dt = 0.125 s で完走。湿潤侵食に幅のスケール(リル幅で τ* を評価する、
  または駆動量を相関長で平滑化する)を入れるのが次の課題。

## 7. 白ママ対照テスト(test/splashslide)

同一地形・同一降雨・同一 splash 係数で、崖の固結度だけを変えた
2 構成の対照実験。「**谷形成の真の臨界条件は崖面の固結度**(凹部が
維持されるか)」という仮説の数値版(sandball 機構が最も活発なはずの
未固結砂面=白ママ断崖に谷がない、という野外の内部対照に対応)。

- 構成1(param_c.txt、固結): f_splash + 弱 creep のみ。崖(56°)は
  安息角を超えて自立 → 凹部が維持され、起伏が成長する。
- 構成2(param_l.txt、未固結): + f_debris + f_slide(**c′ = 0**,
  φ_s = 35°)。崖は安息角まで緩和し、splash が刻む凹部も
  Fs < 1 → 流動化 → 埋め戻しでリセットされる。

検定(Check_contrast.py。崖面帯の y 方向起伏 = 谷の指標):

| 判定 | 固結(c) | 未固結(l) |
|---|---|---|
| 起伏成長比(final/init) | **×1.34 ≥ 1.25** | **×0.75 ≤ 0.9** |
| 台地内部(x ≤ 12 m)の不変 | max\|Δz\| = 0 | max\|Δz\| = 0 |
| 侵食下限の有界(z ≥ −1.5 m) | −1.22 | −1.30 |

MPI は np = 2, 4 とも state.dat が逐次とバイト一致。
補足: 下限判定を sd0 ちょうどにしない理由は、creep が仕様上 sd に
触れない(z − sd = 岩盤面が厳密不変でない)ため(m_geomorph
ヘッダに記載の既知の妥協)。

## 8. 既知の限界と積み残し

- **Phase 2**: 雨滴項の風向・風速依存 Φ_A(κ, θ_wind)(雨滴の斜め
  軌道による風上谷壁への運動量集中)。~~κ 評価の平滑化~~ **実装済み
  2026-10-19**(spl_lc。§2.5・§6.6。格子幅を跨ぐ較正則は ℓ を物理量として
  与えることで ℓ/Δx ≥ 2 の範囲で不要になった)。実 DEM(1 m 級)での
  ℓ・c_b の較正(新島の谷間隔 ≈ 5〜6 ℓ から ℓ を逆算できる)。
- **Phase 3**: 容量式の堆積(§2.2 の D 式、D8 経路)。崖下が海で
  ない内陸バッドランドへの適用に必要。
- Φ_B の関数形(1 + c_b κ の線形)は最も単純な仮定であり、飽和形
  (上限付き)等の検討余地がある。**飽和形は 2026-10-22 に spl_ksat として実装**
  (有効曲率 κ̃ = κ/(1 + κ/κ_s)。developer.md §48.6。既定は飽和なし)。**深い谷の段階では必須**(§6.6): 谷壁の
  垂直化で S が Δx に反比例し、谷頭の κ̃ が深さ/ℓ² で増え続けるため、
  S^h × Φ_B が非有界で深い段階の速さを spl_dzmax が決めてしまう。固結物質
  向けの勾配の飽和(S の上限)と Φ_B の飽和形を組にして導入するのが次段
  (最急降下の勾配評価 §6.7 で稜線とクリップは解消済み。残るのは壁の S)。
- 雨滴項の輸送化(飛散長 $L_h$。§2.6)は定数の物理的意味が明確だが谷の
  尺度では効かない。sandball の $L_h(S)$ と Phase 3 の堆積を扱うときに導入。
- ~~谷間隔の定量(λ と c_b/creep_d 比の関係の系統実験)は未実施。~~
  実施済み(§6.6)。c_b/creep_d は間隔をほぼ選ばず、間隔は ℓ が決める。
- 谷の併合(粗大化)の速さと最終的な間隔の統計、谷頭の後退速度の定量、
  稜線の鋭さ(曲率)の時間発展は examples/badland の主ケースで観察した
