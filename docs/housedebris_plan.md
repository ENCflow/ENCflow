# 家屋破壊・瓦礫モデルの設計(housedebris_plan.md)

**状態: 設計合意済み(2026-10-01 起草・同日合意)・実装済み(同日)**。

確定事項と検証記録の正本は developer.md §63。残るのは §2 の文献照合
(閾値の実務値)で、その消化とともに本書を消し込む(driftwood_plan.md と
同じ運用)。

対象現象: 津波・高潮・洪水の氾濫流による木造家屋の破壊、瓦礫化、
瓦礫の流動・堆積、および流木・瓦礫を含む流れによる破壊力の増加
(破壊 → 瓦礫 → 破壊力増 → 更なる破壊、の連鎖)。

前提となる既存構造: 流木モジュール m_driftwood(§50。3台帳+閾値・
レートの発生・停止、advect_scalar による移流、私有 save、決定的台帳
CSV — 本モジュールの型紙)、家屋の空隙率 gv・平均サイズ bb・付加質量
係数 cm(m_geoinfo の静的物性。§26 の実効平面積率 af)、最大流体力
F9999 = (ρm/ρw)(h+hs)V²(§28.9)、動的 s%z の前例(g%z = 入力の正本、
s%z = 時間発展する状態、geomorph が更新後にハロ交換)。

本書は 2 部構成とする。**§3A 基盤(空隙率の状態化 s%gv)**は瓦礫と
独立した汎用機能で、等価リファクタとして先に合意・実装できる。
**§3B 家屋破壊・瓦礫モジュール**は §3A の上に載る。

## 0. 結論(要約)

- **家屋を「破壊可能なストック」のラスタ場として扱う**。流木の立木
  ストックと同型で、セルごとの瓦礫化可能材積 (m³/m²) を入力ラスタで
  直接与える(§0 方針12。建物台帳からの換算は前処理)。個別家屋・
  個別瓦礫の追跡は持ち込まない(方針2)。
- **3つの台帳**: **家屋ストック wbs**(不動。入力)→ 破壊 →
  **流動瓦礫 s%hbd**(水と同速で移流)→ 接地・低速 → **堆積瓦礫
  s%wbd**(不動。再流動あり)。総和が機械精度で閉じる。
- **破壊判定は被害関数の閾値+レート**(流木の水理的流失と同じ
  数値的閉包)。判定量は浸水深(実務の被害関数と整合)または**荷重
  (h + sg_log·hd + sg_bd·hbd)·V²**(F9999 の混合密度の構造を浮遊物へ
  延長)の選択制。荷重判定のとき、流木モジュールの流動流木 hd と
  自モジュールの瓦礫 hbd が破壊力に加わり、連鎖が一つの時間発展で
  つながる。
- **流木モジュールとは別モジュール**(m_bldgdebris。fn_bldgdebris で
  有効化)。流木モジュールへの変更はなし。依存は一方向(本モジュールが
  s%hd を読むだけ)で、両者の有効化は独立に重ね合わせられる。
- **破壊が流れへ返る経路は空隙率 gv の増加**。gv を状態 s%gv にし
  (§3A)、破壊率に応じて上げる。gv を変える瞬間は空隙面積基底の
  柱状量をすべて再スケールして体積を保存する(m_state の単一手続き)。
  第1段(B1)はこの帰還を持たない片方向結合、第2段(B2)で有効化。
- **個別の衝突力は対象外のまま**。荷重項は「浮遊物を含む流れの平均的な
  破壊力」であり、1本の材の衝撃荷重(国総研 905 §4.3、FEMA P-646)の
  置き換えではない。衝撃荷重は従来どおり V9999 と代表径の後処理。

## 1. スコープの線引き(有効化しないものの明言)

- **対象内**: 木造家屋群の面的な破壊率(どこの家屋がどの程度壊れるか)、
  瓦礫の発生量・到達範囲・堆積分布、流木・瓦礫を含む流れの荷重指標、
  破壊による空隙率の変化が流れに返る効果(B2)。流木モジュールとの
  同時有効化による「流木 → 家屋破壊 → 瓦礫」の連鎖。
- **対象外(有効化しない)**: 個別家屋の構造応答・個別瓦礫の軌跡・
  配向・回転・相互作用(ベクトルベース。方針2)。瓦礫・流木の個別
  衝突力。瓦礫によるジャミング・閉塞の幾何判定(流木と同じ線引き)。
  RC・鉄骨造の破壊(閾値を変えれば形式上は扱えるが、第1段は木造を
  想定して文献照合する)。火災・漂流物の火災。堆積瓦礫の地形 z への
  算入(流木の dep と同じく第1段では見送り)。
- **抽象化(当面定数)**: 瓦礫は単一の代表諸元(代表寸法 bd_dlog、
  見かけ比重 bd_sg < 1 の浮遊瓦礫)。沈む瓦礫(瓦・基礎・家財の一部)は
  第1段では「破壊時に一定比率でその場に堆積する」沈下率 bd_fsink で
  抽象化する(§6-4)。瓦礫の移流速度は鉛直平均流速と同速(流木と同水準)。
  家屋の平均サイズ bb は破壊で変えない(空隙率 1 のとき既に無限大
  扱いになる既存分岐に乗せる)。

## 2. 文献照合の状態(§19.8 の方針の適用)

第1段で実装する判定・閾値は、流木モジュールと同じく**数値的閉包
【独自】+閾値【要文献照合】**の位置づけで始める。照合候補:

- **浸水深ベースの被害関数**: 東北地方太平洋沖地震津波の木造家屋被害
  関数(浸水深 2 m 前後で流失が急増するとされる各種の調査・研究)。
  第1段の bd_hcrit(浸水深閾値)の実務値の当たりに使う。被害関数が
  確率曲線であるのに対し本実装は閾値+レート(または 2 閾値の線形
  ランプ。§6-2)なので、「中央値を閾値、曲線の幅をランプ幅」と読み
  替える対応を文書化する。
- **流体力・運動量流束ベースの判定**: FEMA P-646(津波避難ビルの
  設計荷重: 静水圧・流体力・衝撃力・瓦礫堰き止め)、津波の家屋被害と
  u²h の関係に関する研究。bd_fcrit(荷重閾値)の当たりに使う。
- **流木の荷重算入**: 国総研 905 §4.3 の流木衝撃力は個別衝突式で、
  本実装の平均荷重とは別物であることを明記(置き換えではない)。
- **瓦礫の諸元**: 木造家屋の構造材積(延床面積あたり)、瓦礫の
  見かけ比重の目安。入力ラスタの作り方(建物ポリゴン → 延床 ×
  材積原単位 → セル集計)はユーザーガイドに前処理として記す。

照合の記録先は developer.md §63(予定)。

## 3A. 基盤: 空隙率の状態化(s%gv)

### 3A.1 現状

- gv は t_geoinfo の静的物性(rank0 が読み scatter で帯配布。方式2)。
  派生量 lm = gv + (1−gv)·cm(有効慣性係数)も t_geoinfo。
- 参照箇所: m_swflow_enc 11、m_swflow_enc_bc 16、m_swflow_enc_adv 6、
  他モジュール(boundary_structure・evap・glacier・gwflow_bucket・
  gwflow_greenampt・snow・wq・state・stg)16。運動量項は隣接セルの
  gv・lm を平均する(±1 の近傍参照 = ハロ幅2で範囲内と監査済み)。
- s%af(実効平面積率 = gv × wfrac × 湿潤率)は update_af が毎ステップ
  更新するが、呼び出しは have_width か have_sect のときのみ。
- 柱状量の基底: h・hs・hd・wd・cq・hss は空隙面積基底(セル内体積 =
  柱状量 × gv × wfrac × A)。swe・hi・hl・hb・cg・bp・wst は幾何面積基底。
  hg・hg2・hgc・hgs・hrs は「柱状換算」で、基底は監査が必要
  (gwflow_bucket の `hg += fx·af/gv` は空隙面積基底を示唆)。

### 3A.2 設計(等価リファクタ A1)

- **s%gv・s%lm を t_state に追加**し、時間ループの参照をすべて
  s%gv・s%lm に置換する。m_state の init で g%gv の帯を写してから
  g%gv・g%lm の帯を解放する(z と同じ「持ち主の移動」。メモリ増なし)。
  g%gv の rank0 全域正本を残すかは z に倣う(§6-6)。
- s%af の初期化 `af = gv` は s%gv から。
- 挙動ゼロ変更: 全ケース逐次 ULP=0、np=1,2,4 ULP=0 で合否判定
  (絶対規律2「等価リファクタ」)。
- STG(m_swflow_stg)も同じ置換を行う(本モジュールは ENC のみだが、
  参照の所在を一本化するため)。

### 3A.3 設計(gv 変更の適用手続き A2)

- **m_state に `state_set_gv(g, s, i, j, gvnew)`** を置く。処理:
  1. r = gv_old / gv_new を求め、**空隙面積基底の柱状量すべて**に r を
     掛ける(h, hs, hd, wd, cq, hss, hbd, wbd、監査結果により hg 系)。
     体積 = 柱状量 × gv × A が不変 = 保存則。
  2. s%gv = gv_new、s%lm = gv_new + (1−gv_new)·cm。
  3. e = z + h は h の縮小で下がる(同じ水が広い面積に広がる)。
     これが「破壊が流れへ返る」経路になる(隣接セルとの水位差が変わる)。
- 呼び出し側の契約(呼ぶモジュールが守る):
  - 自帯 js..je のセルだけを更新し、更新後に `par_halo_cell(s%gv)`・
    `par_halo_cell(s%lm)` を行う(運動量項の近傍参照のため。geomorph
    が s%z で行う位置と同じステップ間)。再スケールした h 等のハロは
    ステップ頭の既存交換で揃う。
  - update_af の呼び出し条件に「gv 可動」フラグ s%gv_active を加える
    (`have_width .or. have_sect .or. s%gv_active`)。
  - gv_new ≥ gv_old のみ許す(第1段。瓦礫の堆積で空隙率が再び下がる
    扱いは §6-5)。min_gv の下限は init の既存検証で保証済み。
- 呼び出し元が存在しない段階(A2 単体)では挙動ゼロ変更 = ビット一致で
  検証できる。手続きの単体検定は test/ に「静水池で gv を手動で上げる」
  ケースを置き、水位の低下と体積の不変(機械精度)を確認する(§4)。
- **save**: s%gv はモジュールが変えたときだけ入力と異なるので、
  §7 契約C により変えるモジュールの私有ファイルに保存する。state.dat の
  形式・save_version は不変。

## 3B. 家屋破壊・瓦礫モジュール m_bldgdebris

### 3.1 状態量と台帳

- **s%hbd**(t_state に追加): 流動瓦礫の柱状量 (m³/m² = m。空隙面積
  基底。貯留の意味論は hd と同一)。fn_bldgdebris 指定時のみ確保。
  ハロ交換はステップ頭の hd と同じ並びに `if (s%bd_active)` で追加。
- **s%wbd**(t_state に追加): 堆積瓦礫 (m³/m²)。m_output がフレームを
  読むため t_state に置く(wd と同じ理由)。
- **モジュール私有の帯配列**: wbs(家屋ストック。瓦礫化可能材積
  m³/m²。幾何面積基底。入力ラスタ fn_bdstock を rank0 が読んで
  scatter)、wbs0(初期値の写し。破壊率 = 1 − wbs/wbs0 の分母)、
  fw(破壊可能割合。入力ラスタ fn_bdfrac。省略時 1)。
- **木造率・耐津波構造の分布**: 瓦礫化可能材積 wbs は fn_bdstock に
  木造率込みで与える(木造率 30 % のセルは 100 % のセルの 30 %。建物
  台帳からの集計は前処理。方針12)。残る RC 造・耐津波構造は破壊されず
  建物占有のまま残るので、**fn_bdfrac**(建物占有のうち破壊可能な
  割合 0〜1)が空隙率帰還の上限を決める(§3.5)。都市化・耐津波化の
  シナリオは fn_gv・fn_bdstock・fn_bdfrac の差し替えによる2ケース
  比較で、コード側の追加はない。木造と RC で閾値を変える多クラス化は
  将来(§6-10)。
- **s%bd_active**(logical。init が設定)。
- 単位は材積のみ(棟数・金額への換算は後処理。方針12)。

### 3.2 モジュール構成

- m_bldgdebris: 破壊・停止・再流動・空隙率反映・台帳・診断。移流は
  m_swflow_enc のステップ内 advect_scalar(hd の並びに1行追加)。
- 有効化: fn_bldgdebris(&list_bldgdebris。f_bd=0 で一時無効化)。
  ENC 格子のみ。list_bldgdebris.f90 は namelist を読むだけ(§12)。
- calc の呼び出し位置: 時間ループ内、m_driftwood_calc の**後**
  (同一ステップの hd を荷重に見る。順序を文書化)。毎ステップ。
- 更新は自帯 js..je のみ、セル内交換のみ(エッジ・collective 不要)。
  例外は B2 の gv 更新後のハロ交換(§3A.3 の契約)。
- 流木モジュールとの関係: 本モジュールが s%hd を読む(dw_active で
  分岐。未確保なら荷重に算入しない)。m_driftwood は本モジュールを
  知らない。

### 3.3 破壊(瓦礫化)

判定量 X を f_bdcrit で選ぶ(§6-1):

- **f_bdcrit = 1 浸水深**: X = h + hs(混合流動深。f_out_dmax と同じ)。
  閾値 bd_hcrit (m)。実務の浸水深ベース被害関数と対応。流木・瓦礫の
  効果は入らない。
- **f_bdcrit = 2 荷重**: X = (h + (1+s)·hs + sg_log·hd + sg_bd·hbd)·V²
  (m³/s²。F9999 の清水規格化と同じ基底。hs の項は既存 F9999 と同一、
  hd は流木モジュール有効時のみ、hbd は自モジュール)。閾値 bd_fcrit。
  浮遊物を「水に同伴する付加質量」として混合密度に足す構造で、流木が
  水と同速で移流する前提と整合する(単位面積あたりの運動量流束
  ρ·hd·V² の加算と等価)。
- **レート**: X > 閾値のセルで wbs → hbd を bd_wdes (m³/m²/s) で移す
  (fx = min(wbs, bd_wdes·dt)。流木の dw_wrec と同型の数値的閉包
  【独自】)。破壊の所要時間 = ストック ÷ レートで、曝露時間依存を
  表す。
- **2 閾値ランプ(任意。§6-2)**: bd_hcrit2(または bd_fcrit2)を
  与えたとき、閾値1で 0・閾値2で 1 になる線形の「破壊可能率」を
  レートに掛ける(被害関数の幅を表す。省略時は単一閾値)。
- **沈下率 bd_fsink**(0〜1。既定 0): 破壊量のうちこの比率をその場で
  wbd(堆積)へ直接移す(沈む瓦礫の抽象化。§6-4)。
- 発生済みセルは wbs=0 で再判定は自然に停止。

### 3.4 輸送・停止・堆積・再流動

- 輸送: advect_scalar(hd と同じ契約)。境界流入は清水(hbd=0)。
- 喫水: 代表寸法 bd_dlog と見かけ比重 bd_sg から流木と同じ円柱浮力
  平衡で導出(同じ関数を使う。§6-3)。
- 接地・低速堆積: h+hs < 喫水 または vv < bd_vstop で hbd → wbd を
  bd_wstop で(流木と同型)。乾燥セルは全量。
- 再流動: bd_wfloat・bd_rfloat・bd_vfloat(流木と同型。既定なし)。
- 堆積瓦礫は z に足さない(第1段)。

### 3.5 空隙率への反映(B2)

- 破壊率 d = 1 − wbs/wbs0 に応じて gv を上げる:
  gv_new = gv0 + (1 − gv0)·fw·d(fw = 破壊可能割合 fn_bdfrac。
  fw = 1 のセルは全壊で gv = 1 = 建物なし、RC 造が残るセルは
  gv0 + (1 − gv0)·fw が上限)。gv0 は init 時の s%gv の写し(私有)。
- 更新は state_set_gv(§3A.3)で行い、更新後にハロ交換。
- 破壊率が変わったセルだけ呼ぶ(毎ステップ全セルではない)。
- 堆積瓦礫 wbd が空隙を再び塞ぐ効果は第1段では入れない(§6-5)。
- **B1(片方向結合)では本節を実装しない**: 破壊率と瓦礫の分布を出す
  だけで流れは変わらない。流木の「運動量に算入しない」と同じ流儀で、
  まず面的評価を成立させる。

### 3.6 構造物・境界との関係

- ダム捕捉帯: 流木と同じく hbd も同伴吸収(ダム別台帳)。
- カルバート・ポンプ: 清水のみ転送 → 瓦礫は施設上流に滞留。
- 開境界からの流出: 系外流出として台帳に残差計上。

### 3.7 出力・診断

- f_out_hbd: 流動瓦礫 Bf0001…。f_out_wbd: 堆積瓦礫 Bd0001… と
  期間最大到達量 Bd9999 = max(hbd+wbd)。
- f_out_bds: 破壊率 d の分布 Bs0001…(家屋被害マップの本体。最終
  フレームが被害率、期間最大は不要 = 単調増加)。
- **f_out_fdmax: 荷重込み最大流体力 Fd9999** = max X(f_bdcrit=2 の
  判定量)。既存 F9999 の定義は変えない(流木のみのケースの reference
  をビット一致のまま守る)。流木モジュールのみ有効のときにも Fd9999 が
  欲しいかは §6-7。
- result/bldgdebris.csv(rank0、dt_recrd): ストック残・破壊累積・
  流動・堆積・再流動・ダム捕捉・系外流出(残差)。par_sum_rows。
- save: 私有 bldgdebris.dat(hbd, wbd, wbs, wbs0, fw, gv0, s%gv)。
  §7 契約C。

### 3.8 排他・ガード(init)

- ENC 格子のみ。morfac ≠ 1 は par_stop(流木と同じ理由)。
- fn_bdstock・bd_dlog・bd_sg 必須。0 < bd_sg < 1。fn_bdfrac は任意
  (0 ≤ fw ≤ 1 を検証。wbs > 0 かつ fw = 0 のセルは「破壊しても空隙率が
  変わらない」として受理するが、init で件数を par_info に出す)。
- f_bdcrit = 2 で f_out_fdmax を推奨(警告ではなく案内)。

## 6. 論点と合意結果(2026-10-01 合意。全て推奨案で確定)

1. **破壊判定量**: 浸水深(1)と荷重(2)の選択制で開始。推奨は
   「両方実装し既定は 1」。1 は実務の被害関数と直結し文献照合しやすい。
   2 は流木・瓦礫の連鎖を表す本提案の中心で、閾値は校正パラメータ。
   両閾値の重ね合わせ(どちらかを超えたら破壊)は将来。
2. **被害関数の形**: 単一閾値+レートで開始し、2 閾値の線形ランプを
   任意指定で足す(省略時は単一閾値)。確率曲線(対数正規)の直接指定は
   将来。
3. **瓦礫の諸元**: 単一クラス(bd_dlog・bd_sg)。喫水は流木と同じ
   円柱浮力平衡を流用(木造瓦礫の主体を構造材と見る抽象化)。
4. **沈む瓦礫**: 沈下率 bd_fsink で「破壊時にその場で堆積」。既定 0
   (全量浮遊 = 到達範囲の上限側)。
5. **gv の単調性**: 第1段は上がるだけ(破壊)。堆積瓦礫による再閉塞・
   復旧は対象外。
6. **g%gv の全域正本**: z と同様 rank0 のみ全域保持(帯は解放)。
   将来の「初期からの変化」出力に備える。
7. **Fd9999 の所属**: 本モジュールの出力とする(流木のみのケースでは
   出さない)。流木のみで荷重込み指標が欲しい需要が出たら、F9999 の
   定義を変えずに m_driftwood 側に同名出力を足す。
8. **B1 と B2 の切り方**: B1(片方向)を先に出し、例題で破壊率・瓦礫
   分布を確認してから B2。B2 の有無は f_bdgv(既定 1 = 帰還あり)で
   切り替え可能にし、両者の差を同一ケースで比較できるようにする。
9. **命名**: m_bldgdebris / fn_bldgdebris / &list_bldgdebris /
   bd_* 接頭辞 / s%hbd・s%wbd / 出力 Bf・Bd・Bs・Fd / 私有 save
   bldgdebris.dat。hb・Hb は動く底層が使用済みのため避ける。
10. **構造種別の扱い**: 木造率・耐津波構造の分布は fn_bdstock(材積に
    木造率込み)と fn_bdfrac(空隙率帰還の上限)の2枚のラスタで表し、
    閾値は単一(木造を想定して照合)。RC 造にも別閾値で破壊を与える
    多クラス化は、流木の径級と同じく将来課題。
