# swi_plan.md — 淡塩2層(鋭利界面)モデル設計検討メモ

対象: 地表水・浅層地下水への塩水層の導入(MODFLOW SWI2 パッケージと
同型の準静的・鋭利界面近似)。塩水くさび・海水浸入・淡水レンズ・
高潮遡上後の塩害の近似解析を狙う。
経緯: 2026-08-18 のチャット検討の記録。実装は未着手(本書は設計提案。
developer.md への決定事項の追記は実装合意後)。

**優先順位**: 管路連続体層の残作業(gwconduit_plan.md §10.5 の段 6 と
handoff の残項目)より後。独立した価値(高潮・津波の遡上 → 塩水浸入 →
塩害評価が既存の潮位軸と一気通貫でつながる)があるため、沿岸系の
需要が生じた時点で着手する。

## 1. 目的と適用対象

READMEの「できないこと」に掲げる「密度流・成層」のうち、**準静的な
淡塩2層現象**に限って対象化する:

- 帯水層への**海水浸入**(塩水くさびの地下部分)と汲み上げ・干拓による後退
- 島嶼・砂州の**淡水レンズ**(Ghyben-Herzberg)
- 河口感潮域の**塩水くさび**(地表水の底層貫入。準定常位置)
- 高潮・津波の遡上 → 塩水の浸透 → **農地塩害**の面的評価(m_tide との連携)

引き続き対象外(本設計でも扱わない): 混合・連行を伴う密度流の力学
(内部波・セイシュ・成層破壊)、連続濃度場の移流分散(Henry 問題型)、
水温成層。

## 2. 設計原則との整合(なぜ「準静的・鋭利界面」か)

方針 §0 は「水平は SWE+1方程式拡散が上限」と定める。本設計はこの
内側に収まるように選ぶ:

- **合計水量(バロトロピックモード)は現行のまま**: 地表は SWE
  (m_swflow_enc 不変)、地下は Boussinesq(m_gwflow_lateral 不変の極限)。
- **塩水層は拡散型 1 方程式**を追加するだけ(摩擦支配の重力流近似)。
- **2層とも運動方程式を持つ成層 SWE は不採用**: 方針の上限を超える上、
  層間シアが大きいときの双曲性喪失という既知の数値難点を抱え込む。
  内部モードの慣性(ロック交換のフロント速度、内部セイシュ)は
  再現対象から明示的に外す。

SWI2(MODFLOW の海水浸入パッケージ)が同じ近似(Dupuit・静水圧・
鋭利界面・zone 別の鉛直積分流)で実務的に成立していることが先例。

## 3. 定式化

### 3.1 状態と簿記

- 既存状態 `s%h`(地表水深)・`s%hg`(地下貯留)は**淡塩合計のまま**。
  既存機構(浅水本体・乾湿・質量台帳・save/restore・出力)は不変。
- 新規状態: 塩水層厚(柱状換算 m)。地表 `hss`、地下(層1)`hgs`。
  **塩水は常に層の最下部**(鋭利界面)。拘束 0 ≤ 塩水 ≤ 合計。
- 密度は 2 値(淡 ρf・塩 ρs)。ε = (ρs − ρf)/ρf(海水で ≈ 0.025)。
  Boussinesq 近似: 質量と体積を区別しない(O(ε) の質量誤差は許容)。

### 3.2 水頭(密度が現れる唯一の場所)

静水圧・鋭利界面(水面/地下水面 η、界面 ζ)の下で、各層の駆動水頭は

- 淡水層: Φf = η(**現行の全水頭と同一**)
- 塩水層: Φs = η + ε·ζ

導出: 塩水層内の淡水換算水頭 hf(z) = z + p/(ρf g) に静水圧
p = ρf g(η−ζ) + ρs g(ζ−z) を代入すると hf = η + ε(ζ − z) となり、
水平勾配は ∇η + ε∇ζ(z 依存項は水平微分で消える)。

- 平衡 Φs = const は Ghyben-Herzberg 関係 δζ = −δη/ε(≈ −40δη)を含む。
- **∇η = 0 でも ε∇ζ が塩水層を駆動する**(密度差起因の低層静水圧差)。
  プール仕切り実験(§6.1)の駆動力はこれ。
- 運動方程式(地表 SWE)への密度補正は O(ε) なので**入れない**。

### 3.3 地下水の 2 zone 化(SWI2 相当)

層1(土層)を淡塩 2 zone に分ける。層厚換算 bf = (hg − hgs)/sy、
bs = hgs/sy、η = (z − sd) + (hg/sy)…(現行の全水頭定義)、
ζ = (z − sd) + bs。

- 淡水 zone: q_f = −K_sh · bf_e · ∇η · l_k / dr_k(**現行 lateral_core と
  同一の式形**。通水厚が全厚 → 淡水厚に変わるだけ)
- 塩水 zone: q_s = −K_sh · bs_e · ∇(η + εζ) · l_k / dr_k
- 連続式: hg は q_f + q_s の発散で、hgs は q_s の発散で更新
  (hgs = 0 の極限で現行の側方流と**厳密に一致** → 等価性検証が
  構造的に成立)。

実装は層パラメータ化済みカーネル族(lateral_core / conduit_core)の
第 3 変種「zone_core」: 8 近傍・所有エッジ 4 成分・2 ループ・冪等幾何・
エッジ=スクラッチの規約はすべて共有。**新しい離散化はゼロ**。

数値: 乾燥判定 eps・上流側キャップ・過大流出抑制は既存機構を zone 別に
適用。界面が層天端・底に達する縁(SWI2 の tip/toe 問題)は乾湿処理と
同型に扱う。安定条件: 内部モードの実効拡散は K_sh·ε·b/sy(バロトロ
ピックの ε 倍)なので既存 dtcheck より緩い。拘束は既存の側方安定条件。

### 3.4 地表水の塩水層(河口くさび)

合計 h と運動量は現行 SWE のまま。塩水層厚 hss を追加し、

1. **バロトロピック移流**: swflow_enc の既存スカラー移流フック
   (s%cq・s%hs と同じステップ内移流)に相乗り。層間分担率 α
   (底層の流速分担 < 1)を係数化: 塩水の移流フラックス =
   α·(hss/h)·(セルフラックス)。α は要校正(§8)。
2. **バロクリニック項**(重力流): q_s = (1/n_i)·hss_e^{5/3}·
   √|∇(η+εζ)|·sign(...)·l_k(Manning 型摩擦支配。ζ = z + hss)。
   conduit_core の sqrt 流束と同構造 = カーネル再利用候補。
3. 各セルで hss ≤ h をクランプ(合計は SWE が確定済み)。

くさびの準定常位置は 1(下流向き掃流)と 2(上流向き貫入)の釣り合いで
決まる(Keulegan 型のバランスの離散版)。

### 3.5 鉛直交換・境界との相互作用

- 降雨・河川流入・境界流入は**淡水**(hss/hgs に触れない)。
- 浸透(greenampt 等): 地表の**淡水部分から**地下の淡水部分へ
  (fx ≤ h − hss)。地表が全塩水のときは塩水が浸透し hgs に加算
  (物理的には fingering。即時に地下の最下部へ置く近似 = 逆成層の
  即時入替規則 §8)。
- 蒸発散: 地表・地下とも**淡水部分を優先して**減らす(塩水しか
  なければ塩水の体積が減る。2 値モデルなので「濃縮」は表現されない —
  塩分質量の追跡は wq(cq)との併用による将来拡張 §8)。
- **海側境界(最大の新規点)**: 現行の「海域セルとは無フラックス」
  (意図的仮置き)を撤廃する。海域セル(sw>0)を
  「全塩水・水位 = 潮位 η_sea(m_tide)」の規定水頭境界とし、
  - 塩水 zone: Φs_sea = (1+ε)·η_sea との水頭差で双方向交換
  - 淡水 zone: 海への流出のみ(海に淡水はない → 流入ゼロのドナー制限)
  地表の海域セルは現行どおり m_tide が水位を規定し、その水は塩水として
  扱う(遡上した海水 = hss)。

### 3.6 モジュール構成案(§8 の未決を含む)

- 有効化: fn_* 方式の新モジュール(名称候補 fn_salt / m_saltwater)が
  地表・地下の塩水層状態(hss, hgs)を所有し、swflow・gwflow とは
  共有状態と実行順序で結合する案を第一候補とする。
  代替案: 地下側だけ gwflow ファミリの加算スイッチ(f_gwsalt)+
  地表側を別フラグ、の分割案。単一モジュール案は「淡塩 2 層」という
  1 つの物理を 1 箇所が所有する点で優る(要議論)。
- 無効時は配列も呼び出しもゼロ(既存規約)。σ・河道幅、管路連続体層
  との併用可否は初期実装では「地表塩水層×河道幅は未対応」から始める。
- save は私有ファイル(契約5)。出力は Hss / Hgs 場(f_out_hg 共用か
  新キーかは §8)。S 台帳: 塩水も水なので S_grnd/S_surf に算入
  (現行の合計簿記のままで自動的に成立)。塩水量の別列は将来。

## 4. 実装規模の見積もり

管路連続体層 1 個分程度(状態+カーネル変種+交換項+境界+検証)。
新規性が高いのは海側境界(§3.5)のみで、他は既存カーネル族・既存
フックの変種。段階案:

1. 地下水 2 zone(zone_core)+海側境界+静的平衡検証(SWI2 相当)
2. 定常くさび・淡水レンズの解析解検証(§6)
3. 地表塩水層(移流相乗り+重力流項)と河口くさび模式実験
4. 蒸発・浸透との連成(塩害評価)、wq 併用の塩分質量追跡

段 1〜2 だけでも海水浸入・淡水レンズが完結する。

## 5. 「できること・できないこと」(実装時に README・ガイドへ転記)

- できる: 塩水くさびの準定常位置と応答、海水浸入・後退、淡水レンズの
  形成と厚さ、高潮遡上後の塩水の行き先(面的)。プール実験の終状態
  (上下成層)と単調な成層化過程。
- できない: 混合・連行(界面は永遠に鋭利、汽水は作られない)、
  内部波・ロック交換フロントの慣性的速度、濃度の連続分布と分散
  (Henry 問題は対象外)、蒸発濃縮による塩分濃度上昇(2 値のため。
  塩分質量は wq 併用の将来拡張)。

## 6. 検証計画(解析解が豊富なのが本題材の利点)

1. **プール仕切り実験**(ロック交換の終状態): 閉領域・∇η=0。
   塩水体積の厳密保存と、終状態の水平界面・上下成層(ポテンシャル
   エネルギー最小の基底状態)への単調収束。
2. **Ghyben-Herzberg 静的平衡**: 規定 η 分布の下で ζ → −(η−η_sea)/ε。
   格子上の平衡値が解析値に一致(管路層の模式実験 A と同じ「全桁一致」
   型の検算を狙う)。
3. **Glover 型定常くさび**: 一様淡水流出 q_f の海岸で界面形状の解析解と
   比較。
4. **円形島の淡水レンズ**: 一様涵養 R・島半径 a のレンズ厚解析解と比較。
5. 河口くさび(段 3): 模式水路で Keulegan 型のくさび長スケーリングとの
   整合、および α の感度。

## 7. 科研費・研究上の位置づけ

- 申請書(基盤B)のスコープには**含めない**(都市軸を薄めない)。
  波及効果としても書かない(管路層と違い実装未着手のため)。
- 学術的には「単一離散化原理の拡張」の第 3 例(管路連続体層・氷河に
  続く)であり、既存の高潮・潮位軸(複合災害)と接続して
  「高潮 → 塩水浸入 → 塩害」の一気通貫解析という独自性を作れる。

## 8. 未決事項(実装合意後に determine)

- **α(地表塩水層のバロトロピック移流分担率)**: 底層流速分担の形状
  係数。くさび長を実質的に決める校正点。模式実験で感度を見る。
- **海側境界の具体形**: 規定水頭の交換係数(海底面の目詰まり抵抗)、
  潮位変動との時間結合(毎ステップ η_sea を読むか)。
- **逆成層の即時入替規則**: 塩水が淡水の上に載る経路(遡上海水の浸透、
  将来の密度逆転)をどの時点で最下部へ移すか。
- **モジュール構成**: 単一 m_saltwater 案 vs gwflow/swflow 分割案(§3.6)。
- **層2(風化基岩層)・管路連続体層への塩水拡張**: 初期実装は層1のみ。
  深部帯水層の海水浸入を扱うなら層2の 2 zone 化が要る(同じ zone_core)。
- **wq(cq)との関係**: 塩分質量・濃度の追跡は cq に「塩」を割り当てる
  併用案(密度は 2 値のまま、濃度は診断)を軸に検討。
- 出力キー(Hss/Hgs を f_out_hg 共用にするか新キーか)。
