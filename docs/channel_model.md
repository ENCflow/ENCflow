# サブグリッド河道モデル: 適用条件・既知バイアス・見送った拡張の記録

実装済み設計の正本は developer.md §17(堤防)・§18(開口補正・サブグリッド
河道幅・破堤)。本書はそれを補う独立文書として、(1) モデルの適用条件の宣言、
(2) 階段状河道・セル内蛇行に関する設計議論(2026-08-06〜07)の解析結果、
(3) 検討の末**見送った**拡張案の設計台帳、を残す。将来この領域を再訪する
ときは、まず本書を読むこと。

## 1. 適用条件の宣言(解析実施時の前提)

本河道モデル(fn_channel: 幅 W によるサブグリッド河道)を用いる解析は、
次の前提の成立を利用者が確認すること。

1. **実河道はラスタ経路より滑らかであること。**
   河道セル列(rw)は実河道の中心線をセル解像度で近似した階段状の経路に
   なる。本モデルの斜めショートカット(§3)は「実河道は階段よりも滑らかに
   直進する」ことの近似として機能するよう設計されており、この前提が
   成り立つ解像度を選ぶ必要がある。目安として、**セル内蛇行度
   (セル内の実河道長 ÷ セル通過長)が 1 に近い**こと。
2. **セル内で大きく蛇行する河川に適用すると、流量・流速とも過大評価に
   なる。** 蛇行による経路延長(勾配の緩和・貯留の増加)を本モデルは
   表現しない(§18 の妥協 (2))。勾配は直線距離基準のため急すぎ、
   等流で流速は √m 倍、洪水波の伝播は m^(3/2) 倍程度速く出る
   (m = セル内蛇行度)。このような河川には、解像度を上げて蛇行を
   格子で解像するか、適用しない。
3. 逆に、**実河道が本当に階段状・直角屈曲の場合**(放水路・用水路等)も、
   斜めショートカットが実在しない短絡路として働き、屈曲損失の過小
   (=通水過大)と到達時間の早まりを生む(§3)。

要するに本モデルの守備範囲は「ラスタ経路が実河道の骨格として正しい」
解像度帯であり、上下いずれに外れても通水能は過大側に誤差が出る。
過大側で系統的である(危険側=氾濫の過小評価になりうる)ことに注意。

## 2. モデルの要点(§18 の要約)

- 河道幅 W はセル属性・矩形断面・河道セルの水位は 1 本(セル内の
  非河道部の貯留は表現しない)。
- 通水: 河道—河道エッジの通過幅を min(W, 面長) にキャップ
  (開口補正と同じ frw テーブル)。W ≥ 面長で解像河道表現にビット
  厳密に退化(モデル切替なし)。
- 貯留: 平面積率 wfrac = min(W·L_ch/(dx·dy), 1)。
  **L_ch = 河道隣接8近傍への半距離和**(直線区間で厳密)。
- u,v はセル方向別通水率 cwx/cwy で正規化(vv・摩擦・抗力・移流が
  河道内流速を見る)。m, n は非正規化(測線流量の厳密性の条件)。

## 3. 階段状河道での挙動の解析(定量)

実河道どおりに階段状の河道セル列 A(直進)→B(角)→C があるとき、
A と C は斜め隣接となり、実在しない**斜めショートカット** A–C が
河道—河道エッジとして生じる。dx=dy・W<面長・堤防有効時の現行実装の
挙動(lp≈0.414, ld≈0.293):

- 通水幅: 実経路 A–B, B–C は開口補正(塞がり平均 nb=1.5)で各 **0.85W**、
  ショートカット A–C は **0.41W**(合成幅)。「W/2 ずつの二股」には
  ならない。
- 流量配分: ショートカットは経路長 √2dx(実経路 2dx)で勾配が √2 倍
  急なため、幅シェア以上に流量を取り、**全流量の 3〜4 割**を運ぶ。
- 横断合計: 開口補正の「横断合計=面長で厳密」は**直線区間の性質**。
  角では塞がり本数の両セル平均の近似により **A 側 ≈1.15W / B 側 ≈0.85W**
  と 1.0 を挟んでずれる。
- 貯留: L_ch が斜め隣接の半距離も数えるため、角セルで ≈1.71dx、
  密な 45° 階段の内部セルで **≈2.41dx**(実長 ≈1dx)。階段区間の河道
  貯留は最大 2 倍超に膨らむ。

「実河道はラスタより滑らか」の前提下では、ショートカットは実河道の
直進性を、貯留の膨張は実河道がセルを斜めに横切る長さを、それぞれ
部分的に代弁するため誤差は相殺方向に働く。前提が破れる(実河道が
本当に階段状/セル内で蛇行する)と §1 の系統誤差になる。

## 4. セル内蛇行(蛇行係数)の議論の記録

蛇行係数 m(セル属性)を導入する場合の正しい力学的扱いは:

- 重力項・圧力項の勾配分母を実効的に m 倍(エッジ値は両セル平均。
  per-cell 配列+calc_kth_flux に 1 乗算で実装可能。エッジ配列不要)。
  摩擦項は経路局所の物理なので無変更(勾配 1/m だけで等流流速が
  1/√m に落ちる)。
- 移流項には効かせない(勾配—摩擦バランス支配・湾曲損失は粗度へ
  集約する慣習・TVD submodule 改修のコスト対効果。
  f_channel_advection=0 なら問い自体が消える)。
- **wfrac の L_ch にも m を乗じることが必須**(勾配だけ変えると流速は
  正しいのに波速が合わない。両方で波速 1/m^(3/2) が実現する)。
- 等流の通水能だけなら rn_eff = rn·√m の粗度読み替えで代用可能
  (コードゼロ。貯留効果は別途必要)。

ただし**セル属性の m は斜めショートカット問題を解決できない**。同じ
セルの実経路エッジと幻の斜めエッジを区別できず、貯留補正のつもりで
m<1 を与えると全エッジの勾配が急化してショートカットを増強する
(悪化)。ショートカットはスカラー場では消せない**トポロジーの問題**。

## 5. 見送った拡張案(将来の設計台帳)

以下は 2026-08-07 の議論で設計としては閉じたが、モデル・要求データの
複雑化を避けるため**導入を見送った**もの。再訪時はこの組で考えること
(相互に相補で、単独では階段問題は閉じない)。

1. **冗長性判定付きの斜め除去(f_channel_diag)**
   河道—河道斜めエッジのうち、4近傍の中継河道セル経由の迂回が存在する
   もの(=冗長ショートカット)だけ通水を落とし、開口補正上は「塞がり」
   として法線へ振り替える(→ 角の横断合計が厳密に W)。
   **唯一の連結である斜め(実河道がセル角を斜めに横切る箇所)は残す**
   (一律 4近傍化は河道を堰き止めるため不可)。判定は rw の局所参照
   のみで静的・決定的。
2. **セル内実河道長 fn_length_rw**
   ラスタ化時にセル内の実河道長 L_real を集計して分布で与える。
   wfrac = W·L_real/(dx·dy) で貯留が定義から厳密になり、角をかすめる
   セル(L_real≈0)も正しくなる。さらにエッジ距離を
   d_e = (L_real(i)+L_real(n))/2 とすれば経路隣接エッジでテレスコープ
   して全経路長が保存され、**蛇行係数は独立パラメータとして不要になる**
   (吸収)。ただしショートカットには中継セルの長さが抜けて距離 ≈1dx と
   むしろ急化するため、1 の除去(または中継込み距離
   L_A/2+L_B+L_C/2 への補正)と必ず併用する。距離を補正しても幅の
   二重計上(横断 ≈1.15〜1.26W)は残る点に注意=1 が本命、2 は相補。
3. **対称振り替え**
   現行の開口補正は「塞がれた斜め→法線」の一方向のみ。斜めのみ連結の
   必須リンク区間は斜め方向の開口が標準シェア(≈41%)のままで過小通水
   (直線 1 セル河道の 41.4% 問題の斜め版)。必要が実証されたら、
   横断集合内の「生きている河道—河道メンバー」への比例配分に対称化する。
4. **init 検出・警告**
   必須斜めリンクの本数と並列河道セル(角の 2 セル太り。§18 制約(6))の
   検出を par_info 報告し、データ品質を可視化する(モデル変更なしで
   追加できる最小改善。優先度は上記より高い)。

## 6. 解析前チェックリスト

- [ ] 解像度: 対象河川のセル内蛇行度が ≈1(§1 前提 1)。放水路等の
      直角屈曲区間が主対象なら本モデルの適用可否を再考(§1 前提 3)
- [ ] 河道マスク: 単線・基本 4近傍連結(ベクトル通過判定)。並列
      2 セル太りなし(§18 制約(6))
- [ ] 幅 W: 河道セルに正値。W ≥ 面長の区間は自動的に解像扱い
- [ ] 粗度と植生の分担: 河床は rn(rn0_rw)、植生群落は gv/bb+Cd
      (二重計上しない。§18)
- [ ] 測線: 河道セルを完全横断させる(部分横断は過小計上。§18)
- [ ] dt: 狭幅・深掘り区間の CFL(§18 制約(7))
