# Windows での使い方(Unix がはじめての方へ)

ENCflow は Linux 系の環境で動きます。Windows しか使ったことがなくても
大丈夫です — 次の順路がおすすめです。

## ① まずはインストールなしで試す(5分)

ブラウザだけで ENCflow をビルド・実行・可視化できる Colab ノートブックを
用意しています。管理者権限も設定も不要です。実行には **Google
アカウントが必要**です(無料)。持っていない・作りたくない場合は、
①は飛ばして、このすぐ下の**②の WSL から始めてください**
(①を飛ばしても以降の手順に支障はありません)。

**[→ Colab で ENCflow を動かす](https://colab.research.google.com/github/ENCflow/ENCflow/blob/main/docs/colab_quickstart.ipynb)**

ノートブックのセルに書かれている `git clone` や `make` は、そのまま
下記 WSL でも使う実物の Unix コマンドです。まずここで一度動かして
おくと、以降の説明がすべて「見たことがあるもの」になります。

## ② 続けるなら WSL(Windows 標準の Linux 環境)

WSL は Microsoft 公式の機能で、Windows の中に Ubuntu(Linux)を
入れられます。インストールは PowerShell(管理者)で 1 コマンドです:

```powershell
wsl --install
```

再起動後、スタートメニューから Ubuntu を開き、ユーザー名とパスワードを
決めたら、あとは [インストールガイド](install.md) の手順どおりです:

```bash
sudo apt update && sudo apt install -y gfortran make git
git clone https://github.com/ENCflow/ENCflow.git
cd ENCflow/src && make install
cd ../test/wave && ./Run.sh
```

詰まったら Microsoft の
[WSL インストールガイド](https://learn.microsoft.com/ja-jp/windows/wsl/install)
を参照してください。

> **学校・職場のネットワークからの場合**: プロキシやフィルタリングの
> ある回線では、`wsl --install` や `sudo apt update` が
> ダウンロードに失敗することがあります(タイムアウトや証明書エラーに
> なります)。これはあなたの操作ミスではなくネットワーク側の制限なので、
> ネットワーク管理者に相談してください。すぐに解決できない場合も、
> 文書末尾の「③ WSL が使えない環境では」のとおり Colab だけで
> 進められます。

## 使うコマンドはこれだけ(早見表)

ENCflow の利用で日常的に使う Unix コマンドは 10 個程度です。
これ以上の予習は要りません。

| コマンド | 意味 | 例 |
|---|---|---|
| `cd 場所` | フォルダを移動する | `cd ENCflow/test/wave` |
| `cd ..` | ひとつ上のフォルダへ | |
| `ls` | いまの場所のファイル一覧 | |
| `pwd` | いまどこにいるか表示 | |
| `make install` | ビルド(コンパイル) | src/ で実行 |
| `./Run.sh` | 実行スクリプトを走らせる | 各 test/ ケースで |
| `./encflow param.txt` | ENCflow を直接実行 | |
| `cat ファイル` / `less ファイル` | テキストを表示(less は `q` で終了) | `less result/Log.txt` |
| `cp 元 先` | ファイルをコピー | `cp param.txt param2.txt` |
| `Tab` キー | ファイル名を途中まで打って補完 | 必須テクニック |
| `↑` キー | 前に打ったコマンドを呼び出す | 必須テクニック |

## Windows 側とのファイルのやりとり

WSL の中のファイルは、**エクスプローラー**から**ふつうのフォルダとして**
見えます。エクスプローラーとは、Windows でファイルやフォルダーを一覧する
標準の画面のことです(タスクバーの黄色いフォルダーのアイコン、または
`Windows キー + E` で開きます)。開き方は2つあります:

- **左側の一覧から**: エクスプローラーの左側の一覧を下のほうへたどると、
  ペンギンのアイコンの **Linux** という項目があります(最近の Windows)。
  そこから `Ubuntu` → `home` → `自分のユーザー名`(WSL の初回起動時に
  決めた名前)とクリックしてたどれます。
- **アドレス欄から**: エクスプローラー上部の、現在のフォルダー名が
  表示されている横長の欄(アドレス欄)をクリックして `\\wsl$` と打ち、
  Enter を押します。最初に見えるのは Linux 全体のルートなので、自分の
  ファイルは同じく `Ubuntu` → `home` → `自分のユーザー名` の先にあります。

> **`\` は `¥` と表示されます**: 日本語キーボード・日本語版 Windows
> では、バックスラッシュ `\` は円記号 `¥` として表示・入力されます
> (同じ文字の見た目が違うだけです)。本書の `\\wsl$` が画面上で
> `¥¥wsl$` と見えても同じものですし、入力は `¥` キーでかまいません。

上の手順どおりなら ENCflow は
`\\wsl$\Ubuntu\home\ユーザー名\ENCflow` にあります。よく使うので、
この場所(フォルダー)を右クリックして**クイックアクセスにピン留め**
しておくと便利です。パラメータファイルの編集はメモ帳や VS Code で、
結果のテキスト・CSV は Excel で、GeoTIFF は GIS ソフトでそのまま
開けます。

本格的に使うなら [VS Code](https://code.visualstudio.com/) +
「WSL」拡張機能が快適です(編集・ターミナル・ファイル閲覧が
1 画面にまとまります)。

## ③ WSL が使えない環境では

学校の PC などで WSL を有効化できない場合や、ネットワークの制限で
インストールが通らない場合も、①の Colab はブラウザだけで動きます。ネイティブ Windows 用の環境(MSYS2 等)でも動く
見込みですが、現時点では動作確認が済んでいないため、WSL を推奨します。
