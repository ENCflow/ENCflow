# ENCflow拡張: 地下水流出モジュール (m_gwflow) 実装ハンドオフ

対象: 谷(Tani)型の鉛直浸透支配流出機構を、構造格子分布型モデル(ENCflow)に
組み込むための設計。本ドキュメントは設計議論の要約であり、実装方針の
決定事項と未決定事項を整理する。

参照コード: `m_swflow_enc.f90` (既存の浅水方程式ソルバー。安定化手法の
実装パターンを踏襲する)

---

## 1. 背景と目的

### 1.1 物理現象

山地斜面において、降雨が鉛直浸透して地下水面を上昇させ、下流の河川へ
流出する過程を、次の2つの機構に分解してモデル化する。

- **鉛直浸透支配**: 土層が薄い箇所(特に斜面下端・遷急線付近)では、
  少量の降雨浸透で速やかに地下水面が上昇・飽和する。
- **側方圧力伝搬**: 地下水面上昇が不均一に生じた結果、飽和帯内の
  水頭勾配を介して側方(斜面方向)に圧力が伝搬する。

### 1.2 谷(Tani, 1997; 2020)モデルとの関係

谷先生のオリジナリティは**鉛直浸透の支配方程式自体ではなく**、次の
機構仮説とその実証にある:

> 土層厚 d(x) の空間分布が各地点の鉛直到達時間 T_v(x) = d(x)・n_e / K_s
> を決定し、薄い土層の箇所(斜面下端など)が先行して飽和することで、
> 流出応答全体のタイミングが鉛直浸透過程によって支配される。

したがって実装は「Taniモジュール」という専用コードを作るのではなく、
**汎用の鉛直モジュールと汎用の水平モジュールの組み合わせ**として
谷モデル的挙動を「創発」させる設計とする。d(i,j) が空間的に一様なら
側方流支配(TOPMODEL的)、急峻に薄くなる分布なら鉛直浸透支配(谷型)に
自然に遷移する。

## 2. モジュール構成方針

### 2.1 分離の理由

側方流動(非線形Boussinesq)と鉛直方向の浸透・貯留は、**別系統の
モジュールとして分離する**。

| 観点 | 側方流動 (lateral) | 鉛直浸透 (vertical) |
|---|---|---|
| 依存関係 | 近傍セル間結合(エッジ構造) | セル内で完結 |
| 並列化 | 毎ステップ通信必要(ハロ交換) | 通信不要(embarrassingly parallel) |
| 時間スケール | Δt制約が緩い(下記§4) | 降雨強度に応じ秒〜分スケール |
| 適用範囲 | 山地に限らず汎用の不圧地下水流動 | モデル選択の多様性が高い(Green-Ampt/バケツ/Richards近似等) |
| 既存パターンとの対応 | m_swflow_enc の momentum/continuous 構造を踏襲 | m_gwflow_bucket (既存実装)と同系統 |

### 2.2 構成案

```
m_gwflow (親モジュール・状態変数の所有者、init/calc/dispose の orchestrator)
  ├── m_gwflow_lateral      … 側方流動のモデル選択層(新設。vertical同様
  │     │                     プロシージャポインタで切替可能とする)
  │     - m_swflow_enc の continuous 相当の構造のみ踏襲(momentum 系装置は
  │       不要。§4a「エッジ状態レス設計」参照)
  │     - 状態: h_gw(飽和帯厚) or z_w(地下水面深度)。セル配列のみ
  │     - フラックス: 無履歴(Darcy則は局所平衡)。エッジごとにその場で
  │       計算し発散に消費する。永続エッジ配列(mn_gw, uv_gw相当)は持たない
  │     - 通信: par_halo_cell(h_gw) セル幅1のみ。エッジ交換・エッジマージ
  │       (par_halo_edge, par_edge_merge)は不要(§4a)
  │     ├── m_gwflow_lateral_darcy       (線形。§3.2a)
  │     └── m_gwflow_lateral_boussinesq  (非線形。§3.2b。分離型では
  │                                        h_gw<=d が構造的に成立するため
  │                                        RRIのh_dキャップは不要。§3.2.1)
  │
  ├── m_gwflow_vertical     … 鉛直浸透・貯留のモデル選択層
  │     - m_swflowのenc/stgパターンに倣い、プロシージャポインタで切替
  │     ├── m_gwflow_bucket       (既存の実例。手本とする)
  │     ├── m_gwflow_greenampt    (新規: Tani型 T_v 定式化に対応)
  │     └── (将来拡張: Richards近似等)
  │
  └── 結合ロジック
        - m_gwflow_vertical が d(i,j) と現在の h_gw から
          鉛直到達判定・ソース項 f_v(i,j) を計算
        - m_gwflow_lateral がそれを受けて側方拡散を解く
        - 両者は共有状態(h_gw, z_w, d)を通じてのみ結合
        - 地表流への引き渡し: h_gw >= d(z_w <= 0)のセルの超過水を
          浅水方程式ソルバー(m_swflow_enc)へ渡す
```

土層厚 d(i,j) は両モジュールが参照する共有ジオメトリ情報として
geoinfo構造体(g%)相当に持たせる。

## 3. 支配方程式

### 3.1 鉛直浸透 (m_gwflow_vertical / m_gwflow_greenampt)

Green-Ampt式(ピストン近似):

```
f_v = K_sv * (1 + psi_f * Δθ / F)
```

- `F(t)`: 累積浸透深。`F(t) <= (d - z_w) * Δθ` の間は不飽和帯を浸透中。
- `F(t)` が `(d - z_w) * Δθ` に達した時点で地下水面到達 → 以降は
  地表面到達分を側方モジュールのソース項 f_v として渡す。
- 解析的な到達時間の目安: `T_v = (d - z_w) * n_e / K_sv`
  (この式自体はメッシュ分割不要で評価できる。鉛直方向の離散化は不要)

### 3.2 側方流動 (m_gwflow_lateral) — モデル選択層

2つの選択肢を用意し、対象領域・計算目的に応じて切り替える
(m_swflowのenc/stgパターンに倣いプロシージャポインタで実装)。
(旧稿では「(b)RRI型/(c)谷型フル」をh_dキャップの有無で区別して
いたが、地下水と地表流を分離する本設計では h_gw<=d が構造的に
成立し両者は同一の式になるため、非線形版は単一の(b)に統合した。
§3.2.1参照。2026-08-05)

| 選択肢 | 拡散係数 | 特徴 | 対応する既存モデル |
|---|---|---|---|
| (a) 線形Darcy | D = K_sh*H̄ (固定) | 線形方程式。CFL制約が定数で確定。安価 | 古典的線形貯留・拡散型モデル |
| (b) 非線形Boussinesq | D = K_sh*h (局所) | RRIの側方流と同じ関数形 q=-k_a*h*∂H/∂x。hがdまで自由に変化し、h_dキャップ相当は分離型の構造で自動成立(§3.2.1) | RRI、HSBモデル拡張、Tani機構 |

**(a) 線形Darcy版:**
```
S_y * ∂h/∂t = K_sh*H̄*(∂²h/∂x² + ∂²h/∂y²) + K_sh*tanα*∂h/∂x + f_v(t)
```
H̄はセルごとのd(i,j)または流域一律の代表値として与える固定パラメータ。
拡散係数が状態に依存しないため陽的前進差分でも安価に解ける
(m_swflow_encと同じ陽解法アーキテクチャをそのまま踏襲する。
陰解法は採用しない。2026-08-05 決定)。実質的な利点は、CFL制約
Δt <= S_y*Δx²/(2*K_sh*H̄) が実行前に定数として確定し、非線形版の
ような実行時の動的な安定性監視・係数再評価が不要になる点、および
h→0の特異性(§5)が原理的に発生しない点。ただし飽和帯厚ゼロ近傍の
非線形効果(飽和域の動的拡大・縮小)は表現できないため、基底流量
再現や広域スクリーニングには適するが、谷型の急峻・薄層条件での
ピークタイミング精度は(b)に劣る。

フラックス(1階微分のみ、係数H̄は固定値。全水頭Hの定義は(b)と共通、
§3.2.3参照):
```
q_k = -K_sh * H̄ * (H_n - H_c) / dr_k * l_k
```

**(b) 非線形Boussinesq版:**

まず、離散化で実際に計算するのはセル境界での**フラックス**(1階微分の
み)である。これはRRIの流量式と同型:

```
q_k = -K_sh * h_e * (H_n - H_c) / dr_k * l_k   ! フラックス(1階微分のみ)
```
- `h_e`: セル境界での飽和帯厚(上流側水深でキャップ。f_hcap_upwind相当)
- `H`: 全水頭。地表湛水の寄与を含む(**2026-08-05 訂正。旧稿の
  H=z+(d-h)は符号誤り、かつ地表湛水を未考慮だった。定義と理由は
  §3.2.3参照**)

RRIの q=-k_a*h*∂H/∂x も同型で、H=h+zで展開しても
q=-k_a*h*∂h/∂x - k_a*h*∂z/∂x と1階微分のみ。**フラックス方程式の
段階では二階微分は現れない**(RRIも本設計も同じ)。

参考として、連続の式(質量保存則、∂h/∂t=-∂q/∂x)の右辺を解析的に
展開すると、状態依存フラックスq=-K*h*∂H/∂xの発散を取る操作から
二階微分項が現れる(積の微分則):

```
S_y * ∂h/∂t = K_sh*(∂h/∂x)^2 + K_sh*h*∂²h/∂x²
            + K_sh*(∂h/∂y)^2 + K_sh*h*∂²h/∂y²
            + K_sh*tanα * ∂h/∂x
            + f_v(t)
```

**これはフラックス方程式とは別の、連続極限でのPDE(質量保存則)
であり、CFL安定性(§4)の解析目的でのみ使う。実際の数値実装
(有限体積法)では、上記のフラックスq_kをセル境界ごとに計算し、
セルの流入出フラックス差(離散的な発散、continuous相当)でhを
更新するだけであり、二階微分の式を明示的に評価する箇所は
どこにもない。** RRIと本設計は、フラックスレベルでも数値実装
レベルでも完全に同型である。

各項の意味(上記の連続極限PDEにおいて):
- 第1,2項(x方向): 非線形拡散。実効拡散係数 D = K_sh * h
  (h→0でD→0となる特異性の起源。§5参照)
- 第3,4項(y方向): 等高線方向の圧力伝搬。谷頭凹地への収束流を表現。
- 第5項: 傾斜による移流・重力駆動項。急勾配斜面で支配的。
- 第6項: 鉛直浸透からのソース項(m_gwflow_verticalから受け取る)。

**選択指針:** 谷型の急峻・薄層山地小流域でのピーク遅れの物理的再現も、
RRIとの比較検証も、いずれも(b)(分離型では両者は同一の式になる。
§3.2.1)。広域・長期計算でコストを優先し基底流量の再現で十分なら(a)。

### 3.2.1 補足: RRIのh_d飽和閾値キャップと本設計の対応関係

RRIは地下水と地表水を単一の状態変数h(不透水層基準の水位)で
表現し、流量式がh=h_dで折れ線状に切り替わる一体型の定式化を
とる:

```
q = -k_a*h*∂H/∂x                                    (h<=h_d: 土層内)
q = -k_a*h_d*∂H/∂x - sqrt(|Sf|)/n*(h-h_d)^(5/3)*sign(Sf)  (h>h_d: 地表湛水)
```

h<=h_dの領域は非線形Boussinesq(選択肢b/cと同じ関数形)そのもの。
h>h_dでは地下部分の流量がk_a*h_dで頭打ちになり(透水断面が土層厚
いっぱいで飽和)、超過分(h-h_d)がManning則の地表拡散波として
追加される。h=h_dで連続的に接続されるため、地下水飽和→地表湛水
の遷移を単一の式・単一ソルバーで扱える。

本設計は地下水(m_gwflow_lateral)と地表水(m_swflow_enc)を別モジュール
・別状態変数(h_gw, h_sw)に分離し、「h_gw>=d(=h_d相当)のセルの超過水
を地表流ソルバーに渡す」境界条件的結合とした(§1.2, §9参照)。これは
RRIの折れ線構造を2つの独立モジュールへ分割した等価表現であり、
d(i,j)がh_dに対応する。この分割の帰結として、**h_dキャップ処理の
明示的な実装は不要**である: 分離型では h_gw >= d に達した時点で
超過水が地表流側へ渡り h_gw <= d が構造的に保証されるため、
「透水断面を d で頭打ちにする」操作は恒等操作になる。RRIの折れ線の
上側(地表 Manning 拡散波)は m_swflow_enc がそのまま担う。ゆえに
旧稿の「(b)RRI型/(c)谷型フル」の区別は消滅し、非線形版は単一の
(b)に統合される(2026-08-05 決定)。

トレードオフ: RRIの一体型は単一ソルバーで完結し効率的だが、地下・
地表が密結合しm_swflow_enc既存の家屋透過率等の地表流固有パラメータ
と混在しにくい。本設計の分離型はフラックス受け渡しの追加コストが
生じる代わりに、モデル差し替え(線形/非線形等)の独立性と
m_swflow_enc既存機構の再利用性を確保できる。**RRIのような一体型
(単一状態変数・単一ソルバー)の機構は将来的にも作らない**
(2026-08-05 決定。分離型が恒久方針)。

**注記(重要): RRIの式に非線形拡散項が「ない」わけではない。**
q=-k_a*h*∂H/∂x は H=h+z(全水頭)を用いており、展開すると
q = -k_a*h*∂h/∂x - k_a*h*∂z/∂x となる。第1項が(b)の拡散項
(K_sh*(∂h/∂x)^2 + K_sh*h*∂²h/∂x²の元)、第2項が移流・重力駆動項
に対応する。RRIは両者をHの勾配という1つの表現に圧縮しているだけ
で、拡散項は含まれている。動水勾配を「水面勾配H」で取るか
「地形勾配zのみ」で取るかが、拡散項の有無を分ける本当の分岐点
であり、後者が純粋な運動波近似(kinematic wave, 例:
Takasao and Shiiba 1988, Beven 1981)に相当する。

### 3.2.2 非線形拡散項(水面勾配由来の圧力伝搬)が物理的に効くケース

拡散項が卓越するのは、地下水面勾配 ∂h/∂x が地形勾配 tanα に対し
無視できない場合:

- **谷モデルの機構そのもの**: d(i,j)が急に薄くなる箇所(斜面下端)
  では地下水面が地形勾配と独立に局所的な急勾配を持つ。拡散項を
  落とす(運動波近似)と、この「薄い土層箇所からの圧力伝搬」という
  機構自体が再現できなくなる。**谷型機構の再現(選択肢b)では
  拡散項を落としてはならない**
- 緩勾配の谷底・扇状地(tanαが小さくh勾配の寄与が相対的に増す)
- 河道付近のバックウォーター効果
- 収束地形(谷頭凹地)での等高線方向の圧力伝搬
- K_sh, d(i,j)の不均一性による局所的な飽和パッチ周辺

拡散項が無視できる(運動波近似が妥当な)のは、急勾配で地形が比較的
一様な斜面(tanα >> |∂h/∂x|が常に成立)。表3.2の(b)は拡散項
を保持する設計とし、将来的にm_swflow_encのf_govequation
(DynWE/DifWE/KinWE切替)と同じパターンで、拡散項を落とした軽量な
運動波オプション(c)を追加する余地はあるが、谷型機構の再現には
使えない点を明記しておく。

### 3.2.3 全水頭Hの定義: 地表湛水の寄与(2026-08-05 追加・訂正)

**問題提起**: RRIの式 q=-k_a*h*∂H/∂x (H=h+z) は、h_dキャップ後の
領域(地表湛水あり)でも∂H/∂xとして地表湛水深を含む実際の水面勾配
を使う(透水断面はk_a*h_dで頭打ちにするが、駆動力=動水勾配は地表面
で打ち切らない)。旧稿のH=z+(d-h)はこれを反映しておらず、2つの
不備があった: (1)符号誤り(h=飽和帯厚のときd-h=z_wであり、
「全水頭=地盤高+地下水面深度」では水面が深いほど水頭が高くなる
逆の関係になっていた)、(2)地表湛水深h_sw(m_swflow_encのs%h)を
一切参照していなかった。

**訂正後の定義**: 不透水層(岩盤面、標高z-d)を基準に、

```
H = (z - d) + h_gw + h_sw
```

検算: h_gw<d(不飽和、構造的にh_sw=0)でH=z-d+h_gw(h_gw増加で
H増加、符号正しい)。h_gw=dちょうどでH=z-d+d+0=z(地表面標高に
一致、連続)。h_gw=dかつ地表湛水ありでH=z+h_sw(地表標高+湛水深、
RRIの折れ線構造と等価)。

**帰結: 新しい結合経路(地表流→地下水)が必要になる。** 従来の
結合ロジック(§2.2)は「h_gw>=dのセルの超過水をs%hへ渡す」という
地下水→地表流の一方向だったが、この訂正により
**m_gwflow_lateralのフラックス計算がs%h(h_sw)を読む**という逆方向
の依存が加わる。物理的には、飽和したセルの上に地表湛水(河道の
氾濫による背水等)が乗ると、その分だけ地下水側方流の駆動力が
増す(§3.2.2の「河道付近のバックウォーター効果」の具体的な実装
経路がこれにあたる)。

**MPI・実行順序への影響**: s%hはm_swflow_enc自身がそのステップで
既にハロ交換済みの配列であるため、新たなMPI通信は不要(エッジ状態
レス設計§4aの通信最小化方針は維持される)。ただし、ステップ内の
実行順序を明確にする必要がある: m_swflow_encのハロ交換完了後に
m_gwflow_lateralのフラックス計算を行うか、あるいは前ステップの
s%hを一貫して使うか(陽解法での時間積分順序の問題)。§8未決定事項
に追記。

**(a)線形Darcy版への適用**: H̄は固定パラメータだが、Hの定義自体は
(b)と共通([z-d]+h_gw+h_swのh_gw部分のみ固定値H̄に置き換える形には
ならない点に注意。H̄は拡散係数の固定化であり、勾配側のHは(b)と
同じ定義を用いる)。

## 4. タイムステップに関する結論

**地表流(m_swflow_enc)と同一のΔtを共有できる。** 検証済みの根拠:

浅水方程式のCFL(重力波): `Δt_sw ≲ Δx / sqrt(g*h_sw)`
→ 典型値(h=1m, Δx=50m)で Δt_sw ≲ 16 s

非線形Boussinesq拡散のCFL: `Δt_gw ≲ S_y * Δx² / (2*K_sh*h_gw)`
→ 典型値(S_y=0.2, K_sh=1e-4 m/s, Δx=50m, h_gw=0.1〜2m)で
  Δt_gw ≒ 10^6〜10^7 s (地表流よりはるかに緩い)

移流項のCFL: `Δt_adv ≲ S_y*Δx / (K_sh*tanα)`
→ 急勾配(tanα=0.3)でも Δt_adv ≒ 3×10^5 s (これも十分緩い)

→ **実装は地表流と同じΔtで駆動してよい。** 将来的に側方流動を
サブサイクリング(大きいΔtで間引く)する最適化の余地はあるが、
初期実装では不要。

## 4a. 計算コストの構造的な優位性と対策

### 移流項(運動方程式)が不要

m_swflow_encの浅水方程式は運動方程式(慣性項付き)であり、
momentum サブルーチンとその周辺装置一式(adv_edge/TVDスキーム
[ハロ幅2]、f_adaptive_runge[最大4段RK]、correct_ge[急勾配補正]、
m_ffactor_calc[摩擦の半陰解法])が必要になる。

Darcy則(非線形Boussinesqの基礎)は局所平衡則であり、流速の時間
発展方程式を持たない。フラックスq_kはその瞬間の水頭差のみから
代数的に決まるため、m_gwflow_lateralにはmomentum相当の処理が
一切不要で、continuous相当(フラックス計算+発散による質量収支)
だけで完結する。エッジあたりのFLOP数は m_swflow_enc の momentum
計算より一桁近く少なくなる見込み。ハロ幅も移流TVDスキームが要求
する幅2ではなく、セル幅1で足りる(下記「エッジ状態レス設計」)。

### エッジ状態レス設計(永続エッジ配列・エッジマージの不要化)

フラックスの無履歴性から、メモリ・MPI構造にも次の帰結が出る
(2026-08-05 決定):

- m_swflow_enc が mn の二重バッファ(mn→mn1)と界面エッジマージ
  (par_edge_merge)を必要とするのは、フラックスが時間発展する状態
  (慣性)だからである。Darcyフラックスはその瞬間の h_gw, z, d のみ
  から代数的に決まるため、h_gw をセル幅1でハロ交換すれば、帯界面の
  フラックスは南北両ランクが同一入力から同一値をビット厳密に再計算
  できる(developer.md §11「冗長計算=配布機構」原則)。
- したがって m_gwflow_lateral は永続エッジ配列(mn_gw, uv_gw 相当)、
  二重バッファ、par_halo_edge、par_edge_merge のいずれも持たない。
  フラックスはエッジごとに計算してその場で発散(質量収支)に消費する。
- 効果: (1) エッジ配列はセル配列の数倍を占める最重量級のメモリ項
  (save/restore の見積で 250m 級 1.7GB / 100m 級 11GB)であり、
  これを持たないことで地下水導入のメモリ増分が h_gw + d(i,j) +
  分布オプション程度に縮む。(2) リスタート対象がセル状態だけになる
  (§8)。(3) 通信は par_halo_cell(h_gw) 幅1のみで、サブサイクリング
  と合わせ通信頻度・通信量とも最小になる。(4) m_swflow_enc の MPI
  機構のうち再利用するのはセルハロ交換だけで、MPI 統合が一段簡単になる。
- 診断でフラックス場を出力したい場合のみ、その時に一時配列へ落とす。
- (a)線形Darcy版も陽解法で実装する(陰解法は採用しない。§3.2a)ため、
  エッジ状態レス設計は全モデル選択肢で成立する。

### Δtサブサイクリング

CFL制約が非常に緩い(Δt_gw〜10^6〜10^7 s程度)ため、地表流の毎
ステップに対しNステップに1回だけ側方流動を解くサブサイクリングが
正当化される。

実装方針: m_gwflow_vertical が計算するソース項f_vをNステップ分
積算しておき、側方流動側はその積算値を使って1回だけ大きな
Δt_sub=N*Δtで更新する。これにより計算コストに加え、**MPI通信
(par_halo_cell(h_gw))の回数も1/Nに削減**できる。地下水
側方流動は近傍セル結合を持つため通信コストが本質的に発生するが、
サブサイクリングは通信頻度そのものを下げる効果がある。

Nの決定方法・地表流ループとの同期方法(カウンタ管理)は実装時に
要検討(§10未決定事項に追記)。

### 分布パラメータのメモリ対策

d(i,j), K_sv(i,j), K_sh(i,j), S_y, n_e, psi_f, z_w0(i,j) を
全てセル分布配列にすると、既存の地表流状態量に加えメモリ消費が
増加する。対策は2段構え:

1. §6で示した通り本質的に分布が必要なのはd(i,j)のみ。K_sv, K_sh,
   S_y, n_e, psi_fは流域一様スカラー定数をデフォルトとし、必要な
   場合のみオプションで空間分布を許容する設計とし、メモリ増加を
   最小限にする。
2. d(i,j)等の静的(時間不変)地下水パラメータは、物性係数
   (rn, gv, bb 等)と同じ**方式2**に載せる: rank0 のみが全域を
   読み込み・構築し、par_scatter_cell で各ランクの帯+ハロへ配布する
   (developer.md §11。g%z の「rank0 恒久全域保持」は例外パターンで
   あり、こちらには倣わない)。init では rank0 の全域配列の同時保持
   ピークを避けるため「1配列ずつ 読み→scatter→解放」のストリーミング
   順で処理する。動的状態変数(h_gw)とは別扱い。

## 5. 数値安定化: h→0での特異性対策

非線形Boussinesqは h→0 で拡散係数 D=K_sh*h→0 となる。m_swflow_enc
の安定化パターンがそのまま応用できる。対応表:

| m_swflow_enc の手法 | 該当箇所 | m_gwflow_lateral での対応 |
|---|---|---|
| 乾燥判定(dd閾値) | calc_kth_momentum L549 | `h_gw < eps` の両セルで流量ゼロ |
| **過大流出の抑制(exflux_reduction)** | calc_kth_momentum L594-607 | **同一ロジックを流用**(§5.1) |
| 上流側水深キャップ | calc_kth_flux correct_he() L778 | 界面飽和帯厚 h_e の上流側キャップ |
| 摩擦の半陰解法 | calc_kth_flux L736 | (該当なし。Boussinesqに摩擦項はない) |
| 適応的ルンゲクッタ | calc_kth_momentum L573-579 | 移流項(第5項)が急変する場合に検討 |

### 5.1 過大流出抑制の移植(最重要)

m_swflow_enc の該当コード:
```fortran
if ((dh > 0 .and. s%h(i,j) - dhc <= 0) .or. ...) then
  cor = max(s%h(i,j) - p%dd, 0.0) / dhc
  uve1 = uve1 * cor
  mne1 = mne1 * cor
end if
```

Boussinesq版の骨格(2026-08-05: 全水頭Hの定義を§3.2.3の訂正に
合わせて更新。hsw=地表湛水深、m_swflow_encのs%hから読む):
```fortran
subroutine calc_kth_gw_flux(hgw, hsw, z, d, Ksh, Sy, i, j, k, in, jn, dt, dx, q_out)
  hgw_e = (hgw(i,j) + hgw(in,jn)) / 2
  if (f_hcap_upwind > 0) hgw_e = min(hgw_e, hgw_upwind)  ! correct_he相当

  ! H = (z-d) + hgw + hsw (§3.2.3。hswは構造的にhgw=dのセルのみ非零)
  Hc = (z(i,j)   - d(i,j))   + hgw(i,j)   + hsw(i,j)
  Hn = (z(in,jn) - d(in,jn)) + hgw(in,jn) + hsw(in,jn)
  grad_H = (Hn - Hc) / dr(k)
  q = -Ksh * hgw_e * grad_H * l(k)

  dh_out = q * dt / (dx * dx * Sy)
  if (hgw(i,j) - dh_out <= eps) then
    cor = max(hgw(i,j) - eps, 0.0) / dh_out
    q = q * cor
  end if
end subroutine
```

Boussinesqの場合、フラックスq自体がh_gwに比例するため、浅水方程式
(乾燥時も重力波速度sqrt(gh)が残る)より特異性は軽度である。

## 6. セルごとに必要なパラメータ

| パラメータ | 記号 | 役割 | 空間分布の必要性 |
|---|---|---|---|
| 土層厚 | d(i,j) | T_v・h_gw上限を決定。**最重要** | **必須** |
| 鉛直飽和透水係数 | K_sv(i,j) | Green-Ampt浸透速度 | 推奨 |
| 側方飽和透水係数 | K_sh(i,j) | Boussinesq側方流の速度 | 推奨 |
| 比湧水量 | S_y | 地下水面上昇量の換算 | 均一可(§6.1参照) |
| 有効間隙率 | n_e | 不飽和帯保持量 | 均一可(§6.1参照) |
| 毛管圧力水頭 | psi_f | Green-Ampt閾値 | 均一可 |
| 初期地下水面深度 | z_w0(i,j) | 先行湿潤条件 | セルごと初期化 |
| 斜面傾斜 | tanα | 移流項(重力駆動) | DEMから計算可能(g%z由来) |

d(i,j) 以外は流域一様値でも一定の精度が出る想定。観測・キャリブレー
ションのリソースは d(i,j) の推定精度に優先配分するのが合理的。

### 6.1 補足: 比湧水量 S_y と有効間隙率 n_e の整合性(質量保存上の注意)

S_y(m_gwflow_lateral、Boussinesqで地下水面変動量を水量に換算する
係数)と n_e/Δθ(m_gwflow_vertical、Green-Amptで湿潤前線が消費する
水分不足量の係数)は、物理的起源(排水可能間隙率)は同じだが、
定義上は別物になりうる:

- n_e(Δθ = φ - θ_i)は降雨前の初期含水率θ_iに依存する、
  イベント・セルごとに変わりうる量
- S_yは長期的な排水/充填可能間隙率で、地下水面**上昇**時は
  充填性間隙率、**低下**時は排水性間隙率と呼び分けられ、空気の
  巻き込みにより充填性 < 排水性となり両者が一致しない場合がある
  (本モデルの主用途は降雨時の地下水面上昇なので充填性間隙率の
  値を用いるのが物理的に整合的)

**結合点での質量保存への懸念**: 鉛直浸透が地下水面に到達し h_gw を
持ち上げる際、m_gwflow_vertical側で消費された水分量(Δθ×上昇量)
と、m_gwflow_lateral側がその上昇に必要とする水量(S_y×上昇量)が
食い違うと、両モジュールの結合点(§2.2 結合ロジック)で水収支誤差
が生じる。

対応方針(要決定。候補):
1. n_e = S_y として単一パラメータに統合する(質量保存が構造的に
   保証されるが、上昇時/低下時のヒステリシスや空気巻き込み効果は
   表現できない)
2. 別パラメータのまま許容し、差分を水収支残差として診断・監視する
3. 差分を意図的な物理量(閉じ込め空気等)としてモデル化する

初期実装では**1(n_e=S_y に統一)を推奨**する。§9の単体・結合テスト
(解析解のあるBoussinesq拡散問題、d(i,j)分布シナリオ)で水収支
ゼロを機械的に検証できるため。

**遅延排水(delayed yield)への留意**: S_yを瞬時定数として扱う
Boussinesq方程式(§3.2)は、地下水面変動に対する排水/充填が瞬時に
実現するという仮定を置いている。実際にはこの過程はm_gwflow_vertical
と同じ物理(不飽和帯の鉛直浸透、時間スケールT_v)に支配されており、
T_vが側方流動の時間スケール(§4のΔt_gw)に対して無視できない場合、
二次的な遅れとして応答に影響しうる。初期実装は瞬時平衡近似(S_y
一定)で進め、必要であればT_vとの時間スケール比較を感度解析で
確認する。

## 7. 既存モデルとの位置づけ(設計判断の根拠)

| 比較軸 | 本実装(m_gwflow) | RRI | HSBモデル |
|---|---|---|---|
| 鉛直浸透 | Green-Ampt、d(i,j)空間分布あり | Green-Ampt、h_d均一 | 入力フラックスR(t)のみ |
| 側方流 | 非線形Boussinesq 2D | 非線形Boussinesq 2D(q=-k_a·h·∇H。本実装と同形。h_dで頭打ち。§3.2.1注記) | 非線形Boussinesq 1D |
| 圧力波伝搬 | D=K_sh·h/S_y が動的、上限はd(i,j)分布 | D=k_a·h/S_y が動的、上限はh_d均一 | 斜面幅関数w(x)で制御 |
| 地下・地表の結合 | 分離型、双方向(gw→sw: t_state経由の超過水受け渡し§8。sw→gw: 全水頭Hの地表湛水寄与§3.2.3) | 一体型(単一状態変数hの折れ線流量式) | 地表流なし |
| 地形の3次元性 | 2D格子で自然表現 | 2D格子 | 1D斜面に折り畳み |

側方流の関数形自体はRRIと同形である(旧稿の「RRI=Darcy線形」は
誤りで、q=-k_a·h·∇H は h に比例する非線形フラックス。§3.2.1注記
参照。2026-08-05訂正)。本実装の差別化点は、(1) 土層厚 d(i,j) を
空間分布として陽に扱い、鉛直到達時間 T_v の分布(谷機構)を表現する
点、(2) 地下水と地表流を分離しモデル差し替えを独立にした点、
(3) HSBモデルの非線形飽和帯厚表現を2D格子へ展開した点にある。
