# ENCflow アイコン候補

GitHub のプロジェクトアイコン(アバター)用の候補集。全候補共通の設計条件:

- 正方形または円形(GitHub 側で角丸マスクがかかるため、円形案はどの表示でも形が変わらない)
- 水をイメージした2トーンの青 + 白
  - 濃青 `#0E5A8A`(グレースケール変換でおよそ 30% の暗灰)
  - 淡青 `#66C2E0`(同じくおよそ 72% の明灰)
- 白黒印刷でも印象が変わらないこと(色相ではなく明度差だけで図が成立する)。
  `contact_sheet.png` の中段がグレースケール変換の検証結果。
- 正本はベクトル(SVG、viewBox 1024)。PNG は 1024px と 512px を同梱
  (GitHub アバターは 500px 以上推奨)。

## 候補一覧

| 案 | ファイル | 形 | モチーフ |
|---|---|---|---|
| A | `candidate_a_radial8` | 円 | 八方位の放射(ユニオンジャック風)+ 中央のラスタセル。白=4方位、淡青=斜め4方位の2階層 |
| B | `candidate_b_grid8` | 角丸正方形 | 中央セルと8近傍セルの接続グラフ。ENC 格子の8方向接続を最も直接的に表現 |
| C | `candidate_c_encwave` | 角丸正方形 | 「ENC」モノグラム + 波線。文字ベース案 |
| D | `candidate_d_layers` | 円 | 白の十字と淡青の斜め十字の前後2レイヤ。8方向 + 複数プロセスの重なりを透過なしで表現 |
| E | `candidate_e_compass` | 円 | コンパス風の8方位ティック + リング + 中央に「ENC」。放射案と文字案の折衷 |

- 図形はすべて基本図形(rect/circle/line/path)の組み合わせで、フォント埋め込みなし
  (C・E の文字はストロークで作図しており、環境依存なくレンダリングされる)。
- 「複数プロセスの重なり」は D 案では前後関係(オクルージョン)で、
  A 案では放射の2階層(白/淡青)で示唆している。透明度は使っていない
  (白黒変換・縮小時の安定のため)。

## 再生成の手順

SVG の生成は `gen_icons.py`(標準ライブラリのみ)。PNG 化は任意の SVG ラスタライザでよい。
例(rsvg-convert):

```sh
python3 gen_icons.py
rsvg-convert -w 1024 -h 1024 candidate_a_radial8.svg > candidate_a_radial8_1024.png
```

ヘッドレス Chromium でも可(`--window-size` を縦に余分に取り、上端 1024×1024 を切り出す)。

## 採用時の作業

1. 採用案を決めて `icon.svg` / `icon_1024.png` / `icon_512.png` にリネームし、不採用案を削除
2. GitHub のリポジトリ(または organization)設定でアバターとして PNG をアップロード
3. 必要なら README.md 冒頭にロゴとして掲示
