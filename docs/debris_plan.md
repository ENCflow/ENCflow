## 0. 結論(要約)

- **単層混合体方式**: 土石流は「地表水 h + 土砂濃度(s%hs)」の単層で
  表現する(Kanako 系と同じ定式化水準)。地下水のような別層 ENC は
  作らない — 土石流は移流項が本質で、別層は事実上第二の浅水ソルバ+
  層間交換になりコストが倍以上になるため。
- **既存機構が受け皿になるもの**: 土砂の移流(advect_scalar)、
  停止土砂の z への転換と天然ダム形成(E-D の堆積側+動的 z)、
  移動可能範囲・深さの入力(s%sd = f_sdtype/fn_sdh)、上流からの
  水・土砂の境界条件(区間流入 + inflow_cs/qs)。
- **新規に作るもの**は4つ:
  - **D1 f_debris**: 高橋型の平衡濃度 C∞(θ) に基づく侵食・堆積
    (E-D)。勾配依存の C∞ が「侵食起動のトリガー」を内包する
    (急勾配で C∞ が発散的に増大 → 一気の侵食と流下成長)
  - **D2 f_dbres**: 濃度依存の抵抗則(クーロン+マニング合成)。
    降伏(動き出し・停止)を表現する
  - **D3**: 運動量(重力・圧力項、摩擦水深)への hs の算入
    (流動深の実体 = h + hs)
  - **D4 瞬時流動化**: セル群+崩壊深の初期条件(fn_dbinit)を
    hs/h/z/sd へ台帳整合で転換(t=0 または時刻指定 db_reltime)。
    **f_slide**: 無限長斜面安定(Fs<1)による発生の自動判定
    (gwflow の飽和進行と結合)
- **発生形態の対応**(高橋の分類): (1) 渓床堆積物の表面流による
  侵食起動 = D1、(2) 崩壊土砂の流動化 = D4/f_slide、(3) 天然ダム
  決壊 = 動的 z + 越流侵食(既存+D1)。

## 2. 設計

### 2.1 状態量と定義

新しい保存状態は**増やさない**(save_version 不変)。既存の
s%hs / s%sd / s%z / s%h をそのまま使う。

- 濃度の定義: **混合体積濃度 C = hs / (h + hs)**(h は水柱、hs は
  固体柱状量、h+hs が流動深の実体)。希薄極限では既存の C = hs/h と
  漸近一致する。f_debris の E-D と D2/D3 はこの定義を使う
  (f_suspend の希薄近似 C = hs/h は変更しない)。
- C* (河床の充填濃度)= 1 − λ(既存の fluv_porosity から導出。
  新パラメータにしない。Kanako の C* = 0.65 は porosity 0.35 に相当)。
- 通知フラグ: s%debris_active(logical。m_geomorph_init が設定。
  s%sed_active / s%gw_active と同じ様式)。sed_active は
  f_suspend または f_debris で立つ(移流は共通の advect_scalar)。

### 2.2 D1: f_debris の E-D(m_geomorph_debris submodule)

- 局所勾配: tanθ = 8近傍への最急降下勾配
  max_k (z(i,j) − z(in,jn)) / dist_k(下限 0)。ハロ ±1 で完結
  (z のハロは geomorph calc 末尾交換+ステップ頭交換で最新)。
  流向依存の勾配でなく地形勾配を使う(停止判定が速度 0 でも定義される
  こと、決定性、コストの観点。文書化済みの近似)。
- 平衡濃度(勾配領域で切替。gm%db_tanphi = tan(db_phi)):
  - tanθ ≥ tanφ・0.9 相当(C∞d が上限に届く領域): C∞ = 0.9C*
  - tanθ > 0.138: C∞ = min(tanθ / (s(tanφ − tanθ)), 0.9C*)(石礫型)
  - 0.03 < tanθ ≤ 0.138: C∞ = min(6.7・C∞d², 0.9C*)(未成熟)
  - tanθ ≤ 0.03: C∞ = 0(掃流域は堆積側に一本化。§1)
- 交換(suspend と同じ反対称適用・クランプ・共動更新・gwflow 容量
  引き渡し。fx は固体柱状量):
  - C < C∞(侵食): fx = +C*・δe・(C∞−C)/(C*−C∞)・|V|・dtw
    (可動層クランプ: fx ≤ sd/(morfac・poroi)= sd・C*/morfac)
  - C > C∞(堆積): fx = −C*・δd・(C−C∞)/C*・|V|・dtw = −δd・(C−C∞)・|V|・dtw
    (浮遊量クランプ: |fx| ≤ hs)
  - 乾燥セル(h ≤ dd): hs 全量を河床へ(suspend と同一)
- **停止条件の切替 f_dbstop**(ユーザー要求の「切り替え式」):
  - 0: なし(E-D の ∝|V| のみ = Kanako 相当。|V|→0 で交換が凍結)
  - 1: 低速凝集 — vv < db_vstop かつ C > C∞ のセルで、超過濃度を
    レート db_wstop で河床へ(fx = −min(hs・(C−C∞)/max(C,eps),
    db_wstop・dtw・C*)…実装は簡潔化した等価形)。停止した土塊が
    河床(z)へ転換され、天然ダムの地形として固定される。
    ※この式は数値的閉包(独自)であり文献式ではないことを明記
- 侵食が付加する間隙水・堆積が持ち去る間隙水の授受は**無視**
  (既存 suspend と同じ近似。水相は独立に保存)。δe の校正で吸収する。
- 排他・ガード(init):
  - f_debris と f_suspend は排他(同一 hs 上の E-D 二重計上を防ぐ)
  - f_wash は f_suspend 必須のまま(f_debris との併用は将来)
  - morfac ≠ 1 は par_stop(土石流はイベント計算。地形加速は無意味)
  - dt_geomorph は dt と同程度を推奨(E-D の時定数が速い)
- MPI: セル内交換のみ(エッジ・ハロ不要)。suspend と同型。

### 2.3 D2: 濃度依存抵抗則(f_dbres。m_swflow_enc)

- パラメータの受け渡し: m_geomorph_init が
  m_swflow_enc_set_debris(f_dbres, tanphi, sgrav) を呼ぶ
  (geomorph init は swflow init より前。フラグは s%debris_active)。
- **f_dbres=1: クーロン+マニング合成**(Voellmy 型の構成。実装):
  - エッジ混合濃度 Cm = (hs_c+hs_n) / (h_c+h_n+hs_c+hs_n)
  - クーロン減速度 a_y = ge・tanφ・s・Cm/(1+s・Cm)
    (水中固体重量の底面摩擦。ge は correct_ge 済み=cos²θ を共有。
    ρm = ρ(1+sC) で除した加速度形。経験定数なし)
  - 半陰解法への合成: tfe += −a_y / max(vve, p%vv)
    (既存マニング項・建物抗力と同じ次元・同じ 1/(1−tfe dtl) 系)
  - **降伏判定(動き出し・停止)**: |tae + tge| ≤ a_y かつ
    |uve0| < db_vstop なら uve1 = mne1 = 0(静止維持)。
    駆動が降伏を超えない限り初期土塊は滑らない(地滑り型の
    「置いても滑らない」と、流動後の「停止」を同じ式で表現)
  - Cm→0 で a_y→0 = 清水のマニングへ連続に退化(閾値不要)
- **f_dbres=2: 高橋ダイラタント(予約)**: par_stop(§1。文献照合後)
- f_dbres=0: 既存マニングのみ(D1 だけを検証したいとき用)

### 2.4 D3: 運動量への hs の算入(m_swflow_enc)

s%debris_active のときのみ(分岐1個。無効時ビット一致):

- 圧力・重力項: 水面勾配を (z + h + hs) で評価
  (tge = tg0e − ge・((hn+hsn) − (hc+hsc))/dr・gve)
- 摩擦水深: hhe = max(he + hse, dv)(混合流動深)
- 位相ごとの連続式は不変: 水フラックス mne1 = uve1・he(水柱)、
  固体フラックス = advect_scalar の風上輸送(同じ uve1 が運ぶ)。
  固液同速の単相近似(Kanako と同水準)
- RK 内の仮水深更新は水柱のみ追跡(hs は時刻 n 固定。文書化する近似)
- 移流項(taxy)は水ベースのまま(混合運動量の移流は近似。文書化)

### 2.5 D4: 瞬時流動化(f_release)と f_slide

**共通の転換操作 fluidize(i,j,D)**(発生時に呼ぶ):
- hs += (1−λ)・D、z −= D、sd −= D(固体台帳が構造的に閉じる:
  Δhs = −(1−λ)Δz)
- 水の解放:
  - gw_active: 容量縮小の超過引き渡し(cap = sd・sy0 を下回った
    hg を h へ)のみ = 間隙水は hg から出る(物理的・台帳整合)
  - gwflow 無効: h += λ・db_relsat・D(シナリオ的な間隙水付与。
    relsat は飽和度 0〜1)
- 転換は帯内セルのみ(owner-compute)。z/sd のハロは calc 末尾交換。

**f_release(時刻指定の一斉流動化)**:
- fn_dbinit: 崩壊深 D の分布ファイル(全域 matrix。fn_hinit と同形式)
- db_reltime: 発生時刻 (s)。t0 以下なら最初の geomorph calc で発火
- 発火判定は時刻交差(prev_t < trel ≤ t)で1回だけ。restart 後は
  交差済みなので再発火しない(新規保存状態なし)
- D > sd のセルは D=sd にクリップして par_warn(黙らない)

**f_slide(無限長斜面安定による自動発生)**:
- dt_geomorph 周期で陸セル(sd > 0)の安全率を評価:
  Fs = (c′ + (γt・sd − γw・hw)・cos²θ・tanφs) / (γt・sd・sinθ・cosθ)
  - tanθ: 最急降下勾配(D1 と共通の関数)。tanθ ≈ 0 は Fs=∞ 扱い
  - hw = min(hg/sy0, sd)(飽和厚。gw_active 時。無効なら 0)
  - パラメータ: slide_c (Pa), slide_phi (deg), slide_gamma (N/m³。
    飽和単位体積重量として一律適用の近似)
- Fs < 1 → fluidize(i,j,sd)(全層崩壊。部分深さの探索は将来)
- 崩壊後は sd=0(岩盤露出)。堆積で sd が再生すれば再判定は自然に再開
  (進行性崩壊)。判定はセル局所で collective なし
- 近似(文書化): セル独立の無限長斜面(側方支持なし= SHALSTAB 系と
  同水準)、浅層崩壊限定、崩土は即流動化
- 診断: Fs 最小値を dispose で報告(par_warn 形式ではなく par_info)。
  Fs の分布出力(output_matrix)は将来(f_out_fs。残作業)

### 2.6 前提条件の整理(サンプル設定の指針)

- f_gravity_correction = 1 を土石流ケースの標準とする(急勾配の
  静的投影誤差の補正。developer.md 掲載の Ni, Cao & Liu 2019)
- dt_geomorph = 0(毎ステップ)、morfac = 1(par_stop で強制)
- 発生域・流下域は s%sd(fn_sdh / sd0)で与える(sd=0 は不侵食)
- 上流からの水は既存の区間流入・開境界。土砂供給は inflow_cs/qs も
  併用可(f_debris でも csin テーブルは advect_scalar が読む)
