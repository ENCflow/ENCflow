## 1. 結論(要約)

- 添付回答のコードの読みは、おおむね正しい(§2)。
- ただし、天然ダム例題に効く問題がほかにもある。試算で確かめた(§3)。
  1. 崩壊時に放出される水は排水可能分 hg だけで、混合体の濃度が充填濃度を超える。
  2. 動けない崩壊土塊が「堆積 → 飽和 → 再崩壊」を繰り返す。
  3. 湛水下の斜面では、安全率が過小になる。
  4. 全層流動化が連鎖し、乾いたセルでは「崩壊 ⇄ 復元」が往復する。
  5. 乾いた堆積物が湖水と越流水を吸い込み、決壊が遅れる。
  6. 江頭・芦田式は湖底を侵食してしまう。
  7. 決壊溝で 2 セル周期の凹凸が育つ。
- 5 から分かるとおり、添付回答が指摘した「堆積物の初期の含水状態」は、決壊の時刻を左右する
  一次の効果である。
- 例題を作る前に要る追加・改良は、次の 2 つが中心になる(§5)。設定の整理と小改良は §5.3。
  - **A**: 間隙水の授受を一貫させる(1・5 への対応)。
  - **B**: f_slide を改良する(2・3・4 への対応)。
- 7 は別ブランチ(claude/practical-albattani-ybjreg の §89.28)で同じ変更が進んでいる。
  本書の案からは外す(§6)。
- 決壊の形態は越流によるものが最も多い(§4)。例題の主経路は「越流 → 侵食 → 拡幅」にする。
  安全率による堤体の再流動化は副経路であり、B が入るまでは堤体に f_slide を効かせない構成が安全である。

## 3. 追加で見つかった問題(試算で確認)

記号: λ = fluv_porosity(既定 0.4)、C* = 1 − λ、sy0 = 排水可能な有効間隙率(既定 0.2)、
s = fluv_sgrav(既定 1.65)。

### 3.1 崩壊・侵食で放出される水が排水可能分だけ(混合体の濃度が C* を超える)

- **何が起きるか**
  - gwflow を併用すると、崩壊時(`:668-675`)にも侵食時(`:561-568`)にも、放出されるのは
    排水可能分 hg(容量の超過分)だけである。保持水 (λ − sy0)·sd は放出されない。
  - そのため、飽和した土層が崩壊しても混合体の濃度は C = (1 − λ)/((1 − λ) + sy0) になる。
    既定値では 0.75 で、充填濃度 C* = 0.6 を超える。
- **試算 E1**(test/slide 構成 2 の複製にプローブを足したもの)
  - t = 298 s に崩壊したセルの、崩壊直前の hg は 0.0413 m だった(排水可能分の飽和度 0.28)。
  - 崩壊直後は h = 0.041 m、hs = 0.300 m で、**C = 0.879** だった。
- **副作用**: f_dbed=3 の堆積式(式(27))の限界速度は、C > C* で負になる(`:465`)。
  このとき慣性による堆積が働かず、堆積は f_dbstop の閉包だけになる。
- **gwflow なしの経路は正しい**: 崩壊は h += λ·relsat·D、f_dbwet=1 は λ·s_b を授受する。
  保持水を含む台帳になっている。

### 3.2 動けない崩壊土塊が「堆積 → 飽和 → 再崩壊」を繰り返す

- **何が起きるか**(E1)
  1. 崩壊した土塊(C = 0.88)は、クーロン降伏 a_y/g_e = tanφ_db·sC/(1+sC) = 0.41 が
     斜面勾配 0.4 を上回るので動けない。
  2. f_dbstop が 1 更新に 0.05 m ずつ河床へ戻す。
  3. 戻った薄い堆積を、地表水が Green-Ampt の初期正則化で 1 ステップのうちに満たす。
  4. 飽和した堆積は Fs < 1 で再び流動化する(周期 2 s)。
- **影響**: 崩壊したのは 260 セル(test/slide の README)なのに、流動化は 19,324 回だった。
  developer.md §28.4 の「転換回数が多くなる」は、少なくとも一部がこの往復である。
- **原因は判定条件の食い違い**
  - 崩壊の判定は slide_phi = 25° と間隙水圧で行う。
  - 流動の降伏は db_phi = 35° と、混合体の濃度 C で決まる。
- **整合する条件**(独自に整理)
  - 飽和した無限長斜面(hw = sd、c′ = 0)は、tanθ > (γ′/γt)·tanφ_s で崩壊する。
  - γt = ρw·g·(1 + sC*)(飽和単位体積重量)とすると、γ′/γt = sC*/(1+sC*) になる。
  - これは C = C* の混合体の降伏係数と同じ値である。
  - したがって slide_phi = db_phi、slide_gamma = ρw·g·(1 + sC*)、C = C* の 3 つがそろえば、
    「飽和時に Fs < 1」と「混合体が降伏して動き出す」は同じ条件になり、往復は起きない。
  - 既定値は slide_phi 30°・db_phi 35°・slide_gamma 18,000 N/m³ で、そろっていない
    (既定の λ・s での γt は約 19,500 N/m³)。
  - f_dbres=3 の降伏は tanα′ = 0.45 なので、slide_phi ≥ 24.2° であれば
    「崩壊した飽和土塊は動ける」が成り立つ。

### 3.3 湛水下の斜面では安全率が過小(斜面平行浸透の仮定)

- **何が起きるか**
  - 安全率の式(`:634`)は、斜面に平行な浸透を仮定している。駆動力に土塊の全重量 γt·sd を使う。
  - 湖の下では静水圧なので浸透力はなく、駆動力は水中重量 γ′·sd になる。
    c′ = 0 のときの本来の値は Fs = tanφ/tanθ である。
  - 現行の式は、飽和すると Fs を γ′/γt ≈ 0.455 倍に過小評価する。
- **試算 E2**(堤体模型。§8)
  - 湖側の上流面は勾配 0.33(18°)で、水中なら Fs = 1.75 で安定のはずである。
  - 現行の式では、hw/sd が 0.785 を超えると Fs < 1 になる。湖水の浸透でその飽和に達する時刻
    (上流面の下端に近い i = 43 で約 530 s)に崩壊した。出力では、480 s に健在、540 s に崩壊済み
    だった。上の i = 44・45 は、その段差で続けて崩れた(§3.4)。

### 3.4 全層流動化の連鎖と、乾燥セルでの「崩壊 ⇄ 復元」

- **何が起きるか**(E2)
  1. 湖側の斜面が全層崩壊して、岩盤まで z が下がる。
  2. できた段差(tanθ = 1.6〜2.6)で、乾いた隣のセルも Fs = tanφ/tanθ < 1 になり、全層崩壊する。
  3. 乾燥セル(h ≤ dd)の土砂は、次の更新でその場に全量戻る(`:399`)。
  4. 戻った土層は段差のためにまた崩壊する。
  5. この 2 更新周期の往復が、1 セルおきの位相で堤体の下流端まで約 60 s で広がった。
- **影響**
  - E2: 40 分で流動化 143,418 回(640 セル)。
  - 越流ケース E5c(地下水 + f_slide + 安息角崩落): 流動化 742,244 回。安息角崩落の
    移動量は 470 万 m³ で、fluv_dzmax の頭打ちも 316 万回発動した。
  - E5c では、堤体の天端から湖側にかけてが、流動化と再堆積を繰り返す状態になった。60 分の出力では、
    地盤が 1.5〜5.4 m(元は約 15 m)まで下がり、その上に動けない土砂 hs = 4〜8 m が載っていた。
    湖水はこれに堰き止められ、60 分間、下流の測線へ流出しなかった。

### 3.5 乾いた堆積物の吸水で、越流と決壊が遅れる(添付回答の懸念の大きさ)

越流ケース E5(§8)で、地下水なし(E5b)と地下水あり(E5d)を比べた。
地下水ありでは、堤体と谷底の沖積層がどちらも初期に乾いている。層1には初期地下水を与える口がない(§3.8)。

| 量 | E5b(地下水なし) | E5d(地下水あり) |
|---|---|---|
| 越流の開始(下流の測線で Q ≈ 2 m³/s) | 20 分 | 30 分 |
| 60 分時点の天端の掘り込み | 約 7 m | 1〜2.6 m |
| 60 分時点の流量 | 決壊済み(ピーク 190 m³/s、57 分) | 23 m³/s(未決壊) |
| 地中へ入った水(60 分) | — | 約 20,000 m³(流入 72,000 m³ の 28%) |

E5d の遅れの原因は 2 つある。

- 湖水が乾いた湖底と堤体に浸透する。
- 越流水が乾いた下流面に浸透し、侵食力が落ちる。

実際の天然ダムは、堆積直後は間隙が満ちていると考えられる。地下水を併用する現行の構成では、
乾いた堆積物が吸水するので、決壊を遅く見積もる側に偏る。

### 3.6 湖底の偽侵食と、希薄な混合体の降伏(f_dbed=2・f_dbres=1)

試算 E3: 堤体模型の湖に 5 m³/s を流入させ、30 分計算した。

- 侵食堆積式ごとの結果

  | 侵食堆積式 | 結果 |
  |---|---|
  | f_dbed=1(簡易形) | 湖底の上流面(流速 2 mm/s 程度)で −0.02 m |
  | f_dbed=2(江頭・芦田) | 湖底の上流面で −0.04 m。さらに湖に入る河川(勾配 0.02)の河床全体を −0.07〜−0.27 m 侵食した |
  | f_dbed=3(高橋・中川) | 0(流動面の勾配が平らなので侵食しない) |

- f_dbed=2 は河床勾配を使う。そのため湖全体が濃度 1〜2% の混合体になり、クーロン降伏
  (f_dbres=1)が水面を支えて、湖面が 12.71 → 10.82 m と 1.9 m 傾いた。f_dbed=1・3 では
  湖面は 11.49 m で水平だった。湖面の勾配 0.013 は、C ≈ 1.5% の降伏 a_y/g_e ≈ 0.014 とほぼ一致する。
- f_dbed=3 で流入に濃度 2% を与えると、土砂は流入セルに 1.3〜1.5 m 堆積し、湖面は ±0.01 m で
  水平に保たれた(f_dbres=1・3 とも)。

### 3.7 決壊溝の 2 セル周期の凹凸(f_dbed=3 の流動面勾配の中央差分)

- **何が起きるか**

- **層1に初期地下水を与える口がない**: 層2(gw2_sat0)と管路層(gwc_sat0)にはある。
  例題の谷底や斜面の初期の湿りは、予備計算からの再開でしか与えられない
  (BMI による hg の置換は Green-Ampt では受け付けない。developer.md §76)。
  - 別件の記録: その判定の注(`src/m_gwflow.f90:136-140`)は「Green-Ampt は累積浸透を私有に持つ」と

    食い違っている。初期地下水の口を設計するときに、どちらが正しいかを確かめる。
- **側方地下水の安定条件は初期の sd でしか検査しない**(`src/m_gwflow_lateral.f90:368`)。
  堆積で土層が厚くなる(堤体 10〜30 m)と、陽解法の限界 dt は 1/(層厚) で縮む。
  通常の dt では問題にならないが、dt_gwflow を大きくすると黙って不安定になりうる。
- **f_dbres=1・3 は希薄な混合体にも降伏項が残る**(`src/m_swflow_enc.f90:2062`)。
  - f_dbres=3 は、泥流域(C < db_cmin または h/d ≥ 30)ではダイラタント項をマニングに切り替える。
    しかし降伏項 a_y(tanα′ = 0.45)は残る。
  - 高橋・中川 (1991) の泥流域の式(4)が降伏項を含むかは、原典で確認する必要がある。
  - 緩い勾配の河道を下る希薄な決壊洪水では、この降伏が流れを止める側に効きうる
    (C = 1% で a_y/g_e ≈ 0.007)。
- **安息角崩落 f_repose で決壊口は広がる**: E5b で、決壊口の側斜面はほぼ repose_phi = 35° に
  なった。ピーク流量は拡幅なしの 253 から 190 m³/s になった(中央差分の E5a との比較)。
- **流量測線は水の流量 Q だけ**: 固体の流量は記録しない。混合体の流量は後処理で求める。

## 4. 現象の側からの整理

天然ダムの決壊形態は、越流が最も多い(Costa and Schuster 1988 の USGS 要旨)。
後続の文献は Peng and Zhang (2012) を引いて、越流 91%・浸透などの進行性 8%・斜面崩壊 1% と
している(二次引用で、原典は未確認)。形成から決壊までの時間は、63 例のうち 22% が 1 日以内、
半数が 10 日以内という(Schuster and Costa 1986 の USGS 要旨の記述。原典は未確認)。

| 段階 | ENCflow の機構 | 現状 |
|---|---|---|
| 豪雨 → 浸透 → 地下水位上昇 | precip + gwflow(Green-Ampt + 側方流動) | ある。層1の初期地下水の口はない(§3.8) |
| 斜面崩壊 | f_slide(無限長斜面。全層流動化)または f_release(崩壊深・時刻を与える) | ある。放出水は §3.1、往復は §3.2 |
| 流下・堆積 → 河道閉塞 | f_debris + f_dbstop(停止した土砂を z へ固定) | ある。堆積物は乾いた状態で生じる(§3.5) |
| 湛水 | 浅水流 | ある。湖底の侵食は f_dbed=3 なら起きない(§3.6) |
| 堤体の浸透・飽和・排水 | gwflow 側方流動(飽和セルの水頭に湖水深) | ある。堆積直後の間隙水は引き継がない(§3.5) |
| 堤体斜面の崩壊・再流動化 | f_slide | 湛水下と段差で破綻する(§3.3・§3.4) |
| 越流 → 侵食 → 決壊 | f_debris の侵食堆積(f_dbed=3 推奨) | ある。2 セル周期の凹凸(§3.7、別ブランチで対応中) |
| 決壊口の拡幅 | f_repose | ある(§3.8) |
| 下流の決壊洪水 | 浅水流 + 混合体の希釈・堆積。D9999・F9999 | ある。希薄側の降伏(§3.8) |
| パイピング・内部侵食 | なし | 対象外(§5.4) |
| 堆積後の過剰間隙水圧・圧密 | なし | 対象外(§5.4) |

## 5. 設計案(下書き。未合意)

### 5.1 A: 間隙水の授受の一貫化(f_dbwet=2 案。gwflow 併用版)

- **考え方**: 土層厚 sd の柱に次の 2 つの水があるとみなす。
  - **暗黙の保持水** w_r·sd(w_r = λ − sy0)。常に存在し、土と一緒に動く。
  - **明示の排水可能水** hg。
  - Green-Ampt の水分不足量 Δθ = sy0 は、初期含水率 θ_i = θ_s − sy0 を意味する。θ_s = λ とすれば、
    θ_i = λ − sy0 は w_r と一致する(独自の整理)。
  - 授受は土石流の交換に限る。f_dbwet=1 と同じく calc_debris のパス 2 に置き、崩壊(slide_pass2)と
    瞬時流動化(release_debris)の 2 か所にも足す。
- **侵食・流動化**(厚さ D)
  - 新規: h += w_r·D(保持水が土と一緒に出る)。
  - 既存: 容量 sy0·sd を超えた hg を h へ移す。崩壊では hg の全量を移す。
  - 飽和した柱からは λ·D が出て、C = C* になる。
- **堆積**(厚さ D)
  - 要求水量 W = (w_r + sy0·S_d)·D を h から取る(S_d = db_satbed。堆積物の排水可能間隙の
    飽和度で、既定 1)。h が足りなければ、取れる量で止める。
  - 取った水は、まず保持水 w_r·D に充てる。残りは容量の範囲で hg に入れる。容量を超える分は
    取らない(h に残す)。
  - 保持水に足りない分は hg から取る(毛管吸水の扱い)。それでも足りない分は台帳の不足として
    数え、dispose で報告する(黙らない)。
- **台帳**: 土石流の交換について、Σh + Σhg + w_r·Σsd(+ 不足)が保存される。
  閉領域の検定は、Check_debris.py の wet モードと同じ形で組める。
- **検査**(init。判定は全ランク同一)
  - 容量が sd に基づく鉛直モデルを要求する(Green-Ampt。バケツの容量 gw_capacity は sd と
    無関係なので停止)。
  - sy0 ≤ λ を要求する(排水可能間隙率が全間隙率を超えるのは不合理)。
  - gwflow なしで f_dbwet=2 を指定したら停止し、1 を案内する。
- **無効時**: f_dbwet ≠ 2 なら分岐に入らず、既存の reference とビット一致する。
- **「停止した瞬間に排水されるか」への答え**: A では、堆積物は間隙が満ちた状態で生じる。
  その後は既存の側方流動で徐々に排水される(ダルシー則。時間は K_sh・sy0・形状で決まる)。
  f_gwlateral なしでは排水されない。圧密による絞り出しは表さない(§5.4)。
- **比べた案**

  | 案 | 内容 | 判断 |
  |---|---|---|
  | A1 | 排水可能分だけを堆積時に hg へ移す | 最小の変更だが、§3.1 の C > C* が残り、侵食時の増水も弱いまま。不採用 |
  | A2(上記) | 暗黙の保持水 + 明示の hg | 推奨 |
  | A3 | 堆積物の間隙水・過剰間隙水圧を状態量として持つ(圧密) | §0 の鉛直抽象化を超える。今回は有効化しない |

### 5.2 B: f_slide の改良(どれも既定はオフ。項目ごとに別コミット)

- **B1 浸透力を水頭勾配で入れる安全率**(例: slide_seep = 1)
  - Fs = [c′ + (γt·sd − γw·hw)·cos²θ·tanφ_s] / [cos²θ·{(γt·sd − γw·hw)·tanθ + γw·hw·J}]
  - J は、最急降下の近傍 k への全水頭の水平勾配 (H_c − H_k)/Δ_k である。
    水頭は H = (z − sd) + hw(+ 飽和セルなら h)で、側方流動と同じ定義を使う。
  - 土層厚と飽和厚が一様なら J = tanθ になり、現行の式に一致する。
  - 湖の下では J = 0 になり、Fs = tanφ/tanθ(c′ = 0)になる。
  - 堤体の下流端の湧出部では J > tanθ になりうる(浸透による小崩壊が表れる)。
  - 分母が 0 以下なら、駆動なしとして判定から外す。
  - 近傍の hg・h を読むので、calc_debris の冒頭で両者のハロを交換する(有効時だけ。判定は全ランク同一)。
  - 導出は、標準的な無限長斜面の有効応力と浸透力の釣り合いを、独自に整理したもの。
- **B2 間隙水圧で起きる崩壊に限る**: hw = 0 でも Fs < 1 になるセル(段差・切土など幾何的に
  不安定な所)は流動化しない。そうした所は f_repose(安息角崩落)に任せる。§3.4 の連鎖と往復を断つ。
- **B3 流動中の土砂が載るセルは判定しない**: 河床と流れの交換は侵食堆積式の担当とする。
  §3.2 の往復の残りを断つ。
- **B4 部分深さ**(例: slide_dmax): 上から d = min(sd, slide_dmax) だけを判定し、流動化する。
  飽和厚は hw_d = max(0, hw − (sd − d)) とする。深い堆積物の全層崩壊を避ける。
  handoff.md 1j の「斜面崩壊の部分深さ化」に当たる。
- **採らない案**: 崩壊の発生域をマスクで限る案(fn_slide 等)は、シナリオの制御としては簡単である。
  しかし物理を直さないので、B1〜B3 で足りなければ考える。
- **整合する設定の案内**(§3.2): slide_phi と db_phi(f_dbres=3 なら tanα′)の関係と、
  slide_gamma = ρw·g·(1 + sC*) を利用者ガイドに書く。

### 5.3 設定・小改良

- 侵食堆積式と抵抗則は f_dbed=3 + f_dbres=3 とする。理由は、流動面の勾配を使い、深い水域
  (h/d ≥ 30)でマニングに切り替わるため。§89.28(別ブランチ)が取り込まれてから使う。
- 決壊口の拡幅は f_repose(repose_phi 35° 前後)で表す。
- 地下水は Green-Ampt + 側方流動とする(バケツは A と組めない)。
- 層1の初期地下水: gw_sat0(一様。gw2_sat0 と同形)または fn_hginit(分布)を足す。
  予備計算からの再開で代える案もある。
- 側方地下水の安定条件を、sd が初期の上界を超えたら検査し直す(超過なら停止)。
- f_dbres=1・3 の希薄側の降伏: C < db_cmin で降伏項を外す選択肢を持たせるかを検討する。
  f_dbres=3 は、先に原典の照合をする。
- 流量測線に固体の流量を加えるのは任意(決壊洪水の混合体流量の確認用)。

### 5.4 有効化しないもの(§0)

- **堆積後の過剰間隙水圧と圧密**: 土石流の堆積物は高い間隙水圧を保ち、ゆっくり消散するとの報告が
  ある(添付回答の引用。本書では未確認)。状態量を増やす A3 に当たるので見送る。
- **パイピング・内部侵食**: 3 次元の内部流れであり、平面 2 次元の範囲外。限界として明記する。
- **深い回転すべり**: f_release で崩壊深と時刻を与えるシナリオで代える。
- **高橋・中川 (1991) の不飽和床の侵食式(式(10))**: 将来の拡張。hg/(sy0·sd) との結合が自然で、
  A の後に検討する。

## 9. 例題の構成(下書き)

- **地形**: 斜面崩壊の起きやすい側斜面(0 次谷の凹地)をもつ谷。上流から川が流入する。
  0.5〜1 km² を Δx = 5〜10 m で。
- **経過**
  1. 豪雨で地下水位が上がり、側斜面が崩壊する(f_slide + B。比較用に f_release のシナリオ)。
  2. 流下・堆積して河道を閉塞する。
  3. 湛水する(数時間)。
  4. 越流 → 頭部侵食 → 決壊と拡幅(f_repose)。
  5. 下流へ決壊洪水が流れる。
- **ケース**
  - 基本(A あり)。
  - A なし(現行)。堆積物の含水が湛水と決壊の時刻に効くことを見せる(添付回答への答え)。
  - 地下水なし(乾いた上限)。
  - B を入れた後に、堤体の f_slide のありとなし。
- **出力**
  - プローブ: 湖の水位、天端の z、堤体の hg。
  - 流量測線: 決壊洪水の Q。
  - 統計と分布: D9999・F9999・Fs9999、Z と Hs のフレーム。
- **検定**
  - 固体の台帳、A の水台帳。
  - 湛水の時間を湖の容量と流量の比 V/Q と比べる。
  - 決壊の諸元を経験式(Peng and Zhang 2012 など。原典の確認後)と比べ、桁を確かめる。
- **計算時間の目安**: E5 の規模(1,600 セル・1 時間)は単一スレッドで約 1.7 分。
  例題の規模(数万セル・6〜12 時間)は OpenMP で数十分の見込み。
