# 規定底面運動 fn_bedmotion 設計案(断層津波の発生機構)(bedmotion_plan.md)

**状態(2026-10-06): 段階 1(本体 fn_bedmotion)・段階 2(前処理
utils/fault2disp、例題 examples/tsunami_fault)とも実装・検証済み。その後の
拡張 = 窓付き(矩形限定)入力、経緯度入力(横メルカトル)、地理参照の自動
取得(bil hdr / GeoTIFF)、平面直角座標系の並び f_jpr も済み。要合意事項 §11 は
推奨案どおり決定。規約の正本は developer.md §70、利用者向けは
users_guide/bedmotion.md と utils/fault2disp/README.md。** 本書は設計解説と
実績の記録として残す(lava_plan.md と同じ運用)。残項目は §12。

## 0. 結論(要約)

- 目的: 断層パラメータから求めた海底(地盤)変位の**時刻歴**で s%z を
  強制し、津波の発生から伝播・遡上までを単一ランで再現する。
  GeoClaw の dtopo、COMCOT の時間依存変形入力と同じ考え方。
- 機構は Phase 8(nonhydrostatic_plan.md §16、developer.md §69.10)で
  実装・検証した「外部から z を動かす → h を変えずに水面 e = z + h が
  持ち上がる(geomorph と同じ契約)」そのもの。test/nhbottom の uplift
  ドライバはライブラリ API(m_main_set_value('z'))で同じことをしており、
  線形理論に ±0.7% で一致している。本案はこれを **fn_* の本体機能**にする。
- 入力は「時刻, 変位ファイル」のスナップショット表(不等間隔可)で、
  ステップごとに線形補間した**変位の増分**を z に加える。断層パラメータ
  (Okada)から変位場を作るのは**前処理ユーティリティ**(utils/)の仕事
  (§0-12: 計算で使う物理量は直接与える、変換は前処理で)。
- 無効時はゼロ追加。有効時は帯形状の変位場 2 枚だけ。通信は z のハロ
  交換(既存)のみ。restart は私有状態なし(スナップショット表から
  復元時刻の変位を再評価する)。
- 非静水圧の加速度項 f_nh_bottom はそのまま効く(z の変化を見るだけ)。
  海溝型地震の波長(数十 km ≫ 水深)では F ≈ 1 で静水圧の持ち上げだけで
  足り、震源幅が水深と同程度のとき(分岐断層・深海の狭い滑り)に効く。

## 1. 位置づけと方針適合

- **ラスタ純化(§0-1)**: 入力は z と同じラスタ(変位場)。断層の幾何
  (ベクトル)は本体に持ち込まない。
- **投影座標系スケール(§0-2)**: 変位場は格子と同じ座標・同じ格子で与える。
  経緯度 → 投影の変換は前処理側。
- **複数プロセスの同時概算(§0-4)**: 地震 → 津波 → 遡上 → 氾濫・被害
  (bldgdebris・driftwood)が同じランで連なる。地震で誘発される海底地滑り
  (f_bedslide)との同居は §4 の**増分適用**で可能にする。
- **有効化は fn_*(§0-7)、無効時ゼロ追加(§0-8)**: fn_bedmotion の有無。
- **物理量を直接与える(§0-12)**: 本体は変位 d(x, y, t) [m] を読むだけ。
  断層パラメータ → 変位(Okada 1985、Tanioka & Satake 1996 の水平成分
  寄与)は utils/ の前処理(§6)。
- **単純な入出力(§0-11)**: スナップショット表はテキスト 1 行 1 スナップ、
  変位ファイルは z と同じ形式(テキスト行列 / bil / GeoTIFF。
  fileio_read_matrix)。
- 既存の近縁機構との関係:
  - ライブラリ API の extz(developer.md §57。絶対値の一回適用、geomorph
    等が有効なら拒否)。本案は本体内の時刻歴強制で、API と同じ適用契約を
    共有するが増分適用(§4)の点が違う。fn_bedmotion 有効時は API の
    set_value('z') を拒否する(生産者は変数ごとに一人。'pre' と同じ)。
  - handoff 1n の「分布隆起 fn_uplift(長期地形変動 §32)」は kyr 規模の
    隆起速度の話で、本案(秒〜分の事象)とは時間尺度が違う。将来 §32 で
    必要になれば同じ適用契約(§4)を速度場の積分として流用できる。

## 2. スコープ

- **対象内**: 任意の時刻歴の地盤変位(鉛直)。複数セグメントの時間差破壊・
  立ち上がり時間は前処理で合成してスナップショットに反映。陸上の変位も
  同じ場で与える(陸の隆起・沈降 → 遡上域の地盤高の変化として自然に
  効く)。f_nh_bottom との併用。f_bedslide 等の z 更新プロセスとの同居。
- **対象外(有効化しない)**:
  - 本体での Okada 計算・断層幾何の保持(前処理)。
  - 水平変位の直接扱い(急斜面での寄与 u_h·∇z は前処理で鉛直等価変位に
    換算して含める: Tanioka & Satake 1996)。
  - 海域マスク(sw > 0)のセルの変位(geomorph・API と同じ契約。潮位表現
    s%z と共存させるため)。津波計算は「解く海」(f_htype=2 で水域を
    初期水位で表す)の型で行う(examples/landslide_tsunami と同じ)。
  - 動的な地震動(加速度)による水面の励起、音響・圧縮性(津波モデルの
    通例どおり対象外)。
  - 変位に伴う土層 sd の変化(岩盤ごと動くので z − sd は不変 = sd も同じ
    増分で動く、ではなく**sd は変えない**: 岩盤面 z − sd が変位する。
    §11 D3)。

  初期水面変位方式と同じ(§8 の等価性検定)。

## 4. 定式と適用の契約

- 本体が持つ量: 変位場 d(t)(時間補間値)と、前ステップに適用した d_prev。
  ステップ頭(extz と同じ位置 = swflow の前)で

      Δd_i = d_i(t^{n+1}) − d_prev,i,   z_i ← z_i + Δd_i,   d_prev,i ← d_i(t^{n+1})

  を陸セル(x > 0, sw = 0)に適用し、h は変えず e = z + h を回復、z のハロを
  交換する(m_main の extz 適用と同じ契約。コードも共有する)。
- **増分適用の理由**(絶対値の置換でなく): (a) geomorph・lavaflow・
  bedslide が同じランで z を動かしていても衝突しない(各プロセスが自分の
  増分を足す)。(b) 変位の全体像を本体が「地形」と区別して持つ必要が
  ない。(c) restart で私有状態が要らない(§5)。
- 時刻の取り方: ステップ n(t^n → t^{n+1})の頭で t^{n+1} の変位を与える
  (test/nhbottom の uplift ドライバと同じ。理論比較で検証済み)。
- 水面: h を変えないので η が Δd だけ持ち上がる = 静水圧の底面持ち上げ
  (Kajiura フィルタなし)。短波長成分の減衰は f_nh_bottom が担う
  (nonhydrostatic_plan.md §16.1)。
- 運動量 u, v, m, n は触らない(§57 の契約と同じ)。
- 土層: z − sd(岩盤面)が変位する = sd は不変(§11 D3)。
- 乾いたセルも同じ増分で動く(陸の隆起・沈降)。

## 5. 離散化・時間補間・並列規約・restart

- **読み込み**: init で表を読み、全スナップショットの時刻と単位番号を
  保持(prtype=3 と同じ「全てオープン」方式)。各ランクが**冗長に全域を
  読んで自帯 jsh..jeh を切り出す**(m_precip の分布リストと同じ。
  developer.md §11。scatter は使わない = collective の判定を増やさない)。
  帯形状の配列は d_a(t_a)、d_b(t_b) の 2 枚 + d_prev の 3 枚。
- **スナップショットの進行**: 時刻 t^{n+1} が t_b を越えたら次を読む
  (判定は時刻だけに依存 → 全ランク同一。読み込みは各ランク独立で
  collective なし)。
- **補間**: 線形 d = d_a + (d_b − d_a)(t − t_a)/(t_b − t_a)。階段は d = d_a。
  補間の時間刻みが dt より粗いとき(通常。表 10 s、dt 0.05 s)は増分が
  一定 = 底面速度一定 → NH の加速度項はスナップショット境界でだけ
  z̈ のパルス(積分値 = 速度の跳び)を受ける。これは §16.5 の既知の性質で、
  滑らかな時刻歴が要るときは前処理でスナップショットを細かく出す
  (nhbottom の検証は毎ステップ更新で行っている)。
- **restart**: 私有状態を save しない。復元時刻 t_r で d_prev = d(t_r) と
  初期化する(save の z は t_r までの変位を含んでいる)。中断なしランと
  同じ増分列になる(補間が時刻だけの関数なので)。
- **OpenMP**: セル局所のループ。
- **無効時**: 配列未確保、ステップの呼び出しは logical 1 つの分岐。

## 6. 前処理ユーティリティ utils/fault2disp(段階 2。実装済み)

設計時の案と実装の差を含めて記す(詳細は utils/fault2disp/README.md)。

- 入力: 格子情報(nx, ny, dx, dy、左下隅の外縁座標 x_ll, y_ll)と断層
  セグメント表(≤ 50。各セグメントの上端中心の位置、上端深さ、走向、傾斜、
  すべり角、長さ、幅、すべり量、破壊開始時刻、立ち上がり時間、立ち上がり
  関数 線形/半正弦)。
- 位置の与え方は 3 通り: (a) 格子と同じ投影座標(x_ll, y_ll を原点にすれば
  絶対座標)、(b) 経緯度(f_lonlat=1。横メルカトル = Gauss–Krüger、Krüger 級数
  n⁶。UTM・平面直角座標系を原点・k0・偽距で表す。走向は子午線収差で格子北
  基準に補正)、(c) 平面直角座標系の並び f_jpr=1(X 北距, Y 東距)。
- 地理参照の自動取得(f_georef=1 既定): fn_z が bil+hdr / GeoTIFF なら
  本体と同じ m_georef / m_geotiff で nx, ny, dx, dy, x_ll, y_ll を取る。
  このため**libencflow.a をリンクする型**(utils/rerecord と同じ)に変えた
  (設計時の「本体非依存の独立ユーティリティ」から変更。読み方の解釈を本体と
  揃えるため)。
- 計算: Okada (1985) 式 (25)〜(30)(Poisson 比 1/4、Chinnery の記法)。
  オプションで Tanioka & Satake (1996) の u_h·∇z。セグメントごとの時間
  関数を重ね、出力時刻列でスナップショットと表を書く。f_window=1 で
  |u_z| > d_min の外接矩形だけを書く(§9)。
- 検証: `fault2disp -check` が Okada (1985) Table 2 の case 2(走向すべり・
  傾斜すべり)を 4 桁で再現し、横メルカトルを UTM 54 帯・平面直角 IX 系の点で
  Snyder (1987) の級数と 1 mm で照合する。実装時の実バグ: Okada の y 軸は
  up-dip 方向(傾斜方向に取り違えて隆起が 2W cosδ ずれた。逆断層の隆起が
  断層の投影上に来ることで検出)。

## 9. 既知の割り切り

- 変位は鉛直のみ(水平は前処理で等価換算)。
- 海域マスクのセルは動かない(§2)。
- 時間補間は線形(または階段)。滑らかさは前処理のスナップショット密度で
  決める。
- 変位場は全域ラスタ 1 枚/スナップショットが既定。広域の計算では表の
  行末に窓 `i1 j1 ni nj` を付けて変位がゼロでない矩形だけを持たせる
  (2026-10-06 実装。fault2disp の f_window。developer.md §70)。

## 12. 残項目と実装で分かったこと

- **残**: §8-4(スナップショットの粗さと f_nh_bottom の z̈ パルスの定量)、
  §8-3 の直接比較。横メルカトル以外の投影(ランベルト等)は利用者側で
  変換。各ランクが全域 (nx, ny) の作業配列で読む(m_precip と同じ)ため、
  超広域ではその一時メモリが要る(窓付き入力なら窓の大きさで済む)。
- **実装で見つけた実バグ(修正済み)**: 表の list-directed 読みでファイル名の
  '/' が入力終端になる(語の切り出しに変更)、init で復元時刻に s%it を使い
  restore 後に変位を二重適用(init 時点で有効なのは s%it0)、fault2disp の
  Okada の y 軸(up-dip)の取り違え。
- **方針との関係**: fault2disp は当初「本体非依存」としたが、地理参照の解釈を
  本体と揃えるために libencflow.a をリンクする型にした(§0-9 の範囲内:
  Fortran のみ・外部ライブラリなし)。
