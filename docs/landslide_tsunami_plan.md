## 0. 結論(要約)

- **二層 SWE は採らない**(§0-5 の上限を超え、双曲性喪失の難点もあり、
  developer.md §47 で既に不採用)。代わりに、地滑り土塊を
  **「s%z の内数として動く底層 hb」**で表現する(m_saltwater の
  「hss は h の内数」と同じ簿記)。
- 底層は **慣性なし・摩擦支配の 1 方程式流**(Voellmy 型を第一候補、
  Bingham 型を海底の粘性的すべり向けに追加可)。駆動水頭は
  **Φ = z + r·h(r = ρw/ρs)**。離散化は **8 近傍**(速度はセル勾配の
  大きさから、配分は ENC 本体と同じ l8/w8dr 幾何。§4.3)。乾いた斜面では Φ = z(通常の重力流)、
  水面が平らな水中では ∇Φ = (1−r)∇z(浮力による駆動の減少)が
  一つの式で出る(§4.1)。
- **津波の発生は既存の契約から自動で出る**: geomorph は h を保存して
  z を変え、末尾で e = z + h を回復する。底層が動いて z が上下すれば
  水面がそのまま上下する = 「移動海底」方式の津波源(Tinti・Harbitz 系、
  GeoClaw+地滑り源・COMCOT と同水準)。**swflow は無変更**。
- 段階0(§2)で確認した現行の一層モデルの限界 —「突入した土塊が水中を
  走らず汀線直後に積み上がる」「海底地滑りは水面が平らだと駆動ゼロで
  動けない」— を、hb 層が解消する。
- 置き場所は **m_geomorph の加算プロセス f_bedslide(submodule
  m_geomorph_bedslide)**。z/sd 台帳・発火機構(fn_dbinit 型の与件)・
  2 パス構造・ハロ規約を共有できるため。
- 段階2は、混合体モデル(hs)で陸上を流下した土石流が滞水域に突入した
  セルで **hs → hb へ引き渡す(プランジ)**。土石流(水を多く含む)は
  陸上 = 混合体、水中 = 底層。岩屑なだれ(乾いた大規模崩壊)は陸上から
  水中まで底層一本で扱う。

## 1. 位置づけと方針適合(なぜこの形か)

現行の地表流は力学的に一層で、土石流は「水 h + 土砂柱状量 hs」の
単層混合体(developer.md §28)。駆動は水面 z+h+hs の勾配で固液同速。
この枠で (A)(B) を考えると:

- (A) 突入までは既存機構で出る。突入セルでは柱高 h+hs が増えて水面が
  盛り上がり、体積排除の波が放射される(段階0で確認。§2)。しかし
  突入後、水面が平らになった時点で駆動が消え、土塊はその場に留まる。
  実際の津波はこの**水中ランアウト区間でも生成される**。
- (B) 一層では構造的に不可能。水面下で sd → hs に転換しても駆動が
  ゼロ(f_release/f_slide を水中で使っても土塊は動かない)。

したがって「水面下でも動く別の担い手」が要る。候補と判断:

| 案 | 内容 | 判断 |
|---|---|---|
| 二層 SWE | 水層・土塊層とも運動方程式 | 不採用。§0-5 の上限超過・双曲性喪失(§47 の決定を踏襲) |
| 混合体の駆動水頭改造 | 単層のまま密度加重の水頭 | 不可。h と hs は同一速度場を共有し水の駆動は ∇η でなければならない |
| **動く底層(1 方程式)** | 土塊を z の内数の層 hb とし摩擦支配流で動かす | **採用**。§0-5 の内側。swflow 無変更で津波源になる |
| 外部与件の海底変位 z(t) | 外部モデルの地滑りを読み込む | 見送り(hb の発火与件が内包。外部連携の要望が出たら別途) |

方針との対応: 水平は 1 方程式(§0-5)、有効化はフラグで無効時ゼロ
コスト(§0-7, 8)、ρs・μ・ξ は直接入力(§0-12)、統一表現(§0 目的1:
崩壊→流下→突入→造波→伝播→遡上が一つの格子・一つの時間発展)。
複雑化の抑制(§0-6): 新規状態は hb 1 面、swflow・boundary・tide は
無変更、既存の離散化(creep/lavaflow/glacier の保存形 2 ループ+
ドナー律速+適応サブサイクル)を流用する。

## 2. 段階0の観察(work/slide_tsunami。2026-09-30)

既存機能のみ(f_debris + 等価流体 Voellmy f_dbres=4 + f_release、
解く湖 = sw なし・初期水位 e0・辺は長波放射 e_bc=2)で、斜面
(tanθ=0.4)上の崩壊土塊 19,110 m³ を水深 40 m の湖に突入させた。

- **結合経路は成立**: 汀線到達 ~14 s、先頭波 +2.0 m(x=260 m)→
  +1.0 m(350 m)→ +0.6 m(対岸側 548 m)。伝播速度 20 m/s = √(g·40)。
  放射境界からの流出水量(1.1 万 m³)≒ 湖に入った固体+間隙水。
  固体台帳は 0.02 m³ まで閉合。dt=0.02 と側方テーパなしの変種で
  波高は 5〜10% 以内で一致。
- **水中ランアウトがない**: 湖内堆積 7,106 m³ はすべて汀線から 50 m
  以内(水深 5 m 以下)に積み上がり(湖底隆起 最大 4.75 m)、水中の
  斜面を全く下らない。→ 段階1の対象そのもの。
- **崩壊面の与え方**: 箱型(D 一定)は下流リムが高い「穴」に土塊が残る。
  水平ベンチは 10 m 超の側壁の薄膜(h~1 cm)で発散。**斜面下端で地表に
  抜ける平面すべり面+側方テーパ**で安定。hb の発火与件も同じ型で
  設計する(fn_bsinit の作り方として利用者ガイドに明記)。
- 放射境界と汀線が交わる角セルで一時的な速度スパイク(h≈0、2 セル、
  結果に影響なし)。段階1で湖岸が辺境界に接する配置を使うなら要観察。
- 出力 E は z+h。混合体セルの自由表面は E+Hs(検証・図化で足す)。

## 4. 定式

### 4.1 状態と簿記

- **s%hb**: 動いている底層の厚さ(m。かさ体積 = 間隙込み。幾何面積基底)。
  **s%z と s%sd の内数**で、常に土層の最上部にある。
  - z = 底面標高(hb を含む。水はこれを底として流れる)
  - sd = 土層厚(hb を含む。z − sd = 岩盤面は底層の移動で変わらない)
  - hb が Δ だけセル間を動けば、送り手の z・sd が Δ 減り、受け手の
    z・sd が Δ 増える(**共動更新**。fluvial の Exner と同じ規約)
- **発火(release)**: fn_bsinit(崩壊深分布 D)を bs_reltime に
  hb = min(D, sd) として「可動化」する。**z・sd・h・e は変えない**
  (土塊は既に z の中にある)。水面下の発火で人工的な水面変位が
  出ないのはこの簿記の利点。発火判定は release_debris と同じ時刻交差
  方式(新規保存状態なし・リスタート後に再発火しない)。
- **停止**: セルの底層速度(§4.3)が bs_vstop 未満の状態が bs_tstop 秒
  続いたとき hb → 0(2026-09-30 追加。既定 0 = 即時。突入時に汀線帯が
  離水して底層が失速する過渡で誤固定しないため。連続 tick 数は私有 save に
  hb と並べて保存し往復ビット一致)。以下、bs_vstop 未満のとき hb → 0
  (質量は既に z・sd にあるので消すだけ)。再流動なし(不可逆。
  lavaflow の固化と同じ閉じ方)。全量即時停止でよい(lavaflow の
  レート lv_wsol は Bingham の漸近停止に必要だった機構で、Voellmy は
  降伏で速度が厳密に 0 になるため不要。Bingham 型を追加するときは
  レート付きにする)。
- **水との関係**: 水柱 h は底層の移動で**不変**(geomorph の契約)。
  z が上がれば e = z + h が上がる = 水面の持ち上げ(移動海底)。
  スカーで z が下がれば水面が下がる(引き波)。**水柱が持ち上げられて
  水面より上に出る**(堆積が水面上に露出)場合も h は保存され、次の
  swflow ステップで自然に流れ落ちる。
- **リスタート**: hb はモデル私有ファイル geomorph_bedslide.dat
  (RLE 1 面。契約5。restore 時に自ファイルが無ければ par_stop)。
  save_version は不変。

### 4.2 駆動水頭(浮力込み。導出)

底層の上面 ζ = z(hb は z の内数)、その上の水深 h、水面 η = z + h。
底層内の標高 ξ での圧力は p = ρw g h + ρs g (ζ − ξ)。水平勾配は
∇p = ρw g ∇h + ρs g ∇ζ。底層の単位質量あたりの駆動加速度は

```
a = −(1/ρs)∇p = −g ∇(z + r h),   r = ρw/ρs          … Φ ≡ z + r h
```

- 乾燥(h=0): Φ = z(通常の重力流)
- 水面が平ら(η 一定、h = η − z): ∇Φ = (1 − r)∇z(浮力で駆動が
  (1−r) 倍。r≈0.5 なら半分)
- 汀線(h が急変)でも Φ は連続で、突入時に「水面の盛り上がり」が
  底層を押し戻す向きに働く(∇h の項)= 水から土塊への反力の一次近似

これは m_saltwater の Φs = η + εζ と同じ構造(規格化が異なるだけ)。

### 4.3 フラックス則(慣性なし・摩擦支配)

**Voellmy 型(第一候補。f_bsres=1)**: 既存の f_dbres=4 と同じ形の
力の釣り合いから、慣性を落として底層速度 V を決める。

```
S  = |∇Φ|(エッジ方向の水頭勾配)
b  = 1 − r·w(有効応力の浮力係数。w は浸水率 §4.5)
S > μ b :  V = √( ξ hb (S − μ b) )        (μ: 摩擦係数、ξ: 乱流係数 m/s²)
S ≤ μ b :  V = 0                           (降伏 = 停止)
q  = hb_donor · V(単位幅フラックス。風上 = 送り手の hb)
```

- f_dbres=4 の定常等流解 h_t = (q²/(ξ(tanθ−μ)))^{1/3} と同一の
  関係(ge が両辺で相殺する tan 形。developer.md §28.8 の検定と整合)。
- **正則化**: S − μb が微小な領域では V を線形化する
  (V = √(ξ hb ε_S)·(S−μb)/ε_S、ε_S = bs_eps_s)。フラックスの S 微分が
  降伏近傍で発散するため(§4.6 の安定条件に必要)。saltwater の
  eps_h と同じ流儀。
- **8 近傍(2026-09-30 の議論で 4 近傍案から変更)**。実地形の走路は
  斜めであり、4 近傍では斜め走路で段々の経路になり土塊が捕まる
  (§52 の chichibu 実演と同じ)。ランアウトと堆積形(= 津波源の形)が
  格子方向に依存するのはハザード概算として許容しがたい。
- **速度と配分の分離**(素朴な 8 方向配分の欠点を避ける鍵):
  §28.8 の volcano 検定では、エッジごとの勾配 S_k で Voellmy を評価
  すると斜めエッジの勾配低下(1/√2)が降伏項 (S−μb) に非線形に効き、
  実効通水能が 24% 落ちた。そこで
  1. **速度 V はセルの勾配の大きさから一度だけ決める**: S_c = Φ の
     8 近傍最急降下勾配(debris の slope8 と同じ評価。ハロ ±1 で完結)。
     降伏判定(S_c ≤ μb で V=0)もここで行う。
  2. **エッジへの配分は ENC 本体の幾何**(通過幅 l8・距離 w8dr・
     bs_diagratio。gwflow_lateral_geom と同じ定義)で、ΔΦ_k > 0 の
     下り方向にだけ q_k = hb·V·(ΔΦ_k/w8dr(k))·l8(k) / S_c と振り分ける。
     総流出は Σ_k q_k = hb·V·ws/S_c(ws = Σ_下り (ΔΦ_k/dist_k)·l8(k))で、
     一様勾配では格子沿いで hb·V·dy、45° で hb·V·dx。どちらも質量流束
     ベクトル hb·V·û を与える(ENC の射影速度×通過幅と同じ)。
     **投影幅 W_c = |ex|dy+|ey|dx を掛ける形は誤り**(斜めの 1 ホップは
     √2 倍の距離を運ぶため 45° で √2 倍の過大輸送。2026-09-30 の
     45° 検出器で実検出・修正)。
  3. bs_diagratio = 0 で 4 近傍に退化(解析解比較用。volcano の
     p_diagratio=0 と同じ運用)。
- 反対称性: エッジ流量は ΔΦ_k の符号で送り手が一意に決まるので、
  書き手一意の 2 ループ構造(k=1..4 が所有成分、5..8 は近傍の所有)が
  そのまま使える。

**Bingham 型(将来枠。f_bsres=2)**: lavaflow の潤滑流フラックス
q = (ρs g b S/6η)(hb−h0)²(2hb+h0)、h0 = τ_y/(ρs g b S) をそのまま
使う(粘性的な海底地滑り: Jiang & LeBlond 1993 / BING 系の水準)。
停止は lavaflow と同じ速度閾値+レート。段階1では実装せず予約
(par_stop)。

### 4.4 慣性を落とす近似の意味と限界

- 土塊は発火の瞬間から終端速度(Voellmy の平衡速度)で動く。
  実際の加速期間は v/a ~ 20〜30 m/s ÷ (g(sinθ − μcosθ) ~ 2 m/s²)
  = 10〜20 s。数十秒〜数分の事象では無視できないが、支配的でもない。
  津波の発生効率は土塊のフルード数(V/√(gh))に敏感なので、
  **初期の速度過大 → 近地波の過大**の傾向が出る。概算(§0-4)の範囲
  として利用者ガイドに明記する。
- 急停止(降伏で V→0)も慣性なしの帰結。走行距離は μ・ξ の校正に
  吸収される(RAMMS 等の実務と同じ運用)。
- 起動時間を与える緩和(V を時間定数で追随させる)は「運動方程式を
  持ち込まない」線を守れば可能だが、段階1では入れない(§0-6。
  必要が実証されてから)。
- **偏りの向きは事例で逆になる(2026-09-30 追記。外部レビューの指摘)**:
  上記「終端速度に即達 → 近地波が過大」は水中で発火する海底地滑りに
  当てはまる。**陸上から高速で突入する事例**(眉山 1792 型)では逆で、
  混合体から底層への引き渡し(§4.7)や陸上から続く底層は、その場で
  水中の浮力で減った終端速度に落ちるため、造波が最も強い突入直後の
  フルード数を**過小評価**する。対処として f_bsvplunge=1(混合体の
  速度が底層の終端速度以下に落ちてから引き渡す = 高速のうちは慣性の
  ある混合体として水柱に運動量を渡す)を用意し、引き渡し時の
  混合体速度と底層速度の体積重み平均を dispose で報告する(偏りの
  大きさの診断)。陸上から続く底層(fn_bsinit)の突入では即時に落ちる
  ままなので、高速突入の事例は「陸上 = 混合体、水中 = 底層」の
  引き渡し経路を使うのが推奨。

### 4.5 浸水率 w(有効応力の浮力係数 b = 1 − r·w)

底面摩擦は有効応力(全応力 − 間隙水圧)で決まる。土塊が水没して
飽和し間隙水圧が水面から静水圧なら、有効法線応力は (ρs − ρw) g hb
→ b = 1 − r。乾いていれば b = 1。問題は「薄い水膜が乗っただけの
厚い土塊」で、水膜が瞬時に土塊全体を飽和させるとは言えない。

案:
- (a) w = 1 if h > dd else 0(単純。汀線で摩擦が不連続に半減し、
  突入直後に加速する副作用)
- **(b) w = min(1, h / hb)(推奨)**: 水深が土塊厚に達するまで線形に
  浮力を効かせる。パラメータなし・連続・「薄膜は厚い土塊を飽和
  させない」という物理の読みを持つ。hb→0 の裾では w→1(薄い裾は
  すぐ飽和)で妥当。
- 駆動水頭 Φ = z + r h は間隙水圧に依らず厳密なので w を掛けない
  (上載水の圧力勾配は土塊に必ず作用する)。

### 4.6 離散化・安定条件・並列規約

- **保存形 2 ループ+エッジ反対称フラックス+ドナー律速**(8 近傍・
  所有エッジ 4 成分の gwflow_lateral / saltwater 型)。パス 0: セルの
  S_c と V_c(§4.3 の 1)を作業配列に評価(帯+1 行。近傍 Φ を読む)。
  パス A: V_max と等価拡散係数 D_max の評価 → allreduce_max(2 成分)
  → dt_sub 決定(全ランク同一)。パス B: エッジフラックス(送り手の
  V_c と配分重み。帯界面は je+1 行の書き手が冗長計算)。パス C: 発散を
  取り hb・z・sd を共動更新(自帯のみ)→ hb と z のハロ交換。
  エッジ計算は 4 近傍の 2 倍だがハロ幅は ±1 のまま。
- **安定条件**: 移流的 CFL(dt ≤ cfl·dx/V_max)と、降伏近傍の
  線形化枝の拡散的条件(dt ≤ cfl·0.5/(D_max·(1/dx²+1/dy²))、
  D = hb·√(ξ hb/ε_S) 相当)の小さい方。glacier/saltwater/lavaflow と
  同じ「D_max の allreduce → 分割数」方式で決定的。上限 bs_nsubmax で
  par_stop。
- **ドナー律速**: 送り手の総流出 Q_c·dt_sub ≤ hb·A となるよう係数
  f = min(1, hb·A/(dt_sub·Q_c)) を全エッジに一様に掛ける(セル局所で
  計算できる。hb ≥ 0 が構造的に成立し、エッジ別 1/8 律速のような配分の
  歪みがない)。hb ≤ 1e-4 m の裾は不動として停止で固定(非正規化数への
  痩せ細りによる 0 除算の実検出への対処)。
- **入力の時刻整合(§28.2 の実バグの教訓)**: 近傍の z・h を読むので、
  他プロセスが帯内の z を先に動かしていればハロが時刻 n のままになる。
  calc_bedslide は冒頭で par_halo_cell(s%z) を行い(f_splash→creep の
  経路と同じ処置)、サブサイクルごとに hb・z を交換する。h は swflow の
  ステップ頭交換で最新(本プロセスは h を変えない)。
- **適用順序**: m_geomorph_calc の z 更新プロセス群の**末尾**、
  release_debris の直前(他プロセスの z 更新を見た上で動く。debris の
  勾配評価は先頭で時刻 n の z を読む規約を崩さない)。末尾の e 回復と
  z/sd ハロ交換は既存のまま。
- **海域マスク(sw>0)とは無フラックス**(lavaflow と同じ)。
- **morfac**: f_debris と同じく 1 に限定(イベント計算)。dt_geomorph
  間欠実行は許す(dts をサブサイクルで消化)。
- **OpenMP**: パス A の reduction(max)、パス B/C は書き手一意。

### 4.7 段階2: 混合体(hs)から底層(hb)への引き渡し(プランジ)

陸上を混合体で流下した土石流が滞水域に入ったセルで、固体を hs から
hb へ移す。

- **判定**: 滞水深 ≥ bs_hplunge(m。既定案 2.0)かつ hs > 0 のセル。
  滞水深は f_bsplunge=0 で現在の h、1 で静水時の水深(初期水面 eref −
  現在の底面 z。初期に湿潤だったセルのみ。2026-09-30 追加 — 突入で
  汀線帯が一時的に離水しても引き渡すため。eref は私有 save の 3 面目)
  (滞水深の閾値。密度流のプランジ条件(密度フルード数)の簡便化。
  段階0では汀線から 2〜3 セル目、水深 5 m 付近で土塊が止まった —
  §2 — ので、この程度の閾値で「湖に入った」判定になる)。
  代替: C = hs/(h+hs) < db_cmin(希釈)を併用。段階0の観察では
  突入セルの C は 0.5〜0.7 のまま止まる(h=2.3, hs=4.3)ので、
  濃度条件だけでは引き渡されない。滞水深を主判定にする。
- **転換(台帳)**: Δ = hs / (1−λ)(かさ体積)。hs → 0、hb += Δ、
  z += Δ、sd += Δ。間隙水: h −= λ·Δ(f_dbwet と同じ規則。残量で
  クランプ)。e = z + h + 0 を回復(自由表面は z+h+hs → z+h で連続:
  水柱に混ざっていた固体が底に移っただけで表面高は保存される。
  間隙水を引くぶんは水柱から底層の間隙へ移る = 表面は λΔ 下がる。
  f_dbwet=0 なら h は不変)。
- **運動量**: 混合体の運動量は失われる(底層は慣性なし)。突入セルで
  水柱の速度場が引き続き水面勾配で動くのは変わらない。
- **速度条件 f_bsvplunge=1(2026-09-30 追加)**: 混合体の速度 vv が、引き
  渡し後の底層の終端速度 V_b = √(ξ hb_eq (S_c − μb))(hb_eq = 既存 hb +
  hs/(1−λ))以下に落ちたセルだけ引き渡す(下限 bs_vstop)。速いうちは
  慣性のある混合体として水柱に運動量を渡し(SWE の混合 = 衝突の運動量
  交換)、慣性なしの記述が妥当になってから底層へ移す。引き渡しで底層が
  混合体より遅くなることがない(運動量に対して単調)。
- 適用位置: calc_bedslide の冒頭(その時刻の hs を見て引き渡し →
  同じ tick で底層として流下)。calc_debris(E-D)は先頭で済んでいる。
- **実装(2026-09-30)**: bs_hplunge(既定 0 = なし。f_debris=1 必須。
  指定時は fn_bsinit 省略可)。test/bedslide 構成4: 同じ 19,110 m³ の
  崩壊で、混合体のみ(対照)は湖底平坦部に達しない(max dz 0.00)のに
  対し、引き渡しあり(17,077 m³ かさが底層へ)は 5.0 m 堆積。固体台帳・
  水台帳(疑似間隙水込み)は機械精度で閉合。
- 岩屑なだれ(乾いた崩壊)は fn_bsinit で最初から hb として与え、
  段階2の経路を使わない。

## 8. 既知の割り切り(利用者ガイドに明記する事項)

- 慣性なし(§4.4)。近地波高は過大側に出うる。
- 陸上突入型で移動海底方式は波高を過小に出す傾向(衝撃的な水塊の
  押し出しは 3 次元現象)。段階0で見た「混合体の突入による柱高増加」
  の造波は、段階2でも引き渡し前の突入セルで残る(両者が重なる)。
- 水の抗力・付加質量なし。ξ に押し込む。
- 非静水圧・分散性なし(SWE)。貯水池・狭い湾・浅い沿岸のような
  長波近似の成り立つスケールが適所。
- 深い水域を解くので dt は √(gH) で決まる(氾濫計算より小さい)。
- 8 近傍でも格子依存は残る(配分重みと勾配評価の離散化誤差)。
  45° 回転ベンチマークで大きさを数値化して記録する。

## 11. 既存の拡散型モジュール(creep・glacier・lavaflow)の 8 近傍化

現状はいずれも 4 近傍(cw(1), cw(3) = 0)。8 近傍化は可能で、
やることは 2 種類に分かれる。

**(1) 線形拡散(creep)は重みの正規化だけ**。エッジ流量
q_k = D·(Δz_k/dist_k)·l_k の一様勾配 G⃗ に対する正味フラックスは
D·[Σ_k l_k d̂_k d̂_kᵀ]·G⃗ で、軸 4 方向は 2l_p·I、対角 4 方向も
2l_d·I を与える(対角の d̂d̂ᵀ の和が等方)。**任意の (l_p, l_d) で
等方**であり、実効拡散係数を D に一致させる正規化 l_p + l_d = 1
(単位幅換算)だけが必要 — developer.md §19 が予告している
「(lp+√2·ld) 倍のずれ」がこれ。検出器は既存の test/creep(ガウス丘
解析解)。9 点ステンシルになるので等方性は 4 近傍より良くなる。

**(2) 非線形拡散(SIA: D ∝ H⁵|∇s|², Bingham: h0 = τ_y/(ρgS))は
係数の評価点を変える必要がある**。現状はエッジ法線方向の勾配 S_k で
係数を評価しており(Mahaffy 型の簡略版。本来の Mahaffy 1976 は
スタガード点で両成分から |∇s| を作る)、8 近傍化して斜めエッジに
S_k = S/√2 を渡すと係数が方向依存になる(SIA なら対角の D が 1/2、
Bingham なら対角の降伏厚 h0 が √2 倍)。hb と同じ処方で解決する:
**係数はセル(またはエッジ両側セルの平均)の勾配の大きさ |∇s| から
評価し、エッジ方向は線形項 Δs_k/dist_k·l_k の射影にだけ使う**。
この処方は 4 近傍のままでも等方性を改善する(真の Mahaffy 化)。

**進め方(提案)**:
- hb で処方を確立(§4.3)→ lavaflow(構造が最も近い)→ glacier →
  creep の順に横展開。
- 各モジュールに *_diagratio を追加し、**既定 0(現状の 4 近傍)で
  導入**すれば既存 reference とビット一致(規律2)。既定を 8 近傍に
  変えるのは挙動変更なので別コミットとし、reference は人間の目視後に
  更新(規律1・4)。
- 検出器: creep はガウス丘、SIA/Bingham は軸沿い vs 45° 回転の
  等流・ドーム広がりベンチマーク(hb と共通の型)。
- 優先度は hb の段階1 より低い(既存機能は動いており、格子依存は
  既知の割り切りとして文書化済み)。handoff に別項目として記録する。
