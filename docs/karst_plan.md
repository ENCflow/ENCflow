# 石灰岩の溶食(カルスト地形)の設計(karst_plan.md)

**状態: 第 1・2 段を実装(2026-10-21)、側方溶食 §2.5 を実装(2026-10-22)。
第 3 段(管路の成長)は検討のみ**。
決定事項は developer.md §86 に要約し、本書は定式化の根拠・限界・積み残しの
正本として残す(splash_plan.md・geomorph_plan.md と同じ運用)。

## 0. 結論(要約)

- **実現の可否: 可。ただし「概算の加算的プロセス」として**。カルスト地形の
  形成傾向(面的な削剥・ドリーネの深化・内陸排水)を実験する範囲まで。
  実在の洞窟系の幾何の再現は方針 2(ラスタ純化。ベクトル表現を持ち込ま
  ない)に反するため対象外。
- **カルストの水文は実装済み**: 管路連続体層 `f_gwconduit`(§46)が吸込穴
  密度と 8 方向通水能で洞窟網を等価連続体として表し、吐口が湧泉になる。
  乾谷・内陸排水の水文は溶食モデルなしで表現できる。
- **足りないのは「水に溶けて質量が消える」更新**。既存の地形変化
  プロセスはどれも機械的な運搬(z が下がれば土砂が出る)で、溶食の
  「z が下がって土砂が出ない」更新を持たない。
- **段階実装**: 第 1 段=面的溶食(涵養フラックスに比例)、第 2 段=集中
  溶食(吸込穴流入に比例。ドリーネの正帰還)、第 3 段=管路の成長(通水能・
  容量の時間発展。現契約「管路は掘り直さない」の変更を伴うため別議論)。
  第 1・2 段は `&list_geomorph` の `f_dissol` 1 フラグに統合した。

## 1. 物理と既存構造の対応

### 1.1 カルスト地形形成の 4 要素

| 要素 | 物理 | ENCflow での扱い |
|---|---|---|
| (a) 面的溶食(化学的削剥) | 土壌 CO2 を含んだ涵養水が石灰岩面を溶かす。削剥速度 20〜100 mm/kyr | **第 1 段**: Δz = −k_d·q·Δt_s(q = 涵養フラックス) |
| (b) 集中溶食(ドリーネ) | 水が吸込穴に集中する場所で溶食が集中し、窪みが深まるとさらに集水する正帰還 | **第 2 段**: 吸込穴流入量に比例した追加項。流入は既存の堰式交換(湛水深依存)で正帰還が閉じる |
| (c) 管路の成長(洞窟形成) | 流量に比例して亀裂が拡大し、通水能が時間発展(Dreybrodt 型の speleogenesis) | **第 3 段(未実装)**: 管路層の cap・cnd の動的化。§5 |
| (d) 陥没ドリーネ | 地下空洞上の被覆層の崩落 | 対象外(離散的事象。将来 f_repose との組合せで概念化の余地) |

### 1.2 使える既存構造

- m_geomorph の重ね合わせ骨格(フラグ+パラメータ+サブルーチン 1 本)、
  実効時間刻み dts = dt × idt × morfac、z 更新後の e 回復とハロ交換。
- 風化 `f_wthr`(§32)が「sd を増やし z を保つ」更新の見本。溶食は
  その対になる「z を下げ sd を保つ」更新(残渣があれば sd を微増)。
- 地下水の鉛直交換(bucket / greenampt)が浸透フラックスを s%fxg に記録
  する契約(§30。allocated 判定で書き、消費側がゼロ戻し)。管路層の
  枡流入も s%fxci に同型で記録する。溶食は**同型の専用記録場**を持つ
  (§2.3)。
- LEM 化(§32)の実行様式: 周期強制 × morfac × リスタート連鎖で
  10 kyr オーダー。

## 2. 定式化(第 1・2 段。実装済み)

### 2.1 連続形

セルごとの岩の溶ける厚さの速度:

```math
\frac{dz}{dt}\bigg|_{\rm dissol} = -\,k_d\, f_{\rm sol}\,\big(q_{\rm r} + f_{\rm sink}\, q_{\rm sink}\big),
\qquad k_d = \frac{c_{\rm eq}}{\rho_{\rm r}}
```

- $`q_{\rm r}`$: 面的涵養フラックス (m/s)。既定は地下水モジュールが記録する
  **浸透量**(`dissol_src = 1`)、代替として**地上降雨量** s%pre
  (`dissol_src = 2`。浸透の有無によらない White 型の最大削剥速度モデル)。
- $`q_{\rm sink}`$: 吸込穴(管路層の枡)への流入フラックス (m/s)。
  `dissol_sink = 1` のとき加算。$`f_{\rm sink}`$(`dissol_fsink`)は吸込穴
  流入水の溶解能の比(表面流出水は土壌 CO2 を経ないため 1 より小さく、
  土層を通った水が集まる場合は 1。校正値。既定 1)。
- $`c_{\rm eq}`$(`dissol_ceq`、mg/L CaCO3 換算)は**有効溶解能**。平衡
  溶解度から流入水の既存濃度を引いた「1 m³ の水が溶かす岩の質量」。
  炭酸平衡・CO2 分圧・温度依存は内部で解かず、前処理で与える(方針 §0
  「物理量は直接与える」)。$`\rho_{\rm r}`$(`dissol_rho`、kg/m³)は岩の密度。
- $`f_{\rm sol}`$: セル別の可溶率 0〜1(`fn_dissol`。石灰岩の分布マスク。
  未指定は一様 1)。

**速度の目安**: $`c_{\rm eq}`$ = 100 mg/L、$`\rho_{\rm r}`$ = 2500 kg/m³ →
$`k_d`$ = 4×10⁻⁵ m/m。涵養 1 m/yr で 40 mm/kyr。カルストの化学的削剥速度の
文献域 20〜100 mm/kyr(White 1984; Gabrovšek 2009)に入る。

### 2.2 離散化(1 回の地形更新)

地形更新の間隔 idt ステップのあいだに記録場へ積算された水量
$`F_{\rm r}`$, $`F_{\rm sink}`$ (m) を使い、

```math
w = k_d\, f_{\rm sol}\, (F_{\rm r} + f_{\rm sink} F_{\rm sink})\cdot \texttt{morfac}
```

```math
z \leftarrow z - (1 - f_{\rm res})\, w,\qquad s_d \leftarrow s_d + f_{\rm res}\, w
```

- 積算水量に morfac を掛けるのは「1 回の更新 = 同一イベント morfac 回ぶん」
  (§32 の風化・隆起が dts = dt·idt·morfac で積分するのと同じ意味)。
- $`f_{\rm res}`$(`dissol_fres`、0〜1)は**不溶性残渣の体積率**。溶けた
  岩の体積 w のうち $`f_{\rm res}`$ 倍が土層(テラロッサ)として残り、
  地表は $`(1-f_{\rm res})w`$ 下がる。0(既定)なら sd に触れず、土層の
  ない構成でも動く。> 0 のとき sd を確保する(setup_sd)。
- 更新は線形・局所(近傍参照なし)で無条件安定。dzmax 型の安全弁は不要。
- 海セル(sw > 0)は侵食基準面として対象外。無効セル(x ≤ 0)も対象外。
- 台帳: 溶けた岩の体積 Σ w·A を行部分和(real64)で積み、dispose で
  par_sum_rows により決定的に総括して報告する。

### 2.5 側方溶食(dissol_lat。2026-10-22 実装)

**動機**: 第 1・2 段の溶食はセル自身の z を下げるだけなので、吸込穴の
あるセルは「幅 1 セルの深い穴」になり(examples/karst)、漏斗形のドリーネ、
コックピットの併合、タワーカルストの裾のノッチと壁の後退が出ない。実際の
溶食は湛水が接する岩壁(壁面)でも進む(swamp notch・foot cave)。

**定式化(溶解能の配分)**: 湛水セル w(h_w > dd)の 1 回の更新の溶解能
$`W_w = k_d F_w \cdot \texttt{morfac}`$(§2.2 の w を可溶率を掛ける前で
とったもの)のうち、割合 $`p`$(`dissol_lat`、0〜1)を**壁面**へ、
残り $`1-p`$ を床へ配る。壁面 = w の 8 近傍のうち床が w の水面より高い
陸セル n($`z_n > e_w = z_w + h_w`$。w の水面上に出ている岩壁)。
壁面への配分は接触面の幅 $`L_k`$(軸 Δx、斜め Δx·2/(2+√2))に比例:

```math
\Delta z_n \mathrel{-}= f_{{\rm sol},n}\; p\, W_w \frac{L_k}{\sum_{m \in {\rm walls}(w)} L_m},
\qquad
\Delta z_w \mathrel{-}= f_{{\rm sol},w} (1-p) W_w
```

壁が 1 つもない湛水セル(平坦な水面の内部)と乾いたセルは従来どおり
床に全量。配分なので総溶解能は不変(可溶率 < 1 の壁に当たった分は失われる
= 床の場合と同じ)。壁面で溶けた岩の体積は、berode と同じラスタの慣習で
壁セルの z を下げることで表す(平面の後退を高さの低下に写す)。残渣は
壁セルの sd に残す(簡略。裾への落下は扱わない)。

**なぜ配分(溶解能の分け前)であって独立の速度則でないか**: 側壁の後退速度を
独立係数(berode の K_b 型)にすると「水 1 m³ が溶かす岩は c_eq/ρ_r」という
第 1・2 段の意味論と矛盾し、湛水の大小に無関係に壁が溶ける。配分なら
吸込穴の流入量(= 窪みの集水)が壁の後退も駆動し、集水の大きい窪みほど
広く深くなる、というドリーネの成長則がそのまま出る。$`p`$ は「床と壁の
溶ける比」で、接触面積比の概算(壁の濡れ面 h·L と床面 Δx² の比)から
0.2〜0.5 程度、深い湛水(h ≈ Δx)なら 0.8 程度。`dissol_lat = −1` では
この面積比 $`p_w = h_w \sum L/(h_w \sum L + \Delta x \Delta y)`$ をセルごとに
計算する(推奨。examples/karst の p = 0.3 固定では壁の分け前が小さく、
穴の幅がほとんど変わらなかった = 2026-10-22 の試行)。

**離散化(3 パス。MPI は owner-compute)**:
1. 湛水セルごとに $`W_w`$ を記録場から作り(§2.2 と同じ消費・ゼロ戻し)、
   壁の有無を判定して壁向け $`pW_w`$ をスクラッチ `qw` に、床向けを `wfl` に
   置く(自帯のみ書く)。先頭で z・h のハロを交換し、壁判定は時刻 n の
   z・h で行う。
2. `qw` のハロを交換し、各セル n(自帯)が 8 近傍 w の `qw` から自分の
   分け前を集める(w の壁集合の重みの和は w の近傍 = n から ±2 行以内 =
   ハロ幅 2 で足りる)。書き込みは `dzl(n)` のみ(近傍の z を読みながら
   z を書かない = OpenMP の競合なし。順序固定 = ランク数不変)。
3. 床と壁の量をまとめて z(・sd)に適用し、台帳に積む。
`dissol_lat = 0`(既定)では従来の 1 パスのまま = ビット一致。

**検証(test/dissol 構成 D)**: 平坦地の中央 3×3 の窪み(z = −1)に水位
−0.5 の湛水だけを置き(f_htype = 2)、バケツ浸透で窪みの 9 セルに同じ
記録 F を与える。壁は窪みを囲む 16 セルで、配分の重みは幾何から決まる
(角の窪みセル: 軸 2・斜め 3、辺の窪みセル: 軸 1・斜め 2、中央: 壁なし)。
Z9998 を配分式の解析値(Check_analytic.py が独立に実装)と比較し、
総溶解能 9 W が床+壁の和に一致すること(保存)を見る。MPI は np = 4 で
窪みが帯をまたぐ。

### 2.3 記録場(s%fxd / s%fxdi)と各モジュールの契約

- `s%fxd`(涵養量の記録 m)、`s%fxdi`(吸込穴流入量の記録 m)。
  **確保は m_geomorph_init**(f_dissol > 0。fxdi は dissol_sink = 1 のみ)。
- 書き手: bucket・greenampt の鉛直交換(fxd。`allocated(s%fxd)` 判定で
  s%fxg の隣に 1 行)、conduit の枡流入(fxdi。s%fxci の隣に 1 行)。
  `dissol_src = 2` のときは geomorph 自身が毎ステップ s%pre·dt を fxd に積む。
- 消費: calc_dissol が読んでゼロ戻し。
- **wq の s%fxg と記録場を共用しない理由**: wq は毎ステップ消費してゼロ戻し
  するが、geomorph は idt ステップごとの間欠実行で積算が要る。同じ場を
  2 者が消費すると順序依存になる(wq_calc → geomorph_calc の順のため
  geomorph は常に 0 を見る)。
- 記録場は更新間隔の途中で save されると失われるため、**モジュール私有
  ファイル geomorph_dissol.dat(契約 5)で save/restore する**(fxd、
  sink 有効時は fxdi も)。更新ステップで save されれば値は 0 だが、
  形式は構成に依らず固定。これでリスタート往復は ULP=0 で閉じる。

### 2.4 方針(§0)との整合

| 方針 | 整合 |
|---|---|
| 2 ラスタ純化 | セル局所の更新。洞窟の幾何は持たない |
| 4・5 概算・鉛直の抽象化 | セル 1 個の速度式。化学は c_eq 1 個に抽象化 |
| 6 徐々に精緻化 | 第 1 段=一様速度、第 2 段=集中項、第 3 段=管路成長(別議論) |

| 9 単一ソース | 局所更新のため MPI は z/sd の既存ハロ交換で閉じる |

## 4. 限界(利用者向け文書にも書く)

- **飽和の無視**: 水は常に c_eq ぶん溶かす(未飽和一定率)。流下に伴う
  飽和による溶食の減衰(谷頭で強く下流で弱い)は扱わない。扱うなら wq の
  溶存種(cg)と結合して c_eq − c の形にする(第 4 段の候補。§5)。
- **蒸発散の無視**(dissol_src = 2): P − E ではなく P。
- **速度の桁**: 20〜100 mm/kyr。深さ 10 m 級のドリーネは集中項の非線形性
  (集水 → 流入増 → 溶食増)に依存し、100 kyr 級の地形時間が要る。形成
  様式の実験には足りるが、特定の実地形を狙う用途には向かない。
- **吸込穴の分布は静的**: 枡密度 fn_gwc_inlet は時間発展しない。新しい
  吸込穴は「石灰岩セルに一様な小さい穴密度を与える」ことで表す。
- **壁の後退は高さの低下で表す**(§2.5。berode と同じラスタの慣習)。
  岩壁の崩落(岩 → 岩屑 → 搬出)はない。裸岩斜面の表面流による溶食
  (リンネンカッレン)も水量源にない(表面流源は候補。§5)。
- 陥没ドリーネ・離散的な洞窟の幾何は対象外。

## 5. 第 3 段(管路の成長)の検討メモ(未実装)

- 物理: 管路の断面積 A の成長 dA/dt ∝ Q·(c_eq − c)(Dreybrodt 1990,
  Kaufmann & Braun 2000)。等価連続体では「エッジの通水能 cnd_k を
  |Q_k| に比例して増やす」+「容量 cap を同期して増やす」形になる。
- 現契約との衝突: m_gwflow_conduit は「zbot・cap・cnd は静的(管路は掘り
  直さない)」。動的化すると (a) conduit_build_cnd の再構築、(b) cap・cnd
  のリスタート保存(私有ファイルの形式変更)、(c) dt 上界(サブサイクル
  数 N)の再評価、(d) 水質連携 wq_gwc の濃度意味論、に触れる。
- 位置づけ: 自己組織化する高通水帯の形成(連続体版の洞窟網)を見る実験
  として価値はあるが、都市下水道(第一用途)には不要。**gwflow 側の
  独立フラグ(f_gwc_growth)として、conduit の契約改定を developer.md に
  記してから着手する**。溶食側(本書)とは記録場を介して疎結合にできる
  (管路内の流量は conduit が知っている)。
- 第 4 段候補: wq の溶存種との結合(飽和による減衰)。
- 表面流源 dissol_src = 3(セルを流れる水量に比例。裸岩斜面のリンネン
  カッレン、塔の斜面の溶食)。岩壁の崩落(岩 → 岩屑 sd → クリープ・掃流で
  搬出)はタワーカルストの垂直壁の維持に要るが、別設計。
