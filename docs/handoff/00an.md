00an. **例題 examples/coarse_channel(2026-11-26 作成。粗い格子で川を表す表し方と通水の精度の系統的な確かめ)の残り**
   (作成の経過と結果の読みは developer.md §135。ここには決まっていないこと・確かめていないことだけを書く)
   - **川幅 1〜2 セルの斜めの川の表し方がない**: 例題の帯・1 列のどの表し方も 0.07〜1.85 倍にばらつく(§135.3)。1 列に
     1 セルのサブグリッド河道は川幅 0.6 セルまで合うが、斜めに並ぶ 1 列の通水には上限(0.71〜0.89 セル分)がある。手が
     あるとすれば計算本体の側(横に並んだサブグリッドのセルの斜めの辺のキャップの規則、セルごとの通水の係数、局所の
     細かい格子 = ネスティング)で、どれも §18 の制約か通過幅の規則を変えるので、設計の議論が先。
   - **貯留の違いと洪水波**: 解像 n 列 + 残り・n+1 列・太らせた帯は、表す面積の幅が川幅と違う(1.0〜1.2 倍、太らせた
     1.2 セルの帯で 1.8 倍前後)。定常の通水しか測っておらず、洪水波の遅れと減衰への影響は確かめていない(非定常の
     ケースを足すなら、細かい格子の波形と比べる)。
   - **地形で表した河岸の薄い水膜**: 2 行共有の帯(26.6°・川幅 200 m・Δx = 100 m)で、河岸の雨の水膜 1〜2 cm が通水を
     1.013 → 0.956 倍に下げる(余分な水深 3.6 %。test/wetbank の o4 の形では 0.2〜2.0 %。§134.10)。test/wetbank に太らせた
     帯の形を足すか、側方面・供給元の規則を見直すかは決めていない(規則を変えるなら挙動の変更なので設計の議論が先)。
   - **河道の外を無効セルにするか、乾いた有効セルにするか**で、同じ帯の通水が 1.005 と 1.013 で違う(§135.3)。切り分けて
     いない。
   - **利用者ガイドへの書き方**: 表し方の選び方(例題の「表し方の選び方」の表)と限界を、河道(channel.md)・河道の解説
     (channel_models.md §2)に書くかどうかは決めていない(いまは例題の README だけ。handoff 00ak の同じ項目と一緒に決める)。
   - **前処理の道具**: 中心線と川幅から、1 列に 1 セルのマスク・帯(列の選び方・段の太らせ)・幅を作る道具は utils/ に
     ない(例題の make_cases.py は直線と円弧だけ)。DEM から作る河道マスクの癖(同じ距離のセルの選び方)も確かめていない。
   - **確かめていないこと**: 川幅の変わる区間、蛇行、1 セル幅のサブグリッド河道の屈曲、移流項の既定以外の構成(同じ帯で
     1.00〜1.08 倍に変わる)、MPI での実行。英語版 README の図(en/figs)は plot_results.py en で描いたもので、内容の確認は
     日本語版と同じ計算の結果に基づく。
