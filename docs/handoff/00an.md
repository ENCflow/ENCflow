00an. **例題 examples/coarse_channel(2026-11-26 作成。粗い格子で川を表す表し方と通水の精度の系統的な確かめ)の残り**
   (作成の経過と結果の読みは developer.md §135。2026-11-27 に占有率で作る河道マスクを中心に組み替えた(§135.6)。ここには
   決まっていないこと・確かめていないことだけを書く)
   - **川幅 1 セル前後の斜めの川と、格子に沿う川・45° の川の多めの通水**: 占有率の全セルの作り方(下限 5 %)で、斜めの
     川は 1.2 セル 0.84〜1.04 倍、1.6〜3 セル 0.90〜1.03 倍まで来た(§135.6)。残るのは、(1) 1 セル前後の川(0.8〜1.2 セル。
     1 セル未満は中心線の 1 列に川幅を与える作り方に分けているが、斜めに並ぶ 1 列が流せるのは 0.71〜0.89 セル分まで)、
     (2) 格子に沿う川と 45° の川で、半端なセルが横に並ぶ所の多めの通水(2 セルで 1.20・1.22 倍、10 セルでも 1.04 倍)。
     どちらも作り方では直せず、手があるとすれば計算本体の側(横に並んだサブグリッドのセルの斜めの辺のキャップの規則、
     セルごとの通水の係数、局所の細かい格子 = ネスティング)で、§18 の制約か通過幅の規則を変えるので、設計の議論が先。
   - **占有率の下限と開口の動的な振り替え**: 下限なしで占有率が数 % のセルまで河道にすると、そのセルが「開いている」と
     数えられて斜めの辺の開口の振り替えが止まり、通水が 1〜2 割落ちる(§135.6。振り替えを切ると下限のあるなしの差は
     0.016)。いまは前処理の約束事(下限 5 %)で避けている。振り替えの判定で幅の小さいサブグリッドのセルを塞がりとして
     数えれば下限は要らなくなるかもしれないが、挙動の変更なので設計の議論が先(既存の河道マスクの計算が変わる)。
   - **貯留の違いと洪水波**: 占有率の全セルの作り方は表す面積が川幅とほぼ同じだが、50 % 以上を解像する作り方、解像 n+1 列、
     太らせた帯は表す面積が川幅より大きい(1.0〜1.2 倍、太らせた 1.2 セルの帯で 1.8 倍前後)。定常の通水しか測っておらず、
     洪水波の遅れと減衰への影響は確かめていない(非定常のケースを足すなら、細かい格子の波形と比べる)。
   - **地形で表した河岸の薄い水膜**: 2 行共有の帯(26.6°・川幅 200 m・Δx = 100 m)で、河岸の雨の水膜 1〜2 cm が通水を
     1.013 → 0.956 倍に下げる(余分な水深 3.6 %。test/wetbank の o4 の形では 0.2〜2.0 %。§134.10)。test/wetbank に太らせた
     帯の形を足すか、側方面・供給元の規則を見直すかは決めていない(規則を変えるなら挙動の変更なので設計の議論が先)。
     占有率の作り方の帯で河道の脇の水を確かめていない。
   - **河道の外を無効セルにするか、乾いた有効セルにするか**で、同じ帯の通水が 1.005 と 1.013 で違う(§135.3)。切り分けて
     いない。
   - **利用者ガイドへの書き方**: 河道マスクの作り方の選び方(例題の「河道マスクの作り方の選び方」の表: 1 セル未満は中心線の
     1 列、1 セル以上は占有率の全セル)と限界を、河道(channel.md)・河道の解説(channel_models.md §2)に書くかどうかは
     決めていない(いまは例題の README だけ。handoff 00ak の同じ項目と一緒に決める)。
   - **前処理の道具**: 河道のポリゴンや高解像度の河道マスクから、占有率を数えて河道マスク(fn_rw)と幅(fn_width)を作る
     道具(下限、1 セル未満の区間の中心線の 1 列、8 連結の確かめを含む)は utils/ にない(例題の make_cases.py は直線と
     円弧の帯の点を数えるだけ)。川幅が 1 セルをまたいで変わる所で、中心線の 1 列と占有率の作り方をどうつなぐかも
     決めていない。DEM から作る河道マスクの癖(同じ距離のセルの選び方)も確かめていない。
   - **確かめていないこと**: 実際の河道のポリゴン(川幅の変わる区間、蛇行、中州、合流、河道網)、1 セル幅のサブグリッド
     河道の屈曲、水深 ÷ セル幅が 0.035 以外の流れ、移流項と開口の振り替えの既定以外の構成(同じ帯で 1.00〜1.08 倍に
     変わる)、MPI での実行。英語版 README の図(en/figs)は plot_results.py en で描いたもので、内容の確認は日本語版と同じ
     計算の結果に基づく。
