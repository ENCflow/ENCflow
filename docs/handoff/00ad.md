00ad. **結果のディレクトリ(dir_result)の長いパスで、プローブ・測線・集計のファイル名が 80 字で切れる(2026-11-23 発見。未修正)** —
   src/m_record.f90 の fn_pb(プローブ)・fn_fl(測線)・fn_smry(集計)が character(len=80) で、dir_result(256 字まで)に
   「/probes/probe0001.csv」などを足した名前が 80 字を超えると、黙って切れる。切れた先がディレクトリなら開けずに止まり
   (2026-11-23 の examples の回し直しの診断計算で、長い絶対パスを与えて「Cannot open file '...': Is a directory」で
   止まった。developer.md §114.9)、そうでなければ別の名前のファイルに書く。
   - 直し方の候補: 3 つの変数を可変長(character(:), allocatable)にするか、dir_result の長さに余裕を足した長さにする。
     ほかの出力ファイル名の変数に同じ型の制限がないかも確かめる。
   - 直すときはバグ修正として別のコミットにする(短いパスでは出力は変わらない = 既存の reference とビット一致のはず)。
