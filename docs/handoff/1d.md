       地表水を足し引きするときに水が消えた・増えた不具合を、矩形換算水深で受け渡す形に

       (2) σ のセルの管路層の等化上限は今の水深の σ で線形化した近似(水は保存)。
       (3) σ のセルの非 0 の初期水深の質量は矩形換算(既知の妥協)
