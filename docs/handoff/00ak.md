00ak. **例題 examples/confluence_backwater(2026-11-26 作成。合流点の背水による支川の氾濫と、粗い格子・合流の形の確かめ)の残り**
   (作成と検討の経過は developer.md §131。ここには決まっていないこと・確かめていないことだけを書く)
   - **解像した合流の損失の格子依存**(§131.2): 本川 10 セル・支川 5 セルの直角・鈍角の合流で、合流の損失は
     1 次元の運動量の理論の 3〜5 割(p = 0.33・0.46)、格子を半分にすると 5〜9 割(0.46・0.88)。収束の確認
     (Δx = 2.5 m など)と、水路実験(Weber ら 2001 の 90°・等幅、Hsu ら 1998 の 30〜60°、Gurram ら 1997)との
     比較はしていない。移流項の規則(f_advection_lateral など)を変えるなら挙動の変更なので設計の議論が先。
   - **利用者ガイドへの限界の追記**: 解像した合流の損失の過小と格子依存(移流項のスキーム §4.4・1 セル幅の河道と
     移流項の風上供給元 §7)を、章に書くかどうかは決めていない(いまは例題の README だけ)。粗い格子の河道マスクの
     作り方と限界は、2026-11-27 に河道(channel.md)の節と河道の解説 §2 に書いた(§131.14)。
   - **粗い格子の越水の時期の差**(§131.13・§131.14): 例題の粗い格子は 2026-11-27 から占有率で作る河道マスクの 3 通り
     (簡便・占有率のまま・直したもの)。いちばん合う直したものでも、合流点の水位は越水の時期に +0.03〜0.09 m 高いのに、
     堤内地の水量は 0.76〜0.84 倍。内訳(仮想壁面の堰の式と、細かい格子の堤防のセルを越える浅水流の違い、湾曲部の
     占有率の帯の表し方、残りのセルの貯留の膨らみ = L_ch が横の河道セルまで数える分など)は切り分けていない。
     川幅 1〜1.5 セルの斜めの川・45° の川の多めの通水・河道マスクを作る前処理の道具は handoff 00an にまとめた。
   - **定常の背水曲線の検定**: サブグリッド河道の支川の背水曲線を 1 次元の漸変流の式と比べる検定は test/ にない
     (例題の plot_results.py の数表だけ。差は解像 0.004 m・サブグリッド 0.018 m)。検定にするなら、例題より小さな
     直線の本川と支川の構成で、reference と Check_*.py を作る(reference の確定は人の目視が要る)。
   - **確かめていないこと**: 例題を MPI(np = 2・4)で回していない。英語版 README の図(en/figs)は plot_results.py en
     で描いたもので、内容の確認は日本語版と同じ計算の結果に基づく。
