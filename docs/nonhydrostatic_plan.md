## 0. 結論(要約)

1. **実装は可能で、実証済みの実用路線がある**。「現行の静水圧ステップを
   predictor にし、ステップ末尾でセルスカラー 1 個の楕円型方程式を解いて
   エッジ流速を補正する(射影法)」構成は、1 層非静水圧モデル(SWASH・
   NEOWAVE)と局所適応型の最近の研究(Firdaus & Behrens 2026)が採る
   形で、ENCflow の構造にそのまま載る(§5)。
2. **既存コードへの影響は最小**: momentum / 適応 RK / 移流 / continuous は
   無変更、親モジュールへの hook は m_swflow_enc_calc の 1 箇所、NH OFF で
   配列確保・演算・通信ゼロ追加 = 既存 reference とビット一致(§5.6)。
3. **「必要な場所だけ」の適応化**は、適応 RK と同じ発想で載る(§6):
   検出量 χ ≈ (kH)²/4 で種セルを選び、楕円型作用素の減衰距離 H/2 に
   基づく数 H の縁をつけた活性集合だけで反復する。活性領域の内側は
   厳密解のまま、長波・定常流・氾濫の領域にはコストが乗らない。
4. **反復ループ内の MPI 通信は回避できる**(§7): 掃引数を固定して
   Chebyshev 加速し、幅 m のハロを 1 回だけ交換すれば、反復内のハロ交換と
   collective はゼロ(Δx = H/2 で m ≈ 12)。ただし性能段階の作業とし、
   まず既存ハロの Jacobi で正しさを固める。
5. **「エッジ局所の陰的補正(単一掃引)」は採らない**(§4): 線形解析
   の結果、必要解像度(Δx ≲ H/2)では目標の分散関係の補正量の 1/3〜1/9
   しか出ず、Δx < H/√2 で格子スケールの符号が反転する。本質的に反復法の
   1 回目に過ぎない。
6. **コストの支配要因は空間解像度 Δx ≲ H/2** で、ソルバではない(§3.3)。
   NH ケースは研究計算として深い水域を細かく切る前提で見積もる。
7. **方針との関係で 2 点の改定議論が先に必要**(§10): developer.md §0-5
   「水平は SWE が上限」への研究用の明示的例外、および「セルスカラー
   1 個・決定的・NH OFF でゼロ追加」を満たす反復ソルバの許容。
8. 概念の新規性は主張しない(実用性優先。§9)。差別化しうるのは検出量
   χ、減衰距離に基づく縁幅、通信回避の固定回数 Chebyshev とビット
   再現性だが、採否はいずれも実用性で決める。

## 1. 目的と適用範囲

### 1.1 なぜ非静水圧か

静水圧の浅水方程式(SWE)は本来非分散で、平坦床・微小振幅の線形波の
位相速度は √(gH) で波数に依らない。実際の水面波の分散関係は
ω² = gk tanh(kH) で、浅水展開 ω² = gHk²[1 − (kH)²/3 + …] のとおり
短い波ほど遅い。この**周波数分散**が本質的に効く現象は SWE では原理的に
再現できない。

主対象(研究用途):

- 河川遡上津波のソリトン分裂・undular bore(非線形急峻化と分散の競合)
- 地滑り津波の造波・近地伝播(発生源の水平スケールが水深に比べて
  十分大きくない)
- 弱い段波・undular bore を伴うダム・ため池決壊、貯水池の孤立波

ENCflow の特徴「複数プロセスを一つの格子・一つの時間発展でつなぐ」と
相性がよいのは、

```
津波 → 河川遡上 → ソリトン分裂 → 越水・氾濫 → 家屋破壊 → 流木・瓦礫
地滑り → 動く底面 → 非静水圧造波 → 分散伝播 → 遡上 → 被害
```

を単一時間発展で扱えることにある。

### 1.2 既定は静水圧のまま

降雨流出・河川洪水・氾濫・都市内水・高潮・一般的な長波津波・地下水・
水質・河床変動・土石流・雪崩・氷河・溶岩流・長期地形変動という ENCflow の
大部分の用途に NH は不要である。したがって

- 既定は静水圧 ENC。NH は list_enc の f_nonhydrostatic=1 で明示的に
  有効化する研究機能。
- **f_nonhydrostatic=0 では現行 ENCflow とビット単位で一致**する
  (新しい配列を確保しない、既存の演算順序を変えない、通信を増やさない、
  全回帰テストが ULP=0)。これを最重要の品質基準とする。
- NH の状態・作業配列・係数・差分演算・ソルバ・診断は submodule
  m_swflow_enc_nh に閉じ込め、m_swflow_enc 本体の変更を hook の数行に
  限る(既存の _adv / _diff / _bc / _channel と同じ思想)。

### 1.3 数値分散と物理分散を分けて測る

現行 ENC(2 次精度の空間離散+陽的時間積分)にも**数値分散**がある。
1 次元 C 格子の代表例で ω² = gH[(2/Δx) sin(kΔx/2)]²、長波展開
ω² = gHk²[1 − (kΔx)²/12 + …]。tutorials/wave の波先端の振動はこの種の
数値分散(空間離散+時間積分+方向異方性)である。NH を入れると計算結果の
分散 = 物理分散 + 空間数値分散 + 時間数値分散 + NH 離散化誤差になり、
数値分散を事前に定量化しておかないと、計算に現れた短波列が物理的な
ソリトン分裂なのか偽の波列なのか判別できない。§11 の Phase 1 はこのため
にある。

## 3. 1 層 NH モデル

### 3.1 定式(平坦床・線形化)

深さ平均の 1 層非静水圧モデル(非静水圧 p_nh を鉛直に線形分布とし、
鉛直速度を底面 0・水面 ∂η/∂t の平均で表す)は、平坦床・1 次元・線形化で

    u_t + g η_x − (H²/4) u_xxt = 0

となる。水平加速度 a = u_t で書くと

    (1 − (H²/4) ∂_xx) a = −g η_x

すなわち NH は「静水圧の加速度 b に陰的な分散フィルタを掛ける」操作

    (I − β G D) a = b,   β = h²/4

である(G: セル → エッジの勾配、D: エッジ → セルの発散。§5.2)。Fourier
モードでは â = b̂/(1 + (kH)²/4) で、高波数側の加速度を抑える(増幅しない)
フィルタ。分散関係は

    ω² = gHk² / (1 + (kH)²/4)

で、SWASH の 1 層(Keller-box)と同じ。NH の強さの無次元量を
z = (H²/4)Λ(Λ: 離散ラプラシアンの正の固有値)とすると、静水圧との
位相速度比は 1/√(1+z)。位相速度差 1% / 3% / 10% は z ≈ 0.02 / 0.06 /
0.24(連続極限で kH ≈ 0.29 / 0.50 / 0.97)に対応する。

NH 作用素は静水圧の**全加速度**(圧力・重力・移流・摩擦)に掛ける。
一様流 U₀ 上の微小波では NH が作用すべき量は物質加速度 u_t + U₀u_x で、
分散関係は (ω − U₀k)² = gHk²/(1 + (kH)²/4) となるから、移流を含む
全加速度に掛ける方針は物理的に正しい。

### 3.2 鉛直圧力分布の選択

2 次分布(Jeschke et al. 2017; Firdaus et al. 2025)は Green–Naghdi 相当
ω² = gHk²/(1 + (kH)²/3) で O((kH)²) まで厳密だが、厳密解
ω² = gk tanh(kH) に対する位相速度の誤差を概算すると

| kH | 線形 1/(1+(kH)²/4) | 2 次 1/(1+(kH)²/3) |
|---:|---:|---:|
| 0.5 | +0.9% | −0.1% |
| 1.0 | +2.5% | −0.1% |
| 2.0 | +1.8% | −5.7% |
| 3.0 | −3.7% | −13% |

ソリトン分裂の後続波(kH 1〜2)では線形が劣らず、スカラー 1 個で済む。
2 次分布は射影法で時間微分の曖昧さが出る(Firdaus et al. 2025 が別形式で
回避)。**線形分布 β = h²/4 を採る**。

### 3.3 必要な空間解像度(NH が成立する条件)

C 格子の長波展開 ω² = gHk²[1 − (kΔx)²/12 + …] と 1 層 NH の
ω² = gHk²[1 − (kH)²/4 + …] から、**空間の数値分散と物理分散は
Δx = √3·H ≈ 1.7H で同じ大きさ**になる。

| Δx/H | 数値分散 / 物理分散 |
|---:|---:|
| 2.0 | 1.33 |
| 1.0 | 0.33 |
| 0.5 | 0.083 |
| 0.25 | 0.021 |

- Δx > 1.7H の格子では NH を入れても数値分散に埋もれる(無意味)。
- NH の検証・実用は Δx ≈ H/2〜H/4 が前提。

深さ 10 m の河川遡上津波なら Δx ≈ 2.5〜5 m、dt ≈ 0.1〜0.3 s。10 km ×
1 km で 10⁵〜10⁶ セル・1 時間で 10⁴ ステップ規模(ノート PC〜
ワークステーション、必要なら MPI)。**コストはソルバよりこの解像度要件で
決まる**。

### 3.4 β の扱いと一般地形

- Version 1: β_i = (h_i^n)²/4 をグローバルステップ中固定(局所陰的な
  分母の正値性が明確、線形理論と対応しやすい、RK 中の移流固定と同じ
  ステップ単位の線形化)。
- 一般地形では鉛直速度に底面の運動学的寄与 w_b = u·∇z_b(動く底面では
  ∂z_b/∂t も)が加わり、水平運動量にも −(1/h)∇(h p_nh) に加えて
  −(2p_nh/h)∇z_b 型の底面勾配結合が現れる。浅水化・遡上・地形曲率を
  本格的に扱うにはこれらが要る。Version 1 は平坦〜緩勾配床を対象とし、
  底面勾配項は Version 2(§11 Phase 7)、動く底面は Phase 8 とする。
- g cos²θ(f_gravity_correction)は静水圧の急勾配補正として残し、
  動的 NH とは区別する。両者の二重計上の回避は理論課題(§12)。

**Version 2 の実装(2026-10-05。f_nh_slope=1。developer.md §69.5)**:
深さ平均の NH 項を Leibniz 則で書くと a_NH = −½∇q − (q/2h)∇(η + z_b)、
φ := −q/2 で a = a* + ∇φ + (φ/h)∇(h + 2z_b)。鉛直は w̄ = (w_s + w_b)/2 =
−(h/2)∇·u + u·∇z_b から q = h ∂w̄/∂t → φ = (h²/4) D a − (h/2) a·∇z_b。
ENC の 8 方向重みは Σ_k l8(k) d_k n_k n_kᵀ/(2A) = I を満たすので
(a·∇z_b)_i = ½ Σ_k wd_k a_k^out (z_n − z_i) と離散化でき、
φ_i = (h_i/4) Σ_k wd_k (h_i − Δz_k) a_k^out(平坦なら βDa に戻る)。
作用素は非対称: Jacobi は全項、CG は平坦部分を解いて勾配項を Picard
(warm start)で回す。|Δ(h+2z)/(2h_e)| ≤ ½ のクランプで対角優位を保つ。

## 4. 離散化の候補と線形解析

### 4.1 候補

(I − βGD)a = b を ENC の離散勾配 G(セル → エッジ、(φ_n − φ_c)/w8dr(k))
と離散発散 D(エッジ → セル、continuous と同じ重み l8(k)/(dx·dy))で
書く。1 次元・一定水深 H・Fourier モードでは、C 格子の離散ラプラシアンの
固有値 Λ = 4 sin²(kΔx/2)/Δx² を使って、補正率 P = â/b̂ が

| 方式 | P(k) | 備考 |
|---|---|---|
| (c) 厳密解(目標) | 1 / (1 + βΛ) | ω² = gHΛ/(1 + βΛ) を与える |
| (a) 陽的 1 項 a = b + βGDb | 1 − βΛ | Neumann 級数の 1 次打ち切り |
| (b) エッジ局所の陰的補正(単一掃引) | (1 + ε cos kΔx) / (1 + ε)、ε = 2β/Δx² = H²/(2Δx²) | (I − βGD) に対する Jacobi 反復の 1 回目(初期値 = b)に等しい |

(b) は「対象エッジ e = (i, j) について (Da)_i = C_i + s_e a_e、
(Da)_j = C_j − s_e a_e と分解し、他エッジの寄与 C_i, C_j を静水圧の
Euler predictor から作った値で固定して

    a_e = [b_e + (β_j C_j − β_i C_i)/d_e] / [1 + s_e(β_i + β_j)/d_e]

とスカラーで解く」案(追加メモリはセルスカラー 1 個、全格子ソルバ
なし、RK 段内に入れられる、という利点が期待される)。しかし C を固定する
操作は Jacobi 法の 1 掃引そのもの(対角 1 + ε、非対角 ε/2 × 2)で、
反復の 1 回目にすぎない。

### 4.2 数値

Δx/H を変えた補正率 P(kH = 0.5 / 1.0 / 2.0。各欄は 目標 / (b) / (a))。
kΔx > π のモードは n/a。

| Δx/H | ε | kH = 0.5 | kH = 1.0 | kH = 2.0 | 格子スケールの (b) |
|---:|---:|---|---|---|---:|
| 2.0 | 0.125 | 0.946 / 0.949 / 0.943 | 0.850 / 0.843 / 0.823 | n/a | +0.78 |
| 1.0 | 0.5 | 0.942 / 0.959 / 0.939 | 0.813 / 0.847 / 0.770 | 0.585 / 0.528 / 0.292 | +0.33 |
| 0.5 | 2.0 | 0.941 / 0.979 / 0.938 | 0.803 / 0.918 / 0.755 | 0.521 / 0.694 / 0.081 | −0.33 |
| 0.25 | 8.0 | 0.941 / 0.993 / 0.938 | 0.801 / 0.972 / 0.751 | 0.505 / 0.891 / 0.021 | −0.78 |

読み方: 長波極限で (b) は目標の補正 (1 − P) を **1/(1 + ε) 倍**にしか
出さない(Δx = H/2 で 1/3、H/4 で 1/9)。Δx < H/√2 では格子スケール
モードの加速度の符号が反転する(2Δx モードの不安定化要因)。(a) は
kH ≲ 1 では目標に近いが kH > 1 で過大、格子スケールで負(βΛ > 1)。
§3.3 の解像度要件(Δx ≲ H/2、ε = 2〜8)では (b) は機能しない。
**目標を再現するのは (c) だけ**で、反復(§5.3)が必要である。

### 4.3 2 次元 ENC 作用素と反復の収束

ENC の 8 近傍ラプラシアン −DG の対角成分は Σ_k l8(k)/(dx·dy·w8dr(k))
= 2.83/Δx²(p_diagratio 既定。5 点なら 4.0/Δx²。長波極限で ∇² に一致
することは確認済み)。ε_2D = β·2.83/Δx² として

| Δx/H | ε_2D | Jacobi の長波誤差減衰率 ε/(1+ε) | 1e-4 までの掃引数 | CG の条件数 κ ≈ 1 + 2ε | √κ |
|---:|---:|---:|---:|---:|---:|
| 1.0 | 0.71 | 0.41 | 10 | 2.4 | 1.6 |
| 0.5 | 2.83 | 0.74 | 30 | 6.7 | 2.6 |
| 0.25 | 11.3 | 0.92 | 109 | 23.6 | 4.9 |

恒等項があるため条件数は格子数に依存せず、**CG なら 10 反復程度、
Jacobi でも 30 掃引程度**で収束する。3 次元 NH モデルの圧力ポアソン
(κ ∝ N²、マルチグリッド必須)とは性格が違い、「全格子の反復ソルバ」の
重さはない。

### 4.4 RK 段内に NH を入れない理由

(b) を RK の各段に入れる案は、反復解を段ごとに 4 回解くことになり、
かつ全エッジの Euler predictor を先に完成させる 2 パス構造(momentum の
単一パス構造の変更)を要する。さらに predictor の加速度発散を両セルへ
「B_i += s_ie b_e、B_j += s_je b_e」と散布加算すると OpenMP のセル並列で
競合書き込みになり、atomic にすると総和順序が非決定になる(§8 違反)。
§5 の方式はこれらの問題を持たない。NH 補正はグローバルステップに 1 回、
静水圧 predictor(適応 RK を含む)の後に掛ける。

## 5. 推奨方式: ステップ末尾の射影(fractional step)

### 5.1 時間分割

1 グローバルステップを次の 3 段に分ける(SWASH・NEOWAVE 型の
predictor–corrector)。

1. **静水圧 predictor(現行のまま)**: momentum(適応 RK・保存形移流・
   摩擦・堤防・構造物)→ par_edge_merge → boundary_uvmn。結果を
   u*(sx%uv)、mn1*(sx%mn1)とする。
2. **NH 補正(新設 nh_project。NH ON のときだけ呼ぶ)**:
   - a*_e = (u*_e − u^n_e)/Δt(ステップの静水圧全加速度。移流・摩擦・
     RK の効果を含む)。
   - セルスカラー φ_i = β_i (D a)_i について (I − β D G) φ = β D a* を
     反復で解く(§5.3)。
   - NH エッジで a_e = a*_e + (G φ)_e、u^{n+1}_e = u^n_e + Δt a_e、
     mn1_e = u^{n+1}_e · he。
   - par_edge_merge(uv, mn1)を再実行(界面行の補完)。
3. **continuous 以降(現行のまま)**: 補正後の mn1 で水深更新。質量
   保存は両セルが同じ mn1 を見るので現行どおり厳密。

線形(1 次元・平坦床)では、静水圧部を前進後退 Euler とすると半離散の
分散関係が ω² = gHΛ/(1 + βΛ) に**厳密に**一致する(時間離散化誤差は
現行と同程度)。NH 補正は加速度に 0 < P ≤ 1 のフィルタを掛けるだけ
なので新しい速い波を生まず、CFL は変わらない。

### 5.2 離散式(ENC の重み規約で)

- (D a)_i = Σ_{k=1..8} sign_e(k) a(ke(k), i+die(k), j+dje(k)) · l8(k)/(dx·dy)
  (continuous の dh = mne·mn2dh(k) と同じ重み、Δt を除いたもの)。
- (G φ)_e = (φ_n − φ_c)/w8dr(k)(圧力項 tge と同じ差分)。
- β_i = (h_i^n)²/4(時刻 n で固定)。
- 行列は対角 1/β_i + Σ_k l8/(A·w8dr)、非対角 −l8(k)/(A·w8dr(k)) の
  9 点。A/β_i を掛けた形で対称正定値(エッジ重みが両セルで同じ)なので
  CG が使える。
- Version 1 では gv・wfrac・frw/fwd・σ を NH の作用素に入れない。これらが
  有効なセル・エッジは NH マスク外(静水圧)とする。

### 5.3 ソルバ(決定性・MPI)

- **Jacobi(第 1 実装)**: φ_old → φ_new の二重バッファ。1 掃引 =
  セルループ 1 回 + par_halo_cell(φ_new) 1 回。収束判定は残差の最大値を
  par_allreduce_max(順序不変なので §11 の規律内)。スレッド数・ランク数
  に依らずビット一致する。並列層は無変更。
- **CG(比較用)**: 内積は行部分和 → par_sum_rows(決定的総和)。
  1 反復 = 行列ベクトル積 1 回(セルループ + halo)+ 内積 2 回。
- **固定回数 Chebyshev + 幅 m ハロ(性能段階。§7)**: 反復内の通信を
  ゼロにする。実ケースで通信が律速と計測されてから入れる。
- 反復回数上限・許容残差は namelist(nh_itmax, nh_tol)。不収束は
  par_warn + 継続(研究機能。発散は既存の 250 m/s 判定に掛かる)。

### 5.4 必要な追加状態(NH ON のときだけ確保)

| 配列 | 形 | 用途 |
|---|---|---|
| uv0 | エッジ(1:4, 0:nx, jsh−1:jeh) | ステップ頭の u^n の複製(uv が単一バッファのため。§2) |
| phi, phi1 | セル(1:nx, jsh:jeh) | NH ポテンシャル(二重バッファ) |
| rhs | セル | βD a* |
| nhmask | 整数セル | NH 有効セル(0/1) |

合計はセルスカラー約 7 個分。NH OFF では allocate せず、呼び出しも
行わない(方針 8)。リスタート: Version 1 の NH 状態はすべてステップ内の
一時量で、保存対象なし(φ は現在状態から一意に再構築できる診断量)。
砕波スイッチ(§8.2)を入れる段階で eta_prev と breaking マスクを私有
save に加える。

### 5.5 NH マスク(エッジを静水圧に退化させる条件)

セル: x > 0、sw = 0(海域マスクは潮位強制の対象。§10 D6)、h ≥ nh_hmin、
gv = 1、wfrac = 1(幅河道外)、sdep = 0(σ 非適用)、breaking = .false.
(§8.2)。エッジ: 両セルが NH セル、かつ 堤防壁・海岸堤防・開辺境界面・
区間流入面・構造物面・skip8 でない。マスク外のセルは φ = 0(Dirichlet)
で、マスク境界のエッジは補正しない(エッジの有効度 = 両セルの有効度の
min)。優先順位は dry → h < nh_hmin → breaking → NH。

### 5.6 親モジュールへの変更(最小)

```fortran
  ! m_swflow_enc_calc(boundary_uvmn の後、continuous の前)
  if (nh_active) call nh_project(p, g, s, sx_mod)
```

に加えて init の `call nh_init(p, g, s)`、dispose の `call nh_dispose()`、
ステップ頭(halo 交換直後)の `if (nh_active) call nh_prepare(sx_mod)`
(uv0 の複製)の 4 箇所。interface は _adv / _diff と同じ分離インター
フェース + submodule 実装。NH の式・状態・ソルバはすべて submodule
m_swflow_enc_nh に閉じる。

mn1 の再計算に使うエッジ水深 he は calc_kth_flux の局所変数で、
hcap・dry_head_cap・σ の分岐を含む。流速比 mn1 = mn1*·(u^{n+1}/u*) で
済ませると u* ≈ 0 のエッジで破綻するため、**he の評価を純関数
edge_depth() に切り出す等価リファクタ(ULP=0 のコミット)を先に行い、
両者で共有する**(§11 Phase 2)。

### 5.7 中止・再設計の条件

次が必要になる場合は m_swflow_enc への組込みを中止し、m_swflow から
選択する別ソルバ化または見送りを選ぶ(NH OFF の不変性を守れなくなる
ほど複雑化した場合も同じ)。

- 全エッジを RK stage ごとに同期する、または各 stage で圧力を解く必要
- momentum のループ構造や continuous の全面変更
- 通常 SWE にも NH 用配列が常時必要、NH OFF で既存演算順序が変わる
- boundary / channel / structure の全面的な作り直し

§5 の方式はいずれにも該当しない。「反復ソルバそのもの」は、セルスカラー
1 個・決定的・NH OFF でゼロ追加を満たす限り中止条件にしない(§10 D2)。

## 6. 活性集合による適応化(適応 RK と同じ発想で「必要な場所だけ」)

### 6.1 なぜ単位がエッジでなくセル集合か

適応 RK がエッジ単位で済むのは、RK の作用が自エッジと両側 2 セルに
閉じているため。NH 補正 (1 − β∇²)φ = s は楕円型で 1 点の補正が近傍に
同時に効くが、影響範囲は有限で、Green 関数は exp(−r/√β) = exp(−2r/H)、
すなわち **e 倍減衰距離 H/2** である。数水深より遠くは事実上無関係
なので、適応化の単位は「検出セル+数 H の縁」の連結領域になる
(Δx = H/2 なら縁 4〜6 セル)。§4 の (b) は、この縁が隣 1 セルぶんしか
ない(反復の 1 回目)ことが不足の正体でもある。

### 6.2 手順(nh_project の中。静水圧 predictor の後)

1. 検出: 全セルで 1 パスの gather により
   χ_i = |β_i (D a*)_i| / (ā*_i + |β_i (D a*)_i| + ε)
   を求める。ā*_i は 8 エッジの |a*| の RMS(単一エッジ正規化との比較は
   検証項目)。長波では χ ≈ (kH)²/4 = z で、静水圧 Euler 加速度を NH 式に
   代入した残差の相対量 z/(1+z) と同じ量になる。一定水深・単色波では
   位相速度差 3% の水準が χ ≈ 0.06 に対応する。
2. 活性集合: χ_i > χ_on のセルを種とし、縁幅 nh_margin セル(既定は
   2H/Δx 程度 = 減衰距離の 4 倍)だけ 8 近傍で膨張させる。前ステップに
   活性だったセルは χ_i > χ_off で継続(ヒステリシス。初期候補は
   χ_on ≈ 0.06 / χ_off ≈ 0.04。線形波・孤立波試験で調整)。活性集合は
   §5.5 の NH マスクとの積。膨張はセルループを nh_margin 回(各回 halo
   交換 1 回)。
3. 反復は活性セルだけで解く(非活性は φ = 0 の Dirichlet、演算ゼロ)。
   補正は両セルが活性なエッジだけ。コストは活性セルの割合に比例する。
4. 決定性: χ は時刻 n と predictor の量だけから決まり、膨張は 8 近傍の
   論理和なので、走査順・スレッド数に依らない。MPI では**反復回数と
   収束判定(allreduce)を全ランクが同じ回数呼ぶ**。活性セルのない
   ランクも collective にだけ参加する(developer.md §5)。活性マスクは
   膨張ごとに halo 交換するのでランク境界で連結が切れない。

**効果**: 長波・氾濫・斜面流・河道の定常流では χ ≈ 0 で活性化せず、
NH ON のケースでも静水圧の領域にはコストが乗らない。活性領域の内側は
§5.3 の厳密解のままで、近似は縁の φ = 0 による exp(−2·縁幅/H) 程度の
切り捨てだけである。「全格子の反復」ではなく「検出した小領域の反復」に
なる。

### 6.3 検出量の選択肢

| nh_detector | 検出量 | 性質 | 位置づけ |
|---|---|---|---|
| 1(既定) | χ_i(上記)。長波で χ ≈ (kH)²/4 | 振幅に依らず「分散が効く場所」を測る。長波・定常流・一様流で 0 | ENCflow の主対象(背景流のある河川、洪水波と津波の重なり)で河川全体が常時活性にならない、という**実用上の理由**で既定 |
| 2 | 振幅型(Firdaus & Behrens 2026 の型): |η̃/d| > k_nh または |ũ| > k_nh(k_nh = 0.001) | 振幅検出。静水と乾燥地以外はほぼ活性 | 海の津波には実用的。比較用(§11 Phase 4b) |

|Dw/Dt|/g のような鉛直加速度の絶対量は、線形波では振幅 A/H に依存する
ため「振幅は小さいが kH が大きい(分散が重要な)波」を見逃す。副指標には
使えるが主検出量にしない。

追加パラメータ: f_nh_adaptive(0: マスク内全域、1: 活性集合)、
nh_detector、nh_chi_on、nh_margin(セル数。0 なら 2H/Δx から導出)、
nh_amin・nh_arel(種の下限)。f_nh_adaptive=0 は検証の基準(活性集合の
切り捨て誤差を測る比較対象)として残す。

**実装での改訂(2026-10-05。Phase 4b)**:

- **ヒステリシス(χ_off)は入れない**(stateless)。前ステップの活性
  マスクを持つとリスタート往復のビット一致に私有 save が要る。活性
  集合の縁が動いても φ = 0 の境界が動くだけで、chattering の害は
  観察されていない。必要になれば検討。
- **種の下限が必須**: χ は振幅に依らない比なので、陽解法の前駆ノイズ
  (丸め誤差レベルの短波。情報の伝播速度は Δx/Δt ≫ √(gH))まで拾い、
  閉じた水槽の孤立波で活性セルが 97% になった。絶対下限 nh_amin
  (1e-5 m/s²)と、そのステップの領域最大 |βDa*| に対する相対下限
  nh_arel(1e-3。allreduce max 1 回)を併用して、200 m 四方の孤立波で
  活性 54〜64%(縁 4〜16 セル)、全域解との差は補正量の 0.1〜0.3%。
- 振幅型の検出量(nh_detector=2)は |η/d| でなく |βDa*|/g > nh_chi_on
  とした(ENCflow には「静水深 d」の概念がない河川を扱うため)。

## 7. 通信の回避(固定回数 Chebyshev + 幅 m ハロ。性能段階)

§5.3 の素朴な実装は 1 掃引ごとにハロ交換と収束判定の allreduce を要する。
作用素が恒等項支配で影響距離が H/2 しかないことを使うと、**反復ループ内
の通信を点対点・collective ともゼロ**にできる。

**(1) 固定回数 + 幅 m の一括ハロ**

- Jacobi を m 回掃引した結果は作用素の m 次多項式 = 半径 m の固定
  ステンシルを 1 回掛けたものと同じ。幅 m のハロを一括交換しておけば
  m 回の掃引は帯内で閉じる(1 掃引ごとに有効行が 1 行ずつ縮むだけ)。
- 収束判定の allreduce は使わず、掃引数 nh_nsweep を固定する。必要回数は
  ε(§4.3)から事前に決まる。残差は表示用に dt_disp ごとに 1 回だけ
  集計する(par_allreduce_max。回帰比較の列には入れない)。
- 冗長計算は帯の両端 m 行(帯 200 行・m = 12 で約 1 割)。NH 専用の
  広ハロ配列(1:nx, js−m:je+m)は NH ON のときだけ確保する。
- 並列層に par_halo_edge(a, width) と同型の**幅指定つきセル交換**を
  1 本足す(逐次版は no-op。公開インターフェースは両版で一致。§2)。
  MPI に触れるので np=1,2,4 ULP=0 と -fcheck=all np≥2 を先に回す。
- m が帯幅に対して大きいときはハロ幅 w < m とし ceil(m/w) 回に分けて
  交換する(それでも collective はゼロ)。

**(2) Chebyshev 加速(内積なしで CG 並み)**

- CG は内積(allreduce)を毎反復に要するが、Chebyshev 半反復法は固有値の
  範囲だけ分かれば内積なしで同程度に収束する。対角スケール後の Jacobi
  反復行列のスペクトル半径は ρ = ε/(1+ε) で、ε は水深から決まる既知量。
  漸近収束率は σ = ρ/(1+√(1−ρ²))。
- ρ は活性領域の最大水深から見積もる。過大評価しても収束するだけなので、
  ステップごとの allreduce 1 回(活性セルの h の最大)、または初期の最大
  水深からの静的上限で足りる。

| Δx/H | ρ | Jacobi 掃引数(1e-4) | Chebyshev 掃引数(1e-4)= 必要ハロ幅 m |
|---:|---:|---:|---:|
| 1.0 | 0.41 | 10 | 7 |
| 0.5 | 0.74 | 30 | 12 |
| 0.25 | 0.92 | 109 | 24 |

**(3) 活性集合(§6)との組合せで通信相手も減らす**

- 活性セルが帯境界の 2m 行にない隣接ランク対は交換を省く。省くかどうかは
  両側が同じ情報(マスクのハロ)から対称に判定するので片側だけが待つ
  ことはない。
- collective がないので、活性セルのないランクは何もしない。必須の通信は
  ステップ頭の活性フラグ(隣接ランクへ整数 1 個)だけ。

**(4) ステップあたりの通信量(まとめ)**

| 項目 | 素朴な実装(§5.3) | 本節 |
|---|---|---|
| 反復内のハロ交換 | m 回 | 0 回 |
| 反復内の allreduce | m 回 | 0 回 |
| ステップ頭の交換 | マスク・右辺・β を幅 1〜2 | 同じ 3 量を幅 m で 1 回(3 成分を 1 配列に詰めて 1 回にできる) |
| uv^n の複製 | 帯内コピー(通信なし) | 同じ |
| 補正後の界面行 | par_edge_merge 2 回(既存) | 同じ |
| 残差の表示 | 毎掃引 | dt_disp ごとに 1 回 |

避けられないのは「活性領域が帯境界をまたぐ以上、幅 m のハロ交換 1 回と
界面行の merge は残る」こと。これは momentum が毎ステップ行う幅 2 の
交換と同じ種類・同じ回数で、反復の有無に依らない下限。

**(5) 第 2 段階の候補**

- 前ステップの φ からの warm start(掃引数 1/2〜1/3)。固定回数では結果が
  履歴に依存するので、リスタート往復のビット一致のために φ を私有 save に
  加える必要がある。まずは cold start(状態なし)。
- 帯分割は行を丸ごと持つので、x 方向の三重対角を厳密に解く line-Jacobi は
  ランク内で閉じる。9 点ステンシルの扱いが複雑になるため、Chebyshev で
  足りなければの候補。
- 補正の更新頻度低減(数ステップに 1 回)は分散項のサブサイクリングに
  なるので、精度の裏付けなしには採らない。

**位置づけ**: 本節は**性能段階(§11 Phase 4c)**の作業。まず §5.3 の
Jacobi(既存の幅 2 ハロ+収束判定)で正しさを固め、実ケース(河川遡上
津波・地滑り津波)で通信が律速と計測されてから移る。ノート PC〜
ワークステーション規模では不要な可能性が高い。移行時は Jacobi 収束判定版
との ULP 差(固定回数の切り捨て)を記録する。

## 8. 退化・切替・結合(砕波、乾湿、構造物、動く底面)

### 8.1 乾湿境界と構造物

- h < nh_hmin では p_nh = 0 として静水圧 ENC に退化させる。乾湿前縁・
  極浅水・砕波後の bore・遡上・氾濫は静水圧で扱う(砕波後を bore として
  扱う意味でも合理的)。想定する空間構造は「沖・河川内 = NH → 浅水化・
  砕波・極浅水 = 静水圧 → 遡上・氾濫・家屋被害」。
- 堤防・海岸堤防・ダム・カルバート・ポンプ・樋門・サブグリッド河道幅・
  家屋群(gv < 1)を含む特殊エッジ・セルは Version 1 では NH 対象外
  (§5.5)。最初からすべての構造物を NH 整合させない。

### 8.2 砕波(スイッチなしで先に検証し、保険として残す)

ENCflow は運動量保存形移流(スキーム 3)で段波・跳水の速度を正しく出す。
NEOWAVE も保存形移流で砕波を bore として扱う構成(明示的な砕波判定の
要否は本文で要照合)。hybrid Boussinesq/NSWE 系(Tonelli & Petti 2009;
Tissier et al. 2012; Kazolea & Ricchiuto 2018)では H/NH 切替の安定性と
格子依存が主要な難点と報告されている。したがって

1. まず**スイッチなし**で、斜面に入射する孤立波の砕波・bore 化を
   保存形移流 + NH のまま走らせて砕波位置・bore 速度・遡上高・格子依存を
   見る(静水圧 bore 単独の妥当性は test/dambreak で確認済み)。
2. 破綻する場合だけ保険として砕波スイッチを入れる。候補は SWASH 型:
   自由表面上昇速度 B = (∂η/∂t)/√(gh) が α(SWASH 既定 0.6)を超えたら
   砕波開始、8 近傍に砕波セルがあり B > β(0.3)なら前線の伝播、一度
   砕波したセルは ∂η/∂t < 0(波頂通過)まで静水圧を維持(二閾値 =
   ヒステリシス)。breaking セル自身とそれに接するエッジを静水圧にして
   1 セル幅の緩衝域を作り、連続的な遷移係数は入れない。砕波状態は
   old / new の二重バッファで更新し走査順に依存させない。dry セルでは
   breaking = .false.。砕波セルへ入るときは p_nh = 0、戻るときも
   p_nh = 0 から再開。4 近傍伝播と 8 近傍伝播は検証で比較。
3. 河川流がある場合、固定点で見た ∂η/∂t は Galilean 不変でない(背景流
   による波形移流でも変化する)。SWASH も ambient current 下での砕波
   スイッチを推奨していない。河川津波向けの第 2 候補として、津波到来前の
   背景流 U₀ を保持し (∂η/∂t + U₀·∇η)/√(gh) を使う背景流補正型を、
   無流・順流・逆流のベンチマークで固定点型と比較してから採否を決める
   (瞬間の全流速を U₀ に使うと波自身の運動まで除去するので不可)。
   波高比 H/h 型の breaker index はセル局所で閉じない(波頂・波谷・波群の
   認識が要る)ため診断量にとどめる。

品質基準: f_nonhydrostatic=0 で現行と ULP=0、f_nh_breaking=0 で砕波
機能追加前の NH 結果と ULP=0、砕波状態の更新が走査順・ランク境界に
依らない、切替時に非物理的な圧力 impulse・checkerboard が出ない、砕波
位置が格子方向に強く依存しない、砕波後の最大遡上高が格子細分化で収束。

**実装と検証での改訂(2026-10-05。developer.md §69.4)**: スイッチなしの
1 層 NH は砕波性の孤立波(Synolakis a/H = 0.28)を砕かずに遡上させ、
R/H が非砕波の遡上則に近い 1.59 になった(静水圧 0.39〜0.46、実験則
0.42)。SWASH 型 ∂η/∂t 判定はこの格子で砕波の開始に間に合わないため、
**既定の判定は水面勾配 |∇η| > nh_break_slope(局所・Galilean 不変・
状態なし)**とし、フルード数判定も選べる。砕波セルの周り
nh_break_margin セルまで静水圧にする。段波先端のスパイク(§68.7)を
避けるため f_hcap_upwind=2 と併用する。NH + スイッチの R/H = 0.62 は
実験則の 1.5 倍。原因切り分け(developer.md §69.6): 試験設定(Δx = H/4、
Cr 0.28)では時間刻みの誤差(+22%)と平坦部の数値散逸(−18%)が打ち消し
合っており、Δx/2・Cr 0.07 の収束値も 0.63(+50%)。これは砕波崩壊の散逸
不足(静水圧段波の跳躍条件だけではプランジング砕波の散逸に足りない)で、
Manning n = 0.01 を入れても +10〜20% が残る見込み。静水圧の 0.39 は平坦部
100 m の早期段波化による偶然の一致(収束値 0.34、波を脚の手前に置くと
0.42)。砕波を含む遡上高の定量評価には砕波域の明示的散逸(渦粘性・
ローラー)が必要で、それまでは ±20% 以上の不確かさを明記して使う。

### 8.3 動く底面(地滑り津波)との結合

固定床の NH を先に検証し、動く底面(bedslide の hb)は Phase 8 とする。
底面の鉛直運動 w_b = ∂z_b/∂t + u_b·∇z_b が NH の源項に入るが、現行の
時間ループは swflow → geomorph/bedslide の順なので、z の差分
(z^n − z^{n−1})/Δt を次の水理ステップに使うと forcing が 1 ステップ
遅れる。選択肢は (1) bedslide 側が底面速度を NH モジュールへ明示的に
渡す、(2) bedslide の predictor を swflow 前に計算する、(3) 時間中心化、
(4) 一段遅れを許容した簡易法を研究用に実装し誤差を定量化する。
m_main の順序は変えない方針なので (1) か (4) から始める。源項の定式は
moving-bottom-generated waves を主題とする Firdaus & Behrens / Jeschke
et al. を参照し、自前導出を避ける。

## 9. 先行研究と位置づけ(2026-10-05 調査。要文献照合 = 本文未読)

- **Firdaus, K. & Behrens, J.(ハンブルク大)** Locally Adaptive
  Non-Hydrostatic Shallow Water Extension for Moving Bottom-Generated
  Waves. IJNMF 2026(arXiv 2505.17025、1 次元)/ Two-Dimensional Locally
  Adaptive Non-Hydrostatic Extension of Shallow Water Equations. arXiv
  2606.27562(2026-06、2 次元)。**§5〜§6 と同じ発想の最も近い先行研究**:
  静水圧 SWE を predictor にし、射影法で楕円型問題を判定領域だけで解き、
  砕波は Froude 数で局所的に SWE へ切り替える。2 次元で計算量約 40%
  削減。判定量は静水圧 predictor の |η/d| と流速の大きさで閾値 0.001、
  判定領域を 1 要素広げる。離散化は RK-DG + 局所 DG、鉛直圧力は 2 次分布
  (Jeschke et al. 2017)。MPI は検索で確認できず。
- Stelling & Zijlema (2003)、Zijlema, Stelling & Smit (2011) SWASH:
  1 層 Keller-box で ω² = gHk²/(1+(kH)²/4)。砕波は局所的に静水圧へ
  (α = 0.6, β = 0.3; Smit et al. 2013)。
- Yamazaki, Kowalik & Cheung (2009)、Yamazaki, Cheung & Kowalik (2011)
  NEOWAVE: 1 層・スタガード・保存形移流 + ステップ末尾の圧力補正 =
  本提案と同じ構成(ENC は 8 近傍である点が違う)。ネスト格子内で NH。
- Berger & LeVeque (2024) GeoClaw-Bouss: SGN の楕円型系を AMR のレベル
  ごとに陰的に解く。領域を限る発想は細分化パッチ経由。
- 分散項を局所的に**切る**方向の切替(Tonelli & Petti 2009; Tissier et
  al. 2012; Kazolea & Ricchiuto 2018; FUNWAVE-TVD, Shi et al. 2012)。
  機構(マスク境界で φ = 0 として静水圧に落とす)は ON 方向にも同じ。
- 双曲型緩和(Escalante, Dumbser & Castro 2019; Muñoz-Moncayo &
  Ketcheson 2026): 楕円型解を回避する完全陽解法。**不採用**: 人工圧力
  波速で dt が 3〜10 分の 1 になり、統合モデルでは全プロセスがその dt を
  払う。活性領域だけサブサイクルすれば結局は反復法と同じ。
- ネスト格子・AMR で NH 領域を限る(NEOWAVE・GeoClaw-Bouss): ENCflow は
  単一格子が方針(§0-2・§0-9)。活性集合(§6)がその代替。
- 通信回避の技術(ghost zone expansion で複数反復をローカル化、
  Chebyshev 基底の通信回避 CG)は HPC 分野で確立した手法。分散波モデルの
  文脈での適用例は見つからなかった。

**位置づけ**: 「局所適応 NH」の概念は Firdaus & Behrens を先行研究として
明示し、本提案はその実用路線に乗る。差別化しうるのは (1) 分散性に基づく
検出量 χ(振幅型は振幅が小さくても kH が大きい波を見逃しうる)、
(2) Green 関数の減衰距離から決める縁幅と誤差見積もり、(3) 固定回数
Chebyshev + 幅 m ハロで反復内通信ゼロ・ランク数とスレッド数でビット
一致、(4) 8 近傍 ENC 格子・保存形移流・適応 RK との組合せと統合モデルへの
組込み、(5) 副次的にエッジ局所単一掃引が機能しないという否定的結果。
いずれも概念の優先権ではなく定量的な設計の違いで、採否は実用性で決める。

## 12. 理論課題

1. 「前進後退 Euler/適応 RK の静水圧 predictor + ステップ末尾射影」の
   完全離散の増幅行列と CFL(1 次元・一定水深・平坦床)。
2. ENC 8 近傍の Λ(k_x, k_y) の閉形式と異方性(p_diagratio 依存)。
   Phase 1 の計測と突き合わせる。
3. 一様流 U₀ 上の離散分散関係 (ω − U₀k)² と、RK 内移流固定の位相誤差の
   定量化(frozen advection は Doppler shift・wave–current interaction に
   誤差を出しうる)。
4. 変水深での β_i の非対称性の扱い(A/β_i を掛けた対称形で CG に載せる
   確認)と、NH マスク境界(φ = 0)での反射・不連続。
5. 砕波判定の Galilean 不変性(§8.2-3)。
6. Jacobi / 赤黒 SOR / CG の決定性とコストの比較(赤黒 SOR も色内で
   順序不変なので候補)。
7. Version 2 の底面勾配項の ENC 離散化と、g cos²θ 補正との二重計上回避。
8. 活性集合の縁(φ = 0 の Dirichlet)での切り捨て誤差の見積もり
   exp(−2·縁幅/H) の検証と、縁が波面を横切るときの反射の有無。検出量 χ
   の正規化(単一エッジ / RMS)。
9. 固定回数 Chebyshev の ρ の見積もり(活性領域の最大水深からの上限)と、
   変水深で ε が場所により大きく違うときの収束の一様性。ハロ幅 w < m の
   分割交換が結果を変えないこと(理論上は同値)。
10. 線形圧力分布(1 + (kH)²/4)と 2 次分布(1 + (kH)²/3)の位相速度
    誤差の比較(§3.2 の表)を、ENC の離散 Λ を含めて再評価する。
    保存形移流 + NH で砕波を bore に移行させられる条件(スイッチなしの
    成立範囲)。

## 15. 砕波域の散逸モデル(渦粘性)の設計案(2026-10-05 合意・実装済み。記録は developer.md §69.7)

### 15.1 必要性の根拠(developer.md §69.6)

砕波スイッチ(静水圧への局所切替)だけでは、砕波性孤立波(Synolakis a/H =
0.28)の遡上高が収束値で実験則の +50%(摩擦 n = 0.01 込みで +10〜20%)
になる。無傷の孤立波が斜面で静水圧段波になって遡上すると、静水圧 ENC
でも NH + スイッチでも R/H = 0.5〜0.6(dt 収束。段波の跳躍条件は Stoker 解で
正しい)で、プランジング砕波が失うエネルギー(遡上最大時の残存 E:
実験則相当 ≈ 0.5 E0 に対し 0.71 E0)を段波の跳躍条件だけでは表せない。
不足分 ≈ 0.2 E0 を砕波域で明示的に散逸させるモデルが要る。

### 15.2 候補の比較

| 案 | 内容 | 利点 | 欠点 | 判断 |
|---|---|---|---|---|
| A. 砕波域の渦粘性(Kennedy et al. 2000 / Zelt 1991 型) | 砕波と判定したセルに ν_b を与え、運動量の拡散項 ∇·(ν∇u) で散逸させる | 既存の拡散項(m_swflow_enc_diff。変係数保存形・離散最大値原理・安定上界クランプ)をそのまま使え、追加コードは ν_b 場と判定の滑らかな立ち上げだけ。文献の定数(δ_b = 1.2)を流用でき、自由パラメータは実質 1 つ | 陽解法の安定上界(ν ≦ Δx²/(dt·Σwd8) ≈ 0.5 m²/s @ Δx 0.25、dt 0.02)を超えるとクランプ。段波前面が滑る(なまる) | **推奨** |
| B. 表面ローラー(Schäffer 1993、Madsen 1997) | ローラー厚の幾何と輸送方程式で運動量を再配分 | 砕波後の set-up・流速分布の再現性が高い | ローラー先端角・厚さ・遅れ時間など状態と定数が多い。方針「過度に複雑化しない」に反する | 不採用 |
| C. 砕波セルの底面摩擦を増やす | 砕波域だけ n を大きくする | 最も単純 | 散逸が水深の薄い所に偏る(段波本体でなく舌で効く)。物理的根拠なし | 不採用(摩擦は実物の n として別途与える) |
| D. 静水圧への切替のみ(現行) | 段波の跳躍条件に任せる | 追加なし | §69.6 のとおり不足 | 現行の保険として残す |
| E. 鉛直 2 層 NH | 砕波近傍の鉛直構造を持つ | 砕波の開始が自然に出る | 多層化は plan §0 の範囲外。2 層でも砕波後の散逸には結局 A か D が要る(SWASH も HFA を併用) | 対象外 |

### 15.3 案 A の定式

- **判定**: 既存の砕波スイッチ(f_nh_breaking。既定は水面勾配 |∇η| >
  nh_break_slope、局所・状態なし)をそのまま使う。ν_b は判定量に対して
  滑らかに立ち上げる(段階関数だと ν の on/off がちらつく):
  B = clip((|∇η| − s_on)/s_on, 0, 1)(s_on = nh_break_slope。|∇η| = 2 s_on で
  B = 1)。縁 nh_break_margin のセルは B を線形に減衰させる(距離 d セルで
  B·(1 − d/margin))。
- **粘性係数**: Kennedy et al. (2000) の ν = B δ_b² h ∂η/∂t を、進行波の
  運動学 ∂η/∂t ≈ −c ∂η/∂x(c = √(gh))で局所・状態なしの形に置き換える:
  **ν_b = nh_break_visc · B · h · √(gh) · |∇η|**(nh_break_visc = δ_b² = 1.44 が
  文献相当の既定。0 で無効)。a/H = 0.28 の砕波点(h ≈ 0.5 m、|∇η| ≈ 0.3〜
  0.6)で ν_b ≈ 0.5〜1 m²/s。Zelt (1991) 型 ν = B h √(gh)(勾配なし)は
  判定の on/off がそのまま ν に出るので採らない。
- **作用**: 拡散項 ∇·(ν∇u)、∇·(ν∇v)(セル中心、エッジフラックス発散形)を
  静水圧予測子のエッジ加速度 tae に加える(既存 diff_edge の経路)。
  ν = ν_model(f_diffusion_term の値。無効なら 0)+ ν_b の和。射影(NH 補正)
  より前に入るので、砕波セルの散逸は予測子で完了し、射影には影響しない
  (砕波セルは静水圧なので射影は触らない)。
- **安定性**: 既存の陽解法クランプ(nu_max = 1/(dt·Σwd8))をそのまま適用。
  dt 0.02・Δx 0.25 では ν_b がクランプに掛かるが、その dt は §69.6 のとおり
  未収束であり、定量評価の dt(Cr ≲ 0.1)では上界が 4 倍以上になり掛からない。
  クランプ発動は既存の警告で見える。
- **エネルギー**: 散逸率 ε = ν_b h |∇u|²。段波前面(Δu ≈ 2 m/s、幅 ≈ 1 m、
  h ≈ 0.3 m)で ε ≈ 0.7·0.3·4 ≈ 1 W/m per m → 前面 2 m × 4 s で ≈ 8 J/m
  ≫ 不足分 0.46 J/m(= 0.2 E0)。桁は十分で、立ち上げ B と |∇η| の重みで
  実効値が決まる。過剰なら nh_break_visc を下げる。

### 15.4 実装の設計(単一ソース・無効時ゼロ追加)

- パラメータ: `nh_break_visc`(list_enc。既定 0 = 無効。> 0 で有効。
  f_nonhydrostatic=1 かつ f_nh_breaking=1 が前提。静水圧のみでの利用は
  第 2 段で検討)。
- ν_b 場: m_swflow_enc_nh が `nub(1:nx, jsh:jeh)` を持ち、nh_project の
  breaking_switch で担当帯 js..je に書く(判定は η のハロ 2 で評価できる)。
  拡散項 td は行 js−1..je+1 で計算し近傍 ±1 の ν を読むため、ν_b は
  js−2..je+2 が要る → **nh_project の末尾で par_halo_cell(nub) を 1 回**
  (有効時のみ。無効時は通信ゼロ)。1 ステップ遅れ(ν_b(n) を n+1 の
  予測子で使う)は判定のヒステリシスとして許容。
- 拡散項側: diff_init/diff_prepare の有効条件を `f_diffusion_term > 0 .or.
  nh_break_visc > 0` にし、diff_prepare の ν 構築後に ν = ν + nub を加える
  (f_diffusion_term = 0 のときは ν_model = 0 のまま nub だけ)。td の計算
  範囲・エッジ加速度への加算は既存のまま。
- 並列: nub は帯+ハロ 2 の確保範囲、集団通信は全ランク同一条件
  (nh_break_visc > 0)で実行。np=1,2,4 一致を検証。
- 検証契約: nh_break_visc = 0 で現行(NH + スイッチ)とビット一致。
  f_nonhydrostatic = 0 で全 reference ビット一致。
- save/restore: 状態なし(ν_b は毎ステップ再構築)。判定 (1) の brk の
  私有 save は従来どおり未実装。
