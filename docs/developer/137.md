## 137. 幅の極端に狭いサブグリッド河道のセルを、開口の動的振り替えと通水率で計算の外と同じに数える(占有率の細片。2026-11-27。利用者の依頼。挙動の変更)

### 137.1 依頼と問題

例題 examples/coarse_channel(§135.6)で、河道のポリゴンや高解像度マスクから占有率 f で作った河道マスク(f·Δ の
サブグリッド河道幅)に下限を付けないと、占有率が数 % のセル(河道の縁が角をかすめるだけの細片)が通水を落とすことが
分かった。全セルを占有率の幅にする作り方で、斜めの川(11.3〜33.7°、川幅 1.2〜3 セル、ずれ 0)の通水の幅 ÷ 川幅が、
下限 5 % で 0.92〜1.04 倍、下限なしで 0.73〜0.96 倍。例題は前処理の約束事(下限 5 %)で避けていた。利用者の依頼は、
開口の振り替えで小さいセルを塞がりとして数える案の検討。案を比べた上で(§137.3)、閾値型での実装を利用者が選んだ。

### 137.2 仕組み: 細片が通水を落とす 2 つの経路と、残る 1 つ

1. **開口の動的振り替え**(build_fwd・sblk。§68.14・§68.41): 辺の角のセル(軸の辺の斜め先、斜めの辺の側方)が計算の
   外なら塞がり率 1 で、その分の通過幅を辺へ返す。角のセルが細片だと、河床が同じで濡れているので塞がり率 0
   (開いている)と数えられ、通過幅が返らない。細片を通る道は細片の幅キャップ(min(W/面長, 1)。§18)でほぼ閉じて
   いるので、その分の通水が失われる。細片の幅を 0 に近づけても、細片の無い構成(計算の外 = 振り替えあり)に近づかない
   (不連続)。
2. **通水率(流速の正規化)**(build_cw・cw_cell・build_cwd。§18・§68.32): 幅を持つセルの流速は、周りの辺の幅キャップの
   開口和の比(通水率 cw)で割り戻して河道内の流速にする。隣が細片だと、その辺の小さいキャップが比に入って cw が
   下がり、隣の解像セル(幅 9999 m も幅を持つセル)の流速を過大にして摩擦を増やす。今回の検討で初めて分かった経路。
3. **移流項(残る)**: 移流項の近傍の判定(流向面の風上の供給元・側方面の平行リンクなど)は、細片を濡れた隣として
   数える。幅によらない(test/sliver の格子に沿う帯で、細片の幅 0.01 m と 0.001 m の差が同じ −14.6 mm、スキーム 1
   では +37 mm)。今回の規則は 1 と 2 だけで、3 は残る(§137.6)。

切り分け(examples/coarse_channel の全セルの作り方、ずれ 0。通水の幅 ÷ 川幅。下限なし / 下限 5 %):

| 構成 | 18.4°・川幅 120 m | 26.6°・川幅 200 m | 33.7°・川幅 120 m |
|---|---|---|---|
| 今まで | 0.726 / 0.957 | 0.900 / 1.005 | 0.883 / 1.039 |
| 振り替えだけ閾値型 | 0.854 / 0.957 | 0.959 / 1.005 | 0.941 / 1.039 |
| 振り替えと通水率を閾値型(採用) | 0.919 / 0.957 | 1.026 / 1.005 | 1.010 / 1.039 |
| 開口の動的振り替えを切る(参考) | 0.665 / 0.649 | 0.854 / 0.870 | — |
| 移流項(河道)を切る(参考) | 0.909 / 1.054 | 0.935 / 1.061 | — |

振り替えを切ると下限のあるなしの差は 0.016 に縮み(§135.6)、移流項を切っても差は残る(0.12〜0.15)。

### 137.3 比べた案(作業用ビルドに環境変数で切り替える試作を入れて比べた)

規則はどれも、幅を持つ河道のセルどうしの関係だけに掛ける(角のセル・隣のセルと、比べる側のセルがすべて河道のセル)。

| 案 | 中身 | 結果 | 判断 |
|---|---|---|---|
| 閾値型(相対、5 %) | 角・隣のセルの幅が、比べる側のセルの幅(面長で頭打ち)の 5 % 未満なら閉じた開口と数える | 下限 5 % 以上のケースは変わらない(作りから。試作で 114 件ビット一致)。下限なしの斜めの川: 1.2 / 2 / 3 セルの中央値 0.80 / 0.93 / 0.93 → 0.95 / 0.96 / 1.00 倍。下限のあるなしの差の最大 0.230 → 0.069(50 % 以上を解像 + 残りの作り方は 0.305 → 0.095)。屈曲(全セル、下限なし)の背水 3.7 / 4.4 / 4.7 → 3.2 / 2.8 / 3.0 cm(細かい格子 2.5 / 2.9 / 2.6 cm)。全検定と coarse_channel 以外の全例題で該当する箇所 0 | **採用** |
| 連続型(相対) | 幅の不足分 1 − q_d/q_ref をそのまま塞がり率に、通水率では重みに | 下限のあるなしの差は 0.061 に縮むが、斜めの川の全セルの作り方 1.6〜3 セルが 0.90〜1.03 → 1.02〜1.13 倍、50 % 以上を解像 + 残りの 2 セルが 1.03 → 1.10 倍、45° 2 セルが 1.17 → 1.23 倍、屈曲(全セル)が細かい格子から −3.8〜−5.8 cm。半端なセルの通水の損失と、横に並んだ半端なセルの過大(§135.3)が打ち消し合っていて、損失だけを消すと過大が表に出る。confluence_backwater(粗い格子)・catchment_metal・paddy_dam の合流部が変わる | 不採用(過大の側と一緒に考える。handoff 00an) |
| 閾値型(相対、15 %) | 閾値を 15 % に | 45° 川幅 1.2 セルが 1.01 → 1.39 倍(5〜15 % のセルを閉じると帯の形が変わる)。屈曲(全セル、下限 5 %)が細かい格子から約 −2 cm | 不採用(閾値の位置に敏感) |
| 自分の幅 | 角のセルの幅だけで 1 − min(W_d/面長, 1) | 一様な幅の河道まで変わる(test/chichibu の幅つき 4 連結の河道で 8,956〜34,844 か所)。幅セルどうしの辺を振り替えで太らせるのは §68.38 の二重補正(発散)と同じ形 | 不採用 |
| 絶対閾値 | 角のセルの幅が格子幅の 5 % 未満 | 細い沢そのものの幅が小さい計算(examples/catchment_metal)で 185〜201 か所が変わる(一様な幅の細い河道を閉じてしまう) | 不採用(比べる側との比で測る理由) |

閾値型の細部: 通水率の側で比べる幅を「セルの自然幅 dx·dy/L_ch」で頭打ちにすると(試作 cw4)、帯の中のセルは自然幅が
小さく(隣が多いと 20 m 前後)、数 m の細片が閉じず、18.4° 川幅 120 m の下限なしが 0.854 倍に留まった。振り替えと
同じ「辺の面長」で頭打ちにすると 0.919 倍。2 つの判定を同じ物差しにそろえた。

### 137.4 決めた規則と実装

- 定数 p_wclose = 0.05(m_swflow_enc。独自)。`width_closed(wx, wref, face)` は wx > 0 かつ
  wx < p_wclose·min(wref, face) で真。幅情報なし(wx <= 0)は解像扱いで閉じない。比べる側も幅情報なしなら huge。
- **角のセル**(sblk。build_fwd だけが渡す io, jo があるとき): 辺の両端 c・o と角のセル d(側方 Neumann の鏡像の後)が
  すべて河道のセルで、W_d < p_wclose·min(W_c, W_o, 道 c→d の面長)なら塞がり率 1(計算の外と同じ)。面長は、
  道が軸の面なら dy・dx、斜めの面なら dx·dy/dr。地形による塞がり率より先に判定する。
- **隣のセル**(narrow_nb。build_cw・cw_cell・build_cwd が同じ判定を使う): 自セル c の隣 n が幅を持つ河道のセルで、
  W_n < p_wclose·min(W_c, 辺の面長)なら、壁の辺と同じく通水率の開口和(分子と分母)から外す。3 つの開口和を同じ式に
  保つ条件(§26・§68.32)。
- 一様な幅の河道(1 セル幅の線の河道、4 連結の階段、等分の帯)は、比べる側と同じ幅なので変わらない。
- 費用: fn_width のない計算は判定が走らない(sblk の present(io) と chn%have_width の分岐だけ)。幅のある計算は、
  角・隣ごとに幅の比較が 1 回増える。試作(毎回の判定を関数で書いた版)で計算時間の増え方は 0〜7 %(測定のばらつき
  の範囲)。
- MPI: 読むのは帯+ハロの wrw・rw(sblk がすでに読む s%z、build_cw の隣と同じ範囲)。fwd・cwd は各ランクが同じ式で
  冗長に作るので通信は増えない。restart の書式は変えない(fwd・cwd の値が変わるだけ)。
- 試作(閾値型、振り替えと通水率)と出力ファイルまで一致することを、coarse_channel の下限なし 2 件と屈曲 1 件で確かめた。

### 137.5 検証

- **新しい検定 test/sliver**(Check_sliver.py): 45° の 1 列に 1 セルの解像した河道(幅 9999 m)の斜めの段の角に幅
  0.01 m の河道のセルを添えた構成と添えない構成で、河道セルの水位の差の最大 0.7 mm(この規則の前の版は 1,216 mm)。
  格子に沿う 2 行の解像した河道に幅 0.01 m のセルの行を添えると、区間の 20〜80 % の差の最大 17.5 mm(前の版 329 mm。
  残りは §137.2 の 3)。添えない構成の水深はマニングの等流水深と 0.05 % 以内(45° は斜めの自然幅 70.7 m で数える)。
- **静的な照合**: 試作の照合スクリプトで、規則が働く角・隣の関係を数えた。幅を使う全検定(bankhalo、bedmix、bendloss、
  wallpond、gwwidth、gwsect、wqstruct、chichibu の幅つき)と例題(catchment_metal、paddy_dam、confluence_backwater と
  coarse_check)で 0 か所。これらはビット一致する(規則が働かなければ演算は変わらない)。
- **回帰**(gfortran 13.3・-Ofast、逐次): 夜間の全回帰の reference つき 25 ケース(chichibu・chichibu_cond・paddy を含む)、
  CI の検定型 20 ケース(bankhalo・wallpond・vchannel など)、幅を使う gwwidth・gwsect・wqstruct・bedmix の計 49 ケースが
  すべて合格(reference との比較を含む。規則が働かない計算は演算が変わらない)。旧版の実行ファイルとの出力の
  バイト比較(wave・dambreak、幅を使う wallpond の 4 ケース・bankhalo・gwwidth)で全ファイル一致。test/sliver は逐次・2 ランク・
  4 ランクで合格(Run_MPI.sh は 1 ランクと Log・水位・水深がバイト一致)。
- **MPI**: 規則が働く coarse_channel の下限なしのケース(26.6°・川幅 200 m・全セル)と test/sliver の dg_tiny で、
  1・2・4 ランクの出力が逐次とビット一致。-fcheck=all の MPI ビルドの 2 ランクで同じ 2 ケースが完走(配列の範囲外の
  読みなし)。
- **coarse_channel**: 規則が働くのは 897 ケースのうち 31 件(下限なしの 28 件と、「解像 n 列 + 残りの幅」の帯で残りの
  幅が数 m になる 3 件: 11.3° の川幅 120・200 m、33.7° の川幅 1,000 m)。下限なしの 54 件と「解像 n 列 + 残り」の 31 件を
  計算し直すと、変わったのはこの 31 件だけで、残りはビット一致した。下限なしの結果は試作と出力ファイルまで一致。
  「解像 n 列 + 残り」の 3 件は、残りの行が閉じて解像 n 列と同じになった(0.55・0.78 → 0.63・0.81 倍、0.96 → 0.98 倍)。
  例題の README・図(occ_sens・oblique・wide)を更新した。

### 137.6 残ること・確かめていないこと

- **移流項の濡れた隣**(§137.2 の 3): 細片の幅によらず、細片を濡れた隣として数える分が残る(格子に沿う帯で水深の
  0.6 %)。移流項の近傍の判定で細片を「壁の向こう」と同じに扱う手はある(§134 の walled のフックを幅の比にも広げる)が、
  移流項の規則を変える挙動の変更なので設計の議論が先(handoff 00an)。
- **下限のあるなしの差は残る**: 最大 0.069(全セル)・0.095(50 % 以上を解像 + 残り)。例題は下限 5 % を推奨のまま。
- **5 % は独自の値**で、coarse_channel の直線の帯と円弧(水深 ÷ セル幅 0.035)でしか確かめていない。15 % で 45° の帯が
  大きく変わったように、閾値の前後で扱いが飛ぶ不連続は残る(前処理の下限から計算本体の中へ移っただけ)。
- 実際の河道ポリゴンの細片、解像した川に幅の極端に狭い水路が合流する所(該当する検定・例題がない)。
- 連続型は、横に並んだ半端なセルの過大な通水(§135.3。handoff 00an)と一緒に考える。

### 137.7 出典と独自の部分

開口の動的振り替え(§68.14・§68.41)と通水率(§18・§68.32)は ENCflow 独自の規則で、この節の「幅の比で閉じた開口と
数える」拡張と閾値 5 % も独自。閾値の値は、例題 coarse_channel の下限の感度(5 % と 15 % でほぼ同じ、§135.6)と、
計算本体に入れたときの 15 % の副作用(§137.3)から選んだ。
