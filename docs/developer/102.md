## 102. 運動量保存形移流の流入面の風上値を、面のセルへ実際に水を運ぶ全リンクの流量で重み付けする f_advection_donor = 2(逓減期のハイドログラフの跳ねの原因と対策。2026-11-06 設計合意・実装。2026-11-07 に後継の 3 を追加して 2 は廃止。同日 3 に側方面の乾湿判定の連続化を追加。2026-11-08 に 3 の流向面の判定を薄い供給元に限定。2026-11-09 に 3 を既定に)

(節の番号: 開発ブランチでは §100 として書いたが、メインに別の §100・§101(水面の勾配の可変の重力 g′、混合体流動の
抵抗則)が先に入ったため、2026-11-08 の合流で §102 へ繰り下げた。それより前のコミットメッセージの「§100」はこの節を指す。)

**現象**(tutorials/chichibu Step 3、dd = dv = 0.001 の既定): 測線 4 の逓減部 t = 232 min に 1 分で
+435 m³/s の跳ね(3069 → 3504)があり、その後 2 分周期の減衰振動が 10 分続く。316 min にも小さな
跳ね、測線 3 にも 116・204 min に跳ね。Step 4 の dd = dv = 0.0001 では消える(dd だけでも消え、dv
だけでは消えない。dt の半減・p_adprunge_thresh 1.1 も効かない)。利用者の問い「原因と、dd を変えずに
解決する方法」(2026-11-05)。他のモデルでも逓減期に見る荒れとの関係も。

**原因**(1 分・6 秒刻みの分布出力と、計測印字を入れた作業用ビルドで特定。2026-11-06):
- 跳ねは測線 4 の 2 セル上流、fill DEM の平坦区間(z = 141.2 m が ix 214〜219 に続く「池」)の入口の
  辺 (214,39)→(215,39) で始まる。ここへの流入は (213,40)(z 142.5、|V| 3.6 m/s)から斜め。
- 引き金は (214,39) の西隣 (213,39): 河道マスク上だが標高 167.9 m と池より 26.7 m 高く、雨の残りの
  水膜(1 mm 前後)が乗っているだけの河岸セル。水膜は 215 min 1.15 mm → 231 min 1.00 mm → 249 min
  0.74 mm と減り、t = 231.1 min(it = 2311)にちょうど dd = 1 mm を割る。
- 運動量保存形移流(§68.6)の検査体積は、面 n(= (214,39) の中心)の質量流束 q_n(セル平均流量の
  k 方向投影 = 全リンクの寄与の合計、−15.0 m²/s)に、線 k 上の上流リンク (213,39)→(214,39) の流速から
  作った風上値 ū_n を掛ける。供給元の判定 donor_ok は cell_ok = 「h ≥ dd」。切り替わる前、上流リンクは
  水膜の 1.6 cm/s で実流量 1.6e-5 m²/s(面の流束の百万分の 1)なのに、その流速が ū_n に使われ、
  q_n·(ū_n − u_e) が +0.030 m/s² の減速(東向きの流れに対するブレーキ)になっていた。池の水面勾配の
  駆動(0.65 m/200 m × g = 0.032 m/s²)とほぼ同じ大きさで、平坦な池の中に 1 セルで 0.6〜1.2 m の
  水面段差(90 min 0.60、120 min 1.00、180 min 1.23、231 min 0.65 m)を作って水を堰き止めていた。
- it = 2311 で donor_ok が偽になり ū_n = u_e。ブレーキが 1 ステップで消え(tae 0.030 → 0.0018 m/s²)、
  u_e は 6 ステップで 2.39 → 2.93 m/s に加速、(214,39) の水深は 1 分で 6.65 → 6.07 m(0.58 m × 4 万 m²
  ≈ 2.3 万 m³ ≈ 390 m³/s)。これが +435 m³/s。その後の 2 分周期の振動は堰き止めが外れた池の水面動。
- dd を小さくすると消えるのは先送り: Step 4(dd 1e-4)でも 231 min に同じ 0.65 m の段差があり、水膜が
  0.1 mm まで減るには数時間かかるので切り替わりが計算終了後に来るだけ。Step 4 のピーク(5391)にも
  堰き止めは含まれる。dv は摩擦の水深下限でこの判定に関係しない。dt・RK も関係しない(h の論理条件)。
- 同型の事象: 1 分出力で「dd を下向きに横切るセルが、300 m³/s 以上を運ぶ辺の線 k 上の上流供給元に
  なっている」事象は 61〜360 min に 259 件(推定ブレーキ 0.03 m/s² 超が 127 件)。4 つの跳ねの時刻は
  すべて一致する(231 min (213,39)→(214,39)、315 min (220,37)→(221,38)、115〜116 min (146,103)→
  (146,104)/(147,104)(測線 3 の河道セル)、203〜204 min (151,103)・(146,105)→(147,104))。
- 切り分け(Step 3 の設定): f_dry_head_cap = 0 は数値まで同一(無関係)。f_advection_donor = 1 は
  (213,39) が河道マスク上なので除外されず、跳ねは 236 min に +527 で残る(ピーク +9%)。スキーム 1 は
  232 min の跳ねはないが、同じ引き金で 233・235 min に +94・+75、dd 1e-4 では消える(get_diff_v1 の
  `h < dd の隣接セルを勾配ステンシルから外す` 規則が同じ型のスイッチ。8 近傍の平均と辺の両セルの
  平均で薄まるため小さい。段差は 0.11 m)。旧版の教材(スキーム 1 が既定)の Step 4 で dd・dv を 1/10
  にして跳ねと ex_flux を抑えたのも同じ現象。拡散波(f_govequation = 1)は移流項がないので出ない。
- 一般化: 薄いセルの乾湿判定(h ≥ dd)は、そのセル自身の流量だけを変えるなら無害だが、隣の深い辺の
  運動方程式の項のスイッチになり、切り替わる項が深い辺の流量に比例するとき跳ねになる。運動量保存形
  移流の「質量流束はセル平均(全方向の合計)、流速は線 k 上の 1 リンク」という取り方が、線上のリンクが
  ほとんど水を運ばない河岸の水膜でも面の全流束にその流速を掛ける不整合の元。§68.8(壁・乾床の
  供給元)・§68.18(浸水した谷底の供給元 = f_advection_donor = 1)はこの不整合の個別対症で、どちらも
  二値の判定を持つ。逓減期に集中するのは、雨の後に斜面・河岸の水膜が一斉にゆっくり減って dd を次々に
  横切るから。乾湿の閾値が風上・供給元の選択に入る 2 次元モデル一般に起こりうる(一般論。個別の
  モデルは未確認)。
- 線流量 M, N を予報変数にする古典形(保存形・風上)では、面の運動量流束が風上側の M と u の積
  (同じセル)なので薄いセルの寄与は自分の流量に比例し、切り替わらない(跳ねは起きない)。ただし
  西の面から入る x 運動量はほぼ 0 のままなので、ENC の切り替え前と同じ減速を常に受ける = 堰き止めが
  恒久的(§68.8 で測った「屈曲 1 回あたり 0.55 m の損失水頭」と同根)。ENCflow の STG(f_gridsystem = 1)で
  実測しようとしたが、Step 3 の設定でマスクの有無によらず初期化直後の A0000 の出力(m_output.f90 の
  output_areafactor が ENC の河道モジュールの状態 chn を参照)で segfault する(handoff 00n)。

**設計**(案 B。scratchpad の試作 B1〜B6 で切り分けた。設計メモの正本は本節):
- 流入面(面 c で q_c ≥ 0、面 n で q_n < 0)の風上値 ū を、面のセル X(c または n)へ**流れの上流側
  半平面から実際に水を運ぶリンク l**(実流量 Q_l = −qlk > 0、ê_l·σk̂ > 0。ê_l は供給元 d から X へ向く
  単位ベクトル、σk̂ は面の流れの向き)の流量を重みに、各リンクの水の k̂ 成分 ũ_l の u_e からの偏差を
  平均して決める: ū = u_e + Σ_l w_l Q_l (ũ_l − u_e)/Σ_l Q_l(流入リンクがなければ従来の線 k の値)。
- ũ_l: リンク l 自身の線上で、X へ向かう速さ s_l(= −uv_l)、その上流のリンク、線の続きのリンクから
  従来と同じ MUSCL で面値 f_l を作り、リンクの水の速度ベクトルは供給元セル d の流量ベクトル (m,n)_d に
  平行とみなして k̂ 成分へ射影する: ũ_l = f_l·((m,n)_d·k̂)/((m,n)_d·ê_l)(|射影| ≤ |(m,n)_d|/((m,n)_d·ê_l)
  ≤ 2 で頭打ち。供給元の流量がほぼ 0 か ê_l 成分がないときはリンクに沿う水として f_l·(ê_l·k̂))。
- w_l: 供給元の流向 d̂ が σk̂ から 45° 以内なら 1、90° で 0 のランプ min(1, √2·max(0, d̂·σk̂))。
- 横(直交)・下流側からのリンクは分母にも入れない(横から入る水の運動量の欠損は側方面の規則が担う)。
  線 k のリンク自身も集合に入り、その ũ_l は従来の線 k の MUSCL 値に一致する。乾いた・薄い供給元は
  Q_l が小さく寄与が消えるので、cell_ok の二値は結果に効かない。流出面は従来のまま(S&D の流儀 =
  持ち出しは検査体積自身の風上値)。
- 極限での性質: 一様流(任意の向き)では全リンクで ũ_l = (u,v)·k̂ = u_e → 移流項 0。1 次元(y 一様)
  の流れでは、斜めリンクの線上 MUSCL が軸の MUSCL と同じ x の標本点を持ち、射影の係数 √2 で軸の値に
  戻る(横から見える NE 辺の NW リンクは集合から外れるが、残る W・SW が同じ値)→ 従来の ū と一致。
  乾いた河岸の 90° 屈曲(E → N)は W リンクが直交なので外れ、線 k の供給元(S)が乾いていれば u_e =
  §68.8 の無損失と同じ。階段状の河道(E, NE, E, …)は各セルの平均流向が 22.5° で射影の比が 1 → 無損失。
  池の入口(秩父)は斜めから 3.6 m/s で入る水の E 成分 2.5 ≈ u_e 2.4 → ブレーキなし。河岸の水膜は
  Q_l が百万分の 1 で効かず、dd の横切りで何も変わらない。
- 不採用にした変種(試作): B1「向きを変えても速さを保つ」(ũ_l = f_l·|(m,n)_d|/((m,n)_d·ê_l))は
  斜めの辺で一様流の恒等性が壊れ(x 方向の一様流で NE 辺に u が注入される)、dambreak が 3.3 s で
  発散。B0「横・下流側からのリンクを幾何で中立(u_e)にして分母には入れる」は 1 次元で NE 辺の
  NW リンク(流量の 29%)が中立になり、斜めの辺の移流項が軸の 71% になって段波背後に +0.72 m。
  B2「全リンクを射影」は 1 次元を保つが横流入(bendloss lat1r)で側方面と欠損を二重に数える
  (水深比 1.165)。B5「流出面にも同じ加重平均を使って面の値を一価にする(保存形)」は、流出面の
  持ち出しが下流セルの横からの遅い水に引かれ、検査体積ごとに「輸入で払い、輸出で戻す」が連鎖して
  横流入の水路が亜臨界化(lat1r 3 km で水深比 1.52、Fr 0.96)、秩父のピーク −8〜−11%。B6(w_l なし)
  は B4 と 2% 以内で、zigzag の区間平均水深が +1.2%(B4 は +0.2%)。
- 対症の案 P2ε(線 k の供給元のリンクの実流量が面のセルへの最大の流入リンクの ε = 0.1 未満なら
  風上値を u_e へ寄せるランプ)も跳ねを消す(回帰の変化は一致 24・変わる 18 で薄い水膜のケース以外は
  1% 以内、計算時間 +0.3%)が、ε が経験値で不整合の元は残るので、定式を直す本案を採った。

**実装**(m_swflow_enc_adv.f90 の adv_prepare_mc、list_enc.f90、m_swflow_enc.f90):
- `&list_enc` の `f_advection_donor = 2`(0: 従来、1: 河道セル限定 §68.18、2: 本案)。無効時は
  inflow_face_value を呼ばず厳密に不変(回帰規律 2)。既定は 0 のまま(利用者の指示 2026-11-06
  「B4 を選択式で実装して」)。2 は河道マスク不要。スキーム 1 では無効果(par_info)。
- 内部手続き `uvk8(ci, cj, kk)`(uvk の 8 方向版。ke8/sgn8、鏡像は uvk と同じ)と
  `inflow_face_value(ci, cj, kk, sig, ue, ub, ok)`。面 c(q_c ≥ 0)と面 n(q_n < 0)の流入の分岐で先に
  呼び、ok なら ū に使い、偽なら従来の分岐(donor_ok → MUSCL / u_e)。
- 読む量: qlk(実流量。時刻 n の mn)、uv(エッジ幅 2 の交換済み)、s%m・s%n(セル幅 2)、g%x・g%sw。
  ステンシルは従来と同じ範囲(面 n の upup = 行 j−3 = jsh−1、面 c の upup = 行 j+2 ≤ jeh。リンク l の
  線上の upup は面のセルから 2 歩で、線 k と同じ深さ)。ハロ幅・通信は変えない。書き込みは
  tx%tae(k, ie, je) だけ。
- コスト: 面ごとに 8 リンクの走査と、流入リンクごとに uvk8 × 3・face_value・射影。chichibu Step 3
  (6 時間、OpenMP 2)で 38 → 49 s(+30%)。線上の MUSCL 値・実流量・供給元の流向は k̂ によらないので、
  セルごとに 8 リンク分を 1 回だけ作れば重い部分が 1/8 になる(最適化は未実施。handoff 00n)。

**既定化の判断基準の見直し: 格子収束の条件を外し、正解のある理想化検定で判断する**(2026-11-09。利用者の指摘「格子を

- (2) を外した理由: (2) は、0 の減速が格子を細かくすれば消える誤差(打ち切り誤差)だという前提の基準だった。実際の減速は
  ラスタ河道の段ごとに生じる O(1) の誤差: 流向面の質量流束は深い河道セルのセル流量の投影(adv_prepare_mc の qc)で、
  風上値は線 k の上流のエッジから取る(供給元の水深が dd 以上なら河岸の水膜でも使う)ので、河道が 1 セル横にずれる段
  ごとに q_c (u_e − ū) の減速が 1 か所でき、その大きさは Δx によらない。1 セル幅の河道では段の数が 1 km あたり 1/Δx に
  比例して増え、どの段も全流量が通る。河道と河岸の水深の変わり目が数セルで表されるまで減速は消えないので、200〜50 m
  では 3 が正しくても差は縮まない。一方、0 の減速の一部が本物の損失(谷底の氾濫原との運動量交換など)でも縮まないので、
  縮まないことは 3 の正否を判別しない。

  収まる間は細かくするほど減速は増え、流れが広がると面の数の増加と割合の低下が打ち消し合う。0 との差がほぼ一定
