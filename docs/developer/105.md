## 105. 浅水方程式の入門ページと `f_govequation = 1` の呼称(2026-11-11。利用者の依頼)

**経緯**: チュートリアルと例題に「力学波・拡散波・運動波」「移流項」などの語が、その場の短い説明だけで何度も
出てくる。利用者の依頼で、浅水方程式そのものの入門ページ users_guide/shallow_water.md(日英)を、§34.2 の
「入門ページ」の第 2 号として浅水流計算の章の下に置いた(第 1 号は courant.md)。依頼の範囲は、方程式と各項の
名称・物理的な意味(圧力項と重力項の分離型・一体型を含む)、項の組み合わせによる力学波・拡散波・運動波と局所
慣性方程式、それぞれが使われる現象、力学波がいつも採用されるわけではない理由(移流項の計算の難しさ・安定性・
計算コスト)、ENCflow が力学波を既定にする理由(方針 1)。作業中の追加の指示で、追補(サンブナン式、水理学の
「不定流の式」など実質同等の式の呼び名の対応)、静水圧近似の限界(test の検証ケースを参照)、常流・射流(短く)を
加えた。入門の立場を保ち、導出はせず、文献に基づく一般論を主にする(試算は補助)。

**ページの構成と図**: 1 浅水とは、2 連続式と運動方程式、3 各項の名前と意味(勾配の形、分離型・一体型)、
4 現象ごとの項の大きさ、5 フルード数、6 力学波・局所慣性・拡散波・運動波、7 現象と式の対応と使い分けの目安、
8 力学波がいつも使われるわけではない理由、9 ENCflow の既定と `f_govequation` との対応・実例・残る限界、
10 静水圧近似と水深平均の限界、11 まとめ、追補(A.1 サンブナン式、A.2 等流・不等流・不定流、A.3 分野ごとの
呼び名、A.4 ENCflow の文書の表記)。節の先頭に `<a id>` を置き、日英で同じアンカー(#terms・#wave-models・
#phenomena・#encflow・#hydrostatic・#names など)から参照する。図は docs/figs/guide/fig_shallow_water.py が
描く 3 枚(見取り図と力、5 項と近似ごとに残す項、4 つの場面の項の大きさ。日英の PNG・SVG)と、test/nhwave・
test/nhbore の既存の図の再掲。4 節の項の大きさは同スクリプトの `situations()` が計算する桁の試算(独自。
`python3 fig_shallow_water.py` で表を出す)で、1 行目は examples/benchmark/v-shaped の斜面の条件。

**`f_govequation = 1` の呼称(利用者の決定)**: 実装(m_swflow_enc の初期化で `f_advection_term = 0`・
`f_pressure_term = 1`。calc_kth_flux の半陰の更新 uve1 = (uve0 + (tae + tge)·dtl)/(1 − tfe·dtl) は変えず、
移流項 tae を 0 にするだけ)では局所項 ∂u/∂t が残る。文献の分類では、これは拡散波(局所項も移流項も省き、
流速が水面勾配から代数的に決まる放物型の式)ではなく局所慣性方程式(Bates ら 2010)である。`= 2`(運動波)も
同じく局所項が残る。作業中に「移流項を省いた局所慣性方程式を拡散波と習慣的に呼ぶのは良くないか」との問いが
あり、次の 3 案を示して (1) に決まった。
(1) **定義の箇所だけ改称し、本文は注記する**(採用): users_guide(swflow.md の表と本文・パターン別の推奨値、
advection.md、advection_donor.md、入門ページ)と List_samples/list_sysparam.txt(日英)では「局所慣性(移流項
なし)」を呼び名にして「従来の表記は拡散波」と添える。チュートリアル・例題・test の README は、初出に「厳密には
局所慣性方程式」の注記と入門ページへのリンクを置き、本文の「拡散波」「移流項なし」はそのままにする。図の
ラベルと各 param ファイルのコメント(DifWE)は変えない。
(2) 全面的に改称する(本文・図のラベル・param のコメントまで。図の描き直しに再計算が要る)。
(3) 呼び名は変えず注記だけにする。
`= 2` の呼び名は運動波のままにし、局所項が残ることを swflow.md の表と入門ページ 9 節に書いた。コードの識別子・
コメント(DifWE・KinWE)と計算は変えていない(src の変更なし)。

**swflow.md の推奨値の表の訂正**: 「広域・長期(コスト優先)」の行は `f_govequation = 1` を「コストを落とす」
手段に挙げ、「拡散波は慣性を無視する」と書いていた。局所項は残り、時間刻みの上限(クーラン数)も変わらない
ので、短縮が小さいこと(下の計測)と、表せないのは移流項が担う射流・跳水・段波であることに書き改めた。

**確かめたこと(このページのための計算。回帰テストの対象外。gfortran 13.3、make.inc の既定)**:
- tutorials/wave の Step 1(平坦な水槽の水の山。350 × 350、dt 0.01 s、8 s)に `f_govequation` を足す。2 では
  8 s 後も最大水深 1.9996 m・流速 0 のまま(底面勾配が 0 なので駆動力がない)。1 では波は広がり、裾(水位
  1.005 m)の位置は力学波と同じ中心から 39.0 m、前面の中腹(水位 1.1 m)は 36.7 m(力学波 38.1 m)、山の頂は
  1.170 m・34.4 m(力学波 1.194 m・37.6 m)。計算時間は 1 スレッドで 0 が 118.6 s、1 が 114.4 s(−4 %)、
  2 が 106.4 s(−10 %)(各 2 回の平均。2 回の差は 1.3 % 以内)。
- test/dambreak の `f_govequation` を 1 にする。Check_stoker.py で、30 s の段波の位置は 728.9 m(解析 794.4 m。
  進行距離の −22 %)、中間水深 5.44 m(+37 %)、流速 6.26 m/s(−15 %)、段波の背後の越え高さ 4.2 m。既定の
  力学波は +1.3 %・−1.4 %・+1.2 %。
