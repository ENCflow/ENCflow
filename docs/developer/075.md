## 75. 多段ネスティング: 非静水圧の φ の帯(2026-10-10 実装)

設計の正本は docs/nesting_plan.md §16(要合意事項 §16.6 は 2026-10-10 合意)。
本節は実装の規約と検証記録。

### 要点

- NH 補正は楕円型で、子の内部の φ は子の境界条件に依存する。帯のセルも未知数に
  していた従来の扱いでは、静水圧量の帯 Dirichlet が成立していても **NH を有効に
  した子は比 1:1 で親と一致しない**(test/nest_identity の nh0 対照: 最大 3.2e-2 m)。
  帯のセルを親の φ の Dirichlet 既知セルにすると、子の内部の線形系は親の系の
  「内部への制限 + 既知値」になり、解は親の制限に一致する(nh ケース: 最大
  1.8e-13 m。CG の反復列は領域依存なので一致は許容残差 nh_tol = 1e-12 の精度)。
- **採らなかった 2 案(実装中に確認)**: (a) 帯 φ = 0 の Dirichlet で帯〜内部の
  エッジも補正する: 親の prolong が毎サブステップ上書きするエッジ量と補正が食い
  違い、界面から擾乱が成長する(例題 r3 で子の h_max が通過後 1.02 → 1.17 m、
  ルートにも 3e-2 m)。(b) 帯だけを fmask(静水圧)にして余白なし: §69.8 の
  「規定流束のセルに NH 候補が接すると干渉して発散」がそのまま再現(恒等ケースで
  50 ステップで 250 m/s 超)。帯は規定された状態を持つので他の強制境界と同じく
  余白が要る。nest_nh = 0 は (c) 帯 + 余白を静水圧(安定。恒等ケースの不一致
  1.4e-2 m)。

### 構成

- **m_swflow_enc / _nh**: nh_mod に `have_dir`・`dmask`・`dval`。公開フック
  `m_swflow_enc_nh_export(i1, i2, j1, j2, buf)`(親: 自帯の行の φ を buf へ。NH 無効
  なら触らない)、`m_swflow_enc_nh_import(nx, ny, jlo, jhi, inband, phival)`(子: 帯を
  既知セルにし値を置く。NH 無効なら no-op)、`m_swflow_enc_nh_active()`。
  nh_project の変更は have_dir のときだけ: (1) 既知セルを候補から外し φ・φ1 に
  値を置く(`apply_dirichlet`。φ1 は Jacobi の書き込み先なので両方。CG の方向
  ベクトルとしての φ1 は warm start が改めて 0 にする)、(2) emask の近傍判定に
  既知セルを加える(既知〜既知は除く)、(3) CG を warm start(初期値 = 内部 0・帯
  φ_d、r = b − Mφ。既知値を右辺へ移した系と同値。Version 2 の Picard も初回から)、
  (4) 補正は既知セルが持つ内部向きのエッジも対象(エッジの所有セルが帯側のとき)、
  (5) 動く底面の平滑化解の後に既知値を戻す(補助解は帯 φ = 0 の近似)。
  **have_dir が偽の経路は従来と演算・順序とも同一**(NH ON の reference nhwave_nh・
  nhsolitary が identical)。
- **m_nest**: `nphi`(子が NH 有効で帯があるとき 1。窓 wc の添字 ncq + nfld + 1)、
  `nest_nh`(&list_nest。1 = 帯を親の φ の既知セルに、0 = 帯 + 余白 nh_bc_margin を
  静水圧に〔他の強制境界と同じ fmask〕)。
  capture_one が親の φ をフック経由で窓に写し、**r_t = 1 でも lev 1(t^{n+1})の
  写しを取る**(φ は射影 = サブステップ末尾の量なので α_end = α + 1/r_t で補間。
  r_t = 1 は φ^{n+1} の複写)。prolong の末尾の `fill_phi` が帯セルの値を作り
  (比 1 複写、比 > 1 は双線形。親の 2×2 に乾きがあれば 0)、nh_import で子へ。
  nest_bc = 3(帯なし)では nphi = 0(開いた面は nh_bc_margin のまま)。
- **活性集合の帯からの種**(§16.2。active_set): have_dir のとき、|φ_d| ≥ 種の
  下限(floor)の帯セルに 8 近傍で接する内部候補セルを種に加える(1 ループ。
  パラメータなし。利用者は子でも f_nh_adaptive をそのまま使える)。効果は
  test/nest_identity の nha(子だけ活性集合、親は全域解)で max|Δh| 3.4e-4 → 3.0e-4 m
  (活性セル平均 +6)。残る差は子だけが活性集合であることによる切り捨て誤差
  (§69.2 の水準。山 0.5 m の 0.06%)で、界面に集まってはいない。
- nestcheck に許容差の第 6 引数(0 = ビット一致の従来判定)。

### 検証(2026-10-10。plan §16.5)

- **無効時**: reference 22 ケース PASS(NH ON の nhwave_nh・nhsolitary を含む)、
  厳密フラグ 38 ケースが従来基準とビット一致。
- **NH 恒等(test/nest_identity nh)**: wave 385² + 子 121²(親セル 133..253)、親子とも
  f_nonhydrostatic = 1・CG・nh_tol = 1e-12・f_nh_adaptive = 0、一方向、単一スレッド。
  160 ステップ全てで子の内部(帯 3 を除く)とルートの足元の差が max|Δh| = 1.8e-13 m、
  max|Δvv| = 1.4e-13 m/s(許容 1e-10 で PASS)。対照 nest_nh = 0(帯 + 余白
  〔自動 2H/Δx = 8 セル〕を静水圧)は max|Δh| = 1.4e-2 m、max|Δvv| = 4.4e-2 m/s
  (全ステップ不一致。安定)。
- **例題(examples/nest_reflect の NH 版。σ = 2 m、kH ≈ 0.5、r3 双方向、CG 全域解、
  一様細格子 NH 1155² を基準)**: 親の φ の Dirichlet(nh1)はルートの足元内の誤差が
  粗格子単独の 1/5〜1/10(t = 2 s: RMS 3.2e-5 対 3.7e-4 m、t = 4 s: 1.2e-4 対
  6.6e-4 m)、子の内部(外周 2 親セルを除く)の誤差は 8e-6〜8e-5 m。静水圧の帯 +
  余白(nh0)は子の内部の誤差が nh1 の 20〜80 倍(6.4e-4〜1.5e-3 m)で粗格子単独より
  悪い。表は examples/nest_reflect/README.md。
- **MPI(OpenMPI)np = 1, 2, 4**: 既存 8 ケース・twin・nest_identity(nh・nh0 対照
  含む。nh0 の不一致量もランク数不変)PASS。例題 r3_nh1・r3_nh0(tt = 2 s)の
  ルート・子の Log がランク数不変。
- **-O0 -fcheck=all -finit-real=snan の MPI クリーンビルド**: nest_identity np = 2
  全ケース PASS(nh を含む)、例題 r3_nh1 np = 2 完走(実行時メッセージなし)。
- 検証の過程で主ツリーの再ビルド後に install を忘れ、回帰のスタンプ検査
  (bin/encflow が .mode_* より古い)で 16 ケースが実行拒否になった。実際の不一致では
  なく、install してやり直した(§10 の検査が意図どおり働いた例)。
