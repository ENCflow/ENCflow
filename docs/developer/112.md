### 112.3 流向面の試作 S: 面の流束を、入ってくる連結ごとの流れに分ける

- **考え方。** いまの規則は、流向面(セル中心を通る面)の流束の全量に、線の上流側の 1 本の連結の流速を掛ける。
  これは、流れが格子で解像されている(隣り合う連結の流速がなめらかに変わる)ときに正しい。1 セル幅の河道の階段の
  ように、面の水のほとんどが斜めの連結から来て、線の上流の連結は岸や淵にしかつながっていないとき、その流速は
  面の水を代表しない。そこで、面の流束 F を、面のセルへ入る連結ごとの「流れ」に分ける。
  - F = Σ_l F_l、F_l = g_l Q_l + β_l O。Q_l は連結 l の流入量。g_l Q_l は、その流入が F に占める分で、係数は
    セル平均流量の定義(m_swflow_enc の w8mx・w8my)から決まる: 前向きの線の連結は 1/2、斜め 45° の連結は 1/2(軸の辺)・
    1/4(対角の辺)、直交は 0、後ろ向きは負。O = F − Σ g_l Q_l は流出側の分で、流入量の比 β_l = Q_l / ΣQ で
    各流入に割り当てる(セルの中でよく混ざるとみる)。
  - 重み: 線の連結の流れは 1。前向きの斜めの連結の流れは θ_l = min(1, κ Q_k / Q_l)(Q_k は線の連結の流入量。
    一様な流れでは、向きによらず Q_l ≤ √2 Q_k なので 1。κ = 2)。直交・後ろ向きから入る流れは、従来の重み
    (`donor_share`。合流の扱いを変えないため)。w = Σ F_l × 重み / Σ F_l を、`donor_share` の代わりに使う
    (流向面の風上値と、屈曲の規則 `adv_bend_mc` の重みの両方)。
  - 追加(S3): 斜めの流入元のセルの水が「辺の向きに流れてきたもの」でなければ(流入元のセルへの流入のうち、前向きの
    連結から入る割合 ω_o が小さければ)、直交して入る流れと同じ扱いに戻す: θ'_l = θ_l + (1 − θ_l)(1 − ω_o) × 従来の重み。
    8 近傍の格子では、T 字の合流の支川の水が、斜めの連結で合流の下流のセルへ入るため(これがないと、支川が主の
    合流でエネルギーが増える。§112.5)。側方面の規則の ω_o と同じ考え方である。
- **性質。** 一様な流れ(向きによらない)・横に一様な流れ(段波)・直交する流入だけの合流では、従来と同じ値。
  §111.14 の試作 (D)(w = min(1, Q_k / (q_c l_k)))は、連結の流量をセル平均(流出側を含む)と比べるので、加速する
  流れで 1 を下回ったが、S は、同じセルへ入る連結どうしを比べるので、そうならない。階段の角では、(D) とほぼ同じ
  重み((1 + κ/…) × 線の連結の流量の割合)になる。しきい値 ε は、斜めの流れには使わない。
- **経過。** 初めの形は、流入側の半分だけを流れに分けて、残りを従来の重みにした。対角の辺では、流入側(1/4)と
  流出側(1/2)の投影が違うので、残りが 1/3 出て、階段の河道の 2 つの状態が消えなかった(T-A の 2,000↓ が 9.58 m)。
  流出側も流入の比で割り当てる形にして、(D) と同じ結果になった(同 7.61\*)。

|---|---|---|

**(1) エネルギーの上限は、頭打ちではなく、移流項として入れる(試作 C)。**

- **仕組みの補足(§112.8 の「角のセルから出る辺」の言い直し)。** 屈曲の規則の経路の値 ū_p = f Q_in/(W_e h̆_in)(§110)は、
  「面のセルへの流入のうち、この辺へ出る分が、この辺の幅で、流入時の水深のまま流れたときの流速」= 連続式から決まる
  流速である。定常(Q_in = Q_out)では ū_p = u_e h_e/h̆_in なので、数えるのは、経路に沿って水深が変わる分の加速だけに
  なる。(a) 流入が複数の連結から合わさる面のセル(合流・角のセル)では、合わさった流量がこの辺の幅を通る流速を
  「入ってきた水の流速」とみなすので、遅い流れが合わさって速く出ていく加速を数えない。(b) 寄せる度合いに f(流出の
  うち、この辺の割合)を掛けるので、流出の一部だけが出ていく辺は、ほぼ中立のままになる。どちらの辺も、水面勾配と
  摩擦のつり合いの流速まで上がれる(§112.8 の B → A の 11.3 m/s)。

  「到着した水の速さ」a を上回るときだけ、減速の向きの移流項

  ```
  c_l = max( f W_l/W_e, min(1, W_l/W_e) )、  f = Q_e / Q_out
  ```

  を足す。経路の値の項(§110)が減速の向きのときは、2 つのうち大きい方を取る(どちらも同じ加速を数えるので、
  足し合わせない)。面のセルへの流入がなければ、何もしない。

    分)となり、入ってきた水のエネルギーを超えない。非定常の流れでも、運動方程式の項として正しい向きに働く
    (頭打ちと違い、時間をかけて効く)。
  - 辺が到着した水より遅いとき(u_e² ≤ a²)は、何もしない(入ってきた水の運動量で辺を押さない。§102 の「本流の
    運動量を持ち込まない」を保つ)。
  - c_l は、連結 l の流速を、この辺の通過幅に直す換算。広い連結へ出るときは幅の比で遅くなる(対角 → 軸で 0.707)。

    違いは加減速に数えない」取り決め。§110.6)、一部が枝分かれして入るなら(f < 1)、入ってきた速さのまま
    (f W_l/W_e と 1 の大きい方)。
  - 1 本の経路で加速する流れ(流入の連結が 1 本で f = 1)では、経路の値の項の方が大きい(運動量形の
    q/h̄·(u_e − ū_p) は、エネルギー形の (u_e + ū_p)/2·(u_e − ū_p) 以上)ので、いまの規則と同じ値になる: 壁だけの
    階段・対角・1 つの階段(test/stairbank の zw・dw・sw)は、表示の桁まで変わらず、test/brink の段落ち(dg1・pb1・pf1)
    も通る。効くのは、流入が合わさる面のセルと、流出の一部だけが出ていく辺である。
  - 運動量保存形の原論文(Stelling & Duinmeijer 2003)は、流れが強く縮む所ではエネルギー水頭を保存する形を使う、
    という趣旨だったと作業者は記憶しているが、**本文は未照合**(§112.7)。この形(中立の分だけに、減速の向きだけ
    掛ける。到着した速さの幅の換算)は ENCflow 独自。
  - 結果: sab は定常(流量の標準偏差の最大 11〜17 m³/s、最大流速 12.9 m/s)。test/steepwave は通る。
