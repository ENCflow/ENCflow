## 92. 斜面の最急勾配 slope8 を D∞(Tarboton 1997)で求める(8 方向の勾配の最大による格子の向きの偏りの修正。2026-11-04 挙動変更)

- **現象**: 混合体流動の地形の最急勾配 tanθ(m_geomorph_debris の slope8)が、最急勾配の向きが
  格子の 8 方向の間にあると小さく出る。勾配 G の一様な斜面で、8 方向の勾配の最大は
  G cos β(β は最急勾配の向きと最も近い 8 方向のなす角。0〜22.5°)で、22.5° で 0.924 倍。格子を
  細かくしても変わらない。tanθ を使う量への効き方(22.5° の向き):
  - 斜面安定判定(f_slide)の安全率 Fs: c' = 0・地下水なしで Fs = tanφs/tanθ が +8.2 %(崩壊の
    判定が向きで変わる)。test/dbonset の新しい安全率の構成(_fs)で、旧方式の内部の Fs は 0°・45° で
    tanφs/G に一致し、22.5° で +8.24 %(= 1/cos 22.5° − 1)。
  - f_dbed = 1 の高橋型の平衡濃度 C∞(θ): tanθ = 0.3 で −13 %(侵食が減り、堆積が増える)。
  - f_dbed = 2・3 で速さ 0 のセルの停止判定(f_dbstop = 1)の C∞。
- **原因**: slope8 が 8 近傍への勾配 (z_c − z_k)/dist_k の最大(D8)を返していた。8 方向の勾配の最大は、
  最急勾配の向きが 8 方向のどれかに一致するときだけ最急勾配に等しい。
- **修正**: D∞(Tarboton 1997, Water Resour. Res. 33(2), 309–319)。自セルと、軸方向の近傍 1 つ・
  それに隣り合う斜めの近傍 1 つで作る 8 つの三角形の面ごとに、面内の下り向きの最大勾配を求め、
  その最大を返す。面の下り勾配のベクトル (s1, s2) = ((z_0 − z_1)/d1, (z_1 − z_2)/d2)(d1 は軸方向、
  d2 はそれに直交する向きの格子間隔)の向きが面の角(0〜atan(d2/d1))の内なら √(s1² + s2²)、外なら
  面の 2 辺の向きの勾配 s1・(z_0 − z_2)/dist の大きい方。下限 0。近傍の扱い(領域外・海は対象外、
  開いた辺の外は §28.15 の線形外挿)は変えず、面の片方の近傍が対象外なら残る近傍への勾配だけを
  候補にする。面の勾配は面の 2 辺の向きの勾配以上なので、結果は常に旧方式以上で、平面では向きに
  よらず厳密。関数名 slope8 と呼び出し側は変えない。
- **決定の理由**(2026-11-04 合意):
  - 文献のある標準的な方法で、平面で厳密、ステンシルは従来の 8 近傍(と §28.15 の外挿の 1 セル内側)
    のまま(ハロ・並列の扱いが変わらない)。
  - §91 の重力補正(セルの勾配を minmod で取り、折れでは緩い側)と使い分ける: 安全率・C∞・停止判定に
    要るのは「そのセルから下る最急の勾配」で、尾根・谷壁の肩のような折れでは下り側の急な勾配が
    意味を持つ。重力補正の cos²θ は地盤の傾斜(法線の向き)の量で、折れで片側の急な勾配を拾うと
    谷底の有効重力が下がる。
  - Tarboton の向きの判定 r = atan(s2/s1) と範囲 [0, atan(d2/d1)] への制限を、atan2 を使わない同値な
    比較(s2 ≥ 0 かつ s2 d1 ≤ s1 d2 なら面の内)にした。平らな面(s1 = s2 = 0)の atan2(0, 0) は
    Fortran の規格で値が定まらず(処理系依存)、判定ごとの三角関数(1 セル 16 回)もなくなる。範囲の
    外で 2 辺の大きい方をとるのは「面内の下り向きの最大勾配」の定義どおりで、同論文の選び方と
    異なるのは 2 辺の勾配がどちらも負の場合だけ(下限 0 で結果は同じ)。atan2 による試作と、
    test/dbonset の安全率の出力がバイト一致した。
  - 同じ D∞ を使う §45.2(m_glacier の ava_dir。雪崩の送り先)とは目的が違うので形を揃えていない。
    ava_dir は送り先の向き r も要るので atan2 を使い(平らな面は除く)、近傍の片方が使えない面は
    使わない(送り先が要る。使える下りの面がなければ D8)。slope8 は勾配の大きさだけを返すので
    比較の形にし、近傍の片方が使えない面では残る近傍への勾配を候補にした(旧方式以上を保ち、
    領域の端・海岸で勾配が下がらない)。
  - 旧方式に戻すスイッチは置かない(§0-6。§91 と同じ)。
  - 8 方向の勾配の最大を使うほかの処理(f_splash の spl_sgrad = 1 の最急降下 §48.4、f_bedslide の
    セル勾配 S_c)は、今回の合意の範囲の外として残した(handoff。f_bedslide は S_c で流出の配分を
    正規化しているので、置き換えには配分の検討が要る)。
  - reference と例題の再計算は、§91 と岩盤侵食の g_e の統一と同じ回にまとめる。
- **影響の範囲**: slope8 の呼び出しは、f_slide の安全率(判定・流動化)、f_dbed = 1 の C∞、f_dbed = 2・3 で
  速さ 0 のセルの停止判定の C∞ の 3 つ。最急勾配の向きが 8 方向の間にある斜面で、tanθ が最大 8.2 %
  大きくなる(Fs・C∞ の変化は上の現象のとおり)。これらを使う構成の reference が変わる。
  f_debris = 0 の構成と、slope8 を呼ばない混合体流動の構成(f_dbed = 0・4 で f_slide なし)は不変。
- **ステンシルと並列**: 読む近傍は従来と同じ(8 近傍と、開いた辺の外挿の 1 セル内側)。時刻 n の z を
  読み(本プロセスは m_geomorph_calc の先頭。ハロはステップの頭の交換で最新)、各セルを自ランクが
  計算する。
- **検証**(gfortran 13.3):
  - test/dbonset に斜面安定判定の 9 ケース(名前の末尾 _fs。勾配 0.9 μ・1.1 μ・1.3 μ × 向き 0°・22.5°・
    45°、8 近傍、f_slide = 2・c' = 0・地下水なし)を加え、Check_dbonset.py の (5) で、壁際の 1 列を
    除く内部の Fs の最小・最大を tanφs/G と比べる(相対 1e-3)。D∞ では全 9 ケースが印字の桁まで
    一致し、旧方式(§91 の前のビルド)は 22.5° の 3 ケースが +8.24 % で FAIL(0°・45° は旧方式でも
    一致。検出器として働く)。壁際の 1 列は、閉じた壁の外の近傍が候補にならないので、下り向きが
    壁へ向かう辺で Fs が大きく出る(閉じた境界の扱いとして従来どおり)。降伏の 36 ケースは slope8 を
    呼ばないので値が変わらない(全 45 ケース PASS)。
  - 参照を持つ 41 ケースは slope8 を呼ばないので、§92 による reference の変化はない(§91 の回帰を参照)。
    -fcheck=all・MPI・土石流系の自己検定の新旧は §91 の最終状態の検証と同じ実行に含まれる(slope8 を
    使う slide・debris(f_dbed = 1)・dbonset の安全率が PASS し、MPI で逐次とバイト一致)。
