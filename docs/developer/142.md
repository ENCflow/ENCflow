## 142. 高橋・中川則の堆積の式が、非正規化数の濃度でオーバーフローする不具合と修正(境界検査つきのビルドだけで起こる。release の結果はビット一致。2026-11-28)

### 142.1 見つけ方

土石流の式の侵食を動ける粒径階に限る選択子(§143)の検定の構成を、-Og -fcheck=all・FPE の検出つきのビルドで
回したところ、calc_debris のパス 1 の堆積の式(高橋・中川 1991 の式 (27) の限界速度)で SIGFPE(オーバーフロー)に
なった。release(-Ofast)のビルドは同じ設定で完走する。止まるのは、水深が限界水深 `dd` を超えて流れが
動き始めた直後(test/dbmix の雛形 e で 18 s 過ぎ)。

同じ止まり方は、新しい選択子を使わなくても、HEAD のソースで再現した。高橋・中川則の構成(test/dbmix の tk3)の
土層を斜面だけにして、平坦部を基盤にするだけでよい(下の tkb3)。既存の不具合で、選択子とは独立に直す。

### 142.2 原因

- **止まった命令**: 限界速度 v_c の中の (C*/C)^{1/3}。濃度 C = h_s/(h + h_s) が C*/huge = 3.3e-309 より小さいと、
  C*/C がオーバーフローする。正規化数の下限は 2.2e-308 なので、非正規化数の C だけで起こる。分岐の条件は
  `cc > 0.0` で、非正規化数を通していた。
- **濃度が非正規化数になる経路**: 流れの土砂 h_s が、侵食も堆積もされないセルを移流だけで進むとき。動き始めの
  流れの先端は 1 ステップに 1 セルずつ下流へ広がり、その流速はセルごとに桁で小さくなる(見つけた構成の平坦部の
  1 列で、遷緩点から順に 1.8e-2・4.7e-6・2.8e-11・1.6e-16・2.4e-34 m/s)。土砂の柱はその積で小さくなり、
  数セル先で 1.5e-225・7.7e-301・5.9e-321 m になった(同じ構成で見た値)。最後の値が非正規化数で、濃度
  5.7e-318 のセルで止まった。
- **侵食も堆積もされないセル**: 濡れていて(h > `dd`)、流動面の勾配から決まる平衡濃度が 0 でない(平衡濃度に
  届かないので堆積しない)のに、侵食する土砂がないセル。濡れた基盤がそれに当たる。土層のあるセルは、
  平衡濃度に届かなければその場で侵食して土砂を足すので、柱が流速の積だけでは決まらない。平衡濃度が 0 の
  セル(流動面が水平か逆勾配)は、届いた土砂を低速凝集で毎ステップ全部河床へ戻すので、先へ進まない。
  §143 の選択子で「動ける粒径階がない」とされた表層も、侵食も堆積もされないセルになる(見つけたのはこの形)。
- **release で起きない理由**: -Ofast のビルドは、実行開始時に FTZ/DAZ を設定して、正規化数より小さい演算結果を
  0 にする(§139.7 と同じ事情)。濃度は 0 か正規化数で、式は通る。release の make.inc も FPE のオーバーフローを
  検出する設定なので、非正規化数が残るビルド(-Ofast を外した最適化など)では release でも止まりうる。

### 142.3 修正

分岐の条件を `cc >= tiny(cc)` にした(非正規化数の濃度は 0 と同じに扱い、堆積の式を通さない。-Ofast のビルドが
非正規化数を 0 とみなすのと同じ扱い)。正規化数の濃度では C*/C ≤ 0.6 / 2.2e-308 = 2.7e307 で、オーバーフロー
しない。式の値は変えていない。C*/C の形の式は、ソースの中でここだけ(`grep` で確認)。

### 142.4 再発防止の検定

test/dbmix の構成 **tkb3**(tk3 の土層を斜面だけにする。平坦部は基盤。雨で全域が濡れているので、流れの先端が
侵食できない濡れた基盤の上を進む)。判定 (11) は、粒径階ごとの収支の残差、保存から数えた粒径階ごとの総量 =
初期の総量、平坦部の基盤に土砂が届いて計算が終わること。修正前の境界検査つきのビルドは、この構成で止まる。

### 142.5 確認(同じ計算機・同じ make.inc。gfortran 13)

- **境界検査つき**(-Og -fcheck=all、FPE の検出): HEAD のソースのビルドは、tkb3 が 10〜20 s の間に SIGFPE で
  止まる(m_geomorph_debris.f90:682。式 (27) の限界速度の行)。修正だけを入れたビルドは、test/dbmix の逐次が
  51 判定(既存の 48 + tkb3 の 3)すべて PASS。
- **release**(-Ofast): HEAD のビルドと、HEAD に修正だけを入れたビルドで、土石流・流動化・崩落・混合粒径に関わる
  15 本(dbmix・dbslope・curvature・volcano・rockfall・gvchange・bldgdebris・bedslide・splash・slide・dbrock・
  avalanche・debris・bedmix・dbonset)を回した。Run.sh はどちらの側もすべて PASS で、出力(result・save)の
  5663 ファイルがバイト一致(ほかに保存時刻の行だけが違う save_info.txt が 24。gvchange は単体試験で出力ファイルが
  ない)。修正だけを入れたビルドに tkb3 を足した test/dbmix は、51 判定が PASS(tkb3 の粒径階ごとの残差
  3e-14 m³、総量の差 2e-13 m³、平坦部の基盤の 20 セルに堆積)。
