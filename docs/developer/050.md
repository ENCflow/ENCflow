## 50. 流木モジュール m_driftwood(fn_driftwood。2026-08-21 設計合意)

流木を個別剛体で追跡せず、セルごとの柱状材積 (m3/m2 = m) の
**オイラー的なラスタ場**として概算する加算的プロセスモジュール。
設計全文と合意の経緯は docs/driftwood_plan.md(実装完了と文献照合の
消化で消し込み、本 § が正本になる)。個別流木のラグランジュ追跡・
橋梁やスリットの幾何的閉塞・衝突力は §0 方針2(ラスタ純化)により
**対象外と明言**(閉塞効果はシナリオ与件 = 2ケース比較で運用)。
2026-11-12 に、捕捉率を与件として構造物での集積と流れへの作用を扱う機能を足した
(§50.7。掛かるかどうかの幾何的な判定は引き続き対象外)。

### 50.1 構成(合意事項の要約)

- **3台帳**: 立木ストック wst(入力ラスタ fn_dwstock。不動・私有)→
  流木化 → 流動流木 s%hd(移流)→ 接地・乾燥 → 堆積流木 s%wd
  (不動。再流動可)。総和が機械精度で閉じる(diagnostic は
  result/driftwood.csv、par_sum_rows = 決定的)。
- **輸送は advect_scalar の流用**(hs/cq/hss と同じ並びに dw_active
  分岐を追加。書き込み先 sx%hd1、complete でコミット、ステップ頭
  ハロ交換)。水柱と同じエッジ流量 mn1 が運ぶ = 固液同速の単相近似。
  土石流時は混合体と同速で流下 = 混合流れは追加実装なし。
- **発生2経路**: (a) 水理的流失(wst>0 かつ h+hs>dw_hrec かつ
  vv>dw_vrec で wst→hd をレート dw_wrec。数値的閉包【独自】・閾値は
  校正パラメータ = §50.5 の文献照合で確定)、(b) 侵食連行(累積侵食深 zref−z > dw_droot で
  wst **全量**→hd。zref は init 時 z の私有写し。z 低下の事実だけを
  見るためどの侵食・崩壊プロセスとも自動連動 = モジュール間フック
  なし)。乾燥セル(h≤dd)の hd は全量 wd へ(suspend と同型)。
- **停止・再流動**: 喫水 hf = 円柱の浮力平衡の厳密解(§50.4。
  Braudrick & Grant 2000 式(23)(6)。円形セグメント面積の超越方程式を
  init で二分法により解く。追加パラメータなし)。h+hs < hf または
  vv < dw_vstop で hd→wd をレート dw_wstop(f_dbstop=1 と同型の
  数値的閉包)。再流動は h+hs > dw_rfloat・hf かつ vv > dw_vfloat で
  wd→hd レート dw_wfloat(既定 0 = なし。安全側)。wd は z に足さない
  (第1段)。
- **運動量・抵抗への流木算入はしない**(第1段。§0 方針4・6)。流動流木 hd・堆積流木 wd は
  今も算入しない。捕捉セルの集積流木 wj だけが抵抗として作用する(§50.7)。
- **モジュール様式**: m_wq に倣う(fn_driftwood / &list_driftwood /
  ENC 格子のみ / 無効時ゼロコスト / 私有 save driftwood.dat 契約C /
  ダム捕捉帯の全量吸収同伴)。morfac ≠ 1 は par_stop(f_debris と
  同じ理由)。更新はセル局所のみ(エッジ・ハロ・collective 不要 =
  §28.2 の2パス規約の適用外)。calc は geomorph calc の後(同一
  ステップの z 更新を見た侵食連行)。
- **出力**: f_out_hd(流動 Hd0001…)、f_out_wd(堆積 Wd0001… +
  期間最大到達量 Wd9999 = max(hd+wd)。流木ハザードの一次指標)。
  統計は save 対象外(hmax 系と同じ意図的仕様。§7)。
- **将来課題**(handoff): 多クラス化(径級・樹種)、侵食増分比例の
  連行、境界流入の流木時系列(cbin 経路)、測線流木フラックス、
  抵抗則への算入、動的閉塞則(後の 2 つは、構造物での集積について §50.7 で実装)。

### 50.2 パラメータ(&list_driftwood)

必須: 立木ストック(一様 dw_stock0 か分布 fn_dwstock の排他。m3/m2)、
dw_dlog(代表直径 m)、dw_sglog(材比重 0<sg<1。浮遊前提の検証つき)。
発生: dw_hrec / dw_vrec / dw_wrec(水理的流失の水深・流速閾値と
レート)、dw_droot(根系深 m。侵食連行の閾値)。
停止・再流動: dw_vstop / dw_wstop(接地・低速堆積)、dw_rfloat
(浮遊余裕率。既定 1.5)、dw_vfloat / dw_wfloat(再流動。既定 0)。
レート・閾値は校正パラメータ(コードは形のみ。§19.8 の運用)。

### 50.4 文献照合(Braudrick & Grant 2000。2026-08-21 実施)

出典(ユーザー提供): Braudrick, C. A. and Grant, G. E. (2000),
When do logs move in rivers?, Water Resources Research 36(2), 571-583。

- **確定 → 導出式へ置換**: 喫水(浮遊限界水深)d_b。同論文式(23)
  (rootwad なし円柱の浮力平衡 ρlog・πD²/4 = ρw・A_sub(d_b))を
  式(6)の円形セグメント面積で解いた厳密解に置換した(実装は init の
  二分法 60 回。面積率 f(x) = (θ−sinθ)/(2π)、θ = 2acos(1−2x)、
  x = d/D。全ランク同一演算 = 決定的。追加パラメータなし)。
  従来の線形近似 hf = sg・D は sg=0.5 でのみ厳密(対称解)で、
  厳密解との差は sg=0.3/0.7 で d/D ≈ 0.04(x_exact = 0.34/0.66)、
  sg=0.9 で ≈ 0.06。**test/driftwood は sg=0.5 のため数値はビット不変**
  (全検定 PASS・np=2 逐次一致を再確認)。
- **裏付け(実装変更なし)**:
  - 接地判定「h+hs < 喫水で堆積」は同論文の buoyant depth 概念
    (d_w < d_b では浮遊できない)そのもの
  - **長さ非依存の抽象化**: 「L < 川幅では部材長は移動限界に有意に
    効かない(浮力・重量とも長さに線形で相殺)」が理論・水路実験の
    両方で示されており、長さパラメータを持たない単一 dw_dlog の
    構成を支持する
  - 堆積流木の既定不動(dw_wfloat=0): rootwad 付き・流向平行の
    流木の安定性(喫水超過後まで動かない)と整合する安全側の既定
- **校正のまま(単一閾値に還元できない/論文の対象外)**:
  - 再流動の dw_rfloat・dw_vfloat: 同論文の力の釣り合い式(4)は
    床摩擦係数 μ_bed・抗力係数 Cd・配向 θ に依存し h・v の単一閾値に
    還元できない。実測の目安(記録): 流向平行・rootwad 付きは
    d/d_b ≈ 1.2 で移動、斜交(45°/90°)は d_b 未満でピボットして
    移動 → 既定 dw_rfloat=1.5 は安定側(平行・rootwad 相当)の値
  - 水理的流失 dw_hrec/dw_vrec/dw_wrec: 立木の倒伏・流失は同論文の
    対象外(横たわる丸太の entrainment を扱う)。引き続き
    文献照合を要する(候補: 国総研の流木対策資料・砂防学会の流木研究)
    → §50.5 で国総研資料と照合し、校正パラメータとして確定

### 50.5 文献照合・第2弾(国総研資料 904・905。2026-08-21 実施)

出典(ユーザー提供): 国土技術政策総合研究所資料 第904号「砂防基本
計画策定指針(土石流・流木対策編)解説」/ 第905号「土石流・流木
対策設計技術指針 解説」(いずれも 2016 年 4 月)。

- **発生機構の裏付け(実装変更なし)**: 指針の流木発生原因(904
  表-2)は ①斜面崩壊に伴う立木の滑落 ②土石流発生源での滑落・流下
  ③渓岸・渓床侵食による立木の流出、および過去の倒木・堆積流木の
  再移動。ENCflow の2経路と一対一対応する(①②③ = 侵食連行
  dw_droot、⑤再移動 = 再流動 dw_wfloat)。指針の発生流木量算出も
  「崩壊・土石流の発生・流下範囲に存在する立木の材積」方式
  (904 式(7): Vwy = (Bd・Ldy13/100)・ΣVwy2)であり、**「侵食範囲の
  立木が全量流木化する」という本実装の侵食連行と同じ考え方**。
- **水理的流失(dw_hrec/vrec/wrec)の照合結論**: 指針は水深・流速の
  水理的閾値による立木流失式を**持たない**(発生量は面積×材積密度で
  与える)。よって実務標準値は存在せず、**校正パラメータとして確定**
  (指針スコープ外の緩勾配・氾濫原の立木流失を扱うための独自の
  数値的閉包、という位置づけを維持)。
- **実務値の記録(利用ガイダンスへ反映)**:
  - **dw_dlog の実務対応**: 流木の平均直径 ≈ 上流立木の**平均胸高
    直径**(904 §2.6.10)。最大直径 ≈ 大きい方から本数 5% の立木の
    胸高直径(§2.6.9。衝撃力・部材設計用)
  - 立木ストック wst の算出: 単木材積 Vwy2 = (π/4)・Hw・Rw²・Kd
    (Hw 樹高、Rw 胸高直径、Kd 胸高係数 0.3〜0.7)× 本数密度
    (100 m² あたり。前処理での材積換算の実務式)
  - 発生流木量の実績包絡値: 針葉樹 ≈ 1,000 m³/km²(= 1e-3 m³/m²)、
    広葉樹 ≈ 100 m³/km²(= 1e-4 m³/m²)(渓床勾配 5° 以上の流域
    面積あたり。904 §2.6.2 (3-3)) — wst 設定と結果の量水準の目安
  - 流木流出率(施設なしで発生量のうち谷出口へ届く割合)0.8〜0.9
    (904 §2.6.2)— 渓流スケール計算の検証指標に使える
  - 不透過堰堤からの流木流出率 α ≈ 0.5、計画捕捉量に対する流木
    容積率 Kw1 = 2%(捕捉事例がない場合。904 §3.2.2)
- **幾何的閉塞の対象外の再確認**: 透過型の部材純間隔は最大礫径
  D95 の 1.0 倍程度(905 §2.1)、流木最大長 Lwm ≈ min(1.3Bd, 最大
  樹高)を純間隔設定に使用(904 §2.6.9)— いずれもセル内幾何の
  施設設計論であり、ラスタ場の適用限界(§50.1)と整合する線引き。
- **副産物(§28 f_dbed=1 の照合前進)**: 平衡濃度の**上限 0.9C* の
  出典が確定**(904 §2.6.3:「計算値 Cd が 0.9C* よりも大きくなる
  場合は Cd = 0.9C*」)。C∞ 石礫型式も指針式(12)と同形。指針は
  さらに下限 Cd ≥ 0.3 を規定するが、これは計画ピーク流量算出用の
  安全側クリップであり E-D の平衡濃度としては採用しない(緩勾配の
  堆積側挙動が失われるため。文書化のみ)。未成熟域の 6.7C∞d² と
  閾値 0.138/0.03 は指針解説にも現れない(高橋系成書の系譜のまま。
  handoff 1j)。

### 50.7 構造物での捕捉と集積、集積の抵抗(fn_dwtrap。2026-11-12 合意・第 1 段を実装)

**第 1 段の実装**(m_driftwood・list_driftwood・m_state・m_swflow_enc の 2 か所・m_output・list_sysparam・
m_sysparam):
- **有効化**: &list_driftwood の fn_dwtrap(捕捉率 E の分布。0〜1。使用セルで範囲を検査)。与えなければ
  s%wj・捕捉率の配列を確保せず、流れの側は論理 1 つの分岐(s%dw_jam)だけ(方針 6)。
- **台帳**: s%wj(柱状量。基底は hd・wd と同じ空隙面積・河道幅の中)。持ち主は m_driftwood(確保・更新・
  保存)。m_state_set_gv の「空隙面積基底の柱状量」に足した(家屋の破壊で空隙率が変わっても材積を保つ)。
  流木の台帳は 4 つになり、Σwst + Σhd + Σwd + Σwj(+ ダム捕捉 + 系外流出)が初期材積に閉じる。
- **捕捉の規則(独自)**: m_driftwood_calc の水理的流失の後、接地の堆積の前。よく混ざったセルの滞留時間
  Δx/|V| に対して r = E/(1 − E)·|V|Δt/Δx、1 ステップの捕捉量 hd·r/(1 + r)。E ≥ 1 と、集積量が dw_jamgrow を
  超えたセルは全量(移流の後なので「入った流木をすべて止める」。dw_jamgrow のこの 1 段の切り替えは、
  同日に集積量の連続関数に置き換えた。§50.10)。セル局所の計算で、近傍を読まない。
  格子の軸に沿う一様な定常の流れでは、移流と捕捉を順に適用する離散化の定常解で捕捉される割合が E に
  一致する(1 ステップの流出の割合を c とすると r/(r + c) = E)。
- **集積の抵抗**: f_dwjam = 1(既定)のとき、m_driftwood_init が係数 κ0 = 2 C_D/(π d (1 − φ)³) と φ を
  s%dw_jamk・s%dw_jamphi に書き、s%dw_jam を立てる。calc_kth_flux は、家屋の抗力項の後(土石流の降伏
  抵抗の前)に 1 文 `if (s%dw_jam) tfe = tfe - s%dw_jamk * min(0.5*(wj_c + wj_n)/hhe, s%dw_jamphi) * vve` を
  足す。係数の構造は Follett ら(2020)の多孔質の障害物の係数 C_A = L C_D a/(1 − φ)³(円柱で
  a = 4φ/(π d))で、離散化は独自。f_dwjam = 0 は台帳だけ(流れは流木なしの計算とバイト一致)。
- **ハロ**: 辺が両側のセルの wj を読むので、m_swflow_enc のステップ頭(hd のハロ交換の次)で
  `if (s%dw_jam) call par_halo_cell(s%wj)`。捕捉による更新は前ステップの m_driftwood_calc なので、
  ここで交換すれば最新。collective は増えない(診断の par_sum_rows が、捕捉セルを与えたときだけ 2 つ増える。
  判定は namelist 由来で全ランク同一)。
- **出力**: Wj0001…(f_out_wj。fn_dwtrap がなければ par_stop)。driftwood.csv は、fn_dwtrap を与えたときだけ

### 50.8 カルバートの流入口の損失(culv_jam。2026-11-12 第 2 段を実装)

**経緯**: §50.7 の表の 3(セルより小さい開口は、第 2 段で流量則に損失を足す)の実装。順序(表の 9)の
とおり第 1 段の次に進めた(利用者の判断「推奨で」。2026-11-12)。定式は docs/woodjam_plan.md §5.3・§7.4。

**実装**(list_structure・m_boundary・m_boundary_structure・m_driftwood・m_main):
- **有効化**: &list_struct_culvert の `culv_jam(n) = 1`(既定 0。0・1 以外は par_stop)。流木モジュールが
  無効(fn_driftwood なし、または f_dw = 0)で culv_jam = 1 のカルバートがあれば、m_driftwood_init が
  par_stop する(黙って無視しない)。
- **状態**: 新しい配列はない。t_structure に `jam`(整数)を足し、geom を 1:13 に広げた(geom(12) = 断面積
  B·D、geom(13) = 管路の損失の和 Σ = 1 + ce + 2g n²L/R^(4/3))。集積の台帳は第 1 段の s%wj を使う。
  fn_dwtrap がなくても、culv_jam = 1 のカルバートがあれば m_driftwood が s%wj を確保する(dw%have_jam。
  捕捉率の配列 dw%trap は fn_dwtrap があるときだけ = dw%have_trap)。台帳の列・保存・出力 Wj の条件は
  have_jam に変えた。
- **捕捉**: m_driftwood_calc の先頭(順序の (0))。culv_jam = 1 のカルバートごとに、このステップの目標流量
  `b%struct(ist)%q` の符号で取水している側を決め(q > 0: 取水セル群 cin、q < 0: 吐口セル群 cout、q = 0:
  捕捉しない)、そのセル群の hd を全量 wj へ移す。セルの一覧は init で自帯の分だけ作る(setup_culv。ダムの
  捕捉帯 setup_dams と同じ型で、3 行目にセル群の別を持つ)。q は makebdc が全ランクで同じ値を出すので、
  判定は全ランク同一。m_driftwood_calc の引数に b が増えた(呼び出しは m_main の 1 か所)。
- **損失係数**: structure_makebdc が、代表水位を集める配列 refs の末尾に、culv_jam = 1 のカルバートの
  セルごとの集積の実材積 wj·gv·wfrac·Δx·Δy を足し、既存の par_allreduce_sumr(refs) で共有する。各セルは
  所有ランクだけが非ゼロなので和は厳密で、その後にセルの並びの順で足すので、V_j はランク数に依らない。
  collective は増えない。水位の高い側のセル群の和 V_j から C_A = 2 κ0 V_j/(B D) を作り、law に渡す。
  s%dw_jam(f_dwjam = 1)でなければ refs を広げず、ca = 0 のまま(f_dwjam = 0 は台帳だけ)。

  乗算・加算そのものを飛ばす(ゲートなしのカルバートと同じ扱い。式の形を変えると -Ofast で最終桁が動く
  ことがあるため、分岐で分けた)。限界水深 d_c は、倍率を掛けた後の堰の流量から求める。
- **セルの抵抗との関係**: 流入口のセルの wj には、第 1 段のセルの抵抗も掛かる。流入口へ集まる流れは
  遅いので、ほとんど効かない(メモ §6.3 の試算で 100 m³ を置いて 0.1 %)。

**メモからの変更(実装で決めたこと)**:
- 捕捉する側: メモ §7.4 は「上流側・下流側のセル群を捕捉率 1 の捕捉セルとして扱う」としていた。両側を
  常に捕捉セルにすると、吐口側のセルを通るだけの流木(下流の河道を流れてきた流木)まで止めるので、
  「そのステップに取水している側だけ」にした。
- 実材積の集め方: メモ §7.4 は par_sum_rows を挙げていた。セルごとの値を既存の allreduce で共有してから
  同じ順に足す方が、collective を増やさず、足す順序もランク数に依らない。

**定式の出どころと仮定(独自)**: 構造の係数 C_A = L C_D a/(1 − φ)³(§50.7)で、開口の断面 B × D を
厚さ L・充填率 φ の集積が覆うとして L φ = V_j/(B D) と置いた。満管はエネルギー式の損失の和に足す。
堰は、限界流の断面の手前で損失 C_A u_c²/2g が出るとして H = y_c + (1 + C_A) u_c²/2g、u_c² = g y_c から
y_c = H/(1.5 + C_A/2)、流量は (1 + C_A/3)^(−3/2) 倍。この倍率を本間公式の流量に掛け、潜り越流にも
同じ倍率を掛ける(近似)。損失を限界流の断面の流速で見積もるので、集積の位置(開口の手前の深い所)の
流速で見積もるより大きく出る。照合できる実測はない。

**知っている限界**(利用者ガイド driftwood.md の「できないこと」と driftwood_models.md §6 に書いた):
- 取水セル群に入った流木は、カルバートへ向かう流れの割合によらず全量が集積する。流れの一部だけが
  カルバートへ向かうセル(河道の本流のセルを取水セル群にした樋管)では、閉塞を過大に見積もる。
  直す候補は「カルバートが引いた水の割合だけ捕捉する」規則(1 ステップの捕捉量 = hd × Q Δt /
  セル群の水の体積)で、行き止まりの配置では今の規則と同じ結果に近づく。メモで合意した範囲を
  超えるので実装していない(handoff)。→ 2026-11-13 にこの規則に変えた(§50.11。この節の「捕捉」と
  検証の記述は、変える前の「全量」のときのもの)。
- 損失は V_j/(B D) だけの関数で、流木の長さと開口の寸法の比、集積の形、水位と集積の位置の関係を見ない。
  集積は減らず、流量は 0 にはならない。

### 50.9 例題 bridge_wood_jam と、濡れた河岸に接する河道の 2 つの性質(2026-11-12)

**例題**(examples/bridge_wood_jam。利用者の判断「推奨で」で、第 2 段の次に作った。計算本体の変更なし):
- 構成: 1600 m × 300 m(Δx = 5 m)。幅 20 m・満杯水深 3.5 m の掘り込み河道(勾配 1/500、n = 0.03)、北に

**例題の準備で分かった既存の性質(計算本体。この作業では直していない)**。検討メモ §6.8 (2) の「薄く濡れた

1. **濡れた高い河岸のセルへ、河道の水が移れる(エッジ水深の頭打ちが乾いたセルにしか掛からない)**

     移流項で生じたエッジ流速 × 平均水深(河道 2.9 m と河岸 0.1 m なら 1.5 m)で河岸へ移れる。

     水位は河岸より 0.2〜0.9 m 低い)。最大浸水深の図に細い筋として出る(0.1 m 以上は 101 セル = 0.25 ha)。

### 50.10 捕捉率を集積量の連続関数に(dw_jamgrow の意味の変更。2026-11-12)

**経緯**: 例題 bridge_wood_jam の報告(捕捉の仮定で迂回流量が 4〜60 m³/s と変わる)に対して、利用者から
「捕捉率は集積率の関数にはならないの?」の問いがあった(2026-11-12)。§50.7 の実装は、捕捉率 E が一定で、
dw_jamgrow を与えたときだけ「集積量が閾値を超えたセルは E = 1」に切り替わる 1 段だった。連続関数の案と
スクラッチの試験の結果を示し、利用者の判断(「推奨で」)で置き換えた。

| 論点 | 決定 | 退けた案 |
|---|---|---|
| 関数形 | E_eff = E + (1 − E)·min(w_j/w_full, 1)、w_full = dw_jamgrow。パラメータは 1 つのままで、意味が「閾値」から「全量になる集積量」に変わる | 1 段の切り替えのまま(与えるかどうかで結果が大きく変わり、閾値に物理的な意味を付けにくい)。折れ線の表を与える(入力が増える) |
| 引数 | セルの集積量 w_j(水面を覆う量) | 水柱を占める割合 w_j/(φ h)(流木は水面を流れてくるのに、水位が上がるほど掛かりにくくなる) |
| 目安 | φ d(充填率 × 代表直径 = 流木 1 層ぶん。既定で 0.09 m³/m²)の何倍か。既定値は置かない(未指定 = 捕捉率は一定) | 既定で有効にする(何層で全量になるかの根拠がない) |

**実装**: m_driftwood_calc の (2b) の 1 か所。w_j ≥ dw_jamgrow は分岐で 1.0 にする(E + (1 − E) の丸めで 1 を
割ると、全量の分岐に入らないため)。カルバートの流入口の捕捉(culv_jam。全量)は変わらない。dw_jamgrow を
与えない計算は、式の上では変わらない。

**解**: 捕捉セルの面積あたりに届いた流木の累積を A とすると dw_j/dA = E_eff(w_j) で、
w_j = E w_full/(1 − E)·[exp((1 − E)A/w_full) − 1](A ≤ A* = w_full/(1 − E)·ln(1/E))、
w_j = w_full + (A − A*)(A > A*)。一様な流れで全量が捕捉セルを 1 回通る構成の検定に使う。

**関数形の根拠**: 関数形と目安は独自(文献の式ではない)。捕捉した本数が少ない間は捕捉割合が小さく、
ある本数(その実験で 30 本)を超えると投入した全部が捕捉される、という水路実験の記述が検索の要約に
あった(国土交通省の河川砂防技術研究開発の報告。www.mlit.go.jp は作業環境の接続の許可の外で、原文は
未照合。題名・著者も未確認)。Schalko らの橋脚での集積の確率の実験は、流木の長さ・接近流速・流木が
まとまって来るかどうかで確率が変わるとする(同じく検索の要約)。

**例題での違い**(bridge_wood_jam の基本のケース。E = 0.3、供給 180 m³。スクラッチの試験):

### 50.11 カルバートの流入口の捕捉を「引いた水の割合」に(culv_jam の捕捉の規則の変更。2026-11-13)

**経緯**: §50.8 の「知っている限界」の 1 つ目(取水セル群に入った流木は、カルバートへ向かう流れの割合に
よらず全量が集積する。本流のセルを取水セル群にした樋管・取水口で閉塞を過大に見積もる)を、そこに挙げて
いた候補の規則で直した。例題 bridge_wood_jam の報告のあとに示した推奨の 1 つで、利用者の判断
(「推奨で」。2026-11-13)。

| 論点 | 決定 | 退けた案 |
|---|---|---|
| 捕捉する量 | 取水している側のセルごとに、流動流木 hd のうち、このステップにカルバートが引いた水と同じ割合 Δh/(h + Δh) を wj へ移す | 全量(§50.8)。捕捉率を利用者が与える(水面に浮く流木が流入口の前を通り過ぎる、といった水と流木の動きの違いを表せるが、根拠のない与件が増える) |
| 引いた水深 Δh | 汎用転送(m_swflow_enc_bc の boundary_h)と同じ式。目標の体積 \|q\|Δt をセル群に等分し、gv・wfrac で水深にする | 実際に汲めた体積を boundary_h から受け取る(引数か状態が増える。違いが出るのは汲み切るステップだけ) |
| 引く前の水深 | h + Δh(h は引いた後 = m_driftwood_calc の時点の水深。断面形 σ のセルは矩形換算水深 sect_vh = 体積) | ステップの頭の水深を別に持つ(状態が増える) |

**根拠(独自)**: カルバートは流木を通さないので、水と一緒に入るはずだった流木が流入口に溜まる、とみなす
(よく混ざったセル)。水質の物質を構造物が運ぶ割合(intake_cq。§30.10)と同じ考え方で、文献の式ではない。

**実装**(m_driftwood の 1 か所。順序の (0)):
- 取水している側は従来どおり目標流量 `b%struct(ist)%q` の符号で決め、セル数 ncs は q > 0 なら ncin、q < 0 なら
  ncout(汎用転送と同じ)。`qcell = |q|Δt/(ncs Δx Δy)`、`dht = qcell/colfac`、`w = hd·dht/(hh + dht)`
  (hh = max(h, 0)。σ のセルは max(sect_vh(h), 0))。hd から w を引き、wj に足し、台帳 vrow(j,6) に積む。
- 水が足りずに汲み切ったセルは、引いた後の h が 0 なので w = hd(全量)になり、実際に汲めた割合と合う。
- q・ncs は全ランクで同じ値(makebdc と namelist)、更新は自帯のセルだけ(owner-compute)。collective・
  確保・保存の形式は変わらない。culv_jam = 0 のカルバートと、culv_jam = 1 のカルバートがない計算は、
  この分岐に入らない(従来とビット同一)。
- 順序の関係: swflow_enc のステップは、流動流木の移流 → boundary_h の転送 → 更新の順で、その後に
  m_driftwood_calc が呼ばれる。(0) の時点の hd は移流の後、h は転送の後なので、h + dht が引く前の水深に
  なる(汲み切りを除く)。

**性質**: 捕捉はセルの流木の濃度 c = hd/h(水の体積あたり)を変えない(水と同じ割合を除くため)。
取水セルに上流から入る流量を Q_in、カルバートがそのセルから引く流量を Q_c、下流へ出る流量を Q_in − Q_c と
すると、定常では移流の後の hd1 = c(h + Δh)、捕捉 c Δh(= c Q_c Δt / セルの面積)、移流の収支から c は
上流から来る濃度に等しい。したがって集積する割合は Q_c/Q_in で、流木がまとまって通る場合も、流れが定常なら
時間で積分して同じ比になる。セルの水が全部カルバートへ向かう配置(Q_c = Q_in)は全量が集積し、その速さは
セルの水が入れ替わる時間(セルの水の体積 ÷ 引く流量)で決まる。

**§50.8 からの変化**:
- 行き止まりの配置(test/driftwood の構成 6・6a)でも、集積は最初のステップでは出来上がらず、数十分かけて
  出来上がる(6: 10 分で 97.8 %、20 分で 99.9 %。6a: 94.9 %、99.7 %)。終了時の流動流木は 0 ではなく、
  指数的に小さい値(1e-66・1e-35 m³)になる。
- 検定 Check_woodjam.py culv は、流量則を「その時刻の集積 V_j(t)」の損失で評価する形に変えた
  (driftwood.csv を dt_disp の半分の間隔で記録し、区間の両端と中点の vol_jam_m3 を読んでシンプソン平均に
  使う)。終了時の流動流木の条件は「0」から「V_j の 1e-6 倍未満」にした。
- 本流の水の一部を引くカルバート(樋管・取水口)では、引いた水の割合だけが集積する。利用者ガイドの
  「取水セル群は、流れの全量がカルバートへ向かうセルにしてください」の注意を外し、できないことに
  「流木は水と同じ割合で流入口へ向かうとみなす(捕捉する割合は与えられない)」を書いた。

**知っている限界**: 水と流木の動きの違い(水面に浮く流木が流入口の上を通り過ぎる、流入口へ吸い寄せられる、
スクリーンで止まる、細い流木が通り抜ける)は表さない。取水セル群の中の配分は、汎用転送と同じ等分で、
流入口に近いセルほど多く引く、といった分布は持たない。同じセルから culv_jam = 1 のカルバートが 2 本以上
引くときは、1 本ずつ順に割合を掛ける(まとめて引いた割合との差は Δh/h の 2 次)。

**検証**(2026-11-13。gfortran 13.3、Open MPI 4.1.6):
