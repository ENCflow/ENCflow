## 95. エッジ水深の上流側を新しい流速の向きで決める(f_hcap_upwind。静止から流れ出す辺の頭打ちの抜けの修正。2026-11-05 挙動変更)

**背景**: §94 の調査で、上流側を前ステップの流速 uve0 の向きで決める cap_he_upwind は、uve0 = 0 の辺(静止
から流れ出す辺、前ステップに過大な流出の抑制で 0 にされた辺)で頭打ちが掛からず、エッジ水深が両側の平均に
なることがわかった。深い水に接する dd 未満の水膜(浸透で薄くなった斜面、水位の下がった池の縁)では、流出が
水膜を大きく超えて辺ごとの抑制で 0 にされ、次のステップも流速 0 から始まる繰り返しになる。ex_flux の大半は
この回数だった(examples/ashfall_lahar の param_water で 49,446 回のうち 49,430 回など。§94)。向きが反転する
辺でも、反転前の向きの上流側(反転後の下流側)で頭打ちしていた。

**変更**: calc_kth_flux の RK の各段で、tae・tge・dtl をエッジ水深の頭打ちより先に求め、上流側を半陰解法の
分子 upre = uve0 + (tae + tge)·dtl の符号で決める。半陰解法 uve1 = upre/(1 − tfe·dtl) の分母は 1 以上(摩擦・
抗力・降伏の tfe ≤ 0)なので、upre の符号が新しい流速の向きになる(その後の乾燥側の頭打ち・送り手の乾燥・
降伏の静止は流速を 0 にするだけで、向きは変えない)。波の外力(wv_flow > 0)の項 wfe/h̄·dtl も分子に入れる。
Stokes 輸送の摩擦の項(wv_flow = 2 の −tfe·use_·dtl)は tfe(エッジ水深による)を含むので予測に入れない
(独自の簡略化。予測が外れうるのは Stokes 輸送の摩擦が駆動を上回る辺だけ)。f_hcap_upwind = 1・2 の両方に
効き、0(頭打ちなし)には関係しない。向きが前ステップと同じ辺は従来と同じ(頭打ちの側が同じ)。新しい
選択肢は作らない(前ステップの向きで決める形は頭打ちの抜けで、残す理由がない)。init_enc_status の初期流量
mn1 = uv·he は流速の向きのまま(流速と流量の整合。§7)。

**効果**(§94 の P の上に作業用の木で試作して比べた。-Ofast と -O2 の計測版):
- ex_flux の累計: ashfall_lahar の param_water で 49,612(P のみ)→ 256(辺ごとの抑制 168、セルの合計の抑制
  88)。gwwidth(本体・対照)・gwsect・damwq・sewer_wq で 0。負の水深は試した範囲で 0。残る辺ごとの抑制は
  静止から流れ出す辺 114・向きの反転 0(上流側で頭打ちしても 1 辺だけで水膜を超える流出。セルの合計の抑制と
  合わせて水深は負にならない)。
- 結果: reference を持つ 42 ケースのうち 16 ケース(chichibu・coastal_drain・culvert・dambreak・damwq・gwsect・
  gwseep・gwwidth・kdpart・sewer_wq・tide・tracer・wfdoppler・wqbound・wqstruct・nhbreak)が変わる。最大水深・
  最大単位幅流量・貯留の差は、最大で tide の Q_max 0.19 %・gwsect の h_max −0.27 %、ほかは 0.05 % 以内
  (chichibu は 0.001 % 以内)。最大流速 V_max は薄い水膜のセルで大きく動く(gwsect 0.010 → 0.044 m/s、gwwidth
  0.108 → 0.060 m/s(P との比較)、wqstruct +23 %、nhbreak +5.8 %)。examples/ashfall_lahar の param_water の
  測点・測線のピーク流量・水深は 5 桁まで同じで、ピークの時刻が 0.2〜0.7 分ずれる。
- 薄い水膜は深い側へ流れ出るようになる(従来は止められて、浸透・蒸発するか dd を超えるまで溜まった)。物理と
  しては自然だが、薄い水膜の多い計算では浸透と流出の分け方がわずかに変わりうる。
