## 78. スカラー輸送のリンクごとの MUSCL(f_scalar_scheme。2026-10-13 設計合意・実装)

### 背景と計測

地表のスカラー(浮遊砂 hs・水質 cq・塩水層 hss・流木 hd・瓦礫 hbd)は
`advect_scalar` で、連続式と同じエッジ流量 m_e に風上セルの体積濃度を
掛けた 1 次風上・前進オイラーで運ばれていた。test/tracer(新設)で
数値拡散を計測すると、縦断は修正方程式どおり D = u·Δx·(1 − Cr)/2
(u = 0.91 m/s、Δx = 10 m で 4.3 m²/s。浅水流の dt ではスカラーの Cr が
0.1〜0.2 なので実質 u·Δx/2 で格子幅に比例)、横断は流れがなくても
Dy = 0.293·u·Δy(2.7 m²/s)。横断の拡散は ENC の 8 方向リンクで x 方向の
一様流でも質量流束の 0.293 ずつが両斜めへ振り分けられ、受け手が両斜めの
供給元の平均(3 点平滑化)を受け取るために生じる。物理の分散(Elder 型
縦断 0.3 m²/s、横断 0.01〜0.3 m²/s)を 1〜2 桁上回る。

影響が実用上大きいのは、局所の濃度・密度のピークが判定を駆動する量
(流木・瓦礫込みの流体力 fd と家屋破壊判定、土石流の濃度依存レオロジー、
水質のピーク濃度、塩水くさびの先端)。総量・堆積量には効かない。乾いた
セルへ進む前線は供給元の濃度をそのまま持ち込むので、縦断の拡散が効くのは
湿潤域内の濃度勾配(清水との混合、点源、合流)だけ。

### 設計

- `&list_enc` の `f_scalar_scheme`(1: 1 次風上 = 旧既定、3: MUSCL = 既定。
  2026-10-13 に 1 から昇格。下記)。1 で従来とビット一致。地表の全スカラーに
  一括で効く。地下水の同伴輸送(cg)は対象外。
- 面値: 各リンクの向きに沿って風上 c_up・風下 c_dn・さらに風上 c_uu の
  3 点から c_face = c_up + ψ(r)/2·(c_dn − c_up)、r = (c_up − c_uu)/(c_dn − c_up)、
  ψ = van Leer(流れの移流項 `face_value` と同じ式。§68.6)。c_dn = c_up なら
  面値 = c_up(一様濃度は一様のまま)。濃度は c/vh(σ 有効時は矩形換算
  水深。供給元と同じ定義)。
- 斜めリンクは斜め方向に沿って再構成する。横断に線形な濃度場では面値が
  リンク中点の値になり、受け手の 0.414/0.293/0.293 の重み付き和が中央値に
  一致して横断の数値拡散の主要項が消える。
- 1 次に退化する条件: 境界面からの流入(cbin)、風下が領域外・海セル・
  乾燥(h < dd)、さらに風上のセルが確保範囲外・無効・海・乾燥。壁・乾床・
  規定境界は濃度勾配を供給しない(§69.9 の far_ok と同じ理由)。c_uu は
  j ± 2 までで帯+ハロ 2 に収まり、スカラーのハロ交換(par_halo_cell、
  幅 nhalo = 2)で埋まっている。
- 質量流束・通過幅係数・分担率 α・乾燥エッジや海セルの除外条件は不変
  (流束形式の保存性は保たれる)。新しい状態・保存状態なし。

### 計測(test/tracer。gfortran -Ofast)

| 量 | 1 次風上 | MUSCL | 比 |

| 縦断 D(Δx 10 m、dt 2 s、Cr 0.18) | 3.9 | 0.8 | 0.20 |
| 縦断 D(Δx 20 m、dt 2 s、Cr 0.09) | 8.7 | 2.6 | 0.30 |

残る縦断の拡散は前線の両端(極値)で限定器が 1 次に退化する分。濃度場に
負値・100 % 超えなし(Check_tracer.py で検定)。

### 既定を 3 にした判断(2026-10-13)と副作用

- 実装当日は 1 を既定に残したが、同日の影響調査(下の検証)を踏まえて 3 に
  昇格させた。理由: (1) 1 次の数値拡散は格子幅に比例し横断は斜め配分の
  産物で、物理分散を 1〜2 桁上回る。格子を変えると答えが変わる既定は
  校正の土台にならない。(2) 定数の校正はまだ行われておらず、校正後に
  変えると校正のやり直しになる。(3) 保存性は同一、限定器で正値・単調、
  境界面・乾燥・海の近傍は 1 次に退避するので最悪でも従来と同じ。全 test
  の自己検証が PASS、MPI はビット一致、追加メモリなし。(4) 流れの移流項
  (f_advection_scheme。§68)と違って水理には触れず、正解(解析解の拡散)が
  明確で実測照合を待つ理由がない。
- 濃度が流れに戻るプロセス(土石流の濃度依存レオロジー、流木・瓦礫の
  荷重判定、水質のピーク)はピークが高く出る方向に変わる。校正値を 1 次の
  鈍った濃度場で合わせてある場合は `f_scalar_scheme = 1` で従来の結果に
  戻せる(比較・退避用に残す)。
- 単調性の保証は 1 次元では流出クーラン数 ≤ 1/2(限定器 ψ ≤ 2)。浅水流の
  dt では満たす。多次元では厳密な TVD ではなく、極値のクリップと僅かな
  行き過ぎの可能性がある(計測では出ていない)。
- 薄い水(h ≈ dd)では濃度 c/h のノイズで r が乱れるが、退化条件で 1 次に
  落ちるため発散しない。乾湿前縁付近は実質 1 次。
- コスト: カーネル 2〜3 倍、ステップ全体で数 %。メモリ増なし。

### 検証(2026-10-13。gfortran -Ofast / Open MPI)

- 無効時(既定 1): test/suspend・sedinflow・salt・damwq・sewer_wq・tracer の
  回帰 PASS(identical)。
- 有効時(3): test/tracer の 4 構成で負値・行き過ぎなし。逐次・np=1・2・4 の
  Log・wq.csv・濃度場がビット一致。-Og -fcheck=all -finit-real=snan の
  MPI np=2(規律 3)が完走。-Ofast np=2 との差は Runge 列(適応 RK の
  再計算回数)の 0.5 % と濃度場の印字最終桁(1e-4 mg/L)で、最適化による
  丸め差(§28.3)。トップレベル make で utils の追随漏れなし。
- **-fcheck が捕らえた実バグ(修正済み)**: 最初の実装は、近傍が領域外の
  境界面(自由流出の面)でも風下セル (in, jn) を添字にして g%sw・s%h を読み、
  j = ny + 1 の範囲外参照を起こした(-Ofast では黙って通る)。境界面は
  流入・流出とも 1 次のままにし、近傍が領域内のときだけ MUSCL を適用する
  形に直した。確保範囲に触れる変更は -fcheck の np>=2 を先に回す規律 3 の
  とおり。
- **オーバーフロー(SIGFPE)2 件(修正済み。2026-10-13)**: 既定を 3 にした
  試行で examples/landslide_tsunami(param_debrisflow)が -ffpe-trap=overflow
  で停止した。(1) muscl_face の比 r = (c_up − c_uu)/d は d が 1e-300 級の
  とき溢れる。比を作らず、a·d > 0 のとき a·d/(a + d)(= ψ(r)·d/2 と数学的に
  同値)、そうでなければ c_up と書き換えた。tracer 4 構成の結果は不変、
  np=1・2・4 のビット一致も不変。(2) m_geomorph_bedslide の plunge_cells の
  min(1, hw/hbq) は hbq が極小正値(hs がアンダーフロー寸前で hb = 0)の
  とき溢れる。hw >= hbq なら 1 と分岐して割らない形に直した(値は同一。
  test/bedslide・nhbottom は既存 reference と一致)。濃度の 1e-300 級の裾は
  1 次でも生じるが、1 次は濃度の比を作らないので表に出なかった。
- **既定を 3 にした場合の影響調査(2026-10-13。既定は 1 のまま)**: 全 test
  を既定 3 のビルドで実行した。解析解・保存則の自己検証を持つケース
  (avalanche・bedslide・bldgdebris・curvature・debris・driftwood・sedinflow・

  のみで、damwq・salt は identical、tracer 6e-8、gwseep 1.5e-6、sewer_wq は
