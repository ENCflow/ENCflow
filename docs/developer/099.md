**設計**:
- `&list_lavaflow` の `lv_diagratio`、`&list_glacier` の `gl_diagratio`(範囲 [0, 1]。0 = 従来の 4 近傍)。
  gl_diagratio は SIA 流動(f_glflow = 1)のときだけ読む(過程が無効なら読まない。既定を変えても停止が
  要らない形)。list は読むだけ(§12)。
- 通過幅: §96 のクリープの 9 点と同じ規則(短い辺に d、長い辺は (Δmin/Δmax)² 倍。伝導度 = 通過幅/
  中心間距離)。溶岩と氷河で共有する部品は新しいモジュール m_flow8(flow8_weights・flow8_open・
  flow8_diag_gs2。状態を持たない純関数。z・h は帯確保の配列を assumed-shape + 下限指定で渡す。§12)。
- 係数 D: 4 近傍と同じ式(溶岩は Bingham の cf·hf²(2he + h0)、h0 = τ_y/(ρg|∇s|)。氷河は SIA の
  Γhe⁵|∇s|² + As(ρg)³he⁴|∇s|²)。|∇s| は軸のエッジで √(Sn² + St²)(§51.4・§45.1 の edge_tslope)、斜めの
  エッジで角点の勾配: 対角の差 Dn = s_n − s_c と、角を共有する 2 セル A・B の差 Dab = s_A − s_B から
  x・y 成分を解き(Δx ≠ Δy でも成り立つ)2 乗和を取る。A・B は流れのあるセルだけを使い(edge_tslope と
  同じ考え。流れのないセルの地盤高は流れの面ではない)、片方だけなら角点の値 (s_c + s_n)/2 との片側
  差分の 2 倍、両方なければ Dab = 0。Dn ≠ 0 なら |∇s| > 0 なので h0 の割り算は安全。
- 振り替え(案 A): 水の f_opening_dynamic = 3(§68.14・§68.41 の build_fwd・sblk)と同じ規則を流れの面
  s = z + h(h = 溶岩厚・氷厚)に当てはめる。始点 c から斜め先 d への塞がり率は clamp(dz/h_c, 0, 1)、
  dz = min(z_d − z_c, z_d − z_o, κ)(o はエッジのもう一方の端、κ は局所の平面からの盛り上がり = 一様な
  斜面の上流側の地盤を壁と数えない)。領域外・無効・海のセルは 1(壁。溶岩・氷は海へ流れないので、水の
  sblk と違って海も壁)。軸のエッジ: 界面を横切る斜め 4 本(c から n の左右、n から c の左右)の塞がり率の
  和の 1/2 = nb を ld·面長/距離 に掛けて伝導度に足す(水の (lp + nb·ld)/lp)。斜めのエッジ: 角を共有する
  2 セルへの両端からの斜め 4 本の和の 1/2 を (自然幅 − 斜めの通過幅)/2/距離 に掛けて足す(水の
  1 + sh/l8_d。4 本とも塞がると通過幅が自然幅 ΔxΔy/√(Δx² + Δy²) になる)。流れの厚さで毎サブサイクル
  評価する(表にしない。地形も溶岩の固化・氷河の侵食で変わる)。
- 構造: パスA(flow8_coef)で各エッジの伝導度 G_k = D·(cw + 振り替え) を作業配列 ge(d > 0 のときだけ
  確保。q と同形)に置き、自帯のセルごとの和 Σ_k G_k(8 方向)の全域の最大から dt = cfl·A/max Σ G
  (正値性 = 自セルの係数 1 − dt Σ G/A >= 0)。4 近傍の式 cfl·0.5/(D_max(1/Δx² + 1/Δy²)) の一般化で、
  セルごとの和を使うぶん大きい(D が一様なら一致)。パスB(flow8_flux)は G·(s_c − s_n)、ドナー律速は
  1 エッジ 1/8(8 エッジの合計 ≤ 全量。4 近傍は 1/4 のまま)。パスC(発散・熱量の更新)は共通(もともと
  8 方向を集計していた)。d = 0 の経路はコードを変えていない(if の分岐に入れただけ)。
- 溶岩の温度: 斜めのエッジでも熱の流量 = 流量 × 面の温度。MUSCL(§97)は斜めのエッジの向きの 3 点
  (送り手のさらに風上は斜めの先)で、範囲の切り詰めは 8 方向のまま(§97 の導出は向きによらない)。
- ハロ: 読むのは書き手と近傍とその横 ±1(書き手の行 js..je+1 で行 js−1..je+2、列は行窓 ±1)と、MUSCL の
  送り手のさらに風上(±2)= ハロ幅 2 の内側。新しい状態・保存はない(ge は作業領域)。確保範囲は変えて
  いない。
