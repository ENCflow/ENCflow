## 86. 石灰岩の溶食 f_dissol(カルスト地形。2026-10-21 実装)

設計の正本は docs/karst_plan.md(定式化の根拠・限界・第 3 段の検討メモ)。
ここには決定事項と検証記録を残す。規約: 溶食は基岩 z − sd に働く(土層 sd は
残渣・岩屑の受け皿と浸透の容量)。岩壁の崩落は main の f_rockfall を基岩モード
rf_bedrock = 1 で重ねる(§48.7 末尾。独自の岩盤版は 2026-10-22 に取り下げ)。
例題 karst・tower_karst の README は 2026-11-02 に組み直した(§48 冒頭の注記。計算は不変)。

### 86.1 決定事項

- **位置づけ**: 「カルスト地形を再現できるか」への答えは「概算の加算的
  プロセスとして、形成傾向の実験まで可」。実在の洞窟系の幾何は方針 2
  (ラスタ純化)に反するため対象外。カルストの**水文**(乾谷・内陸排水・
  湧泉)は管路連続体層 §46 の吸込穴と吐口で既に表せる。足りなかったのは
  「水に溶けて質量が消える = z が下がって土砂が出ない」更新だけ。
- **m_geomorph の加算的フラグ f_dissol 1 個**に面的溶食と集中溶食を統合
  (submodule m_geomorph_dissol)。風化 f_wthr(sd を増やし z を保つ)の
  対として z を下げ sd を保つ。残渣率 dissol_fres > 0 のときだけ sd を
  共動更新(溶けた岩 × 率が土層に残る)。
- **定式化**: w = k_d · f_sol · (F_r + f_sink · F_sink) · morfac。
  k_d = c_eq/ρ_r(水 1 m あたり溶ける岩の厚さ。既定 100 mg/L ÷ 2500 kg/m³
  = 4e-5 m/m → 涵養 1 m/yr で 40 mm/kyr = 文献域 20〜100 mm/kyr)。
  F_r は更新間隔に積算された面的涵養水量、F_sink は吸込穴(管路層の枡)
  流入水量。炭酸平衡は解かず c_eq 1 個に畳む(§0「物理量は直接与える」)。
  飽和による減衰はなし(未飽和一定率 = White 型の最大削剥速度モデル)。
- **水量の源は記録場で受ける(fxg と同型の契約。§30)**: s%fxd(涵養。
  bucket / greenampt の鉛直交換が allocated 判定で書く。dissol_src = 2 では
  geomorph 自身が毎ステップ s%pre·dt を積む)と s%fxdi(吸込穴流入。
  conduit の枡流入が書く)。確保は m_geomorph_init、消費とゼロ戻しは
  calc_dissol。**wq の s%fxg と共用しない**: wq は毎ステップ消費するが
  geomorph は idt ステップの間欠実行で積算が要り、同じ場を 2 者が消費
  すると順序依存(wq_calc → geomorph_calc の順で geomorph は常に 0 を見る)。
- **記録場は私有ファイル geomorph_dissol.dat で save/restore(契約 5)**。
  更新間隔の途中で save すると積算が失われ、リスタート往復が ULP=0 で
  閉じなくなるため。面数は fxd 1 面 + sink 有効時 fxdi 1 面。
- **可溶率の分布 fn_dissol** は rank0 が全域を読んで par_scatter_cell で
  帯配布(方式 2。conduit の read_map_scatter と同型)。
- morfac は記録場の水量に掛ける(dts = dt·idt·morfac と同じ意味 = 1 回の
  更新は同一イベント morfac 回ぶん)。局所・線形のため dzmax 型の安全弁は
  不要。海セル(侵食基準面)は対象外だが積算水量は消費して捨てる(次の
  間隔へ持ち越さない)。台帳は行部分和(real64)→ par_sum_rows で決定的。
- 既定値(§62 の流儀。gm_param で採用値を表示): dissol_ceq 100 mg/L
  (土壌 CO₂ を経た涵養水の代表。裸岩の雨水 50〜80、土層下 100〜300)、
  dissol_rho 2500 kg/m³。dissol_fsink(校正値)は 1.0 を既定に置く
  (0 で項なしの明示になるため番兵は使わない)。
- dissol_src = 1 で fn_gwflow 未指定は par_stop(記録が恒久 0 = 設定齟齬。
  降雨源を案内)。dissol_sink = 1 で fn_gwflow 未指定も par_stop。
  f_gwconduit の有無は geomorph init 時点では分からない(gwflow init が
  後)ため、枡がなければ項が 0 のまま動く旨を init で表示するに留める。
- **第 3 段(管路の成長 = 連続体版の洞窟形成)は未実装**。conduit の
  「cap・cnd・zbot は静的」契約の改定を伴うため、gwflow 側の独立フラグ
  として別途合意してから着手する(karst_plan.md §5、handoff 1n2)。

### 86.3 側方溶食 dissol_lat(2026-10-22 実装。karst_plan.md §2.5)

- **動機**: 床だけの溶食では吸込穴セルが幅 1 セルの穴になる
  (examples/karst の限界)。漏斗形ドリーネ・コックピットの併合・タワー
  カルストの裾のノッチには、湛水に接する岩壁の溶食が要る。
- **定式化は配分**: 湛水セル w(h > dd)の溶解能 W_w = k_d·F_w·morfac の
  割合 p(`dissol_lat`)を、w の水面より床が高い 8 近傍の陸セル(岩壁)へ
  接触幅比(軸 Δx、斜め Δx·2/(2+√2))で配り、残りを床へ。壁のない湛水
  セルと乾いたセルは床に全量。独立の速度則(berode の K_b 型)にしなかった
  のは「水 1 m³ が溶かす岩は c_eq/ρ_r」の意味論を保つため(湛水の大小に
  無関係に壁が溶けるのを避ける)。壁の後退は壁セルの z の低下(berode と
  同じ慣習)。残渣は壁セルの sd へ(簡略)。
- **3 パス・owner-compute**: (1) 自帯で W を壁向け qw / 床向け wfl に分け
  (先頭で z・h のハロを交換し、時刻 n の値で壁判定)、(2) qw のハロ交換
  後に各セルが近傍の qw から分け前を dzl に集める(w の壁集合の重み和は
  ±2 行 = ハロ幅で足りる。z は読むだけ = OpenMP 競合なし・順序固定)、
  (3) まとめて適用。p = 0 では従来の 1 パス(ビット一致)。
- **自動配分 dissol_lat = −1**(同日追記): p を固定すると格子幅と湛水深に
  依存する(examples/karst で p = 0.3 は壁の分け前が小さく、穴の幅がほぼ
  変わらなかった)。濡れ面の面積比 p_w = h·ΣL/(h·ΣL + Δx·Δy)(ΣL = 壁の
  接触幅の和)をセルごとに計算する方式を推奨とする(Δx = Δy を想定)。
- **検証**(test/dissol 構成 D・E): 中央 3×3 の窪みに湛水だけを置き、配分式の
  独立実装(Check_analytic.py)と Z9998 が全セル一致、総溶解能 9W が保存。
  E は降雨源で全セルに W を与え、自動配分の p を幾何から再計算して一致。

### 86.4 表面流源 dissol_src = 3(2026-10-22 実装。karst_plan.md §2.7)

- 水量 = 浸透量 + f_surf·f_b·max(雨 − 浸透, 0)。裸岩(土層 < dissol_sdsurf)
  で発生した流出水だけがその岩面で溶解能を使う。通過流は飽和とみなし
  数えない(薄い水膜の飽和距離 ≪ Δx)= 総溶解能は有界。f_surf(既定 0.3)は
  裸岩の雨水と土層下の涵養水の溶解能の比。
- 降雨の積算は私有 frn(src = 2 の fxd と同じ毎ステップ積算)。消費は
  take_water に集約(床のみ・側方溶食の両経路で共用)。frn は
  geomorph_dissol.dat の 3 面目(sink の後)。
- 検証: test/dissol 構成 F が解析値に全桁一致、更新間隔の途中の save →
  継続がバイト一致、np = 2, 4 が逐次と bil バイト一致・Log 同一。
  A〜E・reference 不変。

### 86.5 安全弁 dissol_dzmax(2026-10-22 実装)

- 1 セル・1 更新の溶食量(床 + 壁の合計。可溶率を掛けた後)を dissol_dzmax
  で頭打ちし、超過分の溶解能は捨てる(飽和とみなす。流量段階ではなく量の
  段階 = 総溶解能は減る。溶食は保存則をもたないので berode 型の「流量を
  縮める」必要がない)。既定 0 = 無効(ビット一致)。発動回数は dispose で
  警告(ランク局所)。
- 動機: examples/karst で morfac の上限(1e3)を決めていた「吸込穴に水が
  集まる正帰還の豪雨内の暴走」を、更新あたりの Δz で抑えて morfac を
  上げるため。
- 検証: test/dissol 構成 G(A と同じ浸透に dzmax = 1e-5)が Δz = −20·dzmax に
  全桁一致。A〜F・reference 不変。np = 2, 4 が逐次と bil バイト一致。
  -Og -fcheck=all の np = 2, 4 クリーン(窪みが帯をまたぐ)、-O2 の
  np = 1, 2, 4 が逐次と bil バイト一致・Log ULP = 0。A〜C・リスタート往復・
  無効時の reference は不変。

### 86.6 可溶率の地図の倍率 fn_dissol > 1(2026-11-03)

- 動機: 桂林・石林型の「屹立する柱」「側面の深い溝」は節理・割れ目帯に沿った
  溶解の集中が起点で、一様な溶食(浸透量比例)からは生まれない。2026-11-03 の
  議論(利用者): (1) 既定値は溶食の収支(Corbel/White: k_d = c_eq/ρ、涵養 1 m/yr
  で 40 mm/kyr)で、文献の削剥速度は湧泉の溶存負荷から求めたマクロ値 = 表面積の
  効果を含む。(2) 表面積が効くのは速度律速の領域(裸岩の流出水。dissol_fsurf)
  だけで、平衡(供給律速)の涵養の項は水 1 m³ あたり c_eq/ρ で頭打ち。実面積の
  換算 √(1 + |∇z|²) を入れるなら表面流源の項に限る(側方溶食は既に接触面積
  hΣL の定式化)。(3) 例題で地形がほとんど変わらないのは係数ではなく、地形時間
  (kyr vs 桂林の Myr)・流路に沿った集中の機構の欠如・割れ目の制御の欠如が原因。
- 決定: fn_dissol の上限 1 を外し ≥ 0 とする(0 = 不溶、1 = 基準、> 1 = 倍率)。
  負だけを拒む。既存の 0〜1 の地図はビット一致。
- 検証: test/dissol 構成 H(可溶率 2.0 の一様地図・残渣なし)が Δz = −2·20·W に
  全桁一致。A〜G・reference 不変。np = 2 の Log 同一。
- 併せて examples/tower_karst に準定常強制(年平均の雨 0.228 mm/h を定常に与え
  morfac 6e6 で 60 日 = 0.99 Myr)の構成 param_steady.txt を置く(README に記録)。
  残る課題(karst_plan §5): 流路に沿った速度律速の溶食(溶存濃度の輸送 + 一次反応
  + 流れの深さ依存 + 実面積換算 = 第 4 段)、深く広い谷は f_rockinc(§89)との
  重ね合わせ。

### 86.7 崖錐の溶食(2026-11-03 実装)

- 動機: examples/tower_karst の準定常強制(年平均の雨を定常に、morfac 6e6、0.99 Myr)で、
  裾に崩れ込んだ塔の岩屑(崖錐 ht = sd)が床の溶食の規約「z を下げ sd を保つ」のまま
  不死身で沈み、塔の流出水が全部浸透する裾のセルでは基岩だけが安全弁 0.3 m/更新で
  溶け続けて基岩面が −1.5 km に達した(崖錐 1.35 km の柱)。石灰岩の岩屑は岩盤と同じか
  それ以上の速さで溶けるので、物理的に必須の補正。
- 規則(apply_dissol。床・側方で共通): セルに崖錐 ht > 0 があれば dh = min(ht, w) を
  崖錐から溶かす(ht −= dh、sd −= (1−f_res)·dh(0 でクランプ)、z −= (1−f_res)·dh = 岩屑の
  残渣は土層に残る)、残り w − dh を基岩に当てる(従来: z −= (1−f_res)·w'、sd += f_res·w')。
  ht の有無は allocated(s%ht)(f_rockfall が確保)で判定し、ht 未確保・ht = 0 では従来の
  式そのもの = 既存構成とビット一致(test/dissol A〜H・reference 不変)。台帳 vtrow
  (崖錐として溶けた体積)を par_sum_rows で総括し「removed talus … m3」と報告。
- 検証(test/rockfall): 2 段構成。第 0 段 param_talus0.txt は基岩版の台地を崩して崖錐を
  作り保存(f_dissol は雨 0 で有効 = 私有 save を作る)。第 1 段 param_talus1.txt は再開し、
  崩落を凍結(rf_hc = 1000 m、rf_relax = 1e-6)して一様な雨 100 mm/h の溶食を 600 更新
  (W = 0.667 m、f_res = 0.2)当てる。Check_talus.py: ht1 = max(ht0 − W, 0)、
  z1 = z0 − (1−f_res)W、sd1 = sd0 − (1−f_res)·min(ht0, W) + f_res·max(W − ht0, 0) が
  印字桁(7e-5 m)で一致、崖錐が尽きるセル 96 と残るセル 180 の両分岐を踏む。崩落を
  凍結しないと第 0 段の残りの幾何緩和(0.045 m³)が 4〜5e-4 m 混じる(実検出 → 凍結)。
  MPI np = 2, 4 の Z/Sd/Ht が逐次と同一。
- 残る限界: 崖錐でない土層 sd(残渣・土)は溶けない。岩屑の転動距離はない。

### 86.8 岩への涵養を水量にする dissol_src = 4, 5(2026-11-04 実装)

- 動機: examples/tower_karst の基準面つき構成(param_base: 東端の河道を吐口で地下水面に
  固定、隆起で陸を上げる)で、裾の穴が地下水面を 20 m 以上突き抜け、壁の段差 10 m で
  流れが発散した(120 kyr)。原因は浸透量(src 1, 3 = Green-Ampt/バケツが土層に入れた
  水)を溶食の水量にしていること: 裾には塔の崖錐の残渣が積もり続けて土層の容量
  sd·sy が増え、その増分だけ湛水が浸透し、morfac 6e6 倍で基岩を溶かす(残渣 1 m →
  水 0.2 m → k_d × 0.2 × 6e6 = 144 m)。土層に入っただけの水は岩を溶かさない。
- 決定: 溶食の水量に「岩への涵養」= 土層/層 2 → 管路層の交換量を選べるようにする
  (src 4。5 = 4 + 裸岩の流出水 = 3 の組)。m_gwflow_conduit の層間交換(層 1/層 2 →
  管路の向き)が s%fxdr に積み(allocated 判定 = fxd・fxdi と同じ契約)、take_water が
  読んでゼロ戻し(浸透量 fxd は読んで捨てる)。交換は土層の水頭(基岩面 + 土層の水 / sy)
  と管路水頭の比較で向きが決まるので、管路の水頭が土層の水頭より高い所では涵養 0 =
  溶食が止まる。**ただし基岩面が地下水面より下でも、厚い土層に雨が溜まって土層の水頭が
  管路より高ければ涵養は続く**(下の実測)= 地下水面は溶食平野の基準面には
  ならない(「飽和帯では溶けない」機構は未実装。次項)。src 1〜3 は不変
  (ビット一致)。私有 save geomorph_dissol.dat は src >= 4 のとき fxdr のレコードを
  末尾に追加(既存構成の形式は不変)。accum_dissol_rain は src 2, 3, 5 だけで呼ぶ。
- 検証: test/dissol 構成 I(平坦、雨 30 mm/h、Green-Ampt 36 mm/h = 全量浸透、土層 →
  管路の交換 20 mm/h、src 4)が Δz = −k_d × 20 mm/h × 1 h × morfac に全桁一致
  (浸透量 30 ではなく交換量 20 に比例)。A〜H・往復・reference 不変。
- 制約: 管路層の交換は土層モデル(Green-Ampt または側方流)が前提でバケツは不可
  (m_gwflow_conduit の検査)。src 4/5 で交換が設定されていなければ fxdr は 0 のまま
  (溶食なし)= 設定誤りは init の fn_gwflow 検査までしか拾わない。
- 実測(2026-11-04。examples/tower_karst の param_base.txt、0.99 Myr): 発散はなくなり、
  隆起 200 mm/kyr に対し平野は 210 mm/kyr 溶けて釣り合い(2026-11-12 訂正: 初出の 213 は
  隆起の総量を 200 m として引いた丸め。隆起は 0.2 mm/yr × 985 626 年 = 197.1 m で、平野の
  溶食による地表の低下は 206.6 m = 210 mm/kyr。11-12 の再計算でも同じ)、塔は比高 66〜69 m・
  安息角の円錐として残る(README の「基準面」の節)。一方で (1) 吐口は放流 0: 溶けた岩の
  残渣(平野 24 m)の貯留が管路の水を吸い、地下水面は −5 → −9.5 m に下がった(morfac で
  岩 → 土の転換が水理時間の涵養より速い準定常化の副作用。fres = 0 で消えるはず)。
  (2) 平野の基岩面は地下水面の 24 m 下まで溶けた(土層の水頭 > 管路水頭が続くため)。
  地下水面を溶食平野の基準面にするには「飽和帯(基岩面 < 管路水頭)では面的溶食を
  止める/減衰させる」項が要る(第 4 段の飽和減衰 c_eq − c と同じ場所。未実装)。
