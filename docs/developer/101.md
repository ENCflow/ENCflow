## 101. 混合体流動の抵抗則を斜面に沿って評価する(f_gravity_correction ≥ 2。2026-11-06 挙動変更。案 A)

- **背景と判断**: §93 の 2 は、マニングの摩擦(水の流れと、マニングと合成する混合体流動の抵抗則 f_dbres = 1・5 の
  マニングの項、希薄側でマニングに退化する辺)だけを斜面に沿う速さと地盤に直角な水深で評価し、混合体流動の
  抵抗則の残り(降伏・Voellmy の乱流項・江頭の層流則・高橋・中川の石礫型と掃流状集合流動)は水平の流速・
  鉛直の深さ・g_e のままだった(§93「適用しないもの」)。文献の値(RAMMS の μ・ξ、江頭・高橋の式の速さと厚さ)は
  斜面に沿う量の定義で、§93 で 2 を既定にした理由がそのまま当てはまる。比較案(2 の中で直す案 A と、別の値を
  足す案 B)を示し、利用者の判断(2026-11-06「全て推奨で」)で案 A にした。水平の形は 1 で残る。同じ判断で、3 の
  降伏の垂直応力と停止判定の接線成分を g′ に揃え(§100 の追記)、慣性のない底層の Voellmy は記録だけにした
  (下の「適用しないもの」)。
- **定式化**(本書の導出。§93 のマニングと同じ組み立て): 斜面に沿う抵抗の応力 τ を斜面に沿う速度 V_s の逆向きに
  与えると、斜面の面積あたりの力を水平面積あたりに直して、水平の流速の減速度は τ V/(ρ_m h_n |V_s|)
  (h_n = h cos θ)。r = |V_s|/|V| = √(1 + (V̂·∇z)²)、c = cos θ として、水平の形(1)の半陰の係数に対する倍率は
  - 降伏(クーロン a_y = g_e tanφ sC/(1+sC) とその江頭・高橋の形、Voellmy の μ、一定の停止応力 τ_y/(ρ_m h)):
    斜面に沿う減速度は g c μ' = a_y/c と τ_y/(ρ_m h_n)、係数は −(a_y/c)/(r|V|) → 倍率 fy = 1/(r c)。最急勾配の
    向き(r = 1/c)で 1、等高線に沿う向き(r = 1)で 1/c。
  - 速度の 2 乗の抵抗: Voellmy の乱流項 g V_s²/(ξ h_n)(g_e → g、h → h_n)、江頭の層流則と高橋・中川の石礫型
    (f_b ∝ (d/h)² の h → h_n、速さ |V_s|) → fv = r/c³(最急勾配の向きで 1/c⁴。30° で 1.78)。掃流状集合流動
    (∝ (d/h)¹)→ fv1 = r/c²。
  - Voellmy の等流は V_s² = ξ h_n (sin θ − μ cos θ)(RAMMS と同じ)。1 の形はこの V_s² の 1/c⁴ 倍(30° で速さ
    1.33 倍)になっていた。
  - 停止判定(§28.16)の閾値の降伏は、動き出す向き = 駆動の向き d(辺の法線成分 tae + tge、接線成分 −tte)の
    倍率 √(1 + |∇z|²)/√(1 + (d̂·∇z)²) を掛ける(流れの向きの fy ではない。止まりかけの流れの向きは定まらない)。
    一様な斜面では駆動が最急勾配の向きなので 1 で、閾値 tan θ = μ は 1 と同じ。
- **実装**(m_swflow_enc の calc_kth_flux): 土石流のブロックで降伏 aye と速度の 2 乗の係数 fbe を求め、曲率項の
  倍率を掛けた後で、slf > 0(2・3)のとき slope_db_factors の倍率を掛ける(∇z と V̂ は slope_fric_factor と同じ
  場の勾配と両セルの流速の平均の向き。1 辺だけの段では場の勾配がほぼ 0 で倍率もほぼ 1 = §93 の段の扱いと
  同じ)。掃流状集合流動は fb1 で見分ける。停止判定は、倍率の前の降伏 ayh に yield_dir_factor を掛けた ayt と
  比べる。0・1 では倍率を掛けず、停止判定も ayt = ayh = aye で従来と同じ。新しい配列はない(方針 §0)。

  効き方(降伏が最大 1/c 倍)は等流の検定では確かめていない。
