## 121. 芦田・道上の有効掃流力(式 (11))を f_taupart = 2 として実装する(2026-11-24。§19.8 の今後の課題。既存の手続きの写しで、無効時はビット一致)

§19.8(2026-10-29)で利用者の指示により「今後の課題(実装予定)」とした有効掃流力を、既定を変えない選択肢として
入れた。きっかけは例題 examples/joganji_flume(§120)の README の「ENCflow は芦田・道上の原式の有効掃流力
(式 (11))をまだ持たない」という一文への利用者の問い(実装は推奨か、例題が実験に近づくか、応用が広がるか、
負担は大きいか)。回答は「選択肢としての実装は推奨。ただしこの例題を実験に近づける目的では推奨しない
(試算で流砂量が 0.05〜0.15 倍になり、計測の土砂の収支から遠ざかる)。負担は小さい」で、利用者が
「推奨で進めてください」と決めた。決めごとは 121.2。

### 121.1 原典の照合(2026-11-24。利用者が提供した本文のスキャン)

芦田和男・道上正規 (1972) 移動床流れの抵抗と掃流砂量に関する基礎的研究。土木学会論文報告集 206、59–69
(§19.8 の照合と同じ文献。利用者は先に別の資料「河道計画・河道設計に係る数値解析技術に関する技術資料(案)
v1.1」を添付し、取り違えだったと伝えた。それは使っていない)。

- **式 (7)**: 平坦河床の表面抵抗の対数則 U/u*e' = 6.0 + 5.75 log10(R/ks)。**式 (8)・(9)**: 移動する砂礫の
  層の高さ Hs ~ v_s²/((σ/ρ − 1) g) と v_s ~ u* から ks = d + αHs = d(1 + ατ*)。**式 (10)**: 従来の平坦河床の
  実験の整理で ks = (0.5〜4.0) d_m。**式 (11)**: α = 2 として U/u*e = 6.0 + 5.75 log10{R/(d(1 + 2τ*))}。
- **式 (23)**: Φ = 17 τ*e^{3/2}(1 − τ*c/τ*)(1 − u*c/u*)。閾値の 2 因子は全 τ*・u*(§19.8 の照合のとおり)。
- **式 (24)**: 式 (23) をマニングの n で書いた形 Φ = 17 [R^{1/6} g^{−1/2} / {6.0 + 5.75 log10(R/(d(1 + 2τ*)))}]³
  n^{−3} τ*^{3/2}(1 − τ*c/τ*)(1 − u*c/u*)。[ ] がほぼ一定で τ* ≫ τ*c なら Φ ∝ n^{−3} τ*^{3/2}。実装の係数
  (u*e/u*)³ はこの [ ]³ n^{−3} にあたる。
- **式 (32)**(p. 65): 粒径別 q_Bi/(f0(d_i) u*e d_i) = 17 τ*ei(1 − τ*ci/τ*i)(1 − u*ci/u*)、τ*ei = u*e²/((σ/ρ − 1) g d_i)。
  著者らの混合砂れきの実験は河床形態の領域区分で Upper Regime にあり、u*e = u* として図 -9 を描いた。
  混合砂れきでの u*e を式 (11) のどの粒径で求めるかは書かれていない。
- **4 章**: Ripple Bed は ks ~ d(式 (36))、Dune Bed は ks ~ R(式 (37))、Flat・Antidune Bed は流れの全抵抗を
  式 (11) で u*e = u* とした式 (38) で表せる。Lower Regime(Ripple・Dune)の U/u* は図 -12・-13(τ* と R/d の
  関数)。領域区分図(図 -10・-11)は τ*–R/d の平面。

### 121.2 決めごと(2026-11-24。推奨を示し、利用者が「推奨で進めてください」と決めた)

1. **選択子**: `f_taupart = 2`。分け方は互いに排他なので同じ選択子の値にする(docs/mountain_stream_plan.md §14
   が「将来の τ*e も同じ選択肢の 2 として排他にする」と予定していた)。新しいパラメータは置かない。
2. **流砂量式**: 芦田・道上式(`f_qbform = 1`)だけ。MPM の原式の補正はリップル係数で別の分け方なので、
   `f_qbform = 2` との組み合わせは停止する。
3. **頭打ちと保護**: u*e ≤ u*(τ*e ≤ τ*)。式 (11) の右辺 D ≤ 0(h/ks < 0.0905)も比 1。
4. **向きの係数 γ と閾値**: 全 τ* のまま(原典の閾値の因子と同じ扱い)。

そのほかに決めたこと(回答で示した範囲。実装で具体にした):

- **掛ける所**: 掃流砂の容量(内部のエッジと開境界の面。単一粒径・混合粒径)。側岸侵食の後退速度則
  (超過掃流力の比の形で係数 kb を全せん断で決める経験則)、浮遊砂の平衡濃度、定着の限界には掛けない。
  `f_taupart = 1` が側岸侵食の脚部にも掛かるのと違うのは、1 が τ* に掛ける係数なのに対し、2 は式 (23)・(32)
  の先頭の項だけの置き換えで、後退速度則はその式ではないため。
- **併用の停止**: `fluv_taufac ≠ 1`(二重の分離)、`f_wfsed`(波と流れの複合のせん断は式 (11) の対象外)、
  `f_rockinc`(岩盤下刻)。岩盤下刻は当初、被覆の容量にも掛ける案だったが、121.3 の理由で既存の手続きに
  手を入れられないので停止にした。岩盤河床の渓流は `f_taupart = 1` の領域で、式 (11) の砂床の分離を
  使う場面ではない。
- **混合粒径の d**: 交換層の平均粒径 d_m(エッジの両セルの平均。遮蔽係数と同じ評価の場所)。全粒径階に
  同じ (u*e/u*)³ を掛ける。原典に書かれていないので ENCflow の選択と明記した(式 (10) が ks を d_m で
  表すのに合わせた)。

### 121.3 実装(写しの手続き)

- m_geomorph.f90 に純粋関数 `taueff_fac(gg, rn, hh, taus, d)`: D = 6.0 + 5.75 log10{h/(d(1 + 2τ*))}、
  (u*e/u*)² = h^{1/3}/(g n² D²)(マニング閉じ u*² = g n² U²/h^{1/3} なので U が消える)、結果は min(1, ·)^{3/2}。
  rn ≤ 0・d ≤ 0・D ≤ 0 は 1。D の τ* は流砂量式に渡す全 τ*(斜面に沿うせん断の倍率を含む)、u* はマニング
  閉じのまま(倍率を含めない)。
- **既存の手続きは変えず、写しを足した**: calc_fluvial の先頭の分岐に `taueff` を足し、単一粒径は
  `calc_fluvial_te`(calc_fluvial の写し)、混合粒径は `calc_fluvial_bmix_te`(calc_fluvial_bmix の写し。
  m_geomorph の interface に宣言を足した)へ分ける。写しと元の違いは、単一粒径はエッジの流量 gq を作った
  直後の 2 行(内部のエッジと開境界の面)、混合粒径はエッジごとに d = d_m で係数 fte を求める 2 か所と、
  それを粒径階の gq に掛ける 2 行だけ。どちらも定着の補正と可動層のクランプより前に掛ける(定着の補正は
  qbs の比なので、gq に掛けた係数と打ち消し合わない)。写しは HEAD の手続きの本文から機械的に作り、
  元の手続きは calc_fluvial の先頭の分岐を除いてバイト一致(calc_fluvial_bmix は全文一致)。
  ループ 1 を変えるときは calc_fluvial・calc_fluvial_bmix・両方の写し(と calc_fluvial_wfsed)を同じく変える
  (calc_fluvial の先頭の注に書いた)。
- **ループの中に分岐を足す形を取り下げた理由**(2026-11-24 に確かめた): 最初は既存のループの中で
  `if (taueff) qb = qb × taueff_fac(…)` と掛け、無効時の命令は論理判定 1 回だけ、と考えた。ところが
  無効の計算(test/bedmix の single・equal・armor の保存状態)が HEAD のビルドと最終桁で一致しなかった。
  同じ計算機で HEAD を作り直すと一致したので、原因はこの変更。次の 3 つの形を試し、どれも一致しなかった:
  (A) 単一粒径の挿入を外す → single は一致、混合粒径(局所の通過幅 wle に係数を含める形)は不一致。
  (B) 常に掛ける関数(無効時は厳密に 1.0 を返す。taufac_h と同じ形)→ 不一致。
  (C) 係数を qb ではなく、条件文が続いて連鎖が切れている gq の直後に掛ける → 不一致。
  -Ofast(結合の変更を許す)と -march=native では、ループの中の小さな変更で結合の順やベクトル化
  (べき乗・平方根のベクトル版と非ベクトル版)が変わり、丸めが変わるためと見ている(コンパイラの
  内部までは確かめていない)。写しの形(stage 1 の calc_fluvial_bmix と同じ)で、single・equal・armor が
  一致した。
- 岩盤下刻(m_geomorph_rockinc.f90)・側岸侵食(m_geomorph_bank.f90)・波浪場の写しは変えていない。
- 無効時の命令列: calc_fluvial の先頭の論理判定 1 回(ループの外)。

### 121.6 効果の大きさと限界

- 等流での試算(§19.8): n が粒子粗度の約 2 倍の砂床で流砂量は 0.1〜0.25 倍、礫床で 0.4〜0.65 倍。
- examples/joganji_flume の条件(水深 2〜5 cm、流速 0.3〜0.6 m/s、d_m 1〜4 mm、n = 0.035)で τ*e/τ* = 0.14〜0.28、
  流砂量の係数 0.05〜0.15(中央 0.09 ほど)。閾値の因子は全 τ* なので、係数は場所によらずほぼ一定で、地形の
  変化を遅くする向きに働く。計測の土砂の収支(固体で約 0.5 m³ の正味の流出)を説明できない。
- 限界(sediment.md §3 に書いた): 河床波の形態と抵抗は予測しない(n は与件で、与えた n と式 (11) の差を
  形状抵抗とみなす)。式 (11) は砂の河床で作られた式で、水深が D84 の 10 倍程度より浅い礫まじりの流れでは
  粒子の抵抗を小さく見積もり τ*e を過小にする側に外れる(その領域は f_taupart = 1)。
