## 96. 拡散型プロセスの 4 近傍の異方性: クリープと乾式斜面侵食の曲率の 9 点化(2026-11-05 合意・段 1 を実装)

**経緯と合意(2026-11-05。利用者「splash の曲率も含め、提案通り進めてください」)**: 斜めエッジの流束に
よる数値拡散の解説ページ(§68.45)の作成中に、溶岩の温度が 4 近傍の 1 次風上であることを問われ、クリープ・
氷河(SIA)・溶岩流・乾式斜面侵食の曲率が 4 近傍(5 点)であることの異方性を直す方針になった。合意した
進め方:
1. 段 1: クリープと乾式斜面侵食の曲率(とその平滑化の核)を 8 近傍の 9 点にする。斜め配分 d は 1/3。
   まず既定 0(現状の 5 点。ビット一致)で入れて検証し、既定の変更は reference の更新を伴うので
   利用者の目視確認の後に別コミットで行う(規律 1・4)。
2. 段 2: 溶岩の温度の数値拡散をまず計測し、効くなら MUSCL(範囲の切り詰めは残す)を選択式で足す
   (2026-11-05 実施。§97)。
3. 段 3: 氷河・溶岩流の流動の 8 近傍化は、塞がれた斜めの振り替えの設計を先に詰める(実装は設計の
   合意の後)。landslide_tsunami_plan.md §11 を更新した。

**5 点と 9 点の異方性(本作業での解析)**: ENC の配分則で軸エッジに (1 − d)、斜めエッジに d/2 の通過幅を
配った 9 点ラプラシアン(重み = 通過幅 / 中心間距離 / 面積)は、任意の d で ∇² の係数が厳密に 1
(§20・§16.6)で、修正方程式の次の項は (Δ²/12)(f_xxxx + 6d·f_xxyy + f_yyyy)(正方セル)。等方
(∇⁴ = f_xxxx + 2f_xxyy + f_yyyy)になるのは d = 1/3(Patra & Karttunen 2006 の等方な 9 点。書誌と要旨で
確認)。Fourier モードの減衰率の 45° と 0° の比(同じ |k|)の計算:

| ステンシル | 波長 16Δ | 8Δ | 4Δ | 3Δ | 陽解法の dt の上限(von Neumann) |
|---|---:|---:|---:|---:|---:|
| 5 点(d = 0) | +0.65 % | +2.62 % | +11.20 % | +21.37 % | 0.25 Δ²/D |
| 9 点 d = 0.586(水と同じ) | −0.48 % | −1.89 % | −6.91 % | −10.99 % | 0.50 Δ²/D |
| 9 点 d = 1/3 | +0.00 % | +0.05 % | +0.89 % | +2.96 % | 0.375 Δ²/D |

d = 1/3 を採ったのは、流れ(浅水流・地下水)と通過幅を共有しないクリープ・曲率では、水と同じ 0.586 に
そろえる理由がなく、等方性が最良だから。1 回の更新のエッジ数は 2 倍だが dt の上限が 1.5 倍になる。

**実装(段 1)**:
- `&list_geomorph` に `creep_diagratio`・`spl_diagratio`(既定 0、[0, 1])。list は読むだけ(§12)で、検証と
  導出は init。f_creep・f_splash なしで 0 以外を与えると停止。
- クリープ(m_geomorph_creep): d > 0 で `init_creep_diag` が軸・斜めの伝導度(m_gwflow_lateral_geom_init と
  同じ配分則。Δx ≠ Δy では短い辺に d、長い辺は (Δmin/Δmax)² 倍)と、壁(領域外 x <= 0・海セル sw > 0 =
  クリープの無流束境界)で塞がれた斜めの配分を同じ界面を横切る軸エッジへ振り替えた伝導度の表 cwo
  (q と同形状・同格納規約。§16.6 の f_gw_opening の build_opening と同じ規則: 軸エッジの通過幅 =
  (lp + nb·ld)·面長、nb = 界面を横切る斜め 4 本のうち塞がれた本数 × 0.5)を init で作る(ゾーン 2 の全域
  マスク。書き手ループと同じ js..je+1)。ループ 1(線形と深さ依存 creep_hstar の両方)は表の伝導度を使う。
  振り替えないと壁に平行な拡散係数が 1 − d/2 倍、1 セル幅の帯で 1 − d 倍になる(§16.6 と同じ機構)。
  安定条件は正値性(自セルの係数 1 − D dts Σ cw / A ≥ 0)で、Σ cw は表のセルごとの和の全域の最大
  (par_allreduce_max。全ランク同一)。d = 0 は従来の式と同じ値で、経路も従来のまま(表を確保しない)。
- 乾式斜面侵食(m_geomorph_splash): d > 0 で 9 点の重み w8(1:8) を init で作り、κ = max(lap9(z), 0)、
  `spl_lc > 0` の平滑化は 1 パス zs += τ lap9(zs)(τ = min(ℓ²/(2N), Δmin²/8)。各方向の分散 2τ は 5 点と同じ、
  τ ≤ Δmin²/8 で伝達関数が全波数で非負)。無効な近傍(列の範囲外・x <= 0)は自セルの値で鏡像(5 点と同じ
  規約)。d = 0 は従来の経路のまま。
