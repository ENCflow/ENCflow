## 100. 水面の勾配の項の可変の重力 g′(f_gravity_correction = 3。案 D + E の試作。2026-11-06)

- **背景**(handoff 00l、旧解説 §6.3 の案 D・E): 1・2 の有効重力 g_e = g/(1 + |∇z|²) は地盤の勾配から求めるので
  水深によらず掛かる。急な湖岸・ダム湖の斜面・急な海岸の上の深い水では水面がほぼ水平で鉛直の静水圧が正しいのに、
  波速を cos θ 倍に遅くする(案 D)。また水深の勾配の項の係数は、薄層の式では下り向きで g cos⁴θ、斜面を横切る
  向きで g cos²θ なのに、1・2 は向きによらず g cos²θ で、下り向きの波速が 1/cos θ 倍速い(案 E)。利用者の
  判断(2026-11-06): 推奨どおり D + E を選択式の 3 として試作し、既定は 2 のまま。混合体流動の抵抗則への 2 の
  適用・案 F・落ち口は保留。
- **定式化**(Yuan ら 2016 の式 42 の水の場合。底面の摩擦角の項 tan φ_bed を除く):
  g′ = g cos²θ / (1 + cos²θ ∇h·∇b) = g / (1 + |∇b|² + ∇b·∇h) = g / (1 + ∇b·∇η)。水面の勾配の項(地盤の勾配の項・
  水深の勾配の項・土石流の土砂柱の項)の g_e をこれに置き換え、摩擦・流砂のせん断・混合体流動の抵抗則は 2 の
  まま。性質(本書の検算): (1) ∇h = 0 で g_e(薄い流れの駆動力は 2 と同じ)。(2) ∇η = 0 で g(湖の波が √(gh)。
  力が ∇η に比例するので湖の静止は厳密)。(3) 1 次元で力 F(η′) = −g η′/(1 + b′η′) の η′ = b′(一様な流れ)での
  傾きは −g/(1 + b′²)² = −g cos⁴θ で薄層の式の係数そのもの(1 次の展開でなく微分が一致)、斜面を横切る向きは
  ∇h·∇b = 0 なので g cos²θ。単調減少で、η′ → ∞ でも有界(−g/b′)。
- **離散化**: 辺の法線成分は辺の差分(地盤は correct_ge と同じ s_n、流動深は (h_n − h_c)/Δs)、接線成分は両セルの
  minmod の勾配の平均(地盤は gzx・gzy、流動深は新しい ghx・ghy。gravity_prepare が同じ minmod で書く。minmod は
  奇関数なので、水面が水平なら −gzx、水深が一様なら 0)。流動深は h、土石流が有効なら + max(hs, 0)(圧力項の
  水面 z + h + hs と同じ)。∇b·∇h を [−|∇b|², |∇b|²] に制限する(独自の簡略化。急な前縁・段では ∇b·∇h が大きく、
  分母が 0 に近づくか負になる。下限で g′ ≤ g = 古典の式より速くしない、上限で g′ ≥ g/(1 + 2|∇b|²)。Yuan らは
  経験的な減衰係数 exp(−ω|v_r||∇h|)、ω = 1〜3 を使う)。g_e の分母は correct_ge と同じ順の和なので、∇h = 0 では
  correct_ge と一致する。
- **実装**(m_swflow_enc): calc_kth_flux の文には手を入れず、時刻 n の水面の差に対する差の力
  −(g′ − g_e) g_v (η_n − η_c)/Δs を `gp_edge` が求め、calc_kth_momentum が移流項・拡散項と同じく辺の外力 tae に
  足す(拡散項 diff_edge と同じ「独立な項の重ね合わせ」)。ルンゲクッタの段の間の水深の変化には g_e が掛かる
  (独自の簡略化。g′ も g_e と同じく時刻 n の量から辺ごとに 1 回求める)。opt%have_gp = 3 かつ圧力項あり
  (f_govequation の 0・1。2 = キネマティックは対象外)。セルの流動深の勾配 ghx・ghy は 3 のときだけ確保し
  (無効時は配列も計算もない。方針 §0)、ステップの頭のハロ交換済みの h・hs から js−1..je+1 行を書く。
  境界の辺(put_bc_faces)・構造物・非静水圧(nh)には補正を足していない。
  - **-Ofast の最終桁**: 初めは calc_kth_flux の中で、勾配の項・水深の項・土砂柱の項の ge を g′ の変数に置き換えた
    (既定では g′ = ge の代入)。これで test/gwwidth の Log.txt の S 列が 1 量子(相対 5e-13)だけ reference と
    違った(変更前のコードを同じ環境で組むと一致するので、変更による)。既定の文を残して 3 のときだけ後から
    上書きする形(§90・§93 の注の方式)でも、上書きの文が 1 つ(ルンゲクッタの外の地盤の勾配の項だけ)でもあると
    同じずれが出た(-Ofast の結合則の組み替えが、代入の経路の増えた式で変わると見ている)。差の力を calc_kth_flux の
    外で tae に足す今の形で一致した。
