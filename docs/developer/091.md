## 91. 急勾配の重力補正の cos²θ を地盤の勾配の大きさで求める(格子の向きによる有効重力の偏りの修正。2026-11-04 挙動変更)

(定式化・ステンシル(どの辺にどのセルの地盤を使うか)・既往研究との比較・限界をまとめた
解説は [users_guide/steep_slope.md](../users_guide/steep_slope.md)。2026-11-05 に docs/steep_slope_design.md から移し、
設計の議論を削った)

- **現象**: f_gravity_correction = 1(既定)の有効重力 g_e が、斜面に斜めの辺で大きく出る。勾配 G の
  一様な斜面で、下り向きと角 α をなす辺の g_e は g/(1 + G² cos²α) で、Ni ら (2019) の
  g cos²θ = g/(1 + G²) の (1 + G²)/(1 + G² cos²α) 倍(G = 0.4 で 45° の辺 +7.4 %、斜面を横切る辺
  +16 %。G = 0.18 で +1.6 %・+3.2 %)。格子を細かくしても変わらない。§28.16 の test/dbonset の構成で
  補正を入れると(G = 0.38・0.45)、2 s 後の滑りの速さの g cos²θ (G − μ) t に対する比が、8 近傍で
  1.029〜1.050(向きによる差 2 % 以内)、4 近傍で 0.998〜1.090 になり、4 近傍の 22.5° では向きが
  +0.2°・+0.6° ずれた(§28.16 の作業で見つけ、handoff に記録していた)。
- **原因**: correct_ge が g_e = g dr²/(dr² + Δz²) = g/(1 + (Δz/dr)²) を、辺の法線方向の地盤の勾配
  だけから求めていた。cos²θ の θ は地盤の傾斜角(地盤の法線と鉛直のなす角 = 最急勾配の向きの
  傾斜角)で、辺の向きによらない量。辺の法線成分は下り向きと角 α の辺で G cos α に小さく見え、
  斜面を横切る辺(α = 90°)では補正がかからない(g_e = g)。正しかったのは、軸に沿う斜面で斜面に
  沿う辺だけ(4 近傍の軸に沿う 1 次元の検定は、この場合しか通らない)。
- **修正**: g_e = g/(1 + |∇z|²_e)。|∇z|²_e は、辺の法線成分(辺の差分 Δz/dr。従来と同じ)の二乗と、
  両セルの地盤の勾配の平均を辺の接線へ射影した成分の二乗の和。セルの勾配は、軸方向の両隣との
  差の minmod(両側が有効セルなら符号が同じときだけ絶対値の小さい方、違えば 0。片側だけ有効なら
  片側差分、なしなら 0)で、gravity_prepare がステップごとに前計算する(sx%gzx・gzy。
  f_gravity_correction > 0 のときだけ確保。海域セルの地盤も含める)。
- **決定の理由**(2026-11-04 合意):
  - θ の定義: 地盤の法線方向の静水圧 p_b = ρ g (h cos θ) cos θ = ρ g h cos²θ(h は鉛直の水深)から、
    cos²θ は地盤の傾斜だけで決まる。2 次元の式は Ni ら (2019) の原文で確かめていない(作業した
    環境から doi.org に届かなかった)。上の導出による。(追記 2026-11-04)利用者から原文の提供を受けて
    確かめた: Ni らの 2 次元の CAR は g' = g cos²θ を圧力の流束と勾配の項の両方に掛け(式 5・6)、
    cos θ をセル中心の中心差分の勾配の大きさで求める(式 8。x・y に同じ θ)。θ の定義はこの修正と
    一致し、離散化(セル中心の中心差分 / 辺の法線差分+minmod の接線成分)が違う。摩擦は ENCflow と
    違い、g(補正なし)と地盤に直角な水深 h cos θ と 1/cos θ の係数で評価する(式 7)。ほかの文献との
    比較と、等流で g_e が相殺することの整理は docs/users_guide/steep_slope.md。
  - 接線成分を minmod で取る: 平面で厳密で、谷底と谷壁・堤の肩のような折れでは緩い側を取る。
    中心差分だと谷底のセルに谷壁の勾配が半分入り、粗い格子(谷底が 1〜2 セル)の谷底の有効重力が
    下がる(35° の谷壁なら約 1 割)。法線成分は辺の差分のまま(局所的で、従来の 1 次元の結果を
    保つ)。セルの最急勾配(D∞)を使う案は、堤の頂部のような尾根で下りの片側の急な勾配を拾うので
    重力補正には採らない(§92 の C∞・安全率の勾配は下りの最急勾配が意味を持つので D∞)。
  - 旧方式に戻すスイッチは置かない(§0-6。§28.16・§51.4 と同じ)。
  - reference と例題の再計算は、§92(D∞)と岩盤侵食の g_e の統一と同じ回にまとめる。
- **岩盤侵食の有効重力を揃える**(2026-11-04 合意。§89.18 の「g_e は運動方程式と同じ有効重力」を
  保つ): 土石流による岩盤侵食(rock_kdb)の駆動応力 τ_d = ρ(1 + sC) g_e h_t tanθ_f の g_e は、
  g cos²θ_f = g/(1 + tan²θ_f)(θ_f は流向の河床勾配。旧来の辺の法線方向の勾配による補正と同じ
  考え方)だったので、上の修正に合わせて g/(1 + |∇z|²) にした。|∇z| は gravity_prepare と同じ
  セルの地盤の勾配(軸ごとに両隣との差の minmod。関数 zdiff_minmod を m_swflow_enc から公開して
  共用し、calc_debris のパス 1 でその場で求める。swflow の作業配列 gzx・gzy は geomorph から
  見えないため)。斜面を斜めに流れるセルでは θ_f < θ で、旧式は g_e を大きく見積もっていた
  (勾配 0.4 で流向が下り向きから 45° なら +7 %)。tanθ_f は駆動の向きの勾配としてそのまま使う
  (斜面を斜めに流れる等流の底面せん断の流向成分は ρ g_e h tanθ_f)。f_gravity_correction = 0 の
  構成と、流れが最急勾配の向きの一様な斜面(test/dbrock の DB1)は変わらない。test/dbrock の DB8
  (2 セル周期の凹凸)は、流向の勾配が行ごとに 0.19・0.21 と交互になる一方、minmod の勾配は
  どの行も 0.19 になり、g_e が凸部の行で 0.8 % 大きくなる(Check_dbrock.py の解析解を新しい定義に
  合わせた。新しい解析解との差 1.3e-15、旧式の実行ファイルは 2.0e-2 で FAIL)。
- **影響の範囲**: g_e は辺の重力・圧力項、マニングの摩擦、降伏(クーロン・Voellmy)、曲率項に掛かる。
  駆動と抵抗の両方に g_e が掛かる定常の等流(マニング、クーロン + マニング、Voellmy)は g_e が
  相殺して変わらず、変わるのは加速・動き出し、波速 √(g_e h)、斜面を横切る向きの圧力による
  広がり、g_e に比例しない抵抗則(高橋・中川のダイラタント項、江頭、一定停止応力)の定常の速さ。
  差はおよそ G² sin²α の程度で、緩勾配では小さい(試作で test/chichibu の流量の最大の差 0.7 %、
  examples/debris_fan の 5 m の指標の変化は数 % 以内で、谷の向きによる差は縮んだ)が、斜面のある
  ほぼすべての構成で ULP = 0 の reference が変わる。f_gravity_correction = 0 の構成は不変。
- **ステンシルと並列**: gravity_prepare は js−1..je+1 の勾配を、z の js−2..je+2 から求める(ステップの
  頭の幅 2 の交換の内側。yield_prepare と同じ)。帯の界面の辺は、両ランクが同じ入力から同じ式で
  冗長に計算するのでビット一致する。
