## 30. 水質(負荷流出)モジュール m_wq(&list_wq。2026-08-09 実装)

### 設計

- **単一物質の柱状量 s%cq** を対象とする簡易環境水理(窒素・リン・
  汚染物質・トレーサ等)。輸送は浮遊砂と同じ保存輸送カーネル
  (advect_scalar)を swflow_enc がステップ内で実行(s%wq_active。
  sx%cq1 バッファ・ステップ頭ハロ交換・complete コミットとも hs と
  同型)。発生源・鉛直交換・診断は m_wq が加算的プロセスとして担う。
  有効化は fn_wq(f_wq=0 で一時無効化)。ENC 格子のみ。
- **単位系**: cq = 柱状量 (g/m2。貯留の意味論は h と同一。セル内質量 =
  cq×gv×wfrac×A)。濃度 cqc = cq/vh (mg/L = g/m3。vh は σ の矩形換算
  水深 swflow_vh)。**σ・幅セルの濃度換算はモデル内部で行い直接出力する**
  (C 場・プローブ列。外部で C=cq/h と計算すると σ セルで系統誤差)。
- **発生源**(セル群は inline か read_cell_file2 のファイル):
  点源 = g/s(グループ合計をセルへ等分配)、面源 = 原単位 kg/ha/day
  (×セル面積)。一定値か時系列(t=0 からの経過日、線形補間・端値保持)の
  排他。境界流入濃度(区間流入番号ごと、mg/L)は b%cqin テーブル経由で
  カーネルの風上濃度に入る(浮遊砂 csin と同型)。
- **分布面源(fn_wq_map)**: 土地利用等から作成した原単位分布
  (kg/ha/day のセル別行列 × 倍率 wq_map_factor)を全有効セルへ一定率で
  投入する。点源・面源と**排他でなく重ね合わせ**(背景負荷+特定源)。
  時系列なし(一定)。rank0 が読み(使用セルの負値はエラー)、
  g/s/m2 へ換算してから帯 scatter(方式2)。0 のセルは負荷なし。
- **降雨中濃度(湿性沈着。wq_rain_conc / wq_rain_series の排他)**:
  降雨に含まれる物質濃度(mg/L)。このステップに swflow が加えた
  **地表到達雨量 s%pre·dt(遮断適用後)× 濃度**をセルごとに投入する。
  セル判定(sw 除外・窓)も swflow の降雨適用と同一 = 水と質量が厳密整合。
  樹冠に遮断された雨の沈着分は水と同伴して系外(既知の妥協 — 樹冠洗い
  落としで地表へ戻す拡張は将来)。他の発生源すべてと重ね合わせ。
- **表面蓄積プール+洗い出し(buildup-washoff。L-Q 非線形の機構)**:
  分布状態量 s%bp(g/m2 幾何面積基底。セル内質量 = bp×A)を挟むことで、
  先行蓄積→出水初期の急速流出→枯渇のヒステリシスと L=aQ^b の b>1 が
  機構的に出る。
  - 蓄積: dB/dt = r·(1 − B/Bmax)(飽和指数。wq_bd_max 省略で線形
    dB/dt = r)。レート r は一様 wq_bd_rate(kg/ha/day)か
    **fn_wq_map の転用(f_wq_map=1)**の排他。B ≥ Bmax のセルは蓄積
    しない(沈降還流で上限を超えたプールを蓄積式が削らない条件)。
    更新は指数厳密形(無条件安定)。
  - 洗い出し: λ = wq_wash_kr·P + wq_wash_kf·max(τ/τc − 1, 0)
    (m_geomorph_wash の雨滴+面状侵食と同型)。P = 地表到達降雨強度、
    τ = ρg·n²·vv²/h^(1/3)(マニング閉じの次元付き河床せん断 N/m2。
    粒径・比重が不要)。移送 ΔB = B·(1−e^(−λΔt)) → cq。湿潤セル
    (h > dd)のみ。河道セルも対象(河床堆積の再懸濁)。
    **SWMM 指数型洗い出し(c2=1)とは kr[1/m] = c1[1/mm]×1000 で互換**
    (流出強度は準定常で降雨強度に漸近するため)。c2>1 相当の超線形性は
    せん断項が担う。
  - 初期プール: wq_bd0(kg/ha 一様)か fn_wq_bd0(分布)の排他。
    放射性核種の沈着量マップは「レート0+初期プール+洗い出し+減衰」で
    表現する。海セル(sw)にはプールを置かない。
  - 沈降の行き先: f_wq_settle = 0(河床へ消失 = 既定・従来)/
    1(プールへ = 水域内の沈降・再懸濁サイクルが閉じる)。
    台帳 settle_g は行き先によらず沈降量(=1 では内部移動、閉合式に注意)。
  - 減衰(fdec)は cq・cg と同様に bp にも毎ステップ乗算。
  - B 場出力(kg/ha = g/m2×10。プール有効時のみ)。
- **浸透同伴(f_wq_infil=1 既定)**: gwflow の鉛直交換が s%fxg に浸透量を
  記録し(bucket/greenampt。wq が読んでゼロ戻しする契約)、
  柱状量の同率移動 Δcq = cq·fx/(h+fx) で地下質量プール s%cg へ移す。
  柱状量同士の同率移動なので面積基底によらず質量保存が厳密。
  0 で地表残留(粒子態)。cg の横輸送・湧出還元は §30.5(W3)。
- **ダム捕捉帯**: 水が毎ステップ全量吸収されるため質量も同伴する。
  貯留湖沼は完全混合プール M/V で放流濃度まで閉じる(**§30.7。
  2026-08-26 実装** — W1 の「放流濃度 0」「rscap 吸収の地表残留」の
  妥協はともに解消済み)。gwflow_lateral の飽和湧出の片道問題は
  **W3(§30.5。2026-08-26)で解消済み**。
- **蒸発**: 純水のみが抜けるため質量残留(濃縮)= 物理的に正しい。
- **一次減衰と沈降(W2)**: 減衰は wq_thalf(半減期 day。放射性核種は
  これ)か wq_k20(1/day)の排他指定。前計算の指数厳密係数
  exp(−kΔt) を地表 cq・地下 cg の両方に毎ステップ乗算(温度補正
  k(T)=k20·θ^(T−20) は将来 m_meteo 連携で)。沈降 wq_vs(m/day)は
  地表のみの線形近似 c·(1−vs·Δt/vh)(下限0。河床への消失=台帳計上)。
  消失分は wq.csv の decay_g / settle_g 列。
- **save/restore**: cq・cg・bp をモジュール私有ファイル wq.dat(RLE、
  常に3成分)で保存(契約C。state.dat 形式は不変。cqc は導出量・fxg は
  スクラッチ)。restore 時に wq.dat が無ければ par_stop(意図しない
  質量消失の防止)。3成分化(2026-08-09)で save_version を更新済み。
- **出力**: C 場(mg/L。wq 有効時は常時)。Cg 場(地下質量プール cg、
  g/m2 幾何面積基底。f_wq_infil=1 で確保されているときのみ。フラグは
  f_out_hg と共用 = Hg2/Hgc/Hgs と同じ「地下水の状態量は Hg のフラグに
  相乗り」の様式。2026-10-16)。プローブに C・cq 列、測線に
  負荷 L(g/s。水フラックス×セル濃度=測線の水計測と同じセル中心近似)と
  累積負荷 Lcum(kg。記録間隔の矩形積分)列 — **いずれも wq 有効時のみ
  追加**(無効時は従来形式のまま = reference 不変)。result/wq.csv に
  投入(点/面/分布/降雨/蓄積)・洗い出し・浸透・ダム捕捉・減衰・沈降の
  累積と地表・地下・プールの現在貯留質量。
- **導出濃度の更新タイミング**: m_wq_derive をステップ末尾パス(post)の
  後・統計/出力の前に実行(確定 h に対する濃度を出力系が読む条件)。
  m_wq_calc(発生源・浸透同伴)は gwflow の直後(fxg の消費)。
- **MPI**: 発生源・捕捉はセル局所、台帳集計は par_sum_rows(決定的)。

### 検証記録(2026-08-09)

- 無効時(fn_wq 未指定): 回帰ビット一致 PASS。
- 一様濃度保存(wave、初期 100 mg/L・発生源なし): C 場が全時刻・全セルで
  厳密に 100.0000(カーネルの「一様濃度は一様のまま」の実検証)、
  総質量が全行同値(1.0210190e6 g)。
- 点源収支(wave、閉領域): 投入 500 g/s×8s = 4000 g が地表貯留と厳密一致。

  6時間全出力が逐次と一致。
- 減衰(wave、半減期4秒=2半減期): 一様場が 100·2^(−t/T) を出力精度で
  厳密追従、閉合(減衰累積+貯留=初期質量)3e-8。

  厳密一致、閉合(800 + 1.6 + 8.0 = 809.6 g = 地表貯留)厳密。
  -Og -fcheck=all np=2 クリーン、-O2 で np=1,2,4 の全出力が逐次と
  ULP=0、無効時は全回帰 PASS(2026-08-09)。
- buildup-washoff(いずれも wave、2026-08-09):
  - 洗い出し解析解(B0=100 kg/ha 一様+kr=100/m+一定雨 1e-5 m/s →

### 30.5 地下横輸送+湧出還元(W3。2026-08-26 実装)

地下質量プール cg の側方輸送と、飽和湧出に同伴した地表への質量還元。
これにより「浸透 → 地下水流動 → 河川へ湧出」の経路が質量的に閉じ、
基底流出が支配する平常時の河川水質分布を扱えるようになった(発端の
要件と段階計画は wq_metal_plan.md。外部レビュー案との比較を含む)。

- **方式(実装案の比較で決定)**: フラックス記録契約+独立輸送カーネル
  (案A)ではなく、**lateral_core のループ構造への同伴輸送の畳み込み**
  (案B)を採用した。理由: (1) 地表側の役割分担(輸送はカーネル所有者
  swflow_enc、wq は発生源・鉛直・診断)の地下への対称適用、(2) エッジ
  流量「無履歴スクラッチ」の原則を保てる(記録場の永続化が不要)、
  (3) ループ1は時刻 n の cg/hg をその場で読めるため、案Aで必要になる
  hg^n の退避(2ループ分離で消した旧 wk の復活)を避けられる。
- **カーネル**: ループ1が水流量 q と同時に質量エッジフラックス
  qm = q·(1/R)·cg_up/hg_up(風上体積濃度 × 水流量。g/s)を第2の
  一時エッジ配列 glt%qm に書き、ループ2が水と同じ反対称集計で cg に
  発散を適用する。飽和超過の引き渡しでは、超過水量 fx に同率移動
  w = (1/R)·cg·fx/(hg+fx) を同伴して記録場 **s%fxs** へ移し、m_wq_calc
  (2a) が読んで地表 cq へ還元・台帳化しゼロ戻しする(fxg と同型の契約。
  基底換算と質量意味論は m_wq が担い、lateral は wq を知らない)。
  有効判定は s%cg の allocated(= fn_wq かつ f_wq_infil=1)。未確保なら
  qm も確保せず経路・メモリとも従来どおり。層2(cg2)・conduit_core は
  対象外(将来拡張)。
- **cg の基底変更(幾何面積基底へ)**: cg を「セル内質量 = cg×A」の
  幾何面積基底に変更し、cq 基底(gv×wfrac)との換算(gwfac_of)を
  浸透同伴(×gv·wfrac)と湧出還元(÷gv·wfrac)の両端で行う。
  横輸送は柱状量の対称交換 = Σcg·A を厳密保存するので、この基底なら
  **台帳の閉合が gv・wfrac の分布によらず厳密**になる(cq 基底のままだと
  河道幅セル⇔堤内地セル間の輸送で台帳が破れる)。wq.dat の cg の
  意味が変わるため **save_version を 2026-08-26 に更新**(gv·wfrac=1 の
  ケースでは値は不変)。台帳 mass_gw・cg の減衰列も同基底に変更。
- **遅延化係数 wq_rg(R ≥ 1。既定 1)**: 平衡吸着の遅延 R = 1 + ρb·Kd/θ
  を物理量として直接与える(導出は前処理。§0)。地下の可動(溶存)
  割合 = 1/R として**側方移流と湧出同伴の実効濃度の両方**に乗じる
  (整合条件。R→∞ で不動化 = 実質的な輸送オフ)。実装は s%cg_rginv
  (t_state のスカラー。salt_alpha と同じ流儀)経由で lateral に渡す。
  f_wq_infil=1 が必須(init 検査)。
- **MPI**: gwflow_lateral_calc 冒頭のハロ交換に s%cg を追加(帯界面
  エッジの冗長計算が風上 cg をハロから読む)。qm の帯界面成分は水と
  同じ冗長計算配布。台帳(seep_g)は par_sum_rows(決定的)。
- **wq.csv**: to_gw_g の直後に **seep_g 列を追加**(**列構成変更**。
  wq.csv 依存の後処理は要追随。reference 比較対象ではないが、
  test/sewer_wq は wq.csv を比較対象にしているため reference 更新を

### 30.6 Kd 平衡二相分配(K1。2026-08-26 実装)

重金属など吸着性物質の溶存態⇄粒子態の平衡分配。wq_metal_plan.md §5 の
K1(段階1)= 「分配は毎ステップの平衡、輸送する状態は cq 一本のまま、
相の差は鉛直交換だけに現れる」という最小構成。

- **有効化**: wq_kd(**L/kg**。文献の慣用単位。内部で m3/kg へ換算)。
  **f_suspend 必須**(浮遊砂濃度が分配の分母。wq init は geomorph init
  より先のため、最初の calc で遅延検査 — gwc_checked と同じ流儀。
  f_debris の hs は流動体の固相で対象外 = s%sed_wf > 0 で判別)。
  **wq_vs と排他**(Kd 有効時の沈降速度は浮遊砂の wf で決まるため)。
- **分配**: 溶存率 fd = 1/(1 + Kd·Css)、Css = hs·ρs/vh(kg/m3。
  ρs = (s%sed_sgrav + 1)·ρw、vh = σ・幅の矩形換算水深 = 濃度 cqc と
  同じ基底)。浮遊砂なし・水なしのセルは fd = 1(全量溶存扱い)。
  状態の追加はなく save 形式は不変(fd は毎ステップの導出量)。
- **適用先**(既存機構の係数化のみ):
  - 浸透同伴(f_wq_infil=1): 同伴質量を fd 倍(粒子態は土中に濾し
    取られず地表残留)。
  - 沈降: fp = 1 − fd 分の cq が**浮遊砂の沈降速度 s%sed_wf** で沈む
    (w = cq·fp·min(wf·Δt/vh, 1)。wf は m_geomorph_init が
    init_suspend の後に s%sed_wf へ公開する)。行き先は f_wq_settle の
    既存機構(=1 の bp プール推奨 — せん断洗い出しが再懸濁を担い、
    河床金属の蓄積↔再懸濁が閉じる)。f_wq_settle=1 の必須条件は
    「wq_vs か wq_kd のどちらか」に緩和。
  - 水平移流は cq 一本のまま(両相とも水柱と同速で動くため分ける
    必要がない — 差が出るのは鉛直・河床交換だけ)。
- **沈降式の意味論**: w = fp·cq·wf/vh は「金属/砂 質量比 × 砂の
  沈着フラックス wf·Css」と恒等 = 粒子態金属のグロス沈着。浮遊砂側の
  E-D が正味浸食のセルでも粒子態金属は沈着し、河床側からの再懸濁は
  bp プール+せん断洗い出しが別途担う(グロス双方向交換の近似)。
- **管路連携(fxci)・ダム捕捉は総量のまま**(枡・捕捉帯に飲まれる
  水柱は懸濁粒子ごと飲まれる)。wq_rg(W3)とは独立に併用可
  (地表の分配と地下の遅延はそれぞれの係数)。
- **K2(保留)**: E-D フラックスとの厳密結合(記録契約+河床交換層の
  金属/砂比)は、K1 の実流域適用で不足が示されてから
  (wq_metal_plan.md §5)。

### 30.8 海セルの扱い(2026-10-22 実バグ・修正)

- **症状**: 初期濃度 wq_c0 > 0 のとき cq = c0×h が海セル(sw>0)にも置かれて
  いた。wq init は tide init より前なので h は初期条件の値(h0・e0 − 0)で、
  その後 h だけが hsea0 に置き換わる。advect_scalar は海セルを受け手として
  読み飛ばすため海セルの cq は輸送で減らず、風上の供給元としては読まれる
  ので、海から陸への流入が濃度 c0×h_init/hsea0 を持ち続けた(無限供給。
  h_init ≠ hsea0 なら c0 とも一致しない人工値)。さらに一次減衰は海セルの
  cq にも働き、現在質量 mass_surface_g の集計も海セルを含んでいた。
- **修正**: init で海セルの cq をゼロ化し、減衰ループと現在質量の集計から
  海セルを除外(表面蓄積プール bp・積雪・氷河と同じ「海セルには置かない」
  原則。海から陸への流入は常に清水 = 浮遊砂 hs と同じ)。海セル・辺境界へ
  出た質量は従来どおり台帳に列を持たず収支残差(users_guide/wq.md)。
- **検証**(gfortran 13.3 / serial): test/tracer・damwq・gwseep・sewer_wq・
  kdpart は Log・wq.csv とも reference と identical(海域マスクと水質を併用する
  既存ケースはない)。test/tide に fn_wq と wq_c0 = 100 を加えた構成で、
  海セルの C = 0、mass_surface_g(t=0) = 100×0.5×420×100 = 2.1e6 g(陸セルのみ。
  修正前は 441 セル分の 2.205e6)、海からの浸水で沿岸の C が希釈されることを

### 30.9 系外との出入りの台帳(海セル・開いた辺。2026-11-03 実装)

流域の出口を海域マスクにする構成(河川水質の流域ケース。docs/wq_metal_plan.md の
Phase 0)で、海へ出た総量を台帳から読みたいという利用者の要望による。調査の結論と
合意(2026-11-03 のチャット):

- **海セルへの流出は実装済みで、足りないのは集計だけ**: advect_scalar は海セルを
  受け手から外している(ループ冒頭の sw > 0 の cycle)ので、陸→海の面を通る質量は
  陸セルの更新で減って海セルは受け取らない = 系外へ出る。海→陸の面は供給元濃度 0 =
  清水(§30.8 で海セルの cq を 0 に保つ)。小水路(点源 3600 g、下流端 3 列を海セル)
  で、地表質量 2127 g と海へ出た量 1473 g(測線の Lcum 1487 g はセル中心の濃度で
  数える近似で 1 % 多い)、潮位を上げた逆流でも入る水は清水を確認した。地下水の
  側方流は海セルと無流束なので(m_gwflow_lateral の冒頭)、地下の質量が直接海へ
  出る経路はない。
- **数え方 = 輸送カーネルの任意引数**: advect_scalar に任意引数 xrow(real64 の
  行部分和 (js:je, 1:3))を足し、面を通る質量 mne·cdon·sh·mn2dh(k)·fw·A を
  1 = 海セルへの流出、2 = 開いた辺から外への流出、3 = 開いた辺から内への流入
  (区間流入の cbin・側方 Neumann の鏡像濃度)に分けて積む。c1 の更新と同じ
  流束 × 供給元濃度(winv と gv が質量の基底 gv·wfrac·A と約分される)なので台帳は
  厳密に閉じる。c1 の更新式には触れない(xrow を渡さない呼び出しはビット不変)。
  OpenMP は行 j のループで、行 j の書き手は 1 スレッド = 競合なし。MPI は
  owner-compute の行部分和を記録時に par_sum_rows(決定的)。近傍が領域外
  (x <= 0)のときは sw を読まない(sw・h は全域+帯しか確保されない = 同じカーネルの
  MUSCL の注記にある -fcheck=all np=2 の実バグと同じ注意)。
- **契約**: 記録場 s%cqx(t_state。(js:je, 1:3))を m_wq_init が水質有効時に確保し、
  swflow_enc が水質の呼び出しにだけ渡して記録、m_wq_calc の (0) が vrow(16:18) へ
  移してゼロ戻し(fxg・fxs と同型。swflow は水質を知らない)。
- **出力**: wq.csv の末尾に out_sea_g・out_edge_g・in_edge_g を追加(**既存の 21 列の
  位置は不変** = 列番号で読む後処理は影響を受けない)。これで台帳は「ラン開始時の
  全体系の質量 + 入力 + in_edge − 系外への除去 − out_sea − out_edge = 現在の全体系の
  質量」で閉じる(users_guide/wq.md「読み方と検算のコツ」)。閉合残差の列は置かない
  (to_dam_g が貯留型と水位固定型の捕捉の合計で、利用者が構成に応じて読む必要が
  あるため。必要が出たら別途)。浮遊砂・流木・瓦礫などほかの輸送物質は従来どおり
  列を持たない(系外流出は収支残差)。
- **採らなかった案**: (1) 海セルに質量を貯めて総量を数える — 海セルは質量を持たない
  原則(§30.8)と「海からの流入は清水」の前提が崩れ、潮位で水深が変わるセルに
  貯めると逆流で戻る(水位規定セルの不具合と同じ形になる)。(2) 別ファイル
  (wq_bound.csv)に出す — reference は変わらないが収支が 2 ファイルに割れる。
  利用者の選択で wq.csv の末尾追加とした。

### 30.10 構造物・取水が運ぶ水質の質量(2026-11-04 実装)

examples/catchment_metal(重金属の流域例題)を作った後の見直しで、利用者に「これだけは
直すべき問題」の 1 番目として示した。ダム・湖沼だけは完全混合の濃度 M/V で物質を運ぶが、
ほかの取水は水だけを動かし、物質は取水側に残っていた。

| 経路 | 修正前の動き | 起きていたこと |
|---|---|---|
| 内部ソースの吸い込み(負の流量) | boundary_h が水深を減らすだけ | 取水セルが濃くなる |
| ポンプ・カルバート・分水 | 2 段の転送(汲む → allreduce → 配る)で水だけ | 取水側が濃くなり、送り先には清水が入る。域外へ出す分も物質は残る |
| ため池から汲むポンプ | ため池の水 hrs だけ減る | ため池プール crs が残り、池の濃度が上がる |
| 管路から汲むポンプ(f_pump_src=1) | 管路の水を吐出 | 送り先は清水(噴出・陸側吐口の固定濃度 wq_gwc_conc と揃わない) |
| 井戸揚水(f_gwpump、層 1) | 層 1 から水だけ系外へ | 地下水の濃度が上がる(井戸灌漑の評価に直結) |

台帳は閉じる(質量を動かさないので)ため、既存の検査では見つからなかった。最小例
(test/wqstruct。16 の閉じた区画、全区画 1 mg/L)の修正前の実行ファイルでは、域外ポンプの
取水セル(河道幅 wfrac = 0.2)が 9.6 mg/L、域内ポンプの送り先(空隙率 0.5)が 0.08〜0.88 mg/L、
空の区画へ汲み入れた水が 0、カルバートの上流側 2.7 mg/L・下流側 0.29 mg/L、井戸のセルの
地下水が 2.44 mg/L になった(水の場は修正前後でビット一致)。

- **規則(合意 2026-11-04 のチャット)**: 汲んだ水の割合 f = 汲んだ水深 / 汲む前の水深で、
  その時点の柱状量を同じ割合だけ取り出す(取水セル内の完全混合 = 取水セルの濃度で運ぶ。
  浸透同伴と同じ同率移動の独自の簡略化)。送り先には水と同じセル数等分で入れる(カルバートの
  逆流は上流側が送り先)。吐口のないポンプ・域外分水・内部ソースの吸い込み・井戸揚水が
  持ち出した分は台帳の新しい列 out_intake_g。ため池から汲む分は crs から同じ割合、管路から
  汲むポンプの水は管路の水 = 固定濃度 wq_gwc_conc(噴出・陸側吐口と同じ供給側固定濃度近似。
  in_gwc_g に数える。wq_gwc_conc 未指定なら清水)、井戸揚水は湧出と同じ形の溶存分
  dm = (1/R)·cg·fx/hg(層 2 は質量を持たないので水だけ)。湧き出し(正の流量)は清水のまま
  (負荷は点源で与える)。
- **運ぶ物質の範囲(利用者の選択「浮遊砂は運ばない」)**: 設計案では浮遊砂 hs も運ぶ
  推奨だったが、実装前に geomorph.md の透過型砂防堰堤の近似(堤体にカルバートで抜き口を
  与え「水は通し土砂は全量捕捉する」= 捕捉の上限側評価。hs は土石流の固相も兼ねる)と
  衝突することが分かり、利用者に確認した。水質だけを運び、Kd 分配が有効なら溶存分
  fd = 1/(1 + Kd·ρs·hs/vh) だけを運ぶ(粒子態は浮遊砂と一緒に取水側に残す。fd は m_wq の
  fd_of と同じ式で、h1・hs1 は次の時刻の値。h1 は σ 有効時に矩形換算水深 = vh)。浮遊砂・
  塩水層 hss・流木 hd・瓦礫 hbd は運ばない(従来どおり取水側に残る)。
- **実装の形(案 B = 水を移すその場で物質も移す)**: boundary_h(m_swflow_enc_bc)の転送の
  中で、次の時刻の柱状量 cq1 を同じ割合で移す。cqc = wq_active かつ cq1・cqx が確保済みの
  ときだけ働く(水質が無効なら何もしない)。
  - 取水: 補助手続き intake_cq(contained にしない。§13)が f = min(dh/hb, 1)·fd の cq1 を
    取り出して質量 dm = w·gv·wfrac·A(real64)を返す。ため池セルは crs(幾何面積基底)から
    min(dh/hrs, 1) の割合。fd の Kd は m_wq_init が s%cq_kd に写す(swflow は m_wq を
    参照しない)。
  - 集計: 構造物ごとの質量 mst を水の体積 vst と同じ 1 回の par_allreduce_sumr で共有する
    (vbuf = [vst, mst]。水質なしは従来の呼び出しのまま。要素ごとの和なので、各構造物の
    取水セルが 1 ランクにある限り水の体積は従来とビット同一。取水セルが複数ランクに
    またがる構造物の扱いは従来と同じ §11)。mst は cqc のときだけ構造物数ぶん、それ以外は
    大きさ 0 で常に確保する(条件付き確保だと -fcheck=all のビルドで -Wmaybe-uninitialized の
    誤検出が出たため。無効時の実質の確保はない)。
  - 配る: mcell = mst/ncd を送り先の cq1 に mcell/(gv·wfrac·A) で足す。管路から汲む
    ポンプは送り先の水深の増分 dhd を記録場 fxco に積み、m_wq が wq_gwc_conc を同伴させる
    (噴出・陸側吐口と同じ契約)。
  - 域外: 吐口のない順方向(ncout = 0)の分と内部ソースの吸い込みの分は、取水セルの行の
    記録場 s%cqx(j,6) へ。井戸揚水は m_gwflow_pump(セルの中で閉じる処理)が cg を減らして
    同じ列に積む。どれも逐次のループ(OpenMP の並列区間の外)なので競合はない。
  - 台帳: cqx を (js:je, 1:6) に広げ、m_wq_calc の (0) が vrow(16:21) へ移してゼロ戻し。
    wq.csv の末尾に out_intake_g を追加(既存の 26 列の位置は不変)。閉合は「… −
    out_intake_g」(users_guide/wq.md)。
- **採らなかった案**: (A) 水質モジュールが後から動かす(boundary_h が汲んだ水深を記録場に
  残し、m_wq_calc がステップ末の水深から割合を逆算して動かす。ダム・ため池・浸透と同じ
  方式) — 割合がステップ末の水深基準になって 1e-4 程度ずれ、構造物ごと・セルごとの記録場と
  allreduce が 1 回増える。B は汲む瞬間の水深と柱状量で割合を決め、通信は水の allreduce に
  相乗りして回数が変わらない(浅水流側が台帳の記録場に触れるのは §30.9 に前例あり)。
  浮遊砂を運ぶ案(構造物ごとに止める切り替えを足す案を含む)は上のとおり見送り、塩水層は
  取水口の高さの考え方(淡水優先・足りない分は塩水)を決めてから(handoff 1l)。
- **できないこと・精度の限界**: (1) 転送は水と同じく瞬時で、管内の到達時間・混合・沈降は
  表さない。(2) 濁った水を汲んでも粒子態は送り先へ行かない(粒子態の多い物質では構造物の
  下流の負荷を過小、取水側の堆積を過大に見積もりうる)。(3) 同じステップにため池が吸収した
  水の物質は m_wq がステップ後に crs へ移す(fxr の契約)ので、そのステップに汲んだ分に
  乗らない。ため池から汲む水の濃度は相対で「1 ステップの吸収量 / ため池の貯留量」だけ低く、
  ため池がその分高くなる(test/wqstruct で 1e-4。質量は保存)。同じステップの雨
  (wq_rain_conc)も同様。厳密にするなら、汲む分の保留量(cq1·fxr/(h1 + fxr) の同じ割合)を
  cq1 から取り、fxr を同じ割合だけ減らせばよい(m_wq の式がちょうど残りを移す)が、記録場の
  契約をまたぐ複雑さに見合わないので入れていない。(4) 構造物ごとの流量・負荷の記録はない
  (out_intake_g は系外への取水の合計。構造物を通る負荷は測線の L にも乗らない)。
- **影響の範囲**: 構造物・取水と水質を組み合わせた回帰テストはなかった(coastal_drain・
  culvert・pump は水質なし)= 既存の reference は wq.csv の列が 1 つ増えるだけ。
