### 113.2 実装の形

- **値の持ち方。** `list_enc` の 4・2・2・4 は、init が「1 つ前の値(3・1・1・3)+ 追加の規則のフラグ」に直す
  (`opt%adv_stream`・`adv_energy`・`adv_latflux`・`cap_cellmean`)。時間ループの中の既存の判定
  (`f_advection_donor == 3`・`f_advection_lateral == 1`・`f_dry_head_cap >= 3` など)は、書き換えていない。足した値は、
  どれも「1 つ前の値の規則 + 追加の規則」なので、この形が規則の作りと合い、既定の経路の式を触らずに済む。起動時の
  表示は、足した値を指定したときだけ、その値の説明を出す(1 つ前の値の表示は出さない)。`f_advection_lateral = 2` は、
  1 と同じく、`f_advection_donor` が 3・4 でなければ効かない(0 と同じ扱いにして、そう表示する。§110.28)。
- **無効時。** 追加のメモリは 0(幾何の表 `tx%gst(8, 8)` は、`f_advection_donor = 4` のときだけ確保。連結の実流量の表
  `tx%ql` = セルあたり実数 8 個は、`f_advection_donor = 4`・`f_advection_bend = 2`・`f_advection_lateral = 2` のどれかの
  有効時だけ、流れごとの重みの控え `tx%wst` = セルあたり実数 8 個は、`f_advection_donor = 4` のときだけ確保。§113.7)。
  CPU は、流向面・側方面・登る辺ごとの論理の判定だけ(計算時間は §113.3)。
- **流れごとの重み。** 説明は `adv_prepare_mc` の `stream_share` のコメント。`adv_bend_mc` にも同じ式の写しを置く
  (中立の分 1 − w を、移流項と屈曲の規則で同じ値にするため。実流量は、それぞれの手続きの読み方 `qlk`・`qlk8` で読む。
  枠内の面のセルでは同じ値)。側方 Neumann の境界面には、3 と同じく掛けない(`f_advection_lateral = 2` も、境界面の
  側方面には掛けない。`f_advection_bend = 2` は、1 が掛かる境界面には掛かる)。
- **試作(§112.10・§112.11)から変えた所。**
  1. 8 本の連結の和を、格子の対称操作(鏡映・90° 回転)で入れ替わる対ごとに取る(`path_value` と同じ。対称な配置の
     結果が、丸めで非対称にならないように。test/tjunction の向きを変えた構成が、基本の向きと 1 桁も違わない = §113.5)。
  2. 幾何の表 `gst` で、直交する連結の値を 0 にそろえる(最大の 1e-6 倍に満たない値。前向き・直交の区別を、丸めの
     符号で決めない。正方セルでは、試作も厳密に 0 だった)。
  3. `src_fwd`(斜めの流入元の向きの判別 ω_o)は、領域の枠の外のセルを 1 とする(`qlk` と `qlk8` で値が分かれないように)。
  4. `arrival_excess` の、流入のない・少ない面のセルの扱い。試作は「流入の連結がなければ数えない」で、流入が
     丸めの大きさであるか・ないかで値が飛ぶ形だった(§110.10 と同じ型の不連続)。3 つの形を比べた:
     (a) 経路の値と同じく、流入が流出の ε 倍に満たないとき中立へ寄せる → 流量を湧き出しで与えるセルから出る辺が
     中立のままになり、test/stairbank の段のある形の流量の標準偏差の最大が 10 → 184(zs)・80 → 232 m³/s(ds)に
     増える。(b) 流出のうち流入で賄われない分を、全部「速さ 0 で到着した」と数える → 壁だけの 1 つの階段(sw)の
     水深が 0.01〜0.04 m 変わる(流れているセルの貯留の出入りまで、静止からの加速と数える)。(c) 流入が、海セルから
     でない供給(流入 + 賄われない分)の ε 倍以上あれば流入の速さそのもの、満たなければ分母を ε 倍で下から止めて
     a → 0 へ連続につなぐ → 試作と同じ値(sw は変わらず、zs・ds は 10・80 m³/s)。(c) を採った。流入のないセル
     (湧き出しのセル・流入のない池の出口)は、静止からの加速を数える(1 の経路の値は、この場合を中立にする)。
- **並列。** 読む範囲が増えるのは 2 つ。(i) `src_fwd` が、面のセルの隣のセルの 8 リンクの流量を読む(行 j − 3 の
  エッジまで)。`f_advection_lateral >= 1` の `line_flow` と同じ範囲で、mn・fwd・frw のエッジ幅 2 の交換を、
  `opt%adv_wide`(スキーム 2・3 で、`f_advection_lateral >= 1` または `f_advection_donor = 4`)で入れる(§110.25 の交換の
  条件を広げただけ。既定では、交換の中身は変わらない)。(ii) `f_dry_head_cap = 4` が、送り手のセル(行 j − 1)の m, n を
  読む。スキーム 2・3 では交換済み。スキーム 1 でも交換するようにした(`m_swflow_enc_calc` の冒頭)。`lateral_flux` が
  読む流入元のセルの m, n(行 j − 2 .. j + 1)は、セル幅 2 の交換の範囲。
- **保存・再開。** 状態変数は足していない(save の形式は変わらない)。
