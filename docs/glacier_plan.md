# 氷河モデル設計解説 (glacier_plan.md)

ENCflow の氷河モジュール(m_glacier。fn_glacier / &list_glacier)の設計文書。
陸上氷河の流動と、氷河流動に伴うカール(圏谷)地形などの形成を、既存の
水文・地形変動フレームワークの中で概算するための考え方・定式・実装契約・
既知の妥協を一つにまとめる。実装規約の正本は developer.md §45、利用者向けの
パラメータ見本は examples/List_samples/list_glacier.txt。

## 1. 位置づけと方針適合(なぜ ENCflow に入れられるのか)

氷河は水文的には「涵養・消耗を持つ多年性スノーパック」であり(OGGM と同じ
発想)、力学的には浅氷近似(SIA: Shallow Ice Approximation)が氷厚 H の
**非線形拡散方程式 1 本**に帰着する:

```
∂H/∂t = ∇・(D ∇s) + b
D = Γ H^{n+2} |∇s|^{n-1},  Γ = 2A(ρi g)^n/(n+2),  s = z + H,  n = 3
```

- **§0-5「水平は SWE+1方程式拡散が上限」の範囲内**。鉛直構造(氷温・
  応力分布)は拡散係数 D に抽象化される = §0「鉛直方向は抽象化・概念化」
  の見本そのもの。
- 離散化は既存の calc_creep(線形拡散)・m_gwflow_lateral(Boussinesq
  非線形拡散)と同じ**保存形2ループ+エッジ反対称フラックス+ハロ交換**の
  型にそのまま乗る。氷体積は機械精度で保存される(test/glacier で実測
  相対差 ~1e-15)。
- 質量収支は度日法(m_snow の延長)。エネルギー収支法は導入しない
  (§0-6「入手可能な情報に合わせて徐々に精緻化」。OGGM も度日系)。
- 高次氷力学(Full Stokes、iSOSIA 等の高次近似)は持ち込まない。カールの
  ヘッドウォール(急崖・短波長地形)は SIA の精度限界域だが、SIA+滑動
  侵食則によるカール・U字谷の一次近似的形成は氷河 LEM の先行研究で実証
  されており、「複数プロセスの同時概算」(§0-4)には十分と判断した。

設計上の布石は実装前から打たれていた: m_snow の「SWE に上限なし(多年性
雪渓・氷河涵養の布石)」、comparison.md の「SIA を将来枠に設計済み」、
handoff の将来枠 L4。本文書はその回収である。

## 2. 全体像 — 3層の時間スケールと役割分担

| 層 | 時定数 | 担当 | 時間の扱い |
|---|---|---|---|
| 水文・水理(降雪・融解水・洪水) | 秒〜日 | 既存 swflow / snow | dt(水文時間、×1) |
| 氷体流動(氷厚の発展) | 年〜10² 年 | m_glacier | dts = dt×idt×morfac |
| 氷河侵食(カール形成) | 10⁴〜10⁵ 年 | m_glacier → s%z/s%sd | 同上+リスタート連鎖 |

**morfac は geomorph と共通の 1 個**(「地形の時間」を分裂させない。
m_geomorph のヘッダ方針の延長)。m_geomorph_init が s%geo_morfac に自分の
morfac を通知し、m_glacier_init が gl_morfac との同値を検査する(不一致は
par_stop)。氷河時間=地形時間という解釈である。

### 2.1 MORFAC の二重台帳(浮遊砂 E-D の台帳分離 §19.3 と同型)

氷と水の交換は台帳を分ける:

- **氷面融解**: 水の生成は dt×1(融解水が水文・洪水を駆動)、氷の減少は
  ×morfac(1回の計算 = morfac 回の同一イベント)。
- **氷化(フィルン)**: SWE の減少割合は水文時間で評価(季節雪の寿命を
  壊さない — 地形時間で評価すると morfac が大きいとき冬の雪が季節内に
  全て氷化してしまう)、氷の増加は ×morfac(地形時間の涵養量)。

morfac=1 では両台帳が厳密に一致し質量は機械精度で保存される。morfac>1 の
氷⇄水の質量不一致は MORFAC の既知の近似として受容する(浮遊砂と同じ)。

### 2.2 実行様式(長期実験の回し方)

§32.3 の「代表水文の反復 × MORFAC × リスタート連鎖」をそのまま使う。
リスタートが ULP=0 で厳密なため、連鎖に数値的な継ぎ目が出ない。

- カール形成 10⁴〜10⁵ 年 = 代表年 × morfac(10²〜10³)× 連鎖。
- 氷河主体の理想実験(域内の水が微量)では水理の CFL が緩く、dt を大きく
  取れるため 1 ランで万年オーダーも現実的。
- 気候の長期変化は 2 通り: (a) 連鎖の 1 ラン=1 気候ステージとして temp0 を
  ラン毎に変える(実装ゼロ)、(b) &list_meteo の tempofs(§5)で 1 ラン内に
  長周期 ΔT(t) を重畳する。

### 2.3 SIA の時間刻み(適応サブサイクリング)

D = Γ H⁵|∇s|² は H⁵ で激しく変動するため(H=100 m・勾配 0.1・dx=100 m で
陽解法の限界 ≈ 0.9 年、厚く急な氷では急減)、creep のような init 時静的
検査では足りない。dt_glacier ごとの更新内で、その時点の D_max
(allreduce_max = 全ランク同一)から分割数を動的に決めてサブサイクルする。
サブサイクルごとに hi のハロ交換を行う(collective の同期は D_max の
全ランク一致で保証)。上限 gl_nsubmax はパラメータ暴走のガード。

## 3. モデル定式(&list_glacier のフラグと対応)

すべて加算的フラグの重ね合わせ(geomorph と同じ様式)。無効時ゼロコスト。

### G1: 質量収支(常時)

- **涵養**: 降雪は m_snow(二重閾値の雨雪分離+標高減率)が s%swe に蓄積。
  m_glacier は dt_glacier ごとに指数緩和 `swe×(1−exp(−dtw/tfirn))` を
  氷厚へ変換する(密度換算 ρw/ρi)。tfirn = gl_tfirn_yr(温暖氷河で
  数年〜10年)。越年した多年性 SWE だけが実質的に氷化する。
- **消耗**: 氷面の度日融解(gl_ddfi、氷は雪面より大きい度日係数が文献の
  標準)。雪(swe)に覆われたセルの氷は融けない(雪が先に融ける)。気温は
  **氷面標高 z+hi** で評価する(減率込み = 氷厚の負フィードバック。
  m_snow の雪面評価も fn_glacier 有効時は z+hi に切り替わる)。
  融解水は融雪と同型で s%h へ直接投入され、通常の swflow で流下する。

### G2: SIA 変形流動(f_glflow)

上式の D の第1項。Glen 則 n=3 固定、A = gl_afl(Pa⁻³ yr⁻¹。温暖氷 ~1e-16)。
エッジ拡散係数は両セル平均の H と法線勾配から作り(Mahaffy 型・4近傍)、
ドナー律速(1エッジの持ち出し ≤ ドナー氷体積の 1/4)で hi ≥ 0 を構造的に
保証する。海セルとは無フラックス(カービングは対象外)。

### G3: 底面滑動と氷河侵食(f_glslide / f_glero)

- **Weertman 滑動**: us = As τb³(τb = ρi g H |∇s|)。拡散係数への加算
  D_s = As(ρi g)³ H⁴ |∇s|² で SIA の枠内に収まる。As = gl_as
  (m yr⁻¹ Pa⁻³)。
- **氷河侵食**: 滑動速度べき乗則 ė = Kg・us^l(us は m/yr で評価。
  l = gl_lexp = 1〜2、Kg = gl_kg ~ 1e-4 が文献の標準域)。滑動依存なので
  f_glslide が必須。薄い氷は us ∝ H³ で自動的にほぼ侵食しない。
- **z・sd との結合**: Δz は s%z を削り、s%sd を共動減少させる(sd=0 まで
  基岩 z−sd 固定、以後は基岩侵食 = fluvial の z/sd 共動 §19.2 と同じ構造)。
  侵食後に s%e 回復と s%z(・s%sd)のハロ交換まで行う。

**侵食物の行き先(設計変更の記録)**: 当初案は「同セルの sd へ繰り入れ
(氷底ティル)」だったが、実装検討で **その閉じ方は地形的に不活性**
(削った分だけ土層が同セルで厚くなり、地表面 z がほぼ動かない = カールが
形成されない)ことが明確になった。カール形成には岩屑の搬出が本質であり、
第1弾は**系外排出**(氷内・融氷水による搬出の抽象化)とし、排出体積を
台帳に記録して dispose で報告する。氷内デブリ運搬・モレーン堆積・
proglacial への土砂供給は将来拡張(§7)。

### G4: 雪の重力再配分=雪崩(f_glava)

氷面 z+hi の8近傍最急降下勾配 tanθ が gl_ava_tanc を超えるセルの SWE を
最急降下近傍へ移送する(移送率 = min(1, (tanθ−tanθc)/tanθc)。2パス・
決定的・保存的)。急崖が雪を保持できず圏谷へ雪が集中する、カール涵養の
鍵プロセスの最簡表現(Gruber 型の保持容量モデルの縮約)。

### 気象拡張(&list_meteo。§5)

- **tempofs**: 長周期の気温オフセット系列 ΔT(t)。t_cycle で折り返さない
  実時間軸で補間し、気温入力(一様・分布とも)へ加算。代表年反復に氷期
  サイクル・温暖化トレンドを重畳する。
- **f_prec_lapse / prec_lapse / prec_zref**: 降水の標高倍率
  max(0, 1+β(z−zref))。涵養の標高依存(地形性降水)の簡便表現。
  m_precip が降水更新時に乗じる(氷河有効時は氷面標高 z+hi で評価)。
  分布降水入力(prtype=2,3)で表現できる場合はそちらを推奨(§0-12)。

## 4. 初期条件(無氷スタートと観測氷厚)

一般的な氷河シミュレーションの初期条件は用途で二分される:

1. **無氷からのスピンアップ**: 氷なしで開始し、一定(代表)気候で涵養・
   流動を回して定常氷河に達するまで助走する(山岳氷河の応答時間は数十〜
   数百年)。カール形成・氷河地形進化の研究はほぼ例外なくこの方式
   (最初の数百年は 10⁴〜10⁵ 年の地形時間の誤差の範囲であり、「その気候・
   その地形が作る氷河」が自己整合的に得られる)。
2. **観測氷厚からの直接初期化**: 現在氷河の融解水・流出予測では、氷厚
   逆推定プロダクト(Farinotti et al. 2019 コンセンサス推定、Millan et
   al. 2022 等の全球ラスタ)を切り出して与える。モデル気候と厳密には
   整合しないため、実務でも短いスピンアップで形状を馴染ませるのが通例。

ENCflow は両方をそのまま提供する: **既定は氷なし+降雪涵養**(hi=0)、
実在氷河は **fn_glacier_hi0**(m 氷厚の分布ファイル。前処理・再投影は
GIS 側 = §0-11/12 の分担)。リスタート連鎖がスピンアップ機構を兼ね、
「スピンアップ済み状態」を save として保存・分岐再利用できる(ULP=0 の
リスタート厳密性により、同じ定常氷河から気候シナリオを分岐する実験が
数値的な継ぎ目なしに組める)。定常仮定の内部逆算(perfect plasticity 等)は
モデル内部に持ち込まない(§0-12: 派生量の内部生成はしない)。

## 5. 水理との関係(抽象化)

地表水 s%h は氷の下・上を区別せず**地盤 z の上を流れる**(氷は水理に
不可視)。融解水・氷上の降雨は h に入り通常の swflow で流下する。

- 氷河底の流水は実際には氷面勾配が支配する水理ポテンシャルに従うが、
  平面2次元の概算としては地盤流下で代用する(既知の妥協)。
- 氷の下の geomorph 流水プロセス(掃流・浮遊等)は抑止しない = 融解水の
  河床作用を「氷底流路の侵食」の抽象とみなす。
- 氷河湖決壊(GLOF)・カービング・氷内水系は対象外(将来拡張)。

## 6. 実装契約の要点(m_glacier ヘッダと §45 の要約)

- 状態は s%hi(m 氷柱)。確保は有効時のみ(§0-8)。場出力 Hi。リスタートは
  私有ファイル glacier.dat(契約5)。S 台帳(S_total)に水当量で算入。
- 実行順序: snow_calc の後(SWE を受ける)・swflow の前(融解水を流す)。
  dt_glacier tick 内の順序は 雪崩 → 氷化 → 流動 → 侵食(ヘッダの契約)。
- owner-compute(自帯 js..je)+帯界面の冗長計算+必要箇所のハロ交換。
  tick 判定・サブサイクル数は全ランク同一(collective 安全)。
- STG 非対応(z の時間発展に追従しない。geomorph と同じ init ガード)。
- 近傍マスクの検査は g%x(0 縁取りあり)を先に、g%sw(縁取りなし)は
  その内側で(.and. の短絡評価は言語仕様で保証されない。-fcheck 実検出)。

## 7. 検証(test/glacier)と既知の妥協・将来拡張

### 検証(2026-08-16。gfortran 13.3 / OpenMPI)

- **Halfar ドーム**(平坦床 SIA の相似解): 地形時間 ≈ 2t0 の流動で
  平均絶対誤差 2.35 m(H0=200 m の 1.2%)、中心誤差 4.7 m、最大誤差
  38.6 m(氷縁 1 セル未満の位置誤差相当。解析解は氷縁で勾配無限大)。
  氷体積 S_total の相対変化 1.8e-15 = 機械精度保存。
- **カール形成スモーク**(円錐山体・全プロセス有効): 氷河形成
  (max Hi ≈ 104 m)・氷河下侵食(dz < 0)・隆起なし・NaN なしを検定。
- 無効時: 全回帰ケース(wave/chichibu/creep/fluvial/suspend/wash/debris/
  slide/tide/sedinflow/gtif)が既存 reference とビット一致(逐次+MPI)。
- -fcheck=all np=2(glacier 有効+chichibu)クリーン。np=1,2,4 の
  ランク数不変を確認。

### 既知の妥協(文書化済みの割り切り)

- 氷温・多温構造なし(温暖氷一定の A)。cold-based(凍着)無侵食の閾値
  なし。カービング・氷河湖・氷内/氷底水系なし。
- フィルン化は単一時定数の指数緩和(密度発展・圧密過程は持たない)。
- 侵食物は系外排出(§3 G3。モレーン・氷内デブリは将来)。
- morfac>1 での氷⇄水の質量不一致(MORFAC の既知の近似。§2.1)。
- 水理は地盤の上(§5)。氷厚が水理断面を塞ぐ効果はない。

### 将来拡張の候補

- 氷底ティルの明示(侵食物→ till 層→氷運搬→モレーン堆積→ proglacial の
  土砂プロセスへの引き渡し。氷河期→後氷期の土砂供給の時代連結)。
- 雪崩の保持容量モデル化(Gruber 型)、ddf の季節変化、昇華。
- 有効圧依存の滑動(氷河底水圧との結合)、GLOF(ため池・ダム破堤機構の
  流用)、分布 A(氷温プロキシ)。
- カール実証実験の恒常ケース化(雪線を斜面中腹に置いた理想山体で 10⁴ 年
  スケールの圏谷形成を定量確認する長期ラン)。
