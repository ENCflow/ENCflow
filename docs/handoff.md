   - 結論: 質量は作られていない。全セルの Σh(負値込み)は注入量と
     機械精度で一致する(一時計装の台帳測定で 600 ステップ累積残差

     ファクト: f_exflux_reduction=0 では前縁で dh > h の過大流出が

     ため(m_state.f90 の hsum)、負水深の欠損が S から見えず
     |Σ min(h,0)| ぶん S が過大に見える。乾床注入 30s で
     S 超過 +1.407e-4 m³ ⇔ 負水深計 −1.408e-4 m³(湧き出し)、
     +2.9302e-4 ⇔ −2.9302e-4 m³(区間流入)と全桁一致。
   - 指紋: 台帳は t≈22.5s(最初の h1<0 発生)まで機械精度で厳密。
     f_exflux_reduction=1 にすると負水深がほぼ出ず超過も消える
     (+0.023% → +0.00007%)。適応 RK は無関係。dt/2 で微減。
   - 対処の選択肢(未決。実装前に議論):
     (a) 乾床前縁を扱う計算では f_exflux_reduction=1 を推奨する運用
         (本来この目的のフラグ。例題 param の既定も要検討)
     (b) S モニタの負水深の扱いを変える(負値も総和する、または
         負水深の総量を別枠で表示して見かけの超過をなくす)

   - **運動量保存形の移流(f_advection_scheme = 2, 3)が、区間流入で
     駆動した直線河道(幅 5 セル = 50 m・深さ 4.7 m・両岸が 6〜7 m の
     乾いた壁セル)で 5 分周期・±6 % の流量振動を自励する**。調査結果
     (2026-10-13。再現は examples/levee_breach の param.txt でスキームを
     3 に戻す。破堤なし 90 分の変種は work/ に置いた):
     - 定常スタート(流量・水位一定)からも 50 分頃に成長し(e-folding
       ≈ 7 分)、±6 % で飽和する限界周期。周期 ≈ 5 分は河道長 800 m の
       長波の往復時間。振幅分布は流入端が腹(水位 ±0.34 m)、j ≈ 20 に節、
       水位規定端が節の定在波。
     - 必要条件: 保存形移流(2 でも 3 でも同じ振幅)、**区間流入境界**
       (同じセルに同じ流量を内部ソース &list_bound_source で入れると
       消える)、弱い摩擦(河道粗度 0.05 では消える)。dt(0.5/0.25)、
       流入配分(0/2)、下流端(水位規定/自由流出)、f_exflux_reduction には
       依存しない。スキーム 1 では出ない。
     - **直接の症状は横断方向の 2Δx(市松)モード**: スキーム 3 の 80 分の
       流量場は河道 5 列で [16.1, 9.6, 18.5, 9.6, 16.1] m²/s(j = 2)、
       [15.4, 10.7, 17.2, 10.7, 15.4](j = 10)と列ごとに交互になり、
       スキーム 1 では [14.4, 13.9, 13.6, 13.9, 14.4] と滑らか。保存形の
       側方面は「平行エッジの実流量の c 側・n 側の平均」と「流入側のみ
       隣接エッジの流速、壁・乾床側は u_e」で評価するため、列ごとに交互
       する横断モードに対する運動量交換(減衰)がほぼゼロになり、区間流入
       境界(面ごとの uv 規定)が種を与えると減衰せずに縦断の定在波と
       結合して成長する、というのが現時点の見立て。
     - 河道だけの領域(5 列、壁 = 領域外縁)ではスキーム 2 は安定、
       スキーム 3 だけが流入端の水深低下(2.3 m、Fr > 1)と跳水の振動で
       発散に近い振幅(Q std 210 m³/s)になり、下流端を自由流出にすると
       消える。こちらは MUSCL の面値再構成が流入境界近傍で反拡散に
