## 現在の到達点(要約。2026-10-18)

- MPI 化は完了・検証済み: 帯分割+ハロ交換(案A)、確保縮小(第二段)、
  静的データの帯化(方式a・2点縮小)、m_record の点集約、決定的リダクション。
  検証の柱 =「np=1,2,4 が逐次 reference に ULP=0」+「-fcheck np>=2 を先に回す」
  (-Ofast では逐次↔MPI ビルド間の最終桁差が出るため、厳密なビット検証は
  -O2 厳密数学で行う。§28.3・§63.6)。
- 動的状態化: s%z(計算標高。g%z = 入力地形、rank0 のみ全域保持)に加え、
  空隙率 s%gv / 有効慣性係数 s%lm(§63.1。変更は m_state_set_gv 経由で
  体積保存)。
- 物理プロセスモジュール: 浅水流(ENC/STG)、河道・堤防・構造物族(ポンプ・
  カルバート・分水・ダム/湖沼)、降雨・遮断・蒸発散・気象、2 層地下水+
  管路連続体+井戸+凍土、淡塩 2 層、水質、積雪・融雪、氷河、土砂・地形
  変化(creep/fluvial/suspend/wash/splash/debris/bedslide)、溶岩流、
  流木、家屋破壊・瓦礫、土壌雨量指数。有効化は fn_* の有無、無効時は
  メモリ・CPU ゼロ追加。
- 「まず動かしてみる」既定値方針: geomorph(§62)・流木(§50.6)・家屋破壊・
  瓦礫(§63.9)・地下水(§64。sd0 の既定 1 m を含む)・積雪と氷河(§65)・
  遮断・蒸発散・溶岩流(§66)は物性・校正値に既定を持ち、採用値を
  "(default)" 付きで表示。型別の推奨値は各ガイド章の「パターン別の推奨値」。
  wq は物質依存のため既定を置かず「物質別の代表値」表(§66)。与件
  (強制場・境界・構造物諸元・分布ファイル・噴火口・井戸)には既定を置かず、
  それらの章(浅水流・河道・境界・潮位・初期条件・地理情報の粗度・淡塩・
  SWI・構造物・計測・降雨)には「とりあえず動かしてみる」最小入力と
  型別の目安表を置いた(2026-10-01。日英)。潮位は titype 未指定 = 固定
  潮位 0 m の既定(§67)で空の &list_tide が最小入力。
- 河道水理(fn_channel。§17・§18・§26・§68.9〜§68.33): 堤防(壁は天端が
  両側地盤より高いエッジだけ、堰越流に追い越し禁止上限)、開口補正、
  サブグリッド幅(壁なし=自然河岸は動的開口+動的通水率 cwxd)、σ 断面
  (天端固定 D(t)、濃度 hs/vh)、幅河道終端の出口規則。等流ベンチマーク
  test/bendloss(軸・対角・折れ線 × W × 矩形・σ)が Manning 解析値に一致、
  リスタート往復ビット一致、np=1,2,4 ULP=0。測線計測は ENC でエッジ流量
  方式(§24.2。観測者規律 §24.1 の最初の適用)。
- 利用者向け文書: ユーザーガイド 25 章(日英ミラー)+全パラメータ索引
  556 項目+注釈付き namelist 見本(List_samples 日英)+チュートリアル+
  例題(landslide_tsunami・timberyard・tsunami_town 等は README に図と数表)。
- 移流項(developer.md §68・docs/advection_design.md): 既定は運動量保存形+
  MUSCL(f_advection_scheme = 3。2026-10-13 昇格)。斜め副格子モードは側方面の
  反対偶奇リンク結合で減衰(§68.36)、片側しか無い面はその 1 本が面と同程度の
  深さ(1/2〜2 倍)のときだけ使う(§68.37 の壁面扱いは壁沿いの行で発散 →
  §68.39 で水深の切り分けに改定、2026-10-18)。スカラー輸送もリンクごとの MUSCL が既定

00b. **スカラー輸送(advect_scalar)の 1 次風上の数値拡散を計測(2026-10-13。
   test/tracer 新設)**: 縦断 D = u·Δx·(1 − Cr)/2(u = 0.91 m/s、Δx = 10 m で
   4.3 m²/s、Δx = 20 m で 8.7 m²/s。理論比 1.04〜1.05)、横断は流れが
   なくても ENC の斜め配分で Dy = 0.293·u·Δy(2.7 m²/s。理論比 0.94)。
   浅水流の dt ではスカラーの Cr が 0.1〜0.2 なので D は dt にほぼ依存せず
   格子幅に比例する。物理の分散(Elder 型 0.3 m²/s 級)を 1〜2 桁上回る。
   対象は地表の全スカラー(hs・cq・hss・hd・hbd)と地下水の同伴輸送(cg)
   (計測の対象範囲。下の実装は地表スカラーのみで、cg は対象外)。
   → **f_scalar_scheme = 3(リンクごとの MUSCL)として実装済み(2026-10-13。
   developer.md §78)**。縦断 D が 1/3〜1/5、横断 Dy が 1/14 に下がり、
   負値・行き過ぎなし。**既定は 3(2026-10-13 に 1 から昇格。§78)**。横断の斜め配分による拡散も、リンクごとの
   MUSCL 再構成(斜めリンクの面値をそのリンク方向の風上・さらに風上の
   セルから再構成)で主要項が消える: 横断に線形な濃度場では、斜めリンクの
   面値がリンク中点の値になり、受け手セルの 0.414/0.293/0.293 の重み付き
   和が中央値に一致する(1 次では両斜めの供給元の平均 = 3 点平滑化が
   Dy = 0.293·u·Δy を生む)。残るのは極値での限定器の退化(プルーム中心の
   ピーク)で、2 次精度になる。乾いたセルへ進む前線(土石流・氾濫の先端)は
   供給元の濃度をそのまま持ち込むので縦断の数値拡散は効かず、効くのは
   湿潤域内の濃度勾配(清水との混合、点源プルーム、合流)と横断方向。
   影響が実用上大きいのは、局所の濃度・密度のピークが判定を駆動する
   流木・瓦礫の荷重(fd)と家屋破壊判定、土石流の濃度依存レオロジー、
   水質のピーク濃度。総量・堆積量には効かない。
   → **既定を 3 に変更(2026-10-13。影響調査は §78 検証)**。全 test の

9. **乾床薄膜先端の「質量微増」— 原因特定済み(2026-08-03)。対処は要議論**
   - 結論: 質量は作られていない。全セルの Σh(負値込み)は注入量と
     機械精度で一致する(一時計装の台帳測定で 600 ステップ累積残差
     ~1e-16 m³)。見かけの +0.1% は S モニタの定義による集計アーティ
     ファクト: f_exflux_reduction=0 では前縁で dh > h の過大流出が
     h1 < 0 のセルを作るが、m_state の診断集約は h <= 0 を cycle する
     ため(m_state.f90 の hsum)、負水深の欠損が S から見えず
     |Σ min(h,0)| ぶん S が過大に見える。乾床注入 30s で
     S 超過 +1.407e-4 m³ ⇔ 負水深計 −1.408e-4 m³(湧き出し)、
     +2.9302e-4 ⇔ −2.9302e-4 m³(区間流入)と全桁一致。
   - 指紋: 台帳は t≈22.5s(最初の h1<0 発生)まで機械精度で厳密。
     f_exflux_reduction=1 にすると負水深がほぼ出ず超過も消える
     (+0.023% → +0.00007%)。適応 RK は無関係。dt/2 で微減。
   - 対処の選択肢(未決。実装前に議論):
     (a) 乾床前縁を扱う計算では f_exflux_reduction=1 を推奨する運用
         (本来この目的のフラグ。例題 param の既定も要検討)
     (b) S モニタの負水深の扱いを変える(負値も総和する、または
         負水深の総量を別枠で表示して見かけの超過をなくす)
     (c) 抑制 OFF でも負水深を許さない設計変更(挙動変更なので
