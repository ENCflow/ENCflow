# out2vtk — 計算結果を ParaView で 3D 可視化する

計算結果の分布出力(`result/` の txt / bil+hdr / GeoTIFF)を、
[ParaView](https://www.paraview.org/) でそのまま開ける VTK 形式に変換する
後処理ユーティリティです。地形の 3D 表示、水面の時系列アニメーション、
QGIS で書き出した地図・衛星画像のドレープ(地形への貼り付け)ができます。

計算本体には手を入れない方針です(可視化専用形式は本体の出力に足さず、
変換は後処理で行う。developer.md §0)。閾値や対象変数を変えて何度でも
変換をやり直せます。

## 出力されるファイル

`result/vtk/`(変更可)に以下を書き出します。

| ファイル | 内容 |
|---|---|
| `terrain.vts` | 地形面(Z0000 の標高で持ち上げた曲面)。テクスチャ座標付き |
| `flood_XXXX.vts` | 各出力時刻の水面(標高+水深の曲面)。水深ほか点データ同梱 |
| `flood.pvd` | 時系列コレクション。ParaView のタイムラインが実時刻 t(秒)になる |
| `summary.vts` | 統計量(最大水深・最大流速など。番号 9999 の出力があるとき) |

最終状態の再掲(番号 9998)は時系列と重複するため出力しません。

## ビルド

```
cd utils/out2vtk
make install        # → リポジトリ直下の bin/ にコピーされます
```

リポジトリ直下の `make install` でも本体・他ユーティリティと一緒に
ビルド・コピーされます。

## 使い方

計算ケースのディレクトリ(`result/` がある場所)で:

```
../../bin/out2vtk param.txt    # 計算のパラメータファイルを渡す(推奨)
../../bin/out2vtk              # 全項目デフォルト
../../bin/out2vtk out2vtk.nml  # 設定ファイル指定
```

計算のパラメータファイルを渡すと、`dir_result`・`outfn_suffix` と
格子情報(`&list_geoinfo` の nx, ny, dx, dy)をそのまま引き継ぐので、
多くの場合これだけで済みます(rerecord・lu2mask と同じ流儀)。

閾値などを変えたいときは設定ファイル(namelist 形式、すべて省略可)を
渡します:

```
&out2vtk
  fn_param = "param.txt"   ! 計算のパラメータファイル(上記の引き継ぎ)
  dir_result = ""          ! 分布出力のディレクトリ(空 = param 由来 or result)
  dir_vtk = ""             ! VTK 出力先(空 = dir_result/vtk)
  outfn_suffix = ""        ! 計算時の outfn_suffix と同じ値(空 = param 由来)
  hmin = 0.01              ! 水膜閾値(m)。下記参照
  vars = "H", "V", "Pr"    ! 同梱する変数の接頭辞(省略 = 検出された全部)
  nx = 0                   ! 格子数(通常は自動取得。下記参照)
  ny = 0
  csx = 0.0                ! セル寸法 m(地理参照が無い txt 出力用)
  csy = 0.0
/
```

- **水膜閾値 `hmin`**: 水深がこれ未満のセルは「乾いている」とみなし、
  水面系の変数(H, WSE, 流速など)を NaN にします。数値的な薄い水膜や
  定常的な河道の水位を消して洪水だけを見せるための閾値で、まず既定の
  1 cm、広域で表示がうるさければ 5〜10 cm を試してください。
  `hmin = 0.0` で無効(全セル出力)になります。
- **変数の選択 `vars`**: 出力ファイルが検出された変数はすべて同梱するのが
  既定です。ファイルサイズを抑えたいときに接頭辞(H, E, u, v, V, Q, Pr,
  Hg, Sw など m_output の出力接頭辞)で絞れます。
- **格子情報**: 格子数と座標は `Z0000` の hdr / GeoTIFF から自動取得し、
  txt 出力のみの場合も格子数はファイルから数えます。地理参照がない場合は
  南西端原点のローカル座標(m)になり、セル寸法はパラメータファイル
  (`fn_param` または引数)か `csx`, `csy` から取ります(どちらも
  ないときは 1 m になるので、txt 出力ではパラメータファイルを渡して
  ください)。bil 出力なのに hdr がない(地理参照なしのケースで
  `f_output_mode = 2`)ときだけ `nx`, `ny` の指定が必要です。

### 同梱される点データ

- `H`(水深)と `WSE`(水面標高 = 地盤高 + 水深)は常に入ります。
- `u`, `v` が両方あると流速ベクトル `velocity`(x 東向き正・y 北向き正)
  も作られ、Glyph フィルタで矢印表示できます。
- 降雨強度 Pr・地下貯留 Hg・積雪 Sw など地表・地中の量は hmin の
  マスクをかけずにそのまま入ります(乾燥域でも意味を持つため)。
- 流下方向フラグ(Ddd, Dda)は面の色分けに不向きなため対象外です。

## ParaView クイックスタート

1. **File → Open** で `flood.pvd` と `terrain.vts` を開き、両方 **Apply**。
2. `terrain.vts` の Coloring を `Solid Color`(灰色など)にする。
3. `flood.pvd` の Coloring を `H`(または `WSE`)にする。乾燥セルは NaN
   なので、カラーマップ編集(Edit Color Map)で **NaN の不透明度
   (Opacity)を 0** にすると水域だけが表示される。
   代わりに **Threshold フィルタ**(対象 `H`、下限 = hmin)でもよい。
4. 再生ボタン ▶ でアニメーション。タイムラインは計算の実時刻(秒)。
   **View → Time Inspector** で時刻表示、**Filters → Annotate Time** で
   画面内に時刻を焼き込める。
5. 地形の起伏が小さく見えるときは、両方のオブジェクトに
   **Filters → Transform** を掛けて Scale を `(1, 1, 5)` のように z 方向
   だけ拡大する(鉛直誇張)。
6. 動画の書き出しは **File → Save Animation**(AVI / Ogg / 連番 PNG)。

視点は水面と一緒に動かないので、先に地形だけ表示して構図を決めてから
再生すると楽です。

## 地図・衛星画像のドレープ(QGIS との連携)

ParaView は Web 地図を直接読めませんが、**計算領域と同じ範囲の画像を
QGIS で書き出して地形に貼る**ことで、衛星写真や地図の上を水が流れる
3D アニメーションが作れます。`terrain.vts` には格子範囲を 0..1 に
正規化したテクスチャ座標が入っているので、貼り付けは選ぶだけです。

### QGIS で背景画像を作る

1. QGIS に計算領域のラスタ(出力の GeoTIFF や bil+hdr、例えば
   `Z0000.tif`)を読み込む。**プロジェクトの CRS を計算の投影座標系に
   合わせる**(ラスタと同じ CRS にする。Web メルカトルのままにしない)。
2. 背景にしたいレイヤを重ねる。例:
   - XYZ タイル(地理院タイルの標準地図・写真、衛星画像タイルなど)
   - 行政の航空写真・オルソ画像
3. **プロジェクト → インポートとエクスポート → 地図を画像に保存**。
   - 「範囲」は **レイヤから計算**で手順 1 のラスタを選ぶ
     (= 画像の縁が格子の外縁と一致する。ここが合っていれば位置ずれしない)。
   - 解像度は目安 2000〜8000 px 程度。PNG で保存する。
   - 背景レイヤだけを表示状態にしておく(計算ラスタは非表示に)。

### ParaView で貼る

1. `terrain.vts` を選択し、**Properties パネル下部の Display →
   Texture** で保存した PNG を選ぶ(見つからないときは歯車アイコンで
   詳細プロパティを表示)。
2. Coloring を `Solid Color`・色を白にすると画像がそのまま見える。
3. 水面(`flood.pvd`)を上に重ねて再生すれば、衛星写真の上を洪水が
   広がるアニメーションになる。水面の Opacity を 0.7 程度にすると
   下の地物が透けて見やすい。

経緯度(度単位)の格子は ParaView 内ではメートル換算のローカル座標に
なりますが、テクスチャ座標は格子範囲の正規化なのでドレープはそのまま
使えます。

## 補足・制約

- 座標は投影座標系の実座標(m)です(座標の桁落ちを避けるため点座標は
  倍精度で書いています)。地理参照がない場合と経緯度格子の場合は
  南西端原点のローカル座標(m)です。
- 変換元は `FILENUMBER.csv` に載っている番号だけです(途中で止めた
  計算でもそのまま使えます)。
- 地形変化(geomorph)の計算で各時刻の Z 出力があるときは、水面の
  高さは各時刻の地形で計算します。ただし `terrain.vts` は Z0000 固定です
  (地形自体のアニメーションは今後の課題)。
- VTK ファイルはリトルエンディアン前提です(既存の bil 出力と同じ。
  対応環境の x86 / arm / NEC VE はすべて該当)。
- ファイルサイズの目安は 1 時刻あたり約 (32 + 4×変数数) バイト × セル数。
  大きすぎるときは `vars` で絞ってください。
